# Lesson 3: Assertions and FluentAssertions

## Learning Objectives

By the end of this lesson, you will be able to:
- Write clear, expressive assertions using xUnit
- Use FluentAssertions to improve test readability
- Choose appropriate assertion methods for different scenarios
- Write assertions that provide meaningful failure messages
- Understand assertion best practices and anti-patterns

---

## Introduction

Assertions are the gatekeepers of your tests - they determine whether your code behaves as expected. Well-written assertions make tests self-documenting and provide clear feedback when things go wrong. Poor assertions create confusion and waste debugging time. This lesson covers how to write effective assertions that clearly communicate intent.

## Key Concepts Summary

### Standard xUnit Assertions

xUnit provides built-in assertion methods in the `Assert` class:

**Equality Assertions:**
```csharp
[Fact]
public void StandardAssertions_EqualityExamples()
{
    // Basic equality
    Assert.Equal(5, calculator.Add(2, 3));
    
    // Not equal
    Assert.NotEqual(10, calculator.Add(2, 3));
    
    // Same reference
    var obj1 = new object();
    var obj2 = obj1;
    Assert.Same(obj1, obj2);
    
    // Different references
    var obj3 = new object();
    Assert.NotSame(obj1, obj3);
}
```

**Null Assertions:**
```csharp
[Fact]
public void StandardAssertions_NullExamples()
{
    string? nullString = null;
    string nonNullString = "hello";
    
    Assert.Null(nullString);
    Assert.NotNull(nonNullString);
}
```

**Boolean Assertions:**
```csharp
[Fact]
public void StandardAssertions_BooleanExamples()
{
    Assert.True(user.IsActive);
    Assert.False(user.IsDeleted);
}
```

**Collection Assertions:**
```csharp
[Fact]
public void StandardAssertions_CollectionExamples()
{
    var numbers = new[] { 1, 2, 3, 4, 5 };
    
    Assert.Contains(3, numbers);
    Assert.DoesNotContain(10, numbers);
    Assert.Empty(new int[0]);
    Assert.NotEmpty(numbers);
    
    var users = new List<User> 
    { 
        new User { Id = 1, Name = "Alice" } 
    };
    Assert.Contains(users, u => u.Name == "Alice");
}
```

**Exception Assertions:**
```csharp
[Fact]
public void StandardAssertions_ExceptionExamples()
{
    // Assert that an exception is thrown
    Assert.Throws<ArgumentNullException>(() => 
        service.Process(null));
    
    // Assert specific exception with message
    var ex = Assert.Throws<InvalidOperationException>(() => 
        service.ProcessEmpty());
    Assert.Contains("cannot be empty", ex.Message);
    
    // Assert exception type or derived types
    Assert.ThrowsAny<Exception>(() => 
        service.MightThrowAnything());
}
```

**Range Assertions:**
```csharp
[Fact]
public void StandardAssertions_RangeExamples()
{
    var temperature = 25.5;
    
    Assert.InRange(temperature, 20.0, 30.0);
    Assert.NotInRange(temperature, 0.0, 15.0);
}
```

### FluentAssertions - Better Readability

FluentAssertions provides a more natural, readable syntax:

**Installation:**
```bash
dotnet add package FluentAssertions
```

**Basic Examples:**
```csharp
using FluentAssertions;

[Fact]
public void FluentAssertions_BasicExamples()
{
    // Equality
    calculator.Add(2, 3).Should().Be(5);
    
    // Comparison
    user.Age.Should().BeGreaterThan(18);
    user.Age.Should().BeLessThanOrEqualTo(65);
    
    // Null checks
    user.Should().NotBeNull();
    user.Email.Should().BeNull();
    
    // Boolean
    user.IsActive.Should().BeTrue();
    user.IsDeleted.Should().BeFalse();
}
```

**String Assertions:**
```csharp
[Fact]
public void FluentAssertions_StringExamples()
{
    var message = "Hello, World!";
    
    message.Should().Be("Hello, World!");
    message.Should().Contain("World");
    message.Should().StartWith("Hello");
    message.Should().EndWith("!");
    message.Should().NotBeEmpty();
    message.Should().HaveLength(13);
    
    // Case-insensitive
    message.Should().BeEquivalentTo("hello, world!");
    
    // Wildcards
    message.Should().Match("Hello, *!");
    
    // Regex
    var email = "user@example.com";
    email.Should().MatchRegex(@"^[\w-\.]+@([\w-]+\.)+[\w-]{2,4}$");
}
```

**Collection Assertions:**
```csharp
[Fact]
public void FluentAssertions_CollectionExamples()
{
    var numbers = new[] { 1, 2, 3, 4, 5 };
    
    numbers.Should().Contain(3);
    numbers.Should().NotContain(10);
    numbers.Should().HaveCount(5);
    numbers.Should().NotBeEmpty();
    
    // Order
    numbers.Should().BeInAscendingOrder();
    numbers.Should().Equal(1, 2, 3, 4, 5);
    
    // Complex objects
    var users = new List<User>
    {
        new User { Id = 1, Name = "Alice", Age = 30 },
        new User { Id = 2, Name = "Bob", Age = 25 }
    };
    
    users.Should().ContainSingle(u => u.Name == "Alice");
    users.Should().Contain(u => u.Age > 20);
    users.Should().AllSatisfy(u => u.Age.Should().BeGreaterThan(0));
    
    // Equivalence (deep comparison)
    var expected = new[] { 1, 2, 3, 4, 5 };
    numbers.Should().BeEquivalentTo(expected);
}
```

**Object Assertions:**
```csharp
[Fact]
public void FluentAssertions_ObjectExamples()
{
    var user = new User 
    { 
        Id = 1, 
        Name = "Alice", 
        Email = "alice@example.com",
        Age = 30
    };
    
    // Property assertions
    user.Id.Should().Be(1);
    user.Name.Should().Be("Alice");
    user.Email.Should().NotBeNullOrEmpty();
    
    // Multiple properties
    user.Should().Match<User>(u => 
        u.Name == "Alice" && 
        u.Age == 30);
    
    // Equivalent objects (deep comparison)
    var expected = new User 
    { 
        Id = 1, 
        Name = "Alice", 
        Email = "alice@example.com",
        Age = 30
    };
    user.Should().BeEquivalentTo(expected);
    
    // Partial comparison
    user.Should().BeEquivalentTo(expected, options => 
        options.Excluding(u => u.Id));
}
```

**Exception Assertions:**
```csharp
[Fact]
public void FluentAssertions_ExceptionExamples()
{
    // Basic exception
    Action act = () => service.Process(null);
    act.Should().Throw<ArgumentNullException>();
    
    // Exception with message
    act.Should().Throw<ArgumentNullException>()
        .WithMessage("*cannot be null*")
        .And.ParamName.Should().Be("input");
    
    // Multiple conditions
    act.Should().Throw<ArgumentException>()
        .WithMessage("Invalid input")
        .Where(ex => ex.ParamName == "input");
    
    // Should not throw
    Action validAct = () => service.Process(validData);
    validAct.Should().NotThrow();
}
```

**Date/Time Assertions:**
```csharp
[Fact]
public void FluentAssertions_DateTimeExamples()
{
    var created = DateTime.UtcNow;
    
    created.Should().BeCloseTo(DateTime.UtcNow, TimeSpan.FromSeconds(1));
    created.Should().BeAfter(DateTime.UtcNow.AddDays(-1));
    created.Should().BeBefore(DateTime.UtcNow.AddDays(1));
    
    var birthday = new DateTime(1990, 5, 15);
    birthday.Year.Should().Be(1990);
    birthday.Month.Should().Be(5);
    birthday.Day.Should().Be(15);
}
```

### Why FluentAssertions?

**Standard xUnit:**
```csharp
Assert.Equal(5, calculator.Add(2, 3));
// When it fails: "Assert.Equal() Failure: Expected: 5, Actual: 7"
```

**FluentAssertions:**
```csharp
calculator.Add(2, 3).Should().Be(5);
// When it fails: "Expected calculator.Add(2, 3) to be 5, but found 7."
```

**Benefits:**
1. **More Readable** - Reads like natural language
2. **Better Error Messages** - Contextual, clear failure messages
3. **Chainable** - Multiple assertions in one statement
4. **Extensible** - Easy to add custom assertions
5. **Comprehensive** - Covers more scenarios out of the box

### Custom Assertion Messages

**xUnit:**
```csharp
Assert.True(user.IsActive, $"User {user.Name} should be active");
```

**FluentAssertions:**
```csharp
user.IsActive.Should().BeTrue(
    because: "we just activated user {0}", 
    becauseArgs: user.Name);
```

**Failure output:**
```
Expected user.IsActive to be true because we just activated user Alice, but found false.
```

### Assertion Best Practices

**✅ DO: One Logical Assertion Per Test**
```csharp
[Fact]
public void CreateUser_ValidData_CreatesUserWithCorrectProperties()
{
    var user = service.CreateUser("Alice", "alice@example.com");
    
    // These assertions all verify the same concept: "user created correctly"
    user.Should().NotBeNull();
    user.Name.Should().Be("Alice");
    user.Email.Should().Be("alice@example.com");
    user.CreatedDate.Should().BeCloseTo(DateTime.UtcNow, TimeSpan.FromSeconds(1));
}
```

**❌ DON'T: Mix Unrelated Assertions**
```csharp
[Fact]
public void TestEverything() // Bad!
{
    user.Name.Should().Be("Alice");
    order.Total.Should().Be(100);
    product.IsAvailable.Should().BeTrue();
}
```

**✅ DO: Use Specific Assertions**
```csharp
// ✅ Good - Specific
users.Should().ContainSingle();

// ❌ Bad - Generic
Assert.Equal(1, users.Count);
```

**✅ DO: Provide Context in Failure Messages**
```csharp
discount.Should().Be(0.25m, 
    because: "premium users with 5+ years membership get 25% discount");
```

**❌ DON'T: Assert Inside Loops**
```csharp
// ❌ Bad - First failure stops the test
foreach (var item in items)
{
    item.IsValid.Should().BeTrue();
}

// ✅ Good - See all failures
items.Should().AllSatisfy(item => 
    item.IsValid.Should().BeTrue());
```

**✅ DO: Use Appropriate Precision for Floating Point**
```csharp
// ❌ Bad - Floating point comparison can fail
result.Should().Be(0.3);

// ✅ Good - Allow for precision
result.Should().BeApproximately(0.3, 0.0001);
```

### Common Patterns

**Testing Properties:**
```csharp
[Fact]
public void CreateOrder_ValidData_SetsAllProperties()
{
    var order = service.CreateOrder(customerId: 1, total: 99.99m);
    
    order.Should().NotBeNull();
    order.CustomerId.Should().Be(1);
    order.Total.Should().Be(99.99m);
    order.Status.Should().Be(OrderStatus.Pending);
    order.CreatedDate.Should().BeCloseTo(DateTime.UtcNow, TimeSpan.FromSeconds(1));
}
```

**Testing Collections:**
```csharp
[Fact]
public void GetActiveUsers_ReturnsOnlyActiveUsers()
{
    var users = service.GetActiveUsers();
    
    users.Should().NotBeEmpty();
    users.Should().AllSatisfy(u => u.IsActive.Should().BeTrue());
    users.Should().NotContain(u => u.IsDeleted);
}
```

**Testing Exceptions:**
```csharp
[Fact]
public void ProcessOrder_InvalidData_ThrowsValidationException()
{
    var invalidOrder = new Order { Total = -100 };
    
    Action act = () => service.ProcessOrder(invalidOrder);
    
    act.Should().Throw<ValidationException>()
        .WithMessage("*total cannot be negative*")
        .And.Errors.Should().ContainKey("Total");
}
```
