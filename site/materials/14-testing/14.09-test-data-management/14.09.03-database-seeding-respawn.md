# Lesson 3: Database Seeding and Cleanup with Respawn

## Learning Objectives

By the end of this lesson, you will be able to:
- Implement efficient database seeding strategies for integration tests
- Use Respawn to quickly reset databases between tests
- Understand test isolation strategies and their trade-offs
- Combine Testcontainers with database seeding
- Design maintainable database setup and teardown workflows

---

## Introduction

Integration tests need data in databases, but managing that data is challenging. Creating new databases for each test is slow. Sharing databases between tests causes interference. This lesson teaches you how to efficiently seed databases and reset them between tests using Respawn, enabling fast, isolated integration tests.

**Key principle:** Test isolation is non-negotiable, but you don't need to recreate databases from scratch for every test. Smart cleanup strategies give you speed and isolation.

## Key Concepts Summary

### The Database Testing Challenge

```
Problem: Integration tests need database state

Approach 1: Create new database per test
  ✅ Perfect isolation
  ❌ Extremely slow (seconds per test)
  ❌ Resource intensive

Approach 2: Share database, no cleanup
  ✅ Fast
  ❌ Tests interfere with each other
  ❌ Random failures
  ❌ Test order dependency

Approach 3: Share database, full teardown/rebuild
  ✅ Good isolation
  ❌ Slow (recreate schema every time)

Approach 4: Share database, smart cleanup (Respawn)
  ✅ Fast (milliseconds per reset)
  ✅ Good isolation
  ✅ Resource efficient
  ✅ Winner! ⭐
```

### Introduction to Respawn

```csharp
// Install Respawn NuGet package
// dotnet add package Respawn

using Respawn;

// Respawn intelligently resets your database to a clean state
// by deleting data from tables while preserving schema

// Basic usage
var respawner = await Respawner.CreateAsync(connection, new RespawnerOptions
{
    DbAdapter = DbAdapter.SqlServer, // or Postgres, MySQL, etc.
    SchemasToInclude = new[] { "dbo" }
});

// Reset database before each test
await respawner.ResetAsync(connection);
```

### How Respawn Works

```
Traditional Approach:
1. Drop all tables
2. Recreate schema from migrations
3. Re-apply indexes, constraints, etc.
Time: 2-5 seconds per test

Respawn Approach:
1. Analyze database schema (once)
2. Determine deletion order (respecting foreign keys)
3. DELETE FROM tables in correct order
4. Reset identity columns
Time: 50-200 milliseconds per test

Speed improvement: 10-50x faster! 🚀
```

### Respawn Configuration

```csharp
public class DatabaseFixture : IAsyncLifetime
{
    private Respawner _respawner = null!;
    private NpgsqlConnection _connection = null!;
    
    public async Task InitializeAsync()
    {
        // Connection string for test database
        var connectionString = "Host=localhost;Database=testdb;Username=test;Password=test";
        _connection = new NpgsqlConnection(connectionString);
        await _connection.OpenAsync();
        
        // Create Respawner with configuration
        _respawner = await Respawner.CreateAsync(_connection, new RespawnerOptions
        {
            // Database adapter
            DbAdapter = DbAdapter.Postgres,
            
            // Which schemas to include
            SchemasToInclude = new[] { "public" },
            
            // Tables to ignore (lookup tables, reference data)
            TablesToIgnore = new[]
            {
                new Table("Countries"),
                new Table("States"),
                new Table("Categories")
            },
            
            // Don't delete from these schemas
            SchemasToExclude = new[] { "system" },
            
            // Reset identity/sequence values
            WithReseed = true,
            
            // Use transactions for atomicity
            UseTransaction = true,
            
            // Custom command timeout
            CommandTimeout = 60
        });
    }
    
    public async Task ResetDatabaseAsync()
    {
        await _respawner.ResetAsync(_connection);
    }
    
    public async Task DisposeAsync()
    {
        await _connection.CloseAsync();
        await _connection.DisposeAsync();
    }
}
```

### xUnit Integration with Class Fixtures

```csharp
// DatabaseFixture manages shared database resource
public class DatabaseFixture : IAsyncLifetime
{
    public string ConnectionString { get; } = 
        "Host=localhost;Database=testdb;Username=test;Password=test";
    
    private Respawner _respawner = null!;
    private NpgsqlConnection _connection = null!;
    
    public async Task InitializeAsync()
    {
        _connection = new NpgsqlConnection(ConnectionString);
        await _connection.OpenAsync();
        
        // Run migrations to create schema
        await ApplyMigrationsAsync();
        
        // Create Respawner (analyzes schema once)
        _respawner = await Respawner.CreateAsync(_connection, new RespawnerOptions
        {
            DbAdapter = DbAdapter.Postgres,
            SchemasToInclude = new[] { "public" },
            TablesToIgnore = new[] { new Table("__EFMigrationsHistory") }
        });
    }
    
    public async Task ResetAsync()
    {
        await _respawner.ResetAsync(_connection);
    }
    
    public async Task DisposeAsync()
    {
        await _connection.CloseAsync();
        await _connection.DisposeAsync();
    }
    
    private async Task ApplyMigrationsAsync()
    {
        using var context = new ApplicationDbContext(
            new DbContextOptionsBuilder<ApplicationDbContext>()
                .UseNpgsql(ConnectionString)
                .Options);
        
        await context.Database.MigrateAsync();
    }
}

// Test class uses the fixture
public class CustomerRepositoryTests : IClassFixture<DatabaseFixture>, IAsyncLifetime
{
    private readonly DatabaseFixture _fixture;
    private readonly ApplicationDbContext _context;
    
    public CustomerRepositoryTests(DatabaseFixture fixture)

        _context = new ApplicationDbContext(
            new DbContextOptionsBuilder<ApplicationDbContext>()
                .UseNpgsql(_fixture.ConnectionString)
                .Options);
    }
    
    // Reset database before each test
    public async Task InitializeAsync()
    {
        await _fixture.ResetAsync();
    }
    
    public Task DisposeAsync() => Task.CompletedTask;
    
    [Fact]
    public async Task CreateCustomer_AddsToDatabase()
    {
        // Database is clean at this point
        var repository = new CustomerRepository(_context);
        var customer = new Customer { Name = "John Doe", Email = "john@example.com" };
        
        await repository.AddAsync(customer);

    }
}
```

### Database Seeding Strategies

```csharp
// Strategy 1: Seed in each test (maximum control)
[Fact]
public async Task Test_WithInlineSeeding()
{
    // Seed specific data for this test
    var customer = new Customer { Name = "Test Customer", Email = "test@example.com" };
    await _context.Customers.AddAsync(customer);
    await _context.SaveChangesAsync();
    
    // Test logic
    var repository = new CustomerRepository(_context);
    var result = await repository.GetByEmailAsync("test@example.com");
    
    Assert.NotNull(result);
}

// Strategy 2: Seed in test initialize (shared setup)
public class CustomerTests : IAsyncLifetime
{
    private Customer _testCustomer = null!;
    
    public async Task InitializeAsync()
    {
        await _fixture.ResetAsync();
        
        // Seed common data for all tests in this class
        _testCustomer = new Customer 
        { 
            Name = "Test Customer", 
            Email = "test@example.com" 
        };
        await _context.Customers.AddAsync(_testCustomer);
        await _context.SaveChangesAsync();
    }
    
    // Tests can use _testCustomer
}

// Strategy 3: Seed with helper methods
public class DatabaseSeeder
{
    public static async Task SeedCustomersAsync(ApplicationDbContext context, int count)
    {
        var faker = new Faker<Customer>()
            .RuleFor(c => c.Name, f => f.Name.FullName())
            .RuleFor(c => c.Email, f => f.Internet.Email());
        
        var customers = faker.Generate(count);
        await context.Customers.AddRangeAsync(customers);
        await context.SaveChangesAsync();
    }
    
    public static async Task SeedOrdersAsync(
        ApplicationDbContext context, 
        int customerId, 
        int count)
    {
        var faker = new Faker<Order>()
            .RuleFor(o => o.CustomerId, _ => customerId)
            .RuleFor(o => o.OrderDate, f => f.Date.Past(1))
            .RuleFor(o => o.Total, f => f.Finance.Amount(10, 1000));
        
        var orders = faker.Generate(count);
        await context.Orders.AddRangeAsync(orders);
        await context.SaveChangesAsync();
    }
}

// Usage in tests
[Fact]
public async Task GetTopCustomers_ReturnsCustomersWithMostOrders()
{
    // Seed test data
    await DatabaseSeeder.SeedCustomersAsync(_context, 10);
    var topCustomer = await _context.Customers.FirstAsync();
    await DatabaseSeeder.SeedOrdersAsync(_context, topCustomer.Id, 20);
    
    // Test logic
    var service = new CustomerService(_context);
    var result = await service.GetTopCustomersAsync(5);
    
    Assert.Contains(result, c => c.Id == topCustomer.Id);
}
```

### Combining Respawn with Testcontainers

```csharp
// Install packages:
// dotnet add package Testcontainers.PostgreSql
// dotnet add package Respawn

using Testcontainers.PostgreSql;

public class IntegrationTestBase : IAsyncLifetime
{
    private readonly PostgreSqlContainer _container;
    protected string ConnectionString => _container.GetConnectionString();
    
    private Respawner _respawner = null!;
    private NpgsqlConnection _connection = null!;
    
    public IntegrationTestBase()
    {
        // Create Postgres container
        _container = new PostgreSqlBuilder()
            .WithImage("postgres:16")
            .WithDatabase("testdb")
            .WithUsername("test")
            .WithPassword("test")
            .Build();
    }
    
    public async Task InitializeAsync()
    {
        // Start container
        await _container.StartAsync();
        
        // Apply migrations
        await ApplyMigrationsAsync();
        
        // Create connection
        _connection = new NpgsqlConnection(ConnectionString);
        await _connection.OpenAsync();
        
        // Create Respawner
        _respawner = await Respawner.CreateAsync(_connection, new RespawnerOptions
        {
            DbAdapter = DbAdapter.Postgres,
            SchemasToInclude = new[] { "public" }
        });
    }
    
    protected async Task ResetDatabaseAsync()
    {
        await _respawner.ResetAsync(_connection);
    }
    
    public async Task DisposeAsync()
    {
        await _connection.CloseAsync();
        await _connection.DisposeAsync();
        await _container.DisposeAsync();
    }
    
    private async Task ApplyMigrationsAsync()
    {
        using var context = CreateDbContext();
        await context.Database.MigrateAsync();
    }
    
    protected ApplicationDbContext CreateDbContext()
    {
        return new ApplicationDbContext(
            new DbContextOptionsBuilder<ApplicationDbContext>()
                .UseNpgsql(ConnectionString)
                .Options);
    }
}

// Test class
public class CustomerIntegrationTests : IntegrationTestBase
{
    [Fact]
    public async Task Test_WithCleanDatabase()
    {
        // Reset before test
        await ResetDatabaseAsync();
        
        // Database is now clean
        using var context = CreateDbContext();
        var count = await context.Customers.CountAsync();
        
        Assert.Equal(0, count);
    }
}
```

### Advanced Seeding with Bogus and EF Core

```csharp
public class AdvancedDatabaseSeeder
{
    private readonly ApplicationDbContext _context;
    
    public AdvancedDatabaseSeeder(ApplicationDbContext context)
    {
        _context = context;
    }
    
    public async Task SeedCompleteDatasetAsync()
    {
        // Seed categories (lookup data)
        var categories = new Faker<Category>()
            .RuleFor(c => c.Name, f => f.Commerce.Categories(1)[0])
            .RuleFor(c => c.Description, f => f.Lorem.Sentence())
            .Generate(10);
        
        await _context.Categories.AddRangeAsync(categories);
        await _context.SaveChangesAsync();
        
        // Seed products with relationships
        var productFaker = new Faker<Product>()
            .RuleFor(p => p.Name, f => f.Commerce.ProductName())
            .RuleFor(p => p.Description, f => f.Commerce.ProductDescription())
            .RuleFor(p => p.Price, f => f.Finance.Amount(10, 1000))
            .RuleFor(p => p.CategoryId, f => f.PickRandom(categories).Id);
        
        var products = productFaker.Generate(50);
        await _context.Products.AddRangeAsync(products);
        await _context.SaveChangesAsync();
        
        // Seed customers
        var customerFaker = new Faker<Customer>()
            .RuleFor(c => c.FirstName, f => f.Name.FirstName())
            .RuleFor(c => c.LastName, f => f.Name.LastName())
            .RuleFor(c => c.Email, (f, c) => f.Internet.Email(c.FirstName, c.LastName))
            .RuleFor(c => c.Phone, f => f.Phone.PhoneNumber())
            .RuleFor(c => c.Address, f => f.Address.FullAddress());
        
        var customers = customerFaker.Generate(100);
        await _context.Customers.AddRangeAsync(customers);
        await _context.SaveChangesAsync();
        
        // Seed orders with line items
        var orders = new List<Order>();
        foreach (var customer in customers.Take(50)) // Half of customers have orders
        {
            var orderCount = new Faker().Random.Int(1, 5);
            for (int i = 0; i < orderCount; i++)
            {
                var order = new Order
                {
                    CustomerId = customer.Id,
                    OrderDate = new Faker().Date.Past(1),
                    Status = new Faker().PickRandom<OrderStatus>(),
                    LineItems = new List<OrderLineItem>()
                };
                
                // Add 1-5 line items per order
                var lineItemCount = new Faker().Random.Int(1, 5);
                for (int j = 0; j < lineItemCount; j++)
                {
                    var product = new Faker().PickRandom(products);
                    order.LineItems.Add(new OrderLineItem
                    {
                        ProductId = product.Id,
                        Quantity = new Faker().Random.Int(1, 10),
                        Price = product.Price
                    });
                }
                
                orders.Add(order);
            }
        }
        
        await _context.Orders.AddRangeAsync(orders);
        await _context.SaveChangesAsync();
    }
}

// Usage
[Fact]
public async Task Test_WithFullDatabase()
{
    await ResetDatabaseAsync();
    
    var seeder = new AdvancedDatabaseSeeder(_context);
    await seeder.SeedCompleteDatasetAsync();
    
    // Database now has realistic, related data
    var orderCount = await _context.Orders.CountAsync();
    Assert.True(orderCount > 0);
}
```

### Preserving Reference Data

```csharp
// Some tables shouldn't be cleaned (lookup tables, seed data)
var respawner = await Respawner.CreateAsync(connection, new RespawnerOptions
{
    DbAdapter = DbAdapter.SqlServer,
    
    // Preserve these tables
    TablesToIgnore = new[]
    {
        new Table("Countries"),
        new Table("States"),
        new Table("Categories"),
        new Table("Roles"),
        new Table("Permissions"),
        new Table("__EFMigrationsHistory")
    }
});

// Seed reference data once during fixture initialization
public class DatabaseFixture : IAsyncLifetime
{
    public async Task InitializeAsync()
    {
        await _connection.OpenAsync();
        await ApplyMigrationsAsync();
        
        // Seed reference data once
        await SeedReferenceDataAsync();
        
        // Create Respawner that preserves reference tables
        _respawner = await Respawner.CreateAsync(_connection, new RespawnerOptions
        {
            DbAdapter = DbAdapter.Postgres,
            TablesToIgnore = new[]
            {
                new Table("Countries"),
                new Table("Categories")
            }
        });
    }
    
    private async Task SeedReferenceDataAsync()
    {
        using var context = CreateDbContext();
        
        if (!await context.Countries.AnyAsync())
        {
            var countries = new[] { "USA", "Canada", "UK", "Germany", "France" }
                .Select(name => new Country { Name = name });
            
            await context.Countries.AddRangeAsync(countries);
            await context.SaveChangesAsync();
        }
    }
}
```
