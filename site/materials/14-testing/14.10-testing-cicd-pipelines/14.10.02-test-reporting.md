# Lesson 2: Test Result Reporting and Visualization

## Learning Objectives

By the end of this lesson, you will be able to:
- Configure test result publishing in CI/CD pipelines
- Generate and visualize code coverage reports
- Create custom test result formatters and reporters
- Integrate test results into PR comments and dashboards
- Track test trends and identify regressions over time

---

## Introduction

Running tests is only valuable if you can easily understand the results. Raw test output is hard to parse. This lesson teaches you how to transform test results into actionable insights through reporting, visualization, and integration with your CI/CD platform.

**Key principle:** Test results should be visible, searchable, and actionable. If developers don't see test failures immediately, tests lose their value.

## Key Concepts Summary

### Test Result Formats

```
Common Test Result Formats:

1. TRX (Test Results XML) - Visual Studio format
   - Native .NET format
   - Works with Azure DevOps, Visual Studio
   - Generated by: dotnet test --logger trx

2. JUnit XML
   - Industry standard format
   - Works with Jenkins, GitHub Actions, CircleCI
   - Generated by: dotnet test --logger "junit;LogFilePath=results.xml"

3. NUnit XML
   - NUnit-specific format
   - Similar to JUnit but with NUnit extensions
   - Generated by NUnit test runner

4. xUnit XML
   - xUnit v2+ format
   - Can be converted to other formats
   - Generated by xUnit runner

5. HTML Reports
   - Human-readable format
   - Great for local development
   - Generated by: dotnet test --logger "html;LogFileName=results.html"
```

### Azure DevOps: Publishing Test Results

```yaml
# azure-pipelines.yml
trigger:
  - main

pool:
  vmImage: 'ubuntu-latest'

steps:
  - task: UseDotNet@2
    inputs:
      version: '8.0.x'
  
  - script: dotnet restore
    displayName: 'Restore dependencies'
  
  - script: dotnet build --no-restore
    displayName: 'Build'
  
  # Run tests and generate TRX results
  - script: |
      dotnet test \
        --no-build \
        --logger "trx;LogFileName=test_results.trx" \
        --results-directory $(Build.SourcesDirectory)/TestResults
    displayName: 'Run Tests'
    continueOnError: true  # Continue even if tests fail
  
  # Publish test results to Azure DevOps
  - task: PublishTestResults@2
    inputs:
      testResultsFormat: 'VSTest'
      testResultsFiles: '**/test_results.trx'
      searchFolder: '$(Build.SourcesDirectory)/TestResults'
      mergeTestResults: true
      failTaskOnFailedTests: true
      testRunTitle: 'Unit Tests'
      publishRunAttachments: true
    condition: succeededOrFailed()  # Always publish, even on failure
```

### GitHub Actions: Publishing Test Results

```yaml
name: CI

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    
    steps:
      - uses: actions/checkout@v4
      
      - name: Setup .NET
        uses: actions/setup-dotnet@v4
        with:
          dotnet-version: '8.0.x'
      
      - name: Restore dependencies
        run: dotnet restore
      
      - name: Build
        run: dotnet build --no-restore
      
      - name: Test
        run: |
          dotnet test \
            --no-build \
            --verbosity normal \
            --logger "trx;LogFileName=test-results.trx" \
            --results-directory ./TestResults
        continue-on-error: true
      
      # Publish test results using GitHub Actions
      - name: Publish Test Results
        uses: dorny/test-reporter@v1
        if: always()  # Run even if tests fail
        with:
          name: .NET Tests
          path: 'TestResults/*.trx'
          reporter: 'dotnet-trx'
          fail-on-error: true
```

### Code Coverage with Coverlet

```bash
# Install Coverlet
dotnet add package coverlet.collector

# Run tests with coverage
dotnet test \
  --collect:"XPlat Code Coverage" \
  --results-directory ./TestResults

  /p:CollectCoverage=true \
  /p:CoverletOutputFormat=cobertura \
  /p:CoverletOutput=./TestResults/coverage.cobertura.xml

# - cobertura (default, XML format)
# - json
# - lcov
# - opencover
```

### Generating HTML Coverage Reports with ReportGenerator

```yaml
# GitHub Actions: Coverage with ReportGenerator
name: CI

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    
    steps:
      - uses: actions/checkout@v4
      
      - name: Setup .NET
        uses: actions/setup-dotnet@v4
        with:
          dotnet-version: '8.0.x'
      
      - name: Restore dependencies
        run: dotnet restore
      
      - name: Build
        run: dotnet build --no-restore
      
      - name: Test with Coverage
        run: |
          dotnet test \
            --no-build \
            --collect:"XPlat Code Coverage" \
            --results-directory ./TestResults
      
      # Install ReportGenerator tool
      - name: Install ReportGenerator
        run: dotnet tool install -g dotnet-reportgenerator-globaltool
      
      # Generate HTML report
      - name: Generate Coverage Report
        run: |
          reportgenerator \
            -reports:TestResults/**/coverage.cobertura.xml \
            -targetdir:TestResults/CoverageReport \
            -reporttypes:Html;Badges
      
      # Upload coverage report as artifact
      - name: Upload Coverage Report
        uses: actions/upload-artifact@v4
        with:
          name: coverage-report
          path: TestResults/CoverageReport
      
      # Optional: Add coverage badge to PR
      - name: Add Coverage PR Comment
        uses: actions/github-script@v7
        if: github.event_name == 'pull_request'
        with:
          script: |
            const fs = require('fs');
            const badge = fs.readFileSync('TestResults/CoverageReport/badge_linecoverage.svg', 'utf8');
            github.rest.issues.createComment({
              issue_number: context.issue.number,
              owner: context.repo.owner,
              repo: context.repo.repo,
              body: `## Code Coverage\n\n![Coverage](${badge})`
            });
```

### Custom xUnit Reporters

```csharp
// Creating a custom xUnit reporter
// 1. Create a class library project
// 2. Reference xunit.runner.utility package

using Xunit;
using Xunit.Abstractions;

public class JsonTestReporter : IRunnerReporter
{
    public string Description => "Outputs test results as JSON";
    
    public bool IsEnvironmentSupported(IRunnerReporterMessageHandler messageHandler)
        => true;
    
    public string RunnerSwitch => "json";  // Usage: dotnet test --logger "xunit;RunnerSwitch=json"
    
    public IMessageSink CreateMessageHandler(
        IRunnerLogger logger,
        IMessageSink diagnosticMessageSink)
    {
        return new JsonReporterMessageHandler(logger);
    }
}

public class JsonReporterMessageHandler : IMessageSink
{
    private readonly IRunnerLogger _logger;
    private readonly List<TestResult> _results = new();
    
    public JsonReporterMessageHandler(IRunnerLogger logger)
    {
        _logger = logger;
    }
    
    public bool OnMessage(IMessageSinkMessage message)
    {
        if (message is ITestPassed passed)
        {
            _results.Add(new TestResult
            {
                Name = passed.Test.DisplayName,
                Status = "Passed",
                Duration = passed.ExecutionTime
            });
        }
        else if (message is ITestFailed failed)
        {
            _results.Add(new TestResult
            {
                Name = failed.Test.DisplayName,
                Status = "Failed",
                Duration = failed.ExecutionTime,
                ErrorMessage = failed.Messages.FirstOrDefault()
            });
        }
        else if (message is ITestAssemblyFinished)
        {
            // Write results as JSON
            var json = JsonSerializer.Serialize(_results, new JsonSerializerOptions
            {
                WriteIndented = true
            });
            
            File.WriteAllText("test-results.json", json);
        }
        
        return true;
    }
    
    public void Dispose() { }
}

public class TestResult
{
    public string Name { get; set; }
    public string Status { get; set; }
    public decimal Duration { get; set; }
    public string? ErrorMessage { get; set; }
}
```

### Test Result Dashboards

```yaml
# GitHub Actions: Create test summary
name: CI

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    
    steps:
      - uses: actions/checkout@v4
      
      - name: Setup .NET
        uses: actions/setup-dotnet@v4
        with:
          dotnet-version: '8.0.x'
      
      - name: Test
        run: |
          dotnet test \
            --logger "trx;LogFileName=test-results.trx" \
            --logger "console;verbosity=detailed" \
            --results-directory ./TestResults
        continue-on-error: true
      
      # Parse results and create summary
      - name: Test Summary
        if: always()
        run: |
          echo "## Test Results" >> $GITHUB_STEP_SUMMARY
          echo "" >> $GITHUB_STEP_SUMMARY
          
          # Parse TRX file (simplified)
          TOTAL=$(grep -o 'total="[0-9]*"' TestResults/*.trx | grep -o '[0-9]*')
          PASSED=$(grep -o 'passed="[0-9]*"' TestResults/*.trx | grep -o '[0-9]*')
          FAILED=$(grep -o 'failed="[0-9]*"' TestResults/*.trx | grep -o '[0-9]*')
          
          echo "- **Total Tests**: $TOTAL" >> $GITHUB_STEP_SUMMARY
          echo "- **Passed**: ✅ $PASSED" >> $GITHUB_STEP_SUMMARY
          echo "- **Failed**: ❌ $FAILED" >> $GITHUB_STEP_SUMMARY
          
          if [ "$FAILED" -gt 0 ]; then
            echo "" >> $GITHUB_STEP_SUMMARY
            echo "### Failed Tests" >> $GITHUB_STEP_SUMMARY
            # Extract failed test names from TRX
            grep -o 'testName="[^"]*".*outcome="Failed"' TestResults/*.trx | \
              sed 's/testName="\([^"]*\)".*/- \1/' >> $GITHUB_STEP_SUMMARY
          fi
```

### PR Comment Integration

```yaml
# GitHub Actions: Add test results to PR comments
name: CI

on:
  pull_request:
    types: [opened, synchronize, reopened]

jobs:
  test:
    runs-on: ubuntu-latest
    permissions:
      pull-requests: write
      contents: read
    
    steps:
      - uses: actions/checkout@v4
      
      - name: Setup .NET
        uses: actions/setup-dotnet@v4
        with:
          dotnet-version: '8.0.x'
      
      - name: Test with Coverage
        run: |
          dotnet test \
            --logger "trx" \
            --collect:"XPlat Code Coverage" \
            --results-directory ./TestResults
        continue-on-error: true
      
      - name: Generate Coverage Report
        run: |
          dotnet tool install -g dotnet-reportgenerator-globaltool
          reportgenerator \
            -reports:TestResults/**/coverage.cobertura.xml \
            -targetdir:TestResults/CoverageReport \
            -reporttypes:MarkdownSummary
      
      - name: Add PR Comment
        uses: actions/github-script@v7
        with:
          script: |
            const fs = require('fs');
            
            // Read test results
            const trxContent = fs.readFileSync('TestResults/test-results.trx', 'utf8');
            const totalMatch = trxContent.match(/total="(\d+)"/);
            const passedMatch = trxContent.match(/passed="(\d+)"/);
            const failedMatch = trxContent.match(/failed="(\d+)"/);
            
            const total = totalMatch ? totalMatch[1] : 'Unknown';
            const passed = passedMatch ? passedMatch[1] : 'Unknown';
            const failed = failedMatch ? failedMatch[1] : 'Unknown';
            
            // Read coverage summary
            const coverageSummary = fs.readFileSync(
              'TestResults/CoverageReport/Summary.md', 
              'utf8'
            );
            
            // Create comment
            const comment = `## 🧪 Test Results
            
            | Metric | Count |
            |--------|-------|
            | Total Tests | ${total} |
            | ✅ Passed | ${passed} |
            | ❌ Failed | ${failed} |
            | Pass Rate | ${(parseInt(passed) / parseInt(total) * 100).toFixed(1)}% |
            
            ## 📊 Code Coverage
            
            ${coverageSummary}
            
            *Automated report generated at ${new Date().toISOString()}*
            `;
            
            // Post comment
            github.rest.issues.createComment({
              issue_number: context.issue.number,
              owner: context.repo.owner,
              repo: context.repo.repo,
              body: comment
            });
```

### Trend Analysis

```yaml
# Store test results over time for trend analysis
name: CI

on: [push]

jobs:
  test:
    runs-on: ubuntu-latest
    
    steps:
      - uses: actions/checkout@v4
      
      - name: Setup .NET
        uses: actions/setup-dotnet@v4
        with:
          dotnet-version: '8.0.x'
      
      - name: Test
        run: |
          dotnet test \
            --logger "trx;LogFileName=test-results.trx" \
            --results-directory ./TestResults
      
      # Extract metrics
      - name: Extract Metrics
        id: metrics
        run: |
          TOTAL=$(grep -o 'total="[0-9]*"' TestResults/*.trx | grep -o '[0-9]*')
          PASSED=$(grep -o 'passed="[0-9]*"' TestResults/*.trx | grep -o '[0-9]*')
          DURATION=$(grep -o 'duration="[^"]*"' TestResults/*.trx | grep -o '[0-9:\.]*' | head -1)
          
          echo "total=$TOTAL" >> $GITHUB_OUTPUT
          echo "passed=$PASSED" >> $GITHUB_OUTPUT
          echo "duration=$DURATION" >> $GITHUB_OUTPUT
      
      # Store in artifact for trend tracking
      - name: Store Metrics
        run: |
          mkdir -p metrics
          echo "{
            \"commit\": \"${{ github.sha }}\",
            \"date\": \"$(date -u +%Y-%m-%dT%H:%M:%SZ)\",
            \"total_tests\": ${{ steps.metrics.outputs.total }},
            \"passed_tests\": ${{ steps.metrics.outputs.passed }},
            \"duration\": \"${{ steps.metrics.outputs.duration }}\"
          }" > metrics/test-metrics-${{ github.sha }}.json
      
      - name: Upload Metrics
        uses: actions/upload-artifact@v4
        with:
          name: test-metrics
          path: metrics/
```

### Coverage Thresholds

```xml
<!-- Directory.Build.props -->
<Project>
  <PropertyGroup>
    <!-- Fail build if coverage below threshold -->
    <CoverletOutputFormat>cobertura</CoverletOutputFormat>
    <Threshold>80</Threshold>
    <ThresholdType>line,branch</ThresholdType>
    <ThresholdStat>total</ThresholdStat>
  </PropertyGroup>
</Project>
```
