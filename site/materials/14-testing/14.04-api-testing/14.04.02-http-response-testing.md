# Lesson 2: HTTP Response Testing and Validation

## Learning Objectives

By the end of this lesson, you will be able to:
- Test HTTP status codes comprehensively
- Validate response headers and content types
- Assert on JSON response bodies using FluentAssertions
- Test error responses and validation failures
- Apply best practices for API contract testing
- Use anonymous types to verify API contracts without coupling to DTOs

---

## Introduction

Testing HTTP responses goes beyond checking if the status code is 200. Comprehensive API testing includes validating status codes for different scenarios, verifying response headers, asserting on JSON structure and content, and ensuring error responses provide meaningful information. This lesson covers techniques for thorough HTTP response validation while avoiding brittle tests that break on irrelevant changes.

## Key Concepts Summary

### HTTP Status Code Testing

Test appropriate status codes for different scenarios:

**Success Responses (2xx):**
```csharp
[Fact]
public async Task GetProducts_ReturnsOk()
{
    var client = _factory.CreateClient();
    
    var response = await client.GetAsync("/api/products");
    
    response.StatusCode.Should().Be(HttpStatusCode.OK);
}

[Fact]
public async Task CreateProduct_ReturnsCreated()
{
    var client = _factory.CreateClient();
    var product = new { Name = "New Product", Price = 10.99 };
    
    var response = await client.PostAsJsonAsync("/api/products", product);
    
    response.StatusCode.Should().Be(HttpStatusCode.Created);
    response.Headers.Location.Should().NotBeNull();
}

[Fact]
public async Task UpdateProduct_ReturnsNoContent()
{
    var client = _factory.CreateClient();
    var product = new { Name = "Updated", Price = 15.99 };
    
    var response = await client.PutAsJsonAsync("/api/products/1", product);
    
    response.StatusCode.Should().Be(HttpStatusCode.NoContent);
}
```

**Client Error Responses (4xx):**
```csharp
[Fact]
public async Task GetProduct_WithInvalidId_ReturnsNotFound()
{
    var client = _factory.CreateClient();
    
    var response = await client.GetAsync("/api/products/99999");
    
    response.StatusCode.Should().Be(HttpStatusCode.NotFound);
}

[Fact]
public async Task CreateProduct_WithInvalidData_ReturnsBadRequest()
{
    var client = _factory.CreateClient();
    var invalidProduct = new { Name = "", Price = -10 };
    
    var response = await client.PostAsJsonAsync("/api/products", invalidProduct);
    
    response.StatusCode.Should().Be(HttpStatusCode.BadRequest);
}

[Fact]
public async Task AccessProtectedEndpoint_WithoutAuth_ReturnsUnauthorized()
{
    var client = _factory.CreateClient();
    
    var response = await client.GetAsync("/api/admin/users");
    
    response.StatusCode.Should().Be(HttpStatusCode.Unauthorized);
}

[Fact]
public async Task AccessForbiddenResource_ReturnsForbidden()
{
    var client = _factory.CreateClient();
    client.DefaultRequestHeaders.Authorization = 
        new AuthenticationHeaderValue("Bearer", "valid-user-token");
    
    var response = await client.GetAsync("/api/admin/system-config");
    
    response.StatusCode.Should().Be(HttpStatusCode.Forbidden);
}
```

### Response Header Testing

Validate important response headers:

```csharp
[Fact]
public async Task CreateProduct_ReturnsLocationHeader()
{
    var client = _factory.CreateClient();
    var product = new { Name = "Test", Price = 10.99 };
    
    var response = await client.PostAsJsonAsync("/api/products", product);
    
    response.StatusCode.Should().Be(HttpStatusCode.Created);
    response.Headers.Location.Should().NotBeNull();
    response.Headers.Location!.ToString().Should().Match("/api/products/*");
}

[Fact]
public async Task GetProducts_ReturnsJsonContentType()
{
    var client = _factory.CreateClient();
    
    var response = await client.GetAsync("/api/products");
    
    response.Content.Headers.ContentType.Should().NotBeNull();
    response.Content.Headers.ContentType!.MediaType
        .Should().Be("application/json");
}

[Fact]
public async Task ApiResponse_IncludesCorsHeaders()
{
    var client = _factory.CreateClient();
    client.DefaultRequestHeaders.Add("Origin", "https://example.com");
    
    var response = await client.GetAsync("/api/products");
    
    response.Headers.Should().ContainKey("Access-Control-Allow-Origin");
}
```

### JSON Response Body Validation

**Using Anonymous Types (Recommended for Contract Testing):**

```csharp
[Fact]
public async Task GetProducts_ReturnsExpectedStructure()
{
    var client = _factory.CreateClient();
    
    var response = await client.GetAsync("/api/products");
    var json = await response.Content.ReadAsStringAsync();
    
    // Define the expected structure with anonymous type
    var expected = new[]
    {
        new { Id = 0, Name = "", Price = 0.0m, IsAvailable = false }
    };
    
    var actual = JsonSerializer.Deserialize(json, expected.GetType(),
        new JsonSerializerOptions { PropertyNameCaseInsensitive = true });
    
    actual.Should().BeEquivalentTo(expected, options => options
        .Including(p => p.Name) // Only assert on structure, not values
        .Using<string>(ctx => ctx.Subject.Should().NotBeNullOrEmpty())
            .WhenTypeIs<string>());
}
```

**Using Strong Types:**

```csharp
[Fact]
public async Task GetProduct_ReturnsCorrectProduct()
{
    var client = _factory.CreateClient();
    
    var response = await client.GetAsync("/api/products/1");
    var product = await response.Content.ReadFromJsonAsync<Product>();
    
    product.Should().NotBeNull();
    product!.Id.Should().Be(1);
    product.Name.Should().NotBeNullOrEmpty();
    product.Price.Should().BeGreaterThan(0);
}
```

**Using FluentAssertions for JSON (System.Text.Json):**

```csharp
using System.Text.Json.Nodes;

[Fact]
public async Task GetProduct_ReturnsValidJson()
{
    var client = _factory.CreateClient();
    
    var response = await client.GetAsync("/api/products/1");
    var json = await response.Content.ReadAsStringAsync();
    var jsonNode = JsonNode.Parse(json);
    
    jsonNode.Should().NotBeNull();
    jsonNode!["id"].Should().NotBeNull();
    jsonNode["name"].Should().NotBeNull();
    jsonNode["price"].Should().NotBeNull();
    
    jsonNode["id"]!.GetValue<int>().Should().BeGreaterThan(0);
    jsonNode["name"]!.GetValue<string>().Should().NotBeEmpty();
    jsonNode["price"]!.GetValue<decimal>().Should().BeGreaterThan(0);
}
```

### Testing Error Responses

**Validation Error Testing:**

```csharp
[Fact]
public async Task CreateProduct_WithValidationErrors_ReturnsProblemDetails()
{
    var client = _factory.CreateClient();
    var invalidProduct = new { Name = "", Price = -10 };
    
    var response = await client.PostAsJsonAsync("/api/products", invalidProduct);
    
    response.StatusCode.Should().Be(HttpStatusCode.BadRequest);
    
    var problemDetails = await response.Content
        .ReadFromJsonAsync<ValidationProblemDetails>();
    
    problemDetails.Should().NotBeNull();
    problemDetails!.Errors.Should().ContainKey("Name");
    problemDetails.Errors.Should().ContainKey("Price");
}
```

**Custom Error Response Testing:**

```csharp
[Fact]
public async Task GetProduct_NotFound_ReturnsErrorMessage()
{
    var client = _factory.CreateClient();
    
    var response = await client.GetAsync("/api/products/99999");
    
    response.StatusCode.Should().Be(HttpStatusCode.NotFound);
    
    var error = await response.Content.ReadFromJsonAsync<ErrorResponse>();
    error.Should().NotBeNull();
    error!.Message.Should().Contain("not found");
}
```

### Best Practices for API Contract Testing

**1. Assert Only What's Relevant:**

❌ **Bad - Too brittle:**
```csharp
var product = await response.Content.ReadFromJsonAsync<Product>();
product.Should().BeEquivalentTo(new Product
{
    Id = 1,
    Name = "Exact Name",
    Price = 10.99m,
    CreatedAt = DateTime.Parse("2024-01-01"),
    ModifiedAt = DateTime.Parse("2024-01-01"),
    // ... 20 more properties
});
```

✅ **Good - Focused assertions:**
```csharp
var product = await response.Content.ReadFromJsonAsync<Product>();
product.Should().NotBeNull();
product!.Id.Should().BeGreaterThan(0);
product.Name.Should().NotBeNullOrEmpty();
product.Price.Should().BeGreaterThan(0);
```

**2. Use Anonymous Types for Contract Structure:**

```csharp
// This tests the API contract without coupling to implementation
var expected = new { Id = 0, Name = "", Price = 0.0m };
var actual = JsonSerializer.Deserialize(json, expected.GetType());

actual.Should().NotBeNull();
// Now you know the contract has Id, Name, and Price with correct types
```

**3. Test Content-Type Headers:**

```csharp
[Fact]
public async Task ApiResponse_ReturnsJsonContentType()
{
    var response = await client.GetAsync("/api/products");
    
    response.Content.Headers.ContentType!.MediaType
        .Should().Be("application/json");
    response.Content.Headers.ContentType.CharSet
        .Should().Be("utf-8");
}
```

**4. Test Pagination Headers:**

```csharp
[Fact]
public async Task GetProducts_WithPagination_ReturnsHeaders()
{
    var response = await client.GetAsync("/api/products?page=1&pageSize=10");
    
    response.Headers.Should().ContainKey("X-Total-Count");
    response.Headers.Should().ContainKey("X-Page-Number");
    response.Headers.Should().ContainKey("X-Page-Size");
}
```

### Testing Edge Cases

```csharp
[Fact]
public async Task GetProducts_EmptyList_ReturnsEmptyArray()
{

    var response = await client.GetAsync("/api/products");
```
