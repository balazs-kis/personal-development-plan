# Lesson 3: Message Broker Testing

## Learning Objectives

By the end of this lesson, you will be able to:
- Set up RabbitMQ and Kafka containers for integration testing
- Write tests that verify message publishing and consumption
- Test message handlers and event-driven workflows
- Handle asynchronous message processing in tests
- Implement test patterns for message-driven architectures

---

## Introduction

Message brokers like RabbitMQ and Kafka are central to event-driven and microservices architectures. Testing these systems with real brokers (not mocks) ensures that your message serialization, routing, and handling logic works correctly. Testcontainers makes it easy to spin up message brokers for isolated, reliable integration tests.

## Key Concepts Summary

### Setting Up RabbitMQ Container

Install the RabbitMQ module:
```bash
dotnet add package Testcontainers.RabbitMq
```

Create and configure a RabbitMQ container:
```csharp
using Testcontainers.RabbitMq;

public class RabbitMqTests : IAsyncLifetime
{
    private readonly RabbitMqContainer _rabbitMqContainer = new RabbitMqBuilder()
        .WithImage("rabbitmq:3.13-management-alpine")
        .WithUsername("guest")
        .WithPassword("guest")
        .Build();

    public async Task InitializeAsync()
    {
        await _rabbitMqContainer.StartAsync();
    }

    public async Task DisposeAsync()
    {
        await _rabbitMqContainer.DisposeAsync();
    }

    [Fact]
    public async Task CanPublishAndConsumeMessage()
    {
        // Get connection string
        var connectionString = _rabbitMqContainer.GetConnectionString();
        
        // Create connection and test messaging
        var factory = new ConnectionFactory 
        { 
            Uri = new Uri(connectionString) 
        };
        
        using var connection = await factory.CreateConnectionAsync();
        using var channel = await connection.CreateChannelAsync();
        
        // ... test logic
    }
}
```

### Testing Message Publishing

Test that your application publishes messages correctly:
```csharp
[Fact]
public async Task OrderCreated_PublishesOrderCreatedEvent()
{
    // Arrange
    var connectionString = _rabbitMqContainer.GetConnectionString();
    var factory = new ConnectionFactory { Uri = new Uri(connectionString) };
    
    using var connection = await factory.CreateConnectionAsync();
    using var channel = await connection.CreateChannelAsync();
    
    await channel.QueueDeclareAsync(
        queue: "orders",
        durable: true,
        exclusive: false,
        autoDelete: false);
    
    var receivedMessages = new List<string>();
    var messageReceived = new TaskCompletionSource<bool>();
    
    await channel.BasicConsumeAsync(
        queue: "orders",
        autoAck: true,
        consumer: new EventingBasicConsumer(channel)
        {
            Received = (model, ea) =>
            {
                var body = ea.Body.ToArray();
                var message = Encoding.UTF8.GetString(body);
                receivedMessages.Add(message);
                messageReceived.SetResult(true);
            }
        });
    
    // Act - Call your service that publishes the message
    var orderService = new OrderService(connectionString);
    await orderService.CreateOrderAsync(new Order { Id = 1, Total = 100.00m });
    
    // Assert
    await messageReceived.Task.WaitAsync(TimeSpan.FromSeconds(5));
    receivedMessages.Should().ContainSingle();
    
    var orderEvent = JsonSerializer.Deserialize<OrderCreatedEvent>(receivedMessages[0]);
    orderEvent.Should().NotBeNull();
    orderEvent!.OrderId.Should().Be(1);
}
```

### Testing Message Consumption

Test that your application correctly handles received messages:
```csharp
[Fact]
public async Task MessageHandler_ProcessesOrderCreatedEvent()
{
    // Arrange
    var connectionString = _rabbitMqContainer.GetConnectionString();
    var factory = new ConnectionFactory { Uri = new Uri(connectionString) };
    
    using var connection = await factory.CreateConnectionAsync();
    using var channel = await connection.CreateChannelAsync();
    
    await channel.QueueDeclareAsync(
        queue: "orders",
        durable: true,
        exclusive: false,
        autoDelete: false);
    
    // Start your message handler
    var handler = new OrderEventHandler(connectionString, _dbContext);
    var cancellationTokenSource = new CancellationTokenSource();
    var handlerTask = handler.StartAsync(cancellationTokenSource.Token);
    
    // Act - Publish a test message
    var orderEvent = new OrderCreatedEvent { OrderId = 1, Total = 100.00m };
    var body = Encoding.UTF8.GetBytes(JsonSerializer.Serialize(orderEvent));
    
    await channel.BasicPublishAsync(
        exchange: "",
        routingKey: "orders",
        body: body);
    
    // Wait for processing
    await Task.Delay(1000);
    
    // Assert
    var processedOrder = await _dbContext.Orders.FindAsync(1);
    processedOrder.Should().NotBeNull();
    processedOrder!.Total.Should().Be(100.00m);
    
    // Cleanup
    cancellationTokenSource.Cancel();
    await handlerTask;
}
```

### Kafka Producer and Consumer Testing

```csharp
[Fact]
public async Task CanProduceAndConsumeKafkaMessage()
{
    // Arrange
    var bootstrapServers = _kafkaContainer.GetBootstrapAddress();
    const string topic = "test-topic";
    
    var producerConfig = new ProducerConfig 
    { 
        BootstrapServers = bootstrapServers 
    };
    
    var consumerConfig = new ConsumerConfig
    {
        BootstrapServers = bootstrapServers,
        GroupId = "test-group",
        AutoOffsetReset = AutoOffsetReset.Earliest
    };
    
    // Act - Produce message
    using var producer = new ProducerBuilder<string, string>(producerConfig).Build();
    await producer.ProduceAsync(topic, new Message<string, string>
    {
        Key = "test-key",
        Value = "test-value"
    });
    
    // Consume message
    using var consumer = new ConsumerBuilder<string, string>(consumerConfig).Build();
    consumer.Subscribe(topic);
    
    var consumeResult = consumer.Consume(TimeSpan.FromSeconds(10));
    
    // Assert
    consumeResult.Should().NotBeNull();
    consumeResult.Message.Key.Should().Be("test-key");
    consumeResult.Message.Value.Should().Be("test-value");
}
```

### Handling Asynchronous Processing

Use polling or TaskCompletionSource for async operations:
```csharp
private async Task<T> WaitForMessageAsync<T>(
    Func<Task<T?>> checkFunc,
    TimeSpan timeout)
{
    var stopwatch = Stopwatch.StartNew();
    
    while (stopwatch.Elapsed < timeout)
    {
        var result = await checkFunc();
        if (result != null)
        {
            return result;
        }
        
        await Task.Delay(100); // Poll interval
    }
    
    throw new TimeoutException($"Message not received within {timeout}");
}

// Usage
var order = await WaitForMessageAsync(
    async () => await _dbContext.Orders.FindAsync(orderId),
    TimeSpan.FromSeconds(5));
```
