# Chapter 14.6: Testing Asynchronous Systems

## Overview
Master testing techniques for message-driven and event-driven systems. Learn to test message consumers, verify event publishing, handle eventual consistency, and build reliable tests for asynchronous workflows.

## Key Concepts
- **Testing Message Consumers:** verifying message handling logic in isolation.
- **Verifying Event Publication:** ensuring events are published correctly.
- **Handling Eventual Consistency:** polling strategies and wait patterns.
- **Test Doubles for Messaging:** in-memory brokers and mocks.
- **Timeout and Polling Strategies:** managing asynchronous timing in tests.
