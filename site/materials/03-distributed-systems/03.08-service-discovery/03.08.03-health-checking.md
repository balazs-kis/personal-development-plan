## Learning Objectives

By the end of this lesson, you will be able to:

- Configure heartbeat mechanisms for service registries
- Design effective health check strategies
- Handle unhealthy instances in service discovery

---

## Introduction

Service discovery tells you where services *are*, but health checking tells you which ones are *working*. A service instance might be running but unable to serve requests due to database connectivity issues, memory exhaustion, or dependency failures. Without health checking, the service registry would happily route traffic to broken instances, causing cascading failures.

Health checking is the immune system of your microservices architecture—it detects and isolates unhealthy instances before they can harm the system. Combined with automatic remediation (restart, scale, failover), health checking enables self-healing systems that recover from failures automatically.

## Key Concepts Summary

### Types of Health Checks

#### 1. **Liveness Probe**
Determines if the service is alive and should continue running.

```
Is the service responsive?
├─ Yes → Service is alive, keep running
└─ No → Service is deadlocked/hung, RESTART IT
```

**Example:** Service is in an infinite loop, deadlocked, or has crashed but container hasn't stopped.

```csharp
// Simple liveness endpoint - just returns 200 OK if service responds
app.MapGet("/health/live", () => Results.Ok("alive"));
```

**Kubernetes Configuration:**
```yaml
livenessProbe:
  httpGet:
    path: /health/live
    port: 8080
  initialDelaySeconds: 30
  periodSeconds: 10
  timeoutSeconds: 5
  failureThreshold: 3  # Restart after 3 failures
```

#### 2. **Readiness Probe**
Determines if the service is ready to accept traffic.

```
Can the service handle requests?
├─ Yes → Route traffic to this instance
└─ No → Remove from load balancer, BUT DON'T RESTART
```

**Example:** Service is starting up, database connection pool not ready, warming caches, dependency temporarily unavailable.

```csharp
app.MapGet("/health/ready", async (IDatabase db) =>
{
    // Check dependencies before accepting traffic
    if (!await db.IsConnectedAsync())
        return Results.ServiceUnavailable("Database not connected");
    
    if (!CacheManager.IsWarmedUp)
        return Results.ServiceUnavailable("Cache warming in progress");
    
    return Results.Ok("ready");
});
```

**Kubernetes Configuration:**
```yaml
readinessProbe:
  httpGet:
    path: /health/ready
    port: 8080
  initialDelaySeconds: 10
  periodSeconds: 5
  timeoutSeconds: 3
  failureThreshold: 2  # Remove from service after 2 failures
```

#### 3. **Startup Probe**
Determines if the service has started successfully (for slow-starting applications).

```
Has the service finished starting?
├─ Yes → Switch to using liveness probe
└─ No → Keep waiting, DON'T check liveness yet
```

**Kubernetes Configuration:**
```yaml
startupProbe:
  httpGet:
    path: /health/startup
    port: 8080
  initialDelaySeconds: 0
  periodSeconds: 10
  failureThreshold: 30  # 30 * 10s = 5 minutes to start
```

### Comprehensive Health Check Implementation

```csharp
public class HealthCheckService
{
    private readonly IDatabase _database;
    private readonly IMessageQueue _messageQueue;
    private readonly IHttpClientFactory _httpClientFactory;
    
    // Liveness: Is the service alive?
    public async Task<HealthCheckResult> CheckLivenessAsync()
    {
        // Very basic check - can we respond?
        try
        {
            // Check if we're not deadlocked
            await Task.Delay(1); 
            return HealthCheckResult.Healthy("Service is responsive");
        }
        catch
        {
            return HealthCheckResult.Unhealthy("Service is unresponsive");
        }
    }
    
    // Readiness: Can we serve traffic?
    public async Task<HealthCheckResult> CheckReadinessAsync()
    {
        var checks = new List<(string name, Task<bool> check)>
        {
            ("Database", CheckDatabaseAsync()),
            ("MessageQueue", CheckMessageQueueAsync()),
            ("DependentService", CheckDependentServiceAsync())
        };
        
        var results = await Task.WhenAll(checks.Select(c => c.check));
        var failures = checks.Where((c, i) => !results[i]).Select(c => c.name).ToList();
        
        if (failures.Any())
        {
            return HealthCheckResult.Unhealthy($"Dependencies unhealthy: {string.Join(", ", failures)}");
        }
        
        return HealthCheckResult.Healthy("All dependencies healthy");
    }
    
    private async Task<bool> CheckDatabaseAsync()
    {
        try
        {
            await _database.PingAsync();
            return true;
        }
        catch
        {
            return false;
        }
    }
    
    private async Task<bool> CheckMessageQueueAsync()
    {
        return _messageQueue.IsConnected;
    }
    
    private async Task<bool> CheckDependentServiceAsync()
    {
        try
        {
            var client = _httpClientFactory.CreateClient();
            var response = await client.GetAsync("http://inventory-service/health");
            return response.IsSuccessStatusCode;
        }
        catch
        {
            return false;
        }
    }
}
```

```csharp
                name = e.Key,
```

## Heartbeat Mechanisms

### Active Health Checks (Pull Model)
Registry polls service health endpoints.

```
┌──────────────────┐
│ Service Registry │
│     (Consul)     │
└────────┬─────────┘
         │ Every 10s: GET /health
         ▼
┌─────────────────┐
│ Order Service   │
│  Instance 1     │
└─────────────────┘
```

**Consul Configuration:**
```json
{
  "service": {
    "name": "order-service",
    "port": 8080,
    "check": {
      "http": "http://localhost:8080/health",
      "interval": "10s",
      "timeout": "5s",
      "deregister_critical_service_after": "1m"
    }
  }
}
```

### Passive Health Checks (Push Model - Heartbeats)
Service sends periodic heartbeats to registry.

```
┌─────────────────┐
│ Order Service   │
│  Instance 1     │
└────────┬────────┘
         │ Every 10s: POST /heartbeat
         ▼
┌──────────────────┐
│ Service Registry │
│    (Eureka)      │
└──────────────────┘
```

**Implementation:**
```csharp
public class HeartbeatService : BackgroundService
{
    private readonly IServiceRegistry _registry;
    private readonly string _instanceId;
    
    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            try
            {
                await _registry.SendHeartbeatAsync(_instanceId);
                await Task.Delay(TimeSpan.FromSeconds(10), stoppingToken);
            }
            catch (Exception ex)
            {
                // Log error but continue sending heartbeats
                _logger.LogError(ex, "Failed to send heartbeat");
            }
        }
    }
}
```

## Health Check Best Practices

### 1. **Shallow vs Deep Checks**

**Shallow (Liveness):**
```csharp
// Fast, minimal - just prove we're responsive
app.MapGet("/health/live", () => Results.Ok());
```

**Deep (Readiness):**
```csharp
// Check all critical dependencies
app.MapGet("/health/ready", async (DatabaseContext db, IMessageBus bus) =>
{
    if (!await db.Database.CanConnectAsync())
        return Results.ServiceUnavailable();
    
    if (!bus.IsConnected)
        return Results.ServiceUnavailable();
    
    return Results.Ok();
});
```

### 2. **Appropriate Timeouts**
```yaml
# Don't make health checks too strict
readinessProbe:
  timeoutSeconds: 3      # Service has 3s to respond
  failureThreshold: 3    # Tolerate 3 failures before marking unhealthy
  periodSeconds: 10      # Check every 10s
```

### 3. **Avoid Cascading Health Checks**
```csharp
// ❌ BAD: Service A checks Service B's health, Service B checks Service C's...
// Creates dependency chains and slow health checks

// ✅ GOOD: Only check YOUR direct dependencies
app.MapHealthChecks("/health/ready", new HealthCheckOptions
{
    Predicate = check => check.Tags.Contains("ready")
});

builder.Services.AddHealthChecks()
    .AddCheck("database", () => /* check DB */)     // Direct dependency
    .AddCheck("cache", () => /* check Redis */)     // Direct dependency
    // Don't check services you call - let them report their own health
```

### 4. **Separate Endpoints**
```
/health/live   → Liveness probe (restart if fails)
/health/ready  → Readiness probe (remove from LB if fails)
/health/startup → Startup probe (for slow-starting apps)
```

### 5. **Include Metadata**
```json
{
  "status": "Healthy",
  "checks": {
    "database": "Healthy",
    "cache": "Healthy",
    "messagequeue": "Degraded"
  },
  "version": "1.2.3",
  "uptime": "2d 14h 23m"
}
```

## Advanced Health Check Patterns

### Composite Health Checks

```csharp
public class CompositeHealthCheck : IHealthCheck
{
    private readonly IEnumerable<IHealthCheck> _healthChecks;
    private readonly ILogger _logger;
    
    public async Task<HealthCheckResult> CheckHealthAsync(
        HealthCheckContext context,
        CancellationToken cancellationToken = default)
    {
        var results = new List<(string name, HealthCheckResult result)>();
        
        foreach (var check in _healthChecks)
        {
            try
            {
                var result = await check.CheckHealthAsync(context, cancellationToken);
                results.Add((check.GetType().Name, result));
            }
            catch (Exception ex)
            {
                results.Add((check.GetType().Name, 
                    HealthCheckResult.Unhealthy($"Exception: {ex.Message}")));
            }
        }
        
        var unhealthy = results.Where(r => r.result.Status == HealthStatus.Unhealthy).ToList();
        var degraded = results.Where(r => r.result.Status == HealthStatus.Degraded).ToList();
        
        if (unhealthy.Any())
        {
            return HealthCheckResult.Unhealthy(
                $"Failed checks: {string.Join(", ", unhealthy.Select(r => r.name))}");
        }
        
        if (degraded.Any())
        {
            return HealthCheckResult.Degraded(
                $"Degraded checks: {string.Join(", ", degraded.Select(r => r.name))}");
        }
        
        return HealthCheckResult.Healthy("All checks passed");
    }
}
```

### Circuit Breaker-Aware Health Checks

```csharp
public class CircuitBreakerHealthCheck : IHealthCheck
{
    private readonly Dictionary<string, ICircuitBreaker> _circuitBreakers;
    
    public Task<HealthCheckResult> CheckHealthAsync(
        HealthCheckContext context,
        CancellationToken cancellationToken = default)
    {
        var openBreakers = _circuitBreakers
            .Where(kvp => kvp.Value.State == CircuitState.Open)
            .Select(kvp => kvp.Key)
            .ToList();
        
        if (openBreakers.Any())
        {
            return Task.FromResult(HealthCheckResult.Degraded(
                $"Circuit breakers open: {string.Join(", ", openBreakers)}"));
        }
        
        var halfOpenBreakers = _circuitBreakers
            .Where(kvp => kvp.Value.State == CircuitState.HalfOpen)
            .Select(kvp => kvp.Key)
            .ToList();
        
        if (halfOpenBreakers.Any())
        {
            return Task.FromResult(HealthCheckResult.Degraded(
                $"Circuit breakers testing: {string.Join(", ", halfOpenBreakers)}"));
        }
        
        return Task.FromResult(HealthCheckResult.Healthy("All circuit breakers closed"));
    }
}
```

### Resource Utilization Health Checks

```csharp
public class ResourceHealthCheck : IHealthCheck
{
    private readonly double _cpuThreshold = 80.0;
    private readonly double _memoryThreshold = 85.0;
    
    public async Task<HealthCheckResult> CheckHealthAsync(
        HealthCheckContext context,
        CancellationToken cancellationToken = default)
    {
        var cpuUsage = await GetCpuUsageAsync();
        var memoryUsage = GetMemoryUsage();
        
        var data = new Dictionary<string, object>
        {
            ["cpu_usage"] = $"{cpuUsage:F2}%",
            ["memory_usage"] = $"{memoryUsage:F2}%",
            ["total_memory_mb"] = GC.GetTotalMemory(false) / 1024 / 1024
        };
        
        if (cpuUsage > _cpuThreshold || memoryUsage > _memoryThreshold)
        {
            return HealthCheckResult.Degraded(
                $"High resource usage: CPU {cpuUsage:F1}%, Memory {memoryUsage:F1}%",
                data: data);
        }
        
        return HealthCheckResult.Healthy("Resource usage normal", data: data);
    }
    
    private async Task<double> GetCpuUsageAsync()
    {
        var startTime = DateTime.UtcNow;
        var startCpuUsage = Process.GetCurrentProcess().TotalProcessorTime;
        
        await Task.Delay(500);
        
        var endTime = DateTime.UtcNow;
        var endCpuUsage = Process.GetCurrentProcess().TotalProcessorTime;
        
        var cpuUsedMs = (endCpuUsage - startCpuUsage).TotalMilliseconds;
        var totalMsPassed = (endTime - startTime).TotalMilliseconds;
        var cpuUsageTotal = cpuUsedMs / (Environment.ProcessorCount * totalMsPassed);
        
        return cpuUsageTotal * 100;
    }
    
    private double GetMemoryUsage()
    {
        var process = Process.GetCurrentProcess();
        var totalMemory = GC.GetTotalMemory(false);
        var workingSet = process.WorkingSet64;
        
        return (double)workingSet / (1024 * 1024 * 1024) * 100; // Percentage of 1GB
    }
}
```

## Production Health Check Strategies

### Health Check with Degradation Levels

```csharp
public enum ServiceHealthLevel
{
    Healthy = 0,
    Degraded = 1,
    Critical = 2,
    Down = 3
}

public class TieredHealthCheckService
{
    private readonly IDatabase _database;
    private readonly ICache _cache;
    private readonly IMessageQueue _queue;
    
    public async Task<(ServiceHealthLevel level, string message)> CheckHealthAsync()
    {
        var issues = new List<string>();
        var level = ServiceHealthLevel.Healthy;
        
        // Critical: Database
        if (!await _database.IsConnectedAsync())
        {
            issues.Add("Database disconnected");
            level = ServiceHealthLevel.Down;
            return (level, string.Join("; ", issues));
        }
        
        // Important: Cache
        if (!_cache.IsConnected)
        {
            issues.Add("Cache unavailable");
            level = ServiceHealthLevel.Degraded;
        }
        
        // Optional: Message Queue
        if (!_queue.IsConnected)
        {
            issues.Add("Message queue unavailable");
            if (level < ServiceHealthLevel.Degraded)
                level = ServiceHealthLevel.Degraded;
        }
        
        // Resource checks
        var (cpuOk, memoryOk) = await CheckResourcesAsync();
        if (!cpuOk || !memoryOk)
        {
            issues.Add("High resource usage");
            if (level < ServiceHealthLevel.Critical)
                level = ServiceHealthLevel.Critical;
        }
        
        var message = issues.Any() 
            ? string.Join("; ", issues)
            : "All systems operational";
        
        return (level, message);
    }
}
```

## Heartbeat Implementation Patterns

### Active Heartbeat with Backoff

```csharp
public class AdaptiveHeartbeatService : BackgroundService
{
    private readonly IServiceRegistry _registry;
    private readonly string _instanceId;
    private TimeSpan _currentInterval = TimeSpan.FromSeconds(10);
    private const int MaxFailures = 3;
    private int _consecutiveFailures = 0;
    
    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            try
            {
                await _registry.SendHeartbeatAsync(_instanceId);
                
                // Success - reset
                _consecutiveFailures = 0;
                _currentInterval = TimeSpan.FromSeconds(10);
                
                _logger.LogDebug("Heartbeat sent successfully");
            }
            catch (Exception ex)
            {
                _consecutiveFailures++;
                
                _logger.LogWarning(
                    ex,
                    "Heartbeat failed (attempt {Count}/{Max})",
                    _consecutiveFailures,
                    MaxFailures);
                
                // Exponential backoff
                _currentInterval = TimeSpan.FromSeconds(
                    Math.Min(10 * Math.Pow(2, _consecutiveFailures - 1), 60));
                
                if (_consecutiveFailures >= MaxFailures)
                {
                    _logger.LogError("Max heartbeat failures reached, service may be deregistered");
                }
            }
            
            await Task.Delay(_currentInterval, stoppingToken);
        }
    }
}
```

### Consul TTL-Based Heartbeat

```csharp
public class ConsulTTLHeartbeat : BackgroundService
{
    private readonly IConsulClient _consul;
    private readonly string _checkId;
    
    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        // TTL check - service must update within TTL period
        var registration = new AgentServiceRegistration
        {
            ID = "order-service-1",
            Name = "order-service",
            Address = "10.0.1.5",
            Port = 8080,
            Check = new AgentServiceCheck
            {
                CheckID = _checkId,
                TTL = TimeSpan.FromSeconds(30),  // Must update within 30s
                DeregisterCriticalServiceAfter = TimeSpan.FromMinutes(1)
            }
        };
        
        await _consul.Agent.ServiceRegister(registration);
        
        while (!stoppingToken.IsCancellationRequested)
        {
            try
            {
                // Update TTL check
                await _consul.Agent.PassTTL(_checkId, "Service is healthy");
                
                await Task.Delay(TimeSpan.FromSeconds(10), stoppingToken);
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Failed to update TTL check");
                
                // Mark as warning
                await _consul.Agent.WarnTTL(_checkId, $"Error: {ex.Message}");
            }
        }
    }
}
```

### Custom Health Check Dashboard

```csharp
[ApiController]
[Route("api/health")]
public class HealthDashboardController : ControllerBase
{
    private readonly HealthCheckService _healthCheckService;
    
    [HttpGet("summary")]
    public async Task<IActionResult> GetHealthSummary()
    {
        var report = await _healthCheckService.CheckHealthAsync();
        
        var summary = new
        {
            status = report.Status.ToString(),
            totalDuration = report.TotalDuration.TotalMilliseconds,
            checks = report.Entries.Select(entry => new
            {
                name = entry.Key,
                status = entry.Value.Status.ToString(),
                description = entry.Value.Description,
                duration = entry.Value.Duration.TotalMilliseconds,
                exception = entry.Value.Exception?.Message,
                data = entry.Value.Data
            })
        };
        
        return report.Status == HealthStatus.Healthy
            ? Ok(summary)
            : StatusCode(503, summary);
    }
}
```

## Key Takeaways

✅ Separate liveness (restart) from readiness (route traffic) checks

✅ Keep liveness checks simple and fast

✅ Readiness checks should verify all critical dependencies

✅ Use startup probes for slow-starting applications

✅ Avoid cascading health checks across services

✅ Implement graceful degradation with tiered health levels

✅ Monitor health check failures and response times

✅ Test health checks to ensure they work correctly
