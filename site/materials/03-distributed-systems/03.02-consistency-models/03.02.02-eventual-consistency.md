## Introduction

Eventual consistency is a consistency model that trades immediate consistency for higher availability and lower latency. The guarantee is simple: if no new updates are made, eventually all replicas will converge to the same value. This model powers many large-scale systems like Amazon DynamoDB, Cassandra, and Riak, enabling them to remain available during network partitions.

## What is Eventual Consistency?

### The Guarantee

**Eventual Consistency Promise:**
> If no new updates are made to a data item, eventually all reads will return the last updated value.

**Key Properties:**
- Replicas may temporarily diverge
- System remains available during network partitions
- Conflicts may occur and must be resolved
- Convergence is guaranteed (eventually)

```csharp
// Eventual consistency timeline
Time T0: Write(x = 1) on Node A
Time T1: Read(x) on Node B  → might return 0 (old value)
Time T2: Read(x) on Node B  → might return 0 or 1
Time T3: Read(x) on Node B  → returns 1 (converged)
         After replication completes, all nodes have x = 1
```

## Implementing Eventual Consistency

### 1. Asynchronous Replication

```csharp
public class EventuallyConsistentStore
{
    private readonly IPrimaryStore _primary;
    private readonly IReadOnlyList<IReplicaStore> _replicas;
    private readonly IBackgroundQueue _replicationQueue;
    
    public async Task WriteAsync(string key, string value)
    {
        // Write to primary immediately
        await _primary.WriteAsync(key, value);
        
        // Asynchronously replicate to replicas (fire-and-forget)
        _ = Task.Run(async () =>
        {
            foreach (var replica in _replicas)
            {
                await _replicationQueue.EnqueueAsync(new ReplicationTask
                {
                    Replica = replica,
                    Key = key,
                    Value = value,
                    Timestamp = DateTime.UtcNow
                });
            }
        });
        
        // Return immediately - don't wait for replication
        // This is what makes it "eventual"
    }
    
    public async Task<string> ReadAsync(string key)
    {
        // Read from any replica (might be stale)
        var replica = _replicas[Random.Shared.Next(_replicas.Count)];
        return await replica.ReadAsync(key);
    }
}
```

### 2. Read Repair

Detect and fix inconsistencies during reads:

```csharp
public class ReadRepairStore
{
    private readonly IReadOnlyList<IDataStore> _replicas;
    
    public async Task<string> ReadWithRepairAsync(string key)
    {
        // Read from multiple replicas
        var readTasks = _replicas
            .Select(r => ReadWithTimestampAsync(r, key))
            .ToList();
        
        var results = await Task.WhenAll(readTasks);
        
        // Find the most recent value (by timestamp)
        var mostRecent = results
            .OrderByDescending(r => r.Timestamp)
            .First();
        
        // Repair outdated replicas in the background
        _ = Task.Run(async () =>
        {
            var outdated = results
                .Where(r => r.Timestamp < mostRecent.Timestamp)
                .Select(r => r.Replica);
            
            foreach (var replica in outdated)
            {
                await replica.WriteAsync(key, mostRecent.Value);
            }
        });
        
        return mostRecent.Value;
    }
    
    private async Task<(IDataStore Replica, string Value, DateTime Timestamp)> 
        ReadWithTimestampAsync(IDataStore replica, string key)
    {
        var (value, timestamp) = await replica.ReadWithMetadataAsync(key);
        return (replica, value, timestamp);
    }
}
```

### 3. Anti-Entropy (Gossip Protocol)

Periodically synchronize state between replicas:

```csharp
public class AntiEntropyService : BackgroundService
{
    private readonly IReadOnlyList<IDataStore> _replicas;
    private readonly TimeSpan _syncInterval = TimeSpan.FromSeconds(30);
    
    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            await SynchronizeReplicasAsync();
            await Task.Delay(_syncInterval, stoppingToken);
        }
    }
    
    private async Task SynchronizeReplicasAsync()
    {
        // Pick two random replicas to sync
        var replica1 = _replicas[Random.Shared.Next(_replicas.Count)];
        var replica2 = _replicas[Random.Shared.Next(_replicas.Count)];
        
        if (replica1 == replica2) return;
        
        // Exchange data and merge
        var data1 = await replica1.GetAllDataAsync();
        var data2 = await replica2.GetAllDataAsync();
        
        // Merge using timestamps (Last-Write-Wins)
        var merged = MergeData(data1, data2);
        
        // Update both replicas
        await replica1.BulkUpdateAsync(merged);
        await replica2.BulkUpdateAsync(merged);
        
        _logger.LogInformation(
            "Synchronized {Count} items between replicas", 
            merged.Count);
    }
    
    private Dictionary<string, (string Value, DateTime Timestamp)> MergeData(
        Dictionary<string, (string, DateTime)> data1,
        Dictionary<string, (string, DateTime)> data2)
    {
        var merged = new Dictionary<string, (string Value, DateTime Timestamp)>();
        
        foreach (var key in data1.Keys.Union(data2.Keys))
        {
            var has1 = data1.TryGetValue(key, out var value1);
            var has2 = data2.TryGetValue(key, out var value2);
            
            if (has1 && !has2)
            {
                merged[key] = value1;
            }
            else if (!has1 && has2)
            {
                merged[key] = value2;
            }
            else
            {
                // Both have it - pick newer
                merged[key] = value1.Item2 > value2.Item2 ? value1 : value2;
            }
        }
        
        return merged;
    }
}
```

## Conflict Resolution Strategies

### 1. Last-Write-Wins (LWW)

Simplest but loses data in concurrent updates:

```csharp
public class LastWriteWinsResolver
{
    public string Resolve(
        List<(string Value, DateTime Timestamp, string NodeId)> versions)
    {
        // Pick the version with the latest timestamp
        var winner = versions
            .OrderByDescending(v => v.Timestamp)
            .ThenBy(v => v.NodeId) // Tiebreaker
            .First();
        
        return winner.Value;
    }
}

// Example of data loss:
// Node A: Write(x = "A") at T1
// Node B: Write(x = "B") at T1 (concurrent)
// After merge: Only one value survives (B if NodeB > NodeA)
// Value "A" is lost!
```

### 2. Application-Specific Conflict Resolution

Let the application decide:

```csharp
public class ShoppingCartConflictResolver
{
    public ShoppingCart Resolve(List<ShoppingCart> versions)
    {
        // For shopping carts: merge all items (union)
        var allItems = versions
            .SelectMany(cart => cart.Items)
            .GroupBy(item => item.ProductId)
            .Select(g => new CartItem
            {
                ProductId = g.Key,
                // Take maximum quantity (generous to customer)
                Quantity = g.Max(item => item.Quantity)
            })
            .ToList();
        
        return new ShoppingCart
        {
            UserId = versions.First().UserId,
            Items = allItems
        };
    }
}
```

### 3. CRDTs (Conflict-Free Replicated Data Types)

Mathematically guaranteed convergence:

```csharp
// G-Counter (Grow-only Counter) CRDT
public class GCounter
{
    // Each node maintains its own counter
    private readonly Dictionary<string, int> _counts = new();
    private readonly string _nodeId;
    
    public GCounter(string nodeId)
    {
        _nodeId = nodeId;
        _counts[nodeId] = 0;
    }
    
    // Increment only on local node
    public void Increment()
    {
        _counts[_nodeId]++;
    }
    
    // Total is sum of all node counters
    public int Value => _counts.Values.Sum();
    
    // Merge operation (idempotent, commutative, associative)
    public void Merge(GCounter other)
    {
        foreach (var (nodeId, count) in other._counts)
        {
            if (_counts.ContainsKey(nodeId))
            {
                // Take maximum (monotonic)
                _counts[nodeId] = Math.Max(_counts[nodeId], count);
            }
            else
            {
                _counts[nodeId] = count;
            }
        }
    }
}

// Usage
var counter1 = new GCounter("node1");
var counter2 = new GCounter("node2");

counter1.Increment(); // counter1.Value = 1
counter2.Increment(); // counter2.Value = 1
counter2.Increment(); // counter2.Value = 2

// Merge - guaranteed to converge
counter1.Merge(counter2);
counter2.Merge(counter1);

// Both now show Value = 3 (converged!)
```

#### PN-Counter (Positive-Negative Counter)

```csharp
public class PNCounter
{
    private readonly GCounter _increments;
    private readonly GCounter _decrements;
    
    public PNCounter(string nodeId)
    {
        _increments = new GCounter(nodeId);
        _decrements = new GCounter(nodeId);
    }
    
    public void Increment() => _increments.Increment();
    public void Decrement() => _decrements.Increment();
    
    public int Value => _increments.Value - _decrements.Value;
    
    public void Merge(PNCounter other)
    {
        _increments.Merge(other._increments);
        _decrements.Merge(other._decrements);
    }
}
```

#### OR-Set (Observed-Remove Set)

```csharp
public class ORSet<T>
{
    private readonly Dictionary<T, HashSet<Guid>> _elements = new();
    private readonly HashSet<Guid> _tombstones = new();
    
    public void Add(T element)
    {
        var uniqueTag = Guid.NewGuid();
        
        if (!_elements.ContainsKey(element))
        {
            _elements[element] = new HashSet<Guid>();
        }
        
        _elements[element].Add(uniqueTag);
    }
    
    public void Remove(T element)
    {
        if (_elements.TryGetValue(element, out var tags))
        {
            // Mark all tags as removed
            foreach (var tag in tags)
            {
                _tombstones.Add(tag);
            }
        }
    }
    
    public bool Contains(T element)
    {
        if (!_elements.TryGetValue(element, out var tags))
            return false;
        
        // Element exists if it has tags not in tombstones
        return tags.Any(tag => !_tombstones.Contains(tag));
    }
    
    public void Merge(ORSet<T> other)
    {
        // Merge elements
        foreach (var (element, tags) in other._elements)
        {
            if (!_elements.ContainsKey(element))
            {
                _elements[element] = new HashSet<Guid>();
            }
            
            _elements[element].UnionWith(tags);
        }
        
        // Merge tombstones
        _tombstones.UnionWith(other._tombstones);
    }
    
    public IEnumerable<T> Elements => _elements
        .Where(kvp => kvp.Value.Any(tag => !_tombstones.Contains(tag)))
        .Select(kvp => kvp.Key);
}
```

## Azure Cosmos DB Eventual Consistency

```csharp
public class CosmosDBEventualConsistencyExample
{
    private readonly Container _container;
    
    public CosmosDBEventualConsistencyExample()
    {
        var clientOptions = new CosmosClientOptions
        {
            ConsistencyLevel = ConsistencyLevel.Eventual,
            // Can read from any region (lowest latency)
            ApplicationPreferredRegions = new List<string> 
            { 
                "West US", 
                "East US" 
            }
        };
        
        var client = new CosmosClient(connectionString, clientOptions);
        _container = client.GetContainer("database", "container");
    }
    
    public async Task<User> GetUserAsync(string userId)
    {
        // May return stale data
        // Lowest latency, highest availability
        var response = await _container.ReadItemAsync<User>(
            userId,
            new PartitionKey(userId));
        
        return response.Resource;
    }
    
    public async Task UpdateUserWithConflictHandlingAsync(User user)
    {
        try
        {
            // Optimistic concurrency with ETag
            var requestOptions = new ItemRequestOptions
            {
                IfMatchEtag = user.ETag
            };
            
            var response = await _container.ReplaceItemAsync(
                user,
                user.Id,
                new PartitionKey(user.Id),
                requestOptions);
            
            user.ETag = response.Resource.ETag;
        }
        catch (CosmosException ex) when (ex.StatusCode == HttpStatusCode.PreconditionFailed)
        {
            // Conflict! Handle it
            var current = await GetUserAsync(user.Id);
            var resolved = ResolveConflict(user, current);
            
            // Retry with resolved version
            await UpdateUserWithConflictHandlingAsync(resolved);
        }
    }
    
    private User ResolveConflict(User attempted, User current)
    {
        // Application-specific logic
        // Example: Merge shopping cart items
        var resolved = new User
        {
            Id = current.Id,
            ETag = current.ETag,
            Cart = attempted.Cart.Union(current.Cart).ToList()
        };
        
        return resolved;
    }
}
```

## Best Practices for Eventual Consistency

### 1. Design for Idempotency

Since eventual consistency often involves retries and reprocessing, all operations must be idempotent.

```csharp
// Since messages might be delivered multiple times,
// operations must be idempotent
public class IdempotentUserUpdateProcessor
{
    private readonly IDeduplicationStore _processed;
    private readonly IUserRepository _users;
    
    public async Task ProcessUserUpdateAsync(UserUpdateEvent evt)
    {
        // Use event ID for deduplication
        if (await _processed.ContainsAsync(evt.EventId))
        {
            _logger.LogInformation(
                "Event {EventId} already processed, skipping",
                evt.EventId);
            return; // Already processed
        }
        
        // Process update idempotently
        await UpdateUserAsync(evt.UserId, evt.Changes);
        
        // Mark as processed
        await _processed.AddAsync(evt.EventId, DateTime.UtcNow);
    }
    
    private async Task UpdateUserAsync(string userId, Dictionary<string, object> changes)
    {
        // Use SET operations, not increments
        // Good: user.Email = "new@email.com"
        // Bad: user.PointBalance += 10 (not idempotent!)
        
        var user = await _users.GetAsync(userId);
        
        foreach (var (key, value) in changes)
        {
            switch (key)
            {
                case "Email":
                    user.Email = (string)value;
                    break;
                case "Name":
                    user.Name = (string)value;
                    break;
                // Use SET operations for idempotency
            }
        }
        
        await _users.UpdateAsync(user);
    }
}
```

### 3. Use Version Vectors for Causality

Version vectors track causality to detect concurrent updates.

```csharp
public class VersionedData<T>
{
    public T Value { get; set; }
    public Dictionary<string, long> VersionVector { get; set; } = new();
    
    public void IncrementVersion(string nodeId)
    {
        if (!VersionVector.ContainsKey(nodeId))
        {
            VersionVector[nodeId] = 0;
        }
        
        VersionVector[nodeId]++;
    }
    
    public bool IsConcurrentWith(VersionedData<T> other)
    {
        // Check if neither version vector dominates the other
        bool thisNewer = VersionVector.Any(kvp => 
            kvp.Value > other.VersionVector.GetValueOrDefault(kvp.Key));
        
        bool otherNewer = other.VersionVector.Any(kvp => 
            kvp.Value > VersionVector.GetValueOrDefault(kvp.Key));
        
        return thisNewer && otherNewer; // Concurrent updates!
    }
    
    public bool HappenedBefore(VersionedData<T> other)
    {
        // This happened before other if:
        // - All versions in this are <= other's versions
        // - At least one version in this is < other's version
        
        bool allLessOrEqual = VersionVector.All(kvp =>
            kvp.Value <= other.VersionVector.GetValueOrDefault(kvp.Key));
        
        bool someLess = VersionVector.Any(kvp =>
            kvp.Value < other.VersionVector.GetValueOrDefault(kvp.Key));
        
        return allLessOrEqual && someLess;
    }
    
    public void Merge(VersionedData<T> other)
    {
        // Take component-wise maximum
        foreach (var (nodeId, version) in other.VersionVector)
        {
            if (!VersionVector.ContainsKey(nodeId))
            {
                VersionVector[nodeId] = version;
            }
            else
            {
                VersionVector[nodeId] = Math.Max(VersionVector[nodeId], version);
            }
        }
    }
}

// Usage in distributed system
public class VersionVectorStore<T>
{
    private readonly string _nodeId;
    private readonly Dictionary<string, VersionedData<T>> _data = new();
    
    public void Write(string key, T value)
    {
        if (!_data.ContainsKey(key))
        {
            _data[key] = new VersionedData<T>
            {
                Value = value,
                VersionVector = new Dictionary<string, long>()
            };
        }
        else
        {
            _data[key].Value = value;
        }
        
        _data[key].IncrementVersion(_nodeId);
    }
    
    public VersionedData<T> Read(string key)
    {
        return _data.TryGetValue(key, out var data) ? data : null;
    }
    
    public ConflictResolutionResult<T> Merge(string key, VersionedData<T> incoming)
    {
        if (!_data.ContainsKey(key))
        {
            // No local version - accept incoming
            _data[key] = incoming;
            return ConflictResolutionResult<T>.Accepted(incoming);
        }
        
        var local = _data[key];
        
        if (local.HappenedBefore(incoming))
        {
            // Incoming is newer - accept it
            _data[key] = incoming;
            return ConflictResolutionResult<T>.Accepted(incoming);
        }
        
        if (incoming.HappenedBefore(local))
        {
            // Local is newer - keep it
            return ConflictResolutionResult<T>.Rejected(local);
        }
        
        // Concurrent updates - conflict!
        return ConflictResolutionResult<T>.Conflict(local, incoming);
    }
}

public class ConflictResolutionResult<T>
{
    public bool IsConflict { get; set; }
    public VersionedData<T> LocalVersion { get; set; }
    public VersionedData<T> IncomingVersion { get; set; }
    
    public static ConflictResolutionResult<T> Accepted(VersionedData<T> version) =>
        new() { IsConflict = false, LocalVersion = version };
    
    public static ConflictResolutionResult<T> Rejected(VersionedData<T> version) =>
        new() { IsConflict = false, LocalVersion = version };
    
    public static ConflictResolutionResult<T> Conflict(
        VersionedData<T> local, 
        VersionedData<T> incoming) =>
        new() { IsConflict = true, LocalVersion = local, IncomingVersion = incoming };
}
```

### 4. Implement Backpressure and Rate Limiting

Prevent overwhelming slow replicas during synchronization.

```csharp
public class BackpressureReplicationService
{
    private readonly SemaphoreSlim _rateLimiter = new(maxConcurrent: 10);
    private readonly IReadOnlyList<IDataStore> _replicas;
    
    public async Task ReplicateAsync(string key, string value)
    {
        var tasks = _replicas.Select(async replica =>
        {
            await _rateLimiter.WaitAsync();
            try
            {
                await replica.WriteWithTimeoutAsync(key, value, TimeSpan.FromSeconds(5));
            }
            catch (TimeoutException)
            {
                _logger.LogWarning(
                    "Replica {Replica} slow, will retry later",
                    replica.Id);
                
                // Queue for retry
                await _retryQueue.EnqueueAsync(new RetryTask
                {
                    Replica = replica,
                    Key = key,
                    Value = value
                });
            }
            finally
            {
                _rateLimiter.Release();
            }
        });
        
        await Task.WhenAll(tasks);
    }
}
```

### 5. Monitor Replication Lag

Track how far behind replicas are.

```csharp
public class ReplicationLagMonitor
{
    private readonly IMetricsCollector _metrics;
    
    public async Task MonitorLagAsync()
    {
        while (true)
        {
            foreach (var replica in _replicas)
            {
                var lag = await MeasureLagAsync(replica);
                
                _metrics.RecordGauge(
                    "replication_lag_seconds",
                    lag.TotalSeconds,
                    new Dictionary<string, string>
                    {
                        ["replica"] = replica.Id,
                        ["region"] = replica.Region
                    });
                
                if (lag > TimeSpan.FromMinutes(5))
                {
                    _logger.LogWarning(
                        "Replica {Replica} lagging by {Lag}",
                        replica.Id, lag);
                }
            }
            
            await Task.Delay(TimeSpan.FromSeconds(30));
        }
    }
    
    private async Task<TimeSpan> MeasureLagAsync(IDataStore replica)
    {
        // Write a timestamp to primary
        var key = $"_heartbeat_{Guid.NewGuid()}";
        var timestamp = DateTime.UtcNow;
        await _primary.WriteAsync(key, timestamp.ToString("O"));
        
        // Wait for replication
        await Task.Delay(TimeSpan.FromSeconds(1));
        
        // Read from replica
        var replicaValue = await replica.ReadAsync(key);
        
        if (DateTime.TryParse(replicaValue, out var replicatedAt))
        {
            return DateTime.UtcNow - replicatedAt;
        }
        
        return TimeSpan.MaxValue; // Not replicated yet
    }
}
```

### 6. Provide Strong Consistency Options When Needed

Even in eventually consistent systems, offer strong reads for critical operations.

```csharp
public class HybridConsistencyStore
{
    private readonly IPrimaryStore _primary;
    private readonly IReadOnlyList<IReplicaStore> _replicas;
    
    // Fast, eventual consistency (default)
    public async Task<T> ReadAsync<T>(string key)
    {
        var replica = _replicas[Random.Shared.Next(_replicas.Count)];
        return await replica.ReadAsync<T>(key);
    }
    
    // Slower, strong consistency (when needed)
    public async Task<T> ReadStrongAsync<T>(string key)
    {
        // Read from primary for strong consistency
        return await _primary.ReadAsync<T>(key);
    }
    
    // Write with optional strong consistency
    public async Task WriteAsync<T>(string key, T value, bool waitForReplication = false)
    {
        await _primary.WriteAsync(key, value);
        
        if (waitForReplication)
        {
            // Wait for majority replication (strong consistency)
            var replicationTasks = _replicas
                .Take((_replicas.Count / 2) + 1)
                .Select(r => r.ReplicateAsync(key, value));
            
            await Task.WhenAll(replicationTasks);
        }
        // Otherwise return immediately (eventual consistency)
    }
}
```

## Key Takeaways

- Eventual consistency prioritizes availability and performance over immediate consistency
- Replicas may temporarily diverge but eventually converge
- Conflicts are possible and must be handled (LWW, application logic, or CRDTs)
- CRDTs provide mathematical guarantees of convergence without coordination
- Asynchronous replication, read repair, and anti-entropy help achieve convergence
- Best for scenarios where availability is more important than immediate consistency
- Used by Amazon, Cassandra, Riak, and other large-scale systems
- Trade-off: More complex application logic to handle conflicts
