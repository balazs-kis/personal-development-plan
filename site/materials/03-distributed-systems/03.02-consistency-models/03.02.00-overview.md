# Chapter 3.2: Consistency Models

## Overview
This chapter explores the spectrum of consistency models available in distributed systems, from strong consistency to eventual consistency. You'll learn the trade-offs each model presents, understand when to use each, and how they impact both user experience and system scalability. Understanding consistency models is crucial for making informed architectural decisions in distributed systems.

## Key Concepts
- **Strong Consistency:** linearizability and its guarantees.
- **Eventual Consistency:** convergence and conflict resolution.
- **Causal Consistency:** preserving cause-and-effect relationships.
- **Read-Your-Writes Consistency:** session guarantees and user experience.
- **Consistency vs Availability Trade-offs:** practical implications of the CAP theorem.
