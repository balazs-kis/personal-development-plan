# Chapter 3.6: Data Management in Distributed Systems

## Overview
This chapter tackles one of the most challenging aspects of microservices: managing data across distributed services. You'll learn the Database per Service pattern, how to maintain consistency without distributed transactions using the Saga pattern, leverage Event Sourcing for complete audit trails, apply CQRS for optimized read/write paths, and understand various data consistency strategies.

## Key Concepts
- **Database per Service:** designing independent data stores for each service.
- **Saga Pattern:** coordinating distributed transactions with choreography and orchestration.
- **Event Sourcing:** storing state as a sequence of events for complete auditability.
- **CQRS:** separating read and write models for performance optimization.
- **Consistency Strategies:** balancing consistency, availability, and partition tolerance.
