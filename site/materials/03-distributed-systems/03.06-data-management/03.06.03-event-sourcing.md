## Introduction

**Event Sourcing** is a pattern where you store the state of your application as a sequence of events rather than the current state. Instead of UPDATE statements that destroy history, you append events that describe what happened. This provides complete audit trails, enables temporal queries, and supports complex event-driven architectures.

## Key Concepts

### Traditional State Storage

```csharp
// Current state only
public class Account
{
    public Guid Id { get; set; }
    public decimal Balance { get; set; }  // Current balance only
    public DateTime LastModified { get; set; }

// Update destroys history
account.Balance = 1000; // Was it 900? 500? Unknown!
```

### Event Sourcing

```csharp
// Store events, not state
public abstract class DomainEvent
{
    public Guid Id { get; set; } = Guid.NewGuid();
    public DateTime Timestamp { get; set; } = DateTime.UtcNow;
}

public class AccountOpenedEvent : DomainEvent
{
    public Guid AccountId { get; set; }
    public decimal InitialDeposit { get; set; }
}

public class MoneyDepositedEvent : DomainEvent
{
    public Guid AccountId { get; set; }
    public decimal Amount { get; set; }
}

public class MoneyWithdrawnEvent : DomainEvent
{
    public Guid AccountId { get; set; }
    public decimal Amount { get; set; }
}

// Event Store
public class EventStore
{
    public async Task AppendAsync(Guid aggregateId, DomainEvent @event)
    {
        await _db.Events.AddAsync(new StoredEvent
        {
            AggregateId = aggregateId,
            EventType = @event.GetType().Name,
            EventData = JsonSerializer.Serialize(@event),
            Timestamp = @event.Timestamp
        });
        await _db.SaveChangesAsync();
    }

    public async Task<List<DomainEvent>> GetEventsAsync(Guid aggregateId)
    {
        var events = await _db.Events
            .Where(e => e.AggregateId == aggregateId)
            .OrderBy(e => e.Timestamp)
            .ToListAsync();

        return events.Select(DeserializeEvent).ToList();
    }
}
```

### Reconstructing State

```csharp
public class Account
{
    public Guid Id { get; private set; }
    public decimal Balance { get; private set; }
    private List<DomainEvent> _changes = new();

    // Rebuild from events
    public static Account LoadFrom(List<DomainEvent> history)
    {
        var account = new Account();
        foreach (var @event in history)
        {
            account.Apply(@event);
        }
        return account;
    }

    private void Apply(DomainEvent @event)
    {
        switch (@event)
        {
            case AccountOpenedEvent e:
                Id = e.AccountId;
                Balance = e.InitialDeposit;
                break;
            case MoneyDepositedEvent e:
                Balance += e.Amount;
                break;
            case MoneyWithdrawnEvent e:
                Balance -= e.Amount;
                break;
        }
    }

    // Commands produce events
    public void Deposit(decimal amount)
    {
        if (amount <= 0) throw new ArgumentException("Amount must be positive");

        var @event = new MoneyDepositedEvent
        {
            AccountId = Id,
            Amount = amount
        };
        Apply(@event);
        _changes.Add(@event);
    }
}
```

## Advanced Event Sourcing Patterns

### Pattern: Aggregate Root with Event Sourcing

```csharp
public abstract class AggregateRoot
{
    private readonly List<DomainEvent> _uncommittedEvents = new();
    public IReadOnlyList<DomainEvent> UncommittedEvents => _uncommittedEvents.AsReadOnly();

    public int Version { get; protected set; }

    protected void RaiseEvent(DomainEvent @event)
    {
        ApplyEvent(@event);
        _uncommittedEvents.Add(@event);
    }

    protected abstract void ApplyEvent(DomainEvent @event);

    public void MarkEventsAsCommitted()
    {
        _uncommittedEvents.Clear();
    }

    public void LoadFromHistory(IEnumerable<DomainEvent> history)
    {
        foreach (var @event in history)
        {
            ApplyEvent(@event);
            Version++;
        }
    }
}

public class Account : AggregateRoot
{
    public Guid Id { get; private set; }
    public string AccountNumber { get; private set; }
    public decimal Balance { get; private set; }
    public AccountStatus Status { get; private set; }
    public decimal DailyWithdrawalLimit { get; private set; }
    public decimal WithdrawnToday { get; private set; }

    // Private constructor for reconstitution
    private Account() { }

    // Factory method for new accounts
    public static Account Open(string accountNumber, decimal initialDeposit, decimal dailyLimit)
    {
        if (initialDeposit < 0)
            throw new ArgumentException("Initial deposit must be positive");

        var account = new Account();
        account.RaiseEvent(new AccountOpenedEvent
        {
            AccountId = Guid.NewGuid(),
            AccountNumber = accountNumber,
            InitialDeposit = initialDeposit,
            DailyWithdrawalLimit = dailyLimit,
            OpenedAt = DateTime.UtcNow
        });
        return account;
    }

    public void Deposit(decimal amount, string description)
    {
        if (Status != AccountStatus.Active)
            throw new InvalidOperationException("Account is not active");

        if (amount <= 0)
            throw new ArgumentException("Amount must be positive");

        RaiseEvent(new MoneyDepositedEvent
        {
            AccountId = Id,
            Amount = amount,
            Description = description,
            DepositedAt = DateTime.UtcNow
        });
    }

    public void Withdraw(decimal amount, string description)
    {
        if (Status != AccountStatus.Active)
            throw new InvalidOperationException("Account is not active");

        if (amount <= 0)
            throw new ArgumentException("Amount must be positive");

        if (Balance < amount)
            throw new InsufficientFundsException($"Balance {Balance} is less than {amount}");

        if (WithdrawnToday + amount > DailyWithdrawalLimit)
            throw new DailyLimitExceededException(
                $"Withdrawal would exceed daily limit of {DailyWithdrawalLimit}");

        RaiseEvent(new MoneyWithdrawnEvent
        {
            AccountId = Id,
            Amount = amount,
            Description = description,
            WithdrawnAt = DateTime.UtcNow
        });
    }

    public void Close(string reason)
    {
        if (Status == AccountStatus.Closed)
            return; // Idempotent

        if (Balance != 0)
            throw new InvalidOperationException("Cannot close account with non-zero balance");

        RaiseEvent(new AccountClosedEvent
        {
            AccountId = Id,
            Reason = reason,
            ClosedAt = DateTime.UtcNow
        });
    }

    protected override void ApplyEvent(DomainEvent @event)
    {
        switch (@event)
        {
            case AccountOpenedEvent e:
                Id = e.AccountId;
                AccountNumber = e.AccountNumber;
                Balance = e.InitialDeposit;
                DailyWithdrawalLimit = e.DailyWithdrawalLimit;
                Status = AccountStatus.Active;
                WithdrawnToday = 0;
                break;

            case MoneyDepositedEvent e:
                Balance += e.Amount;
                break;

            case MoneyWithdrawnEvent e:
                Balance -= e.Amount;
                WithdrawnToday += e.Amount;
                break;

            case AccountClosedEvent e:
                Status = AccountStatus.Closed;
                break;

            case DayEndedEvent e:
                // Reset daily withdrawal counter
                WithdrawnToday = 0;
                break;
        }
    }
}
```

### Repository Implementation

```csharp
public interface IEventStore
{
    Task<IEnumerable<DomainEvent>> GetEventsAsync(Guid aggregateId);
    Task SaveEventsAsync(Guid aggregateId, IEnumerable<DomainEvent> events, int expectedVersion);
}

public class EventStoreRepository<T> where T : AggregateRoot, new()
{
    private readonly IEventStore _eventStore;

    public async Task<T> GetByIdAsync(Guid aggregateId)
    {
        var events = await _eventStore.GetEventsAsync(aggregateId);
        if (!events.Any())
            return null;

        var aggregate = new T();
        aggregate.LoadFromHistory(events);
        return aggregate;
    }

    public async Task SaveAsync(T aggregate)
    {
        var events = aggregate.UncommittedEvents;
        if (!events.Any())
            return;

        await _eventStore.SaveEventsAsync(
            aggregate.Id, 
            events, 
            aggregate.Version);

        aggregate.MarkEventsAsCommitted();
    }
}

// SQL-based event store
public class SqlEventStore : IEventStore
{
    private readonly DbContext _dbContext;

    public async Task<IEnumerable<DomainEvent>> GetEventsAsync(Guid aggregateId)
    {
        var storedEvents = await _dbContext.Events
            .Where(e => e.AggregateId == aggregateId)
            .OrderBy(e => e.Version)
            .ToListAsync();

        return storedEvents.Select(e => DeserializeEvent(e));
    }

    public async Task SaveEventsAsync(
        Guid aggregateId, 
        IEnumerable<DomainEvent> events, 
        int expectedVersion)
    {
        var version = expectedVersion;

        foreach (var @event in events)
        {
            version++;
            
            var storedEvent = new StoredEvent
            {
                EventId = Guid.NewGuid(),
                AggregateId = aggregateId,
                EventType = @event.GetType().AssemblyQualifiedName,
                EventData = JsonSerializer.Serialize(@event),
                Version = version,
                Timestamp = DateTime.UtcNow
            };

            await _dbContext.Events.AddAsync(storedEvent);
        }

        try
        {
            await _dbContext.SaveChangesAsync();
        }
        catch (DbUpdateException ex) when (IsConcurrencyException(ex))
        {
            throw new ConcurrencyException(
                $"Aggregate {aggregateId} was modified by another process", ex);
        }
    }

    private DomainEvent DeserializeEvent(StoredEvent storedEvent)
    {
        var eventType = Type.GetType(storedEvent.EventType);
        return (DomainEvent)JsonSerializer.Deserialize(storedEvent.EventData, eventType);
    }
}
```

## Snapshots for Performance

**Problem**: Replaying 100,000 events is slow

**Solution**: Periodic snapshots

```csharp
public class Snapshot
{
    public Guid AggregateId { get; set; }
    public int Version { get; set; }  // Event number
    public string StateData { get; set; }  // Serialized state
    public DateTime Timestamp { get; set; }
}

public interface ISnapshotStore
{
    Task<Snapshot> GetLatestAsync(Guid aggregateId);
    Task SaveAsync(Snapshot snapshot);
}

public class SnapshotRepository<T> where T : AggregateRoot, new()
{
    private readonly IEventStore _eventStore;
    private readonly ISnapshotStore _snapshotStore;
    private readonly int _snapshotFrequency = 100; // Snapshot every 100 events

    public async Task<T> GetByIdAsync(Guid aggregateId)
    {
        T aggregate;
        int startVersion;

        // Try to load snapshot
        var snapshot = await _snapshotStore.GetLatestAsync(aggregateId);

        if (snapshot != null)
        {
            aggregate = JsonSerializer.Deserialize<T>(snapshot.StateData);
            startVersion = snapshot.Version + 1;
        }
        else
        {
            aggregate = new T();
            startVersion = 0;
        }

        // Load events since snapshot
        var events = await _eventStore.GetEventsAsync(aggregateId, startVersion);
        aggregate.LoadFromHistory(events);

        return aggregate;
    }

    public async Task SaveAsync(T aggregate)
    {
        var events = aggregate.UncommittedEvents;
        if (!events.Any())
            return;

        // Save events
        await _eventStore.SaveEventsAsync(
            aggregate.Id, events, aggregate.Version);

        // Create snapshot if needed
        if (aggregate.Version % _snapshotFrequency == 0)
        {
            var snapshot = new Snapshot
            {
                AggregateId = aggregate.Id,
                Version = aggregate.Version,
                StateData = JsonSerializer.Serialize(aggregate),
                Timestamp = DateTime.UtcNow
            };

            await _snapshotStore.SaveAsync(snapshot);
        }

        aggregate.MarkEventsAsCommitted();
    }
}
```

**Snapshot frequency**: Every 100-1000 events, depending on aggregate size

**Snapshot Strategy Options:**

1. **Time-based**: Snapshot every X hours
2. **Event-count-based**: Snapshot every N events (most common)
3. **On-demand**: Snapshot when rebuilding takes too long
4. **Hybrid**: Combine strategies

## Projections from Events

Build read models by projecting events:

```csharp
// Projection: Account balance history
public class AccountBalanceProjection : IEventHandler<MoneyDepositedEvent>,
                                        IEventHandler<MoneyWithdrawnEvent>
{
    private readonly IDbContext _readDb;

    public async Task HandleAsync(MoneyDepositedEvent evt)
    {
        await _readDb.AccountBalanceHistory.AddAsync(new AccountBalanceHistoryEntry
        {
            AccountId = evt.AccountId,
            Timestamp = evt.DepositedAt,
            ChangeAmount = evt.Amount,
            ChangeType = "Deposit",
            Description = evt.Description
        });
        
        await _readDb.SaveChangesAsync();
    }

    public async Task HandleAsync(MoneyWithdrawnEvent evt)
    {
        await _readDb.AccountBalanceHistory.AddAsync(new AccountBalanceHistoryEntry
        {
            AccountId = evt.AccountId,
            Timestamp = evt.WithdrawnAt,
            ChangeAmount = -evt.Amount,
            ChangeType = "Withdrawal",
            Description = evt.Description
        });
        
        await _readDb.SaveChangesAsync();
    }
}

// Multiple projections from same events
public class AccountSummaryProjection : IEventHandler<AccountOpenedEvent>,
                                        IEventHandler<MoneyDepositedEvent>,
                                        IEventHandler<MoneyWithdrawnEvent>,
                                        IEventHandler<AccountClosedEvent>
{
    private readonly IDbContext _readDb;

    public async Task HandleAsync(AccountOpenedEvent evt)
    {
        await _readDb.AccountSummaries.AddAsync(new AccountSummary
        {
            AccountId = evt.AccountId,
            AccountNumber = evt.AccountNumber,
            CurrentBalance = evt.InitialDeposit,
            Status = "Active",
            OpenedAt = evt.OpenedAt,
            TotalDeposits = evt.InitialDeposit,
            TotalWithdrawals = 0
        });
        
        await _readDb.SaveChangesAsync();
    }

    public async Task HandleAsync(MoneyDepositedEvent evt)
    {
        var summary = await _readDb.AccountSummaries.FindAsync(evt.AccountId);
        summary.CurrentBalance += evt.Amount;
        summary.TotalDeposits += evt.Amount;
        summary.LastActivity = evt.DepositedAt;
        
        await _readDb.SaveChangesAsync();
    }

    public async Task HandleAsync(MoneyWithdrawnEvent evt)
    {
        var summary = await _readDb.AccountSummaries.FindAsync(evt.AccountId);
        summary.CurrentBalance -= evt.Amount;
        summary.TotalWithdrawals += evt.Amount;
        summary.LastActivity = evt.WithdrawnAt;
        
        await _readDb.SaveChangesAsync();
    }

    public async Task HandleAsync(AccountClosedEvent evt)
    {
        var summary = await _readDb.AccountSummaries.FindAsync(evt.AccountId);
        summary.Status = "Closed";
        summary.ClosedAt = evt.ClosedAt;
        
        await _readDb.SaveChangesAsync();
    }
}
```

### Rebuilding Projections

```csharp
// Rebuild projection from scratch
public class ProjectionRebuilder
{
    public async Task RebuildAccountSummaryAsync()
    {
        _logger.LogInformation("Starting projection rebuild...");

        // Clear existing projection
        await _readDb.Database.ExecuteSqlRawAsync("TRUNCATE TABLE AccountSummaries");

        // Get all account IDs
        var accountIds = await _eventStore.GetAllAggregateIdsAsync("Account");

        var totalAccounts = accountIds.Count();
        var processed = 0;

        foreach (var accountId in accountIds)
        {
            // Get all events for account
            var events = await _eventStore.GetEventsAsync(accountId);

            // Replay through projection
            foreach (var @event in events)
            {
                await _projectionHandler.HandleAsync(@event);
            }

            processed++;
            if (processed % 100 == 0)
            {
                _logger.LogInformation("Rebuilt {Processed}/{Total} accounts", 
                    processed, totalAccounts);
            }
        }

        _logger.LogInformation("Projection rebuild complete");
    }
}
```

## Event Versioning

**Scenario**: Event schema changes

**Strategies:**

### Strategy 1: Upcasting (Transform Old Events)

```csharp
// V1
public class OrderPlacedEvent_V1
{
    public Guid OrderId { get; set; }
    public decimal Total { get; set; }
}

// V2 - added customer info
public class OrderPlacedEvent_V2
{
    public Guid OrderId { get; set; }
    public decimal Total { get; set; }
    public Guid CustomerId { get; set; }  // New
    public string CustomerEmail { get; set; }  // New
}

public class EventUpcastingDeserializer
{
    public DomainEvent DeserializeEvent(StoredEvent stored)
    {
        return stored.EventType switch
        {
            "OrderPlacedEvent_V1" => UpcastToV2(
                JsonSerializer.Deserialize<OrderPlacedEvent_V1>(stored.EventData)),
            "OrderPlacedEvent_V2" => 
                JsonSerializer.Deserialize<OrderPlacedEvent_V2>(stored.EventData),
            _ => throw new UnknownEventTypeException(stored.EventType)
        };
    }

    private OrderPlacedEvent_V2 UpcastToV2(OrderPlacedEvent_V1 v1)
    {
        return new OrderPlacedEvent_V2
        {
            OrderId = v1.OrderId,
            Total = v1.Total,
            CustomerId = Guid.Empty,  // Default for old events
            CustomerEmail = "unknown@example.com"
        };
    }
}
```

```csharp
// Background job to transform old events
public class EventMigrationService
{
    public async Task MigrateOrderPlacedEventsAsync()
    {
        var oldEvents = await _eventStore.GetEventsByTypeAsync("OrderPlacedEvent_V1");

        foreach (var oldEvent in oldEvents)
        {
```

## Temporal Queries

Query data at a specific point in time:

```csharp
public class TemporalQueryService
{
    // Get account balance at specific date
    public async Task<decimal> GetBalanceAtAsync(Guid accountId, DateTime pointInTime)
    {
        var events = await _eventStore.GetEventsAsync(accountId);
        
        // Filter events up to the point in time
        var relevantEvents = events
            .Where(e => e.Timestamp <= pointInTime)
            .OrderBy(e => e.Timestamp);

        var account = new Account();
        account.LoadFromHistory(relevantEvents);
        
        return account.Balance;
    }

    // Get all accounts that had balance > 1000 on specific date
    public async Task<List<AccountSummary>> GetAccountsWithBalanceAboveAsync(
        decimal threshold, 
        DateTime pointInTime)
    {
        var accountIds = await _eventStore.GetAllAggregateIdsAsync("Account");
        var results = new List<AccountSummary>();

        foreach (var accountId in accountIds)
        {
            var balance = await GetBalanceAtAsync(accountId, pointInTime);
            if (balance > threshold)
            {
                var events = await _eventStore.GetEventsAsync(accountId);
                var openedEvent = events.OfType<AccountOpenedEvent>().First();
                
                results.Add(new AccountSummary
                {
                    AccountId = accountId,
                    AccountNumber = openedEvent.AccountNumber,
                    BalanceAtPointInTime = balance
                });
            }
        }

        return results;
    }
}
```

## When to Use Event Sourcing

### Use Event Sourcing When:

✅ **Audit trail required** (financial, medical, legal domains)
```
Example: Banking - need complete history of transactions
```

✅ **Temporal queries needed** ("What was the state on date X?")
```
Example: Tax reporting - need historical snapshots
```

✅ **Event-driven architecture** (events drive projections/notifications)
```
Example: E-commerce - order events trigger fulfillment, notifications
```

✅ **Complex business workflows** (need to replay decisions)
```
Example: Insurance claims - replay decision process
```

✅ **Debugging/troubleshooting** (need to understand what happened)
```
Example: Any domain where "how did we get here?" is important
```

### Don't Use Event Sourcing When:

❌ **Simple CRUD** - overhead not justified  
❌ **No audit/history needs** - current state is enough  
❌ **Performance critical reads** - rebuilding from events is slow  
❌ **Team unfamiliar** - steep learning curve  
❌ **No clear boundaries** - hard to version events

## Real-World Considerations

### Event Store Selection

**Specialized Event Stores:**
- **EventStoreDB** - Purpose-built for event sourcing
- **Axon Server** - Event store + messaging
- **Marten** - PostgreSQL-based event store for .NET

**General Databases:**
- **PostgreSQL** - Append-only table with strong consistency
- **SQL Server** - Similar to PostgreSQL
- **CosmosDB** - Partition by aggregate ID

**Considerations:**
- Append performance
- Query performance (by aggregate, by event type)
- Subscription/projection support
- Snapshot support
- Event versioning features

### Performance at Scale

**Challenge**: Million events per aggregate

**Solutions:**
1. **Aggressive snapshotting** (every 50-100 events)
2. **Separate hot/cold storage** (recent events in fast DB, old in archive)
3. **Caching** (cache reconstituted aggregates)
4. **Archiving** (move old events to cheaper storage)

```csharp
public class TieredEventStore : IEventStore
{
    public async Task<IEnumerable<DomainEvent>> GetEventsAsync(
        Guid aggregateId, 
        int fromVersion = 0)
    {
        // Get recent events from hot storage (fast)
        var hotEvents = await _hotStorage.GetEventsAsync(aggregateId, fromVersion);
        
        // If we need older events, go to cold storage
        if (fromVersion < _hotStorageThreshold)
        {
            var coldEvents = await _coldStorage.GetEventsAsync(
                aggregateId, fromVersion, _hotStorageThreshold - 1);
            
            return coldEvents.Concat(hotEvents);
        }

        return hotEvents;
    }
}
```

## Self-Check Questions

1. **What's the key difference between event sourcing and traditional storage?**
   - Event sourcing stores events (changes), traditional stores current state

2. **Why use snapshots?**
   - Performance: avoid replaying thousands of events

3. **How do you query event-sourced data?**
   - Rebuild aggregate from events, or use projections/read models

4. **What's the relationship between event sourcing and CQRS?**
   - Often used together: events for write side, projections for read side

## Key Takeaways

✅ **Event sourcing** stores state as sequence of events

✅ **Complete audit trail** of all changes

✅ **Snapshots** improve reconstruction performance

✅ **Event versioning** is critical for evolution

✅ **Use with CQRS** for optimal read performance

✅ **Not for everything** - adds significant complexity
