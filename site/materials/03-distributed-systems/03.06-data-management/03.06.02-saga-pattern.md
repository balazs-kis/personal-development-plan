## Learning Objectives

By the end of this lesson, you will be able to:

- Design compensating transactions for failure handling

---

## Introduction

Traditional ACID transactions don't work across microservices because you can't have a distributed transaction coordinator. The **Saga pattern** solves this by breaking a distributed transaction into a series of local transactions, each published to a message bus. If any step fails, compensating transactions undo the previous steps.

## Key Concepts

### What is a Saga?

A saga is a sequence of local transactions where each transaction updates data within a single service and publishes an event or message to trigger the next transaction. If a transaction fails, the saga executes compensating transactions to undo changes.

**Example: Order Processing Saga**

```
Happy Path:
1. Order Service: Create Order → OrderCreated
2. Inventory Service: Reserve Stock → StockReserved  
3. Payment Service: Charge Customer → PaymentProcessed
4. Shipping Service: Create Shipment → ShipmentCreated
5. Order Service: Confirm Order → OrderConfirmed

Failure Path (Payment fails):
1. Order Service: Create Order → OrderCreated
2. Inventory Service: Reserve Stock → StockReserved
3. Payment Service: Charge Customer → PaymentFailed ❌
4. Inventory Service: Release Stock (compensate)
5. Order Service: Cancel Order (compensate)
```

## Choreography vs Orchestration

### Choreography-Based Saga (Decentralized)

Services coordinate by listening to events:

```csharp
// Order Service
public class OrderService
{
    public async Task CreateOrderAsync(CreateOrderCommand cmd)
    {
        var order = new Order(cmd);
        await _repository.SaveAsync(order);
        
        await _eventBus.PublishAsync(new OrderCreatedEvent
        {
            OrderId = order.Id,
            Items = order.Items
        });
    }
}

// Inventory Service listens
public class InventoryEventHandler : IEventHandler<OrderCreatedEvent>
{
    public async Task HandleAsync(OrderCreatedEvent evt)
    {
        try
        {
            await _inventory.ReserveAsync(evt.Items);
            await _eventBus.PublishAsync(new StockReservedEvent
            {
                OrderId = evt.OrderId
            });
        }
        catch (OutOfStockException)
        {
            await _eventBus.PublishAsync(new StockReservationFailedEvent
            {
                OrderId = evt.OrderId
            });
        }
    }
}

// Payment Service listens
public class PaymentEventHandler : IEventHandler<StockReservedEvent>
{
    public async Task HandleAsync(StockReservedEvent evt)
    {
        try
        {
            await _payment.ProcessAsync(evt.OrderId);
            await _eventBus.PublishAsync(new PaymentProcessedEvent
            {
                OrderId = evt.OrderId
            });
        }
        catch (PaymentException)
        {
            await _eventBus.PublishAsync(new PaymentFailedEvent
            {
                OrderId = evt.OrderId
            });
        }
    }
}

// Inventory Service also listens for compensation
public class InventoryCompensationHandler : IEventHandler<PaymentFailedEvent>
{
    public async Task HandleAsync(PaymentFailedEvent evt)
    {
        await _inventory.ReleaseReservationAsync(evt.OrderId);
        _logger.LogInformation("Released inventory for failed order {OrderId}", 
            evt.OrderId);
    }
}
```

**Pros**: Loose coupling, easy to add new participants  
**Cons**: Hard to understand flow, difficult debugging

### Orchestration-Based Saga (Centralized)

Central coordinator manages the workflow:

```csharp
public class OrderSagaOrchestrator
{
    public async Task ExecuteAsync(CreateOrderCommand cmd)
    {
        var orderId = Guid.NewGuid();
        var sagaState = new SagaState { OrderId = orderId };

        try
        {
            // Step 1: Create Order
            sagaState.OrderCreated = true;
            await _orderService.CreateOrderAsync(orderId, cmd);

            // Step 2: Reserve Inventory
            sagaState.StockReserved = true;
            await _inventoryService.ReserveStockAsync(orderId, cmd.Items);

            // Step 3: Process Payment
            sagaState.PaymentProcessed = true;
            await _paymentService.ProcessPaymentAsync(orderId, cmd.Payment);

            // Step 4: Create Shipment
            sagaState.ShipmentCreated = true;
            await _shippingService.CreateShipmentAsync(orderId, cmd.Address);

            // Step 5: Confirm Order
            await _orderService.ConfirmOrderAsync(orderId);

            _logger.LogInformation("Order saga completed successfully");
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Saga failed, compensating...");
            await CompensateAsync(sagaState);
            throw;
        }
    }

    private async Task CompensateAsync(SagaState state)
    {
        // Undo in reverse order
        if (state.ShipmentCreated)
            await _shippingService.CancelShipmentAsync(state.OrderId);

        if (state.PaymentProcessed)
            await _paymentService.RefundAsync(state.OrderId);

        if (state.StockReserved)
            await _inventoryService.ReleaseStockAsync(state.OrderId);

        if (state.OrderCreated)
            await _orderService.CancelOrderAsync(state.OrderId);
    }
}
```

**Pros**: Clear workflow, centralized logic, easier debugging  
**Cons**: Orchestrator is a dependency, can become complex

## Advanced Saga Patterns

### Pattern 1: Saga with Timeout Handling

```csharp
public class OrderSagaOrchestrator
{
    private readonly TimeSpan _stepTimeout = TimeSpan.FromSeconds(30);

    public async Task ExecuteAsync(CreateOrderCommand cmd)
    {
        var sagaState = new SagaState { OrderId = Guid.NewGuid() };

        try
        {
            // Step 1: Create Order (with timeout)
            using var cts = new CancellationTokenSource(_stepTimeout);
            sagaState.OrderCreated = true;
            await _orderService.CreateOrderAsync(sagaState.OrderId, cmd, cts.Token);

            // Step 2: Reserve Inventory (with timeout)
            using var cts2 = new CancellationTokenSource(_stepTimeout);
            sagaState.StockReserved = true;
            await _inventoryService.ReserveStockAsync(
                sagaState.OrderId, cmd.Items, cts2.Token);

            // Step 3: Process Payment (with timeout)
            using var cts3 = new CancellationTokenSource(_stepTimeout);
            sagaState.PaymentProcessed = true;
            await _paymentService.ProcessPaymentAsync(
                sagaState.OrderId, cmd.Payment, cts3.Token);

            await _orderService.ConfirmOrderAsync(sagaState.OrderId);
        }
        catch (OperationCanceledException)
        {
            _logger.LogWarning("Saga step timed out, compensating...");
            await CompensateAsync(sagaState);
            throw new SagaTimeoutException("Saga execution timed out");
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Saga failed, compensating...");
            await CompensateAsync(sagaState);
            throw;
        }
    }
}
```

### Pattern 2: Saga with Retry Logic

```csharp
public class ResilientSagaOrchestrator
{
    public async Task ExecuteAsync(CreateOrderCommand cmd)
    {
        var sagaState = new SagaState { OrderId = Guid.NewGuid() };

        try
        {
            // Retry transient failures
            var retryPolicy = Policy
                .Handle<HttpRequestException>()
                .Or<TimeoutException>()
                .WaitAndRetryAsync(
                    retryCount: 3,
                    sleepDurationProvider: attempt => TimeSpan.FromSeconds(Math.Pow(2, attempt)),
                    onRetry: (exception, timeSpan, retryCount, context) =>
                    {
                        _logger.LogWarning(
                            "Retry {RetryCount} after {Delay}s due to {Exception}",
                            retryCount, timeSpan.TotalSeconds, exception.Message);
                    });

            sagaState.OrderCreated = true;
            await retryPolicy.ExecuteAsync(() => 
                _orderService.CreateOrderAsync(sagaState.OrderId, cmd));

            sagaState.StockReserved = true;
            await retryPolicy.ExecuteAsync(() => 
                _inventoryService.ReserveStockAsync(sagaState.OrderId, cmd.Items));

            sagaState.PaymentProcessed = true;
            await retryPolicy.ExecuteAsync(() => 
                _paymentService.ProcessPaymentAsync(sagaState.OrderId, cmd.Payment));

            await _orderService.ConfirmOrderAsync(sagaState.OrderId);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Saga failed after retries, compensating...");
            await CompensateAsync(sagaState);
            throw;
        }
    }
}
```

### Pattern 3: Saga State Persistence

Store saga state for crash recovery:

```csharp
public class PersistentSagaOrchestrator
{
    public async Task ExecuteAsync(CreateOrderCommand cmd)
    {
        // Create saga instance
        var saga = new OrderSaga
        {
            Id = Guid.NewGuid(),
            OrderId = Guid.NewGuid(),
            State = SagaState.Started,
            CreatedAt = DateTime.UtcNow
        };

        await _sagaRepository.SaveAsync(saga);

        try
        {
            // Step 1
            await _orderService.CreateOrderAsync(saga.OrderId, cmd);
            saga.State = SagaState.OrderCreated;
            await _sagaRepository.UpdateAsync(saga);

            // Step 2
            await _inventoryService.ReserveStockAsync(saga.OrderId, cmd.Items);
            saga.State = SagaState.StockReserved;
            await _sagaRepository.UpdateAsync(saga);

            // Step 3
            await _paymentService.ProcessPaymentAsync(saga.OrderId, cmd.Payment);
            saga.State = SagaState.PaymentProcessed;
            await _sagaRepository.UpdateAsync(saga);

            // Complete
            saga.State = SagaState.Completed;
            saga.CompletedAt = DateTime.UtcNow;
            await _sagaRepository.UpdateAsync(saga);
        }
        catch (Exception ex)
        {
            saga.State = SagaState.Compensating;
            saga.ErrorMessage = ex.Message;
            await _sagaRepository.UpdateAsync(saga);

            await CompensateAsync(saga);

            saga.State = SagaState.Compensated;
            await _sagaRepository.UpdateAsync(saga);
            throw;
        }
    }
}

// Background job to recover crashed sagas
public class SagaRecoveryService : BackgroundService
{
    protected override async Task ExecuteAsync(CancellationToken ct)
    {
        while (!ct.IsCancellationRequested)
        {
            // Find sagas stuck in intermediate states
            var stuckSagas = await _sagaRepository.GetStuckSagasAsync(
                olderThan: DateTime.UtcNow.AddMinutes(-5));

            foreach (var saga in stuckSagas)
            {
                _logger.LogWarning("Recovering stuck saga {SagaId}", saga.Id);
                
                try
                {
                    await CompensateAsync(saga);
                    saga.State = SagaState.Compensated;
                    await _sagaRepository.UpdateAsync(saga);
                }
                catch (Exception ex)
                {
                    _logger.LogError(ex, "Failed to recover saga {SagaId}", saga.Id);
                }
            }

            await Task.Delay(TimeSpan.FromMinutes(1), ct);
        }
    }
}
```

## Choreography Deep Dive

### Event Chain Example

```csharp
// Domain events
public record OrderCreatedEvent(Guid OrderId, List<OrderItem> Items, Guid CustomerId);
public record StockReservedEvent(Guid OrderId, Guid ReservationId);
public record StockReservationFailedEvent(Guid OrderId, string Reason);
public record PaymentProcessedEvent(Guid OrderId, Guid TransactionId);
public record PaymentFailedEvent(Guid OrderId, string Reason);
public record OrderConfirmedEvent(Guid OrderId);
public record OrderCancelledEvent(Guid OrderId, string Reason);

// Order Service
public class OrderService
{
    public async Task<Guid> CreateOrderAsync(CreateOrderCommand cmd)
    {
        var order = new Order
        {
            Id = Guid.NewGuid(),
            CustomerId = cmd.CustomerId,
            Items = cmd.Items,
            Status = OrderStatus.Pending
        };

        await _repository.SaveAsync(order);

        // Publish event to start saga
        await _eventBus.PublishAsync(new OrderCreatedEvent(
            order.Id, order.Items, order.CustomerId));

        return order.Id;
    }
}

// Inventory Service
public class InventoryService : 
    IEventHandler<OrderCreatedEvent>,
    IEventHandler<PaymentFailedEvent>
{
    public async Task HandleAsync(OrderCreatedEvent evt)
    {
        try
        {
            var reservationId = await _inventory.ReserveAsync(evt.Items);
            
            await _eventBus.PublishAsync(new StockReservedEvent(
                evt.OrderId, reservationId));
        }
        catch (OutOfStockException ex)
        {
            await _eventBus.PublishAsync(new StockReservationFailedEvent(
                evt.OrderId, ex.Message));
        }
    }

    // Compensation
    public async Task HandleAsync(PaymentFailedEvent evt)
    {
        await _inventory.ReleaseReservationAsync(evt.OrderId);
        _logger.LogInformation("Released inventory for order {OrderId}", evt.OrderId);
    }
}

// Payment Service
public class PaymentService : 
    IEventHandler<StockReservedEvent>,
    IEventHandler<OrderCancelledEvent>
{
    public async Task HandleAsync(StockReservedEvent evt)
    {
        try
        {
            var transactionId = await _payment.ChargeAsync(evt.OrderId);
            
            await _eventBus.PublishAsync(new PaymentProcessedEvent(
                evt.OrderId, transactionId));
        }
        catch (PaymentException ex)
        {
            await _eventBus.PublishAsync(new PaymentFailedEvent(
                evt.OrderId, ex.Message));
        }
    }

    // Compensation
    public async Task HandleAsync(OrderCancelledEvent evt)
    {
        await _payment.RefundAsync(evt.OrderId);
        _logger.LogInformation("Refunded payment for order {OrderId}", evt.OrderId);
    }
}

// Order Service listens for completion
public class OrderCompletionHandler : 
    IEventHandler<PaymentProcessedEvent>,
    IEventHandler<StockReservationFailedEvent>,
    IEventHandler<PaymentFailedEvent>
{
    public async Task HandleAsync(PaymentProcessedEvent evt)
    {
        var order = await _repository.GetAsync(evt.OrderId);
        order.Status = OrderStatus.Confirmed;
        await _repository.SaveAsync(order);

        await _eventBus.PublishAsync(new OrderConfirmedEvent(evt.OrderId));
    }

    public async Task HandleAsync(StockReservationFailedEvent evt)
    {
        var order = await _repository.GetAsync(evt.OrderId);
        order.Status = OrderStatus.Cancelled;
        order.CancellationReason = evt.Reason;
        await _repository.SaveAsync(order);

        await _eventBus.PublishAsync(new OrderCancelledEvent(
            evt.OrderId, evt.Reason));
    }

    public async Task HandleAsync(PaymentFailedEvent evt)
    {
        var order = await _repository.GetAsync(evt.OrderId);
        order.Status = OrderStatus.Cancelled;
        order.CancellationReason = evt.Reason;
        await _repository.SaveAsync(order);

        await _eventBus.PublishAsync(new OrderCancelledEvent(
            evt.OrderId, evt.Reason));
    }
}
```

```

                    ↓
```

## Orchestration with MassTransit

### Full Example with State Machine

```csharp
public class OrderStateMachine : MassTransitStateMachine<OrderSagaState>
{
    public OrderStateMachine()
    {
        InstanceState(x => x.CurrentState);

        Initially(
            When(OrderCreated)
                .Then(context => context.Saga.OrderId = context.Message.OrderId)
                .TransitionTo(WaitingForInventoryReservation)
                .PublishAsync(context => context.Init<ReserveStock>(new
                {
                    context.Saga.OrderId,
                    Items = context.Message.Items
                })));

        During(WaitingForInventoryReservation,
            When(StockReserved)
                .TransitionTo(WaitingForPayment)
                .PublishAsync(context => context.Init<ProcessPayment>(new
                {
                    context.Saga.OrderId,
                    Amount = context.Message.Amount
                })),
            When(StockReservationFailed)
                .TransitionTo(Failed)
                .PublishAsync(context => context.Init<CancelOrder>(new
                {
                    context.Saga.OrderId
                })));

        During(WaitingForPayment,
            When(PaymentProcessed)
                .TransitionTo(Completed)
                .Finalize(),
            When(PaymentFailed)
                .TransitionTo(Compensating)
                .PublishAsync(context => context.Init<ReleaseStock>(new
                {
                    context.Saga.OrderId
                })));
    }

    public State WaitingForInventoryReservation { get; private set; }
    public State WaitingForPayment { get; private set; }
    public State Compensating { get; private set; }
    public State Completed { get; private set; }
    public State Failed { get; private set; }

    public Event<OrderCreated> OrderCreated { get; private set; }
    public Event<StockReserved> StockReserved { get; private set; }
    public Event<PaymentProcessed> PaymentProcessed { get; private set; }
    public Event<PaymentFailed> PaymentFailed { get; private set; }
}
```

## Orchestration with MassTransit

### Full Example with State Machine

```csharp
// Saga state
public class OrderSagaState : SagaStateMachineInstance
{
    public Guid CorrelationId { get; set; }
    public string CurrentState { get; set; }
    
    public Guid OrderId { get; set; }
    public Guid? ReservationId { get; set; }
    public Guid? TransactionId { get; set; }
    
    public DateTime CreatedAt { get; set; }
    public DateTime? CompletedAt { get; set; }
}

// State machine
public class OrderStateMachine : MassTransitStateMachine<OrderSagaState>
{
    public OrderStateMachine()
    {
        InstanceState(x => x.CurrentState);

        Event(() => OrderCreated, x => x.CorrelateById(ctx => ctx.Message.OrderId));
        Event(() => StockReserved, x => x.CorrelateById(ctx => ctx.Message.OrderId));
        Event(() => StockReservationFailed, x => x.CorrelateById(ctx => ctx.Message.OrderId));
        Event(() => PaymentProcessed, x => x.CorrelateById(ctx => ctx.Message.OrderId));
        Event(() => PaymentFailed, x => x.CorrelateById(ctx => ctx.Message.OrderId));

        Initially(
            When(OrderCreated)
                .Then(context =>
                {
                    context.Saga.OrderId = context.Message.OrderId;
                    context.Saga.CreatedAt = DateTime.UtcNow;
                })
                .TransitionTo(ReservingStock)
                .PublishAsync(context => context.Init<ReserveStock>(new
                {
                    context.Message.OrderId,
                    context.Message.Items
                })));

        During(ReservingStock,
            When(StockReserved)
                .Then(context => context.Saga.ReservationId = context.Message.ReservationId)
                .TransitionTo(ProcessingPayment)
                .PublishAsync(context => context.Init<ProcessPayment>(new
                {
                    context.Saga.OrderId,
                    context.Message.Amount
                })),
            When(StockReservationFailed)
                .Then(context => _logger.LogWarning(
                    "Stock reservation failed for order {OrderId}: {Reason}",
                    context.Saga.OrderId, context.Message.Reason))
                .TransitionTo(Failed)
                .PublishAsync(context => context.Init<CancelOrder>(new
                {
                    context.Saga.OrderId,
                    Reason = context.Message.Reason
                }))
                .Finalize());

        During(ProcessingPayment,
            When(PaymentProcessed)
                .Then(context =>
                {
                    context.Saga.TransactionId = context.Message.TransactionId;
                    context.Saga.CompletedAt = DateTime.UtcNow;
                })
                .TransitionTo(Completed)
                .PublishAsync(context => context.Init<ConfirmOrder>(new
                {
                    context.Saga.OrderId
                }))
                .Finalize(),
            When(PaymentFailed)
                .Then(context => _logger.LogWarning(
                    "Payment failed for order {OrderId}: {Reason}",
                    context.Saga.OrderId, context.Message.Reason))
                .TransitionTo(Compensating)
                .PublishAsync(context => context.Init<ReleaseStock>(new
                {
                    context.Saga.OrderId,
                    context.Saga.ReservationId
                }))
                .Then(context => context.Saga.TransitionTo(Failed))
                .Finalize());

        SetCompletedWhenFinalized();
    }

    public State ReservingStock { get; private set; }
    public State ProcessingPayment { get; private set; }
    public State Compensating { get; private set; }
    public State Completed { get; private set; }
    public State Failed { get; private set; }

    public Event<OrderCreated> OrderCreated { get; private set; }
    public Event<StockReserved> StockReserved { get; private set; }
    public Event<StockReservationFailed> StockReservationFailed { get; private set; }
    public Event<PaymentProcessed> PaymentProcessed { get; private set; }
    public Event<PaymentFailed> PaymentFailed { get; private set; }
}

// Registration
services.AddMassTransit(x =>
{
    x.AddSagaStateMachine<OrderStateMachine, OrderSagaState>()
        .EntityFrameworkRepository(r =>
        {
            r.AddDbContext<DbContext, SagaDbContext>((provider, builder) =>
            {
                builder.UseNpgsql(connectionString);
            });
        });

    x.UsingRabbitMq((context, cfg) =>
    {
        cfg.ConfigureEndpoints(context);
    });
});
```

## Compensating Transactions

**Rules**:
1. **Semantic compensation**: Undo business effect, not technical changes
2. **Idempotent**: Can be executed multiple times safely
3. **Commutative**: Order doesn't matter (when possible)
4. **Reliable**: Must succeed eventually (with retries)

**Example:**

```csharp
// Forward transaction
public async Task<Guid> ReserveStock(int productId, int quantity)
{
    var reservation = new Reservation
    {
        Id = Guid.NewGuid(),
        ProductId = productId,
        Quantity = quantity,
        ReservedAt = DateTime.UtcNow,
        ExpiresAt = DateTime.UtcNow.AddMinutes(15)
    };

    await _db.Reservations.AddAsync(reservation);
    
    var product = await _db.Products.FindAsync(productId);
    product.AvailableQuantity -= quantity;
    
    await _db.SaveChangesAsync();
    return reservation.Id;
}

// Compensation (semantic, not just DELETE)
public async Task ReleaseReservation(Guid reservationId)
{
    var reservation = await _db.Reservations.FindAsync(reservationId);
    if (reservation == null)
    {
        _logger.LogWarning("Reservation {ReservationId} not found (already released?)", 
            reservationId);
        return; // Idempotent: already compensated
    }

    var product = await _db.Products.FindAsync(reservation.ProductId);
    product.AvailableQuantity += reservation.Quantity;

    _db.Reservations.Remove(reservation);
    await _db.SaveChangesAsync();
    
    _logger.LogInformation("Released {Quantity} units of product {ProductId}",
        reservation.Quantity, reservation.ProductId);
}
```

### Designing Compensatable Operations

**Pattern: Two-Phase Operations**

```csharp
// Phase 1: Reserve (compensatable)
public async Task<Guid> ReservePayment(Guid orderId, decimal amount)
{
    var reservation = new PaymentReservation
    {
        Id = Guid.NewGuid(),
        OrderId = orderId,
        Amount = amount,
        Status = "Reserved",
        ReservedAt = DateTime.UtcNow
    };

    await _db.PaymentReservations.AddAsync(reservation);
    await _db.SaveChangesAsync();
    
    return reservation.Id;
}

// Phase 2: Capture (commit the reservation)
public async Task CapturePayment(Guid reservationId)
{
    var reservation = await _db.PaymentReservations.FindAsync(reservationId);
    
    // Actually charge the customer
    await _paymentGateway.CaptureAsync(reservation.Amount);
    
    reservation.Status = "Captured";
    reservation.CapturedAt = DateTime.UtcNow;
    await _db.SaveChangesAsync();
}

// Compensation: Release/Cancel
public async Task ReleasePayment(Guid reservationId)
{
    var reservation = await _db.PaymentReservations.FindAsync(reservationId);
    if (reservation == null || reservation.Status == "Released")
        return; // Idempotent

    if (reservation.Status == "Captured")
    {
        // Already charged, need to refund
        await _paymentGateway.RefundAsync(reservation.Amount);
    }

    reservation.Status = "Released";
    reservation.ReleasedAt = DateTime.UtcNow;
    await _db.SaveChangesAsync();
}
```

**Non-compensable operations**: Some operations can't be undone:
- Sending emails
- Triggering external workflows
- Physical actions (printing labels, etc.)

**Strategies:**
1. **Delay non-compensable operations** until end of saga
2. **Send corrective notifications** if saga fails after non-compensable operation
3. **Use two-phase commit** where possible

```csharp
// Example: Email at the end
public class OrderStateMachine : MassTransitStateMachine<OrderSagaState>
{
    public OrderStateMachine()
    {
        During(Completed,
            When(OrderConfirmed)
                .PublishAsync(context => context.Init<SendOrderConfirmationEmail>(new
                {
                    context.Saga.OrderId,
                    context.Saga.CustomerEmail
                })));

        During(Failed,
```

## Comparison: Choreography vs Orchestration

| Aspect | Choreography | Orchestration |
|--------|--------------|---------------|
| **Control** | Decentralized | Centralized |
| **Coupling** | Loose | Tighter (to orchestrator) |
| **Visibility** | Difficult (event flow) | Easy (orchestrator logs) |
| **Complexity** | Distributed complexity | Centralized complexity |
| **Testing** | Harder (need all services) | Easier (mock services) |
| **Debugging** | Harder (trace events) | Easier (see orchestrator state) |
| **Adding Steps** | Easy (new listener) | Moderate (update orchestrator) |
| **Transaction Control** | Emergent behavior | Explicit control |
| **Failure Handling** | Each service decides | Orchestrator decides |
| **Best For** | Simple workflows, many participants | Complex workflows, tight control needed |

**Rule of thumb:**
- **2-3 services, simple flow** → Choreography
- **4+ services, complex flow, needs visibility** → Orchestration

### Saga Duration

**Short-lived sagas** (seconds to minutes):

**Long-lived sagas** (hours to days):

- Persistent saga state
- Saga expiration/timeout
- Manual intervention for stuck sagas
- Monitoring and alerts

```csharp
public class OrderSagaOrchestrator

    private readonly ILogger _logger;

        _sagaDurationHistogram = _meter.CreateHistogram<double>("saga.duration", "seconds");
    }

    public async Task ExecuteAsync(CreateOrderCommand cmd)
    {
        var sw = Stopwatch.StartNew();
        _sagaStartedCounter.Add(1, new KeyValuePair<string, object>("saga_type", "order"));

            _sagaCompletedCounter.Add(1, new KeyValuePair<string, object>("saga_type", "order"));

                new KeyValuePair<string, object>("status", "success"));
```

## Self-Check Questions

1. **Why can't we use distributed transactions?**
   - Coordinator becomes bottleneck, reduces availability, complexity

2. **What's the difference between choreography and orchestration?**
   - Choreography: decentralized, events; Orchestration: centralized coordinator

3. **What makes a good compensating transaction?**
   - Idempotent, semantic (undoes business effect), reliable

4. **When should you use sagas?**
   - When operations span multiple services and need consistency

---

## Key Takeaways

✅ **Sagas** coordinate distributed transactions via local transactions + events

✅ **Choreography** = decentralized, **Orchestration** = centralized

✅ **Compensating transactions** undo effects of failed sagas

✅ **Idempotency** is critical for reliable saga execution

✅ Use frameworks like **MassTransit** or **NServiceBus** for production sagas
