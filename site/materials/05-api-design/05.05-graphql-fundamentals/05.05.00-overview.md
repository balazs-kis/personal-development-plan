# Chapter 5.5: GraphQL Fundamentals

## Overview
This chapter introduces GraphQL, a query language for APIs that provides a more flexible alternative to REST. You'll learn the GraphQL type system, how to write queries and mutations, understand the resolver pattern and execution model, solve the N+1 problem with DataLoader, and evaluate when GraphQL is the right choice compared to REST.

## Key Concepts
- **Schema Definition Language (SDL):** GraphQL's type system for defining your API contract.
- **Queries and Mutations:** reading and modifying data in GraphQL.
- **Subscriptions:** real-time updates using GraphQL.
- **Resolvers:** functions that fetch data for each field.
- **N+1 Problem:** performance issue in data fetching and its solution with DataLoader.
- **GraphQL vs REST:** trade-offs and when to use each approach.
