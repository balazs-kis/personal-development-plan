# Chapter 5.2: RESTful API Design

## Overview
This chapter provides a deep dive into RESTful API design principles and practices. You'll learn to design truly RESTful APIs (not just HTTP APIs), understand resource modeling, master HTTP method semantics, choose appropriate status codes, design clean URLs, and implement HATEOAS for API discoverability. By the end, you'll understand what differentiates a mature REST API from a "REST-ish" one.

## Key Concepts
- **Resource-Oriented Design:** modeling your domain as resources with clear relationships.
- **HTTP Method Semantics:** understanding GET, POST, PUT, PATCH, DELETE and their proper use.
- **Status Code Selection:** choosing the right HTTP status codes for every scenario.
- **URL Design and Naming:** creating intuitive, consistent URL patterns.
- **HATEOAS and Richardson Maturity Model:** achieving true REST maturity with hypermedia.
