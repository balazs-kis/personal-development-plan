## Introduction

HTTP defines a set of request methods that indicate the desired action for a resource. Each method has specific semantics, safety guarantees, and idempotency characteristics. Using methods correctly is fundamental to RESTful API design and enables proper caching, retries, and client behavior.

## Key Concepts Summary

### HTTP Method Overview

| Method  | Safe | Idempotent | Cacheable | Use Case |
|---------|------|------------|-----------|----------|
| GET     | ✅   | ✅         | ✅        | Retrieve resource |
| POST    | ❌   | ❌         | ⚠️        | Create resource |
| PUT     | ❌   | ✅         | ❌        | Replace resource |
| PATCH   | ❌   | ⚠️         | ❌        | Partial update |
| DELETE  | ❌   | ✅         | ❌        | Remove resource |
| HEAD    | ✅   | ✅         | ✅        | Get headers only |
| OPTIONS | ✅   | ✅         | ❌        | Get capabilities |

**Safe:** Method doesn't modify resource state
**Idempotent:** Multiple identical requests have the same effect as one

### GET - Retrieve Resources

```csharp
[ApiController]
[Route("api/products")]
public class ProductsController : ControllerBase
{
    private readonly IProductRepository _repository;
    
    // Get collection
    [HttpGet]
    public ActionResult<IEnumerable<ProductDto>> GetProducts(
        [FromQuery] int page = 1,
        [FromQuery] int pageSize = 20,
        [FromQuery] string? category = null)
    {
        var products = _repository.GetProducts(page, pageSize, category);
        return Ok(products);
    }
    
    // Get individual resource
    [HttpGet("{id}")]
    public ActionResult<ProductDto> GetProduct(int id)
    {
        var product = _repository.GetById(id);
        
        if (product == null)
            return NotFound();
            
        return Ok(product);
    }
    
    // Get nested resource
    [HttpGet("{id}/reviews")]
    public ActionResult<IEnumerable<ReviewDto>> GetProductReviews(int id)
    {
        if (!_repository.Exists(id))
            return NotFound();
            
        var reviews = _repository.GetReviews(id);
        return Ok(reviews);
    }
}

// GET characteristics:
// - MUST be safe (no side effects)
// - MUST be idempotent
// - SHOULD be cacheable
// - Body typically ignored
```

### POST - Create Resources

```csharp
[ApiController]
[Route("api/orders")]
public class OrdersController : ControllerBase
{
    private readonly IOrderService _orderService;
    
    // Create new resource
    [HttpPost]
    public ActionResult<OrderDto> CreateOrder([FromBody] CreateOrderRequest request)
    {
        if (!ModelState.IsValid)
            return BadRequest(ModelState);
        
        var order = _orderService.CreateOrder(request);
        
        // Return 201 with Location header
        return CreatedAtAction(
            nameof(GetOrder),
            new { id = order.Id },
            order);
    }
    
    [HttpGet("{id}")]
    public ActionResult<OrderDto> GetOrder(int id)
    {
        var order = _orderService.GetById(id);
        return order == null ? NotFound() : Ok(order);
    }
    
    // POST for actions/operations (non-resource-creating)
    [HttpPost("{id}/cancel")]
    public ActionResult CancelOrder(int id)
    {
        var result = _orderService.CancelOrder(id);
        
        if (!result.Success)
            return BadRequest(result.Error);
            
        return NoContent();
    }
    
    // POST for search (when query too complex for GET)
    [HttpPost("search")]
    public ActionResult<IEnumerable<OrderDto>> SearchOrders(
        [FromBody] OrderSearchCriteria criteria)
    {
        var orders = _orderService.Search(criteria);
        return Ok(orders);
    }
}

// POST characteristics:
// - NOT safe (modifies state)
// - NOT idempotent (multiple requests = multiple resources)
// - Response can be cached with proper headers
// - Returns 201 Created with Location header for new resources
```

### PUT - Replace Resources

```csharp
[ApiController]
[Route("api/users")]
public class UsersController : ControllerBase
{
    private readonly IUserRepository _repository;
    
    // Replace entire resource
    [HttpPut("{id}")]
    public ActionResult UpdateUser(int id, [FromBody] UserDto user)
    {
        if (id != user.Id)
            return BadRequest("ID mismatch");
            
        if (!ModelState.IsValid)
            return BadRequest(ModelState);
        
        var exists = _repository.Exists(id);
        
        if (!exists)
        {
            // PUT can create if resource doesn't exist
            _repository.Create(user);
            return CreatedAtAction(nameof(GetUser), new { id }, user);
        }
        
        _repository.Update(user);
        return NoContent(); // or Ok(user)
    }
    
    [HttpGet("{id}")]
    public ActionResult<UserDto> GetUser(int id)
    {
        var user = _repository.GetById(id);
        return user == null ? NotFound() : Ok(user);
    }
}

// PUT characteristics:
// - NOT safe (modifies state)
// - IS idempotent (repeated requests have same result)
// - Replaces entire resource
// - Client provides complete resource representation
// - Can create resource if it doesn't exist (optional)

// Example: PUT is idempotent
// First PUT:  PUT /api/users/123 { "name": "John", "email": "john@ex.com" }
// Second PUT: PUT /api/users/123 { "name": "John", "email": "john@ex.com" }
// Result: User 123 has same state after both requests
```

### PATCH - Partial Updates

```csharp
using Microsoft.AspNetCore.JsonPatch;

[ApiController]
[Route("api/products")]
public class ProductsController : ControllerBase
{
    private readonly IProductRepository _repository;
    
    // JSON Patch approach
    [HttpPatch("{id}")]
    public ActionResult PatchProduct(
        int id,
        [FromBody] JsonPatchDocument<ProductDto> patchDoc)
    {
        var product = _repository.GetById(id);
        
        if (product == null)
            return NotFound();
        
        // Apply patch
        patchDoc.ApplyTo(product, ModelState);
        
        if (!ModelState.IsValid)
            return BadRequest(ModelState);
        
        _repository.Update(product);
        return NoContent();
    }
    
    // Simple partial update approach
    [HttpPatch("{id}/price")]
    public ActionResult UpdatePrice(int id, [FromBody] decimal newPrice)
    {
        var product = _repository.GetById(id);
        
        if (product == null)
            return NotFound();
        
        product.Price = newPrice;
        _repository.Update(product);
        
        return NoContent();
    }
}

// Client usage:
// PATCH /api/products/123
// Content-Type: application/json-patch+json
// [
//   { "op": "replace", "path": "/price", "value": 29.99 },
//   { "op": "add", "path": "/tags/-", "value": "featured" }
// ]

// PATCH characteristics:
// - NOT safe (modifies state)
// - MAY be idempotent (depends on patch format)
// - Partially updates resource
// - More efficient than PUT for large resources
```

### DELETE - Remove Resources

```csharp
[ApiController]
[Route("api/posts")]
public class PostsController : ControllerBase
{
    private readonly IPostRepository _repository;
    
    [HttpDelete("{id}")]
    public ActionResult DeletePost(int id)
    {
        var post = _repository.GetById(id);
        
        if (post == null)
            return NotFound(); // or 204 if idempotent behavior preferred
        
        _repository.Delete(id);
        return NoContent(); // 204 No Content
    }
    
    // Soft delete
    [HttpDelete("{id}/soft")]
    public ActionResult SoftDeletePost(int id)
    {
        var post = _repository.GetById(id);
        
        if (post == null)
            return NotFound();
        
        post.IsDeleted = true;
        post.DeletedAt = DateTime.UtcNow;
        _repository.Update(post);
        
        return NoContent();
    }
}

// DELETE characteristics:
// - NOT safe (modifies state)
// - IS idempotent (deleting multiple times = same result)
// - Returns 204 No Content or 200 OK with body
// - Second DELETE returns 204 (not 404) for idempotency

// Idempotent DELETE example:
// DELETE /api/posts/123  → 204 No Content (deleted)
// DELETE /api/posts/123  → 204 No Content (already deleted, same state)
```

### HEAD - Metadata Only

```csharp
[ApiController]
[Route("api/files")]
public class FilesController : ControllerBase
{
    private readonly IFileService _fileService;
    
    // GET and HEAD both supported
    [HttpGet("{id}")]
    [HttpHead("{id}")]
    public ActionResult GetFile(int id)
    {
        var file = _fileService.GetById(id);
        
        if (file == null)
            return NotFound();
        
        Response.Headers.Add("Content-Length", file.Size.ToString());
        Response.Headers.Add("Last-Modified", file.ModifiedAt.ToString("R"));
        Response.Headers.Add("ETag", file.ETag);
        
        // For HEAD, ASP.NET Core automatically omits body
        return File(file.Content, file.ContentType);
    }
}

// Client usage:
// HEAD /api/files/123
// Response: 200 OK (headers only, no body)
// Content-Length: 1048576
// Last-Modified: Mon, 15 Jan 2024 10:30:00 GMT
// ETag: "abc123"

// HEAD characteristics:
// - IS safe
// - IS idempotent
// - Returns same headers as GET, but no body
// - Useful for checking existence, size, or modification time
```

### Idempotency in Practice

```csharp
// Implementing idempotent POST with idempotency key
[HttpPost]
public async Task<ActionResult<OrderDto>> CreateOrder(
    [FromBody] CreateOrderRequest request,
    [FromHeader(Name = "Idempotency-Key")] string? idempotencyKey = null)
{
    if (!string.IsNullOrEmpty(idempotencyKey))
    {
        // Check if request with this key already processed
        var existingOrder = await _cache.GetAsync<OrderDto>($"order:{idempotencyKey}");
        
        if (existingOrder != null)
        {
            // Return cached response
            return CreatedAtAction(nameof(GetOrder), 
                new { id = existingOrder.Id }, 
                existingOrder);
        }
    }
    
    var order = await _orderService.CreateOrder(request);
    
    if (!string.IsNullOrEmpty(idempotencyKey))
    {
        // Cache response for future requests
        await _cache.SetAsync($"order:{idempotencyKey}", order, TimeSpan.FromHours(24));
    }
    
    return CreatedAtAction(nameof(GetOrder), new { id = order.Id }, order);
}

// Client usage:
// POST /api/orders
// Idempotency-Key: a1b2c3d4-e5f6-7890-abcd-ef1234567890
// (can safely retry with same key if network fails)
```

### Long-Running Operations

```csharp
[ApiController]
[Route("api/reports")]
public class ReportsController : ControllerBase
{
    private readonly IReportService _reportService;
    
    // Initiate long-running operation
    [HttpPost]
    public async Task<ActionResult> GenerateReport([FromBody] ReportRequest request)
    {
        // Start async operation
        var operationId = await _reportService.StartReportGeneration(request);
        
        // Return 202 Accepted with status endpoint
        return AcceptedAtAction(
            nameof(GetReportStatus),
            new { id = operationId },
            new { operationId, status = "processing" });
    }
    
    // Check operation status
    [HttpGet("{id}/status")]
    public async Task<ActionResult> GetReportStatus(string id)
    {
        var status = await _reportService.GetOperationStatus(id);
        
        if (status == null)
            return NotFound();
        
        if (status.IsComplete)
        {
            // Operation complete, provide resource location
            Response.Headers.Add("Location", $"/api/reports/{id}/download");
            return Ok(new { status = "completed", downloadUrl = $"/api/reports/{id}/download" });
        }
        
        // Still processing
        return Ok(new { status = "processing", progress = status.Progress });
    }
    
    // Download completed report
    [HttpGet("{id}/download")]
    public async Task<ActionResult> DownloadReport(string id)
    {
        var report = await _reportService.GetReport(id);
        
        if (report == null)
            return NotFound();
        
        return File(report.Content, "application/pdf", $"report-{id}.pdf");
    }
}

// Client flow:
// 1. POST /api/reports → 202 Accepted, Location: /api/reports/abc123/status
// 2. GET /api/reports/abc123/status → 200 OK, { "status": "processing", "progress": 45 }
// 3. GET /api/reports/abc123/status → 200 OK, { "status": "completed", "downloadUrl": "..." }
// 4. GET /api/reports/abc123/download → 200 OK (file content)
```

### Conditional Requests and ETags

```csharp
[ApiController]
[Route("api/documents")]
public class DocumentsController : ControllerBase
{
    // GET with ETag support
    [HttpGet("{id}")]
    public ActionResult<DocumentDto> GetDocument(
        int id,
        [FromHeader(Name = "If-None-Match")] string? ifNoneMatch = null)
    {
        var document = _documentService.GetById(id);
        
        if (document == null)
            return NotFound();
        
        var etag = _etagService.Generate(document);
        
        if (ifNoneMatch == etag)
            return StatusCode(304); // Not Modified
        
        Response.Headers.Add("ETag", etag);
        return Ok(document);
    }
    
    // PUT with optimistic concurrency
    [HttpPut("{id}")]
    public ActionResult UpdateDocument(
        int id,
        [FromBody] DocumentDto document,
        [FromHeader(Name = "If-Match")] string? ifMatch = null)
    {
        var existing = _documentService.GetById(id);
        
        if (existing == null)
            return NotFound();
        
        if (ifMatch != null && ifMatch != _etagService.Generate(existing))
        {
            return StatusCode(412, new { error = "ConcurrentModification" });
        }
        
        _documentService.Update(document);
        Response.Headers.Add("ETag", _etagService.Generate(document));
        
        return NoContent();
    }
}
```

### Bulk Operations with Methods

```csharp
[ApiController]
[Route("api/products")]
public class BulkOperationsController : ControllerBase
{
    // Bulk create
    [HttpPost("bulk")]
    public ActionResult<BulkOperationResult<ProductDto>> BulkCreate(
        [FromBody] List<CreateProductRequest> products)
    {
        var results = new List<ProductDto>();
        var errors = new List<BulkOperationError>();
        
        for (int i = 0; i < products.Count; i++)
        {
            try
            {
                results.Add(_productService.Create(products[i]));
            }
            catch (Exception ex)
            {
                errors.Add(new BulkOperationError { Index = i, Error = ex.Message });
            }
        }
        
        return Ok(new BulkOperationResult<ProductDto>
        {
            Successful = results,
            Failed = errors
        });
    }
    
    // Bulk delete
    [HttpDelete("bulk")]
    public ActionResult BulkDelete([FromBody] List<int> ids)
    {
        foreach (var id in ids)
        {
            try { _productService.Delete(id); }
            catch { /* log error */ }
        }
        
        return NoContent();
    }
}
```

### Safe and Unsafe Methods in Practice

```csharp
// Safe methods: no side effects, cacheable
[ApiController]
[Route("api/products")]
public class SafeMethodsController : ControllerBase
{
    // GET - Safe, idempotent, cacheable
    [HttpGet]
    [ResponseCache(Duration = 60)]
    public ActionResult<List<ProductDto>> GetProducts()
    {
        return Ok(_repository.GetAll());
    }
    
    // HEAD - Safe, idempotent
    [HttpHead("{id}")]
    public ActionResult CheckProductExists(int id)
    {
        return _repository.Exists(id) ? Ok() : NotFound();
    }
}

// Unsafe methods: modify server state
[ApiController]
[Route("api/orders")]
public class UnsafeMethodsController : ControllerBase
{
    // POST - Unsafe, not idempotent
    [HttpPost]
    public ActionResult<OrderDto> CreateOrder([FromBody] CreateOrderRequest request)
    {
        var order = _orderService.Create(request);
        return CreatedAtAction(nameof(GetOrder), new { id = order.Id }, order);
    }
    
    // PUT - Unsafe, but idempotent
    [HttpPut("{id}")]
    public ActionResult UpdateOrder(int id, [FromBody] OrderDto order)
    {
        _orderService.Update(id, order);
        return NoContent();
    }
    
    // DELETE - Unsafe, but idempotent
    [HttpDelete("{id}")]
    public ActionResult DeleteOrder(int id)
    {
        _orderService.Delete(id);
        return NoContent();
    }
}
```

## Self-Check Questions

1. **What's the difference between safe and idempotent methods?**
   - Safe: No side effects (GET, HEAD, OPTIONS)
   - Idempotent: Multiple identical requests have same effect as one (GET, PUT, DELETE, HEAD, OPTIONS)
   - POST is neither safe nor idempotent

2. **When should you use PUT vs PATCH?**
   - PUT: Replace entire resource, client sends complete representation
   - PATCH: Partial update, client sends only changed fields
   - PUT is idempotent, PATCH may or may not be depending on implementation

3. **How can you make POST idempotent?**
   - Use Idempotency-Key header
   - Server caches responses by key
   - Duplicate requests return cached response
   - Key should be client-generated UUID

4. **Why is DELETE considered idempotent?**
   - First DELETE: Resource is deleted → state: resource doesn't exist
   - Second DELETE: Resource already doesn't exist → state: resource doesn't exist
   - Same end state regardless of number of requests

5. **What status code should long-running operations return?**
   - Initial request: 202 Accepted with Location header to status endpoint
   - Status check (processing): 200 OK with progress info
   - Status check (complete): 200 OK with result location or 303 See Other
   - Result download: 200 OK with content

6. **When should you use POST instead of GET for queries?**
   - Query parameters too complex for URL
   - Query contains sensitive data
   - Query body exceeds URL length limits
   - Query needs to be in structured format (JSON)

7. **What's the purpose of the HEAD method?**
   - Get metadata without transferring body
   - Check resource existence
   - Check resource size before download
   - Validate cache freshness
   - Test endpoint availability
