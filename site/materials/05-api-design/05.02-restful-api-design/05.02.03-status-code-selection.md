# Lesson 3: Status Code Selection

## Learning Objectives

By the end of this lesson, you will be able to:
- Choose appropriate HTTP status codes for different scenarios
- Understand 2xx, 3xx, 4xx, and 5xx categories
- Implement proper error responses
- Use status codes to communicate API behavior
- Avoid common status code mistakes

---

## Introduction

HTTP status codes are a critical part of RESTful API design. They tell clients exactly what happened with their request—whether it succeeded, failed due to client error, or failed due to server error. Proper status code selection makes your API predictable and enables clients to handle responses correctly.

## Key Concepts Summary

### Status Code Categories

```
1xx: Informational (rarely used in REST APIs)
2xx: Success
3xx: Redirection
4xx: Client Error
5xx: Server Error

Quick decision tree:
- Did it work? → 2xx
- Did the client mess up? → 4xx
- Did the server mess up? → 5xx
- Has the resource moved? → 3xx
```

### 2xx Success Codes

```csharp
[ApiController]
[Route("api/products")]
public class ProductsController : ControllerBase
{
    // 200 OK - Request succeeded, returning resource
    [HttpGet("{id}")]
    public ActionResult<ProductDto> GetProduct(int id)
    {
        var product = _repository.GetById(id);
        
        if (product == null)
            return NotFound();
        
        return Ok(product); // 200 OK
    }
    
    // 201 Created - Resource successfully created
    [HttpPost]
    public ActionResult<ProductDto> CreateProduct([FromBody] CreateProductRequest request)
    {
        var product = _repository.Create(request);
        
        return CreatedAtAction(
            nameof(GetProduct),
            new { id = product.Id },
            product); // 201 Created with Location header
    }
    
    // 202 Accepted - Request accepted for processing
    [HttpPost("bulk-import")]
    public ActionResult ImportProducts([FromBody] List<ProductDto> products)
    {
        var jobId = _importService.StartImport(products);
        
        return AcceptedAtAction(
            nameof(GetImportStatus),
            new { jobId },
            new { jobId, status = "processing" }); // 202 Accepted
    }
    
    // 204 No Content - Successful, no response body
    [HttpPut("{id}")]
    public ActionResult UpdateProduct(int id, [FromBody] ProductDto product)
    {
        if (!_repository.Exists(id))
            return NotFound();
        
        _repository.Update(product);
        return NoContent(); // 204 No Content
    }
    
    [HttpDelete("{id}")]
    public ActionResult DeleteProduct(int id)
    {
        if (!_repository.Exists(id))
            return NotFound();
        
        _repository.Delete(id);
        return NoContent(); // 204 No Content
    }
}

// When to use each 2xx:
// 200 OK: GET, successful operation with body
// 201 Created: POST, new resource created
// 202 Accepted: Long-running async operation started
// 204 No Content: PUT/DELETE succeeded, no body needed
```

### 3xx Redirection Codes

```csharp
[ApiController]
[Route("api")]
public class RedirectionController : ControllerBase
{
    // 301 Moved Permanently - Resource permanently moved
    [HttpGet("old-endpoint")]
    public ActionResult OldEndpoint()
    {
        return RedirectPermanent("/api/new-endpoint"); // 301
    }
    
    // 302 Found - Temporary redirect
    [HttpGet("temp-redirect")]
    public ActionResult TempRedirect()
    {
        return Redirect("/api/temporary-location"); // 302
    }
    
    // 303 See Other - Redirect to different URI (after POST)
    [HttpPost("orders")]
    public ActionResult CreateOrder([FromBody] OrderDto order)
    {
        var created = _repository.Create(order);
        
        // Redirect to GET endpoint
        return RedirectToAction(nameof(GetOrder), new { id = created.Id }); // 303
    }
    
    // 304 Not Modified - Cached version still valid
    [HttpGet("products/{id}")]
    public ActionResult GetProduct(int id, [FromHeader(Name = "If-None-Match")] string? etag)
    {
        var product = _repository.GetById(id);
        
        if (product == null)
            return NotFound();
        
        var currentETag = _etagService.Generate(product);
        
        if (etag == currentETag)
            return StatusCode(304); // 304 Not Modified
        
        Response.Headers.Add("ETag", currentETag);
        return Ok(product);
    }
}

// When to use 3xx:
// 301: API endpoint permanently moved (old version deprecated)
// 302/307: Temporary redirect
// 303: Redirect after POST to GET endpoint
// 304: Resource not modified (caching)
```

### 4xx Client Error Codes

```csharp
[ApiController]
[Route("api/orders")]
public class OrdersController : ControllerBase
{
    // 400 Bad Request - Invalid request format/syntax
    [HttpPost]
    public ActionResult<OrderDto> CreateOrder([FromBody] CreateOrderRequest request)
    {
        if (!ModelState.IsValid)
            return BadRequest(ModelState); // 400 Bad Request
        
        // Additional validation
        if (request.Items == null || request.Items.Count == 0)
        {
            return BadRequest(new 
            { 
                error = "InvalidRequest",
                message = "Order must contain at least one item"
            });
        }
        
        var order = _orderService.Create(request);
        return CreatedAtAction(nameof(GetOrder), new { id = order.Id }, order);
    }
    
    // 401 Unauthorized - Missing or invalid authentication
    [HttpGet]
    [Authorize]
    public ActionResult<List<OrderDto>> GetOrders()
    {
        // If no auth token or invalid token, middleware returns 401
        var orders = _orderService.GetAll();
        return Ok(orders);
    }
    
    // 403 Forbidden - Authenticated but not authorized
    [HttpDelete("{id}")]
    [Authorize]
    public ActionResult DeleteOrder(int id)
    {
        var order = _orderService.GetById(id);
        
        if (order == null)
            return NotFound();
        
        // Check if user owns this order
        if (order.UserId != User.GetUserId())
            return Forbid(); // 403 Forbidden
        
        _orderService.Delete(id);
        return NoContent();
    }
    
    // 404 Not Found - Resource doesn't exist
    [HttpGet("{id}")]
    public ActionResult<OrderDto> GetOrder(int id)
    {
        var order = _orderService.GetById(id);
        
        if (order == null)
            return NotFound(); // 404 Not Found
        
        return Ok(order);
    }
    
    // 405 Method Not Allowed - HTTP method not supported
    // Automatically handled by ASP.NET Core
    // GET /api/orders/123 → 200 OK
    // PATCH /api/orders/123 → 405 Method Not Allowed (if no [HttpPatch])
    
    // 409 Conflict - Request conflicts with current state
    [HttpPost("{id}/confirm")]
    public ActionResult ConfirmOrder(int id)
    {
        var order = _orderService.GetById(id);
        
        if (order == null)
            return NotFound();
        
        if (order.Status != OrderStatus.Pending)
        {
            return Conflict(new 
            { 
                error = "InvalidOrderState",
                message = $"Cannot confirm order in '{order.Status}' status",
                currentStatus = order.Status
            }); // 409 Conflict
        }
        
        _orderService.Confirm(id);
        return Ok();
    }
    
    // 422 Unprocessable Entity - Semantic validation failed
    [HttpPost]
    public ActionResult<OrderDto> CreateOrderDetailed([FromBody] CreateOrderRequest request)
    {
        if (!ModelState.IsValid)
            return BadRequest(ModelState); // 400 - Syntax error
        
        // Semantic validation
        var validationResult = _orderValidator.Validate(request);
        
        if (!validationResult.IsValid)
        {
            return UnprocessableEntity(new 
            {
                error = "ValidationFailed",
                message = "Order validation failed",
                errors = validationResult.Errors
            }); // 422 Unprocessable Entity
        }
        
        var order = _orderService.Create(request);
        return CreatedAtAction(nameof(GetOrder), new { id = order.Id }, order);
    }
    
    // 429 Too Many Requests - Rate limit exceeded
    [HttpGet]
    [RateLimit(MaxRequests = 100, TimeWindow = "1m")]
    public ActionResult<List<OrderDto>> GetOrdersRateLimited()
    {
        // Rate limiting middleware returns 429 if limit exceeded
        var orders = _orderService.GetAll();
        return Ok(orders);
    }
}

// When to use 4xx:
// 400: Malformed request, invalid JSON, syntax errors
// 401: Missing or invalid authentication token
// 403: Authenticated but lacks permission
// 404: Resource not found
// 405: HTTP method not allowed for this endpoint
// 409: Request conflicts with resource state
// 422: Valid syntax but semantic validation failed
// 429: Rate limit exceeded
```

### 5xx Server Error Codes

```csharp
[ApiController]
[Route("api/products")]
public class ProductsController : ControllerBase
{
    // 500 Internal Server Error - Generic server error
    [HttpGet("{id}")]
    public ActionResult<ProductDto> GetProduct(int id)
    {
        try
        {
            var product = _repository.GetById(id);
            
            if (product == null)
                return NotFound();
            
            return Ok(product);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Error retrieving product {ProductId}", id);
            
            return StatusCode(500, new 
            {
                error = "InternalError",
                message = "An unexpected error occurred"
                // Don't expose stack trace or internal details!
            });
        }
    }
    
    // 502 Bad Gateway - Upstream service error
    [HttpGet("{id}/availability")]
    public async Task<ActionResult> GetProductAvailability(int id)
    {
        try
        {
            var availability = await _inventoryService.CheckAvailability(id);
            return Ok(availability);
        }
        catch (HttpRequestException ex)
        {
            _logger.LogError(ex, "Inventory service unavailable");
            
            return StatusCode(502, new 
            {
                error = "UpstreamServiceError",
                message = "Inventory service is currently unavailable"
            });
        }
    }
    
    // 503 Service Unavailable - Service temporarily down
    [HttpGet]
    public ActionResult<List<ProductDto>> GetProducts()
    {
        if (!_healthCheck.IsHealthy())
        {
            Response.Headers.Add("Retry-After", "60"); // Retry after 60 seconds
            
            return StatusCode(503, new 
            {
                error = "ServiceUnavailable",
                message = "Service is temporarily unavailable",
                retryAfter = 60
            });
        }
        
        var products = _repository.GetAll();
        return Ok(products);
    }
    
    // 504 Gateway Timeout - Upstream service timeout
    [HttpGet("{id}/details")]
    public async Task<ActionResult> GetProductDetails(int id)
    {
        using var cts = new CancellationTokenSource(TimeSpan.FromSeconds(5));
        
        try
        {
            var details = await _externalService.GetDetails(id, cts.Token);
            return Ok(details);
        }
        catch (OperationCanceledException)
        {
            return StatusCode(504, new 
            {
                error = "GatewayTimeout",
                message = "External service did not respond in time"
            });
        }
    }
}

// Global exception handler
public class GlobalExceptionHandler : IExceptionHandler
{
    public async ValueTask<bool> TryHandleAsync(
        HttpContext httpContext,
        Exception exception,
        CancellationToken cancellationToken)
    {
        var response = exception switch
        {
            NotFoundException => (StatusCodes.Status404NotFound, "Resource not found"),
            ValidationException => (StatusCodes.Status422UnprocessableEntity, "Validation failed"),
            UnauthorizedException => (StatusCodes.Status401Unauthorized, "Unauthorized"),
            _ => (StatusCodes.Status500InternalServerError, "An error occurred")
        };
        
        httpContext.Response.StatusCode = response.Item1;
        
        await httpContext.Response.WriteAsJsonAsync(new 
        {
            error = exception.GetType().Name,
            message = response.Item2,
            // Don't include exception details in production!
        }, cancellationToken);
        
        return true;
    }
}

// When to use 5xx:
// 500: Generic server error, unexpected exceptions
// 502: Upstream service returned error
// 503: Service temporarily unavailable (maintenance, overload)
// 504: Upstream service timeout
```

### Error Response Structure

```csharp
// Consistent error response model
public class ApiError
{
    public string Error { get; set; }        // Error code/type
    public string Message { get; set; }       // Human-readable message
    public Dictionary<string, string[]>? Errors { get; set; }  // Field-level errors
    public string? TraceId { get; set; }      // For support/debugging
    public DateTime Timestamp { get; set; }    // When error occurred
}

[ApiController]
public class BaseApiController : ControllerBase
{
    protected ActionResult Error(
        int statusCode,
        string errorCode,
        string message,
        Dictionary<string, string[]>? errors = null)
    {
        var error = new ApiError
        {
            Error = errorCode,
            Message = message,
            Errors = errors,
            TraceId = Activity.Current?.Id ?? HttpContext.TraceIdentifier,
            Timestamp = DateTime.UtcNow
        };
        
        return StatusCode(statusCode, error);
    }
}

[Route("api/users")]
public class UsersController : BaseApiController
{
    [HttpPost]
    public ActionResult<UserDto> CreateUser([FromBody] CreateUserRequest request)
    {
        if (!ModelState.IsValid)
        {
            var errors = ModelState
                .Where(x => x.Value?.Errors.Count > 0)
                .ToDictionary(
                    x => x.Key,
                    x => x.Value!.Errors.Select(e => e.ErrorMessage).ToArray());
            
            return Error(400, "ValidationError", "Request validation failed", errors);
        }
        
        if (_userService.EmailExists(request.Email))
        {
            return Error(409, "DuplicateEmail", "A user with this email already exists");
        }
        
        var user = _userService.Create(request);
        return CreatedAtAction(nameof(GetUser), new { id = user.Id }, user);
    }
}
```

### Status Code Decision Tree

```
Request received
    ↓
Is request authenticated? → NO → 401 Unauthorized
    ↓ YES
Is user authorized? → NO → 403 Forbidden
    ↓ YES
Does resource exist? → NO → 404 Not Found
    ↓ YES
Is request syntax valid? → NO → 400 Bad Request
    ↓ YES
Does request pass validation? → NO → 422 Unprocessable Entity
    ↓ YES
Does request conflict with state? → NO → Continue
    ↓ YES                                     ↓
    409 Conflict                    Try processing request
                                              ↓
                                    Did server error occur? → YES → 500/502/503/504
                                              ↓ NO
                                    Is response successful?
                                              ↓ YES
    200 OK (with body)
    201 Created (POST, new resource)
    202 Accepted (async operation)
    204 No Content (PUT/DELETE, no body)
```

### Status Codes for Specific Scenarios

```csharp
// Scenario-based status code selection

[ApiController]
[Route("api/scenarios")]
public class StatusCodeScenariosController : ControllerBase
{
    // Scenario: Resource created successfully
    [HttpPost("orders")]
    public ActionResult CreateOrder([FromBody] CreateOrderRequest request)
    {
        var order = _orderService.Create(request);
        
        // 201 Created with Location header pointing to new resource
        return CreatedAtAction(
            nameof(GetOrder),
            new { id = order.Id },
            order);
    }
    
    // Scenario: Resource updated, return updated resource
    [HttpPut("products/{id}")]
    public ActionResult<ProductDto> UpdateProductWithBody(int id, [FromBody] ProductDto product)
    {
        if (!_productService.Exists(id))
            return NotFound();
        
        var updated = _productService.Update(id, product);
        
        // 200 OK with updated resource in body
        return Ok(updated);
    }
    
    // Scenario: Resource updated, no content to return
    [HttpPut("settings/{id}")]
    public ActionResult UpdateSettings(int id, [FromBody] SettingsDto settings)
    {
        if (!_settingsService.Exists(id))
            return NotFound();
        
        _settingsService.Update(id, settings);
        
        // 204 No Content (successful, nothing to return)
        return NoContent();
    }
    
    // Scenario: Async operation started
    [HttpPost("exports")]
    public async Task<ActionResult> StartExport([FromBody] ExportRequest request)
    {
        var jobId = await _exportService.StartExport(request);
        
        // 202 Accepted with status endpoint
        return AcceptedAtAction(
            nameof(GetExportStatus),
            new { jobId },
            new { jobId, status = "processing" });
    }
    
    // Scenario: Multiple resources found
    [HttpGet("search")]
    public ActionResult<SearchResults> Search([FromQuery] string q)
    {
        var results = _searchService.Search(q);
        
        // 200 OK even if no results
        // Empty array is a valid response
        return Ok(results);
    }
    
    // Scenario: Resource moved permanently
    [HttpGet("old-api/products/{id}")]
    public ActionResult OldProductEndpoint(int id)
    {
        // 301 Moved Permanently
        return RedirectPermanent($"/api/v2/products/{id}");
    }
    
    // Scenario: Resource not modified (caching)
    [HttpGet("products/{id}")]
    public ActionResult<ProductDto> GetProductWithCache(
        int id,
        [FromHeader(Name = "If-None-Match")] string? etag)
    {
        var product = _productService.GetById(id);
        
        if (product == null)
            return NotFound();
        
        var currentETag = _etagService.Generate(product);
        
        if (etag == currentETag)
            return StatusCode(304); // Not Modified
        
        Response.Headers.Add("ETag", currentETag);
        return Ok(product);
    }
    
    // Scenario: Partial success (multi-status)
    [HttpPost("bulk-update")]
    public ActionResult BulkUpdate([FromBody] List<UpdateRequest> updates)
    {
        var results = _bulkService.ProcessUpdates(updates);
        
        // If some succeeded and some failed, return 207 Multi-Status
        if (results.Any(r => r.Failed) && results.Any(r => r.Succeeded))
        {
            return StatusCode(207, results); // Multi-Status
        }
        
        // If all succeeded
        if (results.All(r => r.Succeeded))
            return Ok(results);
        
        // If all failed
        return BadRequest(results);
    }
    
    // Scenario: Payment required
    [HttpGet("premium/content/{id}")]
    public ActionResult GetPremiumContent(int id)
    {
        var user = _userService.GetCurrentUser();
        
        if (!user.HasSubscription)
        {
            // 402 Payment Required (rarely used, but appropriate here)
            return StatusCode(402, new
            {
                error = "PaymentRequired",
                message = "This content requires an active subscription",
                upgradeUrl = "/api/subscriptions"
            });
        }
        
        var content = _contentService.GetById(id);
        return Ok(content);
    }
    
    // Scenario: Resource gone (permanently deleted)
    [HttpGet("deleted-posts/{id}")]
    public ActionResult GetDeletedPost(int id)
    {
        var post = _postService.GetDeletedPost(id);
        
        if (post != null && post.IsDeleted)
        {
            // 410 Gone - resource used to exist but is permanently deleted
            return StatusCode(410, new
            {
                error = "ResourceGone",
                message = "This post was permanently deleted",
                deletedAt = post.DeletedAt
            });
        }
        
        // Never existed
        return NotFound();
    }
}
```

```csharp
// RFC 7807 Problem Details for HTTP APIs

using Microsoft.AspNetCore.Mvc;

// Problem Details model
public class ProblemDetailsError : ProblemDetails
{
    public string TraceId { get; set; }
    public Dictionary<string, object>? Extensions { get; set; }

[ApiController]
public class ProblemDetailsController : ControllerBase
{
    // Using Problem Details format
    [HttpPost("api/orders")]
    public ActionResult<OrderDto> CreateOrder([FromBody] CreateOrderRequest request)
    {
        // Validation failure
        if (!ModelState.IsValid)
        {
            return ValidationProblem(ModelState);
            // Returns:
            // {
            //   "type": "https://tools.ietf.org/html/rfc7231#section-6.5.1",
            //   "title": "One or more validation errors occurred.",
            //   "status": 400,
            //   "errors": {
            //     "customerId": ["The customerId field is required."]
            //   },
            //   "traceId": "00-abc123..."
            // }
        }
        
        // Business logic error
        if (!_customerService.Exists(request.CustomerId))
        {
            return Problem(
                statusCode: 404,
                title: "Customer not found",
                detail: $"Customer with ID {request.CustomerId} does not exist",
                type: "https://api.example.com/errors/customer-not-found"
            );
        }
        
        // Conflict
        if (_orderService.HasPendingOrder(request.CustomerId))
        {
            return Problem(
                statusCode: 409,
                title: "Pending order exists",
                detail: "Customer already has a pending order. Complete or cancel it first.",
                type: "https://api.example.com/errors/pending-order-exists"
            );
        }
        
        var order = _orderService.Create(request);
        return CreatedAtAction(nameof(GetOrder), new { id = order.Id }, order);
    }
}
```

## Practice Exercise

Design status code responses for these scenarios:

1. **User tries to access another user's private data**
   - Status: 403 Forbidden (authenticated but not authorized)
   - Body: `{ "error": "FORBIDDEN", "message": "You don't have permission to access this resource" }`

2. **Credit card validation fails**
   - Status: 422 Unprocessable Entity (valid format, but semantic validation failed)
   - Body: `{ "error": "INVALID_CARD", "message": "Credit card validation failed", "details": "Card number is invalid" }`

3. **Product is out of stock when trying to order**
   - Status: 409 Conflict (request conflicts with current state)
   - Body: `{ "error": "OUT_OF_STOCK", "message": "Product is currently out of stock", "availableQuantity": 0 }`

4. **Database connection fails**
   - Status: 503 Service Unavailable (temporary failure)
   - Headers: `Retry-After: 60`
   - Body: `{ "error": "SERVICE_UNAVAILABLE", "message": "Service temporarily unavailable" }`

5. **File upload succeeds**
   - Status: 201 Created
   - Headers: `Location: /api/files/abc123`
   - Body: `{ "id": "abc123", "name": "document.pdf", "size": 1024 }`

6. **Resource was deleted by another request**
   - First DELETE: 204 No Content
   - Second DELETE: 204 No Content (idempotent, same end state)
   - Or: 410 Gone if you want to explicitly signal permanent deletion

7. **Search returns no results**
   - Status: 200 OK (successful search, empty results is valid)
   - Body: `{ "results": [], "total": 0 }`
   - NOT 404 - the search endpoint exists and worked correctly

8. **API rate limit exceeded**
   - Status: 429 Too Many Requests
   - Headers: `Retry-After: 3600`, `X-RateLimit-Limit: 1000`, `X-RateLimit-Remaining: 0`, `X-RateLimit-Reset: 1704124800`
   - Body: `{ "error": "RATE_LIMIT_EXCEEDED", "message": "API rate limit exceeded", "retryAfter": 3600 }`

**Additional scenarios to consider:**

9. **Concurrent modification detected (optimistic locking)**
   - Status: 412 Precondition Failed
   - Body: `{ "error": "PRECONDITION_FAILED", "message": "Resource was modified", "currentETag": "xyz789" }`

10. **Invalid JSON in request body**
    - Status: 400 Bad Request
    - Body: `{ "error": "INVALID_JSON", "message": "Request body contains invalid JSON" }`

11. **Required header missing**
    - Status: 400 Bad Request
    - Body: `{ "error": "MISSING_HEADER", "message": "Required header 'X-API-Key' is missing" }`

    - Status: 504 Gateway Timeout
    - Body: `{ "error": "GATEWAY_TIMEOUT", "message": "Upstream service did not respond in time" }`

## Self-Check Questions

1. **What's the difference between 400 and 422?**
   - 400: Malformed request, syntax error (e.g., invalid JSON, missing required field)
   - 422: Valid syntax but semantic validation failed (e.g., business rule violation, invalid enum value)
   - 400 = "I can't understand your request"
   - 422 = "I understand your request, but it doesn't make sense in this context"

2. **When should you use 404 vs 410?**
   - 404: Resource not found (may never have existed or may come back)
   - 410: Resource permanently gone (used to exist but is intentionally removed)
   - 410 is stronger signal: "Don't bother checking again"

3. **What's the difference between 401 and 403?**
   - 401: Unauthenticated - missing or invalid credentials, user unknown
   - 403: Forbidden - authenticated but lacking permission, user known but denied
   - 401 = "Who are you?" → Include authentication challenge
   - 403 = "I know who you are, but you can't do this" → No authentication challenge

4. **Should DELETE return 404 if resource doesn't exist?**
   - Debatable. Two approaches:
   - **Idempotent approach**: Return 204 (same end state: resource doesn't exist)
   - **Strict approach**: Return 404 (resource not found)
   - Idempotent approach is more common and aligns with REST principles

5. **When should you use 202 instead of 201?**
   - 201: Resource created immediately, available now
   - 202: Request accepted, resource creation is asynchronous
   - 202 is used for long-running operations where result isn't immediately available
   - Include Location header pointing to status endpoint

6. **What status code for temporarily unavailable service?**
   - 503 Service Unavailable
   - Include Retry-After header (seconds or HTTP date)
   - Used for maintenance, overload, or temporary outages
   - Clients should retry after specified time

7. **What about 418 I'm a teapot?**
   - April Fools' joke from 1998 (RFC 2324)
   - Not for production use
   - Shows HTTP can be fun, but stick to standard codes for real APIs
