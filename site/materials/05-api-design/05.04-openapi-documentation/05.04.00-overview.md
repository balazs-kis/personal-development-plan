# Chapter 5.4: OpenAPI and API Documentation

## Overview
This chapter teaches you how to create comprehensive API documentation using the OpenAPI specification (formerly Swagger). You'll learn to generate OpenAPI specifications from code, create interactive documentation, generate client SDKs, and adopt an API-first design workflow where the specification drives development.

## Key Concepts
- **OpenAPI 3.x Specification:** industry-standard format for describing REST APIs.
- **Generating OpenAPI from Code:** automatic spec generation from .NET controllers.
- **Interactive Documentation (Swagger UI):** browser-based API exploration and testing.
- **Client Code Generation:** automated SDK creation from OpenAPI specs.
- **API Design-First Workflow:** defining the contract before implementation.
