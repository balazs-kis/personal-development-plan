## Introduction

Kubernetes provides built-in DNS for service discovery, allowing pods to find services by name rather than IP address. CoreDNS automatically creates DNS records for Services and Pods, enabling seamless communication across the cluster. Understanding DNS is essential for debugging connectivity and implementing service mesh patterns.

## Key Concepts Summary

### DNS Names for Services

**Format:**
```
<service-name>.<namespace>.svc.<cluster-domain>
```

**Default cluster domain:** `cluster.local`

**Examples:**
```bash
# ClusterIP Service
web.default.svc.cluster.local → 10.96.10.20

# Same namespace (short form)
web → 10.96.10.20

# Different namespace
web.production → 10.96.10.20

# Fully qualified
web.production.svc.cluster.local → 10.96.10.20
```

### DNS for Headless Services

**Headless service (clusterIP: None):**
```yaml
apiVersion: v1
kind: Service
metadata:
  name: mysql
spec:
  clusterIP: None
  selector:
    app: mysql
  ports:
  - port: 3306
```

**DNS returns pod IPs directly:**
```bash
nslookup mysql.default.svc.cluster.local

# Returns multiple A records:
# mysql.default.svc.cluster.local    10.244.1.5
# mysql.default.svc.cluster.local    10.244.2.8
# mysql.default.svc.cluster.local    10.244.3.12
```

**StatefulSet pod DNS:**
```
<pod-name>.<service-name>.<namespace>.svc.<cluster-domain>

Examples:
mysql-0.mysql.default.svc.cluster.local
mysql-1.mysql.default.svc.cluster.local
mysql-2.mysql.default.svc.cluster.local
```

### DNS for Pods

**Pod DNS format:**
```
<pod-ip-with-dashes>.<namespace>.pod.<cluster-domain>

Example:
10-244-1-5.default.pod.cluster.local → 10.244.1.5
```

**Custom pod hostname:**
```yaml
apiVersion: v1
kind: Pod
metadata:
  name: web
spec:
  hostname: web-server
  subdomain: my-service
  containers:
  - name: nginx
    image: nginx
```

**Resulting DNS:**
```
web-server.my-service.default.svc.cluster.local
```

### CoreDNS

**Check CoreDNS:**
```bash
kubectl get pods -n kube-system -l k8s-app=kube-dns
kubectl logs -n kube-system <coredns-pod>
```

**CoreDNS ConfigMap:**
```bash
kubectl get configmap coredns -n kube-system -o yaml
```

**Default Corefile:**
```
.:53 {
    errors
    health {
       lameduck 5s
    }
    ready
    kubernetes cluster.local in-addr.arpa ip6.arpa {
       pods insecure
       fallthrough in-addr.arpa ip6.arpa
       ttl 30
    }
    prometheus :9153
    forward . /etc/resolv.conf {
       max_concurrent 1000
    }
    cache 30
    loop
    reload
    loadbalance
}
```

### DNS Resolution from Pods

**Pod DNS config:**
```bash
kubectl exec -it <pod-name> -- cat /etc/resolv.conf

# Output:
# nameserver 10.96.0.10
# search default.svc.cluster.local svc.cluster.local cluster.local
# options ndots:5
```

**Search domains:**
- `default.svc.cluster.local` (pod's namespace)
- `svc.cluster.local`
- `cluster.local`

**Resolution order:**
```
Query: web

1. web.default.svc.cluster.local
2. web.svc.cluster.local
3. web.cluster.local
4. web (external DNS)
```

### DNS Policy

**dnsPolicy options:**

**ClusterFirst (default):**
```yaml
spec:
  dnsPolicy: ClusterFirst
```
Uses cluster DNS, falls back to node's DNS.

**Default:**
```yaml
spec:
  dnsPolicy: Default
```
Uses node's DNS configuration.

**ClusterFirstWithHostNet:**
```yaml
spec:
  hostNetwork: true
  dnsPolicy: ClusterFirstWithHostNet
```
For pods using host network, still use cluster DNS.

**None (custom):**
```yaml
spec:
  dnsPolicy: None
  dnsConfig:
    nameservers:
    - 1.1.1.1
    - 8.8.8.8
    searches:
    - my-custom.example.com
    options:
    - name: ndots
      value: "2"
```

### Custom DNS Configuration

**Add custom nameservers:**
```yaml
apiVersion: v1
kind: Pod
metadata:
  name: custom-dns
spec:
  containers:
  - name: app
    image: myapp:latest
  dnsPolicy: ClusterFirst
  dnsConfig:
    nameservers:
    - 1.1.1.1
    searches:
    - example.com
    options:
    - name: ndots
      value: "2"
    - name: timeout
      value: "5"
```

### SRV Records for Named Ports

**Service with named port:**
```yaml
apiVersion: v1
kind: Service
metadata:
  name: web
spec:
  ports:
  - name: http
    port: 80
    targetPort: 8080
  selector:
    app: web
```

**SRV record:**
```bash
dig SRV _http._tcp.web.default.svc.cluster.local

# Returns:
# _http._tcp.web.default.svc.cluster.local. 30 IN SRV 0 100 80 web.default.svc.cluster.local.
```

### External Services with DNS

**ExternalName Service:**
```yaml
apiVersion: v1
kind: Service
metadata:
  name: external-db
spec:
  type: ExternalName
  externalName: db.example.com
```

**DNS resolution:**
```bash
nslookup external-db.default.svc.cluster.local

# Returns CNAME:
# external-db.default.svc.cluster.local → db.example.com
```


**Check CoreDNS:**
```bash

# Check CoreDNS logs
kubectl logs -n kube-system -l k8s-app=kube-dns

```

**Common issues:**

**DNS not resolving:**
```bash
# Check CoreDNS running
kubectl get pods -n kube-system -l k8s-app=kube-dns

```

**Slow DNS resolution:**
```bash
# Check ndots value
kubectl exec <pod> -- cat /etc/resolv.conf | grep ndots

# Lower ndots if needed
dnsConfig:
  options:
  - name: ndots
    value: "1"
```

### DNS Performance Optimization

**Reduce DNS queries:**
```yaml
dnsConfig:
  options:
  - name: ndots
    value: "1"  # Fewer search domain attempts
```

**Use NodeLocal DNSCache:**
```bash
kubectl apply -f https://k8s.io/examples/admin/dns/nodelocaldns.yaml
```

Caches DNS on each node for better performance.

### DNS Search Path Behavior

**Understanding ndots:**
```bash
# /etc/resolv.conf
options ndots:5

# Query: "api"
# Tries in order:
1. api.default.svc.cluster.local
2. api.svc.cluster.local
3. api.cluster.local
4. api (external)

# Query: "google.com"
# Has 1 dot (< 5), tries search domains first:
1. google.com.default.svc.cluster.local
2. google.com.svc.cluster.local
3. google.com.cluster.local
4. google.com (works)

# Query: "google.com."
# Trailing dot = absolute, skips search:
1. google.com (direct)
```

**Performance implications:**
```
ndots:5 (default)
- Short names: Fast (local)
- FQDNs without dot: 4 failed queries first!
- FQDNs with dot: Immediate

Optimization:
- Use trailing dot for external: "google.com."
- Or lower ndots to 2
```

### DNS Caching Strategies

**Pod-level caching:**
```yaml
# Application-level DNS cache
# In your app configuration
dnsConfig:
  options:
  - name: timeout
    value: "2"
  - name: attempts
    value: "2"
```

**NodeLocal DNSCache:**
```bash
# Deploy node-local DNS cache
kubectl apply -f https://k8s.io/examples/admin/dns/nodelocaldns.yaml

# Benefits:
- Reduces CoreDNS load
- Faster DNS resolution
- Better reliability
- Lower network usage
```

**Verify NodeLocal DNSCache:**
```bash
kubectl get daemonset -n kube-system node-local-dns

# Check pod DNS points to local cache
kubectl exec <pod> -- cat /etc/resolv.conf
# Should see: nameserver 169.254.20.10
```

### Advanced DNS Configurations

**Custom domains for services:**
```yaml
apiVersion: v1
kind: Service
metadata:
  name: api
  annotations:
    external-dns.alpha.kubernetes.io/hostname: api.example.com
spec:
  type: LoadBalancer
  ports:
  - port: 80
```

**Multiple DNS resolvers:**
```yaml
apiVersion: v1
kind: Pod
metadata:
  name: custom-dns-pod
spec:
  dnsPolicy: None
  dnsConfig:
    nameservers:
    - 169.254.20.10  # NodeLocal DNS
    - 10.96.0.10     # CoreDNS fallback
    - 8.8.8.8        # External fallback
    searches:
    - default.svc.cluster.local
    - svc.cluster.local
    - cluster.local
    - example.com
    options:
    - name: ndots
      value: "2"
    - name: timeout
      value: "5"
    - name: attempts
      value: "3"
  containers:
  - name: app
    image: myapp:latest
```

### DNS for Multi-Cluster Setups

**Cross-cluster service discovery:**
```yaml
# Cluster A exports service
apiVersion: v1
kind: Service
metadata:
  name: database
  annotations:
    multicluster.kubernetes.io/export: "true"
spec:
  type: ClusterIP
  ports:
  - port: 5432

---
# Cluster B imports service
apiVersion: v1
kind: Service
metadata:
  name: remote-database
spec:
  type: ExternalName
  externalName: database.cluster-a.svc.clusterset.local
```

**DNS federation patterns:**
```
Single cluster:
service.namespace.svc.cluster.local

Federated:
service.namespace.svc.cluster-name.federation.local

Multi-cluster mesh:
service.namespace.cluster-name.global
```

### DNS Security Considerations

**Prevent DNS spoofing:**
```yaml
# CoreDNS with DNSSEC
apiVersion: v1
kind: ConfigMap
metadata:
  name: coredns
  namespace: kube-system
data:
  Corefile: |
    .:53 {
        errors
        health
        kubernetes cluster.local {
            pods insecure
        }
        dnssec
        forward . /etc/resolv.conf
        cache 30
    }
```

**Restrict DNS queries:**
```yaml
# Network Policy to allow only DNS
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: allow-dns-only
spec:
  podSelector:
    matchLabels:
      app: restricted-app
  policyTypes:
  - Egress
  egress:
  - to:
    - namespaceSelector:
        matchLabels:
          name: kube-system
    - podSelector:
        matchLabels:
          k8s-app: kube-dns
    ports:
    - protocol: UDP
      port: 53
```

### Best Practices

**1. Use short names in same namespace:**
```bash
# Good
curl http://api

# Unnecessary
curl http://api.default.svc.cluster.local
```

**2. Use namespace-qualified for cross-namespace:**
```bash
curl http://api.production
```

**3. Use trailing dot for external domains:**
```bash
# Avoids search path lookups
curl http://google.com.
curl http://api.example.com.
```

**4. Optimize ndots for external-heavy apps:**
```yaml
dnsConfig:
  options:
  - name: ndots
    value: "2"  # Faster external resolution
```

**5. Monitor CoreDNS:**
```bash
kubectl top pods -n kube-system -l k8s-app=kube-dns

# Watch for:
# - High CPU
# - High memory
# - Restart loops
```

**6. Use NodeLocal DNSCache:**
```bash
# Improves performance and reliability
kubectl apply -f https://k8s.io/examples/admin/dns/nodelocaldns.yaml
```

**7. Use headless services for StatefulSets:**
```yaml
spec:
  clusterIP: None  # Direct pod DNS
```

**8. Set appropriate DNS timeouts:**
```yaml
dnsConfig:
  options:
  - name: timeout
    value: "2"  # Fail faster
  - name: attempts
    value: "2"  # Don't retry too much
```

**9. Use ExternalName for external services:**
```yaml
# Better than hardcoding IPs/domains in code
spec:
  type: ExternalName
  externalName: external-api.example.com
```

**10. Implement DNS-based health checks:**
```yaml
livenessProbe:
  exec:
    command:
    - sh
    - -c
    - nslookup kubernetes.default.svc.cluster.local
  initialDelaySeconds: 30
  periodSeconds: 10
```
