# Chapter 6.3: Containerizing .NET Applications

## Overview
This chapter focuses on .NET-specific containerization practices. You'll learn how to choose the right base images, optimize builds for .NET applications, manage configuration properly, implement health checks, and debug containerized .NET apps effectively.

## Key Concepts
- **.NET Base Images:** understanding SDK vs runtime images, choosing between Alpine and Debian variants.
- **Multi-Stage Builds:** optimizing .NET container builds to separate build-time and runtime dependencies.
- **Configuration Management:** handling appsettings.json, environment variables, user secrets, and Azure Key Vault.
- **Health Check Endpoints:** implementing ASP.NET Core health checks for container orchestration.
- **Debugging Containers:** techniques for debugging .NET applications running in containers.
