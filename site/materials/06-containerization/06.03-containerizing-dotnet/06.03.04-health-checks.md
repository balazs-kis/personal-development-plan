## Introduction

Health checks are essential for container orchestration. They allow platforms like Docker, Kubernetes, and Azure Container Apps to monitor your application's health and automatically restart unhealthy containers. This lesson covers implementing robust health checks in .NET applications.

## Key Concepts Summary

### Why Health Checks Matter

**Without health checks:**
```
Application crashes → Container keeps running → 
Traffic sent to broken container → Users see errors
```

**With health checks:**
```
Application unhealthy → Container orchestrator detects →
Container restarted automatically → Traffic rerouted →
Users experience minimal downtime
```

### Types of Health Checks

1. **Liveness Probe** - Is the application running?
   - Checks if the app needs to be restarted
   - Failure → Container restart

2. **Readiness Probe** - Can the application accept traffic?
   - Checks if the app is ready to handle requests
   - Failure → Remove from load balancer

3. **Startup Probe** - Has the application finished starting?
   - Gives slow-starting apps time to initialize
   - Failure → Container restart (after retries)

### Basic Health Check Implementation

**Install package:**
```bash
dotnet add package Microsoft.Extensions.Diagnostics.HealthChecks
```

**Program.cs:**
```csharp
var builder = WebApplication.CreateBuilder(args);

// Add health checks
builder.Services.AddHealthChecks();

var app = builder.Build();

// Map health check endpoint
app.MapHealthChecks("/health");

app.Run();
```

**Test:**
```bash
curl http://localhost:5000/health
# Response: Healthy
```

### Docker HEALTHCHECK Instruction

**Dockerfile:**
```dockerfile
FROM mcr.microsoft.com/dotnet/aspnet:8.0

WORKDIR /app
COPY --from=build /app/publish .

# Add health check
HEALTHCHECK --interval=30s \
            --timeout=3s \
            --start-period=10s \
            --retries=3 \
  CMD curl -f http://localhost:8080/health || exit 1

EXPOSE 8080
ENTRYPOINT ["dotnet", "MyApp.dll"]
```

**Parameters:**
- `--interval`: How often to check (default: 30s)
- `--timeout`: How long to wait for response (default: 30s)
- `--start-period`: Grace period for startup (default: 0s)
- `--retries`: Consecutive failures before unhealthy (default: 3)

**Check container health:**
```bash
docker ps
# Shows health status: starting, healthy, or unhealthy

docker inspect --format='{{.State.Health.Status}}' mycontainer
```

### Separate Liveness and Readiness Endpoints

**Program.cs:**
```csharp
// Liveness - just checks if app is running
app.MapHealthChecks("/health/live", new HealthCheckOptions
{
    Predicate = check => check.Tags.Contains("live")
});

// Readiness - checks dependencies
app.MapHealthChecks("/health/ready", new HealthCheckOptions
{
    Predicate = check => check.Tags.Contains("ready")
});
```

**Health check registration:**
```csharp
builder.Services.AddHealthChecks()
    // Liveness - always healthy if app is running
    .AddCheck("self", () => HealthCheckResult.Healthy(), tags: new[] { "live" })
    
    // Readiness - check dependencies
    .AddSqlServer(connectionString, tags: new[] { "ready" })
    .AddRedis(redisConnection, tags: new[] { "ready" });
```

### Custom Health Check

```csharp
public class CustomHealthCheck : IHealthCheck
{
    private readonly ILogger<CustomHealthCheck> _logger;
    private readonly IMyService _myService;

    public CustomHealthCheck(
        ILogger<CustomHealthCheck> logger,
        IMyService myService)
    {
        _logger = logger;
        _myService = myService;
    }

    public async Task<HealthCheckResult> CheckHealthAsync(
        HealthCheckContext context,
        CancellationToken cancellationToken = default)
    {
        try
        {
            var isHealthy = await _myService.CheckHealthAsync(cancellationToken);
            
            if (isHealthy)
            {
                return HealthCheckResult.Healthy("Service is healthy");
            }
            
            return HealthCheckResult.Degraded("Service is degraded");
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Health check failed");
            return HealthCheckResult.Unhealthy(
                "Service is unhealthy",
                exception: ex);
        }
    }
}

// Register
builder.Services.AddHealthChecks()
    .AddCheck<CustomHealthCheck>(
        "custom-check",
        tags: new[] { "ready" });
```

### Health Check Response Details

**Detailed response:**
```csharp
app.MapHealthChecks("/health", new HealthCheckOptions
{
    ResponseWriter = async (context, report) =>
    {
        context.Response.ContentType = "application/json";
        
        var result = JsonSerializer.Serialize(new
        {
            status = report.Status.ToString(),
            checks = report.Entries.Select(e => new
            {
                name = e.Key,
                status = e.Value.Status.ToString(),
                description = e.Value.Description,
                duration = e.Value.Duration.TotalMilliseconds

            totalDuration = report.TotalDuration.TotalMilliseconds

    }
});
```

### Complete Production Example

**Program.cs:**
```csharp
var builder = WebApplication.CreateBuilder(args);

// Add services
builder.Services.AddControllers();

// Configure health checks
builder.Services.AddHealthChecks()
    // Self check (liveness)
    .AddCheck("self", () => HealthCheckResult.Healthy(), tags: new[] { "live" })
    
    // Database (readiness)
    .AddSqlServer(
        builder.Configuration.GetConnectionString("DefaultConnection")!,
        name: "sqlserver-db",
        failureStatus: HealthStatus.Unhealthy,
        tags: new[] { "ready", "db" },
        timeout: TimeSpan.FromSeconds(3))
    
    // Redis (readiness)
    .AddRedis(
        builder.Configuration.GetConnectionString("Redis")!,
        name: "redis-cache",
        failureStatus: HealthStatus.Degraded,
        tags: new[] { "ready", "cache" },
        timeout: TimeSpan.FromSeconds(3))
    
    // Memory check
    .AddPrivateMemoryHealthCheck(
        maximumMemoryBytes: 1024 * 1024 * 1024, // 1GB
        name: "memory",
        tags: new[] { "live" });

var app = builder.Build();

app.MapControllers();

// Liveness endpoint
app.MapHealthChecks("/health/live", new HealthCheckOptions
{
    Predicate = check => check.Tags.Contains("live"),
    AllowCachingResponses = false
});

// Readiness endpoint with detailed response
app.MapHealthChecks("/health/ready", new HealthCheckOptions
{
    Predicate = check => check.Tags.Contains("ready"),
    AllowCachingResponses = false,
    ResponseWriter = async (context, report) =>
    {
        context.Response.ContentType = "application/json";
        
        var result = JsonSerializer.Serialize(new
        {
            status = report.Status.ToString(),
            timestamp = DateTime.UtcNow,
            checks = report.Entries.Select(e => new
            {
                name = e.Key,
                status = e.Value.Status.ToString(),
                description = e.Value.Description,
                duration = $"{e.Value.Duration.TotalMilliseconds:F2}ms"
            }),
            totalDuration = $"{report.TotalDuration.TotalMilliseconds:F2}ms"
        }, new JsonSerializerOptions { WriteIndented = true });
        
        await context.Response.WriteAsync(result);
    }
});

app.Run();
```

### Best Practices

**1. Keep health checks lightweight:**
```csharp
// ❌ Bad: expensive query
.AddCheck("db", () => 
{
    var count = dbContext.Users.Count(); // Scans entire table!
    return HealthCheckResult.Healthy();
});

// ✅ Good: simple ping
.AddSqlServer(connectionString, healthQuery: "SELECT 1");
```

**2. Set appropriate timeouts:**
```csharp
.AddSqlServer(
    connectionString,
    timeout: TimeSpan.FromSeconds(3)) // Don't wait forever
```

**3. Use degraded status for non-critical failures:**
```csharp
.AddRedis(
    connectionString,
    failureStatus: HealthStatus.Degraded) // Cache failure shouldn't kill app
```

**4. Separate liveness and readiness:**
```csharp
// Liveness: "Is my app alive?"
.AddCheck("self", () => HealthCheckResult.Healthy(), tags: new[] { "live" })

// Readiness: "Can my app serve requests?"
.AddSqlServer(connectionString, tags: new[] { "ready" })
```

**5. Add startup delay:**
```dockerfile
HEALTHCHECK --start-period=30s  # Give app time to start
```
