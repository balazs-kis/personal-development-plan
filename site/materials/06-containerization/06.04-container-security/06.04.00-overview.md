# Chapter 6.4: Container Security

## Overview
This chapter covers essential security practices for containerized applications. You'll learn how to scan images for vulnerabilities, run containers with minimal privileges, implement resource constraints, and manage secrets securely. Security is not an afterthought—it must be baked into your container strategy from the start.

## Key Concepts
- **Image Vulnerability Scanning:** detecting and remediating security vulnerabilities in container images.
- **Non-Root Containers:** running containers with minimal privileges to limit attack surface.
- **Read-Only Filesystems:** preventing runtime modifications to increase security.
- **Resource Limits:** constraining CPU and memory to prevent resource exhaustion attacks.
- **Secrets Management:** handling sensitive data securely in containerized environments.
