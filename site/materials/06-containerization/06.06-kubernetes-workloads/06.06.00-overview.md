# Chapter 6.6: Kubernetes Workloads

## Overview
This chapter covers the fundamental workload resources in Kubernetes. You'll learn about Pods (the basic building block), Deployments for stateless applications, StatefulSets for stateful workloads, DaemonSets for node-level services, and Jobs/CronJobs for batch processing. Understanding when to use each resource type is essential for running applications effectively in Kubernetes.

## Key Concepts
- **Pods:** the smallest deployable units containing one or more containers.
- **Deployments:** managing replicated stateless applications with rolling updates.
- **StatefulSets:** running stateful applications with stable identities and persistent storage.
- **DaemonSets:** ensuring specific pods run on all (or selected) nodes.
- **Jobs and CronJobs:** running batch processing and scheduled tasks.
