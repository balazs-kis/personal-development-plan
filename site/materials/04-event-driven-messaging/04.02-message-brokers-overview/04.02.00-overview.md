# Chapter 4.2: Message Brokers Overview

## Overview
This chapter surveys the landscape of message brokers, helping you understand the fundamental differences between traditional message queuing systems (like RabbitMQ) and event streaming platforms (like Apache Kafka). You'll learn about consumption models, persistence strategies, ordering guarantees, and scalability characteristics—knowledge essential for choosing the right messaging infrastructure for your use case.

## Key Concepts
- **Message Queues vs Event Streams:** understanding the architectural differences and when to use each.
- **Push vs Pull Consumption:** how consumers receive messages and the trade-offs of each model.
- **Message Persistence and Replay:** how messages are stored and when replay capability matters.
- **Ordering Guarantees:** understanding message ordering and how different brokers handle it.
- **Scalability Characteristics:** how message brokers scale and handle growing workloads.
