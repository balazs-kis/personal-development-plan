## Introduction

Common Table Expressions (CTEs) are temporary named result sets defined using the WITH clause. They make complex queries more readable by breaking them into logical, reusable parts. CTEs are particularly valuable for queries with multiple subqueries or when you need to reference the same subquery multiple times.

## Key Concepts Summary

### Basic CTE Syntax

```sql
-- Single CTE
WITH sales_summary AS (
    SELECT 
        customer_id,
        SUM(amount) as total_sales,
        COUNT(*) as order_count
    FROM orders
    WHERE order_date >= '2024-01-01'
    GROUP BY customer_id
)
SELECT 
    c.name,
    s.total_sales,
    s.order_count
FROM customers c
JOIN sales_summary s ON c.customer_id = s.customer_id
WHERE s.total_sales > 1000;
```

### Multiple CTEs

CTEs can reference previously defined CTEs:

```sql
WITH 
-- First CTE
high_value_customers AS (
    SELECT customer_id, SUM(amount) as total_spent
    FROM orders
    GROUP BY customer_id
    HAVING SUM(amount) > 10000
),
-- Second CTE references the first
recent_orders AS (
    SELECT 
        o.order_id,
        o.customer_id,
        o.order_date,
        o.amount
    FROM orders o
    JOIN high_value_customers hvc 
        ON o.customer_id = hvc.customer_id
    WHERE o.order_date >= CURRENT_DATE - INTERVAL '30 days'
)
-- Main query uses both CTEs
SELECT 
    hvc.customer_id,
    hvc.total_spent,
    COUNT(ro.order_id) as recent_order_count
FROM high_value_customers hvc
LEFT JOIN recent_orders ro 
    ON hvc.customer_id = ro.customer_id
GROUP BY hvc.customer_id, hvc.total_spent;
```

### CTEs for Readability

Before (nested subqueries):

```sql
SELECT 
    p.product_name,
    p.price,
    (SELECT AVG(price) FROM products) as avg_price,
    p.price - (SELECT AVG(price) FROM products) as price_diff
FROM products p
WHERE p.category_id IN (
    SELECT category_id 
    FROM categories 
    WHERE name IN ('Electronics', 'Computers')
);
```

After (with CTE):

```sql
WITH 
avg_prices AS (
    SELECT AVG(price) as avg_price
    FROM products
),
target_categories AS (
    SELECT category_id
    FROM categories
    WHERE name IN ('Electronics', 'Computers')
)
SELECT 
    p.product_name,
    p.price,
    ap.avg_price,
    p.price - ap.avg_price as price_diff
FROM products p
CROSS JOIN avg_prices ap
WHERE p.category_id IN (SELECT category_id FROM target_categories);
```

### CTEs in Data Modification

CTEs can be used with INSERT, UPDATE, DELETE:

```sql
-- Archive old orders and return archived count
WITH archived_orders AS (
    DELETE FROM orders
    WHERE order_date < '2020-01-01'
    RETURNING *
)
INSERT INTO orders_archive
SELECT * FROM archived_orders;
```
