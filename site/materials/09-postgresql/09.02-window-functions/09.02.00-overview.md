# Chapter 9.2: Window Functions

## Overview

This chapter introduces window functions, one of SQL's most powerful features for analytics and reporting. Window functions perform calculations across sets of rows while preserving individual row identity, enabling sophisticated analytics that would otherwise require complex self-joins or application-level processing.

## Key Concepts
- **OVER Clause:** the fundamental syntax that defines window functions.
- **PARTITION BY and ORDER BY:** controlling how data is grouped and ordered for calculations.
- **Ranking Functions:** assigning ranks, row numbers, and percentiles.
- **Aggregate Window Functions:** running totals, moving averages, and cumulative calculations.
- **Navigation Functions:** accessing values from other rows relative to the current row.
- **Window Frames:** fine-grained control over which rows are included in calculations.
