---

## Introduction

Window functions are a game-changer for data analysis in SQL. Unlike aggregate functions that collapse rows into groups, window functions perform calculations across rows while keeping each row separate. This makes them perfect for rankings, running totals, comparisons between rows, and complex analytics.

## Key Concepts Summary

### What Are Window Functions?

Window functions perform calculations across a "window" of rows related to the current row:

```sql
-- Without window functions: loses row detail
SELECT department, AVG(salary) as avg_salary
FROM employees
GROUP BY department;

-- With window functions: preserves all rows
SELECT 
    name,
    department,
    salary,
    AVG(salary) OVER (PARTITION BY department) as dept_avg_salary,
    salary - AVG(salary) OVER (PARTITION BY department) as diff_from_avg
FROM employees;
```

### The OVER Clause

Every window function requires an OVER clause:

```sql
-- Basic syntax
function_name(arguments) OVER (window_specification)

-- Empty OVER: applies to all rows
SELECT 
    name,
    salary,
    AVG(salary) OVER () as company_avg
FROM employees;
```

### PARTITION BY: Dividing Data into Groups

PARTITION BY divides rows into logical groups:

```sql
-- Calculate average salary per department
SELECT 
    name,
    department,
    salary,
    AVG(salary) OVER (PARTITION BY department) as dept_avg
FROM employees;

-- Multiple partitioning columns
SELECT 
    name,
    department,
    location,
    salary,
    AVG(salary) OVER (PARTITION BY department, location) as avg_salary
FROM employees;
```

### ORDER BY: Ordering Within Windows

ORDER BY controls the sequence within each partition:

```sql
-- Running total of sales
SELECT 
    order_date,
    amount,
    SUM(amount) OVER (ORDER BY order_date) as running_total
FROM orders;

-- Combined with PARTITION BY
SELECT 
    department,
    name,
    salary,
    SUM(salary) OVER (
        PARTITION BY department 
        ORDER BY salary DESC
    ) as cumulative_salary
FROM employees;
```

### Window Functions vs GROUP BY

Key differences:

```sql
-- GROUP BY: collapses rows
SELECT department, AVG(salary) as avg_salary
FROM employees
GROUP BY department;
-- Result: one row per department

-- Window function: preserves rows
SELECT 
    name,
    department,
    salary,
    AVG(salary) OVER (PARTITION BY department) as avg_salary
FROM employees;
-- Result: all original rows with the calculation added
```

### Common Use Cases

```sql
-- 1. Compare individual values to group averages
SELECT 
    product_name,
    category,
    price,
    AVG(price) OVER (PARTITION BY category) as category_avg,
    price / AVG(price) OVER (PARTITION BY category) as price_ratio
FROM products;

-- 2. Show both detail and summary
SELECT 
    customer_id,
    order_date,
    amount,
    COUNT(*) OVER (PARTITION BY customer_id) as total_orders,
    SUM(amount) OVER (PARTITION BY customer_id) as lifetime_value
FROM orders;

-- 3. Calculate percentage of total
SELECT 
    department,
    salary_expense,
    SUM(salary_expense) OVER () as company_total,
    ROUND(100.0 * salary_expense / SUM(salary_expense) OVER (), 2) as pct_of_total
FROM department_costs;
```
