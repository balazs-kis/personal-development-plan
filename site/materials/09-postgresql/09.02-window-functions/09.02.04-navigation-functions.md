# Lesson 4: Navigation Functions

## Learning Objectives

By the end of this lesson, you will be able to:
- Use LAG() to access previous row values
- Use LEAD() to access next row values
- Apply FIRST_VALUE() to get the first value in a window
- Apply LAST_VALUE() to get the last value in a window
- Use NTH_VALUE() to access specific row positions
- Solve comparison and trend analysis problems with navigation functions

---

## Introduction

Navigation functions (also called value or offset functions) allow you to access data from other rows relative to the current row without using self-joins. They're perfect for comparing consecutive rows, calculating period-over-period changes, finding trends, and implementing complex time-series analytics.

## Key Concepts Summary

### LAG(): Access Previous Row Values

Returns a value from a row that comes before the current row:

```sql
-- Basic LAG: get previous row's value
SELECT 
    order_date,
    revenue,
    LAG(revenue) OVER (ORDER BY order_date) as previous_day_revenue
FROM daily_revenue
ORDER BY order_date;

-- LAG with offset and default
-- LAG(column, offset, default_value)
SELECT 
    month,
    sales,
    LAG(sales, 1, 0) OVER (ORDER BY month) as prev_month,
    LAG(sales, 12, 0) OVER (ORDER BY month) as same_month_last_year
FROM monthly_sales;
```

### Calculating Period-over-Period Change

```sql
-- Day-over-day change
SELECT 
    date,
    revenue,
    LAG(revenue) OVER (ORDER BY date) as prev_day,
    revenue - LAG(revenue) OVER (ORDER BY date) as daily_change,
    ROUND(
        100.0 * (revenue - LAG(revenue) OVER (ORDER BY date)) / 
        LAG(revenue) OVER (ORDER BY date),
        2
    ) as pct_change
FROM daily_revenue
ORDER BY date;

-- Month-over-month within each product
SELECT 
    product_id,
    month,
    sales,
    LAG(sales) OVER (PARTITION BY product_id ORDER BY month) as prev_month,
    sales - LAG(sales) OVER (PARTITION BY product_id ORDER BY month) as change
FROM monthly_product_sales;
```

### LEAD(): Access Next Row Values

Returns a value from a row that comes after the current row:

```sql
-- Basic LEAD: get next row's value
SELECT 
    date,
    stock_price,
    LEAD(stock_price) OVER (ORDER BY date) as next_day_price
FROM stock_prices
ORDER BY date;

-- Compare current value to next period
SELECT 
    quarter,
    revenue,
    LEAD(revenue) OVER (ORDER BY quarter) as next_quarter,
    revenue - LEAD(revenue) OVER (ORDER BY quarter) as projected_change
FROM quarterly_revenue;

-- LEAD with offset
SELECT 
    week,
    orders,
    LEAD(orders, 1) OVER (ORDER BY week) as next_week,
    LEAD(orders, 4) OVER (ORDER BY week) as four_weeks_ahead
FROM weekly_orders;
```

### FIRST_VALUE(): First Value in Window

Returns the first value in the ordered window:

```sql
-- Compare to first value in the series
SELECT 
    date,
    stock_price,
    FIRST_VALUE(stock_price) OVER (ORDER BY date) as opening_price,
    stock_price - FIRST_VALUE(stock_price) OVER (ORDER BY date) as change_from_start
FROM stock_prices
ORDER BY date;

-- First value per partition
SELECT 
    product_id,
    date,
    price,
    FIRST_VALUE(price) OVER (
        PARTITION BY product_id 
        ORDER BY date
    ) as initial_price
FROM product_prices;
```

### LAST_VALUE(): Last Value in Window

Returns the last value in the window (requires careful frame specification):

```sql
-- IMPORTANT: LAST_VALUE requires proper frame specification
-- Default frame is RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW

-- Compare to last known value
SELECT 
    date,
    stock_price,
    LAST_VALUE(stock_price) OVER (
        ORDER BY date
        ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
    ) as final_price
FROM stock_prices
ORDER BY date;

-- Last value in each partition
SELECT 
    category,
    product_name,
    launch_date,
    LAST_VALUE(product_name) OVER (
        PARTITION BY category 
        ORDER BY launch_date
        ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
    ) as latest_product_in_category
FROM products;
```

### NTH_VALUE(): Nth Value in Window

Access a specific position in the ordered window:

```sql
-- Get the 2nd highest value
SELECT 
    employee_name,
    salary,
    NTH_VALUE(salary, 1) OVER (ORDER BY salary DESC) as highest_salary,
    NTH_VALUE(salary, 2) OVER (ORDER BY salary DESC) as second_highest
FROM employees;

-- Quarterly comparisons
SELECT 
    quarter,
    revenue,
    NTH_VALUE(revenue, 1) OVER (ORDER BY quarter) as q1_revenue,
    revenue - NTH_VALUE(revenue, 1) OVER (ORDER BY quarter) as vs_q1
FROM quarterly_sales;
```

### Practical Example: Stock Price Analysis

```sql
-- Comprehensive stock analysis
SELECT 
    date,
    closing_price,
    -- Previous and next day
    LAG(closing_price) OVER (ORDER BY date) as prev_close,
    LEAD(closing_price) OVER (ORDER BY date) as next_close,
    -- Day-over-day change
    closing_price - LAG(closing_price) OVER (ORDER BY date) as daily_change,
    -- Compare to first and last
    FIRST_VALUE(closing_price) OVER (ORDER BY date) as first_price,
    LAST_VALUE(closing_price) OVER (
        ORDER BY date
        ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
    ) as last_price,
    -- Percentage change from start
    ROUND(
        100.0 * (closing_price - FIRST_VALUE(closing_price) OVER (ORDER BY date)) /
        FIRST_VALUE(closing_price) OVER (ORDER BY date),
        2
    ) as pct_change_from_start
FROM stock_prices
WHERE symbol = 'AAPL'
ORDER BY date;
```

### Practical Example: Cohort Analysis

```sql
-- Customer retention: compare to first purchase
SELECT 
    customer_id,
    order_date,
    order_amount,
    FIRST_VALUE(order_date) OVER (
        PARTITION BY customer_id 
        ORDER BY order_date
    ) as first_order_date,
    FIRST_VALUE(order_amount) OVER (
        PARTITION BY customer_id 
        ORDER BY order_date
    ) as first_order_amount,
    order_date - FIRST_VALUE(order_date) OVER (
        PARTITION BY customer_id 
        ORDER BY order_date
    ) as days_since_first_order,
    ROW_NUMBER() OVER (
        PARTITION BY customer_id 
        ORDER BY order_date
    ) as order_number
FROM orders
ORDER BY customer_id, order_date;
```

### Finding Streaks and Gaps

```sql
-- Days between orders for each customer
SELECT 
    customer_id,
    order_date,
    LAG(order_date) OVER (
        PARTITION BY customer_id 
        ORDER BY order_date
    ) as previous_order_date,
    order_date - LAG(order_date) OVER (
        PARTITION BY customer_id 
        ORDER BY order_date
    ) as days_since_last_order
FROM orders
WHERE customer_id = 123
ORDER BY order_date;
```
