# Chapter 9.9: Database Design Patterns

## Overview
Learn database design patterns: normalization vs denormalization, temporal tables, soft deletes, audit logging, and schema migration strategies.

## Key Concepts
- **Normalization forms:** 1NF, 2NF, 3NF, BCNF for eliminating redundancy.
- **Strategic denormalization:** When and how to denormalize for performance.
- **Temporal data patterns:** Tracking changes over time with bi-temporal tables.
- **Audit trails:** Soft deletes and comprehensive change tracking.
- **Schema migration practices:** Evolving databases safely in production.
