## Introduction

Ansible playbooks are YAML files that define automation tasks in a declarative way. Unlike ad-hoc commands, playbooks allow you to orchestrate complex workflows, reuse code, and maintain infrastructure as code. This lesson covers playbook structure, tasks, handlers, variables, and control structures.

## Key Concepts Summary

### Playbook Structure

**Basic playbook anatomy:**

```yaml
---
# Play 1
- name: Configure web servers
  hosts: webservers
  become: true
  
  tasks:
    - name: Install nginx
      apt:
        name: nginx
        state: present
    
    - name: Start nginx service
      service:
        name: nginx
        state: started
        enabled: true

# Play 2
- name: Configure database servers
  hosts: dbservers
  become: true
  
  tasks:
    - name: Install postgresql
      apt:
        name: postgresql
        state: present
```

**Key components:**
- `---` - YAML document start
- `name` - Description of play/task
- `hosts` - Target hosts or groups
- `become` - Run with sudo
- `tasks` - List of tasks to execute

## Writing Tasks

### Task Basics

**Simple task:**

```yaml
- name: Install nginx
  apt:
    name: nginx
    state: present
```

**Task with multiple parameters:**

```yaml
- name: Create application user
  user:
    name: appuser
    state: present
    shell: /bin/bash
    home: /home/appuser
    groups: sudo,www-data
    create_home: yes
```

**Using variables:**

```yaml
- name: Install package
  apt:
    name: "{{ package_name }}"
    state: "{{ package_state }}"
```

### Common Modules

**Package Management:**

```yaml
# Apt (Debian/Ubuntu)
- name: Install packages
  apt:
    name:
      - nginx
      - git
      - curl
    state: present
    update_cache: yes

# Yum (RHEL/CentOS)
- name: Install packages
  yum:
    name:
      - httpd
      - git
    state: present
```

**File Operations:**

```yaml
# Copy file
- name: Copy configuration file
  copy:
    src: files/nginx.conf
    dest: /etc/nginx/nginx.conf
    owner: root
    group: root
    mode: '0644'
    backup: yes

# Create directory
- name: Create app directory
  file:
    path: /var/www/myapp
    state: directory
    owner: www-data
    group: www-data
    mode: '0755'

# Create symlink
- name: Create symlink
  file:
    src: /var/www/myapp
    dest: /var/www/app
    state: link
```

**Service Management:**

```yaml
- name: Ensure nginx is running
  service:
    name: nginx
    state: started
    enabled: yes

- name: Restart apache
  service:
    name: apache2
    state: restarted

- name: Reload nginx configuration
  service:
    name: nginx
    state: reloaded
```

**Command Execution:**

```yaml
# Command module (doesn't use shell)
- name: Get disk usage
  command: df -h
  register: disk_usage

# Shell module (uses shell features)
- name: Run complex command
  shell: |
    echo "Cleaning logs..."
    find /var/log -name "*.log" -mtime +30 -delete
  args:
    executable: /bin/bash
```

## Variables

### Defining Variables

**In playbook:**

```yaml
- name: Configure web server
  hosts: webservers
  become: true
  
  vars:
    http_port: 80
    https_port: 443
    server_name: www.example.com
    document_root: /var/www/html
  
  tasks:
    - name: Update nginx configuration
      template:
        src: templates/nginx.conf.j2
        dest: /etc/nginx/nginx.conf
```

**External vars file:**

```yaml
# playbook.yml
- name: Deploy application
  hosts: appservers
  become: true
  vars_files:
    - vars/common.yml
    - vars/{{ env }}.yml
  
  tasks:
    - name: Deploy app
      copy:
        src: "{{ app_source }}"
        dest: "{{ app_destination }}"
```

```yaml
# vars/common.yml
app_name: myapp
app_user: appuser
app_group: appgroup
```

```yaml
# vars/production.yml
app_source: /builds/myapp-v2.0.tar.gz
app_destination: /opt/myapp
env: production
```

### Using Variables

**In tasks:**

```yaml
- name: Create user
  user:
    name: "{{ app_user }}"
    group: "{{ app_group }}"
    home: "/home/{{ app_user }}"

- name: Print message
  debug:
    msg: "Deploying {{ app_name }} version {{ app_version }} to {{ env }}"
```

**Variable precedence (highest to lowest):**
1. Extra vars (`-e` in command line)
2. Task vars
3. Block vars
4. Role and include vars
5. Play vars_files
6. Play vars
7. Host facts
8. Playbook host_vars
9. Playbook group_vars
10. Inventory host_vars
11. Inventory group_vars
12. Role defaults

## Templates

### Jinja2 Templates

**Template file: `templates/nginx.conf.j2`**

```jinja2
user www-data;
worker_processes {{ ansible_processor_cores }};

events {
    worker_connections {{ max_connections | default(1024) }};
}

http {
    server {
        listen {{ http_port }};
        server_name {{ server_name }};
        root {{ document_root }};
        
        {% if enable_ssl %}
        listen {{ https_port }} ssl;
        ssl_certificate {{ ssl_cert_path }};
        ssl_certificate_key {{ ssl_key_path }};
        {% endif %}
        
        location / {
            try_files $uri $uri/ =404;
        }
    }
}
```

**Using template in playbook:**

```yaml
- name: Deploy nginx configuration
  template:
    src: templates/nginx.conf.j2
    dest: /etc/nginx/nginx.conf
    owner: root
    group: root
    mode: '0644'
  notify: Restart nginx
```

**Template with loops:**

```jinja2
# /etc/hosts template
127.0.0.1 localhost

{% for host in web_servers %}
{{ host.ip }} {{ host.name }}
{% endfor %}
```

## Handlers

### What Are Handlers?

Handlers are tasks that run only when notified by other tasks, typically used to restart services after configuration changes.

**Defining handlers:**

```yaml
- name: Configure web server
  hosts: webservers
  become: true
  
  tasks:
    - name: Update nginx configuration
      template:
        src: nginx.conf.j2
        dest: /etc/nginx/nginx.conf
      notify: Restart nginx
    
    - name: Update SSL certificate
      copy:
        src: ssl/cert.pem
        dest: /etc/nginx/ssl/cert.pem
      notify:
        - Restart nginx
        - Reload nginx
  
  handlers:
    - name: Restart nginx
      service:
        name: nginx
        state: restarted
    
    - name: Reload nginx
      service:
        name: nginx
        state: reloaded
```

**Handler characteristics:**
- Run at the end of a play
- Run only once even if notified multiple times
- Run only if notified by a task that made changes

**Forcing handler execution:**

```yaml
tasks:
  - name: Configure service
    template:
      src: config.j2
      dest: /etc/service/config
    notify: Restart service
  
  - name: Flush handlers
    meta: flush_handlers  # Run handlers now
  
  - name: Test service
    uri:
      url: http://localhost:8080/health
      status_code: 200
```

## Loops

### Basic Loops

**Simple list:**

```yaml
- name: Install multiple packages
  apt:
    name: "{{ item }}"
    state: present
  loop:
    - nginx
    - git
    - curl
    - vim
```

**Dictionary loop:**

```yaml
- name: Create multiple users
  user:
    name: "{{ item.name }}"
    state: present
    groups: "{{ item.groups }}"
  loop:
    - { name: 'alice', groups: 'developers' }
    - { name: 'bob', groups: 'admins' }
    - { name: 'charlie', groups: 'developers' }
```

**Loop over dictionary:**

```yaml
- name: Create users with attributes
  user:
    name: "{{ item.key }}"
    uid: "{{ item.value.uid }}"
    shell: "{{ item.value.shell }}"
  loop: "{{ users | dict2items }}"
  vars:
    users:
      alice:
        uid: 1001
        shell: /bin/bash
      bob:
        uid: 1002
        shell: /bin/zsh
```

**Loop with index:**

```yaml
- name: Create numbered files
  file:
    path: "/tmp/file-{{ item }}.txt"
    state: touch
  loop: "{{ range(1, 6) | list }}"  # 1, 2, 3, 4, 5
```

### Loop Control

```yaml
- name: Deploy application files
  copy:
    src: "{{ item }}"
    dest: "/var/www/{{ item | basename }}"
  loop:
    - app.js
    - package.json
    - config.json
  loop_control:
    label: "{{ item | basename }}"  # Only show basename in output
    pause: 2  # Pause 2 seconds between iterations
```

## Conditionals

### When Conditions

**Simple condition:**

```yaml
- name: Install nginx on Ubuntu
  apt:
    name: nginx
    state: present
  when: ansible_distribution == "Ubuntu"

- name: Install httpd on RedHat
  yum:
    name: httpd
    state: present
  when: ansible_os_family == "RedHat"
```

**Multiple conditions:**

```yaml
- name: Install package on specific OS version
  apt:
    name: special-package
    state: present
  when:
    - ansible_distribution == "Ubuntu"
    - ansible_distribution_version == "22.04"
```

**Or conditions:**

```yaml
- name: Install on Debian-based systems
  apt:
    name: package
    state: present
  when: ansible_os_family == "Debian" or ansible_distribution == "Ubuntu"
```

**Conditional based on variable:**

```yaml
- name: Deploy to production
  copy:
    src: prod-config.yml
    dest: /etc/app/config.yml
  when: environment == "production"

- name: Enable debug mode in dev
  lineinfile:
    path: /etc/app/config.yml
    line: "debug: true"
  when: environment == "development"
```

**Conditional based on registered variable:**

```yaml
- name: Check if service exists
  command: systemctl status myapp
  register: service_status
  failed_when: false  # Don't fail if command returns non-zero
  changed_when: false

- name: Start service if it exists
  service:
    name: myapp
    state: started
  when: service_status.rc == 0
```

## Register and Debug

### Capturing Task Output

```yaml
- name: Get disk usage
  command: df -h /var
  register: disk_usage

- name: Display disk usage
  debug:
    var: disk_usage.stdout_lines

- name: Fail if disk is full
  fail:
    msg: "Disk is over 90% full!"
  when: disk_usage.stdout | regex_search('9[0-9]%|100%')
```

### Debug Module

```yaml
- name: Show variable value
  debug:
    var: my_variable

- name: Show message
  debug:
    msg: "Deploying version {{ app_version }} to {{ environment }}"

- name: Show all facts
  debug:
    var: ansible_facts

- name: Conditional debug
  debug:
    msg: "This is production!"
  when: environment == "production"
```

## Complete Playbook Example

```yaml
---
- name: Deploy Web Application
  hosts: webservers
  become: true
  
  vars:
    app_name: myapp
    app_version: "1.0.0"
    app_port: 8080
    deploy_user: deploy
  
  vars_files:
    - vars/{{ environment }}.yml
  
  tasks:
    - name: Install required packages
      apt:
        name:
          - nginx
          - python3
          - python3-pip
        state: present
        update_cache: yes
    
    - name: Create application user
      user:
        name: "{{ deploy_user }}"
        state: present
        shell: /bin/bash
        create_home: yes
    
    - name: Create application directory
      file:
        path: "/opt/{{ app_name }}"
        state: directory
        owner: "{{ deploy_user }}"
        group: "{{ deploy_user }}"
        mode: '0755'
    
    - name: Deploy application files
      copy:
        src: "dist/{{ app_name }}-{{ app_version }}.tar.gz"
        dest: "/opt/{{ app_name }}/"
        owner: "{{ deploy_user }}"
      notify: Restart application
    
    - name: Extract application
      unarchive:
        src: "/opt/{{ app_name }}/{{ app_name }}-{{ app_version }}.tar.gz"
        dest: "/opt/{{ app_name }}/"
        remote_src: yes
      notify: Restart application
    
    - name: Install Python dependencies
      pip:
        requirements: "/opt/{{ app_name }}/requirements.txt"
        executable: pip3
    
    - name: Deploy nginx configuration
      template:
        src: templates/nginx-app.conf.j2
        dest: /etc/nginx/sites-available/{{ app_name }}
        mode: '0644'
      notify: Reload nginx
    
    - name: Enable nginx site
      file:
        src: /etc/nginx/sites-available/{{ app_name }}
        dest: /etc/nginx/sites-enabled/{{ app_name }}
        state: link
      notify: Reload nginx
    
    - name: Deploy systemd service file
      template:
        src: templates/app.service.j2
        dest: /etc/systemd/system/{{ app_name }}.service
        mode: '0644'
      notify:
        - Reload systemd
        - Restart application
    
    - name: Ensure application is running
      service:
        name: "{{ app_name }}"
        state: started
        enabled: yes
    
    - name: Wait for application to be ready
      uri:
        url: "http://localhost:{{ app_port }}/health"
        status_code: 200
      retries: 5
      delay: 10
  
  handlers:
    - name: Reload systemd
      systemd:
        daemon_reload: yes
    
    - name: Restart application
      service:
        name: "{{ app_name }}"
        state: restarted
    
    - name: Reload nginx
      service:
        name: nginx
        state: reloaded
```

## Best Practices

### 1. Always Name Your Tasks

```yaml
# ✅ Good
- name: Install nginx web server
  apt:
    name: nginx
    state: present

# ❌ Bad
- apt:
    name: nginx
    state: present
```

### 2. Use Native Modules Over Commands

```yaml
# ✅ Good
- name: Install package
  apt:
    name: nginx
    state: present

# ❌ Bad
- name: Install package
  command: apt-get install -y nginx
```

### 3. Make Tasks Idempotent

```yaml
# ✅ Good: Creates if doesn't exist
- name: Create directory
  file:
    path: /opt/app
    state: directory

# ❌ Bad: Fails if already exists
- name: Create directory
  command: mkdir /opt/app
```

### 4. Use Check Mode

```bash
# Test playbook without making changes
ansible-playbook playbook.yml --check

# Show diff of changes
ansible-playbook playbook.yml --check --diff
```

### 5. Handle Errors Gracefully

```yaml
- name: Try to start service
  service:
    name: myapp
    state: started
  ignore_errors: yes
  register: start_result

- name: Handle failure
  debug:
    msg: "Service failed to start: {{ start_result.msg }}"
  when: start_result is failed
```
