## Introduction

As Ansible projects grow, playbooks can become unwieldy. Roles provide a way to organize and reuse automation code by grouping related tasks, variables, templates, and files into standardized directory structures. This lesson covers role creation, organization patterns, and best practices for maintainable Ansible code.

## Key Concepts Summary

### What Are Roles?

Roles are a way to organize playbooks into reusable components:

**Benefits:**
- **Reusability:** Use roles across multiple playbooks
- **Organization:** Separate concerns into logical units
- **Collaboration:** Share roles with teams via Ansible Galaxy
- **Maintainability:** Easier to update and test individual components
- **Standardization:** Consistent structure across projects

---

## Role Directory Structure

**Standard role structure:**

```
roles/
  role_name/
    ├── tasks/
    │   └── main.yml          # Main task list
    ├── handlers/
    │   └── main.yml          # Handler definitions
    ├── templates/
    │   └── config.j2         # Jinja2 templates
    ├── files/
    │   └── script.sh         # Static files
    ├── vars/
    │   └── main.yml          # High-precedence variables
    ├── defaults/
    │   └── main.yml          # Default variables (low precedence)
    ├── meta/
    │   └── main.yml          # Role metadata and dependencies
    ├── tests/
    │   ├── inventory         # Test inventory
    │   └── test.yml          # Test playbook
    └── README.md             # Documentation
```

**You only need directories you actually use.** Ansible won't complain about missing directories.

## Creating a Role

### Manual Creation

```bash
# Create role directory structure
mkdir -p roles/webserver/{tasks,handlers,templates,files,vars,defaults,meta}
```

### Using ansible-galaxy

```bash
# Create role skeleton
ansible-galaxy role init webserver

# This creates:
# roles/webserver/
#   README.md
#   defaults/main.yml
#   files/
#   handlers/main.yml
#   meta/main.yml
#   tasks/main.yml
#   templates/
#   tests/
#   vars/main.yml
```

## Simple Role Example

### Nginx Role

**roles/nginx/tasks/main.yml:**

```yaml
---
- name: Install nginx
  apt:
    name: nginx
    state: present
    update_cache: yes

- name: Deploy nginx configuration
  template:
    src: nginx.conf.j2
    dest: /etc/nginx/nginx.conf
    mode: '0644'
  notify: Restart nginx

- name: Ensure nginx is running
  service:
    name: nginx
    state: started
    enabled: yes
```

**roles/nginx/handlers/main.yml:**

```yaml
---
- name: Restart nginx
  service:
    name: nginx
    state: restarted

- name: Reload nginx
  service:
    name: nginx
    state: reloaded
```

**roles/nginx/templates/nginx.conf.j2:**

```jinja2
user {{ nginx_user }};
worker_processes {{ nginx_worker_processes }};

events {
    worker_connections {{ nginx_worker_connections }};
}

http {
    server {
        listen {{ nginx_port }};
        server_name {{ server_name }};
        root {{ document_root }};
        
        location / {
            try_files $uri $uri/ =404;
        }
    }
}
```

**roles/nginx/defaults/main.yml:**

```yaml
---
nginx_user: www-data
nginx_worker_processes: auto
nginx_worker_connections: 1024
nginx_port: 80
server_name: localhost
document_root: /var/www/html
```

**roles/nginx/meta/main.yml:**

```yaml
---
galaxy_info:
  author: Your Name
  description: Install and configure nginx
  license: MIT
  min_ansible_version: "2.9"
  platforms:
    - name: Ubuntu
      versions:
        - focal
        - jammy
  galaxy_tags:
    - web
    - nginx
    - webserver

dependencies: []
```

## Using Roles in Playbooks

### Basic Usage

```yaml
---
- name: Configure web servers
  hosts: webservers
  become: true
  
  roles:
    - nginx
```

### With Variables

```yaml
---
- name: Configure web servers
  hosts: webservers
  become: true
  
  roles:
    - role: nginx
      vars:
        nginx_port: 8080
        server_name: www.example.com
        document_root: /var/www/myapp
```

### Multiple Roles

```yaml
---
- name: Configure application server
  hosts: appservers
  become: true
  
  roles:
    - common           # Base configuration
    - security         # Security hardening
    - docker           # Docker installation
    - monitoring       # Monitoring agents
    - application      # Application-specific setup
```

### Mixed Tasks and Roles

```yaml
---
- name: Deploy application
  hosts: webservers
  become: true
  
  pre_tasks:
    - name: Update apt cache
      apt:
        update_cache: yes
  
  roles:
    - common
    - nginx
    - application
  
  tasks:
    - name: Custom post-deployment task
      debug:
        msg: "Deployment complete!"
  
  post_tasks:
    - name: Send deployment notification
      uri:
        url: https://hooks.slack.com/services/YOUR/WEBHOOK/URL
        method: POST
        body_format: json
        body:
          text: "Deployment completed successfully"
```

## Role Dependencies

**roles/application/meta/main.yml:**

```yaml
---
dependencies:
  - role: common
    vars:
      common_packages:
        - curl
        - git
  
  - role: nginx
    vars:
      nginx_port: 8080
  
  - role: postgresql
    when: database_type == "postgresql"
```

**Using a role with dependencies:**

```yaml
---
- name: Deploy application
  hosts: appservers
  become: true
  
  roles:
    - application  # Automatically includes common, nginx, postgresql
```

## Role Organization Patterns

### Pattern 1: Simple Project

```
project/
├── ansible.cfg
├── inventory/
│   ├── production
│   └── staging
├── group_vars/
│   ├── all.yml
│   └── webservers.yml
├── host_vars/
├── roles/
│   ├── common/
│   ├── nginx/
│   └── application/
└── playbooks/
    ├── site.yml
    ├── webservers.yml
    └── dbservers.yml
```

### Pattern 2: Large Project

```
project/
├── ansible.cfg
├── inventories/
│   ├── production/
│   │   ├── hosts
│   │   ├── group_vars/
│   │   └── host_vars/
│   └── staging/
│       ├── hosts
│       ├── group_vars/
│       └── host_vars/
├── roles/
│   ├── internal/              # Internal roles
│   │   ├── common/
│   │   ├── security/
│   │   └── monitoring/
│   └── external/              # Galaxy roles
│       └── requirements.yml
├── playbooks/
│   ├── site.yml
│   ├── webservers.yml
│   └── dbservers.yml
└── group_vars/
    └── all/
        ├── vars.yml
        └── vault.yml          # Encrypted secrets
```

### Pattern 3: Multi-Environment

```
project/
├── ansible.cfg
├── inventories/
│   ├── production/
│   ├── staging/
│   └── development/
├── roles/
│   ├── app_deploy/
│   ├── db_setup/
│   └── monitoring/
├── playbooks/
│   ├── deploy.yml
│   ├── rollback.yml
│   └── maintenance.yml
└── vars/
    ├── production.yml
    ├── staging.yml
    └── development.yml
```

## Complete Role Example: Application Deployment

**roles/app_deploy/tasks/main.yml:**

```yaml
---
- name: Include OS-specific variables
  include_vars: "{{ ansible_os_family }}.yml"

- name: Install application dependencies
  apt:
    name: "{{ app_dependencies }}"
    state: present

- name: Create application user
  user:
    name: "{{ app_user }}"
    state: present
    shell: /bin/bash
    create_home: yes

- name: Create application directories
  file:
    path: "{{ item }}"
    state: directory
    owner: "{{ app_user }}"
    group: "{{ app_group }}"
    mode: '0755'
  loop:
    - "{{ app_install_dir }}"
    - "{{ app_log_dir }}"
    - "{{ app_config_dir }}"

- name: Download application
  get_url:
    url: "{{ app_download_url }}"
    dest: "/tmp/{{ app_name }}.tar.gz"
    checksum: "{{ app_checksum }}"

- name: Extract application
  unarchive:
    src: "/tmp/{{ app_name }}.tar.gz"
    dest: "{{ app_install_dir }}"
    remote_src: yes
    owner: "{{ app_user }}"
    group: "{{ app_group }}"
  notify: Restart application

- name: Deploy application configuration
  template:
    src: app.conf.j2
    dest: "{{ app_config_dir }}/app.conf"
    owner: "{{ app_user }}"
    mode: '0644'
  notify: Restart application

- name: Deploy systemd service
  template:
    src: app.service.j2
    dest: /etc/systemd/system/{{ app_name }}.service
    mode: '0644'
  notify:
    - Reload systemd
    - Restart application

- name: Enable and start application
  service:
    name: "{{ app_name }}"
    state: started
    enabled: yes
```

**roles/app_deploy/defaults/main.yml:**

```yaml
---
app_name: myapp
app_version: "1.0.0"
app_user: appuser
app_group: appgroup
app_install_dir: "/opt/{{ app_name }}"
app_config_dir: "/etc/{{ app_name }}"
app_log_dir: "/var/log/{{ app_name }}"
app_port: 8080

app_dependencies:
  - python3
  - python3-pip
  - supervisor

app_download_url: "https://releases.example.com/{{ app_name }}/{{ app_version }}/{{ app_name }}.tar.gz"
app_checksum: "sha256:abc123..."
```

**roles/app_deploy/vars/Debian.yml:**

```yaml
---
app_dependencies:
  - python3
  - python3-pip
  - python3-venv
  - supervisor
```

**roles/app_deploy/vars/RedHat.yml:**

```yaml
---
app_dependencies:
  - python3
  - python3-pip
  - python3-virtualenv
  - supervisor
```

**roles/app_deploy/handlers/main.yml:**

```yaml
---
- name: Reload systemd
  systemd:
    daemon_reload: yes

- name: Restart application
  service:
    name: "{{ app_name }}"
    state: restarted
```

## Ansible Galaxy

### Finding Roles

```bash
# Search for roles
ansible-galaxy search nginx

# Get role info
ansible-galaxy info geerlingguy.nginx

# Install role
ansible-galaxy install geerlingguy.nginx

# Install to specific path
ansible-galaxy install geerlingguy.nginx -p roles/
```

### Requirements File

**requirements.yml:**

```yaml
---
# From Ansible Galaxy
- name: geerlingguy.nginx
  version: "3.1.4"

- name: geerlingguy.postgresql
  version: "3.4.2"

# From GitHub
- src: https://github.com/organization/ansible-role-custom
  name: custom
  version: main

# From Git with specific version
- src: git+https://github.com/organization/role.git
  name: special_role
  version: "v1.2.3"
```

**Installing from requirements:**

```bash
# Install all roles
ansible-galaxy install -r requirements.yml

# Force reinstall
ansible-galaxy install -r requirements.yml --force
```

```

## Best Practices

### 1. Keep Roles Focused

```
✅ Good: One role per service
  - roles/nginx/
  - roles/postgresql/
  - roles/application/

❌ Bad: One monolithic role
  - roles/everything/
```

### 2. Use Defaults Generously

```yaml
# roles/myapp/defaults/main.yml
# Provide sensible defaults for everything
app_port: 8080
app_workers: 4
app_timeout: 30
app_log_level: info
```

### 3. Document Your Roles

```markdown
# Role: nginx

## Description
Installs and configures nginx web server.

## Requirements
- Ubuntu 20.04 or 22.04
- Python 3.6+

## Role Variables
- `nginx_port`: HTTP port (default: 80)
- `nginx_worker_processes`: Number of workers (default: auto)

## Example Playbook
```yaml
- hosts: webservers
  roles:
    - role: nginx
      vars:
        nginx_port: 8080
```

## Dependencies
- geerlingguy.firewall

## License
MIT
```

### 4. Make Roles Idempotent

```yaml
# ✅ Good: Always idempotent
- name: Ensure directory exists
  file:
    path: /opt/app
    state: directory

# ❌ Bad: Fails on second run
- name: Create directory
  command: mkdir /opt/app
```

### 5. Use Tags

```yaml
# roles/application/tasks/main.yml
- name: Install packages
  apt:
    name: "{{ item }}"
    state: present
  loop: "{{ app_packages }}"
  tags:
    - install
    - packages

- name: Deploy configuration
  template:
    src: config.j2
    dest: /etc/app/config
  tags:
    - config
    - deploy
```

**Using tags:**

```bash
# Run only install tasks
ansible-playbook site.yml --tags install

# Skip config tasks
ansible-playbook site.yml --skip-tags config
```

### 6. Handle Multiple OS Families

```yaml
# roles/myapp/tasks/main.yml
- name: Include OS-specific variables
  include_vars: "{{ ansible_os_family }}.yml"

- name: Install packages (Debian)
  apt:
    name: "{{ packages }}"
    state: present
  when: ansible_os_family == "Debian"

- name: Install packages (RedHat)
  yum:
    name: "{{ packages }}"
    state: present
  when: ansible_os_family == "RedHat"
```

## Master Playbook Pattern

**site.yml:**

```yaml
---
# Master playbook - includes all others
- import_playbook: common.yml
- import_playbook: webservers.yml
- import_playbook: dbservers.yml
- import_playbook: monitoring.yml
```

**webservers.yml:**

```yaml
---
- name: Configure web servers
  hosts: webservers
  become: true
  
  roles:
    - common
    - nginx
    - application
```

**Usage:**

```bash
# Run everything
ansible-playbook site.yml

# Run specific playbook
ansible-playbook webservers.yml

# Target specific environment
ansible-playbook -i inventories/production site.yml
```
