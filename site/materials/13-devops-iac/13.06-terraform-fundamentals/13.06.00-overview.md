# Chapter 13.6: Terraform Fundamentals

## Overview
Terraform is the leading Infrastructure as Code tool for provisioning and managing cloud infrastructure. This chapter covers the fundamentals: HCL syntax, providers, resources, data sources, variables, outputs, and the core Terraform workflow. You'll learn how to write, plan, and apply Terraform configurations to manage infrastructure across any cloud provider.

## Key Concepts
- **HCL Syntax:** Understanding Terraform's declarative configuration language.
- **Providers and Resources:** Connecting to cloud platforms and defining infrastructure objects.
- **Variables and Outputs:** Making configurations dynamic and reusable.
- **Data Sources:** Querying existing infrastructure and external data.
- **Terraform Workflow:** The init, plan, apply, destroy cycle.
