# Chapter 11.10: Security Testing

## Overview

Test application security: static analysis (SAST), dynamic analysis (DAST), dependency scanning, and penetration testing basics. Security testing finds vulnerabilities before attackers do. Automated scanning integrated into CI/CD provides continuous security feedback.

## Key Concepts

- **Static Application Security Testing (SAST):** Analyzing source code for vulnerabilities without executing the application.
- **Dynamic Application Security Testing (DAST):** Testing running applications to discover vulnerabilities through simulated attacks.
- **Dependency vulnerability scanning:** Identifying known vulnerabilities in third-party libraries and packages.
- **Security code review:** Manual inspection of code to identify security flaws and logic errors.
- **Penetration testing basics:** Understanding how to test applications like an attacker to find exploitable vulnerabilities.
