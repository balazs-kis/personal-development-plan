By the end of this lesson, you will be able to:

- Implement the User Secrets tool for local development
- Configure environment-specific settings properly
- Use the Options pattern for strongly-typed configuration

---

## Introduction

Environment variables provide a way to externalize configuration from your application code, including secrets. .NET's configuration system supports multiple providers that load settings from various sources, with later sources overriding earlier ones. This lesson teaches you how to use environment variables and other configuration providers effectively for secret management.

**Key principle:** Use User Secrets for local development, environment variables for deployment, and Key Vault for production. Never mix them up.

## Key Concepts Summary

### Configuration Provider Hierarchy

```csharp
// Configuration sources in .NET (order matters - later overrides earlier)
var builder = WebApplication.CreateBuilder(args);

// The configuration is built from these sources (in order):
// 1. appsettings.json
// 2. appsettings.{Environment}.json
// 3. User Secrets (Development only)
// 4. Environment Variables
// 5. Command-line arguments

// Access configuration
var connectionString = builder.Configuration["ConnectionStrings:DefaultConnection"];
var apiKey = builder.Configuration["ApiKeys:Stripe"];
```

### Environment Variables in .NET

```bash
# Setting environment variables

# Windows (PowerShell)
$env:ConnectionStrings__DefaultConnection="Server=localhost;Database=MyApp"
$env:ApiKeys__Stripe="sk_test_..."

# Linux/macOS
export ConnectionStrings__DefaultConnection="Server=localhost;Database=MyApp"
export ApiKeys__Stripe="sk_test_..."

# Docker
docker run -e ConnectionStrings__DefaultConnection="..." myapp

# Note: Use double underscore (__) to represent nested configuration sections
# ConnectionStrings__DefaultConnection maps to ConnectionStrings:DefaultConnection
```

### Using Environment Variables in Code

```csharp
// Direct access
var connectionString = Environment.GetEnvironmentVariable("DATABASE_URL");

// Through IConfiguration (recommended)
public class MyService
{
    private readonly string _apiKey;
    
    public MyService(IConfiguration configuration)
    {
        _apiKey = configuration["ApiKeys:Stripe"];
        
        // Or with default value
        _apiKey = configuration["ApiKeys:Stripe"] ?? "default-key";
    }
}
```

### User Secrets for Development

```bash
# Initialize User Secrets in your project
cd YourProject
dotnet user-secrets init

# This adds UserSecretsId to .csproj:
# <UserSecretsId>a-unique-guid</UserSecretsId>

# Set secrets
dotnet user-secrets set "ConnectionStrings:DefaultConnection" "Server=localhost;..."
dotnet user-secrets set "ApiKeys:Stripe" "sk_test_..."
dotnet user-secrets set "ApiKeys:SendGrid" "SG...."

# List all secrets
dotnet user-secrets list

# Remove a secret
dotnet user-secrets remove "ApiKeys:Stripe"

# Clear all secrets
dotnet user-secrets clear

# Secrets are stored at:
# Windows: %APPDATA%\Microsoft\UserSecrets\<user_secrets_id>\secrets.json
# Linux/macOS: ~/.microsoft/usersecrets/<user_secrets_id>/secrets.json
```

### Strongly-Typed Configuration (Options Pattern)

```csharp
// Configuration classes
public class ApiKeySettings
{
    public string Stripe { get; set; }
    public string SendGrid { get; set; }
}

public class ConnectionStringSettings
{
    public string DefaultConnection { get; set; }
}

public class JwtSettings
{
    public string Secret { get; set; }
    public string Issuer { get; set; }
    public string Audience { get; set; }
    public int ExpirationMinutes { get; set; }
}

// Register in Program.cs
builder.Services.Configure<ApiKeySettings>(
    builder.Configuration.GetSection("ApiKeys"));
builder.Services.Configure<ConnectionStringSettings>(
    builder.Configuration.GetSection("ConnectionStrings"));
builder.Services.Configure<JwtSettings>(
    builder.Configuration.GetSection("JwtSettings"));

// Use with IOptions
public class PaymentService
{
    private readonly string _stripeKey;
    
    public PaymentService(IOptions<ApiKeySettings> apiKeys)
    {
        _stripeKey = apiKeys.Value.Stripe;
        
        if (string.IsNullOrEmpty(_stripeKey))
        {
            throw new InvalidOperationException(
                "Stripe API key is not configured");
        }
    }
    
    public async Task ProcessPayment(decimal amount)
    {
        // Use _stripeKey to call Stripe API
    }
}
```

### IOptions vs IOptionsSnapshot vs IOptionsMonitor

```csharp
// IOptions<T> - Singleton, doesn't reload
public class Service1
{
    public Service1(IOptions<MySettings> options)
    {
        // Value is cached for application lifetime
        var settings = options.Value;
    }
}

// IOptionsSnapshot<T> - Scoped, reloads per request
public class Service2
{
    public Service2(IOptionsSnapshot<MySettings> options)
    {
        // Value is reloaded for each request
        var settings = options.Value;
    }
}

// IOptionsMonitor<T> - Singleton, reloads on configuration change
public class Service3
{
    private readonly IOptionsMonitor<MySettings> _options;
    
    public Service3(IOptionsMonitor<MySettings> options)
    {
        _options = options;
        
        // Subscribe to changes
        options.OnChange(newSettings =>
        {
            // React to configuration changes
            Console.WriteLine("Configuration changed!");
        });
    }
    
    public void DoWork()
    {
        // Always gets current value
        var settings = _options.CurrentValue;
    }
}
```

### Validating Configuration at Startup

```csharp
public class ApiKeySettings
{
    [Required]
    [MinLength(20)]
    public string Stripe { get; set; }
    
    [Required]
    [EmailAddress]
    public string AdminEmail { get; set; }
}

// Validate on startup
builder.Services.AddOptions<ApiKeySettings>()
    .Bind(builder.Configuration.GetSection("ApiKeys"))
    .ValidateDataAnnotations()
    .ValidateOnStart();

// Or custom validation
builder.Services.AddOptions<ApiKeySettings>()
    .Bind(builder.Configuration.GetSection("ApiKeys"))
    .Validate(settings =>
    {
        if (string.IsNullOrEmpty(settings.Stripe))
            return false;
        
        if (!settings.Stripe.StartsWith("sk_"))
            return false;
        
        return true;
    }, "Invalid Stripe API key format")
    .ValidateOnStart();

// Using IValidateOptions
public class ApiKeySettingsValidator : IValidateOptions<ApiKeySettings>
{
    public ValidateOptionsResult Validate(string name, ApiKeySettings options)
    {
        var errors = new List<string>();
        
        if (string.IsNullOrWhiteSpace(options.Stripe))
            errors.Add("Stripe API key is required");
        
        if (!options.Stripe.StartsWith("sk_"))
            errors.Add("Stripe API key must start with 'sk_'");
        
        if (errors.Any())
            return ValidateOptionsResult.Fail(errors);
        
        return ValidateOptionsResult.Success;
    }
}

// Register validator
builder.Services.AddSingleton<IValidateOptions<ApiKeySettings>, 
    ApiKeySettingsValidator>();
```

### Environment-Specific Configuration

```csharp
// Program.cs - automatically loads environment-specific files
var builder = WebApplication.CreateBuilder(args);

// Loads in this order:
// 1. appsettings.json
// 2. appsettings.{Environment}.json
//    - Development: appsettings.Development.json
//    - Staging: appsettings.Staging.json
//    - Production: appsettings.Production.json

// Check current environment
var environment = builder.Environment.EnvironmentName;
Console.WriteLine($"Environment: {environment}");

// Conditional configuration
if (builder.Environment.IsDevelopment())
{
    // Development-specific configuration
    builder.Configuration.AddUserSecrets<Program>();
}
else if (builder.Environment.IsProduction())
{
    // Production-specific configuration
    // (Add Key Vault here - covered in next lesson)
}
```

### appsettings Structure

```json
// appsettings.json (committed to Git - no secrets!)
{
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft.AspNetCore": "Warning"
    }
  },
  "AllowedHosts": "*",
  "ConnectionStrings": {
    "DefaultConnection": ""  // Empty placeholder
  },
  "ApiKeys": {
    "Stripe": "",
    "SendGrid": ""
  },
  "Features": {
    "EnableCaching": true,
    "MaxUploadSizeMB": 10
  }
}

// appsettings.Development.json (can be committed - no production secrets)
{
  "Logging": {
    "LogLevel": {
      "Default": "Debug"
    }
  },
  "ConnectionStrings": {
    "DefaultConnection": "Server=localhost;Database=MyApp_Dev"
  }
  // Real secrets come from User Secrets, not here
}

// appsettings.Production.json (NOT committed!)
// This file is generated during deployment or loaded from environment
```

### Loading Configuration from Multiple Sources

```csharp
var builder = WebApplication.CreateBuilder(args);

// Add custom configuration sources
builder.Configuration
    .AddJsonFile("appsettings.json", optional: false, reloadOnChange: true)
    .AddJsonFile($"appsettings.{builder.Environment.EnvironmentName}.json", 
        optional: true, reloadOnChange: true)
    .AddEnvironmentVariables(prefix: "MYAPP_") // Only load env vars with MYAPP_ prefix
    .AddCommandLine(args);

// Custom configuration from external file
if (File.Exists("/etc/myapp/config.json"))
{
    builder.Configuration.AddJsonFile("/etc/myapp/config.json");
}
```

### Configuration Best Practices

```csharp
// ✅ DO: Use IConfiguration interface
public class MyService
{
    public MyService(IConfiguration configuration)
    {
        var apiKey = configuration["ApiKeys:Stripe"];
    }
}

// ✅ DO: Use strongly-typed options
public class MyService
{
    public MyService(IOptions<ApiKeySettings> options)
    {
        var apiKey = options.Value.Stripe;
    }
}

// ✅ DO: Validate configuration at startup
builder.Services.AddOptions<ApiKeySettings>()
    .Bind(builder.Configuration.GetSection("ApiKeys"))
    .ValidateDataAnnotations()
    .ValidateOnStart();

// ✅ DO: Provide defaults for optional settings
var timeout = int.Parse(configuration["Timeout"] ?? "30");

// ❌ DON'T: Access configuration directly everywhere
// Use dependency injection instead

// ❌ DON'T: Store secrets in appsettings.json
// Use User Secrets, environment variables, or Key Vault

// ❌ DON'T: Commit environment-specific files with secrets
// Only commit template files
```

### Testing Configuration

```csharp
[TestClass]
public class ConfigurationTests
{
    [TestMethod]
    public void Configuration_ShouldLoadApiKeys()
    {
        // Arrange
        var configuration = new ConfigurationBuilder()
            .AddInMemoryCollection(new Dictionary<string, string>
            {
                ["ApiKeys:Stripe"] = "sk_test_123",
                ["ApiKeys:SendGrid"] = "SG.test"
            })
            .Build();
        
        var options = Options.Create(new ApiKeySettings
        {
            Stripe = configuration["ApiKeys:Stripe"],
            SendGrid = configuration["ApiKeys:SendGrid"]
        });
        
        // Act
        var service = new PaymentService(options);
        
        // Assert
        Assert.IsNotNull(service);
    }
    
    [TestMethod]
    public void Configuration_ShouldValidateRequiredSettings()
    {
        // Arrange
        var services = new ServiceCollection();
        var configuration = new ConfigurationBuilder()
            .AddInMemoryCollection(new Dictionary<string, string>
            {
                ["ApiKeys:Stripe"] = "" // Invalid - empty
            })
            .Build();
        
        services.AddOptions<ApiKeySettings>()
            .Bind(configuration.GetSection("ApiKeys"))
            .ValidateDataAnnotations()
            .ValidateOnStart();
        
        // Act & Assert
        Assert.ThrowsException<OptionsValidationException>(() =>
        {
            var provider = services.BuildServiceProvider();
            provider.GetRequiredService<IOptions<ApiKeySettings>>().Value;
        });
    }
}
```
