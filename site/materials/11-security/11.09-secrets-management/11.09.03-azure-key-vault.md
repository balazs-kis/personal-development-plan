## Introduction

Azure Key Vault is a cloud service for securely storing and accessing secrets, keys, and certificates. It provides centralized secret management with audit logging, access control, and automatic backups. This lesson teaches you how to integrate Azure Key Vault into your .NET applications using Managed Identity for secure, credential-free authentication.

**Key principle:** Use Managed Identity to access Key Vault - never store Key Vault credentials in your application.

## Key Concepts Summary

### What is Azure Key Vault?

```
Azure Key Vault is a centralized cloud service for:
- Secrets: API keys, passwords, connection strings
- Keys: Cryptographic keys for encryption/decryption
- Certificates: SSL/TLS certificates

Benefits:
✅ Centralized secret management
✅ Access control and audit logging
✅ Automatic backups and disaster recovery
✅ Integration with Azure services
✅ Compliance (FIPS 140-2, SOC, PCI DSS)
✅ Secret versioning and rotation
```

### Creating an Azure Key Vault

```bash
# Using Azure CLI
az login

# Create resource group
az group create --name MyResourceGroup --location eastus

# Create Key Vault
az keyvault create \
  --name MyUniqueKeyVault \
  --resource-group MyResourceGroup \
  --location eastus

# Add a secret
az keyvault secret set \
  --vault-name MyUniqueKeyVault \
  --name "ConnectionString" \
  --value "Server=...;Password=..."

# List secrets
az keyvault secret list --vault-name MyUniqueKeyVault

# Get secret value
az keyvault secret show \
  --vault-name MyUniqueKeyVault \
  --name "ConnectionString"
```

### Integrating Key Vault with .NET Configuration

```csharp
// Program.cs
using Azure.Identity;
using Azure.Security.KeyVault.Secrets;

var builder = WebApplication.CreateBuilder(args);

// Add Azure Key Vault to configuration
if (!builder.Environment.IsDevelopment())
{
    var keyVaultUrl = builder.Configuration["KeyVaultUrl"];
    
    // Use DefaultAzureCredential (works with Managed Identity)
    builder.Configuration.AddAzureKeyVault(
        new Uri(keyVaultUrl),
        new DefaultAzureCredential());
}

// Now all Key Vault secrets are available through IConfiguration
var app = builder.Build();

// Access secrets
var connectionString = builder.Configuration["ConnectionString"];
var apiKey = builder.Configuration["ApiKeys--Stripe"]; // Note: -- replaces :
```

### Direct Access to Key Vault (Not Using Configuration)

```csharp
using Azure.Identity;
using Azure.Security.KeyVault.Secrets;

public class SecretService
{
    private readonly SecretClient _secretClient;
    
    public SecretService(IConfiguration configuration)
    {
        var keyVaultUrl = configuration["KeyVaultUrl"];
        _secretClient = new SecretClient(
            new Uri(keyVaultUrl),
            new DefaultAzureCredential());
    }
    
    public async Task<string> GetSecretAsync(string secretName)
    {
        try
        {
            KeyVaultSecret secret = await _secretClient.GetSecretAsync(secretName);
            return secret.Value;
        }
        catch (Azure.RequestFailedException ex)
        {
            throw new InvalidOperationException(
                $"Failed to retrieve secret '{secretName}' from Key Vault", ex);
        }
    }
    
    public async Task SetSecretAsync(string secretName, string secretValue)
    {
        await _secretClient.SetSecretAsync(secretName, secretValue);
    }
    
    public async Task<IEnumerable<string>> ListSecretNamesAsync()
    {
        var secretNames = new List<string>();
        
        await foreach (var secretProperties in _secretClient.GetPropertiesOfSecretsAsync())
        {
            secretNames.Add(secretProperties.Name);
        }
        
        return secretNames;
    }
}

// Register service
builder.Services.AddSingleton<SecretService>();
```

### Working with Secret Versions

```csharp
public class VersionedSecretService
{
    private readonly SecretClient _secretClient;
    
    public VersionedSecretService(SecretClient secretClient)
    {
        _secretClient = secretClient;
    }
    
    // Get latest version
    public async Task<string> GetLatestSecretAsync(string secretName)
    {
        KeyVaultSecret secret = await _secretClient.GetSecretAsync(secretName);
        return secret.Value;
    }
    
    // Get specific version
    public async Task<string> GetSecretVersionAsync(string secretName, string version)
    {
        KeyVaultSecret secret = await _secretClient.GetSecretAsync(secretName, version);
        return secret.Value;
    }
    
    // List all versions
    public async Task<List<SecretVersion>> GetSecretVersionsAsync(string secretName)
    {
        var versions = new List<SecretVersion>();
        
        await foreach (var properties in _secretClient.GetPropertiesOfSecretVersionsAsync(secretName))
        {
            versions.Add(new SecretVersion
            {
                Version = properties.Version,
                CreatedOn = properties.CreatedOn,
                Enabled = properties.Enabled
            });
        }
        
        return versions;
    }
    
    // Update secret (creates new version)
    public async Task<string> UpdateSecretAsync(string secretName, string newValue)
    {
        KeyVaultSecret secret = await _secretClient.SetSecretAsync(secretName, newValue);
        return secret.Properties.Version;
    }
}

public class SecretVersion
{
    public string Version { get; set; }
    public DateTimeOffset? CreatedOn { get; set; }
    public bool? Enabled { get; set; }
}
```

### Secret Naming Conventions in Key Vault

```csharp
// Key Vault secret names must match: ^[0-9a-zA-Z-]+$
// Can only contain: alphanumeric characters and hyphens

// ❌ BAD: Won't work in Key Vault
"ConnectionStrings:DefaultConnection"
"ApiKeys.Stripe"
"Settings/Database/Host"

// ✅ GOOD: Valid Key Vault names
"ConnectionStrings--DefaultConnection"
"ApiKeys--Stripe"
"Settings--Database--Host"

// When loaded into IConfiguration, -- is converted to :
// ConnectionStrings--DefaultConnection → ConnectionStrings:DefaultConnection
```

### Caching Secrets from Key Vault

```csharp
public class CachedSecretService
{
    private readonly SecretClient _secretClient;
    private readonly IMemoryCache _cache;
    private readonly TimeSpan _cacheExpiration = TimeSpan.FromMinutes(5);
    
    public CachedSecretService(SecretClient secretClient, IMemoryCache cache)
    {
        _secretClient = secretClient;
        _cache = cache;
    }
    
    public async Task<string> GetSecretAsync(string secretName)
    {
        // Check cache first
        if (_cache.TryGetValue(secretName, out string cachedValue))
        {
            return cachedValue;
        }
        
        // Retrieve from Key Vault
        KeyVaultSecret secret = await _secretClient.GetSecretAsync(secretName);
        
        // Cache for 5 minutes
        _cache.Set(secretName, secret.Value, _cacheExpiration);
        
        return secret.Value;
    }
    
    public void ClearCache()
    {
        // Clear cache when secrets are rotated
        if (_cache is MemoryCache memCache)
        {
            memCache.Compact(1.0);
        }
    }
}
```

### Access Policy vs RBAC

```csharp
// Two ways to grant access to Key Vault:

// 1. Access Policies (Classic)
// Portal → Key Vault → Access policies → Add Access Policy
// - Choose permissions (Get, List, Set, Delete)
// - Select principal (user, app, managed identity)

// 2. Azure RBAC (Recommended)
// Portal → Key Vault → Access control (IAM) → Add role assignment
// - Key Vault Secrets User: Read secrets
// - Key Vault Secrets Officer: Full secret management
// - Key Vault Administrator: Full vault management

// Enable RBAC:
// Portal → Key Vault → Access policies → 
// Permission model → Azure role-based access control
```

### Best Practices

```csharp
// ✅ DO: Use Managed Identity
builder.Configuration.AddAzureKeyVault(
    new Uri(keyVaultUrl),
    new DefaultAzureCredential());

// ✅ DO: Use different Key Vaults per environment
var keyVaultUrl = environment switch
{
    "Development" => "https://dev-vault.vault.azure.net/",
    "Staging" => "https://staging-vault.vault.azure.net/",
    "Production" => "https://prod-vault.vault.azure.net/",
    _ => throw new InvalidOperationException("Unknown environment")
};

// ✅ DO: Enable soft delete and purge protection
// These prevent accidental deletion

// ✅ DO: Use RBAC instead of access policies
// More granular control and better integration with Azure AD

// ✅ DO: Cache secrets appropriately
// Reduce Key Vault requests, but not too long for rotation

// ✅ DO: Monitor Key Vault access
// Enable diagnostic logging and set up alerts

// ❌ DON'T: Store Key Vault credentials in your app
// Use Managed Identity instead

// ❌ DON'T: Use the same Key Vault for all environments
// Separate vaults provide better isolation

// ❌ DON'T: Give broad permissions
// Follow principle of least privilege

// ❌ DON'T: Disable soft delete in production
// Protects against accidental deletion
```

### Complete Example

```csharp
// Program.cs
var builder = WebApplication.CreateBuilder(args);

// Configure Key Vault
if (!builder.Environment.IsDevelopment())
{
    var keyVaultUrl = builder.Configuration["KeyVaultUrl"];
    builder.Configuration.AddAzureKeyVault(
        new Uri(keyVaultUrl),
        new DefaultAzureCredential());
}

// Register Secret Service
builder.Services.AddSingleton(sp =>
{
    var config = sp.GetRequiredService<IConfiguration>();
    var keyVaultUrl = config["KeyVaultUrl"];
    return new SecretClient(
        new Uri(keyVaultUrl),
        new DefaultAzureCredential());
});
builder.Services.AddSingleton<SecretService>();

builder.Services.AddControllers();
builder.Services.AddMemoryCache();

var app = builder.Build();

app.UseHttpsRedirection();
app.UseAuthorization();
app.MapControllers();

app.Run();

// Controller using secrets
[ApiController]
[Route("api/[controller]")]
public class PaymentsController : ControllerBase
{
    private readonly SecretService _secretService;
    
    public PaymentsController(SecretService secretService)
    {
        _secretService = secretService;
    }
    
    [HttpPost]
    public async Task<IActionResult> ProcessPayment([FromBody] PaymentRequest request)
    {
        // Get Stripe API key from Key Vault
        var stripeKey = await _secretService.GetSecretAsync("ApiKeys--Stripe");
        
        // Use key to process payment
        // ...
        
        return Ok(new { status = "success" });
    }
}
```
