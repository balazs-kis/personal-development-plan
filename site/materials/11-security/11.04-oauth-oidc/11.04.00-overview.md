# Chapter 11.4: OAuth 2.0 and OpenID Connect

## Overview
Master OAuth 2.0 for authorization and OpenID Connect for authentication: flows, tokens, scopes, and secure implementation patterns.

## Key Concepts
- **OAuth 2.0 Grant Types:** Understanding authorization code, client credentials, and deprecated flows.
- **Authorization Code Flow with PKCE:** The secure modern standard for authentication.
- **OpenID Connect Basics:** Authentication layer built on OAuth 2.0.
- **Access Tokens vs ID Tokens:** Understanding their different purposes and uses.
- **Token Validation:** Security checklist for proper token handling.
