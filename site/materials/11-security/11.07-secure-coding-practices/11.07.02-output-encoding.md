# Lesson 2: Output Encoding and XSS Prevention

## Learning Objectives

By the end of this lesson, you will be able to:
- Understand how Cross-Site Scripting (XSS) attacks work
- Apply context-specific output encoding in different scenarios
- Use ASP.NET Core's built-in encoding mechanisms
- Implement HTML, JavaScript, and URL encoding appropriately
- Recognize when to use encoding vs validation

---

## Introduction

Output encoding is a defensive technique that translates special characters into safe equivalents before content reaches the target system. Even with perfect input validation, output encoding is essential because data can come from multiple sources (databases, APIs, other users) and contexts change (HTML, JavaScript, URLs). This lesson teaches you how to prevent XSS attacks through proper encoding.

**Key principle:** Encode output based on the context where it will be used. HTML encoding is different from JavaScript encoding, which differs from URL encoding.

## Key Concepts Summary

### How XSS Works

```csharp
// Vulnerable code (don't do this)
public IActionResult Search(string query)
{
    // User enters: <script>alert('XSS')</script>
    // Without encoding, this executes in the browser
    ViewBag.SearchTerm = query;
    return View();
}

// In View (vulnerable):
<h2>Results for: @Html.Raw(ViewBag.SearchTerm)</h2>
// Renders: <h2>Results for: <script>alert('XSS')</script></h2>
```

### Razor Automatic Encoding

```cshtml
@* Razor automatically HTML-encodes @ expressions *@
<h2>Welcome, @Model.Username</h2>

@* If Username is "<script>alert('xss')</script>" *@
@* Razor renders it as: &lt;script&gt;alert('xss')&lt;/script&gt; *@
@* Browser displays it as text, doesn't execute it *@
```

### HTML Encoding

```csharp
using System.Text.Encodings.Web;

public class CommentService
{
    private readonly HtmlEncoder _htmlEncoder;
    
    public CommentService(HtmlEncoder htmlEncoder)
    {
        _htmlEncoder = htmlEncoder;
    }
    
    public string SanitizeComment(string userComment)
    {
        // Encode special HTML characters
        return _htmlEncoder.Encode(userComment);
        // "<script>alert('xss')</script>" becomes
        // "&lt;script&gt;alert(&quot;xss&quot;)&lt;/script&gt;"
    }
}
```

### JavaScript Context Encoding

```cshtml
@inject JavaScriptEncoder JsEncoder

<script>
    // BAD: HTML encoding isn't enough for JavaScript context
    var username = "@Model.Username";  // Vulnerable
    
    // GOOD: Use JavaScript encoder
    var username = "@JsEncoder.Encode(Model.Username)";
    
    // If Username contains: "; alert('xss'); var x="
    // JS Encoder produces: \u0022; alert(\u0027xss\u0027); var x\u003d\u0022
</script>
```

### URL Encoding

```csharp
using System.Web;

public class RedirectService
{
    public string BuildRedirectUrl(string returnUrl, string message)
    {
        // BAD: Not encoding query parameters
        // return $"/home?redirect={returnUrl}&msg={message}";
        
        // GOOD: URL encode query parameters
        var encodedUrl = HttpUtility.UrlEncode(returnUrl);
        var encodedMsg = HttpUtility.UrlEncode(message);
        return $"/home?redirect={encodedUrl}&msg={encodedMsg}";
    }
}

// In Razor views:
<a href="/search?q=@Uri.EscapeDataString(Model.SearchQuery)">Search</a>
```

### Context-Specific Encoding Summary

```csharp
public class EncodingExamples
{
    private readonly HtmlEncoder _htmlEncoder;
    private readonly JavaScriptEncoder _jsEncoder;
    private readonly UrlEncoder _urlEncoder;
    
    public EncodingExamples(
        HtmlEncoder htmlEncoder,
        JavaScriptEncoder jsEncoder,
        UrlEncoder urlEncoder)
    {
        _htmlEncoder = htmlEncoder;
        _jsEncoder = jsEncoder;
        _urlEncoder = urlEncoder;
    }
    
    public string GetEncodedValues(string userInput)
    {
        // HTML context: <div>userInput</div>
        var htmlEncoded = _htmlEncoder.Encode(userInput);
        
        // JavaScript context: var x = "userInput";
        var jsEncoded = _jsEncoder.Encode(userInput);
        
        // URL context: /search?q=userInput
        var urlEncoded = _urlEncoder.Encode(userInput);
        
        return $"HTML: {htmlEncoded}, JS: {jsEncoded}, URL: {urlEncoded}";
    }
}
```

### When NOT to Encode (Using Html.Raw)

```cshtml
@* DANGEROUS: Only use Html.Raw with trusted, sanitized content *@
@{
    // Content from CMS that's already been sanitized by a library like HtmlSanitizer
    var trustedHtml = GetSanitizedContentFromCMS();
}
<div>@Html.Raw(trustedHtml)</div>

@* NEVER do this with user input: *@
@* <div>@Html.Raw(Model.UserComment)</div> // VULNERABLE! *@
```

### HTML Sanitization for Rich Text

```csharp
// Use a library like HtmlSanitizer for rich text input
using Ganss.Xss;

public class RichTextService
{
    public string SanitizeHtml(string userHtml)
    {
        var sanitizer = new HtmlSanitizer();
        
        // Configure allowed tags and attributes
        sanitizer.AllowedTags.Clear();
        sanitizer.AllowedTags.Add("p");
        sanitizer.AllowedTags.Add("strong");
        sanitizer.AllowedTags.Add("em");
        sanitizer.AllowedTags.Add("ul");
        sanitizer.AllowedTags.Add("ol");
        sanitizer.AllowedTags.Add("li");
        
        // Remove all JavaScript and dangerous attributes
        return sanitizer.Sanitize(userHtml);
    }
}
```

### Tag Helpers Encode Automatically

```cshtml
@* Tag helpers automatically encode attribute values *@
<input asp-for="Username" />
<a asp-route-id="@Model.Id" asp-route-name="@Model.Name">Link</a>

@* Even if Model.Name contains special characters, they're encoded *@
```
