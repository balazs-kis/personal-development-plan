# Chapter 11.8: Cryptography for Developers

## Overview
This chapter covers applied cryptography from a developer's perspective. Rather than diving into mathematical foundations, we focus on understanding what cryptographic tools are available, when to use each one, and how to implement them correctly in .NET. The goal is to help you make informed decisions about cryptography without becoming a cryptographer.

## Key Concepts
- **Symmetric Encryption (AES):** Fast encryption using shared keys for bulk data protection.
- **Asymmetric Encryption (RSA):** Public-key cryptography for secure key exchange and digital signatures.
- **Cryptographic Hashing:** One-way functions for data integrity and verification.
- **Digital Signatures:** Proving authenticity and non-repudiation using certificates.
- **TLS/HTTPS:** Understanding transport layer security and proper certificate configuration.
