## Introduction

Symmetric encryption uses a single shared key for both encryption and decryption, making it fast and efficient for encrypting large amounts of data. AES (Advanced Encryption Standard) is the gold standard for symmetric encryption and is the algorithm you should use in modern applications. This lesson teaches you how to implement AES correctly in .NET.

**Key principle:** Never roll your own crypto. Use established libraries and follow best practices for key management, IV generation, and cipher modes.

## Key Concepts Summary

### What is Symmetric Encryption?

Symmetric encryption uses the **same key** for both encryption and decryption. It's fast and efficient for large amounts of data, but requires secure key distribution between parties.

```
Plaintext → [Encrypt with Key] → Ciphertext
Ciphertext → [Decrypt with Same Key] → Plaintext
```

### AES Basics

```csharp
using System.Security.Cryptography;

// AES supports key sizes: 128, 192, or 256 bits (16, 24, or 32 bytes)
// Block size is always 128 bits (16 bytes)
// Initialization Vector (IV) is always 16 bytes

using var aes = Aes.Create();
aes.KeySize = 256; // Use 256-bit keys for maximum security
aes.GenerateKey(); // Creates a random 32-byte key
aes.GenerateIV();  // Creates a random 16-byte IV

// Key and IV are now available
byte[] key = aes.Key;
byte[] iv = aes.IV;
```

### Encrypting Data

```csharp
public static byte[] EncryptString(string plainText, byte[] key, byte[] iv)
{
    using var aes = Aes.Create();
    aes.Key = key;
    aes.IV = iv;
    
    // Create encryptor
    var encryptor = aes.CreateEncryptor(aes.Key, aes.IV);
    
    using var msEncrypt = new MemoryStream();
    using var csEncrypt = new CryptoStream(msEncrypt, encryptor, CryptoStreamMode.Write);
    using (var swEncrypt = new StreamWriter(csEncrypt))
    {
        // Write plaintext to the stream
        swEncrypt.Write(plainText);
    }
    
    return msEncrypt.ToArray();
}
```

### Decrypting Data

```csharp
public static string DecryptString(byte[] cipherText, byte[] key, byte[] iv)
{
    using var aes = Aes.Create();
    aes.Key = key;
    aes.IV = iv;
    
    // Create decryptor
    var decryptor = aes.CreateDecryptor(aes.Key, aes.IV);
    
    using var msDecrypt = new MemoryStream(cipherText);
    using var csDecrypt = new CryptoStream(msDecrypt, decryptor, CryptoStreamMode.Read);
    using var srDecrypt = new StreamReader(csDecrypt);
    
    // Read decrypted bytes and convert to string
    return srDecrypt.ReadToEnd();
}
```

### Complete Example with Proper IV Storage

```csharp
public class AesEncryptionService
{
    public static byte[] Encrypt(string plainText, byte[] key)
    {
        using var aes = Aes.Create();
        aes.Key = key;
        aes.GenerateIV(); // Generate random IV for each encryption
        
        var encryptor = aes.CreateEncryptor();
        
        using var msEncrypt = new MemoryStream();
        
        // IMPORTANT: Store IV at the beginning of ciphertext
        msEncrypt.Write(aes.IV, 0, aes.IV.Length);
        
        using (var csEncrypt = new CryptoStream(msEncrypt, encryptor, CryptoStreamMode.Write))
        using (var swEncrypt = new StreamWriter(csEncrypt))
        {
            swEncrypt.Write(plainText);
        }
        
        return msEncrypt.ToArray();
    }
    
    public static string Decrypt(byte[] cipherTextWithIV, byte[] key)
    {
        using var aes = Aes.Create();
        aes.Key = key;
        
        // Extract IV from the beginning of ciphertext
        var iv = new byte[aes.IV.Length];
        Array.Copy(cipherTextWithIV, 0, iv, 0, iv.Length);
        aes.IV = iv;
        
        var decryptor = aes.CreateDecryptor();
        
        using var msDecrypt = new MemoryStream(cipherTextWithIV, iv.Length, cipherTextWithIV.Length - iv.Length);
        using var csDecrypt = new CryptoStream(msDecrypt, decryptor, CryptoStreamMode.Read);
        using var srDecrypt = new StreamReader(csDecrypt);
        
        return srDecrypt.ReadToEnd();
    }
}

// Usage
var key = new byte[32]; // 256-bit key
using (var rng = RandomNumberGenerator.Create())
{
    rng.GetBytes(key); // Generate random key
}

string secret = "My sensitive data";
byte[] encrypted = AesEncryptionService.Encrypt(secret, key);
string decrypted = AesEncryptionService.Decrypt(encrypted, key);
```

### Key Generation Best Practices

```csharp
// ✅ GOOD: Use cryptographically secure random number generator
public static byte[] GenerateKey()
{
    using var aes = Aes.Create();
    aes.GenerateKey();
    return aes.Key;
}

// ✅ GOOD: Derive key from password using PBKDF2
public static byte[] DeriveKeyFromPassword(string password, byte[] salt)
{
    using var pbkdf2 = new Rfc2898DeriveBytes(
        password, 
        salt, 
        iterations: 100000, 
        HashAlgorithmName.SHA256);
    
    return pbkdf2.GetBytes(32); // 256-bit key
}

// ❌ BAD: Never use a password directly as a key
// var key = Encoding.UTF8.GetBytes("mypassword"); // WRONG!
```

### Cipher Modes

```csharp
// Default mode is CBC (Cipher Block Chaining) - good for most uses
aes.Mode = CipherMode.CBC;

// GCM (Galois/Counter Mode) provides authenticated encryption
// Use for sensitive data where tampering detection is critical
// Note: Requires .NET 5+
using var aesGcm = new AesGcm(key);

// ❌ AVOID: ECB mode - does not use IV and reveals patterns
// aes.Mode = CipherMode.ECB; // INSECURE!
```

### Padding

```csharp
// Default padding is PKCS7 - works well for most scenarios
aes.Padding = PaddingMode.PKCS7;

// Alternative: ISO10126 adds random padding
aes.Padding = PaddingMode.ISO10126;

// For stream ciphers or when data is already block-aligned
aes.Padding = PaddingMode.None;
```

### Real-World Example: Encrypting Configuration Data

```csharp
public class SecureConfigurationService
{
    private readonly byte[] _encryptionKey;
    
    public SecureConfigurationService(IConfiguration config)
    {
        // In production, load from secure key storage (Azure Key Vault, etc.)
        var keyBase64 = config["EncryptionKey"];
        _encryptionKey = Convert.FromBase64String(keyBase64);
    }
    
    public string EncryptConnectionString(string connectionString)
    {
        var encrypted = AesEncryptionService.Encrypt(connectionString, _encryptionKey);
        return Convert.ToBase64String(encrypted);
    }
    
    public string DecryptConnectionString(string encryptedConnectionString)
    {
        var encryptedBytes = Convert.FromBase64String(encryptedConnectionString);
        return AesEncryptionService.Decrypt(encryptedBytes, _encryptionKey);
    }
}
```

### Common Pitfalls to Avoid

```csharp
// ❌ BAD: Reusing the same IV
public static byte[] BadEncrypt(string plainText, byte[] key, byte[] iv)
{
    // Using the same IV for multiple encryptions reveals patterns!
    // NEVER do this
    aes.IV = iv; // Same IV every time
}

// ✅ GOOD: Generate new IV for each encryption
public static byte[] GoodEncrypt(string plainText, byte[] key)
{
    using var aes = Aes.Create();
    aes.GenerateIV(); // New random IV each time
}

// ❌ BAD: Not storing the IV
// You must store the IV with the ciphertext to decrypt later

// ❌ BAD: Using weak key derivation
var key = Encoding.UTF8.GetBytes("password123"); // WRONG!

// ✅ GOOD: Use PBKDF2 or similar key derivation function
var key = DeriveKeyFromPassword("password123", salt);

// ❌ BAD: Hardcoding keys in source code
const byte[] key = { 0x01, 0x02, ... }; // NEVER!

// ✅ GOOD: Load keys from secure storage
var key = await keyVault.GetKeyAsync("encryption-key");
```

### Performance Considerations

```csharp
// For encrypting files or large data, use streams directly
public static void EncryptFile(string inputFile, string outputFile, byte[] key, byte[] iv)
{
    using var aes = Aes.Create();
    aes.Key = key;
    aes.IV = iv;
    
    using var inputStream = File.OpenRead(inputFile);
    using var outputStream = File.Create(outputFile);
    using var cryptoStream = new CryptoStream(
        outputStream, 
        aes.CreateEncryptor(), 
        CryptoStreamMode.Write);
    
    inputStream.CopyTo(cryptoStream);
}
```
