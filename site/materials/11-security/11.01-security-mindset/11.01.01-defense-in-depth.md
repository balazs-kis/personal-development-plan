---

## Introduction

Defense in depth is a cybersecurity strategy that uses multiple layers of security controls to protect systems and data. Rather than relying on a single security mechanism, this approach ensures that if one layer is compromised, additional layers continue to provide protection. Think of it as having multiple locked doors rather than just one.

## Key Concepts Summary

### The Seven Layers of Defense in Depth

```
┌─────────────────────────────────────┐
│  1. Physical Security               │  Datacenter access control
├─────────────────────────────────────┤
│  2. Identity & Access               │  Authentication, MFA
├─────────────────────────────────────┤
│  3. Perimeter Security              │  DDoS protection, firewalls
├─────────────────────────────────────┤
│  4. Network Security                │  Segmentation, network policies
├─────────────────────────────────────┤
│  5. Compute Layer                   │  VM security, patch management
├─────────────────────────────────────┤
│  6. Application Layer               │  Secure coding, vulnerability scanning
├─────────────────────────────────────┤
│  7. Data Layer                      │  Encryption, access controls
└─────────────────────────────────────┘
```

### CIA Triad

All defense-in-depth mechanisms support three core security objectives:

```csharp
// Example: Implementing defense in depth in an API endpoint
public class SecureOrderController : ControllerBase
{
    [Authorize] // Layer 1: Authentication
    [RequireRole("OrderManager")] // Layer 2: Authorization
    [RateLimit(100, TimeSpan.FromMinutes(1))] // Layer 3: Rate limiting
    public async Task<IActionResult> GetOrder(int orderId)
    {
        // Layer 4: Input validation
        if (orderId <= 0)
            return BadRequest("Invalid order ID");
        
        // Layer 5: Business logic authorization
        var userId = User.GetUserId();
        if (!await _orderService.UserCanAccessOrder(userId, orderId))
            return Forbid();
        
        // Layer 6: Data access with least privilege
        var order = await _orderService.GetOrderAsync(orderId);
        
        // Layer 7: Data masking/filtering
        return Ok(FilterSensitiveData(order));
    }
}
```

### Why Multiple Layers Matter

1. **Redundancy:** If one control fails, others remain active
2. **Complexity for Attackers:** Each layer adds friction to the attack chain
3. **Detection Opportunities:** Multiple layers increase chances of detecting attacks
4. **Diverse Controls:** Different types of controls defend against different attack vectors
