# Lesson 4: Cryptographic Failures and Sensitive Data

## Learning Objectives

By the end of this lesson, you will be able to:
- Understand cryptographic failures and their impact
- Identify sensitive data that requires protection
- Implement proper encryption for data at rest and in transit
- Use secure algorithms and avoid deprecated cryptographic methods
- Properly manage cryptographic keys and certificates

---

## Introduction

Cryptographic Failures (formerly "Sensitive Data Exposure") ranks #4 in the OWASP Top 10:2025. This category focuses on failures related to cryptography, which often lead to exposure of sensitive data. The issue isn't usually flaws in cryptographic algorithms themselves, but rather how developers implement and use them: weak encryption, missing encryption, poor key management, and insecure protocols.

### What Needs Protection?

```csharp
// Classify your data
public enum DataSensitivity
{
    Public,          // News articles, product info
    Internal,        // Employee directory, org charts
    Confidential,    // Business plans, financial data
    Restricted       // Passwords, SSN, credit cards, health records
}

// Example: Sensitive data that requires encryption
public class Customer
{
    public int Id { get; set; }
    public string Name { get; set; }  // Internal - may not need encryption
    
    [Encrypted]
    public string Email { get; set; }  // Confidential
    
    [Encrypted]
    public string SocialSecurityNumber { get; set; }  // Restricted - must encrypt
    
    [Encrypted]
    public string CreditCardNumber { get; set; }  // Restricted - must encrypt
    
    [PasswordHash]
    public string PasswordHash { get; set; }  // Restricted - hash, don't encrypt
}
```

### Common Cryptographic Failures

```csharp
// 1. BAD: Transmitting sensitive data in cleartext
public class InsecureApiClient
{
    public async Task<User> LoginAsync(string username, string password)
    {
        // Using HTTP (not HTTPS) - credentials sent in plaintext!
        var client = new HttpClient { BaseAddress = new Uri("http://api.example.com") };
        
        var response = await client.PostAsJsonAsync("/login", new { username, password });
        return await response.Content.ReadFromJsonAsync<User>();
    }
}

// GOOD: Always use HTTPS
public class SecureApiClient
{
    public async Task<User> LoginAsync(string username, string password)
    {
        var client = new HttpClient { BaseAddress = new Uri("https://api.example.com") };
        
        var response = await client.PostAsJsonAsync("/login", new { username, password });
        return await response.Content.ReadFromJsonAsync<User>();
    }
}

// 2. BAD: Using weak or deprecated algorithms
public class WeakEncryption
{
    public string Encrypt(string plaintext)
    {
        // DES is broken - only 56-bit key
        using var des = DES.Create();
        // ... encryption code
        return Convert.ToBase64String(ciphertext);
    }
}

// GOOD: Use modern algorithms
public class StrongEncryption
{
    public byte[] Encrypt(string plaintext, byte[] key, byte[] iv)
    {
        // AES-256 is the standard
        using var aes = Aes.Create();
        aes.KeySize = 256;
        aes.Key = key;
        aes.IV = iv;
        aes.Mode = CipherMode.CBC;
        aes.Padding = PaddingMode.PKCS7;
        
        using var encryptor = aes.CreateEncryptor();
        using var ms = new MemoryStream();
        using var cs = new CryptoStream(ms, encryptor, CryptoStreamMode.Write);
        using var writer = new StreamWriter(cs);
        
        writer.Write(plaintext);
        writer.Flush();
        cs.FlushFinalBlock();
        
        return ms.ToArray();
    }
}

// 3. BAD: Hardcoded encryption keys
public class HardcodedKeyEncryption
{
    private const string KEY = "MySecretKey12345"; // NEVER do this!
    
    public string Encrypt(string data)
    {
        // Key is in source code - major vulnerability
        return EncryptWithKey(data, KEY);
    }
}

// GOOD: Use key management services
public class SecureKeyEncryption
{
    private readonly IConfiguration _config;
    
    public async Task<string> EncryptAsync(string data)
    {
        // Retrieve key from Azure Key Vault or AWS KMS
        var key = await _config["KeyVault:EncryptionKey"];
        return EncryptWithKey(data, key);
    }
}
```

### Proper Password Hashing

```csharp
// BAD: Storing passwords in plaintext or using weak hashing
public class InsecurePasswordStorage
{
    public void SavePassword(string username, string password)
    {
        // NEVER store plaintext passwords
        var plaintext = password;
        
        // Also bad: MD5 or SHA-1 (too fast, no salt)
        var md5Hash = MD5.HashData(Encoding.UTF8.GetBytes(password));
        
        _repository.Save(username, Convert.ToBase64String(md5Hash));
    }
}

// GOOD: Use bcrypt, scrypt, or Argon2
public class SecurePasswordStorage
{
    public void SavePassword(string username, string password)
    {
        // Using BCrypt with cost factor (work factor)
        var salt = BCrypt.Net.BCrypt.GenerateSalt(workFactor: 12);
        var hash = BCrypt.Net.BCrypt.HashPassword(password, salt);
        
        _repository.Save(username, hash);
    }
    
    public bool VerifyPassword(string username, string password)
    {
        var storedHash = _repository.GetHash(username);
        return BCrypt.Net.BCrypt.Verify(password, storedHash);
    }
}

// Alternative: Use ASP.NET Core Identity (handles hashing automatically)
public class IdentityPasswordStorage
{
    private readonly UserManager<ApplicationUser> _userManager;
    
    public async Task<IdentityResult> CreateUserAsync(string username, string password)
    {
        var user = new ApplicationUser { UserName = username };
        
        // Identity automatically hashes with PBKDF2
        return await _userManager.CreateAsync(user, password);
    }
    
    public async Task<bool> ValidatePasswordAsync(ApplicationUser user, string password)
    {
        return await _userManager.CheckPasswordAsync(user, password);
    }
}
```

### Data Encryption at Rest

```csharp
// Using ASP.NET Core Data Protection API
public class DataProtectionService
{
    private readonly IDataProtector _protector;
    
    public DataProtectionService(IDataProtectionProvider provider)
    {
        // Create a protector with a specific purpose
        _protector = provider.CreateProtector("CustomerData.SSN");
    }
    
    public string EncryptSensitiveData(string plaintext)
    {
        // Encrypt
        return _protector.Protect(plaintext);
    }
    
    public string DecryptSensitiveData(string ciphertext)
    {
        try
        {
            // Decrypt
            return _protector.Unprotect(ciphertext);
        }
        catch (CryptographicException)
        {
            // Handle decryption failure (key rotation, tampering, etc.)
            throw new SecurityException("Unable to decrypt data");
        }
    }
}
```

### Enforcing HTTPS

```csharp
// Always enforce HTTPS
public class Startup
{
    public void ConfigureServices(IServiceCollection services)
    {
        // Require HTTPS for all requests
        services.AddHttpsRedirection(options =>
        {
            options.RedirectStatusCode = StatusCodes.Status307TemporaryRedirect;
            options.HttpsPort = 443;
        });
        
        // HTTP Strict Transport Security (HSTS)
        services.AddHsts(options =>
        {
            options.MaxAge = TimeSpan.FromDays(365);
            options.IncludeSubDomains = true;
            options.Preload = true;
        });
        
        // Require HTTPS on all controllers
        services.AddControllers(options =>
        {
            options.Filters.Add(new RequireHttpsAttribute());
        });
    }
    
    public void Configure(IApplicationBuilder app, IWebHostEnvironment env)
    {
        if (!env.IsDevelopment())
        {
            app.UseHsts();
        }
        
        app.UseHttpsRedirection();
    }
}
```

### TLS Configuration

```csharp
// Program.cs - Configure Kestrel for secure TLS
public class Program
{
    public static void Main(string[] args)
    {
        CreateHostBuilder(args).Build().Run();
    }

    public static IHostBuilder CreateHostBuilder(string[] args) =>
        Host.CreateDefaultBuilder(args)
            .ConfigureWebHostDefaults(webBuilder =>
            {
                webBuilder.ConfigureKestrel(serverOptions =>
                {
                    serverOptions.ConfigureHttpsDefaults(httpsOptions =>
                    {
                        // Only allow TLS 1.2 and 1.3
                        httpsOptions.SslProtocols = 
                            SslProtocols.Tls12 | SslProtocols.Tls13;
                        
                        // Configure certificate
                        httpsOptions.ServerCertificate = 
                            LoadCertificateFromStore();
                    });
                });
                
                webBuilder.UseStartup<Startup>();
            });
    
    private static X509Certificate2 LoadCertificateFromStore()
    {
        using var store = new X509Store(StoreName.My, StoreLocation.LocalMachine);
        store.Open(OpenFlags.ReadOnly);
        
        var certs = store.Certificates
            .Find(X509FindType.FindByThumbprint, "thumbprint-here", validOnly: true);
        
        return certs[0];
    }
}
```

### Key Management Best Practices

```csharp
// DON'T: Store keys in appsettings.json or source code
// {
//   "EncryptionKey": "MySecretKey123" // NEVER!
// }

// DO: Use Azure Key Vault, AWS KMS, or similar
public class KeyManagementService
{
    private readonly SecretClient _keyVaultClient;
    
    public KeyManagementService(SecretClient keyVaultClient)
    {
        _keyVaultClient = keyVaultClient;
    }
    
    public async Task<byte[]> GetEncryptionKeyAsync(string keyName)
    {
        // Retrieve from Key Vault
        var secret = await _keyVaultClient.GetSecretAsync(keyName);
        return Convert.FromBase64String(secret.Value.Value);
    }
    
    public async Task RotateKeyAsync(string keyName)
    {
        // Generate new key
        var newKey = GenerateRandomKey(32); // 256 bits
        
        // Store new version in Key Vault
        await _keyVaultClient.SetSecretAsync(keyName, 
            Convert.ToBase64String(newKey));
        
        // Re-encrypt data with new key (gradual migration)
        await _dataService.ReencryptWithNewKeyAsync(keyName);
    }
    
    private byte[] GenerateRandomKey(int length)
    {
        using var rng = RandomNumberGenerator.Create();
        var key = new byte[length];
        rng.GetBytes(key);
        return key;
    }
}
```

### Avoid Common Mistakes

```csharp
// Mistake 1: ECB mode (patterns visible in ciphertext)
// BAD
var aes = Aes.Create();
aes.Mode = CipherMode.ECB; // Don't use ECB!

// GOOD: Use CBC or GCM
var aes = Aes.Create();
aes.Mode = CipherMode.CBC; // or CipherMode.GCM

// Mistake 2: Insufficient entropy in random generation
// BAD: Using Random for cryptographic purposes
var random = new Random();
var key = new byte[32];
random.NextBytes(key); // NOT cryptographically secure!

// GOOD: Use RandomNumberGenerator
using var rng = RandomNumberGenerator.Create();
var key = new byte[32];
rng.GetBytes(key); // Cryptographically secure

// Mistake 3: Not validating certificates
// BAD
var handler = new HttpClientHandler
{
    ServerCertificateCustomValidationCallback = (message, cert, chain, errors) => true // Accepts any cert!
};

// GOOD: Validate properly
var handler = new HttpClientHandler
{
    ServerCertificateCustomValidationCallback = (message, cert, chain, errors) =>
    {
        if (errors == SslPolicyErrors.None)
            return true;
        
        // Log the error
        _logger.LogError("Certificate validation failed: {Errors}", errors);
        return false;
    }
};
```
