# Chapter 11.6: Authorization Patterns

## Overview
Implement authorization: role-based access control (RBAC), claims-based authorization, attribute-based access control (ABAC), and policy enforcement.

## Key Concepts
- **RBAC Implementation:** Role-based access control patterns and best practices.
- **Claims-Based Authorization:** Using claims for authorization in .NET applications.
- **Policy-Based Authorization:** Building flexible, testable authorization policies.
- **Resource-Based Authorization:** Authorizing access based on specific resource properties.
- **Centralized vs Distributed Authorization:** Architectural patterns for authorization systems.
