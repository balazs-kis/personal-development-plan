## Introduction

As applications grow, authorization logic becomes complex and scattered. Centralized authorization extracts authorization decisions into a dedicated service, providing consistency, auditability, and easier maintenance. This lesson covers centralized patterns, architectural trade-offs, and comprehensive best practices for building robust authorization systems.

**Key principle:** Centralize authorization policy, distribute enforcement.

## Key Concepts Summary

### Centralized vs Distributed Authorization

```
┌─────────────────────────────────────────────────────┐
│ DISTRIBUTED Authorization (Traditional)             │
├─────────────────────────────────────────────────────┤
│                                                     │
│  Service A: if (user.role == "admin") { allow }     │
│  Service B: if (user.hasPermission("X")) { allow }  │
│  Service C: if (user.dept == resource.dept) { ... }│
│                                                     │
│  ❌ Inconsistent logic across services             │
│  ❌ Hard to audit and update                        │
│  ❌ Duplicated code                                 │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ CENTRALIZED Authorization                           │
├─────────────────────────────────────────────────────┤
│                                                     │
│  ┌───────────────────────────────┐                 │
│  │ Authorization Service (PDP)   │                 │
│  │ - All policies in one place   │                 │
│  │ - Consistent evaluation       │                 │
│  │ - Centralized audit           │                 │
│  └───────────┬───────────────────┘                 │
│              │                                     │
│    ┌─────────┼─────────┐                          │
│    ▼         ▼         ▼                          │
│  Service A Service B Service C                    │
│  (Enforce)  (Enforce)  (Enforce)                  │
│                                                     │
│  ✅ Consistent across services                     │
│  ✅ Single source of truth                         │
│  ✅ Easier to audit and maintain                   │
└─────────────────────────────────────────────────────┘
```

## Centralized Authorization Patterns

### Policy Decision Point (PDP) Pattern

```
┌────────────────────────────────────────────────────┐
│ Components                                         │
├────────────────────────────────────────────────────┤
│ PDP (Policy Decision Point): Evaluates policies   │
│ PEP (Policy Enforcement Point): Enforces decisions│
│ PAP (Policy Administration Point): Manages policies│
│ PIP (Policy Information Point): Provides context  │
└────────────────────────────────────────────────────┘

Flow:
1. Service (PEP) asks: "Can user X do action Y on resource Z?"
2. PDP evaluates policies with context from PIP
3. PDP returns decision: Allow or Deny
4. Service (PEP) enforces the decision
```

### Implementation Example

```csharp
// Authorization service (PDP)
public interface IAuthorizationDecisionService
{
    Task<AuthorizationDecision> EvaluateAsync(AuthorizationRequest request);
}

public class AuthorizationRequest
{
    public string UserId { get; set; }
    public string Action { get; set; }       // "read", "write", "delete"
    public string ResourceType { get; set; } // "document", "project"
    public string ResourceId { get; set; }
    public Dictionary<string, object> Context { get; set; }
}

public class AuthorizationDecision
{
    public bool Allowed { get; set; }
    public string Reason { get; set; }
    public List<string> AppliedPolicies { get; set; }
}

// Centralized authorization service
public class AuthorizationDecisionService : IAuthorizationDecisionService
{
    private readonly IUserService _userService;
    private readonly IResourceService _resourceService;
    private readonly IPolicyEngine _policyEngine;
    private readonly IAuditService _audit;
    
    public async Task<AuthorizationDecision> EvaluateAsync(
        AuthorizationRequest request)
    {
        // Gather context
        var user = await _userService.GetUser(request.UserId);
        var resource = await _resourceService.GetResource(
            request.ResourceType, request.ResourceId);
        
        // Evaluate policies
        var context = new PolicyContext
        {
            User = user,
            Resource = resource,
            Action = request.Action,
            Environment = request.Context
        };
        
        var decision = await _policyEngine.Evaluate(context);
        
        // Audit decision
        await _audit.LogDecision(new AuditRecord
        {
            UserId = request.UserId,
            Action = request.Action,
            ResourceType = request.ResourceType,
            ResourceId = request.ResourceId,
            Decision = decision.Allowed ? "Allow" : "Deny",
            Reason = decision.Reason,
            Timestamp = DateTime.UtcNow
        });
        
        return decision;
    }
}

// Service using authorization (PEP)
public class DocumentController : ControllerBase
{
    private readonly IAuthorizationDecisionService _authService;
    private readonly IDocumentRepository _documentRepo;
    
    [HttpPut("{id}")]
    public async Task<IActionResult> UpdateDocument(
        int id, [FromBody] DocumentUpdate update)
    {
        var userId = User.FindFirst(ClaimTypes.NameIdentifier)?.Value;
        
        // Ask PDP for decision
        var decision = await _authService.EvaluateAsync(new AuthorizationRequest
        {
            UserId = userId,
            Action = "update",
            ResourceType = "document",
            ResourceId = id.ToString(),
            Context = new Dictionary<string, object>
            {
                ["ip_address"] = HttpContext.Connection.RemoteIpAddress?.ToString(),
                ["time"] = DateTime.UtcNow
            }
        });
        
        // Enforce decision
        if (!decision.Allowed)
        {
            return Forbid();
        }
        
        // Process update
        var document = await _documentRepo.GetById(id);
        await _documentRepo.Update(document);
        
        return Ok(document);
    }
}
```

## Authorization Engines

### Open Policy Agent (OPA)

**Policy-as-code approach using Rego language:**

```rego
# policy.rego
package authz

# Default deny
default allow = false

# Allow if user is owner
allow {
    input.user_id == input.resource.owner_id
}

# Allow if user is admin
allow {
    input.user.role == "admin"
}

# Allow if same department and resource is not confidential
allow {
    input.user.department == input.resource.department
    input.resource.classification != "confidential"
}
```

**Using OPA from .NET:**

```csharp
public class OpaAuthorizationService : IAuthorizationDecisionService
{
    private readonly HttpClient _opaClient;
    
    public OpaAuthorizationService(IHttpClientFactory clientFactory)
    {
        _opaClient = clientFactory.CreateClient("OPA");
        _opaClient.BaseAddress = new Uri("http://localhost:8181");
    }
    
    public async Task<AuthorizationDecision> EvaluateAsync(
        AuthorizationRequest request)
    {
        var input = new
        {
            user_id = request.UserId,
            action = request.Action,
            resource = new
            {
                type = request.ResourceType,
                id = request.ResourceId
            }
        };
        
        var response = await _opaClient.PostAsJsonAsync(
            "/v1/data/authz/allow", new { input });
        
        var result = await response.Content.ReadFromJsonAsync<OpaResponse>();
        
        return new AuthorizationDecision
        {
            Allowed = result?.Result ?? false,
            Reason = result?.Result == true ? "Policy matched" : "No policy matched"
        };
    }
}
```

### Google Zanzibar Pattern

**Graph-based authorization using relationships:**

```
# Zanzibar-style relationships
document:doc123#owner@user:alice
document:doc123#editor@user:bob
document:doc123#viewer@group:engineers

# Checking permissions
Can user:alice write document:doc123?
  → YES (owner can write)

Can user:bob write document:doc123?
  → YES (editor can write)

Can user:charlie (member of group:engineers) view document:doc123?
  → YES (engineers group has viewer permission)
```

**Implementing Zanzibar-style authorization:**

```csharp
public class RelationshipTuple
{
    public string ObjectType { get; set; }     // "document"
    public string ObjectId { get; set; }       // "doc123"
    public string Relation { get; set; }       // "owner", "editor", "viewer"
    public string SubjectType { get; set; }    // "user", "group"
    public string SubjectId { get; set; }      // "alice", "engineers"
}

public class ZanzibarStyleAuthz
{
    private readonly List<RelationshipTuple> _tuples;
    
    public async Task<bool> Check(
        string userId, string permission, string objectType, string objectId)
    {
        // Direct relationship check
        var directRelation = _tuples.FirstOrDefault(t =>
            t.ObjectType == objectType &&
            t.ObjectId == objectId &&
            CanPerform(t.Relation, permission) &&
            t.SubjectType == "user" &&
            t.SubjectId == userId);
        
        if (directRelation != null)
            return true;
        
        // Group membership check
        var userGroups = await GetUserGroups(userId);
        
        foreach (var group in userGroups)
        {
            var groupRelation = _tuples.FirstOrDefault(t =>
                t.ObjectType == objectType &&
                t.ObjectId == objectId &&
                CanPerform(t.Relation, permission) &&
                t.SubjectType == "group" &&
                t.SubjectId == group);
            
            if (groupRelation != null)
                return true;
        }
        
        return false;
    }
    
    private bool CanPerform(string relation, string permission)
    {
        // Define what each relation can do
        var permissions = new Dictionary<string, List<string>>
        {
            ["owner"] = new() { "read", "write", "delete", "share" },
            ["editor"] = new() { "read", "write" },
            ["viewer"] = new() { "read" }
        };
        
        return permissions.TryGetValue(relation, out var allowed) &&
               allowed.Contains(permission);
    }
}
```

## Authorization Best Practices

### 1. Principle of Least Privilege

```csharp
// ❌ BAD: Overly permissive default
public class DefaultPolicy
{
    public bool Evaluate(User user, Resource resource)
    {
        // Default allow - DANGEROUS!
        return true;
    }
}

// ✅ GOOD: Deny by default
public class SecureDefaultPolicy
{
    public bool Evaluate(User user, Resource resource)
    {
        // Default deny - explicitly grant access
        return false;
    }
}
```

### 2. Fail Securely

```csharp
public async Task<AuthorizationDecision> EvaluateAsync(
    AuthorizationRequest request)
{
    try
    {
        return await _policyEngine.Evaluate(request);
    }
    catch (Exception ex)
    {
        _logger.LogError(ex, "Authorization evaluation failed");
        
        // ✅ GOOD: Fail closed (deny access on error)
        return new AuthorizationDecision
        {
            Allowed = false,
            Reason = "Authorization system error"
        };
        
        // ❌ BAD: Fail open (allow access on error)
        // return new AuthorizationDecision { Allowed = true };
    }
}
```

### 3. Prevent Privilege Escalation

```csharp
// Horizontal privilege escalation check
public async Task<bool> CanAccessUserData(string requestingUserId, string targetUserId)
{
    // ✅ GOOD: Check user can only access their own data
    if (requestingUserId != targetUserId)
    {
        // Unless they're an admin
        var user = await _userService.GetUser(requestingUserId);
        if (!user.IsAdmin)
        {
            _logger.LogWarning(
                "User {RequestingUserId} attempted to access data for {TargetUserId}",
                requestingUserId, targetUserId);
            
            return false;
        }
    }
    
    return true;
}

// Vertical privilege escalation check
public async Task<bool> CanPerformAdminAction(string userId, string action)
{
    var user = await _userService.GetUser(userId);
    
    // ✅ GOOD: Verify role in authoritative source, not just claims
    var hasAdminRole = await _roleService.UserHasRole(userId, "Admin");
    
    if (!hasAdminRole)
    {
        _logger.LogWarning(
            "User {UserId} attempted admin action: {Action}",
            userId, action);
        
        return false;
    }
    
    return true;
}
```

### 4. Comprehensive Auditing

```csharp
public class AuditedAuthorizationService : IAuthorizationDecisionService
{
    private readonly IAuthorizationDecisionService _inner;
    private readonly IAuditService _audit;
    
    public async Task<AuthorizationDecision> EvaluateAsync(
        AuthorizationRequest request)
    {
        var stopwatch = Stopwatch.StartNew();
        
        try
        {
            var decision = await _inner.EvaluateAsync(request);
            
            // Audit successful evaluation
            await _audit.LogAuthorizationDecision(new AuditRecord
            {
                UserId = request.UserId,
                Action = request.Action,
                ResourceType = request.ResourceType,
                ResourceId = request.ResourceId,
                Decision = decision.Allowed ? "Allow" : "Deny",
                Reason = decision.Reason,
                DurationMs = stopwatch.ElapsedMilliseconds,
                Timestamp = DateTime.UtcNow,
                Context = request.Context
            });
            
            return decision;
        }
        catch (Exception ex)
        {
            // Audit evaluation failure
            await _audit.LogAuthorizationFailure(new AuditRecord
            {
                UserId = request.UserId,
                Action = request.Action,
                ResourceType = request.ResourceType,
                ResourceId = request.ResourceId,
                Decision = "Error",
                Reason = ex.Message,
                DurationMs = stopwatch.ElapsedMilliseconds,
                Timestamp = DateTime.UtcNow
            });
            
            throw;
        }
    }
}
```

### 5. Test Authorization Thoroughly

```csharp
// Test positive cases
[Fact]
public async Task Owner_CanDeleteResource()
{
    var decision = await _authService.EvaluateAsync(new AuthorizationRequest
    {
        UserId = "owner123",
        Action = "delete",
        ResourceType = "document",
        ResourceId = "doc456"
    });
    
    Assert.True(decision.Allowed);
}

// Test negative cases
[Fact]
public async Task NonOwner_CannotDeleteResource()
{
    var decision = await _authService.EvaluateAsync(new AuthorizationRequest
    {
        UserId = "user999",
        Action = "delete",
        ResourceType = "document",
        ResourceId = "doc456"
    });
    
    Assert.False(decision.Allowed);
}

// Test boundary cases
[Fact]
public async Task NullUser_DeniesAccess()
{
    var decision = await _authService.EvaluateAsync(new AuthorizationRequest
    {
        UserId = null,
        Action = "read",
        ResourceType = "document",
        ResourceId = "doc456"
    });
    
    Assert.False(decision.Allowed);
}

// Test privilege escalation scenarios
[Fact]
public async Task RegularUser_CannotEscalateToAdmin()
{
    var decision = await _authService.EvaluateAsync(new AuthorizationRequest
    {
        UserId = "user123",
        Action = "assign_role",
        ResourceType = "user",
        ResourceId = "user123",  // Trying to assign role to self
        Context = new Dictionary<string, object>
        {
            ["target_role"] = "Admin"
        }
    });
    
    Assert.False(decision.Allowed);
}
```

## Performance Considerations

### Caching Authorization Decisions

```csharp
public class CachedAuthorizationService : IAuthorizationDecisionService
{
    private readonly IAuthorizationDecisionService _inner;
    private readonly IDistributedCache _cache;
    
    public async Task<AuthorizationDecision> EvaluateAsync(
        AuthorizationRequest request)
    {
        var cacheKey = GenerateCacheKey(request);
        
        var cachedDecision = await _cache.GetStringAsync(cacheKey);
        if (cachedDecision != null)
        {
            return JsonSerializer.Deserialize<AuthorizationDecision>(cachedDecision);
        }
        
        var decision = await _inner.EvaluateAsync(request);
        
        // Cache for short duration (5 minutes)
        await _cache.SetStringAsync(
            cacheKey,
            JsonSerializer.Serialize(decision),
            new DistributedCacheEntryOptions
            {
                AbsoluteExpirationRelativeToNow = TimeSpan.FromMinutes(5)
            });
        
        return decision;
    }
    
    private string GenerateCacheKey(AuthorizationRequest request)
    {
        return $"authz:{request.UserId}:{request.Action}:{request.ResourceType}:{request.ResourceId}";
    }
}
```

**Important:** Cache invalidation is critical when permissions change.

## Migration Strategy

### Gradual Centralization

```csharp
// Phase 1: Dual-mode authorization
public class HybridAuthorizationService : IAuthorizationDecisionService
{
    private readonly ILegacyAuthorizationService _legacy;
    private readonly ICentralizedAuthorizationService _centralized;
    private readonly IFeatureFlagService _featureFlags;
    
    public async Task<AuthorizationDecision> EvaluateAsync(
        AuthorizationRequest request)
    {
        if (await _featureFlags.IsEnabled("centralized_authz"))
        {
            return await _centralized.EvaluateAsync(request);
        }
        
        return await _legacy.EvaluateAsync(request);
    }
}

// Phase 2: Comparison mode
public async Task<AuthorizationDecision> EvaluateAsync(
    AuthorizationRequest request)
{
    var legacyDecision = await _legacy.EvaluateAsync(request);
    var centralizedDecision = await _centralized.EvaluateAsync(request);
    
    // Compare decisions
    if (legacyDecision.Allowed != centralizedDecision.Allowed)
    {
        _logger.LogWarning(
            "Authorization mismatch: Legacy={Legacy}, Centralized={Centralized}",
            legacyDecision.Allowed, centralizedDecision.Allowed);
    }
    
    // Use legacy decision while testing
    return legacyDecision;
}

// Phase 3: Full migration
public async Task<AuthorizationDecision> EvaluateAsync(
    AuthorizationRequest request)
{
    return await _centralized.EvaluateAsync(request);
}
```

## Security Checklist

```
Authorization Security Checklist:

□ Deny by default (fail closed)
□ Principle of least privilege applied
□ All authorization decisions audited
□ Input validation on authorization requests
□ Authorization checks cannot be bypassed
□ Privilege escalation prevented
□ Authorization tested thoroughly
□ Consistent authorization across services
□ Authorization decoupled from authentication
□ Sensitive operations require re-authentication
□ Authorization decisions cached appropriately
□ Cache invalidation on permission changes
□ Authorization errors don't leak information
□ Regular authorization audits performed
□ Stale permissions cleaned up
```
