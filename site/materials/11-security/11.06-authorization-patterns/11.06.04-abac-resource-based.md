## Introduction

Attribute-Based Access Control (ABAC) and resource-based authorization extend beyond simple role checks. ABAC makes authorization decisions based on attributes of the user, resource, action, and environment. Resource-based authorization evaluates specific resource properties. These approaches provide the flexibility needed for complex, dynamic authorization requirements.

**Key principle:** Authorization decisions consider who (user attributes), what (resource attributes), when (environment), and how (action).

## Key Concepts Summary

### Attribute-Based Access Control (ABAC)

ABAC determines access based on attributes of:

```
┌─────────────────────────────────────────────────────┐
│ ABAC Decision Inputs                                │
├─────────────────────────────────────────────────────┤
│                                                     │
│  1. SUBJECT Attributes (User)                       │
│     - Department, Role, Clearance Level             │
│     - Location, Employment Type                     │
│                                                     │
│  2. OBJECT Attributes (Resource)                    │
│     - Owner, Classification, Status                 │
│     - Created Date, Department                      │
│                                                     │
│  3. ACTION Attributes                               │
│     - Read, Write, Delete, Approve                  │
│                                                     │
│  4. ENVIRONMENT Attributes                          │
│     - Time of Day, Location, IP Address             │
│     - Device Type, Network                          │
└─────────────────────────────────────────────────────┘
```

### ABAC vs RBAC

```
RBAC: Can Alice (Editor) edit documents?
  → YES (if Editor role has edit permission)

ABAC: Can Alice edit THIS document?
  → Depends on:
    - Is Alice in same department as document?
    - Is document status "draft"?
    - Is it during business hours?
    - Is Alice the owner or collaborator?
```

## Resource-Based Authorization in ASP.NET Core

### The Problem

Declarative `[Authorize]` attributes can't check resource properties:

```csharp
// ❌ CAN'T DO THIS: Resource not loaded yet
[Authorize(Policy = "CanEditThisDocument")]  
public IActionResult Edit(int id)
{
    // How does policy know about document properties?
}
```

**Solution:** Use imperative authorization with `IAuthorizationService`.

### Basic Resource-Based Authorization

```csharp
public class Document
{
    public int Id { get; set; }
    public string OwnerId { get; set; }
    public string Department { get; set; }
    public string Classification { get; set; }
    public DocumentStatus Status { get; set; }
}

// Requirement
public class CanEditDocumentRequirement : IAuthorizationRequirement { }

// Handler that checks resource properties
public class DocumentEditHandler : 
    AuthorizationHandler<CanEditDocumentRequirement, Document>
{
    protected override Task HandleRequirementAsync(
        AuthorizationHandlerContext context,
        CanEditDocumentRequirement requirement,
        Document document)
    {
        var userId = context.User.FindFirst(ClaimTypes.NameIdentifier)?.Value;
        
        // Check 1: User is owner
        if (document.OwnerId == userId)
        {
            context.Succeed(requirement);
            return Task.CompletedTask;
        }
        
        // Check 2: User is admin
        if (context.User.IsInRole("Admin"))
        {
            context.Succeed(requirement);
            return Task.CompletedTask;
        }
        
        // Check 3: Same department AND document is draft
        var userDept = context.User.FindFirst("department")?.Value;
        if (userDept == document.Department && 
            document.Status == DocumentStatus.Draft)
        {
            context.Succeed(requirement);
        }
        
        return Task.CompletedTask;
    }
}

// Register
services.AddSingleton<IAuthorizationHandler, DocumentEditHandler>();

services.AddAuthorization(options =>
{
    options.AddPolicy("CanEditDocument", policy =>
        policy.Requirements.Add(new CanEditDocumentRequirement()));
});

// Controller usage
public class DocumentController : ControllerBase
{
    private readonly IAuthorizationService _authorizationService;
    private readonly IDocumentRepository _documentRepo;
    
    [HttpPut("{id}")]
    public async Task<IActionResult> Edit(int id, [FromBody] DocumentUpdate update)
    {
        // 1. Load resource first
        var document = await _documentRepo.GetById(id);
        
        if (document == null)
            return NotFound();
        
        // 2. Check authorization with resource
        var authResult = await _authorizationService.AuthorizeAsync(
            User, document, "CanEditDocument");
        
        if (!authResult.Succeeded)
        {
            return Forbid();
        }
        
        // 3. Process edit
        await _documentRepo.Update(document);
        return Ok(document);
    }
}
```

## Complex ABAC Patterns

### Multi-Attribute Authorization

```csharp
public class DocumentAccessRequirement : IAuthorizationRequirement { }

public class DocumentAccessHandler : 
    AuthorizationHandler<DocumentAccessRequirement, Document>
{
    private readonly ITimeService _timeService;
    
    public DocumentAccessHandler(ITimeService timeService)
    {
        _timeService = timeService;
    }
    
    protected override Task HandleRequirementAsync(
        AuthorizationHandlerContext context,
        DocumentAccessRequirement requirement,
        Document document)
    {
        // USER attributes
        var userId = context.User.FindFirst(ClaimTypes.NameIdentifier)?.Value;
        var userDept = context.User.FindFirst("department")?.Value;
        var userClearance = context.User.FindFirst("clearance")?.Value;
        var userLocation = context.User.FindFirst("location")?.Value;
        
        // RESOURCE attributes
        var docOwner = document.OwnerId;
        var docDept = document.Department;
        var docClassification = document.Classification;
        var docLocation = document.Location;
        
        // ENVIRONMENT attributes
        var currentTime = _timeService.GetCurrentTime();
        var isBusinessHours = currentTime.Hour >= 9 && currentTime.Hour < 17;
        
        // DECISION LOGIC
        
        // Rule 1: Owner can always access
        if (userId == docOwner)
        {
            context.Succeed(requirement);
            return Task.CompletedTask;
        }
        
        // Rule 2: Same department + appropriate clearance + business hours
        if (userDept == docDept &&
            HasSufficientClearance(userClearance, docClassification) &&
            isBusinessHours)
        {
            context.Succeed(requirement);
            return Task.CompletedTask;
        }
        
        // Rule 3: Same location + lower classification
        if (userLocation == docLocation &&
            docClassification == "Public")
        {
            context.Succeed(requirement);
            return Task.CompletedTask;
        }
        
        // No rules matched - access denied
        return Task.CompletedTask;
    }
    
    private bool HasSufficientClearance(string userClearance, string docClassification)
    {
        var clearanceLevels = new Dictionary<string, int>
        {
            ["Public"] = 0,
            ["Internal"] = 1,
            ["Confidential"] = 2,
            ["Secret"] = 3,
            ["TopSecret"] = 4
        };
        
        if (!clearanceLevels.TryGetValue(userClearance ?? "Public", out int userLevel) ||
            !clearanceLevels.TryGetValue(docClassification, out int docLevel))
        {
            return false;
        }
        
        return userLevel >= docLevel;
    }
}
```

### Relationship-Based Authorization (ReBAC)

```csharp
public class Project
{
    public int Id { get; set; }
    public string OwnerId { get; set; }
    public List<string> MemberIds { get; set; }
    public List<string> CollaboratorIds { get; set; }
}

public class ProjectAccessRequirement : IAuthorizationRequirement
{
    public ProjectPermission Permission { get; }
    
    public ProjectAccessRequirement(ProjectPermission permission)
    {
        Permission = permission;
    }
}

public enum ProjectPermission
{
    View,
    Edit,
    Delete,
    ManageMembers
}

public class ProjectAccessHandler : 
    AuthorizationHandler<ProjectAccessRequirement, Project>
{
    protected override Task HandleRequirementAsync(
        AuthorizationHandlerContext context,
        ProjectAccessRequirement requirement,
        Project project)
    {
        var userId = context.User.FindFirst(ClaimTypes.NameIdentifier)?.Value;
        
        var isOwner = project.OwnerId == userId;
        var isMember = project.MemberIds.Contains(userId);
        var isCollaborator = project.CollaboratorIds.Contains(userId);
        
        var authorized = requirement.Permission switch
        {
            ProjectPermission.View => isOwner || isMember || isCollaborator,
            ProjectPermission.Edit => isOwner || isMember,
            ProjectPermission.Delete => isOwner,
            ProjectPermission.ManageMembers => isOwner,
            _ => false
        };
        
        if (authorized)
        {
            context.Succeed(requirement);
        }
        
        return Task.CompletedTask;
    }
}

// Usage
[HttpDelete("projects/{id}")]
public async Task<IActionResult> DeleteProject(int id)
{
    var project = await _projectRepo.GetById(id);
    
    var authResult = await _authorizationService.AuthorizeAsync(
        User, project, new ProjectAccessRequirement(ProjectPermission.Delete));
    
    if (!authResult.Succeeded)
        return Forbid();
    
    await _projectRepo.Delete(project);
    return NoContent();
}
```

## Dynamic Authorization Rules

### Rule Engine Pattern

```csharp
public interface IAuthorizationRule<TResource>
{
    string Name { get; }
    Task<bool> EvaluateAsync(ClaimsPrincipal user, TResource resource);
}

public class OwnerRule : IAuthorizationRule<Document>
{
    public string Name => "Owner";
    
    public Task<bool> EvaluateAsync(ClaimsPrincipal user, Document document)
    {
        var userId = user.FindFirst(ClaimTypes.NameIdentifier)?.Value;
        return Task.FromResult(document.OwnerId == userId);
    }
}

public class SameDepartmentRule : IAuthorizationRule<Document>
{
    public string Name => "SameDepartment";
    
    public Task<bool> EvaluateAsync(ClaimsPrincipal user, Document document)
    {
        var userDept = user.FindFirst("department")?.Value;
        return Task.FromResult(userDept == document.Department);
    }
}

public class RuleBasedAuthorizationHandler : 
    AuthorizationHandler<DocumentAccessRequirement, Document>
{
    private readonly IEnumerable<IAuthorizationRule<Document>> _rules;
    private readonly ILogger<RuleBasedAuthorizationHandler> _logger;
    
    public RuleBasedAuthorizationHandler(
        IEnumerable<IAuthorizationRule<Document>> rules,
        ILogger<RuleBasedAuthorizationHandler> logger)
    {
        _rules = rules;
        _logger = logger;
    }
    
    protected override async Task HandleRequirementAsync(
        AuthorizationHandlerContext context,
        DocumentAccessRequirement requirement,
        Document document)
    {
        foreach (var rule in _rules)
        {
            var result = await rule.EvaluateAsync(context.User, document);
            
            if (result)
            {
                _logger.LogInformation(
                    "Authorization succeeded via rule: {RuleName}", rule.Name);
                context.Succeed(requirement);
                return;
            }
        }
        
        _logger.LogWarning("Authorization failed: No rules matched");
    }
}

// Register rules
services.AddSingleton<IAuthorizationRule<Document>, OwnerRule>();
services.AddSingleton<IAuthorizationRule<Document>, SameDepartmentRule>();
services.AddScoped<IAuthorizationHandler, RuleBasedAuthorizationHandler>();
```

## Best Practices

### 1. Cache Resource Lookups

```csharp
// ✅ GOOD: Cache expensive lookups
public class CachedDocumentAccessHandler : 
    AuthorizationHandler<DocumentAccessRequirement, Document>
{
    private readonly IMemoryCache _cache;
    private readonly IDocumentRepository _repo;
    
    protected override async Task HandleRequirementAsync(
        AuthorizationHandlerContext context,
        DocumentAccessRequirement requirement,
        Document document)
    {
        var userId = context.User.FindFirst(ClaimTypes.NameIdentifier)?.Value;
        var cacheKey = $"doc_access_{userId}_{document.Id}";
        
        if (!_cache.TryGetValue(cacheKey, out bool authorized))
        {
            authorized = await EvaluateAccessAsync(context.User, document);
            
            _cache.Set(cacheKey, authorized, TimeSpan.FromMinutes(5));
        }
        
        if (authorized)
        {
            context.Succeed(requirement);
        }
    }
}
```

### 2. Separate Concerns

```csharp
// ✅ GOOD: Separate attribute extraction from logic
public class AttributeExtractor
{
    public UserAttributes GetUserAttributes(ClaimsPrincipal user)
    {
        return new UserAttributes
        {
            UserId = user.FindFirst(ClaimTypes.NameIdentifier)?.Value,
            Department = user.FindFirst("department")?.Value,
            Clearance = user.FindFirst("clearance")?.Value,
            Location = user.FindFirst("location")?.Value
        };
    }
    
    public DocumentAttributes GetDocumentAttributes(Document doc)
    {
        return new DocumentAttributes
        {
            OwnerId = doc.OwnerId,
            Department = doc.Department,
            Classification = doc.Classification,
            Status = doc.Status
        };
    }
}

public class AttributeBasedHandler : 
    AuthorizationHandler<DocumentAccessRequirement, Document>
{
    private readonly AttributeExtractor _extractor;
    private readonly IAuthorizationPolicyEvaluator _evaluator;
    
    protected override Task HandleRequirementAsync(
        AuthorizationHandlerContext context,
        DocumentAccessRequirement requirement,
        Document document)
    {
        var userAttrs = _extractor.GetUserAttributes(context.User);
        var docAttrs = _extractor.GetDocumentAttributes(document);
        
        if (_evaluator.Evaluate(userAttrs, docAttrs))
        {
            context.Succeed(requirement);
        }
        
        return Task.CompletedTask;
    }
}
```

### 3. Audit Authorization Decisions

```csharp
public class AuditedAuthorizationHandler : 
    AuthorizationHandler<DocumentAccessRequirement, Document>
{
    private readonly IAuditService _audit;
    
    protected override async Task HandleRequirementAsync(
        AuthorizationHandlerContext context,
        DocumentAccessRequirement requirement,
        Document document)
    {
        var userId = context.User.FindFirst(ClaimTypes.NameIdentifier)?.Value;
        var authorized = await EvaluateAccessAsync(context.User, document);
        
        // Audit the decision
        await _audit.LogAuthorizationAttempt(new AuthorizationAudit
        {
            UserId = userId,
            ResourceId = document.Id.ToString(),
            ResourceType = "Document",
            Action = "Access",
            Result = authorized ? "Granted" : "Denied",
            Timestamp = DateTime.UtcNow,
            Attributes = new
            {
                UserDepartment = context.User.FindFirst("department")?.Value,
                DocumentDepartment = document.Department,
                DocumentClassification = document.Classification
            }
        });
        
        if (authorized)
        {
            context.Succeed(requirement);
        }
    }
}
```

## Testing Resource-Based Authorization

```csharp
[Fact]
public async Task DocumentOwner_CanEditDocument()
{
    // Arrange
    var document = new Document
    {
        Id = 1,
        OwnerId = "user123",
        Department = "Engineering"
    };
    
    var claims = new[]
    {
        new Claim(ClaimTypes.NameIdentifier, "user123"),
        new Claim("department", "Engineering")
    };
    var user = new ClaimsPrincipal(new ClaimsIdentity(claims));
    
    var requirement = new CanEditDocumentRequirement();
    var handler = new DocumentEditHandler();
    var context = new AuthorizationHandlerContext(
        new[] { requirement }, user, document);
    
    // Act
    await handler.HandleRequirementAsync(context, requirement, document);
    
    // Assert
    Assert.True(context.HasSucceeded);
}

[Fact]
public async Task NonOwner_DifferentDepartment_CannotEditDocument()
{
    // Arrange
    var document = new Document
    {
        Id = 1,
        OwnerId = "user123",
        Department = "Engineering"
    };
    
    var claims = new[]
    {
        new Claim(ClaimTypes.NameIdentifier, "user999"),  // Different user
        new Claim("department", "Marketing")  // Different department
    };
    var user = new ClaimsPrincipal(new ClaimsIdentity(claims));
    
    var requirement = new CanEditDocumentRequirement();
    var handler = new DocumentEditHandler();
    var context = new AuthorizationHandlerContext(
        new[] { requirement }, user, document);
    
    // Act
    await handler.HandleRequirementAsync(context, requirement, document);
    
    // Assert
    Assert.False(context.HasSucceeded);
}
```
