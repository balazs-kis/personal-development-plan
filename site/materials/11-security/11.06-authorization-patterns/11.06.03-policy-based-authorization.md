## Introduction

Policy-based authorization is the foundation of ASP.NET Core's authorization system. It provides a rich, reusable, and testable way to express authorization logic. Policies consist of one or more requirements, and handlers evaluate whether those requirements are met. This approach separates authorization logic from application code, making it easier to test and maintain.

**Key principle:** Authorization policies define what must be true for access to be granted. Handlers determine if those conditions are met.

## Key Concepts Summary

### Policy-Based Authorization Architecture

```
┌────────────────────────────────────────────────────┐
│ Policy-Based Authorization Flow                    │
├────────────────────────────────────────────────────┤
│                                                    │
│  Request → [Authorize] → Policy → Requirements    │
│                             ↓                      │
│                          Handlers                  │
│                             ↓                      │
│                     Succeed / Fail                 │
│                             ↓                      │
│                     Allow / Deny                   │
└────────────────────────────────────────────────────┘
```

**Core components:**
1. **Policy:** Named authorization rules
2. **Requirement:** Condition that must be satisfied
3. **Handler:** Logic to evaluate if requirement is met
4. **Authorization Service:** Orchestrates evaluation

## Creating Authorization Policies

### Simple Policies

```csharp
// Program.cs / Startup.cs
services.AddAuthorization(options =>
{
    // Require authenticated user (built-in)
    options.AddPolicy("AuthenticatedUser", policy =>
        policy.RequireAuthenticatedUser());
    
    // Require specific role
    options.AddPolicy("AdminOnly", policy =>
        policy.RequireRole("Admin"));
    
    // Require specific claim
    options.AddPolicy("EmployeeOnly", policy =>
        policy.RequireClaim("EmployeeId"));
    
    // Require claim with specific value
    options.AddPolicy("HRDepartment", policy =>
        policy.RequireClaim("Department", "HR"));
    
    // Multiple requirements (AND logic)
    options.AddPolicy("SeniorManager", policy =>
        policy.RequireRole("Manager")
              .RequireClaim("Level", "Senior"));
});

// Usage in controller
[Authorize(Policy = "SeniorManager")]
public class ManagementController : Controller
{
    // Only senior managers can access
}
```

### Custom Assertion Policies

```csharp
services.AddAuthorization(options =>
{
    options.AddPolicy("Over18", policy =>
        policy.RequireAssertion(context =>
        {
            var birthDateClaim = context.User.FindFirst("BirthDate");
            if (birthDateClaim == null)
                return false;
            
            if (DateTime.TryParse(birthDateClaim.Value, out DateTime birthDate))
            {
                var age = DateTime.Today.Year - birthDate.Year;
                if (birthDate > DateTime.Today.AddYears(-age))
                    age--;
                
                return age >= 18;
            }
            
            return false;
        }));
    
    options.AddPolicy("WorkingHours", policy =>
        policy.RequireAssertion(context =>
        {
            var now = DateTime.Now;
            return now.Hour >= 9 && now.Hour < 17;  // 9 AM - 5 PM
        }));
});
```

## Custom Requirements and Handlers

### Creating a Custom Requirement

```csharp
// Requirement (defines what must be true)
public class MinimumAgeRequirement : IAuthorizationRequirement
{
    public int MinimumAge { get; }
    
    public MinimumAgeRequirement(int minimumAge)
    {
        MinimumAge = minimumAge;
    }
}

// Handler (evaluates if requirement is met)
public class MinimumAgeHandler : AuthorizationHandler<MinimumAgeRequirement>
{
    protected override Task HandleRequirementAsync(
        AuthorizationHandlerContext context,
        MinimumAgeRequirement requirement)
    {
        var birthDateClaim = context.User.FindFirst("BirthDate");
        
        if (birthDateClaim == null)
        {
            // Requirement not met - don't call Succeed()
            return Task.CompletedTask;
        }
        
        if (DateTime.TryParse(birthDateClaim.Value, out DateTime birthDate))
        {
            var age = CalculateAge(birthDate);
            
            if (age >= requirement.MinimumAge)
            {
                context.Succeed(requirement);  // Requirement met!
            }
        }
        
        return Task.CompletedTask;
    }
    
    private int CalculateAge(DateTime birthDate)
    {
        var age = DateTime.Today.Year - birthDate.Year;
        if (birthDate > DateTime.Today.AddYears(-age))
            age--;
        return age;
    }
}

// Registration
services.AddSingleton<IAuthorizationHandler, MinimumAgeHandler>();

services.AddAuthorization(options =>
{
    options.AddPolicy("Over21", policy =>
        policy.Requirements.Add(new MinimumAgeRequirement(21)));
    
    options.AddPolicy("Over18", policy =>
        policy.Requirements.Add(new MinimumAgeRequirement(18)));
});

// Usage
[Authorize(Policy = "Over21")]
[HttpGet("alcohol")]
public IActionResult AlcoholSection()
{
    return View();
}
```

### Multiple Requirements

```csharp
// Requirements can be combined
services.AddAuthorization(options =>
{
    options.AddPolicy("SeniorEmployeeInHR", policy =>
    {
        policy.Requirements.Add(new MinimumAgeRequirement(30));
        policy.Requirements.Add(new DepartmentRequirement("HR"));
        policy.Requirements.Add(new MinimumTenureRequirement(5));  // 5 years
    });
});

// ALL requirements must succeed for policy to succeed
```

## Dependency Injection in Handlers

### Using Services in Handlers

```csharp
public class DocumentOwnerRequirement : IAuthorizationRequirement { }

public class DocumentOwnerHandler : AuthorizationHandler<DocumentOwnerRequirement>
{
    private readonly IDocumentRepository _documentRepo;
    private readonly ILogger<DocumentOwnerHandler> _logger;
    
    public DocumentOwnerHandler(
        IDocumentRepository documentRepo,
        ILogger<DocumentOwnerHandler> logger)
    {
        _documentRepo = documentRepo;
        _logger = logger;
    }
    
    protected override async Task HandleRequirementAsync(
        AuthorizationHandlerContext context,
        DocumentOwnerRequirement requirement)
    {
        // Get document ID from route data or resource
        if (context.Resource is HttpContext httpContext)
        {
            var docIdString = httpContext.Request.RouteValues["id"]?.ToString();
            
            if (int.TryParse(docIdString, out int documentId))
            {
                var userId = context.User.FindFirst(ClaimTypes.NameIdentifier)?.Value;
                var document = await _documentRepo.GetById(documentId);
                
                if (document != null && document.OwnerId == userId)
                {
                    _logger.LogInformation(
                        "User {UserId} authorized for document {DocId}", 
                        userId, documentId);
                    
                    context.Succeed(requirement);
                }
                else
                {
                    _logger.LogWarning(
                        "User {UserId} denied access to document {DocId}", 
                        userId, documentId);
                }
            }
        }
        
        return;
    }
}

// Register as scoped to use scoped services
services.AddScoped<IAuthorizationHandler, DocumentOwnerHandler>();
```

## Advanced Policy Patterns

### Parameterized Requirements

```csharp
public class MinimumRoleLevel Requirement : IAuthorizationRequirement
{
    public int MinimumLevel { get; }
    
    public MinimumRoleLevelRequirement(int minimumLevel)
    {
        MinimumLevel = minimumLevel;
    }
}

public class MinimumRoleLevelHandler : 
    AuthorizationHandler<MinimumRoleLevelRequirement>
{
    protected override Task HandleRequirementAsync(
        AuthorizationHandlerContext context,
        MinimumRoleLevelRequirement requirement)
    {
        var levelClaim = context.User.FindFirst("RoleLevel");
        
        if (levelClaim != null && 
            int.TryParse(levelClaim.Value, out int userLevel))
        {
            if (userLevel >= requirement.MinimumLevel)
            {
                context.Succeed(requirement);
            }
        }
        
        return Task.CompletedTask;
    }
}

// Register different policies with different parameters
services.AddAuthorization(options =>
{
    options.AddPolicy("Level1Access", policy =>
        policy.Requirements.Add(new MinimumRoleLevelRequirement(1)));
    
    options.AddPolicy("Level3Access", policy =>
        policy.Requirements.Add(new MinimumRoleLevelRequirement(3)));
    
    options.AddPolicy("Level5Access", policy =>
        policy.Requirements.Add(new MinimumRoleLevelRequirement(5)));
});
```

### Multiple Handlers for Same Requirement

```csharp
// Requirement
public class AccessDocumentRequirement : IAuthorizationRequirement { }

// Handler 1: Check if user is document owner
public class DocumentOwnerHandler : 
    AuthorizationHandler<AccessDocumentRequirement>
{
    protected override Task HandleRequirementAsync(
        AuthorizationHandlerContext context,
        AccessDocumentRequirement requirement)
    {
        if (IsDocumentOwner(context))
        {
            context.Succeed(requirement);  // Owner can access
        }
        return Task.CompletedTask;
    }
}

// Handler 2: Check if user is admin
public class AdminHandler : 
    AuthorizationHandler<AccessDocumentRequirement>
{
    protected override Task HandleRequirementAsync(
        AuthorizationHandlerContext context,
        AccessDocumentRequirement requirement)
    {
        if (context.User.IsInRole("Admin"))
        {
            context.Succeed(requirement);  // Admin can access
        }
        return Task.CompletedTask;
    }
}

// Handler 3: Check if document is public
public class PublicDocumentHandler : 
    AuthorizationHandler<AccessDocumentRequirement>
{
    protected override Task HandleRequirementAsync(
        AuthorizationHandlerContext context,
        AccessDocumentRequirement requirement)
    {
        if (IsDocumentPublic(context))
        {
            context.Succeed(requirement);  // Public document accessible
        }
        return Task.CompletedTask;
    }
}

// Register all handlers
services.AddSingleton<IAuthorizationHandler, DocumentOwnerHandler>();
services.AddSingleton<IAuthorizationHandler, AdminHandler>();
services.AddSingleton<IAuthorizationHandler, PublicDocumentHandler>();

// If ANY handler succeeds, the requirement is met (OR logic)
```

## Failing Requirements Explicitly

```csharp
public class BannedUserHandler : AuthorizationHandler<AccessRequirement>
{
    private readonly IUserService _userService;
    
    public BannedUserHandler(IUserService userService)
    {
        _userService = userService;
    }
    
    protected override async Task HandleRequirementAsync(
        AuthorizationHandlerContext context,
        AccessRequirement requirement)
    {
        var userId = context.User.FindFirst(ClaimTypes.NameIdentifier)?.Value;
        
        if (userId != null)
        {
            var user = await _userService.GetUser(userId);
            
            if (user.IsBanned)
            {
                // Explicitly fail - prevents other handlers from succeeding
                context.Fail();
                return;
            }
        }
        
        // Don't call Succeed - let other handlers evaluate
    }
}

// Note: context.Fail() stops all processing and denies access
// Not calling anything allows other handlers to run
```

## Imperative Authorization

### Using IAuthorizationService

```csharp
public class DocumentController : ControllerBase
{
    private readonly IAuthorizationService _authorizationService;
    private readonly IDocumentRepository _documentRepo;
    
    public DocumentController(
        IAuthorizationService authorizationService,
        IDocumentRepository documentRepo)
    {
        _authorizationService = authorizationService;
        _documentRepo = documentRepo;
    }
    
    [HttpGet("{id}")]
    public async Task<IActionResult> GetDocument(int id)
    {
        var document = await _documentRepo.GetById(id);
        
        if (document == null)
            return NotFound();
        
        // Imperative authorization check
        var authResult = await _authorizationService.AuthorizeAsync(
            User, document, "DocumentAccessPolicy");
        
        if (!authResult.Succeeded)
        {
            return Forbid();
        }
        
        return Ok(document);
    }
    
    [HttpPut("{id}")]
    public async Task<IActionResult> UpdateDocument(int id, Document updates)
    {
        var document = await _documentRepo.GetById(id);
        
        if (document == null)
            return NotFound();
        
        // Check edit permission
        var authResult = await _authorizationService.AuthorizeAsync(
            User, document, "DocumentEditPolicy");
        
        if (!authResult.Succeeded)
        {
            // Log why authorization failed
            foreach (var failure in authResult.Failure.FailedRequirements)
            {
                _logger.LogWarning(
                    "Authorization failed: {Requirement}", 
                    failure.GetType().Name);
            }
            
            return Forbid();
        }
        
        // Process update
        await _documentRepo.Update(document);
        return Ok(document);
    }
}
```

```csharp
[Authorize(Policy = "EmployeeOnly")]
public class ProjectController : Controller
```

### Fallback Policies

```csharp
services.AddAuthorization(options =>
{
    // Set global fallback policy
    options.FallbackPolicy = new AuthorizationPolicyBuilder()
        .RequireAuthenticatedUser()
        .Build();
});

// No need for [Authorize] on every controller
```

## Testing Policy-Based Authorization

### Unit Testing Handlers

```csharp
[Fact]
public async Task MinimumAgeHandler_UserOver18_Succeeds()
{
    // Arrange
    var requirement = new MinimumAgeRequirement(18);
    var handler = new MinimumAgeHandler();
    
    var claims = new[]
    {
        new Claim("BirthDate", "1990-01-01")  // Over 18
    };
    var identity = new ClaimsIdentity(claims);
    var user = new ClaimsPrincipal(identity);
    
    var context = new AuthorizationHandlerContext(
        new[] { requirement }, user, null);
    
    // Act
    await handler.HandleRequirementAsync(context, requirement);
    
    // Assert
    Assert.True(context.HasSucceeded);
}

[Fact]
public async Task MinimumAgeHandler_UserUnder18_Fails()
{
    // Arrange
    var requirement = new MinimumAgeRequirement(18);
    var handler = new MinimumAgeHandler();
    
    var claims = new[]
    {
        new Claim("BirthDate", "2010-01-01")  // Under 18
    };
    var identity = new ClaimsIdentity(claims);
    var user = new ClaimsPrincipal(identity);
    
    var context = new AuthorizationHandlerContext(
        new[] { requirement }, user, null);
    
    // Act
    await handler.HandleRequirementAsync(context, requirement);
    
    // Assert
    Assert.False(context.HasSucceeded);
}
```

## Best Practices

### 1. Keep Handlers Focused

```csharp
// ✅ GOOD: Single responsibility
public class MinimumAgeHandler : AuthorizationHandler<MinimumAgeRequirement>
{
    // Only checks age
}

public class DepartmentHandler : AuthorizationHandler<DepartmentRequirement>
{
    // Only checks department
}

// ❌ BAD: Handler doing too much
public class ComplexHandler : AuthorizationHandler<SomeRequirement>
{
    // Checks age, department, role, permissions, etc.
    // Too complex, hard to test
}
```

### 2. Use Dependency Injection

```csharp
// ✅ GOOD: Inject services
public class DocumentOwnerHandler : AuthorizationHandler<OwnerRequirement>
{
    private readonly IDocumentRepository _repo;
    
    public DocumentOwnerHandler(IDocumentRepository repo)
    {
        _repo = repo;
    }
}

// Register with appropriate lifetime
services.AddScoped<IAuthorizationHandler, DocumentOwnerHandler>();
```

### 3. Log Authorization Decisions

```csharp
public class AuditedHandler : AuthorizationHandler<SomeRequirement>
{
    private readonly ILogger<AuditedHandler> _logger;
    
    protected override Task HandleRequirementAsync(
        AuthorizationHandlerContext context,
        SomeRequirement requirement)
    {
        var userId = context.User.FindFirst(ClaimTypes.NameIdentifier)?.Value;
        
        if (IsAuthorized(context))
        {
            _logger.LogInformation(
                "Authorization succeeded for user {UserId}", userId);
            context.Succeed(requirement);
        }
        else
        {
            _logger.LogWarning(
                "Authorization failed for user {UserId}", userId);
        }
        
        return Task.CompletedTask;
    }
}
```

### 4. Make Policies Reusable

```csharp
// ✅ GOOD: Generic, reusable requirements
public class MinimumValueRequirement : IAuthorizationRequirement
{
    public string ClaimType { get; }
    public int MinimumValue { get; }
    
    public MinimumValueRequirement(string claimType, int minimumValue)
    {
        ClaimType = claimType;
        MinimumValue = minimumValue;
    }
}

// Can be used for age, level, clearance, etc.
options.AddPolicy("Over21", policy =>
    policy.Requirements.Add(new MinimumValueRequirement("age", 21)));

options.AddPolicy("Level3", policy =>
    policy.Requirements.Add(new MinimumValueRequirement("level", 3)));
```
