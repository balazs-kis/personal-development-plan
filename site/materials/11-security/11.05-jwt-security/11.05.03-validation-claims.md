## Learning Objectives

By the end of this lesson, you will be able to:
- Implement comprehensive JWT validation
- Understand and validate registered claims (exp, iat, nbf, iss, aud)
- Handle clock skew in distributed systems
- Implement proper error handling for validation failures

---

## Introduction

Creating a JWT is straightforward. Validating it correctly is where most security vulnerabilities occur. Many applications decode JWTs without proper validation, trusting unverified data. This lesson covers the complete validation checklist and how to implement it properly.

**Key principle:** Never trust a JWT until every validation step passes. A single skipped check can compromise your entire security model.

## Key Concepts Summary

### The JWT Validation Checklist

Every JWT must pass ALL of these validations:

```
┌──────────────────────────────────────────────────┐
│ CRITICAL VALIDATIONS (All must pass)            │
├──────────────────────────────────────────────────┤
│ ✓ 1. Token structure is valid (3 parts)         │
│ ✓ 2. Signature is valid                         │
│ ✓ 3. Algorithm matches expected                 │
│ ✓ 4. Issuer (iss) matches expected             │
│ ✓ 5. Audience (aud) matches your application    │
│ ✓ 6. Token has not expired (exp)                │
│ ✓ 7. Token is not used before valid time (nbf)  │
│ ✓ 8. Token ID (jti) not revoked (if using)     │
└──────────────────────────────────────────────────┘

Skip ANY → Security vulnerability
```

## 1. Token Structure Validation

### What to Check

```csharp
public bool ValidateStructure(string jwt)
{
    // Must have exactly 3 parts separated by dots
    var parts = jwt.Split('.');
    
    if (parts.Length != 3)
        return false;
    
    // Each part must be valid Base64Url
    foreach (var part in parts)
    {
        if (!IsValidBase64Url(part))
            return false;
    }
    
    // Header and payload must be valid JSON
    try
    {
        var header = DecodeBase64Url(parts[0]);
        var payload = DecodeBase64Url(parts[1]);
        
        JsonDocument.Parse(header);
        JsonDocument.Parse(payload);
    }
    catch
    {
        return false;
    }
    
    return true;
}
```

## 2. Signature Validation

### Why It's Critical

The signature proves:
1. The token was issued by a trusted party
2. The token hasn't been tampered with

### How to Validate

```csharp
using System.IdentityModel.Tokens.Jwt;
using Microsoft.IdentityModel.Tokens;

public ClaimsPrincipal ValidateSignature(string jwt, SecurityKey key)
{
    var validationParameters = new TokenValidationParameters
    {
        ValidateIssuerSigningKey = true,  // CRITICAL
        IssuerSigningKey = key,
        
        // Temporarily disable other validations to isolate signature check
        ValidateIssuer = false,
        ValidateAudience = false,
        ValidateLifetime = false
    };
    
    var handler = new JwtSecurityTokenHandler();
    
    try
    {
        return handler.ValidateToken(jwt, validationParameters, out _);
    }
    catch (SecurityTokenInvalidSignatureException)
    {
        // Token signature is invalid
        throw;
    }
}
```

## 3. Algorithm Validation

### Why It Matters

Prevents algorithm confusion attacks where attackers change the algorithm to bypass security.

### Implementation

```csharp
var validationParameters = new TokenValidationParameters
{
    ValidateIssuerSigningKey = true,
    IssuerSigningKey = key,
    
    // Whitelist ONLY expected algorithms
    ValidAlgorithms = new[] { SecurityAlgorithms.RsaSha256 },
    
    // OR explicitly reject "none"
    RequireSignedTokens = true
};

// Additional check: Read algorithm from header
var handler = new JwtSecurityTokenHandler();
var token = handler.ReadJwtToken(jwt);

if (token.Header.Alg == "none")
{
    throw new SecurityTokenException("Algorithm 'none' not allowed");
}

if (!validAlgorithms.Contains(token.Header.Alg))
{
    throw new SecurityTokenException($"Algorithm '{token.Header.Alg}' not allowed");
}
```

## 4. Issuer Validation

### What Is the Issuer?

The `iss` claim identifies who created and signed the JWT.

```json
{
  "iss": "https://auth.example.com",
  "sub": "12345",
  ...
}
```

### Why Validate It?

Ensures the token came from your trusted authorization server, not an impersonator.

### Implementation

```csharp
var validationParameters = new TokenValidationParameters
{
    ValidateIssuer = true,
    ValidIssuer = "https://auth.example.com",  // Exact match
    
    // OR for multiple trusted issuers
    ValidIssuers = new[]
    {
        "https://auth.example.com",
        "https://auth2.example.com"
    }
};
```

### Case Sensitivity

```csharp
// Issuer comparison is case-sensitive!

"https://auth.example.com"     ✓
"https://AUTH.example.com"     ✗  (Different!)
"https://auth.example.com/"    ✗  (Trailing slash!)
```

## 5. Audience Validation

### What Is the Audience?

The `aud` claim identifies who the token is intended for (your application or API).

```json
{
  "iss": "https://auth.example.com",
  "aud": "https://api.example.com",
  "sub": "12345"
}
```

### Why Validate It?

**Most commonly skipped validation, most dangerous oversight.**

Without audience validation, a token intended for API A can be used on API B.

### Attack Scenario

```
1. Attacker obtains valid token for "https://api.attacker.com"
2. Attacker sends token to "https://api.victim.com"
3. If victim API doesn't validate audience...
4. Token is accepted (WRONG!)
5. Attacker gains unauthorized access
```

### Implementation

```csharp
var validationParameters = new TokenValidationParameters
{
    ValidateAudience = true,  // CRITICAL - often forgotten!
    ValidAudience = "https://api.example.com",
    
    // OR for multiple valid audiences
    ValidAudiences = new[]
    {
        "https://api.example.com",
        "https://api2.example.com"
    }
};
```

### Multiple Audiences

Some tokens have multiple audiences:

```json
{
  "aud": [
    "https://api.example.com",
    "https://api2.example.com"
  ]
}
```

Validation passes if ANY audience matches your expected value.

## 6. Expiration Validation

### What Is Expiration?

The `exp` claim specifies when the token expires (Unix timestamp).

```json
{
  "exp": 1641234567,  // Unix timestamp: Jan 3, 2022 17:29:27 UTC
  "iat": 1641230967   // Issued at: Jan 3, 2022 16:29:27 UTC
}
```

### Why Validate It?

Expired tokens must be rejected. Accepting expired tokens allows indefinite access.

### Implementation

```csharp
var validationParameters = new TokenValidationParameters
{
    ValidateLifetime = true,  // Validates both exp and nbf
    ClockSkew = TimeSpan.FromMinutes(5),  // Allow 5 minutes leeway
    
    LifetimeValidator = (notBefore, expires, token, parameters) =>
    {
        if (expires != null)
        {
            var now = DateTime.UtcNow;
            var exp = expires.Value;
            
            // Account for clock skew
            if (now > exp.Add(parameters.ClockSkew))
            {
                return false;  // Expired
            }
        }
        
        return true;
    }
};
```

### Clock Skew

Distributed systems have clock drift. Allow small tolerance:

```
Token expires: 12:00:00 UTC
Current time:  12:02:00 UTC (2 minutes late)
Clock skew:    5 minutes

Result: Token accepted (within tolerance)

But at 12:06:00 UTC → Rejected (beyond tolerance)
```

**Recommendation:** 5 minutes maximum clock skew.

```csharp
ClockSkew = TimeSpan.FromMinutes(5)  // ✅ Reasonable
ClockSkew = TimeSpan.FromHours(1)    // ❌ Too permissive
ClockSkew = TimeSpan.Zero            // ⚠️ Strict (may cause issues)
```

## 7. Not Before Validation

### What Is Not Before?

The `nbf` claim specifies when the token becomes valid.

```json
{
  "iat": 1641230967,  // Issued at: 16:29:27
  "nbf": 1641231027,  // Not before: 16:30:27 (1 minute later)
  "exp": 1641234567   // Expires: 17:29:27
}
```

### Why Use It?

Prevents accepting tokens that aren't valid yet. Useful for:
- Tokens issued "in the future" for delayed activation
- Preventing time-based race conditions

### Implementation

```csharp
var validationParameters = new TokenValidationParameters
{
    ValidateLifetime = true,  // Also validates nbf
    ClockSkew = TimeSpan.FromMinutes(5)
};

// Manual check
var token = handler.ReadJwtToken(jwt);
var nbf = token.Payload.Nbf;  // Nullable<int>

if (nbf.HasValue)
{
    var notBefore = DateTimeOffset.FromUnixTimeSeconds(nbf.Value);
    var now = DateTimeOffset.UtcNow;
    
    if (now < notBefore.Subtract(clockSkew))
    {
        throw new SecurityTokenNotYetValidException("Token not yet valid");
    }
}
```

## 8. Issued At Validation

### What Is Issued At?

The `iat` claim records when the token was created.

```json
{
  "iat": 1641230967  // Unix timestamp
}
```

### Why Validate It?

- Sanity check: Token shouldn't be issued in the future
- Reject very old tokens
- Audit and logging

### Implementation

```csharp
var token = handler.ReadJwtToken(jwt);
var iat = token.Payload.Iat;

if (iat.HasValue)
{
    var issuedAt = DateTimeOffset.FromUnixTimeSeconds(iat.Value);
    var now = DateTimeOffset.UtcNow;
    
    // Reject tokens issued in the future (beyond clock skew)
    if (issuedAt > now.Add(clockSkew))
    {
        throw new SecurityTokenException("Token issued in the future");
    }
    
    // Optionally: Reject very old tokens
    var maxAge = TimeSpan.FromDays(7);
    if (now - issuedAt > maxAge)
    {
        throw new SecurityTokenException("Token too old");
    }
}
```

## Complete Validation Example

### Comprehensive JWT Validator

```csharp
using System.IdentityModel.Tokens.Jwt;
using Microsoft.IdentityModel.Tokens;

public class JwtValidator
{
    private readonly string _issuer = "https://auth.example.com";
    private readonly string _audience = "https://api.example.com";
    private readonly SecurityKey _signingKey;
    
    public JwtValidator(SecurityKey signingKey)
    {
        _signingKey = signingKey;
    }
    
    public ClaimsPrincipal Validate(string jwt)
    {
        var validationParameters = new TokenValidationParameters
        {
            // Signature validation
            ValidateIssuerSigningKey = true,
            IssuerSigningKey = _signingKey,
            
            // Algorithm validation
            ValidAlgorithms = new[] { SecurityAlgorithms.RsaSha256 },
            RequireSignedTokens = true,
            
            // Issuer validation
            ValidateIssuer = true,
            ValidIssuer = _issuer,
            
            // Audience validation
            ValidateAudience = true,
            ValidAudience = _audience,
            
            // Lifetime validation (exp, nbf)
            ValidateLifetime = true,
            ClockSkew = TimeSpan.FromMinutes(5),
            
            // Require standard claims
            RequireExpirationTime = true,
            RequireAudience = true
        };
        
        var handler = new JwtSecurityTokenHandler();
        
        try
        {
            // Validate token
            var principal = handler.ValidateToken(jwt, validationParameters, 
                out SecurityToken validatedToken);
            
            // Additional custom validations
            var jwtToken = (JwtSecurityToken)validatedToken;
            
            // Validate issued-at time
            ValidateIssuedAt(jwtToken);
            
            // Validate custom claims if needed
            ValidateCustomClaims(principal);
            
            return principal;
        }
        catch (SecurityTokenException ex)
        {
            // Log validation failure
            Console.WriteLine($"JWT validation failed: {ex.Message}");
            throw;
        }
    }
    
    private void ValidateIssuedAt(JwtSecurityToken token)
    {
        if (!token.Payload.Iat.HasValue)
            return;
        
        var issuedAt = DateTimeOffset.FromUnixTimeSeconds(token.Payload.Iat.Value);
        var now = DateTimeOffset.UtcNow;
        var clockSkew = TimeSpan.FromMinutes(5);
        
        if (issuedAt > now.Add(clockSkew))
        {
            throw new SecurityTokenException("Token issued in the future");
        }
    }
    
    private void ValidateCustomClaims(ClaimsPrincipal principal)
    {
        // Example: Validate custom claim
        var role = principal.FindFirst("role")?.Value;
        if (string.IsNullOrEmpty(role))
        {
            throw new SecurityTokenException("Required 'role' claim missing");
        }
    }
}
```

## ASP.NET Core Integration

### Startup Configuration

```csharp
// Program.cs
services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddJwtBearer(options =>
    {
        options.Authority = "https://auth.example.com";
        options.Audience = "https://api.example.com";
        
        options.TokenValidationParameters = new TokenValidationParameters
        {
            // All validations enabled
            ValidateIssuer = true,
            ValidateAudience = true,
            ValidateLifetime = true,
            ValidateIssuerSigningKey = true,
            
            // Algorithm whitelist
            ValidAlgorithms = new[] { SecurityAlgorithms.RsaSha256 },
            
            // Clock skew
            ClockSkew = TimeSpan.FromMinutes(5),
            
            // Require critical claims
            RequireExpirationTime = true,
            RequireSignedTokens = true
        };
        
        // Event handlers
        options.Events = new JwtBearerEvents
        {
            OnTokenValidated = context =>
            {
                var userId = context.Principal?.FindFirst("sub")?.Value;
                Console.WriteLine($"Token validated for user: {userId}");
                return Task.CompletedTask;
            },
            
            OnAuthenticationFailed = context =>
            {
                Console.WriteLine($"Authentication failed: {context.Exception.Message}");
                
                if (context.Exception is SecurityTokenExpiredException)
                {
                    context.Response.Headers.Add("Token-Expired", "true");
                }
                
                return Task.CompletedTask;
            },
            
            OnChallenge = context =>
            {
                // Custom response for failed authentication
                Console.WriteLine($"OnChallenge: {context.Error}, {context.ErrorDescription}");
                return Task.CompletedTask;
            }
        };
    });

app.UseAuthentication();
app.UseAuthorization();
```

## Handling Validation Errors

### Error Types

```csharp
try
{
    var principal = validator.Validate(jwt);
}
catch (SecurityTokenInvalidSignatureException)
{
    // Signature invalid - token tampered or wrong key
    return Unauthorized("Invalid token signature");
}
catch (SecurityTokenExpiredException)
{
    // Token expired
    return Unauthorized("Token has expired");
}
catch (SecurityTokenNotYetValidException)
{
    // Token used before nbf time
    return Unauthorized("Token not yet valid");
}
catch (SecurityTokenInvalidIssuerException)
{
    // Issuer doesn't match
    return Unauthorized("Invalid token issuer");
}
catch (SecurityTokenInvalidAudienceException)
{
    // Audience doesn't match
    return Unauthorized("Invalid token audience");
}
catch (SecurityTokenInvalidAlgorithmException)
{
    // Algorithm not allowed
    return Unauthorized("Invalid signing algorithm");
}
catch (SecurityTokenException ex)
{
    // General validation failure
    return Unauthorized($"Token validation failed: {ex.Message}");
}
```

## Best Practices

### 1. Always Validate Everything

```csharp
// ✅ GOOD: All validations enabled
ValidateIssuer = true
ValidateAudience = true
ValidateLifetime = true
ValidateIssuerSigningKey = true

// ❌ BAD: Disabling validations
ValidateAudience = false  // NEVER DO THIS
```

### 2. Use Strict Clock Skew

```csharp
// ✅ GOOD: Reasonable tolerance
ClockSkew = TimeSpan.FromMinutes(5)

// ❌ BAD: Too permissive
ClockSkew = TimeSpan.FromHours(1)
```

### 3. Whitelist Algorithms

```csharp
// ✅ GOOD: Explicit whitelist
ValidAlgorithms = new[] { "RS256" }

// ❌ BAD: Accepting any algorithm
ValidateIssuerSigningKey = true  // Without ValidAlgorithms
```

### 4. Require Critical Claims

```csharp
RequireExpirationTime = true
RequireSignedTokens = true
RequireAudience = true  // (when audience is expected)
```
