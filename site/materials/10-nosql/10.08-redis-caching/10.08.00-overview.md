# Chapter 10.8: Redis for Caching

## Overview
Learn Redis as a caching layer: data structures, common patterns, expiration, pub/sub, and integration with .NET applications for caching.

## Key Concepts
- **Redis data structures:** Strings, hashes, lists, sets, sorted sets.
- **Key expiration and eviction:** TTL management and eviction policies.
- **Caching patterns:** Cache-aside, write-through, and other strategies.
- **Pub/sub for messaging:** Real-time communication using Redis channels.
- **Redis with .NET:** StackExchange.Redis client library.
