# Chapter 10.4: Data Modeling for MongoDB

## Overview
This chapter teaches you to model data for MongoDB effectively. You'll learn when to embed versus reference data, how to handle different relationship types, and how to apply design patterns that optimize query performance and reduce data duplication.

## Key Concepts
- **Relationship Patterns:** understanding one-to-one, one-to-many, and many-to-many relationships.
- **Embedding vs Referencing:** deciding when to denormalize versus normalize data.
- **Design Patterns:** applying subset, extended reference, and other patterns to solve common problems.
- **Schema Evolution:** versioning schemas to support graceful migration.
