## Introduction

The MongoDB .NET/C# Driver provides a powerful, idiomatic way to work with MongoDB from .NET applications. It offers both a low-level API for flexibility and a high-level API for ease of use, with full support for modern .NET features including async/await.

## Key Concepts Summary

### Installation

```bash
# Install the MongoDB driver via NuGet
dotnet add package MongoDB.Driver
```

### Basic Setup

```csharp
using MongoDB.Driver;
using MongoDB.Bson;
using MongoDB.Bson.Serialization.Attributes;

// Define your model
public class Product
{
    [BsonId]
    [BsonRepresentation(BsonType.ObjectId)]
    public string? Id { get; set; }
    
    [BsonElement("name")]
    public string Name { get; set; } = string.Empty;
    
    [BsonElement("price")]
    public decimal Price { get; set; }
    
    [BsonElement("category")]
    public string Category { get; set; } = string.Empty;
    
    [BsonElement("inStock")]
    public bool InStock { get; set; }
}
```

### Connecting to MongoDB

```csharp
// Connection string (Atlas or local)
const string connectionString = "mongodb://localhost:27017";
// or for Atlas: "mongodb+srv://username:password@cluster.mongodb.net/"

var client = new MongoClient(connectionString);
var database = client.GetDatabase("shop");
var collection = database.GetCollection<Product>("products");
```

### Create (Insert)

```csharp
// Insert one
var product = new Product
{
    Name = "Laptop",
    Price = 999.99m,
    Category = "Electronics",
    InStock = true
};

await collection.InsertOneAsync(product);
Console.WriteLine($"Inserted product with ID: {product.Id}");

// Insert many
var products = new List<Product>
{
    new() { Name = "Mouse", Price = 19.99m, Category = "Electronics", InStock = true },
    new() { Name = "Keyboard", Price = 49.99m, Category = "Electronics", InStock = true },
    new() { Name = "Monitor", Price = 299.99m, Category = "Electronics", InStock = false }
};

await collection.InsertManyAsync(products);
```

### Read (Find)

```csharp
// Find one
var filter = Builders<Product>.Filter.Eq(p => p.Name, "Laptop");
var foundProduct = await collection.Find(filter).FirstOrDefaultAsync();

// Find many
var electronicFilter = Builders<Product>.Filter.Eq(p => p.Category, "Electronics");
var electronics = await collection.Find(electronicFilter).ToListAsync();

// Find all
var allProducts = await collection.Find(_ => true).ToListAsync();
// or
var allProducts2 = await collection.Find(new BsonDocument()).ToListAsync();

// Find with conditions
var expensiveFilter = Builders<Product>.Filter.Gt(p => p.Price, 100);
var inStockFilter = Builders<Product>.Filter.Eq(p => p.InStock, true);
var combinedFilter = Builders<Product>.Filter.And(expensiveFilter, inStockFilter);

var expensiveInStock = await collection.Find(combinedFilter).ToListAsync();
```

### Update

```csharp
// Update one
var updateFilter = Builders<Product>.Filter.Eq(p => p.Name, "Laptop");
var update = Builders<Product>.Update
    .Set(p => p.Price, 899.99m)
    .Set(p => p.InStock, false);

var updateResult = await collection.UpdateOneAsync(updateFilter, update);
Console.WriteLine($"Modified count: {updateResult.ModifiedCount}");

// Update many
var categoryFilter = Builders<Product>.Filter.Eq(p => p.Category, "Electronics");
var bulkUpdate = Builders<Product>.Update.Mul(p => p.Price, 0.9m); // 10% discount

var bulkResult = await collection.UpdateManyAsync(categoryFilter, bulkUpdate);

// Replace entire document
var replacement = new Product
{
    Id = foundProduct.Id,
    Name = "Gaming Laptop",
    Price = 1299.99m,
    Category = "Electronics",
    InStock = true
};

await collection.ReplaceOneAsync(
    p => p.Id == foundProduct.Id, 
    replacement
);
```

### Delete

```csharp
// Delete one
var deleteFilter = Builders<Product>.Filter.Eq(p => p.Name, "Mouse");
var deleteResult = await collection.DeleteOneAsync(deleteFilter);
Console.WriteLine($"Deleted count: {deleteResult.DeletedCount}");

// Delete many
var outOfStockFilter = Builders<Product>.Filter.Eq(p => p.InStock, false);
var bulkDeleteResult = await collection.DeleteManyAsync(outOfStockFilter);
```

### Filter Builder Operators

```csharp
var builder = Builders<Product>.Filter;

// Comparison operators
var eq = builder.Eq(p => p.Category, "Electronics");
var ne = builder.Ne(p => p.Category, "Books");
var gt = builder.Gt(p => p.Price, 50);
var gte = builder.Gte(p => p.Price, 50);
var lt = builder.Lt(p => p.Price, 100);
var lte = builder.Lte(p => p.Price, 100);
var inList = builder.In(p => p.Category, new[] { "Electronics", "Books" });

// Logical operators
var and = builder.And(
    builder.Eq(p => p.Category, "Electronics"),
    builder.Gt(p => p.Price, 100)
);

var or = builder.Or(
    builder.Eq(p => p.Category, "Electronics"),
    builder.Eq(p => p.Category, "Books")
);

var not = builder.Not(builder.Eq(p => p.InStock, false));

// Array and string operators
var regex = builder.Regex(p => p.Name, new BsonRegularExpression("^Lap", "i"));
var exists = builder.Exists(p => p.Category);
```

## Best Practices

1. **Connection Reuse:** Create `MongoClient` once and reuse it (it's thread-safe).
2. **Async Operations:** Always use async methods for database operations.
3. **Strongly-Typed:** Use strongly-typed collections over `BsonDocument` when possible.
4. **Filter Builders:** Use filter builders instead of raw BSON for type safety.
5. **Indexes:** Create appropriate indexes for frequently queried fields.
