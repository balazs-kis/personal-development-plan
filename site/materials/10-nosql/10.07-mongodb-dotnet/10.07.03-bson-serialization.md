# Lesson 3: BSON Serialization and Attributes

## Learning Objectives

By the end of this lesson, you will be able to:
- Control how C# objects are serialized to BSON
- Use BSON attributes to customize serialization
- Handle different data type representations
- Manage extra elements and null values
- Create custom serializers when needed

---

## Introduction

BSON (Binary JSON) is MongoDB's native data format. The .NET driver automatically serializes C# objects to BSON and vice versa. Understanding serialization control through attributes and conventions allows you to optimize storage, maintain compatibility with existing data, and handle complex data types effectively.

## Key Concepts Summary

### Core BSON Attributes

```csharp
using MongoDB.Bson;
using MongoDB.Bson.Serialization.Attributes;

public class Product
{
    // Mark as document ID
    [BsonId]
    // Represent string as ObjectId in BSON
    [BsonRepresentation(BsonType.ObjectId)]
    public string? Id { get; set; }
    
    // Custom field name in BSON
    [BsonElement("product_name")]
    public string Name { get; set; } = string.Empty;
    
    // Ignore this property entirely
    [BsonIgnore]
    public string InternalNotes { get; set; } = string.Empty;
    
    // Don't serialize if null
    [BsonIgnoreIfNull]
    public string? Description { get; set; }
    
    // Don't serialize if default value
    [BsonIgnoreIfDefault]
    public int ViewCount { get; set; }
    
    // Set default value for deserialization
    [BsonDefaultValue(true)]
    public bool IsActive { get; set; } = true;
    
    // Required field (throws if missing during deserialization)
    [BsonRequired]
    public decimal Price { get; set; }
}
```

### BsonId and ObjectId Handling

```csharp
// Option 1: String represented as ObjectId
public class Product

}

// Option 2: Native ObjectId type
public class Product
{
    [BsonId]
    public ObjectId Id { get; set; }
}

// Option 3: Let MongoDB generate ObjectId, use string in C#
public class Product
{
    [BsonId]
    [BsonRepresentation(BsonType.ObjectId)]
    public string? Id { get; set; }
}

// Option 4: Use GUID
public class Product
{
    [BsonId]
    [BsonRepresentation(BsonType.String)]
    public Guid Id { get; set; } = Guid.NewGuid();
}

// Option 5: Integer ID
public class Product
{
    [BsonId]
    public int Id { get; set; }
}
```

### BsonElement - Field Naming

```csharp
public class Product
{
    // C# property: "Name", BSON field: "product_name"
    [BsonElement("product_name")]
    public string Name { get; set; } = string.Empty;
    
    // Useful for matching existing database schemas
    [BsonElement("qty")]
    public int Quantity { get; set; }
    
    // Or following different naming conventions (snake_case, camelCase)
    [BsonElement("createdAt")]
    public DateTime CreatedDate { get; set; }
}
```

### BsonRepresentation - Type Control

```csharp
public class Order
{
    [BsonId]
    [BsonRepresentation(BsonType.ObjectId)]
    public string? Id { get; set; }
    
    // Store enum as string instead of int
    [BsonRepresentation(BsonType.String)]
    public OrderStatus Status { get; set; }
    
    // Store as 64-bit integer
    [BsonRepresentation(BsonType.Int64)]
    public long TotalCents { get; set; }
    
    // Store decimal as double (be careful with precision!)
    [BsonRepresentation(BsonType.Double)]
    public decimal ApproximateWeight { get; set; }
}

public enum OrderStatus
{
    Pending,
    Processing,
    Shipped,
    Delivered,
    Cancelled
}
```

### DateTime Handling

```csharp
public class Event
{
    [BsonId]
    [BsonRepresentation(BsonType.ObjectId)]
    public string? Id { get; set; }
    
    // Default: stored as UTC
    public DateTime EventDate { get; set; }
    
    // Explicit control over DateTime serialization
    [BsonDateTimeOptions(Kind = DateTimeKind.Utc)]
    public DateTime UtcDate { get; set; }
    
    [BsonDateTimeOptions(Kind = DateTimeKind.Local)]
    public DateTime LocalDate { get; set; }
    
    // Store as string instead of BSON date
    [BsonRepresentation(BsonType.String)]
    public DateTime StringDate { get; set; }
}

// Setting default DateTime kind globally
BsonSerializer.RegisterSerializer(
    new DateTimeSerializer(DateTimeKind.Utc)
);
```

### Handling Extra Elements

```csharp
// Option 1: Ignore extra fields in database
[BsonIgnoreExtraElements]
public class Product
{
    [BsonId]
    [BsonRepresentation(BsonType.ObjectId)]
    public string? Id { get; set; }
    
    public string Name { get; set; } = string.Empty;
    // If document has more fields, they're ignored
}

// Option 2: Capture extra elements
public class Product
{
    [BsonId]
    [BsonRepresentation(BsonType.ObjectId)]
    public string? Id { get; set; }
    
    public string Name { get; set; } = string.Empty;
    
    // Store any extra fields here
    [BsonExtraElements]
    public BsonDocument? ExtraElements { get; set; }
}

// Option 3: Use Dictionary for extra elements
public class Product
{
    [BsonId]
    [BsonRepresentation(BsonType.ObjectId)]
    public string? Id { get; set; }
    
    public string Name { get; set; } = string.Empty;
    
    [BsonExtraElements]
    public Dictionary<string, object>? AdditionalData { get; set; }
}
```

### Working with Dictionaries

```csharp
public class ProductAttributes
{
    [BsonId]
    [BsonRepresentation(BsonType.ObjectId)]
    public string? Id { get; set; }
    
    public string ProductName { get; set; } = string.Empty;
    
    // Default: stored as BSON document
    public Dictionary<string, string> Specifications { get; set; } = new();
    
    // Store as array of key-value pairs
    [BsonDictionaryOptions(DictionaryRepresentation.ArrayOfDocuments)]
    public Dictionary<string, int> Ratings { get; set; } = new();
}

// Example documents in MongoDB:
// Default:
// { specifications: { "color": "blue", "size": "large" } }

// ArrayOfDocuments:
// { ratings: [ { "k": "quality", "v": 5 }, { "k": "value", "v": 4 } ] }
```

### Constructor Selection

```csharp
public class Product
{
    [BsonId]
    [BsonRepresentation(BsonType.ObjectId)]
    public string? Id { get; set; }
    
    public string Name { get; }
    public decimal Price { get; }
    
    // Default constructor
    public Product()
    {
        Name = string.Empty;
        Price = 0m;
    }
    
    // Use this constructor for deserialization
    [BsonConstructor]
    public Product(string name, decimal price)
    {
        Name = name;
        Price = price;
    }
}
```

### Polymorphism and Discriminators

```csharp
// Base class
[BsonDiscriminator(RootClass = true)]
[BsonKnownTypes(typeof(Book), typeof(Electronics))]
public abstract class Product
{
    [BsonId]
    [BsonRepresentation(BsonType.ObjectId)]
    public string? Id { get; set; }
    
    public string Name { get; set; } = string.Empty;
    public decimal Price { get; set; }
}

// Derived classes
[BsonDiscriminator("book")] // Custom discriminator value
public class Book : Product
{
    public string Author { get; set; } = string.Empty;
    public string ISBN { get; set; } = string.Empty;
}

[BsonDiscriminator("electronics")]
public class Electronics : Product
{
    public string Brand { get; set; } = string.Empty;
    public int WarrantyMonths { get; set; }
}

// Stored in MongoDB with discriminator:
// { "_t": "book", "name": "...", "author": "...", ... }
// { "_t": "electronics", "name": "...", "brand": "...", ... }

// Query the collection
var collection = database.GetCollection<Product>("products");
var allProducts = await collection.Find(_ => true).ToListAsync();
// Returns mixed list of Book and Electronics instances
```

### Class Maps (Alternative to Attributes)

```csharp
using MongoDB.Bson.Serialization;

// Register class map during application startup
BsonClassMap.RegisterClassMap<Product>(cm =>
{
    cm.AutoMap(); // Map all properties automatically
    cm.MapIdMember(p => p.Id)
        .SetIdGenerator(StringObjectIdGenerator.Instance);
    
    cm.MapMember(p => p.Name)
        .SetElementName("product_name")
        .SetIsRequired(true);
    
    cm.MapMember(p => p.Description)
        .SetIgnoreIfNull(true);
    
    cm.MapMember(p => p.InternalNotes)
        .SetShouldSerializeMethod(obj => false); // Never serialize
    
    cm.SetIgnoreExtraElements(true);
});

public class Product
{
    // No attributes needed when using class maps
    public string? Id { get; set; }
    public string Name { get; set; } = string.Empty;
    public string? Description { get; set; }
    public string InternalNotes { get; set; } = string.Empty;
}
```

### Custom Serializers

```csharp
using MongoDB.Bson.Serialization;
using MongoDB.Bson.Serialization.Serializers;

// Custom serializer for Money type
public class MoneySerializer : SerializerBase<Money>
{
    public override Money Deserialize(
        BsonDeserializationContext context,
        BsonDeserializationArgs args)
    {
        var bsonReader = context.Reader;
        var cents = bsonReader.ReadInt64();
        return Money.FromCents(cents);
    }

    public override void Serialize(
        BsonSerializationContext context,
        BsonSerializationArgs args,
        Money value)
    {
        var bsonWriter = context.Writer;
        bsonWriter.WriteInt64(value.ToCents());
    }
}

// Register the serializer
BsonSerializer.RegisterSerializer(new MoneySerializer());

// Value object
public record Money(decimal Amount)
{
    public long ToCents() => (long)(Amount * 100);
    public static Money FromCents(long cents) => new(cents / 100m);
}

// Use in your model
public class Product
{
    [BsonId]
    [BsonRepresentation(BsonType.ObjectId)]
    public string? Id { get; set; }
    
    public string Name { get; set; } = string.Empty;
    
    // Uses custom serializer automatically
    public Money Price { get; set; } = new(0m);
}
```

## Common Patterns

### Immutable Objects

```csharp
public class Product
{
    [BsonId]
    [BsonRepresentation(BsonType.ObjectId)]
    public string Id { get; }
    
    public string Name { get; }
    public decimal Price { get; }
    
    [BsonConstructor]
    public Product(string id, string name, decimal price)
    {
        Id = id;
        Name = name;
        Price = price;
    }
}
```

### Record Types (C# 9+)

```csharp
public record Product(
    [property: BsonId]
    [property: BsonRepresentation(BsonType.ObjectId)]
    string? Id,
    
    [property: BsonElement("name")]
    string Name,
    
    decimal Price
);
```

## Best Practices

1. **Use Attributes:** Prefer attributes over class maps for simple scenarios.
2. **Required Fields:** Mark critical fields with `[BsonRequired]`.
3. **Ignore Nulls:** Use `[BsonIgnoreIfNull]` to reduce document size.
4. **Extra Elements:** Use `[BsonIgnoreExtraElements]` for forward compatibility.
5. **Enums as Strings:** Store enums as strings for better readability.
6. **UTC Dates:** Always use UTC for DateTime fields.
7. **Consistent IDs:** Choose one ObjectId strategy and stick with it.
