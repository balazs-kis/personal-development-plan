# Chapter 10.2: Document Database Concepts

## Overview
This chapter explores document database fundamentals: documents, collections, embedded vs referenced data, and the flexibility of schema-less design. You'll learn the core concepts that differentiate document databases from relational databases and understand when to leverage their unique strengths.

## Key Concepts
- **Documents and Collections:** understanding the hierarchical structure and organization.
- **BSON Format:** binary JSON representation and extended data types.
- **Schema Flexibility:** dynamic schemas and optional validation.
- **Embedding vs Referencing:** data modeling strategies for relationships.
- **Atomicity:** document-level consistency guarantees and transaction boundaries.
