## Learning Objectives

By the end of this lesson, you will be able to:

- Implement pagination with $limit and $skip

---

## Introduction

After filtering and grouping data, you often need to reshape the output, order results, and paginate large datasets. The `$project` stage lets you select specific fields, rename them, and compute new values. `$sort`, `$limit`, and `$skip` control result ordering and size. Together, these stages give you complete control over your pipeline output, enabling you to deliver exactly the data your application needs in the right format.

## Key Concepts Summary

### $project Stage

The `$project` stage reshapes documents by including, excluding, or computing fields.

**Basic Syntax:**
```javascript
{
  $project: {
    <field1>: <1 or 0>,           // Include or exclude
    <field2>: <expression>,        // Compute new field
    <newField>: <expression>       // Add new field
  }
}
```

**Examples:**

**1. Include specific fields:**
```javascript
{
  $project: {
    title: 1,
    author: 1,
    year: 1
    // _id included by default
  }
}
```

**2. Exclude fields:**
```javascript
{
  $project: {
    _id: 0,           // Exclude _id
    internalNotes: 0  // Exclude internalNotes
  }
}
```

**3. Rename fields:**
```javascript
{
  $project: {
    _id: 0,
    productName: "$name",
    productPrice: "$price",
    isAvailable: "$inStock"
  }
}
```

**4. Compute new fields:**
```javascript
{
  $project: {
    name: 1,
    price: 1,
    quantity: 1,
    total: { $multiply: ["$price", "$quantity"] },
    discountedPrice: {
      $multiply: ["$price", 0.9]  // 10% discount
    }
  }
}
```

**5. Nested field access:**
```javascript
{
  $project: {
    customerName: "$customer.name",
    shippingCity: "$shipping.address.city",
    firstItem: { $arrayElemAt: ["$items", 0] }
  }
}
```

**6. Conditional fields:**
```javascript
{
  $project: {
    name: 1,
    price: 1,
    priceCategory: {
      $cond: {
        if: { $gte: ["$price", 100] },
        then: "Premium",
        else: "Standard"
      }
    }
  }
}
```

**7. String operations:**
```javascript
{
  $project: {
    fullName: { $concat: ["$firstName", " ", "$lastName"] },
    upperName: { $toUpper: "$name" },
    firstInitial: { $substr: ["$firstName", 0, 1] }
  }
}
```

**8. Date operations:**
```javascript
{
  $project: {
    orderDate: 1,
    year: { $year: "$orderDate" },
    month: { $month: "$orderDate" },
    dayOfWeek: { $dayOfWeek: "$orderDate" },
    formattedDate: {
      $dateToString: {
        format: "%Y-%m-%d",
        date: "$orderDate"
      }
    }
  }
}
```

### $addFields and $set Stages

Alternative to `$project` when you want to add fields without removing existing ones.

**$addFields (or $set, they're synonymous):**
```javascript
// Adds fields without removing others
{
  $addFields: {
    total: { $multiply: ["$price", "$quantity"] },
    discountApplied: true
  }
}

// Same as $set
{
  $set: {
    total: { $multiply: ["$price", "$quantity"] },
    discountApplied: true
  }
}
```

**When to use:**
- Use `$project` to include/exclude fields and compute new ones
- Use `$addFields`/`$set` to add computed fields while keeping all existing fields

### $sort Stage

The `$sort` stage orders documents by specified fields.

**Syntax:**
```javascript
{
  $sort: {
    <field1>: <1 or -1>,
    <field2>: <1 or -1>
  }
}
```
- `1` = ascending order
- `-1` = descending order

**Examples:**

**1. Single field sort:**
```javascript
// Sort by price, low to high
{ $sort: { price: 1 } }

// Sort by date, newest first
{ $sort: { createdAt: -1 } }
```

**2. Multi-field sort:**
```javascript
// Sort by category (A-Z), then price (high to low)
{
  $sort: {
    category: 1,
    price: -1
  }
}
```

**3. Sort by computed field:**
```javascript
// Must compute field first, then sort
[
  {
    $addFields: {
      total: { $multiply: ["$price", "$quantity"] }
    }
  },
  {
    $sort: { total: -1 }
  }
]
```

**Performance Note:** 
- Sorting is memory-intensive
- MongoDB limits sort to 100 MB of RAM
- Use indexes when possible by sorting early in the pipeline
- For large datasets, use `allowDiskUse: true`

### $limit Stage

The `$limit` stage restricts the number of documents passed to the next stage.

**Syntax:**
```javascript
{
  $limit: <positive integer>
}
```

**Examples:**

```javascript
// Get top 10 products by price
[
  { $sort: { price: -1 } },
  { $limit: 10 }
]

// Get any 5 documents
[
  { $limit: 5 }
]
```

**Important:** 
- Always place `$limit` **after** `$sort` if you want "top N" results
- Placing `$limit` before `$sort` gives you N random documents sorted

### $skip Stage

The `$skip` stage skips a specified number of documents.

**Syntax:**
```javascript
{
  $skip: <positive integer>
}
```

**Examples:**

```javascript
// Skip first 20 documents
{ $skip: 20 }

// Pagination: Page 3, 10 items per page
[
  { $sort: { createdAt: -1 } },
  { $skip: 20 },  // Skip pages 1 and 2 (20 items)
  { $limit: 10 }  // Get page 3 (10 items)
]
```

### Pagination Pattern

**Complete pagination example:**

```javascript
function getPage(pageNumber, pageSize) {
  const skip = (pageNumber - 1) * pageSize;
  
  return db.products.aggregate([
    // Filter
    {
      $match: { status: "active" }
    },
    
    // Sort
    {
      $sort: { name: 1 }
    },
    
    // Paginate
    {
      $skip: skip
    },
    {
      $limit: pageSize
    },
    
    // Shape output
    {
      $project: {
        _id: 0,
        name: 1,
        price: 1,
        category: 1
      }
    }
  ]);
}

// Get page 1 (items 1-10)
getPage(1, 10);

// Get page 2 (items 11-20)
getPage(2, 10);

// Get page 3 (items 21-30)
getPage(3, 10);
```

### Complete Example: Product Catalog

```javascript
// Build product listing with pagination and computed fields
db.products.aggregate([
  // Stage 1: Filter active products
  {
    $match: {
      status: "active",
      stock: { $gt: 0 }
    }
  },
  
  // Stage 2: Add computed fields
  {
    $addFields: {
      discountPrice: {
        $multiply: ["$price", { $subtract: [1, { $divide: ["$discountPercent", 100] }] }]
      },
      savings: {
        $multiply: ["$price", { $divide: ["$discountPercent", 100] }]
      },
      inStockStatus: {
        $cond: {
          if: { $gte: ["$stock", 10] },
          then: "In Stock",
          else: "Low Stock"
        }
      }
    }
  },
  
  // Stage 3: Sort by category, then discounted price
  {
    $sort: {
      category: 1,
      discountPrice: 1
    }
  },
  
  // Stage 4: Pagination (page 2, 20 items per page)
  {
    $skip: 20
  },
  {
    $limit: 20
  },
  
  // Stage 5: Shape output (exclude internal fields)
  {
    $project: {
      _id: 0,
      productId: "$_id",
      name: 1,
      category: 1,
      originalPrice: "$price",
      discountPrice: 1,
      savings: 1,
      discountPercent: 1,
      inStockStatus: 1,
      rating: 1
    }
  }
])
```

**Output:**
```javascript
[
  {
    productId: ObjectId("..."),
    name: "Wireless Mouse",
    category: "Electronics",
    originalPrice: 29.99,
    discountPrice: 23.99,
    savings: 6.00,
    discountPercent: 20,
    inStockStatus: "In Stock",
    rating: 4.5
  },
  // ... 19 more products
]
```

## Practice Exercise

After completing the materials, try this exercise (do not spend more than 20 minutes):

Given a `reviews` collection:
```javascript
{
  _id: 1,
  productId: "prod123",
  userId: "user456",
  rating: 4,
  comment: "Great product!",
  helpful: 15,
  notHelpful: 2,
  createdAt: ISODate("2026-01-10")
}
```

Write aggregation pipelines to:

1. **Top 10 most helpful reviews**
   - Calculate helpfulness score: (helpful - notHelpful)
   - Sort by score descending
   - Limit to 10
   - Project: productId, userId, rating, comment, helpfulnessScore

2. **Product review summary with pagination**
   - For a specific productId
   - Sort by date (newest first)
   - Get page 2 (10 reviews per page)
   - Include: rating, comment, createdAt, and formatted date

3. **Review statistics by rating level**
   - Group by rating (1-5)
   - Count reviews per rating
   - Calculate average helpful votes
   - Sort by rating descending
   - Add a field "percentage" showing what % of total reviews

4. **Recent high-quality reviews**
   - Reviews from last 30 days
   - Rating >= 4
   - Helpful votes > 5
   - Sort by helpful votes
   - Format output with computed "quality score"
