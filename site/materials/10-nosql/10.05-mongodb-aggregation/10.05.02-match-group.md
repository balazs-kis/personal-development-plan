## Learning Objectives

By the end of this lesson, you will be able to:

- Utilize accumulator operators ($sum, $avg, $min, $max, $push)
- Combine $match and $group for powerful analytics queries

---

## Introduction

The `$match` and `$group` stages are the workhorses of aggregation pipelines. `$match` filters documents (similar to find queries but within a pipeline), while `$group` aggregates data by grouping documents and performing calculations. Together, they enable you to answer questions like "What's the total revenue by product category?" or "How many orders did each customer place last month?" Understanding these stages is essential for any data analysis in MongoDB.

## Key Concepts Summary

### $match Stage

The `$match` stage filters documents based on specified conditions, similar to find queries.

**Basic Syntax:**
```javascript
{
  $match: {
    <field>: <value>,
    <field>: { <operator>: <value> }
  }
}
```

**Examples:**

```javascript
// Match documents with status "shipped"
{ $match: { status: "shipped" } }

// Match orders from 2026
{
  $match: {
    orderDate: {
      $gte: ISODate("2026-01-01"),
      $lt: ISODate("2027-01-01")
    }
  }
}

// Match multiple conditions
{
  $match: {
    status: "completed",
    total: { $gte: 100 },
    category: { $in: ["Electronics", "Computers"] }
  }
}
```

**Best Practices:**
- Place `$match` as early as possible in the pipeline to reduce documents processed by later stages
- Use indexes: `$match` at the beginning can leverage indexes
- Multiple `$match` stages are fine if they filter at different points

### $group Stage

The `$group` stage groups documents by a specified expression and performs aggregations.

**Basic Syntax:**
```javascript
{
  $group: {
    _id: <expression>,  // Grouping key
    <field1>: { <accumulator>: <expression> },
    <field2>: { <accumulator>: <expression> }
  }
}
```

**The _id Field:**
- Required field that specifies how to group documents
- Can be a single field, multiple fields, or an expression
- Set to `null` to group all documents together

**Examples:**

**1. Count documents by category:**
```javascript
{
  $group: {
    _id: "$category",
    count: { $sum: 1 }
  }
}
// Output: { _id: "Electronics", count: 45 }
```

**2. Sum values by field:**
```javascript
{
  $group: {
    _id: "$customerId",
    totalSpent: { $sum: "$amount" },
    orderCount: { $sum: 1 }
  }
}
// Output: { _id: "cust123", totalSpent: 5420, orderCount: 12 }
```

**3. Calculate averages:**
```javascript
{
  $group: {
    _id: "$product",
    avgRating: { $avg: "$rating" },
    minPrice: { $min: "$price" },
    maxPrice: { $max: "$price" }
  }
}
```

**4. Group by multiple fields:**
```javascript
{
  $group: {
    _id: {
      year: { $year: "$date" },
      month: { $month: "$date" },
      category: "$category"
    },
    totalSales: { $sum: "$amount" }
  }
}
// Output: { _id: { year: 2026, month: 1, category: "Books" }, totalSales: 8500 }
```

**5. Collect values into arrays:**
```javascript
{
  $group: {
    _id: "$customerId",
    products: { $push: "$productName" },
    orderIds: { $push: "$_id" }
  }
}
// Output: { _id: "cust123", products: ["Laptop", "Mouse", "Keyboard"], orderIds: [...] }
```

**6. Group all documents (no grouping key):**
```javascript
{
  $group: {
    _id: null,
    totalRevenue: { $sum: "$revenue" },
    avgOrderValue: { $avg: "$total" },
    documentCount: { $sum: 1 }
  }
}
// Output: { _id: null, totalRevenue: 125000, avgOrderValue: 87.50, documentCount: 1429 }
```

### Common Accumulator Operators

| Operator | Purpose | Example |
|----------|---------|---------|
| `$sum` | Sum numeric values or count | `{ $sum: "$amount" }` or `{ $sum: 1 }` |
| `$avg` | Calculate average | `{ $avg: "$score" }` |
| `$min` | Find minimum value | `{ $min: "$price" }` |
| `$max` | Find maximum value | `{ $max: "$temperature" }` |
| `$first` | Get first value in group | `{ $first: "$date" }` |
| `$last` | Get last value in group | `{ $last: "$status" }` |
| `$push` | Collect values into array | `{ $push: "$item" }` |
| `$addToSet` | Collect unique values | `{ $addToSet: "$tag" }` |

### Combining $match and $group

**Real-world Example: E-commerce Sales Analysis**

```javascript
// Calculate total sales by category for completed orders in January 2026
db.orders.aggregate([
  // Stage 1: Filter to completed orders in date range
  {
    $match: {
      status: "completed",
      orderDate: {
        $gte: ISODate("2026-01-01"),
        $lt: ISODate("2026-02-01")
      }
    }
  },
  
  // Stage 2: Unwind items array to process each item
  {
    $unwind: "$items"
  },
  
  // Stage 3: Match only Electronics and Computers
  {
    $match: {
      "items.category": { $in: ["Electronics", "Computers"] }
    }
  },
  
  // Stage 4: Group by category and calculate metrics
  {
    $group: {
      _id: "$items.category",
      totalRevenue: {
        $sum: {
          $multiply: ["$items.price", "$items.quantity"]
        }
      },
      totalItems: { $sum: "$items.quantity" },
      avgItemPrice: { $avg: "$items.price" },
      orders: { $addToSet: "$_id" }
    }
  },
  
  // Stage 5: Add order count
  {
    $addFields: {
      orderCount: { $size: "$orders" }
    }
  },
  
  // Stage 6: Remove orders array (just needed for count)
  {
    $project: {
      orders: 0
    }
  },
  
  // Stage 7: Sort by revenue descending
  {
    $sort: { totalRevenue: -1 }
  }
])
```

**Output:**
```javascript
[
  {
    _id: "Computers",
    totalRevenue: 458900,
    totalItems: 342,
    avgItemPrice: 1250.50,
    orderCount: 187
  },
  {
    _id: "Electronics",
    totalRevenue: 287600,
    totalItems: 891,
    avgItemPrice: 325.75,
    orderCount: 412
  }
]
```

### Performance Considerations

**1. Place $match early:**
```javascript
// GOOD: Filter first, then group
[
  { $match: { status: "active" } },
  { $group: { _id: "$type", count: { $sum: 1 } } }
]

// BAD: Group all, then filter (processes unnecessary data)
[
  { $group: { _id: "$type", count: { $sum: 1 } } },
  { $match: { count: { $gt: 10 } } }
]
```

**2. Use indexes with $match:**
- Create indexes on fields used in early `$match` stages
- MongoDB can use indexes only for `$match` at the pipeline start

**3. Group on indexed fields when possible:**
- Grouping by indexed fields can be more efficient

After completing the materials, try this exercise (do not spend more than 20 minutes):

Given a `transactions` collection:
```javascript
{
  _id: 1,
  userId: "user123",
  type: "purchase",
  amount: 150.00,
  category: "Groceries",
  date: ISODate("2026-01-15"),
  status: "completed"
}
```

Write aggregation pipelines to:

1. **Calculate total spending by user for completed transactions**
   - Show userId, totalSpent, and transactionCount
   - Sort by totalSpent descending

2. **Find average transaction amount by category**
   - Only include "purchase" type transactions
   - Show category, avgAmount, and count

3. **Monthly sales summary**
   - Group by year and month
   - Calculate total revenue, transaction count, and average per transaction
   - Only include completed transactions from 2026

4. **Top 5 spending users**
   - Sum all completed purchase amounts per user
   - Show user's total spending
   - Limit to top 5
