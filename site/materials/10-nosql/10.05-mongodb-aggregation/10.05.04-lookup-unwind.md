# Lesson 4: $lookup for Joins and $unwind for Arrays

## Learning Objectives

By the end of this lesson, you will be able to:
- Use $lookup to join data from multiple collections
- Apply $unwind to deconstruct array fields
- Combine $lookup and $unwind for complex queries
- Understand performance implications of joins and array operations

---

## Introduction

MongoDB's document model encourages embedding related data, but sometimes you need to reference data across collections. The `$lookup` stage performs left outer joins, bringing related documents together in your pipeline. The `$unwind` stage deconstructs arrays into individual documents, enabling you to filter, group, and analyze array elements. Together, these stages handle scenarios where denormalization isn't practical, such as many-to-many relationships or frequently changing reference data.

## Key Concepts Summary

### $lookup Stage (Basic Syntax)

The `$lookup` stage performs a left outer join to another collection.

**Basic Syntax:**
```javascript
{
  $lookup: {
    from: "<collection to join>",
    localField: "<field from input documents>",
    foreignField: "<field from foreign collection>",
    as: "<output array field>"
  }
}
```

**Example: Join Orders with Customers**

```javascript
// orders collection
{
  _id: 1,
  customerId: "cust123",
  items: ["item1", "item2"],
  total: 150
}

// customers collection
{
  _id: "cust123",
  name: "Alice Johnson",
  email: "alice@example.com"
}

// Aggregation with $lookup
db.orders.aggregate([
  {
    $lookup: {
      from: "customers",           // Collection to join
      localField: "customerId",    // Field in orders
      foreignField: "_id",         // Field in customers
      as: "customerInfo"           // Output field name
    }
  }
])

// Result
{
  _id: 1,
  customerId: "cust123",
  items: ["item1", "item2"],
  total: 150,
  customerInfo: [
    {
      _id: "cust123",
      name: "Alice Johnson",
      email: "alice@example.com"
    }
  ]
}
```

**Key Points:**
- `$lookup` always returns an **array** (even for one-to-one joins)
- If no match found, array is empty: `customerInfo: []`
- This is a **left outer join**: all documents from left side are returned

### Extracting Joined Data

Since `$lookup` returns an array, extract the first element for one-to-one joins:

```javascript
db.orders.aggregate([
  // Join
  {
    $lookup: {
      from: "customers",
      localField: "customerId",
      foreignField: "_id",
      as: "customerInfo"
    }
  },
  
  // Extract first element
  {
    $addFields: {
      customer: { $arrayElemAt: ["$customerInfo", 0] }
    }
  },
  
  // Remove array
  {
    $project: {
      customerInfo: 0
    }
  }
])

// Result
{
  _id: 1,
  customerId: "cust123",
  items: ["item1", "item2"],
  total: 150,
  customer: {
    _id: "cust123",
    name: "Alice Johnson",
    email: "alice@example.com"
  }
}
```

### $lookup with Pipeline (Advanced)

For complex joins with filtering or transformation:

```javascript
{
  $lookup: {
    from: "<collection>",
    let: { <var1>: <expression>, ... },  // Variables from input docs
    pipeline: [                           // Pipeline to run on foreign collection
      { <stage1> },
      { <stage2> },
      ...
    ],
    as: "<output array field>"
  }
}
```

**Example: Join with Filtering**

```javascript
// Get orders with their active products only
db.orders.aggregate([
  {
    $lookup: {
      from: "products",
      let: { orderItems: "$items" },
      pipeline: [
        // Match products in this order
        {
          $match: {
            $expr: {
              $in: ["$_id", "$$orderItems"]
            },
            status: "active"  // Additional filter
          }
        },
        // Only return needed fields
        {
          $project: {
            name: 1,
            price: 1
          }
        }
      ],
      as: "productDetails"
    }
  }
])
```

### Multi-Field Joins

Join on multiple corresponding fields:

```javascript
db.orders.aggregate([
  {
    $lookup: {
      from: "inventory",
      let: {
        orderProduct: "$product",
        orderWarehouse: "$warehouse"
      },
      pipeline: [
        {
          $match: {
            $expr: {
              $and: [
                { $eq: ["$product", "$$orderProduct"] },
                { $eq: ["$warehouse", "$$orderWarehouse"] }
              ]
            }
          }
        }
      ],
      as: "inventoryInfo"
    }
  }
])
```

### $unwind Stage

The `$unwind` stage deconstructs an array field, outputting one document per array element.

**Basic Syntax:**
```javascript
{
  $unwind: "<array field path>"  // Simple form
}

// Or with options
{
  $unwind: {
    path: "<array field path>",
    includeArrayIndex: "<string>",
    preserveNullAndEmptyArrays: <boolean>
  }
}
```

**Example:**

```javascript
// Input document
{
  _id: 1,
  customer: "Alice",
  items: [
    { product: "Laptop", price: 1000, qty: 1 },
    { product: "Mouse", price: 25, qty: 2 }
  ]
}

// Pipeline with $unwind
db.orders.aggregate([
  {
    $unwind: "$items"
  }
])

// Output (two documents)
[
  {
    _id: 1,
    customer: "Alice",
    items: { product: "Laptop", price: 1000, qty: 1 }
  },
  {
    _id: 1,
    customer: "Alice",
    items: { product: "Mouse", price: 25, qty: 2 }
  }
]
```

### $unwind Options

**includeArrayIndex:**
Adds a field with the array index:

```javascript
{
  $unwind: {
    path: "$items",
    includeArrayIndex: "itemIndex"
  }
}

// Output includes index
{
  _id: 1,
  customer: "Alice",
  items: { product: "Laptop", price: 1000, qty: 1 },
  itemIndex: 0
}
```

**preserveNullAndEmptyArrays:**
Keeps documents even if array is empty/missing:

```javascript
// Document with empty array
{ _id: 2, customer: "Bob", items: [] }

// Without preserveNullAndEmptyArrays: false (default) - document is dropped

// With preserveNullAndEmptyArrays: true
{
  $unwind: {
    path: "$items",
    preserveNullAndEmptyArrays: true
  }
}

// Output keeps document
{ _id: 2, customer: "Bob" }
```

### Combining $lookup and $unwind

**Common Pattern: Join and Flatten**

```javascript
// Get order details with product information
db.orders.aggregate([
  // Stage 1: Join products
  {
    $lookup: {
      from: "products",
      localField: "productIds",
      foreignField: "_id",
      as: "products"
    }
  },
  
  // Stage 2: Unwind products array
  {
    $unwind: "$products"
  },
  
  // Stage 3: Project needed fields
  {
    $project: {
      orderId: "$_id",
      orderDate: 1,
      productName: "$products.name",
      productPrice: "$products.price",
      category: "$products.category"
    }
  }
])
```

### Real-World Example: Order Analytics

```javascript
// Calculate revenue by product category from orders
db.orders.aggregate([
  // Stage 1: Filter to completed orders
  {
    $match: {
      status: "completed",
      orderDate: { $gte: ISODate("2026-01-01") }
    }
  },
  
  // Stage 2: Unwind items array
  {
    $unwind: "$items"
  },
  
  // Stage 3: Join product details
  {
    $lookup: {
      from: "products",
      localField: "items.productId",
      foreignField: "_id",
      as: "productInfo"
    }
  },
  
  // Stage 4: Extract product info
  {
    $addFields: {
      product: { $arrayElemAt: ["$productInfo", 0] }
    }
  },
  
  // Stage 5: Calculate line total
  {
    $addFields: {
      lineTotal: {
        $multiply: ["$items.quantity", "$items.price"]
      }
    }
  },
  
  // Stage 6: Group by category
  {
    $group: {
      _id: "$product.category",
      totalRevenue: { $sum: "$lineTotal" },
      totalItems: { $sum: "$items.quantity" },
      orderCount: { $sum: 1 },
      avgOrderValue: { $avg: "$lineTotal" }
    }
  },
  
  // Stage 7: Sort by revenue
  {
    $sort: { totalRevenue: -1 }
  },
  
  // Stage 8: Shape output
  {
    $project: {
      _id: 0,
      category: "$_id",
      totalRevenue: { $round: ["$totalRevenue", 2] },
      totalItems: 1,
      orderCount: 1,
      avgOrderValue: { $round: ["$avgOrderValue", 2] }
    }
  }
])
```

### Performance Considerations

**$lookup Performance:**
- Can be expensive, especially on large collections
- Consider embedding data when possible
- Ensure indexes exist on `localField` and `foreignField`
- As of MongoDB 5.1, works with sharded collections

**$unwind Performance:**
- Memory-intensive for documents with large arrays
- Consider filtering with `$match` before unwinding
- Use `preserveNullAndEmptyArrays` carefully (can create unexpected results)

**Optimization Strategies:**
1. Filter before joining/unwinding when possible
2. Use `$project` early to reduce document size
3. Index join fields
4. Consider denormalization for frequently joined data

## Practice Exercise

After completing the materials, try this exercise (do not spend more than 25 minutes):

Given these collections:

```javascript
// users collection
{ _id: "user1", name: "Alice", email: "alice@example.com" }

// posts collection
{
  _id: 1,
  userId: "user1",
  title: "My First Post",
  tags: ["mongodb", "database", "nosql"],
  likes: 45,
  createdAt: ISODate("2026-01-15")
}

// comments collection
{
  _id: 101,
  postId: 1,
  userId: "user2",
  text: "Great post!",
  createdAt: ISODate("2026-01-16")
}
```

Write aggregation pipelines to:

1. **Post details with author information**
   - Join posts with users
   - Show post title, author name, author email, tags, and likes
   - Sort by likes descending

2. **Posts with comment counts**
   - Join posts with comments (one-to-many)
   - Count comments per post
   - Show post title, author, comment count
   - Only include posts with > 0 comments

3. **Tag popularity analysis**
   - Unwind tags array from posts
   - Count how many posts use each tag
   - Calculate total likes for posts with each tag
   - Sort by post count descending

4. **User activity report**
   - For a specific user, get all their posts
   - For each post, include comment count
   - Calculate total likes across all user's posts
   - Show: username, total posts, total likes, avg likes per post
