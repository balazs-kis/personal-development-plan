## Learning Objectives

By the end of this lesson, you will be able to:

## Introduction

CRUD operations form the foundation of working with any database. In MongoDB, creating documents (inserting) and reading documents (querying) are the most common operations you'll perform. This lesson covers the syntax, patterns, and best practices for these essential operations.

## Key Concepts Summary

### Creating Documents

**insertOne() - Insert a Single Document:**

```javascript
// Basic insert
db.users.insertOne({
  name: "Alice Johnson",
  email: "alice@example.com",
  age: 30,
  status: "active"
})

// Result
{
  acknowledged: true,
  insertedId: ObjectId("507f1f77bcf86cd799439011")
}
```

**Key Points:**
- MongoDB automatically generates `_id` if not provided
- `acknowledged: true` confirms write was successful
- Returns the `insertedId` for the new document

**insertMany() - Insert Multiple Documents:**

```javascript
// Insert array of documents
db.users.insertMany([
  {
    name: "Bob Smith",
    email: "bob@example.com",
    age: 25
  },
  {
    name: "Charlie Davis",
    email: "charlie@example.com",
    age: 35,
    department: "Engineering"
  },
  {
    name: "Diana Wilson",
    email: "diana@example.com",
    age: 28
  }
])

// Result
{
  acknowledged: true,
  insertedIds: {
    '0': ObjectId("507f1f77bcf86cd799439012"),
    '1': ObjectId("507f1f77bcf86cd799439013"),
    '2': ObjectId("507f1f77bcf86cd799439014")
  }
}
```

**Key Points:**
- More efficient than multiple insertOne() calls
- By default, inserts are ordered (stops on first error)
- Use `{ ordered: false }` for unordered inserts (continues on errors)
- Returns map of inserted IDs

**Ordered vs Unordered Inserts:**

```javascript
// Ordered insert (default) - stops on first error
db.users.insertMany([
  { _id: 1, name: "Alice" },
  { _id: 2, name: "Bob" },
  { _id: 1, name: "Charlie" },  // Duplicate _id - ERROR HERE
  { _id: 3, name: "Diana" }     // This won't be inserted
], { ordered: true })

// Unordered insert - continues despite errors
db.users.insertMany([
  { _id: 1, name: "Alice" },
  { _id: 2, name: "Bob" },
  { _id: 1, name: "Charlie" },  // Duplicate _id - ERROR
  { _id: 3, name: "Diana" }     // This WILL be inserted
], { ordered: false })
```

**Auto-creating Collections:**

```javascript
// Collection is created automatically on first insert
db.newCollection.insertOne({ field: "value" })
// 'newCollection' is now created
```

### Reading Documents

**find() - Query Multiple Documents:**

```javascript
// Find all documents
db.users.find()

// Find with filter
db.users.find({ age: 30 })

// Find with multiple conditions (implicit AND)
db.users.find({ 
  age: 30, 
  status: "active" 
})

// Find all and get array
db.users.find().toArray()
```

**findOne() - Query Single Document:**

```javascript
// Find first matching document
db.users.findOne({ name: "Alice Johnson" })

// Returns null if not found
db.users.findOne({ name: "NonExistent" })  // null

// Find by _id
db.users.findOne({ _id: ObjectId("507f1f77bcf86cd799439011") })
```

**Key Differences:**
- `find()` returns a cursor (iterable)
- `findOne()` returns a single document or null
- `find()` without filters returns all documents
- `findOne()` is faster when you only need one result

### Basic Query Filters

**Exact Match:**

```javascript
// Simple equality
db.users.find({ age: 30 })
db.users.find({ status: "active" })

// Multiple fields (AND)
db.users.find({ 
  age: 30, 
  status: "active" 
})
```

**Nested Fields:**

```javascript
// Documents with nested objects
{
  _id: 1,
  name: "Alice",
  address: {
    city: "Springfield",
    state: "IL",
    zipCode: "62701"
  }
}

// Query nested fields with dot notation
db.users.find({ "address.city": "Springfield" })
db.users.find({ "address.state": "IL" })
```

**Array Fields:**

```javascript
// Documents with arrays
{
  _id: 1,
  name: "Alice",
  tags: ["mongodb", "database", "nosql"]
}

// Match entire array
db.posts.find({ tags: ["mongodb", "database", "nosql"] })

// Match if array contains value
db.posts.find({ tags: "mongodb" })

// Match multiple values (any)
db.posts.find({ tags: { $in: ["mongodb", "postgres"] } })
```

### Working with Cursors

```javascript
// find() returns a cursor
const cursor = db.users.find({ age: { $gte: 25 } })

// Iterate cursor
cursor.forEach(doc => {
  print(doc.name)
})

// Or use toArray()
const docs = db.users.find({ age: { $gte: 25 } }).toArray()

// Cursor methods can be chained
db.users.find({ status: "active" })
        .limit(10)
        .sort({ age: -1 })
```

**Cursor Auto-close:**
- Cursors automatically close after iterating through all results
- Cursors timeout after 10 minutes of inactivity
- Use `.noCursorTimeout()` for long-running operations

### Counting Documents

```javascript
// Count all documents
db.users.countDocuments()

// Count with filter
db.users.countDocuments({ age: { $gte: 25 } })

// Estimated count (faster, less accurate)
db.users.estimatedDocumentCount()
```


### Error Handling

```javascript
// Duplicate _id error
try {
  db.users.insertOne({ 
    _id: "user123", 
    name: "Alice" 
  })
  // Second insert with same _id
  db.users.insertOne({ 
    _id: "user123",  // Error: duplicate key
    name: "Bob" 
  })
} catch (error) {
  print("Error:", error.message)
}

// Check for existing document before insert
const existing = db.users.findOne({ email: "alice@example.com" })
if (!existing) {
  db.users.insertOne({ 
    email: "alice@example.com",
    name: "Alice"
  })
}
```

### Best Practices

**1. Let MongoDB Generate _id:**
```javascript
// GOOD: Let MongoDB generate _id
db.users.insertOne({ name: "Alice", email: "alice@example.com" })

// AVOID: Unless you have a natural unique key
db.users.insertOne({ _id: "custom-id", name: "Alice" })
```

**2. Use insertMany for Bulk Inserts:**
```javascript
// GOOD: Single insertMany
db.users.insertMany(arrayOfUsers)

// AVOID: Multiple insertOne
users.forEach(user => db.users.insertOne(user))  // Slower
```

**3. Validate Before Insert:**
```javascript
// Check required fields
function insertUser(userData) {
  if (!userData.email || !userData.name) {
    throw new Error("Email and name are required")
  }
  return db.users.insertOne(userData)
}
```

**4. Use findOne When You Need One Result:**
```javascript
// GOOD: Use findOne
const user = db.users.findOne({ email: "alice@example.com" })

// AVOID: Using find and taking first
const user = db.users.find({ email: "alice@example.com" }).toArray()[0]
```
