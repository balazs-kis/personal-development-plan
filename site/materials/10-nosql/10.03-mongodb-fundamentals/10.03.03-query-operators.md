# Lesson 3: Query Operators and Expressions

## Learning Objectives

By the end of this lesson, you will be able to:
- Use comparison operators ($eq, $gt, $lt, $gte, $lte, $ne, $in, $nin)
- Apply logical operators ($and, $or, $not, $nor)
- Query arrays with array operators
- Use element and evaluation operators
- Build complex query conditions

---

## Introduction

MongoDB's query language is expressive and powerful, going far beyond simple equality matches. Query operators allow you to filter documents based on ranges, existence, type, regular expressions, and complex logical conditions. Mastering these operators is essential for effective data retrieval.

## Key Concepts Summary

### Comparison Operators

**$eq - Equals:**

```javascript
// Explicit equality
db.users.find({ age: { $eq: 30 } })

// Shorthand (same as above)
db.users.find({ age: 30 })

// With arrays - matches if array contains value
db.posts.find({ tags: { $eq: "mongodb" } })
```

**$ne - Not Equal:**

```javascript
// Find users not age 30
db.users.find({ age: { $ne: 30 } })

// Excludes documents without the field
db.users.find({ status: { $ne: "inactive" } })
```

**$gt, $gte - Greater Than:**

```javascript
// Greater than
db.products.find({ price: { $gt: 100 } })

// Greater than or equal
db.users.find({ age: { $gte: 21 } })

// Combined range query
db.products.find({ 
  price: { $gte: 50, $lte: 150 } 
})
```

**$lt, $lte - Less Than:**

```javascript
// Less than
db.products.find({ stock: { $lt: 10 } })

// Less than or equal
db.users.find({ age: { $lte: 65 } })
```

**$in - Match Any Value:**

```javascript
// Match any value in array
db.users.find({ 
  status: { $in: ["active", "pending"] } 
})

// With numbers
db.products.find({ 
  category_id: { $in: [1, 2, 3] } 
})

// Works with any type
db.orders.find({ 
  _id: { $in: [ObjectId("..."), ObjectId("...")] } 
})
```

**$nin - Not in Array:**

```javascript
// Exclude values
db.users.find({ 
  status: { $nin: ["banned", "suspended"] } 
})

// Also excludes documents without the field
```

### Logical Operators

**$and - Logical AND:**

```javascript
// Explicit $and
db.users.find({ 
  $and: [
    { age: { $gte: 21 } },
    { status: "active" }
  ]
})

// Implicit AND (same field conditions)
db.users.find({ 
  age: { $gte: 21 },
  status: "active"
})

// Use explicit $and for same field, different operators
db.inventory.find({
  $and: [
    { price: { $ne: 1.99 } },
    { price: { $exists: true } }
  ]
})
```

**$or - Logical OR:**

```javascript
// Match either condition
db.users.find({ 
  $or: [
    { age: { $lt: 18 } },
    { age: { $gte: 65 } }
  ]
})

// Multiple conditions
db.products.find({ 
  $or: [
    { onSale: true },
    { price: { $lt: 20 } },
    { featured: true }
  ]
})
```

**$nor - Logical NOR:**

```javascript
// Match documents that fail ALL conditions
db.users.find({ 
  $nor: [
    { status: "inactive" },
    { deleted: true }
  ]
})
// Returns users that are NOT inactive AND NOT deleted
```

**$not - Logical NOT:**

```javascript
// Negates an expression
db.products.find({ 
  price: { $not: { $gt: 100 } } 
})
// Same as: price <= 100 or price doesn't exist

// With regex
db.users.find({ 
  email: { $not: /@example\.com$/ } 
})
```

### Element Operators

**$exists - Field Exists:**

```javascript
// Find documents with field
db.users.find({ 
  middleName: { $exists: true } 
})

// Find documents without field
db.users.find({ 
  middleName: { $exists: false } 
})

// Combined with other operators
db.products.find({ 
  discount: { $exists: true, $gt: 0 } 
})
```

**$type - Field Type:**

```javascript
// Find by BSON type
db.users.find({ 
  age: { $type: "number" } 
})

// By type number
db.users.find({ 
  age: { $type: 16 } // 16 = 32-bit integer
})

// Multiple types
db.collection.find({ 
  field: { $type: ["string", "null"] } 
})

// Common types:
// "double" (1), "string" (2), "object" (3), "array" (4),
// "objectId" (7), "bool" (8), "date" (9), "null" (10),
// "int" (16), "long" (18), "decimal" (19)
```

### Array Query Operators

**$all - Match All Elements:**

```javascript
// Array must contain ALL specified values
db.posts.find({ 
  tags: { $all: ["mongodb", "database"] } 
})
// Order doesn't matter, can have additional elements
```

**$elemMatch - Match Array Element:**

```javascript
// Documents with nested objects/arrays
{
  _id: 1,
  scores: [
    { subject: "math", score: 85 },
    { subject: "english", score: 92 }
  ]
}

// Match array element with multiple conditions
db.students.find({ 
  scores: { 
    $elemMatch: { 
      subject: "math", 
      score: { $gte: 80 } 
    } 
  } 
})

// Without $elemMatch (different behavior)
db.students.find({ 
  "scores.subject": "math",
  "scores.score": { $gte: 80 }
})
// Matches if ANY element has subject="math" AND ANY element has score >= 80
```

**$size - Array Length:**

```javascript
// Find arrays with specific length
db.posts.find({ 
  tags: { $size: 3 } 
})

// Note: Cannot use with ranges like $gt
// Workaround: Store array length in separate field
```

### Evaluation Operators

**$regex - Regular Expression:**

```javascript
// Pattern matching
db.users.find({ 
  email: { $regex: /@example\.com$/ } 
})

// With options
db.users.find({ 
  name: { $regex: "^john", $options: "i" } // Case-insensitive
})

// Options: i (case-insensitive), m (multiline), x (verbose), s (dotall)
```

**$expr - Compare Fields:**

```javascript
// Compare two fields in same document
db.sales.find({ 
  $expr: { $gt: ["$spent", "$budget"] } 
})

// With aggregation expressions
db.monthlyBudget.find({
  $expr: { $gt: [ { $multiply: ["$spent", 5] }, "$budget" ] }
})
```

**$mod - Modulo:**

```javascript
// Find where field % divisor = remainder
db.inventory.find({ 
  qty: { $mod: [5, 0] } // Divisible by 5
})
```

### Complex Query Examples

**Example 1: E-commerce Product Search**

```javascript
// Products: in stock, price range, specific categories
db.products.find({ 
  $and: [
    { inStock: true },
    { price: { $gte: 20, $lte: 100 } },
    { category: { $in: ["electronics", "home"] } },
    { rating: { $gte: 4.0 } }
  ]
})
```

**Example 2: User Filtering**

```javascript
// Active users, verified email, age range, recent login
db.users.find({ 
  status: "active",
  emailVerified: true,
  age: { $gte: 18, $lte: 65 },
  lastLogin: { $gte: new Date("2026-01-01") }
})
```

**Example 3: Advanced Array Query**

```javascript
// Posts with specific tags and comment count
db.posts.find({ 
  $and: [
    { tags: { $all: ["mongodb", "tutorial"] } },
    { tags: { $nin: ["outdated", "deprecated"] } },
    { "comments.0": { $exists: true } } // At least one comment
  ]
})
```

**Example 4: OR with Complex Conditions**

```javascript
// Premium users OR users with many purchases
db.users.find({ 
  $or: [
    { membership: "premium" },
    { 
      $and: [
        { totalPurchases: { $gte: 10 } },
        { accountAge: { $gte: 365 } }
      ]
    }
  ]
})
```

**Example 5: Field Existence and Type**

```javascript
// Documents with optional field of correct type
db.profiles.find({ 
  $or: [
    { phoneNumber: { $exists: false } },
    { 
      $and: [
        { phoneNumber: { $exists: true } },
        { phoneNumber: { $type: "string" } },
        { phoneNumber: { $regex: /^\+?[0-9]{10,15}$/ } }
      ]
    }
  ]
})
```

### Best Practices

**1. Use Indexes for Query Performance:**
```javascript
// Create index for frequently queried fields
db.users.createIndex({ email: 1 })
db.products.createIndex({ category: 1, price: 1 })
```

**2. Avoid $ne and $nin When Possible:**
```javascript
// SLOW: $ne doesn't use indexes efficiently
db.users.find({ status: { $ne: "inactive" } })

// BETTER: Query for specific statuses
db.users.find({ status: { $in: ["active", "pending"] } })
```

**3. Use $exists Carefully:**
```javascript
// Can be slow without index
db.collection.find({ field: { $exists: true } })

// Better to design schema to avoid sparse fields
```

**4. Prefer Implicit AND:**
```javascript
// GOOD: Simple and readable
db.users.find({ age: { $gte: 18 }, status: "active" })

// UNNECESSARY: Explicit $and
db.users.find({ $and: [{ age: { $gte: 18 } }, { status: "active" }] })
```

**5. Validate User Input:**
```javascript
// DANGEROUS: User input in regex
db.users.find({ name: { $regex: userInput } })

// SAFE: Escape regex special characters
const escaped = userInput.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')
db.users.find({ name: { $regex: escaped } })
```
