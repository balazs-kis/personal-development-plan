## Introduction

MongoDB provides two primary tools for interacting with databases: mongosh (the MongoDB Shell) for command-line operations and MongoDB Compass for visual database management. Understanding both tools gives you flexibility—use the shell for scripting and automation, and Compass for visual exploration and ad-hoc queries.

## Key Concepts Summary

### MongoDB Shell (mongosh)

**What is mongosh?**

mongosh is the modern MongoDB Shell, a JavaScript-based REPL (Read-Eval-Print Loop) for interacting with MongoDB:
- Full JavaScript environment
- Native MongoDB commands
- Supports modern JavaScript (ES6+)
- Syntax highlighting and autocomplete
- Replaced the legacy `mongo` shell

**Starting mongosh:**

```bash
# Connect to local MongoDB
mongosh

# Connect with connection string
mongosh "mongodb://localhost:27017"

# Connect to Atlas
mongosh "mongodb+srv://username:password@cluster.mongodb.net/dbname"

# Connect with authentication
mongosh --username alice --password --authenticationDatabase admin
```

**Basic mongosh Commands:**

```javascript
// Show databases
show dbs

// Switch to database
use myDatabase

// Show collections
show collections

// Get current database
db

// Get database stats
db.stats()

// Get collection stats
db.users.stats()

// Clear screen
cls

// Exit shell
exit
```

**Running JavaScript in mongosh:**

```javascript
// Variables
let userName = "Alice"
let age = 30

// Functions
function findUserByEmail(email) {
  return db.users.findOne({ email: email })
}

// Loops
for (let i = 0; i < 10; i++) {
  db.numbers.insertOne({ value: i })
}

// Modern JS features
const users = db.users.find().toArray()
users.forEach(user => {
  print(`${user.name}: ${user.email}`)
})

// Arrow functions
const activeUsers = db.users.find({ status: "active" }).toArray()
const emails = activeUsers.map(u => u.email)
```

**Shell Helpers:**

```javascript
// Help commands
help
db.help()
db.collection.help()

// Load external JavaScript file
load("script.js")

// Pretty print
db.users.findOne().pretty()  // Deprecated, now default

// Format output
db.users.find().limit(5)  // Formatted by default in mongosh
```

**Multi-line Input:**

```javascript
// Use parentheses for multi-line
db.users.find(
  { age: { $gte: 18 } }
).sort(
  { name: 1 }
)

// Functions span multiple lines automatically
function complexQuery() {
  return db.users.aggregate([
    { $match: { status: "active" } },
    { $group: { _id: "$city", count: { $sum: 1 } } }
  ])
}
```

**Script Execution:**

```javascript
// Create a script file: migrate.js
// migrate.js content:
const users = db.users.find({ oldFormat: true })
users.forEach(user => {
  db.users.updateOne(
    { _id: user._id },
    { 
      $set: { newFormat: true },
      $unset: { oldFormat: "" }
    }
  )
})
print("Migration complete")

// Run from command line
mongosh --file migrate.js

// Or load in shell
load("migrate.js")
```

### MongoDB Compass

**What is MongoDB Compass?**

MongoDB Compass is the official GUI for MongoDB:
- Visual database explorer
- Query builder
- Schema analyzer
- Performance insights
- Aggregation pipeline builder
- Index management
- Document editing
- Export/import data

**Connecting to MongoDB:**

1. **Launch Compass**
2. **Enter Connection String:**
   ```
   Local: mongodb://localhost:27017
   Atlas: mongodb+srv://user:pass@cluster.mongodb.net/
   ```
3. **Advanced Options:**
   - Authentication
   - SSL/TLS
   - SSH Tunnel
   - Read Preference
4. **Save Connection (Favorite)**

**Main Interface Components:**

```
┌─────────────────────────────────────────────┐
│  Connections Sidebar                        │
├─────────────────────────────────────────────┤
│  ├─ My Cluster                              │
│  │  ├─ Database 1                           │
│  │  │  ├─ Collection A                      │
│  │  │  └─ Collection B                      │
│  │  └─ Database 2                           │
│  └─ Local MongoDB                           │
├─────────────────────────────────────────────┤
│  Main Content Area                          │
│  - Databases view                           │
│  - Collections view                         │
│  - Documents view                           │
│  - Schema analysis                          │
│  - Aggregation pipeline                     │
│  - Indexes                                  │
└─────────────────────────────────────────────┘
```

**Viewing and Querying Data:**

**Documents Tab:**
- Browse documents
- Visual document editor
- Filter with query bar
- Project (select fields)
- Sort results
- Pagination controls

**Query Bar:**
```json
// Filter
{ "age": { "$gte": 18 }, "status": "active" }

// Project
{ "name": 1, "email": 1 }

// Sort
{ "age": -1 }

// Max Time MS
5000
```

**Schema Tab:**
- Visualizes document structure
- Shows data types
- Displays value ranges
- Helps understand schema variations
- Useful for schema design

**Explain Plan Tab:**
- Query performance analysis
- Index usage
- Execution stats
- Identifies slow queries

**Aggregation Builder:**
- Visual pipeline builder
- Drag-and-drop stages
- Preview at each stage
- Export to code
- Save pipelines

**Creating Documents:**

1. Navigate to collection
2. Click "ADD DATA" → "Insert Document"
3. Edit JSON in editor
4. Click "Insert"

**Editing Documents:**

1. Find document in list view
2. Click edit icon (pencil)
3. Modify JSON
4. Click "Update"

**Deleting Documents:**

1. Find document
2. Click delete icon (trash)
3. Confirm deletion

### Embedded Shell in Compass

**Access mongosh in Compass:**

1. Click `>_MONGOSH` at bottom
2. Or press `Ctrl+`` (backtick)
3. Full mongosh environment within Compass

**Benefits:**
- Run complex queries
- Execute scripts
- Use all mongosh features
- Visual + command-line power

**Common Use Cases:**

```javascript
// Complex updates
db.users.updateMany(
  { status: "inactive", lastLogin: { $lt: new Date("2024-01-01") } },
  { $set: { archived: true } }
)

// Bulk operations
db.products.bulkWrite([
  { updateOne: { filter: { sku: "A123" }, update: { $inc: { stock: 10 } } } },
  { updateOne: { filter: { sku: "B456" }, update: { $inc: { stock: 5 } } } }
])

// Aggregations
db.orders.aggregate([
  { $match: { status: "completed" } },
  { $group: { _id: "$customerId", total: { $sum: "$amount" } } },
  { $sort: { total: -1 } },
  { $limit: 10 }
])
```

### When to Use Each Tool

**Use mongosh when:**
- Scripting and automation
- Bulk operations
- Complex queries requiring JavaScript
- Server administration tasks
- Performance-critical operations
- CI/CD pipelines
- SSH-only access (no GUI)

**Use Compass when:**
- Exploring unfamiliar databases
- Visual schema analysis
- Building aggregation pipelines
- Ad-hoc queries and filtering
- Document editing
- Index management
- Learning MongoDB
- Presentations and demos

**Use Both Together:**
- Compass for exploration
- mongosh for execution
- Embedded shell for quick commands

### Common Administrative Tasks

**Database Management:**

```javascript
// mongosh
use newDatabase        // Create/switch database
db.dropDatabase()      // Delete database

// Stats
db.stats()
db.serverStatus()
```

**Collection Management:**

```javascript
// Create collection
db.createCollection("users")

// Create with options
db.createCollection("products", {
  validator: { $jsonSchema: { ... } },
  validationLevel: "moderate"
})

// Drop collection
db.users.drop()

// Rename collection
db.oldName.renameCollection("newName")
```

**Index Management:**

```javascript
// Create index
db.users.createIndex({ email: 1 }, { unique: true })

// Create compound index
db.products.createIndex({ category: 1, price: -1 })

// List indexes
db.users.getIndexes()

// Drop index
db.users.dropIndex("email_1")

// Drop all indexes
db.users.dropIndexes()
```

**In Compass:**
1. Navigate to collection
2. Click "Indexes" tab
3. Click "CREATE INDEX"
4. Select fields and options
5. Click "Create Index"
