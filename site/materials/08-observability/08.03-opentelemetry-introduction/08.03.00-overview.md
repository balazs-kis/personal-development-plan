# Chapter 8.3: OpenTelemetry Introduction

## Overview
This chapter introduces OpenTelemetry, the vendor-neutral observability standard that provides a unified approach to collecting logs, metrics, and traces. You'll learn about its architecture, SDKs, instrumentation approaches, exporters, and the OpenTelemetry Collector—the components that make OpenTelemetry the CNCF's solution for standardizing observability data.

## Key Concepts
- **OpenTelemetry Standard:** understanding what OpenTelemetry is and why it's become the industry standard for observability.
- **Architecture Components:** learning about the specification, SDKs, APIs, and how they work together.
- **Instrumentation Approaches:** understanding manual vs automatic instrumentation and when to use each.
- **Exporters and Backends:** learning how to send telemetry data to various observability platforms.
- **OpenTelemetry Collector:** mastering the vendor-agnostic proxy for receiving, processing, and exporting telemetry.
