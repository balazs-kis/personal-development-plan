# Chapter 8.4: Distributed Tracing

## Overview
This chapter explores distributed tracing—the practice of tracking requests as they flow through distributed systems and microservices. You'll learn about spans and traces, how context propagates across service boundaries, sampling strategies for managing trace volume, instrumenting code for tracing, and analyzing traces to diagnose latency and errors.

## Key Concepts
- **Spans and Traces:** understanding the fundamental building blocks of distributed tracing.
- **Context Propagation:** learning how trace context flows across service boundaries using W3C standards.
- **Sampling Strategies:** mastering head-based and tail-based sampling to manage trace volume.
- **Code Instrumentation:** implementing tracing in .NET applications using the Activity API.
- **Trace Analysis:** using tools like Jaeger to visualize and analyze traces for debugging.
