# Chapter 8.8: Distributed Tracing with Jaeger

## Overview
This chapter explores Jaeger, an open-source distributed tracing platform originally developed by Uber and now a graduated CNCF project. You'll learn Jaeger's architecture, how to deploy it with various storage backends, analyze traces using the Jaeger UI, understand service dependencies, compare traces, and integrate with OpenTelemetry for comprehensive observability.

## Key Concepts
- **Jaeger Architecture:** understanding components (collector, agent, query, ingester) and deployment modes.
- **Trace Storage Options:** comparing Cassandra, Elasticsearch, OpenSearch, and other backends.
- **Service Dependency Analysis:** visualizing system topology and understanding service relationships.
- **Trace Comparison:** comparing multiple traces to identify performance differences.
- **OpenTelemetry Integration:** using OpenTelemetry SDKs to send traces to Jaeger.
