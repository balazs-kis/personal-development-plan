# Chapter 8.7: Log Aggregation with Loki

## Overview
This chapter explores Grafana Loki, a horizontally scalable, multi-tenant log aggregation system designed to be cost-effective and easy to operate. Unlike traditional logging solutions like Elasticsearch, Loki only indexes metadata (labels), not the full text of logs, making it more resource-efficient. You'll learn Loki's architecture, how to ingest logs with Promtail and other collectors, query logs with LogQL, integrate with Grafana for visualization, and understand when to choose Loki over alternatives.

## Key Concepts
- **Loki Architecture:** understanding components (distributor, ingester, querier) and deployment modes.
- **Log Ingestion:** using Promtail, Grafana Alloy, and other collectors to send logs to Loki.
- **LogQL Query Language:** querying logs with stream selectors, filters, parsers, and aggregations.
- **Grafana Integration:** visualizing logs, creating dashboards, and correlating with metrics.
- **Loki vs Elasticsearch:** comparing indexing strategies, resource usage, and use cases.
