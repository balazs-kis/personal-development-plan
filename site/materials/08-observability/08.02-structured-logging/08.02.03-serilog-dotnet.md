## Introduction

Serilog is the most popular structured logging library for .NET. Unlike built-in logging that can lose structure, Serilog preserves parameters as structured data, enabling powerful querying and filtering. This lesson teaches you to implement Serilog in .NET applications, configure multiple outputs, and take full advantage of structured logging capabilities.

## Key Concepts Summary

### Why Serilog?

**Built-in .NET logging:**
```csharp
// May lose structure
_logger.LogInformation($"User {userId} placed order {orderId}");
// Result: Plain text string

// Structure depends on provider
_logger.LogInformation("User {UserId} placed order {OrderId}", userId, orderId);
// Structure may or may not be preserved
```

**Serilog:**
```csharp
// Always structured
_logger.LogInformation("User {UserId} placed order {OrderId}", userId, orderId);
// Result: JSON with userId and orderId fields
{
  "UserId": "user-123",
  "OrderId": "order-456",
  "Message": "User user-123 placed order order-456"
}
```

**Key benefits:**
```
✓ Always structured (not just with certain providers)
✓ Rich ecosystem of sinks
✓ Powerful enrichers
✓ Message templates
✓ Structured exceptions
✓ Performance optimized
```

### Installation

**NuGet packages:**
```bash
# Core package
dotnet add package Serilog.AspNetCore

# Additional sinks
dotnet add package Serilog.Sinks.Console
dotnet add package Serilog.Sinks.File
dotnet add package Serilog.Sinks.Seq

# Enrichers
dotnet add package Serilog.Enrichers.Environment
dotnet add package Serilog.Enrichers.Thread
```

### Basic Configuration

**Program.cs setup:**
```csharp
using Serilog;

// Create logger early
Log.Logger = new LoggerConfiguration()
    .WriteTo.Console()
    .CreateLogger();

try
{
    Log.Information("Starting application");
    
    var builder = WebApplication.CreateBuilder(args);
    
    // Add Serilog
    builder.Host.UseSerilog((context, services, configuration) => configuration
        .ReadFrom.Configuration(context.Configuration)
        .ReadFrom.Services(services)
        .Enrich.FromLogContext()
        .WriteTo.Console());
    
    var app = builder.Build();
    
    app.Run();
}
catch (Exception ex)
{
    Log.Fatal(ex, "Application terminated unexpectedly");
}
finally
{
    Log.CloseAndFlush();
}
```

**appsettings.json:**
```json
{
  "Serilog": {
    "Using": ["Serilog.Sinks.Console", "Serilog.Sinks.File"],
    "MinimumLevel": {
      "Default": "Information",
      "Override": {
        "Microsoft": "Warning",
        "Microsoft.AspNetCore": "Warning"
      }
    },
    "WriteTo": [
      {
        "Name": "Console"
      },
      {
        "Name": "File",
        "Args": {
          "path": "logs/log-.txt",
          "rollingInterval": "Day"
        }
      }
    ],
    "Enrich": ["FromLogContext", "WithMachineName", "WithThreadId"]
  }
}
```

### Message Templates

**Basic templates:**
```csharp
// Property capture
_logger.LogInformation("User {UserId} logged in", userId);
// → {"UserId": "user-123", "Message": "User user-123 logged in"}

// Multiple properties
_logger.LogInformation(
    "Order {OrderId} placed by {UserId} for ${Amount}",
    orderId,
    userId,
    amount);
```

**Destructuring (`@` operator):**
```csharp
var user = new User { Id = 123, Name = "John", Email = "john@example.com" };

// Without @: ToString() called
_logger.LogInformation("User logged in: {User}", user);
// → {"User": "User { Id: 123, Name: John }"}

// With @: Object structure preserved
_logger.LogInformation("User logged in: {@User}", user);
// → {"User": {"Id": 123, "Name": "John", "Email": "john@example.com"}}
```

**Stringify (`$` operator):**
```csharp
// Force string conversion
_logger.LogInformation("Processing {$Data}", complexObject);
// → {"Data": "ComplexObject.ToString()"}
```

**Format specifiers:**
```csharp
// Formatting
_logger.LogInformation("Amount: {Amount:C}", 99.99);
// → {"Amount": "$99.99"}

_logger.LogInformation("Date: {Date:yyyy-MM-dd}", DateTime.Now);
// → {"Date": "2026-01-27"}
```

### Sinks

**Console sink:**
```csharp
.WriteTo.Console()

// With formatting
.WriteTo.Console(
    outputTemplate: "[{Timestamp:HH:mm:ss} {Level:u3}] {Message:lj}{NewLine}{Exception}")
```

**File sink:**
```csharp
.WriteTo.File(
    path: "logs/log-.txt",
    rollingInterval: RollingInterval.Day,
    retainedFileCountLimit: 7,
    outputTemplate: "{Timestamp:yyyy-MM-dd HH:mm:ss.fff zzz} [{Level:u3}] {Message:lj}{NewLine}{Exception}")
```

**JSON file:**
```csharp
.WriteTo.File(
    new JsonFormatter(),
    path: "logs/log-.json",
    rollingInterval: RollingInterval.Day)
```

**Seq (log server):**
```csharp
.WriteTo.Seq("http://localhost:5341")

// With API key
.WriteTo.Seq(
    serverUrl: "http://localhost:5341",
    apiKey: "your-api-key")
```

**Multiple sinks:**
```csharp
.WriteTo.Console()
.WriteTo.File("logs/log-.txt", rollingInterval: RollingInterval.Day)
.WriteTo.Seq("http://localhost:5341")
// All sinks receive logs simultaneously
```

### Enrichers

**Built-in enrichers:**
```csharp
.Enrich.FromLogContext()        // Enables context properties
.Enrich.WithMachineName()       // Adds machine name
.Enrich.WithThreadId()          // Adds thread ID
.Enrich.WithEnvironmentName()   // Adds environment (dev/staging/prod)
```

**Log context usage:**
```csharp
using Serilog.Context;

// Push context property
using (LogContext.PushProperty("OrderId", orderId))
using (LogContext.PushProperty("UserId", userId))
{
    _logger.LogInformation("Processing payment");
    // Both OrderId and UserId included automatically
    
    _logger.LogInformation("Payment complete");
    // Still includes OrderId and UserId
}
// Context disposed, properties removed
```

**Custom enrichers:**
```csharp
public class CorrelationIdEnricher : ILogEventEnricher
{
    private readonly IHttpContextAccessor _httpContextAccessor;

    public void Enrich(LogEvent logEvent, ILogEventPropertyFactory propertyFactory)
    {
        var correlationId = _httpContextAccessor.HttpContext?
            .TraceIdentifier;
        
        if (correlationId != null)
        {
            var property = propertyFactory.CreateProperty(
                "CorrelationId",
                correlationId);
            logEvent.AddPropertyIfAbsent(property);
        }
    }
}

// Register
.Enrich.With<CorrelationIdEnricher>()
```

### Request Logging

**Enable request logging:**
```csharp
// In Program.cs
app.UseSerilogRequestLogging();

// Logs each HTTP request
// GET /api/users responded 200 in 125ms
```

**Custom request logging:**
```csharp
app.UseSerilogRequestLogging(options =>
{
    // Customize message template
    options.MessageTemplate = 
        "HTTP {RequestMethod} {RequestPath} responded {StatusCode} in {Elapsed:0.0000}ms";
    
    // Enrich with custom properties
    options.EnrichDiagnosticContext = (diagnosticContext, httpContext) =>
    {
        diagnosticContext.Set("RequestHost", httpContext.Request.Host.Value);
        diagnosticContext.Set("UserAgent", httpContext.Request.Headers["User-Agent"].ToString());
        diagnosticContext.Set("ClientIP", httpContext.Connection.RemoteIpAddress);
    };
});
```

### Structured Exceptions

**Logging exceptions:**
```csharp
try
{
    await ProcessOrderAsync(order);
}
catch (Exception ex)
{
    _logger.LogError(
        ex,
        "Failed to process order {OrderId} for user {UserId}",
        orderId,
        userId);
}

// Serilog captures full exception structure:
{
  "Level": "Error",
  "Message": "Failed to process order...",
  "OrderId": "order-123",
  "UserId": "user-456",
  "Exception": {
    "Type": "PaymentException",
    "Message": "Payment gateway timeout",
    "StackTrace": "...",
    "InnerException": {...}
  }
}
```

### Minimum Level Overrides

**Configuration:**
```json
{
  "Serilog": {
    "MinimumLevel": {
      "Default": "Information",
      "Override": {
        "Microsoft": "Warning",
        "Microsoft.AspNetCore": "Warning",
        "Microsoft.EntityFrameworkCore": "Warning",
        "System": "Warning",
        "MyApp.Services": "Debug"
      }
    }
  }
}
```

**Effect:**
```
Microsoft.* logs: Only Warning and above
System.* logs: Only Warning and above
MyApp.Services.* logs: Debug and above (more verbose)
Everything else: Information and above
```

### Filters

**Exclude logs:**
```csharp
.Filter.ByExcluding(logEvent => 
    logEvent.Properties.ContainsKey("RequestPath") &&
    logEvent.Properties["RequestPath"].ToString().Contains("/health"))
```

**Include only:**
```csharp
.Filter.ByIncludingOnly(logEvent =>
    logEvent.Level >= LogEventLevel.Warning ||
    logEvent.Properties.ContainsKey("Important"))
```

### Practical Example

**Complete setup:**
```csharp
Log.Logger = new LoggerConfiguration()
    .MinimumLevel.Information()
    .MinimumLevel.Override("Microsoft", LogEventLevel.Warning)
    .Enrich.FromLogContext()
    .Enrich.WithMachineName()
    .Enrich.WithEnvironmentName()
    .WriteTo.Console(
        outputTemplate: "[{Timestamp:HH:mm:ss} {Level:u3}] {Message:lj} {Properties:j}{NewLine}{Exception}")
    .WriteTo.File(
        new JsonFormatter(),
        path: "logs/log-.json",
        rollingInterval: RollingInterval.Day,
        retainedFileCountLimit: 7)
    .WriteTo.Seq("http://localhost:5341")
    .CreateLogger();
```

**Usage in controller:**
```csharp
[ApiController]
[Route("api/[controller]")]
public class OrdersController : ControllerBase
{
    private readonly ILogger<OrdersController> _logger;

    [HttpPost]
    public async Task<IActionResult> CreateOrder([FromBody] CreateOrderRequest request)
    {
        using (LogContext.PushProperty("OrderId", request.OrderId))
        using (LogContext.PushProperty("UserId", request.UserId))
        {
            _logger.LogInformation(
                "Creating order: {@OrderRequest}",
                request);
            
            try
            {
                var order = await _orderService.CreateAsync(request);
                
                _logger.LogInformation(
                    "Order created successfully: {OrderId}",
                    order.Id);
                
                return Ok(order);
            }
            catch (ValidationException ex)
            {
                _logger.LogWarning(
                    ex,
                    "Order validation failed: {Errors}",
                    ex.Errors);
                return BadRequest(ex.Errors);
            }
            catch (Exception ex)
            {
                _logger.LogError(
                    ex,
                    "Failed to create order");
                return StatusCode(500);
            }
        }
    }
}
```
