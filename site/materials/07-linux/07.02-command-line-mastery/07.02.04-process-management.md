## Key Concepts Summary

### Understanding Processes

**What is a process?**
- A running instance of a program
- Has a unique Process ID (PID)
- Has a parent process (PPID), except PID 1
- Consumes system resources (CPU, memory)
- Has a state, priority, and owner

**Process states:**
- **R** - Running or runnable
- **S** - Sleeping (waiting for an event)
- **D** - Uninterruptible sleep (usually I/O)
- **T** - Stopped (suspended)
- **Z** - Zombie (terminated but not reaped)

## The ps Command

**Basic ps syntax:**
```bash
ps [options]
```

### Common ps Usage

**View your processes:**
```bash
ps                              # Your current shell's processes
ps -u username                  # Processes for specific user
```

**View all processes:**
```bash
ps aux                          # All processes, BSD style
ps -ef                          # All processes, UNIX style
ps -ely                         # Long format with priority
```

**Understanding ps aux output:**
```
USER    PID %CPU %MEM    VSZ   RSS TTY   STAT START   TIME COMMAND
root      1  0.0  0.1 169416 11944 ?     Ss   10:00   0:02 /sbin/init
alice  1234  2.5  1.2 892456 99123 ?     Sl   10:15   1:23 /usr/bin/node app.js
```

- **USER** - Process owner
- **PID** - Process ID
- **%CPU** - CPU usage percentage
- **%MEM** - Memory usage percentage
- **VSZ** - Virtual memory size (KB)
- **RSS** - Resident set size (physical memory, KB)
- **TTY** - Terminal (? means no terminal)
- **STAT** - Process state
- **START** - Start time
- **TIME** - CPU time used
- **COMMAND** - Command that started the process

### Filtering and Formatting ps Output

**Filter by name:**
```bash
ps aux | grep nginx             # Find nginx processes
ps aux | grep -i python         # Case-insensitive search
ps aux | grep nginx | grep -v grep   # Remove grep from output
```

**Custom output format:**
```bash
ps -eo pid,user,%cpu,%mem,command          # Custom columns
ps -eo pid,ppid,cmd,%cpu,%mem --sort=-%cpu # Sort by CPU descending
ps -eo pid,cmd --sort=-rss                 # Sort by memory
```

**Process tree:**
```bash
ps -ejH                         # Show process hierarchy
ps axjf                         # ASCII art tree
pstree                          # Better process tree visualization
pstree -p                       # Show PIDs in tree
pstree -u alice                 # Show tree for specific user
```

### Practical ps Examples

**Find resource hogs:**
```bash
# Top CPU consumers
ps aux --sort=-%cpu | head -10

# Top memory consumers
ps aux --sort=-%mem | head -10

# Processes using most CPU time
ps -eo pid,user,time,cmd --sort=-time | head
```

**Process investigation:**
```bash
# Find PID of a process
ps aux | grep "nginx: master"
pidof nginx
pgrep nginx

# Show all threads of a process
ps -L -p 1234

# Show environment variables
ps eww -p 1234

# Show full command line
ps -fp 1234
```

**User and group filtering:**
```bash
# All processes by user
ps -u alice

# Count processes per user
ps aux | tail -n +2 | awk '{print $1}' | sort | uniq -c | sort -rn

# Processes by group
ps -G developers
```

## The top Command

**What is top?**
Top provides a dynamic, real-time view of running processes and system resource usage.

**Basic usage:**
```bash
top                             # Start top
```

**Top interface:**
```
top - 10:30:45 up 2 days, 14:23,  3 users,  load average: 0.52, 0.58, 0.59
Tasks: 245 total,   2 running, 243 sleeping,   0 stopped,   0 zombie
%Cpu(s):  5.2 us,  2.1 sy,  0.0 ni, 92.1 id,  0.3 wa,  0.0 hi,  0.3 si,  0.0 st
MiB Mem :  15951.2 total,   3421.5 free,   8234.2 used,   4295.5 buff/cache
MiB Swap:   8192.0 total,   8192.0 free,      0.0 used.   6892.3 avail Mem

  PID USER      PR  NI    VIRT    RES    SHR S  %CPU  %MEM     TIME+ COMMAND
 1234 alice     20   0  892456  99123  45678 S   5.3   1.2   1:23.45 node
 5678 bob       20   0 1234567 234567  89012 R   3.2   2.8   0:45.12 python
```

### Top Interactive Commands

**While top is running:**
```
h or ?    - Help
q         - Quit
k         - Kill a process (prompts for PID)
r         - Renice a process (change priority)
u         - Filter by user
M         - Sort by memory
P         - Sort by CPU (default)
T         - Sort by running time
c         - Toggle command line/program name
1         - Toggle individual CPU core display
f         - Field management (add/remove columns)
```

**Sorting:**
- **Shift + P** - Sort by CPU usage
- **Shift + M** - Sort by memory usage
- **Shift + T** - Sort by time/running duration

**Filtering:**
```bash
# Start top showing only user's processes
top -u alice

# Update interval (seconds)
top -d 2

# Batch mode (for logging)
top -b -n 1 > top-output.txt
```

## The htop Command

**What is htop?**
An improved, more user-friendly version of top with better visualization and mouse support.

**Installation:**
```bash
# Ubuntu/Debian
sudo apt install htop

# CentOS/RHEL
sudo yum install htop
```

**Advantages over top:**
- Color-coded output
- Horizontal and vertical scrolling
- Mouse support
- Visual CPU/memory bars
- Process tree view (F5)
- Easier to kill/renice processes

**htop interactive commands:**
```
F1 - Help
F2 - Setup (customize display)
F3 - Search
F4 - Filter
F5 - Tree view
F6 - Sort by column
F9 - Kill process
F10 - Quit
```

**Using htop:**
```bash
htop                            # Start htop
htop -u alice                   # Show only alice's processes
htop -p 1234,5678               # Show specific PIDs
```

## Killing Processes

### Understanding Signals

**Common signals:**
```
Signal   Number   Meaning                           Usage
SIGHUP     1      Hang up                          Reload config
SIGINT     2      Interrupt (Ctrl+C)               Interrupt politely
SIGQUIT    3      Quit (Ctrl+\)                    Quit and core dump
SIGKILL    9      Kill (forceful)                  Cannot be caught/ignored
SIGTERM   15      Terminate (graceful, default)    Polite shutdown
SIGSTOP   19      Stop (pause)                     Pause process
SIGCONT   18      Continue                         Resume paused process
```

### The kill Command

**Basic syntax:**
```bash
kill [signal] PID
```

**Send signals:**
```bash
# Graceful termination (default SIGTERM)
kill 1234

# Force kill (SIGKILL)
kill -9 1234
kill -SIGKILL 1234

# Reload configuration (SIGHUP)
kill -1 1234
kill -HUP 1234

# List all signals
kill -l
```

**Best practice for killing processes:**
```bash
# 1. Try graceful shutdown first
kill 1234
sleep 5

# 2. If still running, use SIGKILL
kill -9 1234
```

### The killall Command

**Kill by process name:**
```bash
killall process_name            # Kill all processes with this name
killall -9 firefox              # Force kill all Firefox processes
killall -u alice python3        # Kill all alice's Python processes
killall -i nginx                # Interactive (ask before each)
```

### The pkill Command

**Kill by pattern:**
```bash
pkill pattern                   # Kill processes matching pattern
pkill -9 chrome                 # Force kill chrome processes
pkill -u alice                  # Kill all alice's processes
pkill -f "python.*app.py"       # Kill by full command line
```

**Advanced pkill:**
```bash
pkill -SIGTERM -u alice         # Gracefully terminate alice's processes
pkill -oldest python            # Kill oldest python process
pkill -newest node              # Kill newest node process
```

### Process Management in top/htop

**Kill process in top:**
1. Press `k`
2. Enter PID (or press Enter for highlighted process)
3. Enter signal number (9 for SIGKILL, 15 for SIGTERM)
4. Press Enter

**Kill process in htop:**
1. Navigate to process (arrow keys or mouse)
2. Press `F9`
3. Select signal from list
4. Press Enter

## Process Priority and Nice

**What is nice?**
Process priority ranges from -20 (highest) to 19 (lowest). Default is 0.

**Start process with priority:**
```bash
nice -n 10 command              # Start with lower priority (10)
nice -n -10 command             # Start with higher priority (-10) [requires sudo]
```

**Change running process priority:**
```bash
renice -n 5 -p 1234             # Set process 1234 to priority 5
renice -n 10 -u alice           # Set all alice's processes to 10
```

**In top:**
1. Press `r`
2. Enter PID
3. Enter new nice value

## Background and Foreground Jobs

**Start process in background:**
```bash
command &                       # Run in background
sleep 100 &                     # Example
```

**Job control:**
```bash
jobs                            # List background jobs
fg                              # Bring last job to foreground
fg %1                           # Bring job 1 to foreground
bg                              # Resume job in background
bg %2                           # Resume job 2 in background
```

**Suspend and resume:**
```bash
Ctrl+Z                          # Suspend current process
bg                              # Resume in background
fg                              # Resume in foreground
```

**Disown process (keep running after logout):**
```bash
command &                       # Start in background
disown                          # Detach from shell
```

**Better approach - use nohup:**
```bash
nohup command &                 # Ignore hangup signal
nohup ./script.sh > output.log 2>&1 &
```

## Practical Examples

**Troubleshooting high CPU:**
```bash
# Find process using most CPU
ps aux --sort=-%cpu | head -10
top -o %CPU

# Investigate specific process
ps -fp $(pgrep -n java)
lsof -p 1234                    # Files opened by process
strace -p 1234                  # System calls (debugging)
```

**Finding memory leaks:**
```bash
# Monitor memory usage over time
ps -o pid,user,%mem,rss,cmd -p 1234

# Watch memory grow
watch -n 5 'ps aux --sort=-%mem | head -10'
```

**Cleanup stuck processes:**
```bash
# Find zombie processes
ps aux | grep Z

# Find and kill hung processes
ps aux | grep "D"

# Kill all python processes gracefully
pkill -SIGTERM python
sleep 5
pkill -9 python
```
