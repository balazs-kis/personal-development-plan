## Learning Objectives

By the end of this lesson, you will be able to:
- Use grep to search for patterns in files and command output

- Use grep options for case-insensitive, recursive, and inverse searches
- Count matches and display line numbers
- Combine grep with other commands in pipelines

---

## Introduction

The `grep` command (Global Regular Expression Print) is one of the most essential tools in Linux. It searches for patterns in text files and streams, making it invaluable for log analysis, debugging, and data extraction. Mastering grep will dramatically improve your efficiency when working with Linux systems.

Whether you're searching through application logs, finding configuration entries, or filtering command output, grep is the tool you'll reach for constantly in production environments.

## Key Concepts Summary

### Basic Grep Syntax

```bash
grep [options] pattern [file...]
```

**Search for a pattern in a file:**
```bash
grep "error" app.log
grep "user123" access.log
```

**Search in multiple files:**
```bash
grep "error" *.log
grep "TODO" *.js *.ts
```

**Search in command output (using pipes):**
```bash
ps aux | grep nginx
cat file.txt | grep "pattern"
history | grep git
```

### Essential Grep Options

**Case-insensitive search (-i):**
```bash
grep -i "error" log.txt       # Matches: error, Error, ERROR, ErRoR
```

**Line numbers (-n):**
```bash
grep -n "function" script.js  # Shows line numbers for matches
```

**Recursive search (-r or -R):**
```bash
grep -r "TODO" /path/to/project/    # Search all files in directory
grep -R "import React" ./src/       # Search recursively in src
```

**Inverse search (-v):**
```bash
grep -v "debug" app.log        # Show lines that DON'T contain "debug"
ps aux | grep -v grep          # Remove grep itself from ps output
```

**Count matches (-c):**
```bash
grep -c "error" app.log        # Count how many lines contain "error"
```

**Show only filenames (-l):**
```bash
grep -l "TODO" *.js            # List files containing "TODO"
```

**Show only filenames without match (-L):**
```bash
grep -L "TODO" *.js            # List files NOT containing "TODO"
```

**Context lines (-A, -B, -C):**
```bash
grep -A 3 "error" app.log      # Show 3 lines After match
grep -B 2 "error" app.log      # Show 2 lines Before match
grep -C 5 "error" app.log      # Show 5 lines of Context (before and after)
```

**Quiet mode (-q):**
```bash
grep -q "error" app.log && echo "Errors found!"   # No output, just exit code
```

### Regular Expressions with Grep

**Basic regex (default):**
```bash
grep "^error" log.txt          # Lines starting with "error"
grep "error$" log.txt          # Lines ending with "error"
grep "." log.txt               # Any character (all non-empty lines)
grep "a*b" log.txt             # Zero or more 'a' followed by 'b'
```

**Extended regex (-E):**
```bash
grep -E "error|warning" log.txt           # Match "error" OR "warning"
grep -E "colou?r" text.txt                # Match "color" or "colour"
grep -E "[0-9]{3}" file.txt               # Exactly 3 digits
grep -E "^(http|https)://" urls.txt      # Lines starting with http:// or https://
grep -E "[a-zA-Z]+@[a-zA-Z]+\." emails.txt  # Basic email pattern
```

**Fixed strings (-F):**
```bash
grep -F "user@example.com" log.txt   # Treat pattern as literal string (no regex)
grep -F "$(cat pattern.txt)" file.txt  # Search for exact string from file
```

### Character Classes and Patterns

**Character classes:**
```bash
grep "[aeiou]" file.txt        # Any vowel
grep "[^aeiou]" file.txt       # Any consonant (not vowel)
grep "[0-9]" file.txt          # Any digit
grep "[A-Z]" file.txt          # Any uppercase letter
grep "[a-zA-Z0-9]" file.txt    # Any alphanumeric character
```

**Anchors:**
```bash
grep "^#" config.conf          # Lines starting with #
grep "^$" file.txt             # Empty lines
grep -v "^$" file.txt          # Non-empty lines
grep "log$" file.txt           # Lines ending with "log"
```

### Practical Grep Examples

**Log analysis:**
```bash
# Find all errors in today's logs
grep "ERROR" /var/log/app.log | grep "$(date +%Y-%m-%d)"

# Count errors by type
grep "ERROR" app.log | cut -d: -f2 | sort | uniq -c

# Find 500 errors in web server logs
grep " 500 " /var/log/nginx/access.log

# Show context around exceptions
grep -C 10 "Exception" app.log
```

**Code searching:**
```bash
# Find all TODO comments
grep -rn "TODO" ./src

# Find function definitions
grep -E "function [a-zA-Z_][a-zA-Z0-9_]*" *.js

# Find all imports
grep -r "^import" ./src

# Find files using a specific library
grep -l "import React" src/**/*.tsx
```

**System administration:**
```bash
# Find running processes
ps aux | grep nginx | grep -v grep

# Find listening ports
netstat -tulpn | grep LISTEN

# Search configuration files
grep -r "ServerName" /etc/apache2/

# Find users with bash shell
grep "/bin/bash" /etc/passwd

# Find failed login attempts
grep "Failed password" /var/log/auth.log
```

**Data extraction:**
```bash
# Extract IP addresses (simple pattern)
grep -Eo "([0-9]{1,3}\.){3}[0-9]{1,3}" access.log

# Extract email addresses
grep -Eo "[a-zA-Z0-9._-]+@[a-zA-Z0-9.-]+" file.txt

# Extract URLs
grep -Eo "https?://[a-zA-Z0-9./?=_-]*" file.html
```

### Combining Grep with Other Commands

**Pipeline patterns:**
```bash
# Find and count
cat app.log | grep "error" | wc -l

# Filter, sort, and count unique
grep "ERROR" app.log | cut -d: -f2 | sort | uniq -c | sort -rn

# Find files, then search content
find . -name "*.js" | xargs grep "console.log"

# Search in compressed files
zgrep "error" /var/log/app.log.gz

# Real-time log monitoring
tail -f /var/log/app.log | grep --color "ERROR"
```

After completing the materials, try these exercises (spend 15 minutes):

```bash
# Create a test file
cat > test.log << EOF
2026-01-26 10:00:01 INFO Application started
2026-01-26 10:00:15 ERROR Database connection failed
2026-01-26 10:00:20 WARNING Retrying connection
2026-01-26 10:00:25 INFO Connected to database
2026-01-26 10:01:30 ERROR File not found: /tmp/data.txt
2026-01-26 10:02:45 INFO Processing complete
EOF

# Exercise 1: Basic searches
grep "ERROR" test.log
grep -i "error" test.log
grep -n "ERROR" test.log

# Exercise 2: Count and inverse
grep -c "ERROR" test.log
grep -v "ERROR" test.log

# Exercise 3: Regex patterns
grep "^2026" test.log
grep "ERROR.*database" test.log
grep -E "ERROR|WARNING" test.log

# Exercise 4: Context
grep -A 1 "ERROR" test.log
grep -B 1 "INFO" test.log

# Exercise 5: Practical use
# How many log entries are there?
wc -l test.log

# How many errors occurred?
grep -c "ERROR" test.log

# Show all non-INFO messages
grep -v "INFO" test.log

# Extract timestamps for errors
grep "ERROR" test.log | cut -d' ' -f1,2
```
