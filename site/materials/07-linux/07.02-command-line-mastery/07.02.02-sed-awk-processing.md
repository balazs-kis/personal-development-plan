## Introduction

While grep is excellent for searching, sed (stream editor) and awk are powerful tools for transforming and processing text. Sed excels at search-and-replace operations and text transformations, while awk is ideal for extracting and processing columnar data. Together, they form the core of text processing in Linux.

These tools are essential for log processing, data transformation, report generation, and automating text-based operations in production systems.

## Key Concepts Summary

### Sed - Stream Editor

**Basic sed syntax:**
```bash
sed [options] 'command' file
sed [options] -e 'command1' -e 'command2' file
```

### Sed Substitution

**Basic substitution (s command):**
```bash
# Replace first occurrence per line
sed 's/old/new/' file.txt

# Replace all occurrences per line (g flag)
sed 's/old/new/g' file.txt

# Replace in-place (modify the file)
sed -i 's/old/new/g' file.txt

# Create backup before in-place edit
sed -i.bak 's/old/new/g' file.txt
```

**Case-insensitive replacement:**
```bash
sed 's/error/ERROR/gi' file.txt    # Replace regardless of case
```

**Using different delimiters:**
```bash
# Useful when pattern contains /
sed 's|/home/user|/home/newuser|g' file.txt
sed 's#http://old#https://new#g' file.txt
```

**Capture groups and backreferences:**
```bash
# Swap two words
sed 's/\([a-z]*\) \([a-z]*\)/\2 \1/' file.txt

# Extract and reformat
sed 's/\([0-9]*\)-\([0-9]*\)-\([0-9]*\)/\3\/\2\/\1/' dates.txt  # YYYY-MM-DD to DD/MM/YYYY
```

### Sed Addressing

**Line-specific operations:**
```bash
sed '3d' file.txt                  # Delete line 3
sed '2,5d' file.txt                # Delete lines 2-5
sed '10s/old/new/' file.txt        # Replace only on line 10
sed '$d' file.txt                  # Delete last line
```

**Pattern-based operations:**
```bash
sed '/ERROR/d' log.txt             # Delete lines containing ERROR
sed '/^#/d' config.txt             # Delete comment lines
sed '/^$/d' file.txt               # Delete empty lines
```

### Sed Commands

**Delete (d):**
```bash
sed '/pattern/d' file.txt          # Delete matching lines
sed '1,10d' file.txt               # Delete lines 1-10
```

**Print (p):**
```bash
sed -n '/pattern/p' file.txt       # Print only matching lines (like grep)
sed -n '1,10p' file.txt            # Print lines 1-10 (like head)
```

**Insert (i) and Append (a):**
```bash
sed '3i\New line' file.txt         # Insert before line 3
sed '3a\New line' file.txt         # Append after line 3
sed '/pattern/a\Added text' file.txt  # Append after matching lines
```

**Change (c):**
```bash
sed '/pattern/c\Replacement text' file.txt   # Replace entire line
```

### Practical Sed Examples

**Configuration file editing:**
```bash
# Change server port
sed -i 's/port = 8080/port = 9000/g' config.ini

# Uncomment a line
sed -i 's/^# *ServerName/ServerName/' httpd.conf

# Add configuration entry
sed -i '/\[section\]/a\new_key = value' config.ini
```

**Log processing:**
```bash
# Remove debug lines
sed '/DEBUG/d' app.log > clean.log

# Redact sensitive info
sed 's/password=[^&]*/password=****/g' access.log

# Extract specific log levels
sed -n '/ERROR/p' app.log
```

**Text transformation:**
```bash
# Convert DOS to Unix line endings
sed 's/\r$//' dosfile.txt > unixfile.txt

# Remove trailing whitespace
sed 's/[[:space:]]*$//' file.txt

# Add line numbers
sed = file.txt | sed 'N;s/\n/\t/'
```

## Awk - Pattern Scanning and Processing

**Basic awk syntax:**
```bash
awk 'pattern { action }' file
awk -F'delimiter' 'pattern { action }' file
```

### Awk Field Processing

**Print specific columns:**
```bash
# Print first column
awk '{print $1}' file.txt

# Print multiple columns
awk '{print $1, $3}' file.txt

# Print with custom separator
awk '{print $1 ":" $2}' file.txt

# Print all columns
awk '{print $0}' file.txt
```

**Custom field separator:**
```bash
# CSV file (comma separated)
awk -F',' '{print $1, $3}' data.csv

# Colon separated (like /etc/passwd)
awk -F':' '{print $1, $6}' /etc/passwd

# Multiple separators
awk -F'[,:]' '{print $1}' file.txt
```

### Awk Patterns and Conditions

**Pattern matching:**
```bash
# Print lines matching pattern
awk '/ERROR/ {print $0}' log.txt

# Print specific column from matching lines
awk '/ERROR/ {print $1, $2}' log.txt

# Multiple patterns
awk '/ERROR|WARNING/ {print $0}' log.txt
```

**Conditional processing:**
```bash
# Print if column value matches condition
awk '$3 > 100 {print $1, $3}' file.txt

# Multiple conditions
awk '$3 > 100 && $4 < 200 {print $0}' file.txt

# String comparison
awk '$2 == "active" {print $1}' status.txt

# Pattern and condition
awk '/ERROR/ && $3 > 100 {print $0}' log.txt
```

### Awk Built-in Variables

**Special variables:**
```bash
NR    # Current record (line) number
NF    # Number of fields in current record
FS    # Field separator (default: whitespace)
OFS   # Output field separator (default: space)
ORS   # Output record separator (default: newline)
```

**Examples using variables:**
```bash
# Print line numbers
awk '{print NR, $0}' file.txt

# Print last column
awk '{print $NF}' file.txt

# Print lines with more than 5 fields
awk 'NF > 5' file.txt

# Print with custom output separator
awk 'BEGIN {OFS="|"} {print $1, $2, $3}' file.txt
```

### Awk BEGIN and END

**BEGIN and END blocks:**
```bash
# BEGIN: executed before processing
awk 'BEGIN {print "Starting processing..."} {print $1}' file.txt

# END: executed after processing
awk '{sum += $3} END {print "Total:", sum}' file.txt

# Both together
awk 'BEGIN {print "Name\tScore"} {print $1, $2} END {print "Done"}' data.txt
```

### Practical Awk Examples

**Log analysis:**
```bash
# Count log entries by level
awk '{count[$2]++} END {for (level in count) print level, count[level]}' app.log

# Calculate average response time
awk '{sum += $5; count++} END {print "Average:", sum/count}' metrics.log

# Find slow requests (>1 second)
awk '$5 > 1000 {print $1, $2, $5 "ms"}' access.log
```

**Data extraction:**
```bash
# Extract usernames from /etc/passwd
awk -F':' '{print $1}' /etc/passwd

# Print users with specific shell
awk -F':' '$7 == "/bin/bash" {print $1, $6}' /etc/passwd

# Extract and sum numbers
awk '{sum += $3} END {print sum}' numbers.txt
```

**CSV processing:**
```bash
# Print specific columns from CSV
awk -F',' '{print $1, $4}' data.csv

# Calculate total from CSV
awk -F',' '{sum += $3} END {print "Total:", sum}' sales.csv

# Filter CSV rows
awk -F',' '$2 == "Active" {print $1, $3}' users.csv
```

**System monitoring:**
```bash
# Memory usage by process
ps aux | awk '{sum += $6} END {print "Total MB:", sum/1024}'

# Top memory consumers
ps aux | awk '{print $6, $11}' | sort -rn | head -10

# Disk usage summary
df -h | awk 'NR>1 {print $1, $5}'
```

## Sed vs Awk: When to Use Which

**Use sed when:**
- Simple search-and-replace operations
- Deleting or inserting lines
- Line-based transformations
- In-place file editing

**Use awk when:**
- Processing columnar data
- Performing calculations
- Complex pattern-based processing
- Generating reports
- Working with CSV or structured text

**Example comparison:**
```bash
# Replace text: sed is simpler
sed 's/old/new/g' file.txt
awk '{gsub(/old/, "new"); print}' file.txt

# Extract columns: awk is better
awk '{print $1, $3}' file.txt
sed 's/^\([^ ]*\) [^ ]* \([^ ]*\).*/\1 \2/' file.txt  # Much harder!

# Calculate sum: awk only
awk '{sum += $3} END {print sum}' file.txt
```

## Practice Exercise

After completing the materials, try these exercises (spend 15-20 minutes):

```bash
# Create test files
cat > users.csv << EOF
name,email,age,status
Alice,alice@example.com,28,active
Bob,bob@example.com,35,inactive
Charlie,charlie@example.com,42,active
Diana,diana@example.com,31,active
EOF

cat > access.log << EOF
192.168.1.100 GET /api/users 200 145
192.168.1.101 POST /api/login 401 89
192.168.1.102 GET /api/products 200 234
192.168.1.100 GET /api/profile 500 2100
192.168.1.103 DELETE /api/users/5 204 67
EOF

# Sed exercises
# 1. Replace all instances of 'active' with 'enabled'
sed 's/active/enabled/g' users.csv

# 2. Delete the header line
sed '1d' users.csv

# 3. Extract only active users (using sed like grep)
sed -n '/active/p' users.csv

# 4. Add a comment at the top
sed '1i# User Database' users.csv

# Awk exercises
# 1. Print only names and ages
awk -F',' 'NR>1 {print $1, $3}' users.csv

# 2. Print active users
awk -F',' '$4 == "active" {print $1}' users.csv

# 3. Calculate average age
awk -F',' 'NR>1 {sum += $3; count++} END {print "Average age:", sum/count}' users.csv

# 4. Process access log - print IP and status code
awk '{print $1, $4}' access.log

# 5. Find slow requests (>1000ms)
awk '$5 > 1000 {print $2, $3, "- slow:", $5 "ms"}' access.log

# 6. Count requests by status code
awk '{count[$4]++} END {for (code in count) print code ":", count[code]}' access.log

# Combined pipeline
# Get active users' emails and format them
cat users.csv | sed '1d' | awk -F',' '$4 == "active" {print $2}' | sed 's/@/ at /g'
```
