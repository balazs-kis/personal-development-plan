# Lesson 4: Network Performance Monitoring

## Learning Objectives

By the end of this lesson, you will be able to:
- Monitor network throughput and bandwidth usage
- Identify network errors and dropped packets
- Use tools like ip, ifstat, iftop, and nethogs
- Troubleshoot network performance issues
- Understand network statistics and metrics
- Detect network bottlenecks

---

## Introduction

Network performance affects distributed applications, web services, and database communication. Network bottlenecks can manifest as application timeouts, slow responses, or connection failures. This lesson teaches you to monitor network performance and identify issues before they impact users.

## Key Concepts Summary

### Network Performance Metrics

**Key indicators:**
```
Throughput      - Data transfer rate (Mbps/Gbps)
Bandwidth       - Network capacity
Latency         - Round-trip time (ms)
Packet loss     - Dropped/lost packets (%)
Errors          - Transmission errors
Collisions      - Network collisions (rare on modern networks)
```

### Basic Network Statistics

**Using ip command:**
```bash
# Interface statistics
ip -s link

# Specific interface
ip -s link show eth0

# Detailed statistics
ip -s -s link show eth0
```

**Key metrics:**
```
RX packets  - Received packets
TX packets  - Transmitted packets
RX bytes    - Received bytes
TX bytes    - Transmitted bytes
errors      - Error count
dropped     - Dropped packets
overruns    - Buffer overruns
carrier     - Carrier errors
```

**Example:**
```bash
$ ip -s link show eth0
2: eth0: <BROADCAST,MULTICAST,UP> mtu 1500
    RX: bytes  packets  errors  dropped overrun mcast
    1048576000 1000000  0       5       0       0
    TX: bytes  packets  errors  dropped carrier collsns
    524288000  500000   0       0       0       0
```

### netstat / ss for Connections

**View connections:**
```bash
# Active connections
netstat -an
ss -an

# Connection summary
netstat -s
ss -s

# Listening ports
netstat -tlnp
ss -tlnp
```

**Network statistics:**
```bash
# TCP statistics
netstat -st
ss -t -a

# UDP statistics
netstat -su
ss -u -a
```

### Interface Throughput with ifstat

**Installation:**
```bash
sudo apt install ifstat  # Ubuntu/Debian
sudo dnf install ifstat  # Red Hat/Fedora
```

**Usage:**
```bash
# Current throughput
ifstat

# Monitor every second
ifstat 1

# Specific interface
ifstat -i eth0 1

# Show totals
ifstat -t 1
```

**Example output:**
```
 eth0                 eth1
KB/s in  KB/s out   KB/s in  KB/s out
1024.5    512.3      0.0      0.0
```

### iftop - Real-time Bandwidth Monitor

**Installation:**
```bash
sudo apt install iftop  # Ubuntu/Debian
sudo dnf install iftop  # Red Hat/Fedora
```

**Usage:**
```bash
# Monitor default interface
sudo iftop

# Specific interface
sudo iftop -i eth0

# No DNS resolution
sudo iftop -n

# Show ports
sudo iftop -P
```

**Interactive keys:**
```
t  - Toggle display mode
n  - Toggle DNS resolution
s  - Toggle source
d  - Toggle destination
p  - Toggle port display
q  - Quit
```

### nethogs - Per-Process Bandwidth

**Installation:**
```bash
sudo apt install nethogs  # Ubuntu/Debian
sudo dnf install nethogs  # Red Hat/Fedora
```

**Usage:**
```bash
# Monitor all interfaces
sudo nethogs

# Specific interface
sudo nethogs eth0

# Update every second
sudo nethogs -d 1
```

**Shows:**
- Process name and PID
- User
- Send/receive rates per process

### Bandwidth Testing

**Using iperf3:**
```bash
# Install
sudo apt install iperf3

# Server side
iperf3 -s

# Client side
iperf3 -c server_ip

# Test for 30 seconds
iperf3 -c server_ip -t 30

# Multiple streams
iperf3 -c server_ip -P 4
```

**Using speedtest-cli:**
```bash
# Install
sudo apt install speedtest-cli

# Test internet speed
speedtest-cli

# Show servers
speedtest-cli --list
```

### Ping and Latency

**Basic ping:**
```bash
# Continuous ping
ping hostname

# Limited count
ping -c 10 hostname

# Set interval
ping -i 0.5 hostname  # Every 0.5s

# Flood ping (root only)
sudo ping -f hostname
```

**Statistics:**
```
min/avg/max/stddev
= Minimum, average, maximum, standard deviation
```

### mtr - Advanced Traceroute

**Installation:**
```bash
sudo apt install mtr  # Ubuntu/Debian
sudo dnf install mtr  # Red Hat/Fedora
```

**Usage:**
```bash
# Interactive
mtr hostname

# Report mode
mtr -r -c 10 hostname

# No DNS
mtr -n hostname
```

**Shows:**
- Each hop
- Packet loss per hop
- Latency per hop
```

### Troubleshooting Network Issues

**Symptom: High packet loss**
```bash
# 1. Check interface errors
ip -s link

# 2. Look for:
# - RX/TX errors
# - Dropped packets
# - Overruns

# 3. Check switch/cable
# - Physical connection
# - Cable quality
# - Switch port errors
```

**Symptom: Slow network**
```bash
# 1. Check bandwidth usage
iftop
nethogs

# 2. Test actual speed
iperf3 -c server

# 3. Check for errors
ip -s link
netstat -i

# 4. Check latency
ping -c 100 gateway
mtr destination
```

**Symptom: Connection timeouts**
```bash
# 1. Check connectivity
ping destination

# 2. Check route
traceroute destination
mtr destination

# 3. Check listening services
ss -tlnp | grep PORT

# 4. Check firewall
sudo iptables -L -n
```

### Practical Examples

**Monitor network usage:**
```bash
#!/bin/bash
# Monitor network every 5 seconds

while true; do
    echo "=== $(date) ==="
    ip -s link show eth0 | grep -A 2 "RX:\|TX:"
    echo ""
    sleep 5
done
```

**Alert on high errors:**
```bash
#!/bin/bash
# Alert on network errors

INTERFACE="eth0"
ERRORS=$(ip -s link show $INTERFACE | awk '/RX:/{getline; getline; print $3}')

if [ "$ERRORS" -gt 100 ]; then
    echo "WARNING: $ERRORS errors on $INTERFACE"
    ip -s -s link show $INTERFACE
fi
```

**Log bandwidth usage:**
```bash
#!/bin/bash
# Log network bandwidth

while true; do
    echo "$(date),$(ifstat -i eth0 1 1 | tail -1)" >> network_log.csv
    sleep 60
done
```
