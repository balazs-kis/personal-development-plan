# Lesson 3: Loops: for and while

## Learning Objectives

By the end of this lesson, you will be able to:
- Write for loops to iterate over lists, ranges, and files
- Use while loops for condition-based iteration
- Implement until loops and understand when to use them
- Control loop execution with break and continue
- Use loop patterns for common automation tasks

---

## Introduction

Loops allow you to repeat actions efficiently, making them essential for automation. The `for` loop iterates over a list of items, the `while` loop continues as long as a condition is true, and the `until` loop runs until a condition becomes true. Mastering loops enables you to process files, handle arrays, and automate repetitive tasks.

## Key Concepts Summary

### for Loop Syntax

**Basic syntax:**
```bash
for variable in list; do
    commands
done
```

### for Loop Patterns

**Iterate over explicit values:**
```bash
for name in Alice Bob Charlie; do
    echo "Hello, $name"
done
```

**Iterate over array:**
```bash
fruits=("apple" "banana" "cherry")
for fruit in "${fruits[@]}"; do
    echo "Fruit: $fruit"
done
```

**Iterate over command output:**
```bash
for user in $(cat /etc/passwd | cut -d: -f1); do
    echo "User: $user"
done

# Better: use while to handle spaces in output
while IFS= read -r user; do
    echo "User: $user"
done < <(cut -d: -f1 /etc/passwd)
```

**Iterate over files (glob pattern):**
```bash
for file in *.txt; do
    echo "Processing $file"
    wc -l "$file"
done

# Recursively with find
for file in $(find . -name "*.log"); do
    echo "Log file: $file"
done
```

**Range iteration (brace expansion):**
```bash
# Numbers
for i in {1..5}; do
    echo "Number: $i"
done

# With step
for i in {0..20..2}; do
    echo "Even number: $i"
done

# Letters
for letter in {a..z}; do
    echo "$letter"
done
```

**C-style for loop:**
```bash
for ((i=1; i<=10; i++)); do
    echo "Iteration $i"
done

# Multiple conditions
for ((i=0, j=10; i<j; i++, j--)); do
    echo "i=$i, j=$j"
done
```

### while Loop Syntax

**Basic syntax:**
```bash
while [ condition ]; do
    commands
done
```

**Examples:**
```bash
# Counter loop
count=1
while [ $count -le 5 ]; do
    echo "Count: $count"
    ((count++))
done

# With (( ))
count=1
while ((count <= 5)); do
    echo "Count: $count"
    ((count++))
done
```

**Read file line by line:**
```bash
while IFS= read -r line; do
    echo "Line: $line"
done < file.txt

# With pipe
cat file.txt | while read line; do
    echo "Line: $line"
done
```

**Infinite loop:**
```bash
while true; do
    echo "Press Ctrl+C to stop"
    sleep 1
done

# Alternative
while :; do
    echo "Running..."
    sleep 1
done
```

### until Loop

**Syntax (opposite of while):**
```bash
until [ condition ]; do
    commands
done
```

**Examples:**
```bash
# Wait until condition becomes true
count=1
until [ $count -gt 5 ]; do
    echo "Count: $count"
    ((count++))
done

# Wait for file
until [ -f "/tmp/ready" ]; do
    echo "Waiting for file..."
    sleep 2
done
echo "File exists!"

# Wait for service
until curl -s http://localhost:8080/health > /dev/null; do
    echo "Waiting for service..."
    sleep 5
done
echo "Service is up!"
```

### Loop Control: break and continue

**break - Exit loop entirely:**
```bash
for i in {1..10}; do
    if [ $i -eq 5 ]; then
        echo "Breaking at $i"
        break
    fi
    echo "Number: $i"
done
echo "Loop exited"
```

**continue - Skip to next iteration:**
```bash
for i in {1..10}; do
    if [ $((i % 2)) -eq 0 ]; then
        continue  # Skip even numbers
    fi
    echo "Odd number: $i"
done
```

**With nested loops:**
```bash
for i in {1..3}; do
    for j in {1..3}; do
        if [ $i -eq 2 ] && [ $j -eq 2 ]; then
            break 2  # Break out of both loops
        fi
        echo "i=$i, j=$j"
    done
done
```

### Practical Loop Examples

**Process multiple files:**
```bash
#!/bin/bash

for logfile in /var/log/*.log; do
    if [ -r "$logfile" ]; then
        echo "Processing $logfile"
        error_count=$(grep -c "ERROR" "$logfile" 2>/dev/null || echo 0)
        echo "  Errors: $error_count"
    fi
done
```

**Backup script:**
```bash
#!/bin/bash

backup_dir="/backup"
timestamp=$(date +%Y%m%d_%H%M%S)

for dir in /var/www /etc/nginx /home/user/projects; do
    if [ -d "$dir" ]; then
        dirname=$(basename "$dir")
        backup_file="${backup_dir}/${dirname}_${timestamp}.tar.gz"
        echo "Backing up $dir to $backup_file"
        tar -czf "$backup_file" "$dir" 2>/dev/null
    fi
done
```

**Service health check:**
```bash
#!/bin/bash

services=("nginx" "postgresql" "redis")
failed=()

for service in "${services[@]}"; do
    if systemctl is-active --quiet "$service"; then
        echo "✓ $service is running"
    else
        echo "✗ $service is not running"
        failed+=("$service")
    fi
done

if [ ${#failed[@]} -gt 0 ]; then
    echo "Failed services: ${failed[*]}"
    exit 1
fi
```

**Menu with while loop:**
```bash
#!/bin/bash

while true; do
    echo ""
    echo "Menu:"
    echo "1) List files"
    echo "2) Show date"
    echo "3) Show users"
    echo "4) Exit"
    read -p "Choice: " choice
    
    case "$choice" in
        1) ls -l ;;
        2) date ;;
        3) who ;;
        4) echo "Goodbye!"; break ;;
        *) echo "Invalid option" ;;
    esac
done
```

**Wait for condition:**
```bash
#!/bin/bash

max_attempts=30
attempt=0

until curl -sf http://localhost:8080/health > /dev/null; do
    ((attempt++))
    if [ $attempt -ge $max_attempts ]; then
        echo "Service failed to start after $max_attempts attempts"
        exit 1
    fi
    echo "Attempt $attempt: Waiting for service..."
    sleep 2
done

echo "Service is healthy!"
```

**Process array with index:**
```bash
#!/bin/bash

servers=("web1" "web2" "web3")

for i in "${!servers[@]}"; do
    echo "Server $((i+1)): ${servers[$i]}"
    ping -c 1 "${servers[$i]}" &> /dev/null && echo "  Status: UP" || echo "  Status: DOWN"
done
```

### Reading Files Line by Line

**Best practice for reading files:**
```bash
# Method 1: Input redirection (preferred)
while IFS= read -r line; do
    echo "$line"
done < file.txt

# Method 2: Process substitution
while IFS= read -r line; do
    echo "$line"
done < <(command)

# Method 3: Pipe (creates subshell - variables don't persist)
cat file.txt | while read line; do
    echo "$line"
done
```

**Read CSV file:**
```bash
#!/bin/bash

while IFS=',' read -r name age city; do
    echo "Name: $name, Age: $age, City: $city"
done < data.csv
```

**Skip header line:**
```bash
#!/bin/bash

{
    read  # Skip first line
    while IFS=',' read -r name age city; do
        echo "$name is $age years old"
    done
} < data.csv
```

### Nested Loops

**Multiplication table:**
```bash
#!/bin/bash

for i in {1..10}; do
    for j in {1..10}; do
        result=$((i * j))
        printf "%4d" $result
    done
    echo
done
```

**Process multiple directories:**
```bash
#!/bin/bash

dirs=("/var/log" "/tmp" "/home")
extensions=("log" "txt" "conf")

for dir in "${dirs[@]}"; do
    echo "Searching in $dir"
    for ext in "${extensions[@]}"; do
        count=$(find "$dir" -name "*.$ext" 2>/dev/null | wc -l)
        echo "  .$ext files: $count"
    done
done
```

### Loop Best Practices

**1. Always quote variables in loops:**
```bash
# Bad: breaks with spaces in filenames
for file in $(ls); do
    cat $file
done

# Good: preserves spaces
for file in *; do
    cat "$file"
done
```

**2. Use array iteration instead of parsing ls:**
```bash
# Bad
for file in $(ls *.txt); do
    echo "$file"
done

# Good
for file in *.txt; do
    [ -f "$file" ] || continue  # Skip if glob didn't match
    echo "$file"
done
```

**3. Handle empty glob patterns:**
```bash
for file in *.txt; do
    # Skip if pattern didn't match any files
    [ -e "$file" ] || continue
    echo "Processing $file"
done
```

**4. Use while for reading process substitution:**
```bash
# Preserves variables (no subshell)
count=0
while read line; do
    ((count++))
done < <(find . -name "*.txt")
echo "Found $count files"
```
