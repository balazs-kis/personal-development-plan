## Introduction

Variables are fundamental to any scripting language. In Bash, variables store data that your scripts can use and manipulate. Unlike compiled languages, Bash is dynamically typed—you don't declare variable types explicitly. Understanding how to work with variables, arrays, and special parameters is essential for writing effective automation scripts.

## Key Concepts Summary

### Variable Declaration and Assignment

**Basic syntax:**
```bash
# Variable assignment (no spaces around =)
name="Alice"
age=30
path="/home/user"

# Use variables with $
echo "Name: $name"
echo "Age: $age"
echo "Path: $path"
```

**Important rules:**
- No spaces around `=` sign
- Variable names are case-sensitive
- By convention, use lowercase for local variables
- Use UPPERCASE for constants and environment variables

```bash
# Correct
username="alice"
PORT=8080

# Incorrect (will cause errors)
username = "alice"    # Spaces around =
user name="alice"     # Space in name
```

### Quoting Rules

**Double quotes (`"`) - Allow variable expansion:**
```bash
name="World"
echo "Hello $name"       # Output: Hello World
echo "Path: $PATH"       # Output: Path: /usr/bin:/bin:...
```

**Single quotes (`'`) - Literal string (no expansion):**
```bash
name="World"
echo 'Hello $name'       # Output: Hello $name
echo 'Path: $PATH'       # Output: Path: $PATH
```

**No quotes - Word splitting and glob expansion:**
```bash
files=$(ls *.txt)        # Expands wildcards
echo $files              # Word splitting occurs

# Better: use quotes to preserve formatting
echo "$files"
```

**Best practice:** Always quote variables unless you specifically need word splitting.

```bash
# Dangerous - breaks with spaces
file=$1
cat $file               # Breaks if filename has spaces

# Safe - preserves spaces
file="$1"
cat "$file"
```

### Command Substitution

**Capture command output:**
```bash
# Modern syntax (preferred)
current_date=$(date +%Y-%m-%d)
user_count=$(wc -l < /etc/passwd)
files=$(ls *.log)

# Old syntax (deprecated but still works)
current_date=`date +%Y-%m-%d`

# Use the captured value
echo "Today is $current_date"
echo "There are $user_count users"
```

**Nested command substitution:**
```bash
# Modern syntax nests cleanly
result=$(echo "Value: $(date +%H:%M:%S)")

# Old syntax is harder to read
result=`echo "Value: \`date +%H:%M:%S\``
```

### String Manipulation

**String length:**
```bash
name="Alice"
echo ${#name}           # Output: 5
```

**Substring extraction:**
```bash
text="Hello World"
echo ${text:0:5}        # Output: Hello (from position 0, length 5)
echo ${text:6}          # Output: World (from position 6 to end)
echo ${text: -5}        # Output: World (last 5 characters)
```

**Find and replace:**
```bash
path="/usr/local/bin/script.sh"

# Replace first occurrence
echo ${path/bin/sbin}   # /usr/local/sbin/script.sh

# Replace all occurrences
echo ${path//\//\\}     # \usr\local\bin\script.sh (/ to \)

# Remove prefix
echo ${path#*/}         # usr/local/bin/script.sh
echo ${path##*/}        # script.sh (remove longest prefix)

# Remove suffix
echo ${path%/*}         # /usr/local/bin
echo ${path%%/*}        # (empty - remove longest suffix)
```

### Default Values and Parameter Expansion

**Set default if variable is unset:**
```bash
# Use default value if variable is unset or empty
echo ${name:-"Guest"}    # If name is unset, use "Guest"

# Assign default value if unset
: ${PORT:=8080}          # If PORT is unset, set it to 8080

# Error if variable is unset
echo ${required_var:?"Error: required_var is not set"}

# Use alternate value if variable is set
echo ${name:+"Name is set"}
```

**Examples:**
```bash
#!/bin/bash
# Use defaults for optional parameters
host=${1:-"localhost"}
port=${2:-8080}
echo "Connecting to $host:$port"
```

### Arrays

**Indexed arrays:**
```bash
# Declare array
fruits=("apple" "banana" "cherry")

# Access elements (0-indexed)
echo ${fruits[0]}       # apple
echo ${fruits[1]}       # banana
echo ${fruits[2]}       # cherry

# Get all elements
echo ${fruits[@]}       # apple banana cherry
echo ${fruits[*]}       # apple banana cherry

# Array length
echo ${#fruits[@]}      # 3

# Add elements
fruits+=("date")
fruits[4]="elderberry"

# Iterate over array
for fruit in "${fruits[@]}"; do
    echo "Fruit: $fruit"
done
```

**Associative arrays (Bash 4+):**
```bash
# Declare associative array
declare -A config
config["host"]="localhost"
config["port"]=8080
config["timeout"]=30

# Access
echo ${config["host"]}  # localhost

# Get all keys
echo ${!config[@]}      # host port timeout

# Get all values
echo ${config[@]}       # localhost 8080 30

# Iterate
for key in "${!config[@]}"; do
    echo "$key: ${config[$key]}"
done
```

### Special Variables

**Positional parameters:**
```bash
$0    # Script name
$1    # First argument
$2    # Second argument
...
$9    # Ninth argument
${10} # Tenth argument (braces required for >9)
$#    # Number of arguments
$@    # All arguments as separate words
$*    # All arguments as single word
```

**Process and exit status:**
```bash
$$    # Current shell PID
$!    # PID of last background process
$?    # Exit status of last command
```

**Examples:**
```bash
#!/bin/bash
# Script: greet.sh

echo "Script name: $0"
echo "Number of arguments: $#"
echo "All arguments: $@"

if [ $# -lt 1 ]; then
    echo "Usage: $0 <name>"
    exit 1
fi

echo "Hello, $1!"
```

### Reading User Input

**Basic input:**
```bash
# Prompt and read
echo "Enter your name:"
read name
echo "Hello, $name!"

# Inline prompt
read -p "Enter your age: " age
echo "You are $age years old"

# Silent input (for passwords)
read -sp "Enter password: " password
echo  # New line after silent input
echo "Password received"

# Read with timeout
read -t 5 -p "Enter quickly (5 seconds): " response

# Read into array
echo "Enter multiple values:"
read -a values
echo "You entered: ${values[@]}"
```

### Environment Variables

**Common environment variables:**
```bash
$HOME     # User's home directory
$USER     # Current username
$PATH     # Executable search path
$PWD      # Current working directory
$OLDPWD   # Previous working directory
$SHELL    # Current shell
$HOSTNAME # Machine hostname
```

**Setting environment variables:**
```bash
# For current script only
MY_VAR="value"

# Export for child processes
export MY_VAR="value"

# Temporary for one command
MY_VAR="value" command
```

### Practical Examples

**Configuration script:**
```bash
#!/bin/bash

# Load configuration with defaults
CONFIG_FILE="${1:-config.txt}"
DB_HOST="${DB_HOST:-localhost}"
DB_PORT="${DB_PORT:-5432}"
DB_NAME="${DB_NAME:-myapp}"

echo "Configuration:"
echo "  Config File: $CONFIG_FILE"
echo "  Database: $DB_HOST:$DB_PORT/$DB_NAME"
```

**File processing:**
```bash
#!/bin/bash

# Process all log files
log_dir="/var/log/myapp"
timestamp=$(date +%Y%m%d_%H%M%S)

for logfile in "$log_dir"/*.log; do
    filename=$(basename "$logfile")
    archive_name="${filename%.log}_${timestamp}.gz"
    echo "Archiving $filename to $archive_name"
    gzip -c "$logfile" > "/backup/$archive_name"
done
```

**Array processing:**
```bash
#!/bin/bash

# Server management
servers=("web1.example.com" "web2.example.com" "web3.example.com")

for server in "${servers[@]}"; do
    echo "Checking $server..."
    if ping -c 1 "$server" &> /dev/null; then
        echo "  ✓ $server is up"
    else
        echo "  ✗ $server is down"
    fi
done
```
