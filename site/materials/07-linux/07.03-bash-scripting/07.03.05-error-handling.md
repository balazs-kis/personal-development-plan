## Introduction

Proper error handling is critical for production scripts. Exit codes indicate success or failure, `set` options enforce strict error checking, and `trap` handlers ensure cleanup runs even when scripts fail. Understanding these mechanisms helps you write reliable automation that fails predictably and recovers gracefully.

Without error handling, scripts can silently fail, corrupt data, or leave systems in inconsistent states. This lesson teaches you to write defensive, production-ready scripts.

## Key Concepts Summary

### Exit Codes

**What are exit codes?**
- Every command returns an exit code (0-255)
- 0 means success
- Non-zero means failure
- Stored in `$?` special variable

**Check last command status:**
```bash
ls /nonexistent
echo $?  # Will be non-zero (typically 2)

ls /home
echo $?  # Will be 0 (success)
```

**Exit from script:**
```bash
#!/bin/bash

if [ $# -lt 1 ]; then
    echo "Usage: $0 <filename>" >&2
    exit 1  # Exit with error code
fi

echo "Processing file..."
exit 0  # Exit with success (optional, default)
```

**Common exit codes:**
```bash
0   - Success
1   - General error
2   - Misuse of shell command
126 - Command cannot execute
127 - Command not found
128 - Invalid exit argument
130 - Script terminated by Ctrl+C
255 - Exit code out of range
```

### Set Options for Strict Mode

**set -e (errexit):**
```bash
#!/bin/bash
set -e  # Exit immediately if any command fails

echo "Starting..."
ls /nonexistent  # Script exits here if directory doesn't exist
echo "This won't run if previous command failed"
```

**set -u (nounset):**
```bash
#!/bin/bash
set -u  # Exit if undefined variable is used

name="Alice"
echo "$name"      # OK
echo "$age"       # Error: age is unset
```

**set -o pipefail:**
```bash
#!/bin/bash
set -o pipefail  # Pipeline fails if any command in pipeline fails

# Without pipefail: succeeds (only last command matters)
false | echo "hello"  # exit code: 0

# With pipefail: fails (first command failed)
set -o pipefail
false | echo "hello"  # exit code: 1
```

**Strict mode (combined):**
```bash
#!/bin/bash
set -euo pipefail  # Recommended for production scripts

# Alternative: individual lines
set -e
set -u
set -o pipefail
```

**When NOT to use set -e:**
- When you need to handle command failures explicitly
- In scripts with complex control flow
- When using commands that might legitimately fail

### Handling Errors Explicitly

**Check command success:**
```bash
#!/bin/bash

if command -v git &> /dev/null; then
    echo "Git is installed"
else
    echo "Error: Git not found" >&2
    exit 1
fi
```

**Use && and ||:**
```bash
# Run command2 only if command1 succeeds
command1 && command2

# Run command2 only if command1 fails
command1 || command2

# Chain multiple commands
mkdir /tmp/test && cd /tmp/test && touch file.txt

# Provide default on failure
result=$(command || echo "default")
```

**Manual error checking:**
```bash
#!/bin/bash

cp source.txt dest.txt
if [ $? -ne 0 ]; then
    echo "Error: Copy failed" >&2
    exit 1
fi

# Alternative: inline check
if ! cp source.txt dest.txt; then
    echo "Error: Copy failed" >&2
    exit 1
fi
```

### Error Functions

**Create error handling functions:**
```bash
#!/bin/bash

error_exit() {
    echo "Error: $1" >&2
    exit "${2:-1}"  # Exit with code, default 1
}

# Usage
if [ ! -f "$config_file" ]; then
    error_exit "Config file not found: $config_file" 2
fi
```

**Logging functions:**
```bash
#!/bin/bash

log_error() {
    echo "[ERROR] $(date '+%Y-%m-%d %H:%M:%S') - $*" >&2
}

log_info() {
    echo "[INFO] $(date '+%Y-%m-%d %H:%M:%S') - $*"
}

log_warn() {
    echo "[WARN] $(date '+%Y-%m-%d %H:%M:%S') - $*"
}

# Usage
log_info "Script started"
if ! some_command; then
    log_error "Command failed"
    exit 1
fi
log_info "Script completed"
```

### Trap Command

**Basic trap syntax:**
```bash
trap 'commands' SIGNAL
```

**Common signals:**
```bash
EXIT   - Script exits (any reason)
ERR    - Command fails (with set -e)
INT    - Ctrl+C (SIGINT)
TERM   - Termination signal
HUP    - Hangup signal
```

**Cleanup on exit:**
```bash
#!/bin/bash

temp_dir=$(mktemp -d)

cleanup() {
    echo "Cleaning up..."
    rm -rf "$temp_dir"
}

trap cleanup EXIT  # Run cleanup on exit

# Do work with temp directory
echo "Working in $temp_dir"
touch "$temp_dir/file.txt"

# Cleanup runs automatically on exit
exit 0
```

**Error handling with trap:**
```bash
#!/bin/bash
set -e

error_handler() {
    echo "Error occurred in script at line $1" >&2
    exit 1
}

trap 'error_handler $LINENO' ERR

# Script continues...
```

**Trap Ctrl+C:**
```bash
#!/bin/bash

interrupted() {
    echo ""
    echo "Script interrupted by user"
    exit 130
}

trap interrupted INT

# Long-running operation
for i in {1..100}; do
    echo "Processing item $i..."
    sleep 1
done
```

**Multiple cleanup operations:**
```bash
#!/bin/bash

temp_file=$(mktemp)
temp_dir=$(mktemp -d)

cleanup() {
    echo "Cleaning up..."
    [ -f "$temp_file" ] && rm -f "$temp_file"
    [ -d "$temp_dir" ] && rm -rf "$temp_dir"
    echo "Cleanup complete"
}

trap cleanup EXIT

# Do work...
```

### Comprehensive Error Handling Example

```bash
#!/bin/bash

# Strict mode
set -euo pipefail

# Global variables
readonly SCRIPT_NAME=$(basename "$0")
readonly LOG_FILE="/var/log/${SCRIPT_NAME}.log"
TEMP_DIR=""

# Logging functions
log() {
    echo "[$(date '+%Y-%m-%d %H:%M:%S')] $*" | tee -a "$LOG_FILE"
}

error_exit() {
    log "ERROR: $*" >&2
    exit 1
}

# Cleanup handler
cleanup() {
    local exit_code=$?
    
    if [ -n "$TEMP_DIR" ] && [ -d "$TEMP_DIR" ]; then
        log "Removing temporary directory: $TEMP_DIR"
        rm -rf "$TEMP_DIR"
    fi
    
    if [ $exit_code -eq 0 ]; then
        log "Script completed successfully"
    else
        log "Script failed with exit code $exit_code"
    fi
    
    exit $exit_code
}

# Set trap
trap cleanup EXIT

# Main script
main() {
    log "Script started"
    
    # Validate input
    if [ $# -lt 1 ]; then
        error_exit "Usage: $SCRIPT_NAME <input_file>"
    fi
    
    local input_file=$1
    
    # Check file exists
    if [ ! -f "$input_file" ]; then
        error_exit "Input file not found: $input_file"
    fi
    
    # Create temp directory
    TEMP_DIR=$(mktemp -d) || error_exit "Failed to create temp directory"
    log "Created temp directory: $TEMP_DIR"
    
    # Process file
    log "Processing $input_file..."
    if ! process_file "$input_file"; then
        error_exit "Failed to process file"
    fi
    
    log "Processing complete"
}

process_file() {
    local file=$1
    # Processing logic here
    return 0
}

# Run main function
main "$@"
```

### Debugging Techniques

**Enable debug mode:**
```bash
#!/bin/bash
set -x  # Print commands before executing

echo "Hello"
name="Alice"
echo "Hello, $name"

set +x  # Disable debug mode
```

**Conditional debugging:**
```bash
#!/bin/bash

# Enable debug if DEBUG environment variable is set
[ -n "$DEBUG" ] && set -x

echo "This is logged only with DEBUG=1"
```

**Verbose mode:**
```bash
#!/bin/bash

verbose=false

if [ "$1" = "-v" ] || [ "$1" = "--verbose" ]; then
    verbose=true
    shift
fi

log_verbose() {
    if $verbose; then
        echo "[VERBOSE] $*"
    fi
}

log_verbose "This message shows only in verbose mode"
```

**Check syntax without running:**
```bash
bash -n script.sh  # Check syntax only
shellcheck script.sh  # Lint script (if installed)
```

### Best Practices

**1. Always handle errors:**
```bash
# Good
if ! cp source.txt dest.txt; then
    echo "Error: Copy failed" >&2
    exit 1
fi

# Bad
cp source.txt dest.txt  # Ignores errors
```

**2. Use meaningful exit codes:**
```bash
# Good
readonly ERR_MISSING_FILE=2
readonly ERR_INVALID_INPUT=3
readonly ERR_NETWORK=4

if [ ! -f "$file" ]; then
    exit $ERR_MISSING_FILE
fi

# Bad
exit 1  # Generic error
```

**3. Always cleanup resources:**
```bash
# Good
temp_file=$(mktemp)
trap "rm -f '$temp_file'" EXIT

# Bad
temp_file=$(mktemp)
# No cleanup - file remains
```

**4. Provide helpful error messages:**
```bash
# Good
error_exit "Configuration file '$config_file' not found. Please create it or specify with --config"

# Bad
error_exit "File not found"
```

**5. Validate inputs early:**
```bash
# Good - fail fast
if [ $# -lt 2 ]; then
    error_exit "Usage: $0 <source> <dest>"
fi

source=$1
dest=$2

# Validate more
[ -f "$source" ] || error_exit "Source file not found: $source"
[ -d "$(dirname "$dest")" ] || error_exit "Destination directory doesn't exist"

# Bad - proceed with invalid data
source=$1
dest=$2
cp "$source" "$dest"  # May fail unexpectedly
```
