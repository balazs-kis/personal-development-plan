# Chapter 12.2: Profiling .NET Applications

## Overview

Master profiling tools and techniques for .NET: CPU profiling, memory profiling, allocation analysis, and identifying hotspots in production code. Profilers reveal where time and memory are actually spent, often surprising developers who optimize based on intuition. Data-driven optimization is effective optimization.

## Key Concepts

- **CPU profiling (dotTrace, PerfView):** Identifying where time is spent in your code.
- **Memory profiling (dotMemory):** Understanding memory allocation patterns and finding memory leaks.
- **Allocation tracking:** Tracking object allocations to reduce GC pressure.
- **Flame graphs and call trees:** Visualizing performance data to identify hotspots.
- **Production profiling techniques:** Safely profiling live applications with minimal overhead.
