## Introduction

The cache-aside pattern (also known as lazy loading) is one of the most commonly used caching strategies. In this pattern, the application code is responsible for reading from cache, fetching from the data source on cache misses, and writing back to the cache. This gives you complete control over the caching logic but also means you need to handle cache consistency carefully.

## Key Concepts Summary

### Cache-Aside Flow

```
1. Application receives request
2. Check cache for data
   ├─ Cache hit → Return cached data
   └─ Cache miss → 
      ├─ Fetch from database/source
      ├─ Store in cache
      └─ Return data
```

### Basic Implementation

```csharp
public async Task<Product> GetProductAsync(int id)
{
    var cacheKey = $"product_{id}";
    
    // Try to get from cache
    var cachedProduct = await _cache.GetAsync<Product>(cacheKey);
    if (cachedProduct != null)
    {
        return cachedProduct;
    }
    
    // Cache miss - fetch from database
    var product = await _dbContext.Products.FindAsync(id);
    
    if (product != null)
    {
        // Store in cache for future requests
        await _cache.SetAsync(
            cacheKey,
            product,
            TimeSpan.FromMinutes(10));
    }
    
    return product;
}
```

### ICacheService Abstraction

```csharp
public interface ICacheService
{
    Task<T?> GetAsync<T>(string key, CancellationToken cancellationToken = default);
    
    Task SetAsync<T>(
        string key,
        T value,
        TimeSpan? expiration = null,
        CancellationToken cancellationToken = default);
    
    Task RemoveAsync(string key, CancellationToken cancellationToken = default);
    
    Task RemoveByPrefixAsync(string prefix, CancellationToken cancellationToken = default);
}

public class CacheService : ICacheService
{
    private readonly IDistributedCache _cache;
    private readonly ConcurrentDictionary<string, bool> _keys = new();
    
    public async Task<T?> GetAsync<T>(string key, CancellationToken cancellationToken = default)
    {
        var cachedValue = await _cache.GetStringAsync(key, cancellationToken);
        
        if (string.IsNullOrEmpty(cachedValue))
            return default;
            
        return JsonSerializer.Deserialize<T>(cachedValue);
    }
    
    public async Task SetAsync<T>(
        string key,
        T value,
        TimeSpan? expiration = null,
        CancellationToken cancellationToken = default)
    {
        var serializedValue = JsonSerializer.Serialize(value);
        
        var options = new DistributedCacheEntryOptions
        {
            AbsoluteExpirationRelativeToNow = expiration ?? TimeSpan.FromMinutes(5)
        };
        
        await _cache.SetStringAsync(key, serializedValue, options, cancellationToken);
        _keys.TryAdd(key, true);
    }
    
    public async Task RemoveAsync(string key, CancellationToken cancellationToken = default)
    {
        await _cache.RemoveAsync(key, cancellationToken);
        _keys.TryRemove(key, out _);
    }
    
    public async Task RemoveByPrefixAsync(string prefix, CancellationToken cancellationToken = default)
    {
        var keysToRemove = _keys.Keys.Where(k => k.StartsWith(prefix));
        
        var tasks = keysToRemove.Select(key => RemoveAsync(key, cancellationToken));
        await Task.WhenAll(tasks);
    }
}
```

### Generic Cache-Aside Helper

```csharp
public async Task<T> GetOrSetAsync<T>(
    string key,
    Func<Task<T>> factory,
    TimeSpan? expiration = null,
    CancellationToken cancellationToken = default)
{
    var cachedValue = await GetAsync<T>(key, cancellationToken);
    
    if (cachedValue != null)
        return cachedValue;
    
    var value = await factory();
    
    if (value != null)
    {
        await SetAsync(key, value, expiration, cancellationToken);
    }
    
    return value;
}

// Usage
var product = await _cacheService.GetOrSetAsync(
    $"product_{id}",
    () => _dbContext.Products.FindAsync(id).AsTask(),
    TimeSpan.FromMinutes(10));
```

### Handling Cache Invalidation

```csharp
public async Task UpdateProductAsync(Product product)
{
    await _dbContext.SaveChangesAsync();
    
    // Invalidate cache after update
    await _cacheService.RemoveAsync($"product_{product.Id}");
    
    // Or invalidate all related caches
    await _cacheService.RemoveByPrefixAsync("product_");
}
```

### Cache Stampede Prevention

When cache expires and many requests arrive simultaneously:

```csharp
private readonly SemaphoreSlim _cacheLock = new(1, 1);

public async Task<T> GetOrSetAsync<T>(string key, Func<Task<T>> factory)
{
    var cachedValue = await GetAsync<T>(key);
    if (cachedValue != null) return cachedValue;
    
    // Use semaphore to prevent multiple threads from fetching
    await _cacheLock.WaitAsync();
    try
    {
        // Double-check after acquiring lock
        cachedValue = await GetAsync<T>(key);
        if (cachedValue != null) return cachedValue;
        
        var value = await factory();
        await SetAsync(key, value);
        return value;
    }
    finally
    {
        _cacheLock.Release();
    }
}
```
