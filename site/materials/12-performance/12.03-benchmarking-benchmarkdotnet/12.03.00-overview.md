# Chapter 12.3: Benchmarking with BenchmarkDotNet

## Overview

Create reliable micro-benchmarks with BenchmarkDotNet: setup, measurement, memory diagnostics, comparing implementations, and avoiding common benchmarking mistakes. Micro-benchmarks answer specific questions about code performance. BenchmarkDotNet provides statistically sound measurements that account for JIT warmup and GC effects.

## Key Concepts

- **Benchmark setup and configuration:** Creating benchmark classes, configuring jobs, and running benchmarks correctly.
- **Memory diagnosers:** Tracking allocations and GC pressure to understand memory performance.
- **Parameterized benchmarks:** Testing performance across different input sizes and scenarios.
- **Comparing implementations:** Using baselines to compare different approaches and interpret results.
- **Interpreting results:** Understanding statistical metrics, ratios, and avoiding common pitfalls.
