## Introduction

Processing items in parallel is a common requirement for high-performance applications. While `Task.WhenAll` allows concurrent execution of multiple tasks, it doesn't provide built-in throttling. `Parallel.ForEachAsync`, introduced in .NET 6, fills this gap by providing controlled parallel execution of async operations with automatic throttling. Understanding when and how to use each approach is essential for building efficient concurrent systems.

## Key Concepts Summary

### Parallel.ForEachAsync Basics

**Simple Example:**
```csharp
var urls = new[]
{
    "https://api.example.com/data/1",
    "https://api.example.com/data/2",
    "https://api.example.com/data/3",
    // ... 100 more URLs
};

// Process all URLs concurrently with throttling
await Parallel.ForEachAsync(
    urls,
    new ParallelOptions { MaxDegreeOfParallelism = 10 },
    async (url, ct) =>
    {
        var data = await _httpClient.GetStringAsync(url, ct);
        await ProcessDataAsync(data, ct);
    });
```

**Key Features:**
```
1. Automatic Throttling
   - MaxDegreeOfParallelism limits concurrent operations
   - Default: Environment.ProcessorCount
   - Prevents overwhelming resources

2. Cancellation Support
   - CancellationToken passed to each operation
   - Cooperative cancellation
   - Cancels remaining work efficiently

3. Exception Handling
   - Aggregates exceptions from all operations
   - Throws AggregateException
   - All started operations complete before throwing

4. Efficient Scheduling
   - Work-stealing scheduler
   - Doesn't create task per item upfront
   - Scales well for large collections
```

### Parallel.ForEachAsync vs Task.WhenAll

**Task.WhenAll Approach:**
```csharp
var urls = GetUrls(); // 100 URLs

// Creates 100 tasks immediately
var tasks = urls.Select(async url =>
{
    return await _httpClient.GetStringAsync(url);
});

// Wait for all to complete
var results = await Task.WhenAll(tasks);

// Problems:
// - All 100 HTTP calls start simultaneously
// - May overwhelm server or network
// - No built-in throttling
// - Higher memory usage (100 Task objects)
```

**Parallel.ForEachAsync Approach:**
```csharp
var urls = GetUrls(); // 100 URLs
var results = new ConcurrentBag<string>();

// Only 10 concurrent at a time
await Parallel.ForEachAsync(
    urls,
    new ParallelOptions { MaxDegreeOfParallelism = 10 },
    async (url, ct) =>
    {
        var data = await _httpClient.GetStringAsync(url, ct);
        results.Add(data);
    });

// Benefits:
// - Only 10 HTTP calls concurrent
// - Automatically starts next as each completes
// - Lower memory usage
// - Prevents resource exhaustion
```

**Performance Comparison:**
```
Scenario: 25 tasks, each taking 100ms

Task.WhenAll:
- Time: ~360 ns overhead
- Memory: 25 Task objects immediately
- All tasks start at once
- Good for small batches

Parallel.ForEachAsync (MaxDegreeOfParallelism = 10):
- Time: ~3,197 ns overhead
- Memory: ~10 Tasks at a time
- Controlled concurrency
- Good for large batches with throttling need

Scenario: 10,000 tasks

Task.WhenAll:
- Memory: 10,000 Task objects (~960 KB)
- May overwhelm resources
- All start simultaneously

Parallel.ForEachAsync:
- Memory: Only MaxDegreeOfParallelism tasks at a time
- Scales well
- Controlled resource usage
```

### Configuring MaxDegreeOfParallelism

**Choosing the Right Value:**
```csharp
// CPU-bound work (parallel processing)
// Rule: Set to processor count
await Parallel.ForEachAsync(
    items,
    new ParallelOptions 
    { 
        MaxDegreeOfParallelism = Environment.ProcessorCount 
    },
    async (item, ct) =>
    {
        // CPU-intensive work
        var result = await ProcessCpuBoundAsync(item);
    });

// I/O-bound work (network calls, database queries)
// Rule: Much higher than CPU count
await Parallel.ForEachAsync(
    urls,
    new ParallelOptions 
    { 
        MaxDegreeOfParallelism = 50 // Or 100, 200
    },
    async (url, ct) =>
    {
        // I/O-bound work
        var data = await _httpClient.GetStringAsync(url, ct);
    });

// Guidelines:
// CPU-bound: MaxDegreeOfParallelism = Environment.ProcessorCount
// I/O-bound: 
//   - Start with 10-20x processor count
//   - Test and measure
//   - Consider downstream service limits
//   - Consider rate limiting requirements
```

**Dynamic Throttling:**
```csharp
// Adjust based on response times or errors
public class AdaptiveParallelProcessor
{
    private int _currentDegree = 10;
    
    public async Task ProcessAsync(IEnumerable<string> urls)
    {
        await Parallel.ForEachAsync(
            urls,
            new ParallelOptions 
            { 
                MaxDegreeOfParallelism = _currentDegree 
            },
            async (url, ct) =>
            {
                var sw = Stopwatch.StartNew();
                
                try
                {
                    await _httpClient.GetStringAsync(url, ct);
                    
                    // If fast, increase concurrency
                    if (sw.ElapsedMilliseconds < 100 && _currentDegree < 100)
                    {
                        Interlocked.Increment(ref _currentDegree);
                    }
                }
                catch (HttpRequestException)
                {
                    // If errors, decrease concurrency
                    Interlocked.Exchange(ref _currentDegree, 
                        Math.Max(1, _currentDegree / 2));
                    throw;
                }
            });
    }
}
```

### Cancellation Support

**Cancellation Pattern:**
```csharp
public async Task ProcessItemsAsync(
    IEnumerable<Item> items,
    CancellationToken cancellationToken)
{
    await Parallel.ForEachAsync(
        items,
        new ParallelOptions 
        { 
            MaxDegreeOfParallelism = 10,
            CancellationToken = cancellationToken // Pass to ParallelOptions
        },
        async (item, ct) => // ct is per-operation token
        {
            // Both cancellationToken and ct work
            await ProcessItemAsync(item, ct);
        });
}

// Cancellation behavior:
// 1. No new operations start
// 2. Currently executing operations continue
// 3. They can check ct to stop early
// 4. OperationCanceledException thrown when cancelled
```

**Early Cancellation:**
```csharp
using var cts = new CancellationTokenSource();
var processed = 0;

try
{
    await Parallel.ForEachAsync(
        items,
        new ParallelOptions 
        { 
            MaxDegreeOfParallelism = 10,
            CancellationToken = cts.Token
        },
        async (item, ct) =>
        {
            await ProcessItemAsync(item, ct);
            
            if (Interlocked.Increment(ref processed) >= 100)
            {
                // Cancel after processing 100 items
                cts.Cancel();
            }
        });
}
catch (OperationCanceledException)
{
    // Expected when cancelled
    Console.WriteLine($"Processed {processed} items before cancellation");
}
```

### Exception Handling

**Handling Failures:**
```csharp
var failures = new ConcurrentBag<(string Url, Exception Error)>();

try
{
    await Parallel.ForEachAsync(
        urls,
        new ParallelOptions { MaxDegreeOfParallelism = 10 },
        async (url, ct) =>
        {
            try
            {
                await ProcessUrlAsync(url, ct);
            }
            catch (Exception ex)
            {
                // Collect failures
                failures.Add((url, ex));
                // Don't rethrow - continue processing other items
            }
        });
}
catch (AggregateException ae)
{
    // Only thrown if exceptions are rethrown from body
    foreach (var ex in ae.InnerExceptions)
    {
        Console.WriteLine($"Error: {ex.Message}");
    }
}

// Process failures after
if (!failures.IsEmpty)
{
    Console.WriteLine($"Failed to process {failures.Count} URLs");
    // Retry logic, logging, etc.
}
```

### When to Use Each Approach

**Use Task.WhenAll When:**
```
✅ Tasks already created/running
✅ Small number of tasks (< 100)
✅ No throttling needed
✅ Lowest overhead is critical
✅ Need results in specific order

Example:
var tasks = new[]
{
    GetUserAsync(1),
    GetOrdersAsync(1),
    GetPreferencesAsync(1)
};
var results = await Task.WhenAll(tasks);
```

**Use Parallel.ForEachAsync When:**
```
✅ Large collection to process
✅ Need throttling/concurrency limit
✅ I/O-bound operations
✅ Don't want to create all tasks upfront
✅ Need automatic work scheduling

Example:
// Process 10,000 orders, 20 at a time
await Parallel.ForEachAsync(
    orderIds,
    new ParallelOptions { MaxDegreeOfParallelism = 20 },
    async (orderId, ct) => await ProcessOrderAsync(orderId, ct));
```

**Use SemaphoreSlim + Task.WhenAll When:**
```
✅ Need more control over throttling
✅ Complex scheduling requirements
✅ Conditional throttling

Example:
var semaphore = new SemaphoreSlim(10);
var tasks = urls.Select(async url =>
{
    await semaphore.WaitAsync();
    try
    {
        return await ProcessUrlAsync(url);
    }
    finally
    {
        semaphore.Release();
    }
});
await Task.WhenAll(tasks);
```

### Working with IAsyncEnumerable

**Async Streams:**
```csharp
public async IAsyncEnumerable<Data> GetDataStreamAsync(
    [EnumeratorCancellation] CancellationToken ct = default)
{
    await foreach (var item in FetchItemsAsync(ct))
    {
        yield return await ProcessItemAsync(item, ct);
    }
}

// Process async stream in parallel
await Parallel.ForEachAsync(
    GetDataStreamAsync(),
    new ParallelOptions { MaxDegreeOfParallelism = 10 },
    async (data, ct) =>
    {
        await SaveDataAsync(data, ct);
    });
```

### Real-World Example

**Parallel HTTP Requests:**
```csharp
public class ParallelApiClient
{
    private readonly HttpClient _httpClient;
    private readonly ILogger _logger;
    
    public async Task<List<Product>> GetProductsAsync(
        IEnumerable<int> productIds,
        CancellationToken ct = default)
    {
        var products = new ConcurrentBag<Product>();
        var failures = new ConcurrentBag<int>();
        
        await Parallel.ForEachAsync(
            productIds,
            new ParallelOptions
            {
                MaxDegreeOfParallelism = 20,
                CancellationToken = ct
            },
            async (id, token) =>
            {
                try
                {
                    var product = await _httpClient
                        .GetFromJsonAsync<Product>(
                            $"api/products/{id}", 
                            token);
                    
                    if (product != null)
                        products.Add(product);
                }
                catch (Exception ex)
                {
                    _logger.LogError(ex, 
                        "Failed to fetch product {ProductId}", id);
                    failures.Add(id);
                }
            });
        
        if (!failures.IsEmpty)
        {
            _logger.LogWarning(
                "Failed to fetch {Count} products: {Ids}",
                failures.Count,
                string.Join(", ", failures));
        }
        
        return products.ToList();
    }
}
```
