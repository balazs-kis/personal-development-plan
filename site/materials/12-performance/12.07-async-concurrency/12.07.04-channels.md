## Introduction

The producer-consumer pattern is fundamental to concurrent programming: one or more producers generate data while one or more consumers process it. System.Threading.Channels provides a high-performance, thread-safe way to implement this pattern in .NET. Channels offer better performance than alternatives like ConcurrentQueue, built-in async/await support, and natural backpressure mechanisms for bounded channels. Understanding channels is essential for building efficient async processing pipelines.

## Key Concepts Summary

### What Are Channels?

**Channel Basics:**
```csharp
// Channel is a generic data structure for passing data
// Think: thread-safe, async-enabled queue

// Create unbounded channel
var channel = Channel.CreateUnbounded<Order>();

// Write to channel (producer)
await channel.Writer.WriteAsync(order);

// Read from channel (consumer)
await foreach (var order in channel.Reader.ReadAllAsync())
{
    await ProcessOrderAsync(order);
}

// Complete channel (no more data)
channel.Writer.Complete();
```

**Why Use Channels:**
```
✅ Better than ConcurrentQueue:
- Built-in async/await support
- Efficient waiting (no busy polling)
- Less locking overhead
- Natural completion signaling

✅ Better than BlockingCollection:
- True async support (no blocking)
- Works with async/await
- More efficient in async scenarios

✅ Features:
- Thread-safe
- Producer-consumer synchronization
- Backpressure support (bounded channels)
- Multiple readers/writers support
- Cancellation support
```

### Unbounded vs Bounded Channels

**Unbounded Channel:**
```csharp
// Can grow indefinitely
var channel = Channel.CreateUnbounded<Message>(new UnboundedChannelOptions
{
    SingleReader = false,     // Multiple consumers allowed
    SingleWriter = false,     // Multiple producers allowed
    AllowSynchronousContinuations = false  // Performance/safety trade-off
});

// Characteristics:
// - No limit on items
// - WriteAsync never blocks/waits
// - Memory can grow unbounded
// - Risk of OutOfMemoryException

// Use when:
// - Producer much slower than consumer
// - Memory not a concern
// - Don't need backpressure
```

**Bounded Channel:**
```csharp
// Has capacity limit
var channel = Channel.CreateBounded<Message>(new BoundedChannelOptions(100)
{
    FullMode = BoundedChannelFullMode.Wait,  // Wait when full
    SingleReader = false,
    SingleWriter = false
});

// Characteristics:
// - Fixed maximum capacity
// - WriteAsync blocks when full (if FullMode.Wait)
// - Provides natural backpressure
// - Prevents memory overflow

// Use when:
// - Need backpressure
// - Producer faster than consumer
// - Memory constraints
// - Want to throttle producers
```

**FullMode Options:**
```csharp
// BoundedChannelFullMode.Wait (default)
// - WriteAsync waits until space available
// - Producer slows down naturally
// - Most common choice

var channel = Channel.CreateBounded<int>(new BoundedChannelOptions(10)
{
    FullMode = BoundedChannelFullMode.Wait
});

// BoundedChannelFullMode.DropNewest
// - Drops newest item when full
// - Returns false from TryWrite
// - Useful for "latest value wins" scenarios

var channel = Channel.CreateBounded<int>(new BoundedChannelOptions(10)
{
    FullMode = BoundedChannelFullMode.DropNewest
});

// BoundedChannelFullMode.DropOldest
// - Drops oldest item when full
// - Keeps newest data
// - Useful for sensor data, logs

var channel = Channel.CreateBounded<int>(new BoundedChannelOptions(10)
{
    FullMode = BoundedChannelFullMode.DropOldest
});

// BoundedChannelFullMode.DropWrite
// - Drops the new item being written
// - Preserves existing items
// - Returns false from TryWrite
```

### Basic Producer-Consumer Pattern

**Single Producer, Single Consumer:**
```csharp
public class OrderProcessor
{
    private readonly Channel<Order> _channel;
    
    public OrderProcessor()
    {
        _channel = Channel.CreateUnbounded<Order>();
        
        // Start consumer in background
        _ = Task.Run(ProcessOrdersAsync);
    }
    
    // Producer: Called by API endpoints
    public async Task QueueOrderAsync(Order order)
    {
        await _channel.Writer.WriteAsync(order);
    }
    
    // Consumer: Background processing
    private async Task ProcessOrdersAsync()
    {
        await foreach (var order in _channel.Reader.ReadAllAsync())
        {
            try
            {
                await ProcessOrderAsync(order);
            }
            catch (Exception ex)
            {
                // Log error but keep processing
                _logger.LogError(ex, "Failed to process order {OrderId}", 
                    order.Id);
            }
        }
    }
    
    public async Task StopAsync()
    {
        _channel.Writer.Complete();
        // Wait for consumer to finish processing remaining items
    }
}
```

**Multiple Producers, Multiple Consumers:**
```csharp
public class BackgroundTaskProcessor
{
    private readonly Channel<Func<Task>> _channel;
    private readonly int _consumerCount;
    
    public BackgroundTaskProcessor(int consumerCount = 3)
    {
        _consumerCount = consumerCount;
        _channel = Channel.CreateBounded<Func<Task>>(
            new BoundedChannelOptions(100)
            {
                FullMode = BoundedChannelFullMode.Wait
            });
        
        // Start multiple consumers
        for (int i = 0; i < consumerCount; i++)
        {
            _ = Task.Run(() => ConsumeAsync(i));
        }
    }
    
    // Multiple producers can call this
    public async Task<bool> QueueWorkAsync(
        Func<Task> work,
        CancellationToken ct = default)
    {
        return await _channel.Writer.WaitToWriteAsync(ct) &&
               await _channel.Writer.WriteAsync(work, ct);
    }
    
    // Multiple consumers running in parallel
    private async Task ConsumeAsync(int consumerId)
    {
        await foreach (var work in _channel.Reader.ReadAllAsync())
        {
            try
            {
                _logger.LogDebug("Consumer {Id} processing task", consumerId);
                await work();
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Consumer {Id} task failed", consumerId);
            }
        }
    }
}
```

### Backpressure with Bounded Channels

**Automatic Backpressure:**
```csharp
// Bounded channel with capacity of 10
var channel = Channel.CreateBounded<Order>(10);

// Fast producer
var producerTask = Task.Run(async () =>
{
    for (int i = 0; i < 1000; i++)
    {
        var order = new Order { Id = i };
        
        // This will block when channel is full
        // Natural backpressure - producer waits for consumer
        await channel.Writer.WriteAsync(order);
        
        Console.WriteLine($"Produced order {i}");
    }
    
    channel.Writer.Complete();
});

// Slow consumer
var consumerTask = Task.Run(async () =>
{
    await foreach (var order in channel.Reader.ReadAllAsync())
    {
        // Slow processing
        await Task.Delay(100);
        Console.WriteLine($"Consumed order {order.Id}");
    }
});

await Task.WhenAll(producerTask, consumerTask);

// Producer automatically slows down to match consumer
// Channel never has more than 10 items
// Memory usage bounded
```

**Manual Backpressure Control:**
```csharp
public async Task ProduceWithBackpressureAsync(
    IEnumerable<Message> messages)
{
    foreach (var message in messages)
    {
        // Check if channel can accept more
        while (!_channel.Writer.TryWrite(message))
        {
            // Channel full - wait a bit
            await Task.Delay(10);
            
            // Or: wait for space
            // await _channel.Writer.WaitToWriteAsync();
        }
    }
}
```

### ASP.NET Core Background Processing

**API with Background Worker:**
```csharp
// Controller
[ApiController]
[Route("api/[controller]")]
public class OrdersController : ControllerBase
{
    private readonly IBackgroundTaskQueue _taskQueue;
    
    [HttpPost]
    public async Task<IActionResult> CreateOrder(Order order)
    {
        // Validate order
        if (!ModelState.IsValid)
            return BadRequest(ModelState);
        
        // Queue for background processing
        await _taskQueue.QueueAsync(async ct =>
        {
            await ProcessOrderAsync(order, ct);
        });
        
        // Return immediately
        return Accepted(new { OrderId = order.Id, Status = "Queued" });
    }
}

// Background task queue interface
public interface IBackgroundTaskQueue
{
    Task QueueAsync(Func<CancellationToken, Task> workItem);
    Task<Func<CancellationToken, Task>> DequeueAsync(
        CancellationToken ct);
}

// Implementation
public class BackgroundTaskQueue : IBackgroundTaskQueue
{
    private readonly Channel<Func<CancellationToken, Task>> _queue;
    
    public BackgroundTaskQueue(int capacity)
    {
        var options = new BoundedChannelOptions(capacity)
        {
            FullMode = BoundedChannelFullMode.Wait
        };
        _queue = Channel.CreateBounded<Func<CancellationToken, Task>>(options);
    }
    
    public async Task QueueAsync(Func<CancellationToken, Task> workItem)
    {
        ArgumentNullException.ThrowIfNull(workItem);
        await _queue.Writer.WriteAsync(workItem);
    }
    
    public async Task<Func<CancellationToken, Task>> DequeueAsync(
        CancellationToken ct)
    {
        return await _queue.Reader.ReadAsync(ct);
    }
}

// Background service
public class QueuedHostedService : BackgroundService
{
    private readonly IBackgroundTaskQueue _taskQueue;
    private readonly ILogger _logger;
    
    public QueuedHostedService(
        IBackgroundTaskQueue taskQueue,
        ILogger<QueuedHostedService> logger)
    {
        _taskQueue = taskQueue;
        _logger = logger;
    }
    
    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        _logger.LogInformation("Queued Hosted Service is running");
        
        await BackgroundProcessingAsync(stoppingToken);
    }
    
    private async Task BackgroundProcessingAsync(CancellationToken ct)
    {
        while (!ct.IsCancellationRequested)
        {
            try
            {
                var workItem = await _taskQueue.DequeueAsync(ct);
                await workItem(ct);
            }
            catch (OperationCanceledException)
            {
                // Expected on shutdown
                break;
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Error processing background work");
            }
        }
    }
}

// Registration in Program.cs
builder.Services.AddSingleton<IBackgroundTaskQueue>(
    new BackgroundTaskQueue(capacity: 100));
builder.Services.AddHostedService<QueuedHostedService>();
```

### Advanced Patterns

**Pipeline Pattern:**
```csharp
// Stage 1: Fetch data
var fetchChannel = Channel.CreateUnbounded<int>();

// Stage 2: Transform data
var transformChannel = Channel.CreateUnbounded<string>();

// Stage 3: Save data
var saveChannel = Channel.CreateUnbounded<Data>();

// Producer
var producer = Task.Run(async () =>
{
    for (int i = 0; i < 1000; i++)
    {
        await fetchChannel.Writer.WriteAsync(i);
    }
    fetchChannel.Writer.Complete();
});

// Stage 1: Fetch
var fetcher = Task.Run(async () =>
{
    await foreach (var id in fetchChannel.Reader.ReadAllAsync())
    {
        var data = await FetchDataAsync(id);
        await transformChannel.Writer.WriteAsync(data);
    }
    transformChannel.Writer.Complete();
});

// Stage 2: Transform
var transformer = Task.Run(async () =>
{
    await foreach (var raw in transformChannel.Reader.ReadAllAsync())
    {
        var transformed = TransformData(raw);
        await saveChannel.Writer.WriteAsync(transformed);
    }
    saveChannel.Writer.Complete();
});

// Stage 3: Save
var saver = Task.Run(async () =>
{
    await foreach (var data in saveChannel.Reader.ReadAllAsync())
    {
        await SaveDataAsync(data);
    }
});

await Task.WhenAll(producer, fetcher, transformer, saver);
```
