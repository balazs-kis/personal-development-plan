# Chapter 12.4: Memory Management and GC Optimization

## Overview

Understand .NET garbage collection: generations, GC modes, memory pressure, and techniques for reducing allocations and GC pauses. GC pauses can cause latency spikes. Understanding memory management helps you write code that's efficient and avoids unnecessary allocations.

## Key Concepts

- **GC generations and collection:** Understanding how the generational GC works and optimizes memory management.
- **Large Object Heap (LOH):** Special handling for objects ≥85,000 bytes and performance implications.
- **GC modes (Workstation vs Server):** Choosing the right GC mode based on application characteristics.
- **Reducing allocations:** Techniques to minimize heap allocations and GC pressure.
- **Object pooling:** Using ArrayPool and custom pools to reuse objects and reduce allocations.
