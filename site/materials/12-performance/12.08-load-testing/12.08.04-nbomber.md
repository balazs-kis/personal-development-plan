## Introduction

NBomber is a modern, open-source load testing framework built specifically for .NET. It allows you to write load tests in C# or F#, providing a developer-friendly approach for .NET developers. NBomber supports testing any protocol including HTTP, WebSockets, gRPC, AMQP, Kafka, and direct database access.

## Key Concepts Summary

### Installation

Create a console application and add NBomber:

```bash
# Create new console app
dotnet new console -n MyLoadTest
cd MyLoadTest

# Add NBomber package
dotnet add package NBomber

# For HTTP testing, add HTTP plugin
dotnet add package NBomber.Http
```

### Core Concepts

#### 1. Scenario

A scenario represents a user flow or workload. It contains one or more steps that NBomber executes and measures.

#### 2. Step

A step is a single action within a scenario (e.g., HTTP request, database query). NBomber tracks execution time, success/failure, and other metrics for each step.

#### 3. Load Simulation

Defines how load is applied - constant rate, ramping up, etc.

#### 4. NBomberRunner

Orchestrates test execution and reporting.

### Your First NBomber Test

```csharp
using NBomber.CSharp;

// Define a simple scenario
var scenario = Scenario.Create("hello_world_scenario", async context =>
{
    await Task.Delay(1000); // Simulate work
    return Response.Ok();
})
.WithoutWarmUp()
.WithLoadSimulations(
    Simulation.Inject(
        rate: 10,
        interval: TimeSpan.FromSeconds(1),
        during: TimeSpan.FromSeconds(30)
    )
);

// Run the test
NBomberRunner
    .RegisterScenarios(scenario)
    .Run();
```

**What this does:**
- Creates a scenario that waits 1 second and returns success
- Injects 10 requests per second for 30 seconds
- Runs without warm-up period
- Displays results

### Load Simulation Strategies

#### Inject - Constant Rate

Injects requests at a constant rate (open workload model):

```csharp
Simulation.Inject(
    rate: 100,                          // 100 requests
    interval: TimeSpan.FromSeconds(1),  // per second
    during: TimeSpan.FromMinutes(5)     // for 5 minutes
)
```

#### RampingInject - Gradually Increase

Gradually ramps up the injection rate:

```csharp
Simulation.RampingInject(
    rate: 200,                          // ramp up to 200 requests/sec
    interval: TimeSpan.FromSeconds(1),
    during: TimeSpan.FromMinutes(2)     // over 2 minutes
)
```

Combine multiple simulations:

```csharp
.WithLoadSimulations(
    Simulation.RampingInject(
        rate: 100,
        interval: TimeSpan.FromSeconds(1),
        during: TimeSpan.FromMinutes(1)    // Ramp up
    ),
    Simulation.Inject(
        rate: 100,
        interval: TimeSpan.FromSeconds(1),
        during: TimeSpan.FromMinutes(3)    // Maintain load
    ),
    Simulation.RampingInject(
        rate: 0,
        interval: TimeSpan.FromSeconds(1),
        during: TimeSpan.FromMinutes(1)    // Ramp down
    )
)
```

#### KeepConstant - Constant Virtual Users

Maintains a constant number of virtual users (closed workload model):

```csharp
Simulation.KeepConstant(
    copies: 50,                         // 50 virtual users
    during: TimeSpan.FromMinutes(5)     // for 5 minutes
)
```

#### RampingConstant - Gradually Increase Virtual Users

```csharp
Simulation.RampingConstant(
    copies: 100,                        // ramp up to 100 users
    during: TimeSpan.FromMinutes(2)     // over 2 minutes
)
```

### Multiple Steps in a Scenario

```csharp
var scenario = Scenario.Create("multi_step_scenario", async context =>
{
    // Step 1: Get product list
    var step1 = await Step.Run("get_products", context, async () =>
    {
        var request = Http.CreateRequest("GET", "https://api.example.com/products");
        var response = await Http.Send(httpClient, request);
        return response;
    });
    
    // Step 2: Get product details
    var step2 = await Step.Run("get_product_details", context, async () =>
    {
        var productId = 123; // In reality, parse from step1 response
        var request = Http.CreateRequest("GET", $"https://api.example.com/products/{productId}");
        var response = await Http.Send(httpClient, request);
        return response;
    });
    
    // Step 3: Add to cart
    var step3 = await Step.Run("add_to_cart", context, async () =>
    {
        var payload = new { productId = 123, quantity = 1 };
        var request = Http.CreateRequest("POST", "https://api.example.com/cart")
            .WithJsonBody(payload);
        var response = await Http.Send(httpClient, request);
        return response;
    });
    
    return Response.Ok();
});
```

### Data Feed - Using Test Data

```csharp
// Create data feed
var userFeed = DataFeed.Random(
    data: new[]
    {
        new { Username = "user1@example.com", Password = "pass1" },
        new { Username = "user2@example.com", Password = "pass2" },
        new { Username = "user3@example.com", Password = "pass3" },
    }
);

var scenario = Scenario.Create("data_feed_scenario", async context =>
{
    // Get data from feed
    var user = userFeed.GetNextItem(context.ScenarioInfo);
    
    var loginPayload = new
    {
        username = user.Username,
        password = user.Password
    };
    
    var request = Http.CreateRequest("POST", "https://api.example.com/login")
        .WithJsonBody(loginPayload);
    
    var response = await Http.Send(httpClient, request);
    
    return response;
})
.WithInit(context =>
{
    // Inject the feed into scenario
    context.AddDataFeed("userFeed", userFeed);
    return Task.CompletedTask;
});
```

### HTTP Request Configuration

```csharp
// GET request
var getRequest = Http.CreateRequest("GET", "https://api.example.com/products");

// POST with JSON body
var postRequest = Http.CreateRequest("POST", "https://api.example.com/users")
    .WithJsonBody(new { name = "John", email = "john@example.com" });

// With headers
var authRequest = Http.CreateRequest("GET", "https://api.example.com/profile")
    .WithHeader("Authorization", "Bearer token123")
    .WithHeader("Accept", "application/json");

// With timeout
var timeoutRequest = Http.CreateRequest("GET", "https://api.example.com/slow")
    .WithTimeout(TimeSpan.FromSeconds(30));

// Check response
var response = await Http.Send(httpClient, getRequest);
if (response.IsError)
{
    return Response.Fail(response.Message);
}

var statusCode = response.StatusCode;
var body = response.Payload.Value;
```

### Custom Reporting

```csharp
NBomberRunner
    .RegisterScenarios(scenario)
    .WithReportFolder("./load-test-reports")

```

Reports include:
- Test summary
- Scenario statistics
- Step statistics with latency percentiles
- Status code distribution
- Error details

## Complete Example: E-Commerce API Load Test

```csharp
using NBomber.CSharp;
using NBomber.Http.CSharp;

class Program
{
    static void Main(string[] args)
    {
        var httpClient = new HttpClient();
        const string baseUrl = "https://api.example.com";
        
        // Data feed for users
        var userFeed = DataFeed.Random(
            data: Enumerable.Range(1, 100)
                .Select(i => new
                {
                    Email = $"user{i}@example.com",
                    Password = "Password123!"
                })
                .ToArray()
        );
        
        // Scenario 1: Browser (60% of users)
        var browserScenario = Scenario.Create("browser_flow", async context =>
        {
            var productsStep = await Step.Run("get_products", context, async () =>
            {
                var request = Http.CreateRequest("GET", $"{baseUrl}/products");
                var response = await Http.Send(httpClient, request);
                
                await Task.Delay(TimeSpan.FromSeconds(Random.Shared.Next(5, 8))); // Think time
                
                return response;
            });
            
            if (productsStep.IsError)
                return Response.Fail();
            
            var productDetailsStep = await Step.Run("get_product_details", context, async () =>
            {
                var productId = Random.Shared.Next(1, 100);
                var request = Http.CreateRequest("GET", $"{baseUrl}/products/{productId}");
                var response = await Http.Send(httpClient, request);
                
                await Task.Delay(TimeSpan.FromSeconds(Random.Shared.Next(10, 15))); // Think time
                
                return response;
            });
            
            return Response.Ok();
        })
        .WithoutWarmUp()
        .WithLoadSimulations(
            Simulation.RampingInject(
                rate: 60,
                interval: TimeSpan.FromSeconds(1),
                during: TimeSpan.FromMinutes(2)
            ),
            Simulation.Inject(
                rate: 60,
                interval: TimeSpan.FromSeconds(1),
                during: TimeSpan.FromMinutes(5)
            )
        );
        
        // Scenario 2: Shopper (30% of users)
        var shopperScenario = Scenario.Create("shopper_flow", async context =>
        {
            var user = userFeed.GetNextItem(context.ScenarioInfo);
            string? authToken = null;
            
            // Login
            var loginStep = await Step.Run("login", context, async () =>
            {
                var request = Http.CreateRequest("POST", $"{baseUrl}/auth/login")
                    .WithJsonBody(new { email = user.Email, password = user.Password });
                
                var response = await Http.Send(httpClient, request);
                
                if (!response.IsError)
                {
                    // Parse token from response (simplified)
                    authToken = "token123"; // In reality, parse from response.Payload
                }
                
                await Task.Delay(TimeSpan.FromSeconds(2));
                
                return response;
            });
            
            if (loginStep.IsError || authToken == null)
                return Response.Fail();
            
            // Browse products
            await Step.Run("browse_products", context, async () =>
            {
                var request = Http.CreateRequest("GET", $"{baseUrl}/products");
                var response = await Http.Send(httpClient, request);
                await Task.Delay(TimeSpan.FromSeconds(Random.Shared.Next(5, 8)));
                return response;
            });
            
            // Add to cart
            var addToCartStep = await Step.Run("add_to_cart", context, async () =>
            {
                var productId = Random.Shared.Next(1, 100);
                var request = Http.CreateRequest("POST", $"{baseUrl}/cart/items")
                    .WithHeader("Authorization", $"Bearer {authToken}")
                    .WithJsonBody(new { productId, quantity = 1 });
                
                var response = await Http.Send(httpClient, request);
                await Task.Delay(TimeSpan.FromSeconds(3));
                
                return response;
            });
            
            // View cart
            await Step.Run("view_cart", context, async () =>
            {
                var request = Http.CreateRequest("GET", $"{baseUrl}/cart")
                    .WithHeader("Authorization", $"Bearer {authToken}");
                
                var response = await Http.Send(httpClient, request);
                await Task.Delay(TimeSpan.FromSeconds(Random.Shared.Next(5, 10)));
                
                return response;
            });
            
            return Response.Ok();
        })
        .WithInit(context =>
        {
            context.AddDataFeed("userFeed", userFeed);
            return Task.CompletedTask;
        })
        .WithoutWarmUp()
        .WithLoadSimulations(
            Simulation.RampingInject(
                rate: 30,
                interval: TimeSpan.FromSeconds(1),
                during: TimeSpan.FromMinutes(2)
            ),
            Simulation.Inject(
                rate: 30,
                interval: TimeSpan.FromSeconds(1),
                during: TimeSpan.FromMinutes(5)
            )
        );
        
        // Scenario 3: Buyer (10% of users)
        var buyerScenario = Scenario.Create("buyer_flow", async context =>
        {
            var user = userFeed.GetNextItem(context.ScenarioInfo);
            string? authToken = null;
            
            // Login
            var loginStep = await Step.Run("login", context, async () =>
            {
                var request = Http.CreateRequest("POST", $"{baseUrl}/auth/login")
                    .WithJsonBody(new { email = user.Email, password = user.Password });
                
                var response = await Http.Send(httpClient, request);
                if (!response.IsError)
                {
                    authToken = "token123";
                }
                await Task.Delay(TimeSpan.FromSeconds(2));
                return response;
            });
            
            if (loginStep.IsError || authToken == null)
                return Response.Fail();
            
            // Browse and add to cart (similar to shopper)
            // ... (abbreviated for brevity)
            
            // Checkout
            var checkoutStep = await Step.Run("checkout", context, async () =>
            {
                var request = Http.CreateRequest("POST", $"{baseUrl}/orders")
                    .WithHeader("Authorization", $"Bearer {authToken}")
                    .WithJsonBody(new
                    {
                        paymentMethod = "credit_card",
                        shippingAddress = "123 Main St"
                    });
                
                var response = await Http.Send(httpClient, request);
                await Task.Delay(TimeSpan.FromSeconds(Random.Shared.Next(15, 20)));
                
                return response;
            });
            
            return checkoutStep.IsError ? Response.Fail() : Response.Ok();
        })
        .WithInit(context =>
        {
            context.AddDataFeed("userFeed", userFeed);
            return Task.CompletedTask;
        })
        .WithoutWarmUp()
        .WithLoadSimulations(
            Simulation.RampingInject(
                rate: 10,
                interval: TimeSpan.FromSeconds(1),
                during: TimeSpan.FromMinutes(2)
            ),
            Simulation.Inject(
                rate: 10,
                interval: TimeSpan.FromSeconds(1),
                during: TimeSpan.FromMinutes(5)
            )
        );
        
        // Run all scenarios
        NBomberRunner
            .RegisterScenarios(browserScenario, shopperScenario, buyerScenario)
            .WithReportFolder("./load-test-reports")
            .WithReportFormats(ReportFormat.Html, ReportFormat.Txt, ReportFormat.Md)
            .Run();
    }
}
```



## CI/CD Integration

NBomber can exit with error codes based on test results:

```csharp
var stats = NBomberRunner
    .RegisterScenarios(scenario)
    .Run();

// Check results and exit with appropriate code
if (stats.ScenarioStats.Any(s => s.Fail.Request.RPS > 0.01)) // More than 1% errors
{
    Environment.Exit(1); // Fail the build
}
```

Or use in unit test framework:

```csharp
[Fact]
public void LoadTest_ShouldMeetPerformanceRequirements()
{
    var scenario = Scenario.Create(/* ... */);
    
    var stats = NBomberRunner
        .RegisterScenarios(scenario)
        .WithoutReports()
        .Run();
    
    var scenarioStats = stats.ScenarioStats[0];
    
    // Assert performance requirements
    Assert.True(scenarioStats.Ok.Latency.Percent95 < 500); // p95 < 500ms
    Assert.True(scenarioStats.Fail.Request.RPS < 0.01);    // < 1% error rate
}
```

## Best Practices

✅ **Always run in Release mode** - Debug mode skews results

✅ **Use data feeds** - Avoid hardcoded test data

✅ **Add think times** - Simulate realistic user behavior

✅ **Start with smoke tests** - Verify scenarios work before ramping up

✅ **Monitor server metrics** - Use Application Insights, Prometheus, etc.

✅ **Test realistic scenarios** - Multi-step user flows, not isolated endpoints

✅ **Use multiple scenarios** - Different user behaviors with different loads

✅ **Save reports** - Track performance over time

✅ **Run from CI/CD** - Automate performance testing
