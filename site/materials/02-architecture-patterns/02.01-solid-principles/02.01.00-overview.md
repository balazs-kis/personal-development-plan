# Chapter 2.1: SOLID Principles at Scale

## Overview
This chapter revisits SOLID principles (Single Responsibility, Open-Closed, Liskov Substitution, Interface Segregation, Dependency Inversion) with a focus on their application at the architectural level, not just class design. You'll learn when to apply these principles and, equally important, when breaking them might be the pragmatic choice.

## Key Concepts
- **SRP at Scale:** applying Single Responsibility to services and modules, not just classes.
- **OCP Through Composition:** achieving Open-Closed through plugin architectures and composition.
- **ISP for APIs:** designing client contracts and API boundaries.
- **DIP and DI Containers:** understanding dependency injection containers and inversion of control.
- **Pragmatic SOLID:** recognizing when SOLID becomes over-engineering.
