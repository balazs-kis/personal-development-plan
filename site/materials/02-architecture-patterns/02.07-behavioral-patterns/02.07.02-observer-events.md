## Introduction

The Observer pattern defines a one-to-many dependency between objects where when one object (subject) changes state, all its dependents (observers) are notified automatically. This pattern is fundamental to event-driven programming and is implemented natively in .NET through events, delegates, and reactive extensions.

The Observer pattern promotes loose coupling between the subject and observers, as the subject doesn't need to know concrete observer types—only that they implement the observer interface.

## Key Concepts Summary

### Classic Observer Pattern

The classic implementation uses interfaces for subject and observer:

```csharp
// Subject interface
public interface ISubject
{
    void Attach(IObserver observer);
    void Detach(IObserver observer);
    void Notify();
}

// Observer interface
public interface IObserver
{
    void Update(ISubject subject);
}

// Concrete Subject
public class Stock : ISubject
{
    private readonly List<IObserver> _observers = new();
    private string _symbol;
    private decimal _price;
    
    public string Symbol => _symbol;
    public decimal Price => _price;
    
    public Stock(string symbol, decimal price)
    {
        _symbol = symbol;
        _price = price;
    }
    
    public void SetPrice(decimal price)
    {
        _price = price;
        Notify();  // Notify all observers
    }
    
    public void Attach(IObserver observer)
    {
        _observers.Add(observer);
    }
    
    public void Detach(IObserver observer)
    {
        _observers.Remove(observer);
    }
    
    public void Notify()
    {
        foreach (var observer in _observers)
        {
            observer.Update(this);
        }
    }
}

// Concrete Observers
public class StockDisplay : IObserver
{
    private readonly string _name;
    
    public StockDisplay(string name)
    {
        _name = name;
    }
    
    public void Update(ISubject subject)
    {
        if (subject is Stock stock)
        {
            Console.WriteLine($"{_name}: {stock.Symbol} is now ${stock.Price}");
        }
    }
}

// Usage
var appleStock = new Stock("AAPL", 150.00m);
var display1 = new StockDisplay("Display 1");
var display2 = new StockDisplay("Display 2");

appleStock.Attach(display1);
appleStock.Attach(display2);

appleStock.SetPrice(152.50m);
// Output:
// Display 1: AAPL is now $152.50
// Display 2: AAPL is now $152.50
```

### .NET Events (Idiomatic Observer)

```csharp
// Event args
public class PriceChangedEventArgs : EventArgs
{
    public string Symbol { get; }
    public decimal OldPrice { get; }
    public decimal NewPrice { get; }
    
    public PriceChangedEventArgs(string symbol, decimal oldPrice, decimal newPrice)
    {
        Symbol = symbol;
        OldPrice = oldPrice;
        NewPrice = newPrice;
    }
}

// Publisher (Subject)
public class Stock
{
    private decimal _price;
    
    public string Symbol { get; }
    public decimal Price => _price;
    
    // Event declaration
    public event EventHandler<PriceChangedEventArgs>? PriceChanged;
    
    public Stock(string symbol, decimal price)
    {
        Symbol = symbol;
        _price = price;
    }
    
    public void SetPrice(decimal newPrice)
    {
        var oldPrice = _price;
        _price = newPrice;
        
        // Raise event
        OnPriceChanged(new PriceChangedEventArgs(Symbol, oldPrice, newPrice));
    }
    
    protected virtual void OnPriceChanged(PriceChangedEventArgs e)
    {
        PriceChanged?.Invoke(this, e);
    }
}

// Subscribers (Observers)
public class StockMonitor
{
    public void Subscribe(Stock stock)
    {
        stock.PriceChanged += OnPriceChanged;
    }
    
    public void Unsubscribe(Stock stock)
    {
        stock.PriceChanged -= OnPriceChanged;
    }
    
    private void OnPriceChanged(object sender, PriceChangedEventArgs e)
    {
        decimal change = e.NewPrice - e.OldPrice;
        decimal percentChange = (change / e.OldPrice) * 100;
        
        Console.WriteLine($"{e.Symbol}: ${e.OldPrice} → ${e.NewPrice} " +
                          $"({percentChange:+0.00;-0.00}%)");
    }
}

// Usage
var stock = new Stock("MSFT", 300.00m);
var monitor = new StockMonitor();

monitor.Subscribe(stock);
stock.SetPrice(305.50m);
// Output: MSFT: $300.00 → $305.50 (+1.83%)

monitor.Unsubscribe(stock);
stock.SetPrice(310.00m);
// No output - unsubscribed
```

### Domain Events Pattern

```csharp
// Domain event
public record OrderPlacedEvent(
    Guid OrderId,
    Guid CustomerId,
    decimal TotalAmount,
    DateTime PlacedAt);

// Domain event dispatcher
public interface IDomainEventDispatcher
{
    Task PublishAsync<TEvent>(TEvent domainEvent) where TEvent : notnull;
}

public class DomainEventDispatcher : IDomainEventDispatcher
{
    private readonly IServiceProvider _serviceProvider;
    
    public DomainEventDispatcher(IServiceProvider serviceProvider)
    {
        _serviceProvider = serviceProvider;
    }
    
    public async Task PublishAsync<TEvent>(TEvent domainEvent) where TEvent : notnull
    {
        var handlers = _serviceProvider.GetServices<IDomainEventHandler<TEvent>>();
        
        foreach (var handler in handlers)
        {
            await handler.HandleAsync(domainEvent);
        }
    }
}

// Event handler interface
public interface IDomainEventHandler<in TEvent>
{
    Task HandleAsync(TEvent domainEvent);
}

// Concrete handlers
public class SendOrderConfirmationHandler : IDomainEventHandler<OrderPlacedEvent>
{
    private readonly IEmailService _emailService;
    
    public async Task HandleAsync(OrderPlacedEvent domainEvent)
    {
        await _emailService.SendOrderConfirmation(
            domainEvent.CustomerId,
            domainEvent.OrderId);
    }
}

public class UpdateInventoryHandler : IDomainEventHandler<OrderPlacedEvent>
{
    private readonly IInventoryService _inventoryService;
    
    public async Task HandleAsync(OrderPlacedEvent domainEvent)
    {
        await _inventoryService.ReserveItems(domainEvent.OrderId);
    }
}

// Usage in aggregate
public class Order
{
    public async Task PlaceOrder(IDomainEventDispatcher dispatcher)
    {
        // Business logic
        
        // Raise domain event
        await dispatcher.PublishAsync(new OrderPlacedEvent(
            Id,
            CustomerId,
            TotalAmount,
            DateTime.UtcNow));
    }
}

// DI registration

```

### Memory Leak Prevention

```csharp
// Problem: Event subscription can cause memory leaks
public class ProblemExample
{
    private Stock _stock = new Stock("GOOG", 100);
    
    public void CreateMonitors()
    {
        for (int i = 0; i < 1000; i++)
        {
            var monitor = new StockMonitor();
            _stock.PriceChanged += monitor.OnPriceChanged;
            // monitor goes out of scope, but subscription keeps it alive!
        }
    }
}

// Solution 1: WeakEvent pattern
public class WeakEventManager<TEventArgs> where TEventArgs : EventArgs
{
    private readonly List<WeakReference<EventHandler<TEventArgs>>> _handlers = new();
    
    public void AddHandler(EventHandler<TEventArgs> handler)
    {
        _handlers.Add(new WeakReference<EventHandler<TEventArgs>>(handler));
    }
    
    public void Raise(object sender, TEventArgs e)
    {
        var deadReferences = new List<WeakReference<EventHandler<TEventArgs>>>();
        
        foreach (var weakRef in _handlers)
        {
            if (weakRef.TryGetTarget(out var handler))
            {
                handler(sender, e);
            }
            else
            {
                deadReferences.Add(weakRef);
            }
        }
        
        // Clean up dead references
        foreach (var deadRef in deadReferences)
        {
            _handlers.Remove(deadRef);
        }
    }
}

// Solution 2: IDisposable pattern
public class SafeStockMonitor : IDisposable
{
    private readonly Stock _stock;
    
    public SafeStockMonitor(Stock stock)
    {
        _stock = stock;
        _stock.PriceChanged += OnPriceChanged;
    }
    
    private void OnPriceChanged(object sender, PriceChangedEventArgs e)
    {
        // Handle event
    }
    
    public void Dispose()
    {
        _stock.PriceChanged -= OnPriceChanged;
    }
}

// Usage
using var monitor = new SafeStockMonitor(stock);
// Automatically unsubscribes when disposed
```

### Reactive Extensions (Rx.NET)

```csharp
// Install: dotnet add package System.Reactive

public class TemperatureSensor
{
    private readonly Subject<double> _temperatureSubject = new();
    
    public IObservable<double> Temperature => _temperatureSubject.AsObservable();
    
    public void RecordTemperature(double temp)
    {
        _temperatureSubject.OnNext(temp);
    }

// Observable queries
var sensor = new TemperatureSensor();

// Subscribe to high temperatures
sensor.Temperature
    .Where(temp => temp > 30)
    .Subscribe(temp => Console.WriteLine($"High temp: {temp}°C"));

sensor.Temperature
    .Buffer(TimeSpan.FromSeconds(5))
    .Select(temps => temps.Average())
    .Subscribe(avg => Console.WriteLine($"5-sec avg: {avg:F2}°C"));
```

### Event Aggregator Pattern

```csharp
public interface IEventAggregator
{
    void Subscribe<TEvent>(Action<TEvent> handler) where TEvent : class;
    void Unsubscribe<TEvent>(Action<TEvent> handler) where TEvent : class;
    Task PublishAsync<TEvent>(TEvent eventData) where TEvent : class;
}

public class EventAggregator : IEventAggregator
{
    private readonly ConcurrentDictionary<Type, List<Delegate>> _handlers = new();
    
    public void Subscribe<TEvent>(Action<TEvent> handler) where TEvent : class
    {
        var eventType = typeof(TEvent);
        _handlers.AddOrUpdate(
            eventType,
            _ => new List<Delegate> { handler },
            (_, handlers) => { handlers.Add(handler); return handlers; });
    }
    
    public void Unsubscribe<TEvent>(Action<TEvent> handler) where TEvent : class
    {
        if (_handlers.TryGetValue(typeof(TEvent), out var handlers))
        {
            handlers.Remove(handler);
        }
    }
    
    public async Task PublishAsync<TEvent>(TEvent eventData) where TEvent : class
    {
        if (!_handlers.TryGetValue(typeof(TEvent), out var handlers))
            return;
        
        var tasks = handlers
            .OfType<Action<TEvent>>()
            .Select(handler => Task.Run(() => handler(eventData)));
        
        await Task.WhenAll(tasks);
    }
}
```

### Observer with Filtering

```csharp
public interface IConditionalObserver<T>
{
    bool ShouldNotify(T data);
    void OnNotification(T data);
}

public class ConditionalSubject<T>
{
    private readonly List<IConditionalObserver<T>> _observers = new();
    
    public void Notify(T data)
    {
        foreach (var observer in _observers.Where(o => o.ShouldNotify(data)))
        {
            observer.OnNotification(data);
        }
    }
}
```

### Async Observer Pattern

```csharp
public interface IAsyncObserver<T>
{
    Task OnNextAsync(T value);
}

public class AsyncSubject<T>
{
    private readonly List<IAsyncObserver<T>> _observers = new();
    
    public async Task NotifyAsync(T value)
    {
        await Task.WhenAll(_observers.Select(o => o.OnNextAsync(value)));
    }
}
```

## Common Pitfalls

**1. Memory Leaks**
```csharp
// BAD - Creates memory leak
public Dashboard(DataService dataService)
{
    dataService.DataUpdated += OnDataUpdated;
    // Never unsubscribes
}

// GOOD - Properly unsubscribe
public class Dashboard : IDisposable
{
    public void Dispose()
    {
        _dataService.DataUpdated -= OnDataUpdated;
    }
}
```

**2. Unhandled Exceptions**
```csharp
// BAD - One exception stops all observers
public void Notify()
{
    foreach (var observer in _observers)
        observer.Update(this);  // Throws, stops others
}

// GOOD - Isolate exceptions
public void Notify()
{
    foreach (var observer in _observers)
    {
        try { observer.Update(this); }
        catch (Exception ex) { _logger.LogError(ex); }
    }
}
```

## Self-Check Questions

1. **What's the difference between Observer pattern and .NET events?**
   - Observer: Explicit interfaces (ISubject, IObserver), more control, more code
   - .NET Events: Language-level support, simpler syntax, built-in multicast

2. **How can event subscriptions cause memory leaks?**
   - Event source holds reference to subscriber through delegate
   - If subscriber is not unsubscribed, it can't be garbage collected
   - Long-lived event source + short-lived subscriber = memory leak

3. **When should you use domain events instead of regular events?**
   - Domain events: Business-significant occurrences, persisted, part of domain model
   - Regular events: Technical notifications, transient, infrastructure concerns

4. **How do you properly unsubscribe from events?**
   - Use -= operator to remove handler
   - Implement IDisposable and unsubscribe in Dispose()
   - Use weak event pattern for long-lived sources
   - Consider using Rx.NET subscriptions (automatically disposable)

5. **What's the difference between hot and cold observables in Rx.NET?**
   - Hot: Produces values regardless of subscribers (like stock tickers)
   - Cold: Produces values only when subscribed (like file reads)

6. **How does the Event Aggregator pattern differ from standard Observer?**
   - Event Aggregator: Centralized event distribution, decouples publishers from subscribers
   - Standard Observer: Direct subscription, publishers know subscribers exist

## Key Takeaways

1. **Observer pattern** enables one-to-many dependencies with automatic notification
2. **.NET events** provide language-level support for Observer pattern
3. **Memory leaks** can occur if event subscriptions are not properly managed
4. **Domain events** represent business-significant occurrences and promote loose coupling
5. **MediatR** simplifies domain event handling with automatic discovery
6. **Rx.NET** provides powerful observable streams with LINQ-like operators
7. **Event Aggregator** centralizes event distribution across modules
8. Always handle **observer exceptions** to prevent notification failures
