# Chapter 2.7: Behavioral Design Patterns

## Overview
Study patterns that define how objects communicate: Strategy, Observer, Command, State, Template Method, Chain of Responsibility, and Mediator patterns. These patterns enable flexible, decoupled interactions between objects and are fundamental for implementing workflows, event handling, and complex business rules.

## Key Concepts
- **Strategy Pattern:** encapsulating algorithms for runtime selection.
- **Observer/Event Patterns:** implementing event-driven communication in .NET.
- **Command Pattern:** encapsulating actions for undo/redo operations.
- **State Pattern:** implementing state machines cleanly.
- **Mediator Pattern:** using MediatR library for decoupled communication.
