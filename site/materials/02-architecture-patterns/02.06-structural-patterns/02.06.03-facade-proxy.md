## Introduction

Facade and Proxy are structural patterns that control how clients interact with subsystems. Facade simplifies complex subsystems with a unified interface, while Proxy controls access to an object, adding functionality like lazy loading, caching, or access control.

---

## Key Concepts Summary

### Facade Pattern

**Problem:** Complex subsystem with many interdependent classes

```csharp
// Complex subsystem
public class OrderValidator { }
public class InventoryChecker { }
public class PaymentProcessor { }
public class ShippingCalculator { }
public class EmailService { }
public class SmsService { }

// Client code is complicated
var validator = new OrderValidator();
var inventory = new InventoryChecker();
var payment = new PaymentProcessor();
var shipping = new ShippingCalculator();
var email = new EmailService();

if (validator.Validate(order))
{
    if (inventory.CheckAvailability(order.Items))
    {
        var shippingCost = shipping.Calculate(order);
        if (payment.Process(order.Total + shippingCost))
        {
            email.SendConfirmation(order);
            // ... more complexity
        }
    }
}
```

**Solution: Facade Pattern**

```csharp
// Facade simplifies the subsystem
public class OrderFacade
{
    private readonly OrderValidator _validator;
    private readonly InventoryChecker _inventory;
    private readonly PaymentProcessor _payment;
    private readonly ShippingCalculator _shipping;
    private readonly EmailService _email;
    private readonly SmsService _sms;
    
    public OrderFacade(
        OrderValidator validator,
        InventoryChecker inventory,
        PaymentProcessor payment,
        ShippingCalculator shipping,
        EmailService email,
        SmsService sms)
    {
        _validator = validator;
        _inventory = inventory;
        _payment = payment;
        _shipping = shipping;
        _email = email;
        _sms = sms;
    }
    
    public async Task<OrderResult> PlaceOrder(Order order)
    {
        // Facade coordinates the subsystem
        if (!_validator.Validate(order))
            return OrderResult.Failure("Validation failed");
        
        if (!await _inventory.CheckAvailability(order.Items))
            return OrderResult.Failure("Items not available");
        
        var shippingCost = _shipping.Calculate(order);
        
        var paymentResult = await _payment.Process(order.Total + shippingCost);
        if (!paymentResult.Success)
            return OrderResult.Failure("Payment failed");
        
        await _email.SendConfirmation(order);
        await _sms.SendNotification(order.Customer.Phone, "Order confirmed");
        
        return OrderResult.Success(order.Id);
    }
}

// Client code is simple
var result = await _orderFacade.PlaceOrder(order);
```

### Proxy Pattern

**Types of Proxies:**
1. **Virtual Proxy** - Lazy initialization
2. **Protection Proxy** - Access control
3. **Remote Proxy** - Represents remote object
4. **Caching Proxy** - Caches results

**Virtual Proxy (Lazy Loading)**

```csharp
// Subject interface
public interface IDocument
{
    void Display();
    string GetContent();
}

// Real subject - expensive to create
public class Document : IDocument
{
    private readonly string _filePath;
    private string _content;
    
    public Document(string filePath)
    {
        _filePath = filePath;
        LoadFromDisk();  // Expensive operation
    }
    
    private void LoadFromDisk()
    {
        Console.WriteLine($"Loading document from {_filePath}...");
        Thread.Sleep(2000);  // Simulate slow disk I/O
        _content = File.ReadAllText(_filePath);
    }
    
    public void Display()
    {
        Console.WriteLine(_content);
    }
    
    public string GetContent() => _content;
}

// Virtual Proxy - delays creation
public class DocumentProxy : IDocument
{
    private readonly string _filePath;
    private Document _realDocument;
    
    public DocumentProxy(string filePath)
    {
        _filePath = filePath;
        // Real document not created yet!
    }
    
    public void Display()
    {
        EnsureDocumentLoaded();
        _realDocument.Display();
    }
    
    public string GetContent()
    {
        EnsureDocumentLoaded();
        return _realDocument.GetContent();
    }
    
    private void EnsureDocumentLoaded()
    {
        if (_realDocument == null)
        {
            _realDocument = new Document(_filePath);
        }
    }
}

// Usage
IDocument doc = new DocumentProxy("large-file.txt");
// Document not loaded yet!
Console.WriteLine("Proxy created, but document not loaded");

doc.Display();  // Now it loads
```

**Protection Proxy (Access Control)**

```csharp
public interface IUserRepository
{
    Task<User> GetUser(Guid userId);
    Task UpdateUser(User user);
    Task DeleteUser(Guid userId);
}

public class UserRepository : IUserRepository
{
    private readonly DbContext _context;
    
    public async Task<User> GetUser(Guid userId)
    {
        return await _context.Users.FindAsync(userId);
    }
    
    public async Task UpdateUser(User user)
    {
        _context.Users.Update(user);
        await _context.SaveChangesAsync();
    }
    
    public async Task DeleteUser(Guid userId)
    {
        var user = await _context.Users.FindAsync(userId);
        _context.Users.Remove(user);
        await _context.SaveChangesAsync();
    }
}

// Protection proxy - enforces access control
public class SecureUserRepositoryProxy : IUserRepository
{
    private readonly IUserRepository _inner;
    private readonly ICurrentUserService _currentUser;
    private readonly IAuthorizationService _authService;
    
    public SecureUserRepositoryProxy(
        IUserRepository inner,
        ICurrentUserService currentUser,
        IAuthorizationService authService)
    {
        _inner = inner;
        _currentUser = currentUser;
        _authService = authService;
    }
    
    public async Task<User> GetUser(Guid userId)
    {
        // Anyone can read
        return await _inner.GetUser(userId);
    }
    
    public async Task UpdateUser(User user)
    {
        if (!await _authService.CanUpdateUser(_currentUser.UserId, user.Id))
            throw new UnauthorizedAccessException();
        
        await _inner.UpdateUser(user);
    }
    
    public async Task DeleteUser(Guid userId)
    {
        if (!await _authService.IsAdmin(_currentUser.UserId))
            throw new UnauthorizedAccessException("Only admins can delete users");
        
        await _inner.DeleteUser(userId);
    }
}
```

**Caching Proxy**

```csharp
public class CachingWeatherServiceProxy : IWeatherService
{
    private readonly IWeatherService _inner;
    private readonly IMemoryCache _cache;
    
    public CachingWeatherServiceProxy(IWeatherService inner, IMemoryCache cache)
    {
        _inner = inner;
        _cache = cache;
    }
    
    public async Task<WeatherData> GetWeather(string city)
    {
        var cacheKey = $"weather_{city}";
        
        if (_cache.TryGetValue(cacheKey, out WeatherData cached))
        {
            Console.WriteLine($"Cache HIT for {city}");
            return cached;
        }
        
        Console.WriteLine($"Cache MISS for {city}");
        var weather = await _inner.GetWeather(city);
        
        _cache.Set(cacheKey, weather, TimeSpan.FromMinutes(10));
        
        return weather;
    }
}
```

### Smart Proxy (Reference Counting)

```csharp
// Proxy that tracks object usage
public interface IResource : IDisposable
{
    void Use();
}

public class ExpensiveResource : IResource
{
    public ExpensiveResource()
    {
        Console.WriteLine("Expensive resource created");
    }
    
    public void Use()
    {
        Console.WriteLine("Using expensive resource");
    }
    
    public void Dispose()
    {
        Console.WriteLine("Expensive resource disposed");
    }
}

public class SmartResourceProxy : IResource
{
    private static int _referenceCount = 0;
    private static ExpensiveResource _sharedResource;
    private bool _disposed;
    
    public SmartResourceProxy()
    {
        if (_sharedResource == null)
        {
            _sharedResource = new ExpensiveResource();
        }
        _referenceCount++;
        Console.WriteLine($"Reference count: {_referenceCount}");
    }
    
    public void Use()
    {
        if (_disposed)
            throw new ObjectDisposedException(nameof(SmartResourceProxy));
        
        _sharedResource.Use();
    }
    
    public void Dispose()
    {
        if (!_disposed)
        {
            _disposed = true;
            _referenceCount--;
            Console.WriteLine($"Reference count: {_referenceCount}");
            
            if (_referenceCount == 0)
            {
                _sharedResource?.Dispose();
                _sharedResource = null;
            }
        }
    }
}

// Usage
using (var proxy1 = new SmartResourceProxy())
{
    proxy1.Use();
    
    using (var proxy2 = new SmartResourceProxy())
    {
        proxy2.Use();  // Same resource, shared
    }  // Reference count decremented
}  // Resource disposed when count reaches 0
```

### Remote Proxy Example

```csharp
// Proxy for remote service call
public interface IUserService
{
    Task<User> GetUserAsync(int userId);
}

public class RemoteUserServiceProxy : IUserService
{
    private readonly HttpClient _httpClient;
    private readonly string _baseUrl;
    
    public RemoteUserServiceProxy(HttpClient httpClient, string baseUrl)
    {
        _httpClient = httpClient;
        _baseUrl = baseUrl;
    }
    
    public async Task<User> GetUserAsync(int userId)
    {
        // Proxy handles remote communication
        var response = await _httpClient.GetAsync($"{_baseUrl}/users/{userId}");
        response.EnsureSuccessStatusCode();
        
        return await response.Content.ReadFromJsonAsync<User>();
    }
}

// Client code doesn't know it's remote
IUserService userService = new RemoteUserServiceProxy(httpClient, "https://api.example.com");
var user = await userService.GetUserAsync(123);
```

### Composite Proxy (Combines Multiple Proxy Types)

```csharp
public class CompositeDataServiceProxy : IDataService
{
    private readonly IDataService _inner;
    private readonly IMemoryCache _cache;
    private readonly ILogger _logger;
    private IDataService _lazyService;
    
    public CompositeDataServiceProxy(
        Func<IDataService> serviceFactory,
        IMemoryCache cache,
        ILogger logger)
    {
        // Virtual proxy - lazy initialization
        _inner = new Lazy<IDataService>(serviceFactory).Value;
        _cache = cache;
        _logger = logger;
    }
    
    public async Task<Data> GetDataAsync(string key)
    {
        // Protection proxy - check permissions
        if (!HasPermission())
        {
            _logger.LogWarning("Unauthorized access attempt");
            throw new UnauthorizedAccessException();
        }
        
        // Caching proxy
        if (_cache.TryGetValue(key, out Data cached))
        {
            _logger.LogDebug("Cache hit for {Key}", key);
            return cached;
        }
        
        // Logging proxy
        _logger.LogInformation("Fetching data for {Key}", key);
        var data = await _inner.GetDataAsync(key);
        
        _cache.Set(key, data, TimeSpan.FromMinutes(5));
        return data;
    }
    
    private bool HasPermission()
    {
        // Permission check logic
        return true;
    }
}
```

### Dynamic Proxy with DispatchProxy

```csharp
// .NET built-in dynamic proxy
public class LoggingProxy<T> : DispatchProxy
{
    private T _decorated;
    private ILogger _logger;
    
    protected override object Invoke(MethodInfo targetMethod, object[] args)
    {
        _logger.LogInformation("Calling {Method} with args: {Args}",
            targetMethod.Name,
            string.Join(", ", args));
        
        try
        {
            var result = targetMethod.Invoke(_decorated, args);
            _logger.LogInformation("Completed {Method}", targetMethod.Name);
            return result;
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Error in {Method}", targetMethod.Name);
            throw;
        }
    }
    
    public static T Create(T decorated, ILogger logger)
    {
        object proxy = Create<T, LoggingProxy<T>>();
        ((LoggingProxy<T>)proxy).SetParameters(decorated, logger);
        return (T)proxy;
    }
    
    private void SetParameters(T decorated, ILogger logger)
    {
        _decorated = decorated;
        _logger = logger;
    }
}

// Usage
var service = LoggingProxy<IOrderService>.Create(
    new OrderService(),
    logger);
```

### Facade for Microservices Orchestration

```csharp
// Facade coordinates multiple microservices
public class OrderProcessingFacade
{
    private readonly IInventoryService _inventory;
    private readonly IPaymentService _payment;
    private readonly IShippingService _shipping;
    private readonly INotificationService _notification;
    private readonly ILogger<OrderProcessingFacade> _logger;
    
    public OrderProcessingFacade(
        IInventoryService inventory,
        IPaymentService payment,
        IShippingService shipping,
        INotificationService notification,
        ILogger<OrderProcessingFacade> logger)
    {
        _inventory = inventory;
        _payment = payment;
        _shipping = shipping;
        _notification = notification;
        _logger = logger;
    }
    
    public async Task<OrderResult> ProcessOrderAsync(OrderRequest request)
    {
        var orderId = Guid.NewGuid();
        
        try
        {
            // Step 1: Reserve inventory
            _logger.LogInformation("Reserving inventory for order {OrderId}", orderId);
            var reservation = await _inventory.ReserveItemsAsync(request.Items);
            if (!reservation.Success)
            {
                return OrderResult.Failed("Insufficient inventory");
            }
            
            // Step 2: Process payment
            _logger.LogInformation("Processing payment for order {OrderId}", orderId);
            var paymentResult = await _payment.ChargeAsync(request.PaymentInfo, request.Total);
            if (!paymentResult.Success)
            {
                await _inventory.ReleaseReservationAsync(reservation.Id);
                return OrderResult.Failed("Payment failed");
            }
            
            // Step 3: Create shipment
            _logger.LogInformation("Creating shipment for order {OrderId}", orderId);
            var shipment = await _shipping.CreateShipmentAsync(
                reservation.Id,
                request.ShippingAddress);
            
            // Step 4: Send notifications
            _logger.LogInformation("Sending notifications for order {OrderId}", orderId);
            await _notification.SendOrderConfirmationAsync(
                request.CustomerEmail,
                orderId,
                shipment.TrackingNumber);
            
            return OrderResult.Success(orderId, shipment.TrackingNumber);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Error processing order {OrderId}", orderId);
            // Compensation logic would go here
            throw;
        }
    }
}
```

### Facade vs Proxy

| Aspect | Facade | Proxy |
|--------|--------|-------|
| **Purpose** | Simplify complex subsystem | Control access to object |
| **Interface** | New, simplified interface | Same interface as subject |
| **Composition** | Coordinates multiple objects | Wraps single object |
| **When to use** | Complex subsystem with many parts | Need lazy loading, caching, or access control |
| **Flexibility** | Can expose selective functionality | Transparent to client |

### Common Mistakes

**Facade Anti-Patterns:**
```csharp
// BAD - Facade becomes God object
public class EverythingFacade
{
    public void DoUserStuff() { }
    public void DoOrderStuff() { }
    public void DoPaymentStuff() { }
    public void DoShippingStuff() { }
    // ... becomes unmanageable
}

// GOOD - Focused facades
public class UserManagementFacade { }
public class OrderProcessingFacade { }
public class PaymentFacade { }
```

**Proxy Anti-Patterns:**
```csharp
// BAD - Proxy adds business logic
public class BadProxy : IService
{
    public async Task<Result> DoWork()
    {
        // Proxy should NOT contain business logic!
        ValidateBusinessRules();
        ApplyBusinessLogic();
        
        return await _inner.DoWork();
    }
}

// GOOD - Proxy only controls access
public class GoodProxy : IService
{
    public async Task<Result> DoWork()
    {
        // Only access control, logging, caching, etc.
        if (!HasPermission())
            throw new UnauthorizedAccessException();
        
        return await _inner.DoWork();
    }
}
```

**Scenario 1: Cloud Storage Facade**

Simplify multi-cloud storage operations:

```csharp
public class CloudStorageFacade
{
    private readonly IS3Storage _s3;
    private readonly IAzureBlobStorage _azure;
    private readonly ILogger _logger;
    
    public async Task<string> UploadFileAsync(
        Stream fileStream,
        string fileName,
        CloudProvider provider)
    {
        _logger.LogInformation("Uploading {FileName} to {Provider}",
            fileName, provider);
        
        return provider switch
        {
            CloudProvider.AWS => await UploadToS3(fileStream, fileName),
            CloudProvider.Azure => await UploadToAzure(fileStream, fileName),
            _ => throw new NotSupportedException()
        };
    }
    
    private async Task<string> UploadToS3(Stream stream, string fileName)
    {
        // Complex S3 logic hidden from client
        var bucket = ConfigureS3Bucket();
        var encryption = ConfigureEncryption();
        var metadata = AddMetadata(fileName);
        
        return await _s3.PutObjectAsync(bucket, fileName, stream, metadata, encryption);
    }
    
    private async Task<string> UploadToAzure(Stream stream, string fileName)
    {
        // Complex Azure logic hidden from client
        var container = GetAzureContainer();
        var options = ConfigureUploadOptions();
        
        return await _azure.UploadBlobAsync(container, fileName, stream, options);
    }
}

// Client code is simple
```

## Self-Check Questions

1. **What's the main difference between Facade and Proxy?**
   - Facade: Provides simplified interface to complex subsystem
   - Proxy: Provides same interface with controlled access

2. **When would you use a virtual proxy?**
   - Delaying expensive object creation until needed
   - Lazy loading of resources
   - Optimizing application startup time

3. **How does a protection proxy enforce security?**
   - Checks permissions before forwarding to real object
   - Can deny access based on user role, time, or other criteria
   - Centralizes security logic

4. **Can Facade and Proxy be used together?**
   - Yes! Facade can use proxies internally
   - Proxy can delegate to a facade
   - Common in complex systems with multiple concerns

5. **What's a smart proxy?**
   - Proxy that adds intelligence like reference counting
   - Can manage resource lifecycle automatically
   - Examples: copy-on-write, connection pooling

6. **When is a Facade too large?**
   - When it has too many responsibilities
   - When it becomes a god object
   - Solution: Split into multiple focused facades
