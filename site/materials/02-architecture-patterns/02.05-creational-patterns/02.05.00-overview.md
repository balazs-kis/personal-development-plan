# Chapter 2.5: Creational Design Patterns

## Overview
Deep dive into patterns for object creation: Factory Method, Abstract Factory, Builder, Prototype, and Singleton, with modern .NET implementations and when each is appropriate. Learn how creational patterns encapsulate object creation logic, enabling flexibility without coupling client code to specific classes.

## Key Concepts
- **Factory Patterns:** decoupling object creation from usage.
- **Builder Pattern:** constructing complex objects step-by-step.
- **Dependency Injection:** using DI as a creational pattern.
- **Object Pooling:** managing expensive resources efficiently.
- **Singleton Pitfalls:** avoiding common anti-patterns with singletons.
