## Introduction
Event Sourcing stores all changes to application state as a sequence of events. Instead of storing current state, you store the history of state changes, allowing you to rebuild state by replaying events.

## Key Concepts Summary

### Traditional State Storage vs Event Sourcing

**Traditional (Current State):**
```csharp
// Database stores only current state
Order: { Id: 123, Status: "Shipped", Total: 150.00 }

// History is lost!
// We don't know: What items were originally in the order?
//                When was it placed? When was it paid?
```

**Event Sourcing (Event Stream):**
```csharp
// Database stores all events that happened
OrderCreated: { OrderId: 123, CustomerId: 456, Timestamp: "2024-01-01 10:00" }
OrderLineAdded: { OrderId: 123, ProductId: 789, Quantity: 2, Price: 50.00 }
OrderLineAdded: { OrderId: 123, ProductId: 790, Quantity: 1, Price: 50.00 }
OrderSubmitted: { OrderId: 123, Timestamp: "2024-01-01 10:05" }
PaymentReceived: { OrderId: 123, Amount: 150.00, Timestamp: "2024-01-01 10:10" }
OrderShipped: { OrderId: 123, TrackingNumber: "ABC123", Timestamp: "2024-01-02 15:00" }

// Complete history is preserved!
// Current state can be rebuilt by replaying events
```

### Event-Sourced Aggregate
```csharp
public class Order
{
    // Current state (rebuilt from events)
    public Guid Id { get; private set; }
    public Guid CustomerId { get; private set; }
    public OrderStatus Status { get; private set; }
    private readonly List<OrderLine> _lines = new();
    public decimal TotalAmount { get; private set; }
    
    // Events that haven't been persisted yet
    private readonly List<DomainEvent> _uncommittedEvents = new();
    public IReadOnlyList<DomainEvent> UncommittedEvents => _uncommittedEvents.AsReadOnly();
    
    // Version for optimistic concurrency
    public int Version { get; private set; }
    
    // Create new aggregate
    public static Order Create(Guid customerId)
    {
        var order = new Order();
        order.RaiseEvent(new OrderCreated(Guid.NewGuid(), customerId, DateTime.UtcNow));
        return order;
    }
    
    // Command methods raise events
    public void AddLine(Guid productId, string productName, int quantity, decimal unitPrice)
    {
        if (Status != OrderStatus.Draft)
            throw new InvalidOperationException("Cannot modify submitted order");
        
        RaiseEvent(new OrderLineAdded(Id, productId, productName, quantity, unitPrice));
    }
    
    public void Submit()
    {
        if (_lines.Count == 0)
            throw new InvalidOperationException("Cannot submit empty order");
        
        if (Status != OrderStatus.Draft)
            throw new InvalidOperationException("Order already submitted");
        
        RaiseEvent(new OrderSubmitted(Id, DateTime.UtcNow));
    }
    
    // Apply events to rebuild state
    public void Apply(DomainEvent @event)
    {
        When(@event);
        Version++;
    }
    
    private void When(DomainEvent @event)
    {
        switch (@event)
        {
            case OrderCreated e:
                Id = e.OrderId;
                CustomerId = e.CustomerId;
                Status = OrderStatus.Draft;
                break;
            
            case OrderLineAdded e:
                _lines.Add(new OrderLine(e.ProductId, e.ProductName, e.Quantity, e.UnitPrice));
                TotalAmount = _lines.Sum(l => l.LineTotal);
                break;
            
            case OrderSubmitted e:
                Status = OrderStatus.Submitted;
                break;
            
            case PaymentReceived e:
                Status = OrderStatus.Paid;
                break;
            
            case OrderShipped e:
                Status = OrderStatus.Shipped;
                break;
        }
    }
    
    private void RaiseEvent(DomainEvent @event)
    {
        // Apply to current state
        When(@event);
        
        // Add to uncommitted events for persistence
        _uncommittedEvents.Add(@event);
        
        Version++;
    }
    
    public void MarkEventsAsCommitted()
    {
        _uncommittedEvents.Clear();
    }
}
```

### Event Store
```csharp
// Simple event store interface
public interface IEventStore
{
    Task SaveEvents(Guid aggregateId, IEnumerable<DomainEvent> events, int expectedVersion);
    Task<List<DomainEvent>> GetEvents(Guid aggregateId);
}

// Event store implementation
public class EventStore : IEventStore
{
    private readonly DbContext _context;
    
    public async Task SaveEvents(Guid aggregateId, IEnumerable<DomainEvent> events, int expectedVersion)
    {
        // Check for concurrency conflicts
        var currentVersion = await GetCurrentVersion(aggregateId);
        if (currentVersion != expectedVersion)
            throw new ConcurrencyException($"Expected version {expectedVersion} but found {currentVersion}");
        
        var eventWrappers = events.Select((e, index) => new EventWrapper
        {
            EventId = e.EventId,
            AggregateId = aggregateId,
            EventType = e.GetType().Name,
            EventData = JsonSerializer.Serialize(e),
            Version = expectedVersion + index + 1,
            Timestamp = e.Timestamp
        });
        
        await _context.Events.AddRangeAsync(eventWrappers);
        await _context.SaveChangesAsync();
    }
    
    public async Task<List<DomainEvent>> GetEvents(Guid aggregateId)
    {
        var eventWrappers = await _context.Events
            .Where(e => e.AggregateId == aggregateId)
            .OrderBy(e => e.Version)
            .ToListAsync();
        
        return eventWrappers
            .Select(w => DeserializeEvent(w.EventType, w.EventData))
            .ToList();
    }
    
    private DomainEvent DeserializeEvent(string eventType, string eventData)
    {
        var type = Type.GetType(eventType);
        return (DomainEvent)JsonSerializer.Deserialize(eventData, type);
    }
}

// Event wrapper for database storage
public class EventWrapper
{
    public Guid EventId { get; set; }
    public Guid AggregateId { get; set; }
    public string EventType { get; set; }
    public string EventData { get; set; }  // JSON serialized event
    public int Version { get; set; }
    public DateTime Timestamp { get; set; }
}
```

### Repository for Event-Sourced Aggregates
```csharp
public class OrderRepository
{
    private readonly IEventStore _eventStore;
    
    public OrderRepository(IEventStore eventStore)
    {
        _eventStore = eventStore;
    }
    
    public async Task<Order> GetById(Guid orderId)
    {
        var events = await _eventStore.GetEvents(orderId);
        
        if (!events.Any())
            throw new AggregateNotFoundException();
        
        var order = new Order();
        foreach (var @event in events)
        {
            order.Apply(@event);
        }
        
        return order;
    }
    
    public async Task Save(Order order)
    {
        var uncommittedEvents = order.UncommittedEvents;
        
        if (uncommittedEvents.Any())
        {
            await _eventStore.SaveEvents(
                order.Id,
                uncommittedEvents,
                order.Version - uncommittedEvents.Count);
            
            order.MarkEventsAsCommitted();
        }
    }
}
```

### Benefits of Event Sourcing

| Benefit | Description |
|---------|-------------|
| **Complete Audit Trail** | Every change is recorded forever |
| **Temporal Queries** | Query state at any point in time |
| **Event Replay** | Rebuild state by replaying events |
| **Debugging** | See exactly what happened and when |
| **Business Intelligence** | Analyze event patterns |
| **Event-Driven Architecture** | Events can trigger other processes |

### Challenges of Event Sourcing

| Challenge | Mitigation |
|-----------|------------|
| **Event Schema Evolution** | Use event versioning and upcasting |
| **Query Complexity** | Use projections/read models (CQRS) |
| **Storage Growth** | Implement snapshotting |
| **Learning Curve** | Start simple, add complexity as needed |
| **Eventual Consistency** | Design for it from the start |

### Snapshotting
```csharp
// For performance: save snapshots to avoid replaying thousands of events
public class OrderSnapshot
{
    public Guid OrderId { get; set; }
    public int Version { get; set; }
    public DateTime SnapshotDate { get; set; }
    public string State { get; set; }  // Serialized aggregate state
}

public interface ISnapshotStore
{
    Task<TSnapshot?> GetLatestSnapshot<TSnapshot>(Guid aggregateId) where TSnapshot : class;
    Task SaveSnapshot<TSnapshot>(Guid aggregateId, TSnapshot snapshot, int version);
}

// Rebuild from snapshot + recent events
public async Task<Order> GetByIdWithSnapshot(Guid orderId)
{
    // Try to get snapshot
    var snapshot = await _snapshotStore.GetLatestSnapshot<OrderSnapshot>(orderId);
    
    Order order;
    int fromVersion;
    
    if (snapshot != null)
    {
        // Deserialize from snapshot
        order = JsonSerializer.Deserialize<Order>(snapshot.State);
        fromVersion = snapshot.Version;
    }
    else
    {
        order = new Order();
        fromVersion = 0;
    }
    
    // Get events after snapshot
    var eventsAfterSnapshot = await _eventStore.GetEvents(orderId, fromVersion);
    
    // Apply remaining events
    foreach (var @event in eventsAfterSnapshot)
    {
        order.Apply(@event);
    }
    
    // Create snapshot every 100 events
    if (order.Version - fromVersion >= 100)
    {
        var newSnapshot = new OrderSnapshot
        {
            OrderId = orderId,
            Version = order.Version,
            SnapshotDate = DateTime.UtcNow,
            State = JsonSerializer.Serialize(order)
        };
        await _snapshotStore.SaveSnapshot(orderId, newSnapshot, order.Version);
    }
    
    return order;
}
```

### Event Versioning

**Problem:** Events change over time but old events are immutable.

**Solution: Upcasting**
```csharp
// Version 1 - Original event
public record OrderCreatedV1(
    Guid OrderId,
    Guid CustomerId,
    DateTime CreatedAt) : DomainEvent;

// Version 2 - Added customer email
public record OrderCreatedV2(
    Guid OrderId,
    Guid CustomerId,
    string CustomerEmail,
    DateTime CreatedAt) : DomainEvent;

// Upcaster to convert V1 to V2
public class OrderCreatedUpcaster
{
    private readonly ICustomerRepository _customerRepo;
    
    public async Task<OrderCreatedV2> Upcast(OrderCreatedV1 oldEvent)
    {
        // Fetch missing data
        var customer = await _customerRepo.GetById(oldEvent.CustomerId);
        
        return new OrderCreatedV2(
            oldEvent.OrderId,
            oldEvent.CustomerId,
            customer.Email,
            oldEvent.CreatedAt);
    }
}

// Event store handles versioning
public class EventWrapper
{

    public Guid AggregateId { get; set; }
    public string EventType { get; set; }
    public string EventData { get; set; }
    public int Version { get; set; }
    public int SchemaVersion { get; set; }  // Track event schema version
    public DateTime Timestamp { get; set; }
}
```

### Projection Patterns

**Real-time projection:**
```csharp
public class OrderProjection : INotificationHandler<OrderCreated>,
                               INotificationHandler<OrderLineAdded>,
                               INotificationHandler<OrderSubmitted>
{
    private readonly IReadDbContext _readDb;
    
    public async Task Handle(OrderCreated notification, CancellationToken ct)
    {
        var readModel = new OrderReadModel
        {
            Id = notification.OrderId,
            CustomerId = notification.CustomerId,
            Status = "Draft",
            TotalAmount = 0,
            ItemCount = 0,
            CreatedAt = notification.CreatedAt
        };
        
        _readDb.Orders.Add(readModel);
        await _readDb.SaveChangesAsync(ct);
    }
    
    public async Task Handle(OrderLineAdded notification, CancellationToken ct)
    {
        var order = await _readDb.Orders.FindAsync(notification.OrderId);
        order.ItemCount++;
        order.TotalAmount += notification.Quantity * notification.UnitPrice;
        await _readDb.SaveChangesAsync(ct);
    }
    
    public async Task Handle(OrderSubmitted notification, CancellationToken ct)
    {
        var order = await _readDb.Orders.FindAsync(notification.OrderId);
        order.Status = "Submitted";
        order.SubmittedAt = notification.SubmittedAt;
        await _readDb.SaveChangesAsync(ct);
    }
}
```

**Batch projection (rebuild):**
```csharp
public class RebuildOrderProjection
{
    private readonly IEventStore _eventStore;
    private readonly IReadDbContext _readDb;
    
    public async Task Rebuild()
    {
        // Clear existing projections
        await _readDb.Database.ExecuteSqlRawAsync("TRUNCATE TABLE OrderReadModels");
        
        // Get all order IDs
        var orderIds = await _eventStore.GetAllAggregateIds("Order");
        
        foreach (var orderId in orderIds)
        {
            var events = await _eventStore.GetEvents(orderId);
            
            var readModel = new OrderReadModel { Id = orderId };
            
            foreach (var @event in events)
            {
                ApplyEventToReadModel(readModel, @event);
            }
            
            _readDb.Orders.Add(readModel);
        }
        
        await _readDb.SaveChangesAsync();
    }
    
    private void ApplyEventToReadModel(OrderReadModel model, DomainEvent @event)
    {
        switch (@event)
        {
            case OrderCreated e:
                model.CustomerId = e.CustomerId;
                model.Status = "Draft";
                model.CreatedAt = e.CreatedAt;
                break;
            
            case OrderLineAdded e:
                model.ItemCount++;
                model.TotalAmount += e.Quantity * e.UnitPrice;
                break;
            
            case OrderSubmitted e:
                model.Status = "Submitted";
                model.SubmittedAt = e.SubmittedAt;
                break;
        }
    }
}
```

### 2. Create Event-Sourced Aggregate:

```csharp
public class BankAccount
{
    // State
    public Guid Id { get; private set; }
    public Guid OwnerId { get; private set; }
    public string OwnerName { get; private set; }
    public decimal Balance { get; private set; }
    public AccountStatus Status { get; private set; }
    public DateTime OpenedAt { get; private set; }
    public DateTime? ClosedAt { get; private set; }
    
    // Event tracking
    private readonly List<BankAccountEvent> _uncommittedEvents = new();
    public IReadOnlyList<BankAccountEvent> UncommittedEvents => _uncommittedEvents.AsReadOnly();
    public int Version { get; private set; }
    
    // Create new account
    public static BankAccount Open(Guid ownerId, string ownerName, decimal initialBalance)
    {
        if (initialBalance < 10)
            throw new DomainException("Minimum opening balance is $10");
        
        var account = new BankAccount();
        account.RaiseEvent(new AccountOpened(
            Guid.NewGuid(),
            ownerId,
            ownerName,
            initialBalance,
            DateTime.UtcNow));
        
        return account;
    }
    
    // Commands
    public void Deposit(decimal amount, string description)
    {
        if (amount <= 0)
            throw new DomainException("Deposit amount must be positive");
        
        if (Status != AccountStatus.Open)
            throw new DomainException("Cannot deposit to closed account");
        
        RaiseEvent(new MoneyDeposited(Id, amount, description, DateTime.UtcNow));
    }
    
    public void Withdraw(decimal amount, string description)
    {
        if (amount <= 0)
            throw new DomainException("Withdrawal amount must be positive");
        
        if (Status != AccountStatus.Open)
            throw new DomainException("Cannot withdraw from closed account");
        
        if (Balance < amount)
            throw new DomainException($"Insufficient funds. Balance: ${Balance}, Requested: ${amount}");
        
        RaiseEvent(new MoneyWithdrawn(Id, amount, description, DateTime.UtcNow));
    }
    
    public void Close(string reason)
    {
        if (Status == AccountStatus.Closed)
            throw new DomainException("Account already closed");
        
        if (Balance > 0)
            throw new DomainException("Cannot close account with positive balance. Withdraw all funds first.");
        
        RaiseEvent(new AccountClosed(Id, reason, DateTime.UtcNow));
    }
    
    public void AccrueInterest(decimal interestRate)
    {
        if (Status != AccountStatus.Open)
            throw new DomainException("Cannot accrue interest on closed account");
        
        var interestAmount = Balance * interestRate;
        if (interestAmount > 0)
        {
            RaiseEvent(new InterestAccrued(Id, interestAmount, DateTime.UtcNow));
        }
    }
    
    // Event application
    public void Apply(BankAccountEvent @event)
    {
        When(@event);
        Version++;
    }
    
    private void When(BankAccountEvent @event)
    {
        switch (@event)
        {
            case AccountOpened e:
                Id = e.AccountId;
                OwnerId = e.OwnerId;
                OwnerName = e.OwnerName;
                Balance = e.InitialBalance;
                Status = AccountStatus.Open;
                OpenedAt = e.OpenedAt;
                break;
            
            case MoneyDeposited e:
                Balance += e.Amount;
                break;
            
            case MoneyWithdrawn e:
                Balance -= e.Amount;
                break;
            
            case InterestAccrued e:
                Balance += e.InterestAmount;
                break;
            
            case AccountClosed e:
                Status = AccountStatus.Closed;
                ClosedAt = e.ClosedAt;
                break;
        }
    }
    
    private void RaiseEvent(BankAccountEvent @event)
    {
        When(@event);
        _uncommittedEvents.Add(@event);
        Version++;
    }
    
    public void MarkEventsAsCommitted()
    {
        _uncommittedEvents.Clear();
    }
}

public enum AccountStatus { Open, Closed }
```

### 3. Test Event Replay:

```csharp
public class BankAccountTests
{
    [Fact]
    public void EventReplay_ShouldRecreateCorrectState()
    {
        // Arrange - Create account and perform operations
        var account = BankAccount.Open(Guid.NewGuid(), "John Doe", 100m);
```

## Self-Check Questions

1. **What's the fundamental difference between event sourcing and traditional state storage?**
   - Answer: Traditional storage keeps only current state. Event sourcing stores all state changes as events, allowing you to rebuild state at any point in time by replaying events.

2. **How do you rebuild aggregate state from events?**
   - Answer: Create a new aggregate instance, load all events for that aggregate from the event store, and apply each event in order using the `Apply()` or `When()` method.

3. **What is snapshotting and why is it useful?**
   - Answer: Snapshotting saves aggregate state at a point in time to avoid replaying thousands of events. Load the snapshot, then only replay events after that snapshot version.

4. **What are the main challenges of event sourcing?**
   - Answer: Event schema evolution, query complexity (need projections), storage growth, learning curve, eventual consistency, and increased complexity.

5. **How does event sourcing enable temporal queries?**
   - Answer: Replay events up to a specific timestamp to see state at that point in time. Example: "What was the account balance on January 1st?"

6. **What's the purpose of the `Version` field?**
   - Answer: Optimistic concurrency control. Ensures no conflicting changes were made between loading and saving an aggregate.

7. **Why are events immutable?**
   - Answer: Events represent facts that happened in the past. Facts don't change. Immutability ensures audit trail integrity and enables event replay.

8. **How do you handle changing requirements with immutable events?**
   - Answer: Use event versioning and upcasting. Create new event versions and write upcasters to transform old events to new format when replaying.
