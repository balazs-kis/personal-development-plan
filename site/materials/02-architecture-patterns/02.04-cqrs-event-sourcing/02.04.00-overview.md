# Chapter 2.4: CQRS and Event Sourcing

## Overview
Explore Command Query Responsibility Segregation (CQRS) for separating read and write models, and Event Sourcing for persisting state as a sequence of events rather than current state. These patterns are powerful for complex domains but add significant complexity—learn when to use them and when simpler alternatives suffice.

## Key Concepts
- **Command vs Query Separation:** splitting read and write responsibilities.
- **Read Models and Projections:** optimizing queries independently from writes.
- **Event Sourcing Fundamentals:** storing events instead of current state.
- **Event Store:** implementing and working with event stores.
- **When to Use:** understanding the trade-offs and appropriate use cases.
