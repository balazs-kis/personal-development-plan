## Key Concepts Summary

### Complete CQRS Architecture

```
                Write Side                          Read Side
                    │                                  │
                    ▼                                  ▼
            ┌──────────────┐                  ┌──────────────┐
            │   Commands   │                  │   Queries    │
            └──────┬───────┘                  └──────┬───────┘
                   │                                  │
                   ▼                                  ▼
            ┌──────────────┐                  ┌──────────────┐
            │   Handlers   │                  │   Handlers   │
            └──────┬───────┘                  └──────┬───────┘
                   │                                  │
                   ▼                                  ▼
            ┌──────────────┐                  ┌──────────────┐
            │  Domain      │  ─── Events ───▶ │  Read Model  │
            │  Model       │                  │  Projections │
            └──────┬───────┘                  └──────┬───────┘
                   │                                  │
                   ▼                                  ▼
            ┌──────────────┐                  ┌──────────────┐
            │  Write DB    │                  │   Read DB    │
            └──────────────┘                  └──────────────┘
```

**1. Domain Model (Write Side)**
```csharp
// Domain/Entities/Product.cs
public class Product
{
    public Guid Id { get; private set; }
    public string Name { get; private set; }
    public string Description { get; private set; }
    public decimal Price { get; private set; }
    public int StockQuantity { get; private set; }
    
    private Product() { }  // For EF
    
    public static Product Create(string name, string description, decimal price, int initialStock)
    {
        var product = new Product
        {
            Id = Guid.NewGuid(),
            Name = name,
            Description = description,
            Price = price,
            StockQuantity = initialStock
        };
        
        // Raise domain event
        product.AddDomainEvent(new ProductCreated(product.Id, name, price));
        
        return product;
    }
    
    public void UpdateStock(int quantity)
    {
        StockQuantity += quantity;
        AddDomainEvent(new ProductStockUpdated(Id, StockQuantity));
    }
    
    // Domain events collection
    private List<DomainEvent> _domainEvents = new();
    public IReadOnlyCollection<DomainEvent> DomainEvents => _domainEvents.AsReadOnly();
    
    private void AddDomainEvent(DomainEvent eventItem)
    {
        _domainEvents.Add(eventItem);
    }
    
    public void ClearDomainEvents()
    {
        _domainEvents.Clear();
    }
}
```

**2. Commands (Write Side)**
```csharp
// Application/Products/Commands/CreateProduct/CreateProductCommand.cs
public record CreateProductCommand(
    string Name,
    string Description,
    decimal Price,
    int InitialStock) : IRequest<Guid>;

// Validator
public class CreateProductCommandValidator : AbstractValidator<CreateProductCommand>
{
    public CreateProductCommandValidator()
    {
        RuleFor(x => x.Name)
            .NotEmpty().WithMessage("Product name is required")
            .MaximumLength(200).WithMessage("Product name must not exceed 200 characters");
        
        RuleFor(x => x.Price)
            .GreaterThan(0).WithMessage("Price must be greater than zero");
        
        RuleFor(x => x.InitialStock)
            .GreaterThanOrEqualTo(0).WithMessage("Stock cannot be negative");
    }
}

// Handler
public class CreateProductCommandHandler : IRequestHandler<CreateProductCommand, Guid>
{
    private readonly IApplicationDbContext _context;
    private readonly IEventPublisher _eventPublisher;
    
    public CreateProductCommandHandler(
        IApplicationDbContext context,
        IEventPublisher eventPublisher)
    {
        _context = context;
        _eventPublisher = eventPublisher;
    }
    
    public async Task<Guid> Handle(CreateProductCommand request, CancellationToken cancellationToken)
    {
        var product = Product.Create(
            request.Name,
            request.Description,
            request.Price,
            request.InitialStock);
        
        _context.Products.Add(product);
        await _context.SaveChangesAsync(cancellationToken);
        
        // Publish domain events
        foreach (var domainEvent in product.DomainEvents)
        {
            await _eventPublisher.Publish(domainEvent, cancellationToken);
        }
        
        product.ClearDomainEvents();
        
        return product.Id;
    }
}
```

**3. Queries (Read Side)**
```csharp
// Application/Products/Queries/GetProductsList/GetProductsListQuery.cs
public record GetProductsListQuery : IRequest<List<ProductListDto>>;

public class ProductListDto
{
    public Guid Id { get; set; }
    public string Name { get; set; }
    public decimal Price { get; set; }
    public int StockQuantity { get; set; }
    public bool InStock => StockQuantity > 0;
}

// Handler - optimized for reading
public class GetProductsListQueryHandler : IRequestHandler<GetProductsListQuery, List<ProductListDto>>
{
    private readonly IApplicationDbContext _context;
    
    public GetProductsListQueryHandler(IApplicationDbContext context)
    {
        _context = context;
    }
    
    public async Task<List<ProductListDto>> Handle(GetProductsListQuery request, CancellationToken cancellationToken)
    {
        return await _context.Products
            .AsNoTracking()  // Read-only, no change tracking overhead
            .Select(p => new ProductListDto
            {
                Id = p.Id,
                Name = p.Name,
                Price = p.Price,
                StockQuantity = p.StockQuantity
            })
            .ToListAsync(cancellationToken);
    }
}

// Detailed query
public record GetProductDetailQuery(Guid ProductId) : IRequest<ProductDetailDto>;

public class ProductDetailDto
{
    public Guid Id { get; set; }
    public string Name { get; set; }
    public string Description { get; set; }
    public decimal Price { get; set; }
    public int StockQuantity { get; set; }
    public DateTime CreatedAt { get; set; }
    public DateTime? LastModified { get; set; }
}

public class GetProductDetailQueryHandler : IRequestHandler<GetProductDetailQuery, ProductDetailDto>
{
    private readonly IApplicationDbContext _context;
    
    public GetProductDetailQueryHandler(IApplicationDbContext context)
    {
        _context = context;
    }
    
    public async Task<ProductDetailDto> Handle(GetProductDetailQuery request, CancellationToken cancellationToken)
    {
        var product = await _context.Products
            .AsNoTracking()
            .Where(p => p.Id == request.ProductId)
            .Select(p => new ProductDetailDto
            {
                Id = p.Id,
                Name = p.Name,
                Description = p.Description,
                Price = p.Price,
                StockQuantity = p.StockQuantity,
                CreatedAt = p.CreatedAt,
                LastModified = p.LastModified
            })
            .FirstOrDefaultAsync(cancellationToken);
        
        if (product == null)
            throw new NotFoundException(nameof(Product), request.ProductId);
        
        return product;
    }
}
```

**6. Separate Databases (Optional but powerful)**
```csharp
// Write database - normalized, enforces constraints
public class WriteDbContext : DbContext
{
    public DbSet<Product> Products { get; set; }
    public DbSet<Order> Orders { get; set; }
    public DbSet<OrderLine> OrderLines { get; set; }
    
    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        // Full entity configurations with relationships
        modelBuilder.Entity<Product>(entity =>
        {
            entity.HasKey(e => e.Id);
            entity.Property(e => e.Name).IsRequired().HasMaxLength(200);
            entity.Property(e => e.Price).HasPrecision(18, 2);
        });
        
        modelBuilder.Entity<Order>(entity =>
        {
            entity.HasKey(e => e.Id);
            entity.HasMany(e => e.Lines)
                .WithOne()
                .OnDelete(DeleteBehavior.Cascade);
        });
    }
}

// Read database - denormalized, optimized for queries
public class ReadDbContext : DbContext
{
    public DbSet<ProductReadModel> Products { get; set; }
    public DbSet<OrderSummaryReadModel> OrderSummaries { get; set; }
    
    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        // Flat, denormalized structures for fast queries
        modelBuilder.Entity<ProductReadModel>(entity =>
        {
            entity.ToTable("ProductReadModels");
            entity.HasKey(e => e.Id);
            entity.HasIndex(e => e.Name);  // Indexes for common queries
            entity.HasIndex(e => e.Category);
            entity.HasIndex(e => e.Price);
        });
        
        modelBuilder.Entity<OrderSummaryReadModel>(entity =>
        {
            entity.ToTable("OrderSummaries");
            entity.HasKey(e => e.Id);
            entity.HasIndex(e => e.CustomerId);
            entity.HasIndex(e => e.Status);
            entity.HasIndex(e => e.OrderDate);
        });
    }
}

// Denormalized read model
public class ProductReadModel
```

**7. Dependency Injection Setup:**
```csharp
// Program.cs or Startup.cs
public static IServiceCollection AddCqrs(
    this IServiceCollection services,
    IConfiguration configuration)
{
    // MediatR
    services.AddMediatR(cfg => 
        cfg.RegisterServicesFromAssembly(Assembly.GetExecutingAssembly()));
    
    // FluentValidation
    services.AddValidatorsFromAssembly(Assembly.GetExecutingAssembly());
    
    // Pipeline behaviors
    services.AddTransient(typeof(IPipelineBehavior<,>), typeof(ValidationBehavior<,>));
    services.AddTransient(typeof(IPipelineBehavior<,>), typeof(LoggingBehavior<,>));
    services.AddTransient(typeof(IPipelineBehavior<,>), typeof(PerformanceBehavior<,>));
    
    // Write database
    services.AddDbContext<WriteDbContext>(options =>
        options.UseSqlServer(configuration.GetConnectionString("WriteDb")));
    
    // Read database (could be different DB or read replica)
    services.AddDbContext<ReadDbContext>(options =>
        options.UseSqlServer(configuration.GetConnectionString("ReadDb")));
    
    // Repositories
    services.AddScoped<IApplicationDbContext>(sp => sp.GetRequiredService<WriteDbContext>());
    services.AddScoped<IReadDbContext>(sp => sp.GetRequiredService<ReadDbContext>());
    
    // Event publisher
    services.AddScoped<IEventPublisher, EventPublisher>();
    
    return services;
}
```

## Advanced Patterns

### Caching Read Models

```csharp
public class GetProductDetailQueryHandler : IRequestHandler<GetProductDetailQuery, ProductDetailDto>
{
    private readonly IReadDbContext _context;
    private readonly IDistributedCache _cache;
    
    public async Task<ProductDetailDto> Handle(
        GetProductDetailQuery request,
        CancellationToken cancellationToken)
    {
        var cacheKey = $"product:{request.ProductId}";
        var cached = await _cache.GetStringAsync(cacheKey, cancellationToken);
        
        if (cached != null)
            return JsonSerializer.Deserialize<ProductDetailDto>(cached);
        
        var product = await _context.Products
            .AsNoTracking()
            .Where(p => p.Id == request.ProductId)
            .Select(p => new ProductDetailDto { /* ... */ })
            .FirstOrDefaultAsync(cancellationToken);
        
        if (product == null)
            throw new NotFoundException(nameof(Product), request.ProductId);
        
        await _cache.SetStringAsync(
            cacheKey,
            JsonSerializer.Serialize(product),
            new DistributedCacheEntryOptions
            {
                AbsoluteExpirationRelativeToNow = TimeSpan.FromMinutes(5)
            },
            cancellationToken);
        
        return product;
    }
}
```

```csharp
public class Post
{
    public Guid Id { get; private set; }
    public string Title { get; private set; }
    public string Content { get; private set; }
    public Guid AuthorId { get; private set; }
    public PostStatus Status { get; private set; }
    public DateTime CreatedAt { get; private set; }
    public DateTime? PublishedAt { get; private set; }
    private readonly List<Comment> _comments = new();
    public IReadOnlyCollection<Comment> Comments => _comments.AsReadOnly();
    
    private Post() { }
    
    public static Post Create(string title, string content, Guid authorId)
    {
        if (string.IsNullOrWhiteSpace(title))
            throw new DomainException("Title is required");
        if (title.Length > 200)
            throw new DomainException("Title cannot exceed 200 characters");
        
        return new Post
        {
            Id = Guid.NewGuid(),
            Title = title,
            Content = content,
            AuthorId = authorId,
            Status = PostStatus.Draft,
            CreatedAt = DateTime.UtcNow
        };
    }
    
    public void Publish()
    {
        if (Status == PostStatus.Published)
            throw new DomainException("Post already published");
        
        Status = PostStatus.Published;
        PublishedAt = DateTime.UtcNow;
    }
    
    public void AddComment(Guid authorId, string content)
    {
        if (Status != PostStatus.Published)
            throw new DomainException("Cannot comment on unpublished post");
        
        _comments.Add(Comment.Create(Id, authorId, content));
    }
}

public class Comment
{
    public Guid Id { get; private set; }
    public Guid PostId { get; private set; }
    public Guid AuthorId { get; private set; }
    public string Content { get; private set; }
    public DateTime CreatedAt { get; private set; }
    
    public static Comment Create(Guid postId, Guid authorId, string content)
    {
        return new Comment
        {
            Id = Guid.NewGuid(),
            PostId = postId,
            AuthorId = authorId,
            Content = content,
            CreatedAt = DateTime.UtcNow
        };
    }
}

public enum PostStatus { Draft, Published, Archived }
```

### 2. Commands (Write Side)

```csharp
// Create Post Command
public record CreatePostCommand(
    string Title,
    string Content,
    Guid AuthorId) : IRequest<Guid>;

public class CreatePostCommandValidator : AbstractValidator<CreatePostCommand>
{
    public CreatePostCommandValidator()
    {
        RuleFor(x => x.Title)
            .NotEmpty()
            .MaximumLength(200);
        
        RuleFor(x => x.Content)
            .NotEmpty()
            .MinimumLength(50)
            .WithMessage("Post content must be at least 50 characters");
        
        RuleFor(x => x.AuthorId).NotEmpty();
    }
}

public class CreatePostCommandHandler : IRequestHandler<CreatePostCommand, Guid>
{
    private readonly IApplicationDbContext _context;
    private readonly IEventPublisher _eventPublisher;
    
    public async Task<Guid> Handle(CreatePostCommand request, CancellationToken ct)
    {
        var post = Post.Create(request.Title, request.Content, request.AuthorId);
        
        _context.Posts.Add(post);
        await _context.SaveChangesAsync(ct);
        
        await _eventPublisher.Publish(new PostCreated(post.Id, post.Title, post.AuthorId), ct);
        
        return post.Id;
    }
}

// Publish Post Command
public record PublishPostCommand(Guid PostId) : IRequest;

public class PublishPostCommandHandler : IRequestHandler<PublishPostCommand>
{
    private readonly IApplicationDbContext _context;
    private readonly IEventPublisher _eventPublisher;
    
    public async Task Handle(PublishPostCommand request, CancellationToken ct)
    {
        var post = await _context.Posts.FindAsync(request.PostId);
        
        if (post == null)
            throw new NotFoundException(nameof(Post), request.PostId);
        
        post.Publish();
        await _context.SaveChangesAsync(ct);
        
        await _eventPublisher.Publish(new PostPublished(post.Id, post.PublishedAt.Value), ct);
    }
}

// Add Comment Command
public record AddCommentCommand(
    Guid PostId,
    Guid AuthorId,
    string Content) : IRequest<Guid>;

public class AddCommentCommandValidator : AbstractValidator<AddCommentCommand>
{
    public AddCommentCommandValidator()
    {
        RuleFor(x => x.PostId).NotEmpty();
        RuleFor(x => x.AuthorId).NotEmpty();
        RuleFor(x => x.Content)
            .NotEmpty()
            .MinimumLength(10)
            .MaximumLength(1000);
    }
}

public class AddCommentCommandHandler : IRequestHandler<AddCommentCommand, Guid>
{
    private readonly IApplicationDbContext _context;
    
    public async Task<Guid> Handle(AddCommentCommand request, CancellationToken ct)
    {
        var post = await _context.Posts
            .Include(p => p.Comments)
            .FirstOrDefaultAsync(p => p.Id == request.PostId, ct);
        
        if (post == null)
            throw new NotFoundException(nameof(Post), request.PostId);
        
        post.AddComment(request.AuthorId, request.Content);
        await _context.SaveChangesAsync(ct);
        
        return post.Comments.Last().Id;
    }
}
```

### 3. Queries (Read Side)

```csharp
// Get Posts List Query
public record GetPostsListQuery(bool PublishedOnly = true) : IRequest<List<PostListDto>>;

public class PostListDto
{
    public Guid Id { get; set; }
    public string Title { get; set; }
    public string AuthorName { get; set; }
    public DateTime PublishDate { get; set; }
    public int CommentCount { get; set; }
}

public class GetPostsListQueryHandler : IRequestHandler<GetPostsListQuery, List<PostListDto>>
{
    private readonly IApplicationDbContext _context;
    
    public async Task<List<PostListDto>> Handle(GetPostsListQuery request, CancellationToken ct)
    {
        var query = _context.Posts.AsNoTracking();
        
        if (request.PublishedOnly)
            query = query.Where(p => p.Status == PostStatus.Published);
        
        return await query
            .OrderByDescending(p => p.PublishedAt ?? p.CreatedAt)
            .Select(p => new PostListDto
            {
                Id = p.Id,
                Title = p.Title,
                AuthorName = p.Author.Name,
                PublishDate = p.PublishedAt ?? p.CreatedAt,
                CommentCount = p.Comments.Count
            })
            .ToListAsync(ct);
    }
}

// Get Post Detail Query
public record GetPostDetailQuery(Guid PostId) : IRequest<PostDetailDto>;

public class PostDetailDto
{
    public Guid Id { get; set; }
    public string Title { get; set; }
    public string Content { get; set; }
    public string AuthorName { get; set; }
    public DateTime PublishDate { get; set; }
    public List<CommentDto> Comments { get; set; }
}

public class CommentDto
{
    public Guid Id { get; set; }
    public string AuthorName { get; set; }
    public string Content { get; set; }
    public DateTime CreatedAt { get; set; }
}

public class GetPostDetailQueryHandler : IRequestHandler<GetPostDetailQuery, PostDetailDto>
{
    private readonly IApplicationDbContext _context;
    
    public async Task<PostDetailDto> Handle(GetPostDetailQuery request, CancellationToken ct)
    {
        var post = await _context.Posts
            .AsNoTracking()
            .Include(p => p.Author)
            .Include(p => p.Comments)
                .ThenInclude(c => c.Author)
            .Where(p => p.Id == request.PostId)
            .Select(p => new PostDetailDto
            {
                Id = p.Id,
                Title = p.Title,
                Content = p.Content,
                AuthorName = p.Author.Name,
                PublishDate = p.PublishedAt ?? p.CreatedAt,
                Comments = p.Comments.Select(c => new CommentDto
                {
                    Id = c.Id,
                    AuthorName = c.Author.Name,
                    Content = c.Content,
                    CreatedAt = c.CreatedAt
                }).ToList()
            })
            .FirstOrDefaultAsync(ct);
        
        if (post == null)
            throw new NotFoundException(nameof(Post), request.PostId);
        
        return post;
    }
}
```

## Self-Check Questions

1. **What's the main benefit of having separate write and read databases?**
   - Answer: Write DB can be normalized for data integrity and business rules. Read DB can be denormalized for query performance. Each optimized for its purpose, and they scale independently.

2. **How do domain events bridge the write and read sides?**
   - Answer: After write operations save to the write DB, they publish domain events. Event handlers listen for these events and update read models/projections accordingly.

3. **Why use `AsNoTracking()` in query handlers?**
   - Answer: Queries only read data, never modify it. AsNoTracking() disables change tracking, improving query performance since EF doesn't need to track entities.

4. **When should you use denormalized read models?**
   - Answer: When queries need data from multiple tables, when read performance is critical, when the same data is queried frequently, or when scaling read operations.

5. **What's eventual consistency and how do you handle it?**
   - Answer: Read models may lag behind write models (milliseconds to seconds). Handle it by: designing UI to expect it, showing "processing" states, using polling/websockets for updates, or accepting stale data for non-critical reads.

6. **How do you handle failures in event projections?**
   - Answer: Implement retry logic, use dead-letter queues for failed events, log failures for manual intervention, and design projections to be idempotent (safe to replay).

7. **What's the difference between a projection and a read model?**
   - Answer: A projection is the process of transforming events/domain entities into read models. Read models are the denormalized data structures optimized for queries.

## CQRS vs Traditional Architecture

| Aspect | Traditional | CQRS |
|--------|------------|------|
| **Models** | Single model | Separate read/write models |
| **Scalability** | Scale together | Scale independently |
| **Complexity** | Low | Higher |
| **Performance** | Balanced | Optimized per side |
| **Consistency** | Immediate | Eventual |
| **Best For** | Simple CRUD | Complex domains |
