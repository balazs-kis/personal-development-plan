## Introduction

Performance optimization begins with accurate measurement. BenchmarkDotNet is the gold standard for benchmarking .NET code, providing statistically rigorous performance measurements that account for JIT compilation, garbage collection, and other runtime effects. It eliminates the guesswork from performance tuning by giving you reliable, repeatable metrics to make informed optimization decisions.

## Key Concepts Summary

### Why BenchmarkDotNet?

Traditional benchmarking approaches are unreliable:

```csharp
❌ Don't: Manual timing
var sw = Stopwatch.StartNew();
for (int i = 0; i < 1000; i++)
{
    MyMethod();
}
sw.Stop();
Console.WriteLine($"Took: {sw.ElapsedMilliseconds}ms");
```

**Problems with Manual Timing:**
- No warm-up for JIT compilation
- Single measurement (unreliable)
- No statistical analysis
- Affected by garbage collection
- Debug builds vs. Release builds
- No isolation from other processes

**BenchmarkDotNet Handles:**
- JIT warm-up iterations
- Multiple runs with statistical analysis
- Garbage collection effects
- Platform and runtime detection
- Memory allocation tracking
- Comprehensive reporting

### Getting Started

#### 1. Create Console Application

```bash
dotnet new console -n MyBenchmarks
cd MyBenchmarks
```

**Important:** BenchmarkDotNet only works with Console Applications.

#### 2. Install Package

```bash
dotnet add package BenchmarkDotNet
```

#### 3. Create a Benchmark Class

```csharp
using BenchmarkDotNet.Attributes;
using BenchmarkDotNet.Running;

public class StringConcatenationBenchmarks
{
    private const int Iterations = 1000;

    [Benchmark]
    public string ConcatenateWithPlus()
    {
        string result = "";
        for (int i = 0; i < Iterations; i++)
        {
            result += "a";
        }
        return result;
    }

    [Benchmark]
    public string ConcatenateWithStringBuilder()
    {
        var sb = new StringBuilder();
        for (int i = 0; i < Iterations; i++)
        {
            sb.Append("a");
        }
        return sb.ToString();
    }

    [Benchmark]
    public string ConcatenateWithStringCreate()
    {
        return string.Create(Iterations, 0, (span, _) =>
        {
            span.Fill('a');
        });
    }
}

public class Program
{
    public static void Main(string[] args)
    {
        var summary = BenchmarkRunner.Run<StringConcatenationBenchmarks>();
    }
}
```

#### 4. Run Benchmarks

```bash
dotnet run -c Release
```

**Critical:** Always use Release configuration. Debug can be 10-100x slower.

#### 5. View Results

Results are displayed in console and saved to:
```
.\BenchmarkDotNet.Artifacts\results\
```

**Example Output:**
```
| Method                           | Mean       | Error    | StdDev   | Allocated |
|--------------------------------- |-----------:|---------:|---------:|----------:|
| ConcatenateWithPlus              | 50.234 us  | 0.425 us | 0.377 us |   499 KB  |
| ConcatenateWithStringBuilder     |  1.234 us  | 0.012 us | 0.011 us |     4 KB  |
| ConcatenateWithStringCreate      |  0.089 us  | 0.001 us | 0.001 us |     1 KB  |
```

### Key Attributes

#### [Benchmark] - Mark Methods to Measure

```csharp
public class MyBenchmarks
{
    [Benchmark]
    public int Method1() => 42;

    [Benchmark(Baseline = true)]  // Compare others to this
    public int Method2() => 43;
}
```

#### [Params] - Parameterize Benchmarks

```csharp
public class CollectionBenchmarks
{
    [Params(10, 100, 1000)]
    public int Size { get; set; }

    private int[] data;

    [GlobalSetup]
    public void Setup()
    {
        data = Enumerable.Range(0, Size).ToArray();
    }

    [Benchmark]
    public int SumWithFor()
    {
        int sum = 0;
        for (int i = 0; i < data.Length; i++)
        {
            sum += data[i];
        }
        return sum;
    }

    [Benchmark]
    public int SumWithLinq()
    {
        return data.Sum();
    }
}
```

**Output:** Runs benchmarks for each parameter combination:
- Size = 10
- Size = 100
- Size = 1000

#### [MemoryDiagnoser] - Track Allocations

```csharp
[MemoryDiagnoser]
public class AllocationBenchmarks
{
    [Benchmark]
    public string CreateString()
    {
        return new string('a', 100);
    }

    [Benchmark]
    public byte[] CreateArray()
    {
        return new byte[100];
    }
}
```

**Output includes:**
- Gen0/Gen1/Gen2 collections
- Total allocated bytes

#### Setup and Cleanup Attributes

```csharp
public class DatabaseBenchmarks
{
    private DbConnection connection;
    private DbCommand command;

    [GlobalSetup]  // Once before all iterations
    public void GlobalSetup()
    {
        connection = new SqlConnection(connectionString);
        connection.Open();
    }

    [GlobalCleanup]  // Once after all iterations
    public void GlobalCleanup()
    {
        connection.Dispose();
    }

    [IterationSetup]  // Before each benchmark iteration
    public void IterationSetup()
    {
        command = connection.CreateCommand();
        command.CommandText = "SELECT * FROM Users";
    }

    [IterationCleanup]  // After each benchmark iteration
    public void IterationCleanup()
    {
        command.Dispose();
    }

    [Benchmark]
    public int ExecuteQuery()
    {
        using var reader = command.ExecuteReader();
        int count = 0;
        while (reader.Read()) count++;
        return count;
    }
}
```

**Important:** Avoid `[IterationSetup]` and `[IterationCleanup]` for microbenchmarks as they add overhead.

### Configuring Benchmarks

#### Job Configuration

```csharp
using BenchmarkDotNet.Jobs;

[SimpleJob(RuntimeMoniker.Net70)]
[SimpleJob(RuntimeMoniker.Net80)]
public class RuntimeComparisonBenchmarks
{
    [Benchmark]
    public string ReverseString()
    {
        return new string("Hello World".Reverse().ToArray());
    }
}
```

**Compares performance across .NET 7 and .NET 8.**

#### Custom Configuration

```csharp
using BenchmarkDotNet.Configs;
using BenchmarkDotNet.Diagnosers;
using BenchmarkDotNet.Exporters;

[Config(typeof(Config))]
public class CustomConfigBenchmarks
{
    private class Config : ManualConfig
    {
        public Config()
        {
            AddDiagnoser(MemoryDiagnoser.Default);
            AddDiagnoser(ThreadingDiagnoser.Default);
            AddExporter(HtmlExporter.Default);
            AddExporter(MarkdownExporter.GitHub);
        }
    }

    [Benchmark]
    public async Task AsyncMethod()
    {
        await Task.Delay(10);
    }
}
```

### Understanding Results

**Key Metrics:**

```
| Method | Mean    | Error   | StdDev  | Median  | Allocated |
|------- |--------:|--------:|--------:|--------:|----------:|
| Method | 1.234us | 0.012us | 0.011us | 1.230us |     256 B |
```

- **Mean** - Average execution time
- **Error** - Half of 99.9% confidence interval
- **StdDev** - Standard deviation of all measurements
- **Median** - Middle value in sorted measurements
- **Allocated** - Total memory allocated

**Reading the Results:**
```
Method1: 1.234 us ± 0.012 us
         ↑         ↑
         Mean      Error

Interpretation: "Method1 takes 1.234 microseconds, 
                 give or take 0.012 microseconds"
```

### Baseline Comparison

```csharp
public class ComparisonBenchmarks
{
    [Benchmark(Baseline = true)]
    public int ListFor()
    {
        var list = new List<int>();
        for (int i = 0; i < 100; i++)
            list.Add(i);
        return list.Count;
    }

    [Benchmark]
    public int ListAddRange()
    {
        var list = new List<int>();
        list.AddRange(Enumerable.Range(0, 100));
        return list.Count;
    }

    [Benchmark]
    public int ArrayToList()
    {
        var array = Enumerable.Range(0, 100).ToArray();
        var list = new List<int>(array);
        return list.Count;
    }
}
```

**Output with Ratio:**
```
| Method        | Mean    | Ratio |
|-------------- |--------:|------:|
| ListFor       | 1.234us | 1.00  | ← Baseline
| ListAddRange  | 1.456us | 1.18  |
| ArrayToList   | 0.987us | 0.80  |
```

### Best Practices

#### 1. Always Use Release Configuration

```xml
<!-- In .csproj -->
<PropertyGroup>
  <Optimize>true</Optimize>
</PropertyGroup>
```

```bash
# Run from command line, not Visual Studio
dotnet run -c Release
```

#### 2. Return Values to Prevent Dead Code Elimination

```csharp
❌ Bad: JIT might eliminate the code
[Benchmark]
public void ComputeSum()
{
    int sum = 0;
    for (int i = 0; i < 1000; i++)
        sum += i;
    // sum is never used - might be optimized away!
}

✅ Good: Return the value
[Benchmark]
public int ComputeSum()
{
    int sum = 0;
    for (int i = 0; i < 1000; i++)
        sum += i;
    return sum;  // Forces computation
}
```

#### 3. Use Appropriate Iteration Counts

```csharp
❌ Bad: Too few iterations
[Benchmark]
public string BuildString()
{
    return "Hello";  // Too fast to measure accurately
}

✅ Good: Enough work to measure
[Benchmark]
public string BuildString()
{
    var sb = new StringBuilder();
    for (int i = 0; i < 100; i++)
        sb.Append("Hello");
    return sb.ToString();
}
```

#### 4. Isolate What You're Measuring

```csharp
❌ Bad: Setup in benchmark
[Benchmark]
public int ProcessData()
{
    var data = new int[1000];  // Don't measure this
    for (int i = 0; i < data.Length; i++)
        data[i] = i;           // Don't measure this
    
    return data.Sum();         // Only want to measure this
}

✅ Good: Use GlobalSetup
private int[] data;

[GlobalSetup]
public void Setup()
{
    data = new int[1000];
    for (int i = 0; i < data.Length; i++)
        data[i] = i;
}

[Benchmark]
public int ProcessData()
{
    return data.Sum();  // Only measure this
}
```

#### 5. Control GC Effects

```csharp
// Force GC between iterations
[MemoryDiagnoser]
[GcForce]  // Enabled by default
public class GCSensitiveBenchmarks
{
    [Benchmark]
    public byte[] AllocateLargeArray()
    {
        return new byte[1_000_000];
    }
}
```

#### 6. Warm Up the JIT

BenchmarkDotNet automatically does this, but be aware:

```
Benchmark Process:
1. Pilot: Determine optimal iteration count
2. Warm-up: Let JIT compile and optimize (default 6-15 iterations)
3. Actual: Collect measurements (default 15-100 iterations)
4. Result: Calculate statistics
```

#### Multiple Runtimes

```csharp
[SimpleJob(RuntimeMoniker.Net60)]
[SimpleJob(RuntimeMoniker.Net70)]

public class RuntimeBenchmarks
```

#### Arguments and ArgumentsSource

```csharp
public class ArgumentsBenchmarks
{
    [Benchmark]
    [Arguments(100)]
    [Arguments(1000)]
    [Arguments(10000)]
    public int ComputeSum(int n)
    {
        int sum = 0;
        for (int i = 0; i < n; i++)
            sum += i;
        return sum;
    }

    // Or use ArgumentsSource
    public IEnumerable<int> GetSizes()
    {
        yield return 100;
        yield return 1000;
        yield return 10000;
    }

    [Benchmark]
    [ArgumentsSource(nameof(GetSizes))]
    public int ComputeSumWithSource(int n)
    {
        int sum = 0;
        for (int i = 0; i < n; i++)
            sum += i;
        return sum;
    }
}
```

```csharp
[HtmlExporter]
[MarkdownExporter]

```
