## Introduction

Modern applications often need to perform work in the background—processing queues, sending scheduled emails, cleaning up old data, or polling external services. ASP.NET Core provides hosted services as a first-class way to run background tasks within your application. These services run alongside your web API or web application, sharing the same dependency injection container and configuration. This lesson covers everything from basic timed tasks to sophisticated queued background work patterns.

## Key Concepts Summary

### What are Hosted Services?

Hosted services are background tasks that run within your ASP.NET Core application:

```
ASP.NET Core App
├── Web API / MVC (handles HTTP requests)
└── Hosted Services (background tasks)
    ├── Timed tasks
    ├── Queue processors
    ├── Data synchronization
    └── Cleanup jobs
```

**Key Characteristics:**
- Run in the background alongside your web application
- Share the same DI container and configuration
- Lifecycle managed by the host
- Can be started, stopped, and monitored
- Multiple hosted services can run concurrently

**When to Use:**
```
✅ Use Hosted Services for:
   - Timed/scheduled tasks
   - Processing background queues
   - Data synchronization
   - Cache warming
   - Health checks
   - Monitoring and metrics collection
   - Cleanup operations

❌ Don't Use for:
   - Long-running CPU-intensive work (use separate worker service)
   - Very high-volume queue processing (use dedicated queue processor)
   - Tasks requiring guaranteed execution (use durable orchestration)
```

### IHostedService Interface

The foundation for all background services:

```csharp
public interface IHostedService
{
    Task StartAsync(CancellationToken cancellationToken);
    Task StopAsync(CancellationToken cancellationToken);
}
```

**Lifecycle:**
```
Application Startup → StartAsync() called
    ↓
Service runs in background
    ↓
Application Shutdown → StopAsync() called
```

### Basic IHostedService Implementation

```csharp
public class MyHostedService : IHostedService
{
    private readonly ILogger<MyHostedService> _logger;
    private Timer? _timer;

    public MyHostedService(ILogger<MyHostedService> logger)
    {
        _logger = logger;
    }

    public Task StartAsync(CancellationToken cancellationToken)
    {
        _logger.LogInformation("Service starting");
        
        // Start a timer that fires every 5 seconds
        _timer = new Timer(
            callback: DoWork,
            state: null,
            dueTime: TimeSpan.Zero,        // Start immediately
            period: TimeSpan.FromSeconds(5) // Repeat every 5 seconds
        );
        
        return Task.CompletedTask;
    }

    private void DoWork(object? state)
    {
        _logger.LogInformation("Background work executing at {Time}", DateTime.Now);
    }

    public Task StopAsync(CancellationToken cancellationToken)
    {
        _logger.LogInformation("Service stopping");
        
        _timer?.Change(Timeout.Infinite, 0);  // Stop the timer
        _timer?.Dispose();
        
        return Task.CompletedTask;
    }
}

// Registration
builder.Services.AddHostedService<MyHostedService>();
```

### BackgroundService Base Class

ASP.NET Core provides `BackgroundService` for easier implementation:

```csharp
public abstract class BackgroundService : IHostedService
{
    protected abstract Task ExecuteAsync(CancellationToken stoppingToken);
    
    // StartAsync and StopAsync are implemented for you
}
```

**Benefits:**
- Simpler to implement
- Handles StartAsync/StopAsync logic
- Provides CancellationToken for graceful shutdown
- Better for long-running tasks

**Basic Implementation:**

```csharp
public class MyBackgroundService : BackgroundService
{
    private readonly ILogger<MyBackgroundService> _logger;

    public MyBackgroundService(ILogger<MyBackgroundService> logger)
    {
        _logger = logger;
    }

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        _logger.LogInformation("Background service started");

        // Keep running until cancellation requested
        while (!stoppingToken.IsCancellationRequested)
        {
            _logger.LogInformation("Working at {Time}", DateTime.Now);
            
            // Do work here
            await Task.Delay(TimeSpan.FromSeconds(5), stoppingToken);
        }
        
        _logger.LogInformation("Background service stopping");
    }
}
```

### Timed Background Task Pattern

**Using Timer:**

```csharp
public class TimedHostedService : BackgroundService
{
    private readonly ILogger<TimedHostedService> _logger;
    private readonly TimeSpan _period = TimeSpan.FromMinutes(5);

    public TimedHostedService(ILogger<TimedHostedService> logger)
    {
        _logger = logger;
    }

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        using var timer = new PeriodicTimer(_period);
        
        while (!stoppingToken.IsCancellationRequested &&
               await timer.WaitForNextTickAsync(stoppingToken))
        {
            try
            {
                await DoWorkAsync(stoppingToken);
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Error occurred executing task");
            }
        }
    }

    private async Task DoWorkAsync(CancellationToken cancellationToken)
    {
        _logger.LogInformation("Timed task executing at {Time}", DateTime.Now);
        
        // Your work here
        await Task.Delay(100, cancellationToken);
    }
}
```

**Benefits of PeriodicTimer (.NET 6+):**
- More accurate than Task.Delay in a loop
- Prevents timer drift
- Better resource usage
- Automatically stops on cancellation

### Using Scoped Services in Hosted Services

**Problem:** Hosted services are singletons, but you often need scoped services (like DbContext):

```csharp
❌ WRONG: Can't inject scoped service into singleton
public class MyBackgroundService : BackgroundService
{
    private readonly AppDbContext _db;  // DbContext is scoped!
    
    public MyBackgroundService(AppDbContext db)  // This will fail!
    {
        _db = db;
    }
}
```

**Solution: Create a scope for each work iteration:**

```csharp
✅ CORRECT: Create scope, resolve scoped services
public class DatabaseCleanupService : BackgroundService
{
    private readonly IServiceProvider _serviceProvider;
    private readonly ILogger<DatabaseCleanupService> _logger;

    public DatabaseCleanupService(
        IServiceProvider serviceProvider,
        ILogger<DatabaseCleanupService> logger)
    {
        _serviceProvider = serviceProvider;
        _logger = logger;
    }

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            try
            {
                // Create a new scope for each iteration
                using var scope = _serviceProvider.CreateScope();
                
                // Resolve scoped services from the scope
                var db = scope.ServiceProvider.GetRequiredService<AppDbContext>();
                var orderService = scope.ServiceProvider.GetRequiredService<IOrderService>();
                
                // Do work with scoped services
                await CleanupOldOrdersAsync(db, stoppingToken);
                
                // Scope is disposed, services are disposed
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Error in cleanup service");
            }
            
            await Task.Delay(TimeSpan.FromHours(1), stoppingToken);
        }
    }

    private async Task CleanupOldOrdersAsync(AppDbContext db, CancellationToken ct)
    {
        var cutoffDate = DateTime.UtcNow.AddMonths(-6);
        var oldOrders = await db.Orders
            .Where(o => o.CreatedDate < cutoffDate)
            .ToListAsync(ct);
        
        db.Orders.RemoveRange(oldOrders);
        await db.SaveChangesAsync(ct);
        
        _logger.LogInformation("Cleaned up {Count} old orders", oldOrders.Count);
    }
}
```

### Queued Background Work Pattern

**Use Case:** Web API receives requests that trigger background work:

```
1. API receives request
2. Add work to queue
3. Return response immediately
4. Background service processes queue
```

**Implementation:**

#### 1. Work Item Interface

```csharp
public interface IBackgroundTaskQueue
{
    ValueTask QueueBackgroundWorkItemAsync(Func<CancellationToken, ValueTask> workItem);
    ValueTask<Func<CancellationToken, ValueTask>> DequeueAsync(CancellationToken cancellationToken);
}
```

#### 2. Queue Implementation

```csharp
public class BackgroundTaskQueue : IBackgroundTaskQueue
{
    private readonly Channel<Func<CancellationToken, ValueTask>> _queue;

    public BackgroundTaskQueue(int capacity = 100)
    {
        var options = new BoundedChannelOptions(capacity)
        {
            FullMode = BoundedChannelFullMode.Wait
        };
        
        _queue = Channel.CreateBounded<Func<CancellationToken, ValueTask>>(options);
    }

    public async ValueTask QueueBackgroundWorkItemAsync(
        Func<CancellationToken, ValueTask> workItem)
    {
        if (workItem == null)
            throw new ArgumentNullException(nameof(workItem));

        await _queue.Writer.WriteAsync(workItem);
    }

    public async ValueTask<Func<CancellationToken, ValueTask>> DequeueAsync(
        CancellationToken cancellationToken)
    {
        var workItem = await _queue.Reader.ReadAsync(cancellationToken);
        return workItem;
    }
}
```

#### 3. Background Service

```csharp
public class QueuedHostedService : BackgroundService
{
    private readonly IBackgroundTaskQueue _taskQueue;
    private readonly ILogger<QueuedHostedService> _logger;

    public QueuedHostedService(
        IBackgroundTaskQueue taskQueue,
        ILogger<QueuedHostedService> logger)
    {
        _taskQueue = taskQueue;
        _logger = logger;
    }

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        _logger.LogInformation("Queued Hosted Service is running");

        await BackgroundProcessingAsync(stoppingToken);
    }

    private async Task BackgroundProcessingAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            var workItem = await _taskQueue.DequeueAsync(stoppingToken);

            try
            {
                await workItem(stoppingToken);
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Error occurred executing work item");
            }
        }
    }

    public override async Task StopAsync(CancellationToken stoppingToken)
    {
        _logger.LogInformation("Queued Hosted Service is stopping");
        await base.StopAsync(stoppingToken);
    }
}
```

#### 4. Registration

```csharp
builder.Services.AddSingleton<IBackgroundTaskQueue, BackgroundTaskQueue>();
builder.Services.AddHostedService<QueuedHostedService>();
```

#### 5. Usage in Controller

```csharp
[ApiController]
[Route("api/[controller]")]
public class WorkController : ControllerBase
{
    private readonly IBackgroundTaskQueue _taskQueue;
    private readonly ILogger<WorkController> _logger;

    public WorkController(
        IBackgroundTaskQueue taskQueue,
        ILogger<WorkController> logger)
    {
        _taskQueue = taskQueue;
        _logger = logger;
    }

    [HttpPost]
    public async Task<IActionResult> Post([FromBody] WorkItem item)
    {
        // Queue the work
        await _taskQueue.QueueBackgroundWorkItemAsync(async cancellationToken =>
        {
            _logger.LogInformation("Processing work item {Id}", item.Id);
            
            // Simulate work
            await Task.Delay(TimeSpan.FromSeconds(10), cancellationToken);
            
            _logger.LogInformation("Completed work item {Id}", item.Id);
        });

        return Accepted();  // Return immediately
    }
}
```

### Real-World Example: Email Queue Service

```csharp
// Email message
public record EmailMessage(string To, string Subject, string Body);

// Email queue interface
public interface IEmailQueue
{
    ValueTask QueueEmailAsync(EmailMessage message);
}

// Email queue implementation
public class EmailQueue : IEmailQueue
{
    private readonly Channel<EmailMessage> _queue;

    public EmailQueue()
    {
        _queue = Channel.CreateUnbounded<EmailMessage>();
    }

    public async ValueTask QueueEmailAsync(EmailMessage message)
    {
        await _queue.Writer.WriteAsync(message);
    }

    public async ValueTask<EmailMessage> DequeueAsync(CancellationToken ct)
    {
        return await _queue.Reader.ReadAsync(ct);
    }
}

// Background email sender
public class EmailSenderService : BackgroundService
{
    private readonly EmailQueue _queue;
    private readonly IServiceProvider _serviceProvider;
    private readonly ILogger<EmailSenderService> _logger;

    public EmailSenderService(
        EmailQueue queue,
        IServiceProvider serviceProvider,
        ILogger<EmailSenderService> logger)
    {
        _queue = queue;
        _serviceProvider = serviceProvider;
        _logger = logger;
    }

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        _logger.LogInformation("Email Sender Service started");

        while (!stoppingToken.IsCancellationRequested)
        {
            try
            {
                var message = await _queue.DequeueAsync(stoppingToken);
                await SendEmailAsync(message, stoppingToken);
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Error sending email");
            }
        }
    }

    private async Task SendEmailAsync(EmailMessage message, CancellationToken ct)
    {
        using var scope = _serviceProvider.CreateScope();
        var emailService = scope.ServiceProvider.GetRequiredService<IEmailService>();
        
        _logger.LogInformation("Sending email to {To}", message.To);
        await emailService.SendAsync(message.To, message.Subject, message.Body);
        _logger.LogInformation("Email sent successfully");
    }
}

// Registration
builder.Services.AddSingleton<EmailQueue>();
builder.Services.AddSingleton<IEmailQueue>(sp => sp.GetRequiredService<EmailQueue>());
builder.Services.AddHostedService<EmailSenderService>();
```

### Graceful Shutdown

**Respecting CancellationToken:**

```csharp
public class GracefulBackgroundService : BackgroundService
{
    private readonly ILogger<GracefulBackgroundService> _logger;

    public GracefulBackgroundService(ILogger<GracefulBackgroundService> logger)
    {
        _logger = logger;
    }

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            try
            {
                await ProcessItemsAsync(stoppingToken);
            }
            catch (OperationCanceledException)
            {
                // Expected during shutdown
                _logger.LogInformation("Service shutting down gracefully");
                break;
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Error in background service");
            }
            
            await Task.Delay(TimeSpan.FromSeconds(5), stoppingToken);
        }
    }

    private async Task ProcessItemsAsync(CancellationToken ct)
    {
        // Check cancellation before long operations
        ct.ThrowIfCancellationRequested();
        
        // Pass cancellation token to async operations
        await SomeLongRunningOperationAsync(ct);
        
        ct.ThrowIfCancellationRequested();
        
        await AnotherOperationAsync(ct);
    }

    private async Task SomeLongRunningOperationAsync(CancellationToken ct)
    {
        // Simulate work with cancellation support
        for (int i = 0; i < 100; i++)
        {
            ct.ThrowIfCancellationRequested();
            await Task.Delay(100, ct);
        }
    }
}
```

### Best Practices

**1. Always Respect CancellationToken**
```csharp
✅ Good:
protected override async Task ExecuteAsync(CancellationToken stoppingToken)
{
    while (!stoppingToken.IsCancellationRequested)
    {
        await DoWorkAsync(stoppingToken);
        await Task.Delay(1000, stoppingToken);  // Pass token
    }
}

❌ Bad:
protected override async Task ExecuteAsync(CancellationToken stoppingToken)
{
    while (true)  // Never checks cancellation
    {
        await DoWorkAsync(CancellationToken.None);  // Ignores token
        await Task.Delay(1000);  // No cancellation support
    }
}
```

**2. Use Scopes for Scoped Services**
```csharp
✅ Good:
using var scope = _serviceProvider.CreateScope();
var db = scope.ServiceProvider.GetRequiredService<AppDbContext>();
```

**3. Handle Exceptions Gracefully**
```csharp
✅ Good:
try
{
    await DoWorkAsync(stoppingToken);
}
catch (OperationCanceledException)
{
    // Expected during shutdown
}
catch (Exception ex)
{
    _logger.LogError(ex, "Error in background task");
    // Don't let exception kill the service
}
```

**4. Use PeriodicTimer for Timed Tasks**
```csharp
✅ Modern (.NET 6+):
using var timer = new PeriodicTimer(TimeSpan.FromMinutes(5));
while (await timer.WaitForNextTickAsync(stoppingToken))
{
    await DoWorkAsync(stoppingToken);
}

❌ Old way:
while (!stoppingToken.IsCancellationRequested)
{
    await DoWorkAsync(stoppingToken);
    await Task.Delay(TimeSpan.FromMinutes(5), stoppingToken);
}
```

**5. Keep StartAsync Fast**
```csharp
✅ Good:
public Task StartAsync(CancellationToken cancellationToken)
{
    _logger.LogInformation("Starting");
    // Quick initialization only
    return Task.CompletedTask;
}

❌ Bad:
public async Task StartAsync(CancellationToken cancellationToken)
{
    await LoadLargeDataAsync();  // Blocks application startup!
}
```
