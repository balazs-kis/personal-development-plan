## Introduction

IAsyncEnumerable<T>, introduced in C# 8.0, brings async/await to enumeration. It allows you to produce and consume sequences of data asynchronously, streaming results as they become available rather than waiting for an entire collection. This is crucial for scenarios like paginated APIs, database queries, real-time data feeds, and processing large datasets without loading everything into memory.

## Key Concepts Summary

### What is IAsyncEnumerable<T>?

IAsyncEnumerable<T> is the asynchronous version of IEnumerable<T>:

```csharp
// Synchronous enumeration
public IEnumerable<int> GetNumbers()
{
    for (int i = 0; i < 10; i++)
    {
        yield return i;
    }
}

// Asynchronous enumeration
public async IAsyncEnumerable<int> GetNumbersAsync()
{
    for (int i = 0; i < 10; i++)
    {
        await Task.Delay(100); // Async operation
        yield return i;
    }
}
```

**Key Differences:**

| Feature | IEnumerable<T> | IAsyncEnumerable<T> |
|---------|----------------|---------------------|
| **Iteration** | `foreach` | `await foreach` |
| **Async support** | ❌ Blocks thread | ✅ Truly asynchronous |
| **Memory** | May load all data | Streams data incrementally |
| **Cancellation** | Limited support | Built-in with CancellationToken |
| **Use case** | In-memory collections | I/O-bound sequences |

### Generating Async Streams

#### Basic Pattern

```csharp
public async IAsyncEnumerable<string> ReadLinesAsync(string filePath)
{
    using var reader = new StreamReader(filePath);
    
    while (!reader.EndOfStream)
    {
        string? line = await reader.ReadLineAsync();
        if (line != null)
        {
            yield return line;
        }
    }
}
```

#### With Cancellation Support

```csharp
public async IAsyncEnumerable<int> GenerateNumbersAsync(
    int count,
    [EnumeratorCancellation] CancellationToken cancellationToken = default)
{
    for (int i = 0; i < count; i++)
    {
        cancellationToken.ThrowIfCancellationRequested();
        
        await Task.Delay(100, cancellationToken);
        yield return i;
    }
}
```

The `[EnumeratorCancellation]` attribute allows the compiler to automatically propagate the cancellation token.

### Consuming Async Streams

#### Simple Consumption

```csharp
await foreach (var item in GetItemsAsync())
{
    Console.WriteLine(item);
}
```

#### With Cancellation

```csharp
var cts = new CancellationTokenSource();

try
{
    await foreach (var item in GetItemsAsync().WithCancellation(cts.Token))
    {
        Console.WriteLine(item);
        
        if (ShouldStop())
        {
            cts.Cancel();
        }
    }
}
catch (OperationCanceledException)
{
    Console.WriteLine("Operation cancelled");
}
```

#### With ConfigureAwait

```csharp
await foreach (var item in GetItemsAsync().ConfigureAwait(false))
{
    // Process without capturing context
    ProcessItem(item);
}
```

### Real-World Patterns

#### 1. Database Pagination

```csharp
public async IAsyncEnumerable<Product> GetAllProductsAsync(
    [EnumeratorCancellation] CancellationToken cancellationToken = default)
{
    const int pageSize = 100;
    int page = 0;
    
    while (true)
    {
        var products = await _dbContext.Products
            .OrderBy(p => p.Id)
            .Skip(page * pageSize)
            .Take(pageSize)
            .ToListAsync(cancellationToken);
        
        if (products.Count == 0)
            yield break;
        
        foreach (var product in products)
        {
            yield return product;
        }
        
        if (products.Count < pageSize)
            yield break;
            
        page++;
    }
}

// Usage
await foreach (var product in GetAllProductsAsync())
{
    await ProcessProductAsync(product);
}
```

#### 2. REST API Pagination

```csharp
public async IAsyncEnumerable<User> GetAllUsersAsync(
    [EnumeratorCancellation] CancellationToken cancellationToken = default)
{
    string? nextPageUrl = "https://api.example.com/users?page=1";
    
    while (!string.IsNullOrEmpty(nextPageUrl))
    {
        var response = await _httpClient.GetFromJsonAsync<PagedResponse<User>>(
            nextPageUrl, 
            cancellationToken);
        
        if (response?.Data == null)
            yield break;
        
        foreach (var user in response.Data)
        {
            yield return user;
        }
        
        nextPageUrl = response.NextPageUrl;
    }
}

public class PagedResponse<T>
{
    public List<T> Data { get; set; } = new();
    public string? NextPageUrl { get; set; }
}
```

#### 3. Real-Time Data Streaming

```csharp
public async IAsyncEnumerable<StockPrice> StreamStockPricesAsync(
    string symbol,
    [EnumeratorCancellation] CancellationToken cancellationToken = default)
{
    using var connection = new HubConnectionBuilder()
        .WithUrl($"https://api.stockmarket.com/hub")
        .Build();
    
    await connection.StartAsync(cancellationToken);
    
    var channel = Channel.CreateUnbounded<StockPrice>();
    
    connection.On<StockPrice>("UpdatePrice", price =>
    {
        channel.Writer.TryWrite(price);
    });
    
    await connection.InvokeAsync("Subscribe", symbol, cancellationToken);
    
    await foreach (var price in channel.Reader.ReadAllAsync(cancellationToken))
    {
        yield return price;
    }
}
```

#### 4. File Processing

```csharp
public async IAsyncEnumerable<LogEntry> ParseLogFileAsync(
    string filePath,
    [EnumeratorCancellation] CancellationToken cancellationToken = default)
{
    using var stream = new FileStream(filePath, FileMode.Open, FileAccess.Read);
    using var reader = new StreamReader(stream);
    
    while (!reader.EndOfStream)
    {
        cancellationToken.ThrowIfCancellationRequested();
        
        var line = await reader.ReadLineAsync(cancellationToken);
        if (string.IsNullOrWhiteSpace(line))
            continue;
        
        if (TryParseLogEntry(line, out var entry))
        {
            yield return entry;
        }
    }
}

// Usage with filtering
await foreach (var entry in ParseLogFileAsync("app.log")
    .Where(e => e.Level == LogLevel.Error))
{
    Console.WriteLine($"Error: {entry.Message}");
}
```

### LINQ with Async Streams

Use the `System.Linq.Async` NuGet package for LINQ operations on IAsyncEnumerable:

```bash
dotnet add package System.Linq.Async
```

```csharp
using System.Linq;

// Filtering
var errors = GetLogEntriesAsync()
    .Where(entry => entry.Level == LogLevel.Error);

// Mapping
var userNames = GetUsersAsync()
    .Select(user => user.Name);

// Take
var firstTen = GetProductsAsync()
    .Take(10);

// Skip
var afterFirst100 = GetProductsAsync()
    .Skip(100);

// Aggregation (materializes the stream)
int errorCount = await GetLogEntriesAsync()
    .Where(e => e.Level == LogLevel.Error)
    .CountAsync();

decimal totalRevenue = await GetOrdersAsync()
    .SumAsync(order => order.Total);

// ToList (materializes the stream)
List<User> users = await GetUsersAsync()
    .Where(u => u.IsActive)
    .ToListAsync();
```

### ASP.NET Core Integration

#### Streaming JSON Response

```csharp
[HttpGet("products/stream")]
public IAsyncEnumerable<Product> StreamProducts(
    CancellationToken cancellationToken)
{
    return _productService.GetAllProductsAsync(cancellationToken);
}
```

ASP.NET Core automatically serializes each item as it's yielded.

#### NDJSON (Newline Delimited JSON) Streaming

```csharp
[HttpGet("products/ndjson")]
public async Task StreamProductsAsNdjson(CancellationToken cancellationToken)
{
    Response.ContentType = "application/x-ndjson";
    
    await foreach (var product in _productService.GetAllProductsAsync(cancellationToken))
    {
        var json = JsonSerializer.Serialize(product);
        await Response.WriteAsync(json + "\n", cancellationToken);
        await Response.Body.FlushAsync(cancellationToken);
    }
}
```

### Best Practices

#### 1. Always Support Cancellation

```csharp
// ✅ Good - supports cancellation
public async IAsyncEnumerable<T> GetItemsAsync(
    [EnumeratorCancellation] CancellationToken cancellationToken = default)
{
    foreach (var item in GetBatch())
    {
        cancellationToken.ThrowIfCancellationRequested();
        yield return item;
    }
}

// ❌ Bad - no cancellation support
public async IAsyncEnumerable<T> GetItemsAsync()
{
    foreach (var item in GetBatch())
    {
        yield return item;
    }
}
```

#### 2. Handle Exceptions Appropriately

```csharp
public async IAsyncEnumerable<Result<T>> SafeGetItemsAsync(
    [EnumeratorCancellation] CancellationToken cancellationToken = default)
{
    await foreach (var item in GetItemsAsync(cancellationToken))
    {
        Result<T> result;
        try
        {
            var processed = await ProcessAsync(item);
            result = Result<T>.Success(processed);
        }
        catch (Exception ex)
        {
            result = Result<T>.Failure(ex.Message);
        }
        
        yield return result;
    }
}
```

#### 3. Use ConfigureAwait in Libraries

```csharp
public async IAsyncEnumerable<T> GetItemsAsync()
{
    using var connection = await OpenConnectionAsync()
        .ConfigureAwait(false);
    
    await foreach (var item in ReadItemsAsync(connection)
        .ConfigureAwait(false))
    {
        yield return item;
    }
}
```

#### 4. Be Careful with DbContext

```csharp
// ❌ Bad - DbContext disposal issues
public async IAsyncEnumerable<User> GetUsersAsync()
{
    using var context = new AppDbContext();
    
    await foreach (var user in context.Users.AsAsyncEnumerable())
    {
        yield return user; // Context disposed before enumeration completes!
    }
}

// ✅ Good - DbContext lives for entire enumeration
public async IAsyncEnumerable<User> GetUsersAsync()
{
    using var context = new AppDbContext();
    
    // Materialize the query first
    var users = await context.Users.ToListAsync();
    
    foreach (var user in users)
    {
        yield return user;
    }
}

// ✅ Better - Let caller manage DbContext
public IAsyncEnumerable<User> GetUsersAsync(AppDbContext context)
{
    return context.Users.AsAsyncEnumerable();
}
```

### Performance Considerations

**Benefits:**
- ✅ Reduced memory usage (streaming vs loading all data)
- ✅ Faster time-to-first-result
- ✅ Better scalability for large datasets
- ✅ Natural backpressure (consumer controls flow)

**Tradeoffs:**
- ⚠️ More complex error handling
- ⚠️ Can't easily count items without enumerating
- ⚠️ Some LINQ operations require materialization
- ⚠️ Network/resource connections stay open longer
