## Introduction

Records are reference types introduced in C# 9 that provide built-in functionality for immutable data modeling with value-based equality. They dramatically reduce boilerplate code when working with data transfer objects (DTOs), domain models, and other data-centric types. Understanding records is essential for writing modern, idiomatic C#.

## Key Concepts Summary

### What Are Records?

Records are reference types designed for immutable data models with value-based equality. They can be declared using the `record` keyword:

```csharp
// Positional record (concise syntax)
public record Person(string FirstName, string LastName);

// Nominal record (traditional property syntax)
public record Person
{
    public string FirstName { get; init; }
    public string LastName { get; init; }
}
```

### Record vs Class: Key Differences

| Feature | Class | Record |
|---------|-------|--------|
| **Equality** | Reference equality (same instance) | Value equality (same values) |
| **Default Mutability** | Mutable | Immutable (with init-only properties) |
| **ToString()** | Type name | All property values formatted |
| **Deconstruction** | Manual implementation | Automatic with positional syntax |
| **With-expressions** | Not supported | Built-in support |
| **Primary Use** | Behavior + data | Data modeling |

### Value Equality Example

```csharp
// Records
var person1 = new Person("John", "Doe");
var person2 = new Person("John", "Doe");
Console.WriteLine(person1 == person2); // True - value equality

// Classes
var customer1 = new Customer { Name = "John" };
var customer2 = new Customer { Name = "John" };
Console.WriteLine(customer1 == customer2); // False - reference equality
```

### Immutability with Init-Only Setters

```csharp
public record Employee
{
    public int Id { get; init; }
    public string Name { get; init; }
    public DateTime HireDate { get; init; }
}

var employee = new Employee 
{ 
    Id = 1, 
    Name = "Jane", 
    HireDate = DateTime.Now 
};

// employee.Name = "John"; // ❌ Compilation error after initialization
```

### Non-Destructive Mutation with With-Expressions

```csharp
var original = new Person("John", "Doe");

// Create a copy with one property changed
var updated = original with { FirstName = "Jane" };

Console.WriteLine(original); // Person { FirstName = John, LastName = Doe }
Console.WriteLine(updated);  // Person { FirstName = Jane, LastName = Doe }
```

### Record Structs

C# 10 introduced record structs for value-type records:

```csharp
// Immutable record struct
public readonly record struct Point(int X, int Y);

// Mutable record struct (not recommended)
public record struct MutablePoint(int X, int Y);
```

**Best Practice:** Always use `readonly record struct` to maintain immutability benefits.

### Deconstruction

Positional records support automatic deconstruction:

```csharp
var person = new Person("John", "Doe");

// Deconstruct into individual variables
var (firstName, lastName) = person;
Console.WriteLine($"{firstName} {lastName}"); // John Doe
```

### Record Inheritance

Records support inheritance, but only from other records:

```csharp
public record Person(string FirstName, string LastName);
public record Employee(string FirstName, string LastName, string Department) 
    : Person(FirstName, LastName);

var emp = new Employee("John", "Doe", "Engineering");
Console.WriteLine(emp); 
// Employee { FirstName = John, LastName = Doe, Department = Engineering }
```

### When to Use Records

**✅ Use Records For:**
- Data Transfer Objects (DTOs)
- API request/response models (read-only)
- Immutable domain models
- Configuration objects
- Messages in event-driven architectures
- Simple data structures (2-5 properties with no complex behavior)

**❌ Avoid Records For:**
- Entity Framework Core entities (EF Core expects reference equality)
- Mutable state objects
- Types with significant behavior/methods
- Classes requiring complex inheritance hierarchies
- Types that need private setters (use classes instead)

### Common Patterns

#### 1. API Response Models
```csharp
public record UserResponse(
    int Id, 
    string Username, 
    string Email, 
    DateTime CreatedAt
);
```

#### 2. Domain Events
```csharp
public abstract record DomainEvent(DateTime OccurredAt);
public record OrderCreated(
    DateTime OccurredAt, 
    int OrderId, 
    decimal Total
) : DomainEvent(OccurredAt);
```

#### 3. Configuration
```csharp
public record DatabaseConfig
{
    public string ConnectionString { get; init; } = string.Empty;
    public int MaxRetries { get; init; } = 3;
    public TimeSpan Timeout { get; init; } = TimeSpan.FromSeconds(30);
}
```

### Advanced Features

#### Custom ToString()
```csharp
public record Person(string FirstName, string LastName)
{
    public override string ToString() => $"{FirstName} {LastName}";
}
```

#### Additional Members
```csharp
public record Person(string FirstName, string LastName)
{
    // Computed property
    public string FullName => $"{FirstName} {LastName}";
    
    // Method
    public bool IsNameValid() => 
        !string.IsNullOrWhiteSpace(FirstName) && 
        !string.IsNullOrWhiteSpace(LastName);
}
```
