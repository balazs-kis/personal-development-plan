## Learning Objectives

By the end of this lesson, you will be able to:
- Understand the different types of patterns available in C#
- Use pattern matching to simplify complex conditional logic
- Apply switch expressions effectively in your code
- Combine pattern matching with logical operators for complex scenarios

---

## Introduction

Pattern matching is one of the most powerful features added to modern C#. It allows you to test whether an expression meets specific conditions and extract information from that expression in a single operation. This leads to more readable, maintainable code while reducing boilerplate and repetitive checks.

## Key Concepts Summary

### Core Pattern Types

#### 1. Type Patterns
```csharp
// Check type and declare variable in one step
if (obj is string s)
{
    Console.WriteLine($"String length: {s.Length}");
}

// In switch expressions
string result = value switch
{
    int i => $"Integer: {i}",
    string s => $"String: {s}",
    bool b => $"Boolean: {b}",
    _ => "Unknown type"
};
```

#### 2. Constant Patterns
```csharp
// Match against specific values
string classification = number switch
{
    0 => "Zero",
    1 => "One",
    > 1 and < 10 => "Single digit",
    >= 10 and < 100 => "Double digit",
    _ => "Large number"
};
```

#### 3. Property Patterns
```csharp
// Match based on object properties
string status = order switch
{
    { Status: "Pending", Amount: > 100 } => "High-value pending order",
    { Status: "Pending" } => "Standard pending order",
    { Status: "Shipped", DeliveryDate: not null } => "Shipped with delivery date",
    { Status: "Shipped" } => "Shipped, awaiting delivery date",
    _ => "Unknown status"
};
```

#### 4. Relational Patterns
```csharp
// Use comparison operators
string grade = score switch
{
    >= 90 => "A",
    >= 80 => "B",
    >= 70 => "C",
    >= 60 => "D",
    _ => "F"
};
```

#### 5. Logical Patterns
```csharp
// Combine patterns with and, or, not
bool IsValidInput(object input) => input switch
{
    int i when i >= 0 and i <= 100 => true,
    string s when s is not null and s.Length > 0 => true,
    _ => false
};
```

### Switch Expressions vs Switch Statements

**Traditional Switch Statement:**
```csharp
string result;
switch (shape)
{
    case Circle c:
        result = $"Circle with radius {c.Radius}";
        break;
    case Rectangle r:
        result = $"Rectangle {r.Width}x{r.Height}";
        break;
    default:
        result = "Unknown shape";
        break;
}
```

**Modern Switch Expression:**
```csharp
string result = shape switch
{
    Circle c => $"Circle with radius {c.Radius}",
    Rectangle r => $"Rectangle {r.Width}x{r.Height}",
    _ => "Unknown shape"
};
```

### Best Practices

1. **Prefer Pattern Matching Over Traditional Casts**
   - ❌ `var s = obj as string; if (s != null) { ... }`
   - ✅ `if (obj is string s) { ... }`

2. **Use Switch Expressions for Readability**
   - Switch expressions are more concise and always return a value
   - They force exhaustiveness, reducing bugs

3. **Combine Patterns for Complex Logic**
   ```csharp
   bool IsValidUser(User user) => user switch
   {
       { IsActive: true, Role: "Admin" or "Moderator" } => true,
       { IsActive: true, SubscriptionLevel: > 1 } => true,
       _ => false
   };
   ```

4. **Be Exhaustive**
   - Always include a discard pattern (`_`) as a catch-all to avoid non-exhaustive switch expressions

### Common Pitfalls

1. **Non-Compile-Time Constants**: Pattern values must be known at compile time
   ```csharp
   // ❌ Won't compile
   int configValue = GetFromConfig();
   var result = input switch { configValue => "match", _ => "no match" };
   
   // ✅ Use when clause instead
   var result = input switch
   {
       var x when x == configValue => "match",
       _ => "no match"
   };
   ```

2. **Forgetting the Discard Pattern**: Can lead to runtime exceptions
   ```csharp
   // ❌ May throw at runtime if no pattern matches
   string result = value switch
   {
       int i => "integer",
       string s => "string"
   };
   
   // ✅ Always include catch-all
   string result = value switch
   {
       int i => "integer",
       string s => "string",
       _ => "unknown"
   };
   ```
