# Chapter 1.4: .NET Runtime Internals

## Overview
Gain a deeper understanding of how your code executes at the runtime level. This chapter covers JIT compilation, assembly loading contexts, Native AOT compilation, memory management, and interoperability with native code. Understanding these internals helps you write more performant applications and make informed architectural decisions.

## Key Concepts
- **JIT Compilation:** tiered compilation, Profile Guided Optimization (PGO), and how code gets optimized at runtime.
- **Assembly Loading:** isolating dependencies with AssemblyLoadContext and building plugin systems.
- **Native AOT:** ahead-of-time compilation for reduced startup time and smaller footprint.
- **Memory Internals:** how the managed heap works, generational garbage collection, and the Large Object Heap.
- **Interop:** calling native code using P/Invoke with modern source generation techniques.
