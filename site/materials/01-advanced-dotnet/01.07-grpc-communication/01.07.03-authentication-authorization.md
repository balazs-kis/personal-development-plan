## Introduction

Security is paramount in production gRPC services. Unlike REST APIs where authentication is well-established, gRPC requires understanding how to integrate ASP.NET Core's authentication middleware with gRPC's metadata-based communication. This lesson covers everything from basic JWT authentication to advanced authorization patterns, ensuring your gRPC services are secure and production-ready.

## Key Concepts Summary

### Authentication vs Authorization

```
Authentication: "Who are you?"
- Verifies identity (username/password, JWT token, certificate)
- Answers: Is this a valid user?

Authorization: "What can you do?"
- Verifies permissions (roles, policies, claims)
- Answers: Can this user access this resource?
```

**gRPC Security Flow:**
```
Client → Token in Metadata → Server
         ↓
      Authentication Middleware
         ↓
      Authorization Policies
         ↓
      gRPC Service Method
```

### Transport Security with TLS

**CRITICAL:** gRPC services in production MUST use TLS (HTTPS).

```csharp
❌ Insecure (Development Only):
http://localhost:5000

✅ Secure (Required for Production):
https://localhost:5001
```

**Why TLS is Required:**
1. Encrypts all communication (including authentication tokens)
2. Prevents man-in-the-middle attacks
3. Required by many HTTP/2 implementations
4. Protects sensitive data in transit

**Kestrel TLS Configuration:**

```csharp
// Program.cs
var builder = WebApplication.CreateBuilder(args);

builder.WebHost.ConfigureKestrel(options =>
{
    // HTTP/2 endpoint with TLS
    options.ListenLocalhost(5001, o => o.UseHttps());
});
```

### JWT Authentication in gRPC

JWT (JSON Web Token) is the most common authentication mechanism for gRPC services.

#### JWT Structure

```
Header.Payload.Signature

Example:
eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiIxMjM0NTY3ODkwIiwibmFtZSI6IkpvaG4gRG9lIiwiaWF0IjoxNTE2MjM5MDIyfQ.SflKxwRJSMeKKF2QT4fwpMeJf36POk6yJV_adQssw5c
```

**Header:**
```json
{
  "alg": "HS256",
  "typ": "JWT"
}
```

**Payload (Claims):**
```json
{
  "sub": "1234567890",
  "name": "John Doe",
  "email": "john@example.com",
  "role": "Admin",
  "exp": 1735689600
}
```

**Signature:**
```
HMACSHA256(
  base64UrlEncode(header) + "." +
  base64UrlEncode(payload),
  secret
)
```

### Server-Side Authentication Setup

#### 1. Install Required Packages

```bash
dotnet add package Microsoft.AspNetCore.Authentication.JwtBearer
```

#### 2. Configure JWT Authentication

```csharp
// Program.cs
using Microsoft.AspNetCore.Authentication.JwtBearer;
using Microsoft.IdentityModel.Tokens;
using System.Text;

var builder = WebApplication.CreateBuilder(args);

// Add gRPC
builder.Services.AddGrpc();

// Configure JWT Authentication
builder.Services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddJwtBearer(options =>
    {
        options.TokenValidationParameters = new TokenValidationParameters
        {
            ValidateIssuer = true,
            ValidateAudience = true,
            ValidateLifetime = true,
            ValidateIssuerSigningKey = true,
            ValidIssuer = builder.Configuration["Jwt:Issuer"],
            ValidAudience = builder.Configuration["Jwt:Audience"],
            IssuerSigningKey = new SymmetricSecurityKey(
                Encoding.UTF8.GetBytes(builder.Configuration["Jwt:Key"]!))
        };
    });

// Add Authorization
builder.Services.AddAuthorization();

var app = builder.Build();

// CRITICAL: Middleware order matters!
app.UseRouting();
app.UseAuthentication();  // Must be after UseRouting
app.UseAuthorization();   // Must be after UseAuthentication

app.MapGrpcService<GreeterService>();

app.Run();
```

#### 3. Configuration (appsettings.json)

```json
{
  "Jwt": {
    "Key": "YourSuperSecretKeyThatIsAtLeast32CharactersLong",
    "Issuer": "YourApp",
    "Audience": "YourAppUsers",
    "ExpiryMinutes": 60
  }
}
```

**Important Security Notes:**
```
❌ Never hardcode secrets in source code
❌ Never commit secrets to version control
✅ Use User Secrets for development
✅ Use Azure Key Vault or environment variables for production
```

### Securing gRPC Services

#### Apply [Authorize] to Services

```csharp
[Authorize]

{

        ProductRequest request, 
        ServerCallContext context)
    {
        // User is authenticated
        var userId = context.GetHttpContext().User.FindFirst("sub")?.Value;
        
        // ... implementation
    }
}
```

#### Apply [Authorize] to Specific Methods

```csharp
public class ProductService : Products.ProductsBase
{
    // No authentication required
    public override async Task<ProductListResponse> GetAllProducts(
        EmptyRequest request, 
        ServerCallContext context)
    {
        // Public endpoint
    }

    // Authentication required
    [Authorize]
    public override async Task<ProductResponse> CreateProduct(
        CreateProductRequest request, 
        ServerCallContext context)
    {
        // Only authenticated users can create
    }

    // Requires specific role
    [Authorize(Roles = "Admin")]
    public override async Task<DeleteResponse> DeleteProduct(
        ProductRequest request, 
        ServerCallContext context)
    {
        // Only admins can delete
    }
}
```

#### Apply Policy-Based Authorization

```csharp
// Program.cs - Define policies
builder.Services.AddAuthorization(options =>
{
    options.AddPolicy("AdminOnly", policy =>
        policy.RequireRole("Admin"));
    
    options.AddPolicy("RequireEmail", policy =>
        policy.RequireClaim("email"));
    
    options.AddPolicy("MinimumAge", policy =>
        policy.Requirements.Add(new MinimumAgeRequirement(18)));
});

// Service - Use policies
public class ProductService : Products.ProductsBase
{
    [Authorize(Policy = "AdminOnly")]
    public override async Task<ProductResponse> DeleteProduct(
        ProductRequest request, 
        ServerCallContext context)
    {
        // Only admins
    }
}
```

### Accessing User Information

```csharp
public override async Task<ProductResponse> GetProduct(
    ProductRequest request, 
    ServerCallContext context)
{
    // Get HTTP context
    var httpContext = context.GetHttpContext();
    
    // Get user
    var user = httpContext.User;
    
    // Check if authenticated
    if (user.Identity?.IsAuthenticated == true)
    {
        // Get claims
        var userId = user.FindFirst(ClaimTypes.NameIdentifier)?.Value;
        var userName = user.FindFirst(ClaimTypes.Name)?.Value;
        var email = user.FindFirst(ClaimTypes.Email)?.Value;
        var roles = user.FindAll(ClaimTypes.Role).Select(c => c.Value);
        
        // Get custom claims
        var customClaim = user.FindFirst("CustomClaimType")?.Value;
        
        Console.WriteLine($"User: {userName} ({userId})");
        Console.WriteLine($"Email: {email}");
        Console.WriteLine($"Roles: {string.Join(", ", roles)}");
    }
    
    // ... implementation
}
```

### Client-Side Authentication

#### Creating JWT Tokens (Login Service)

```csharp
using Microsoft.IdentityModel.Tokens;
using System.IdentityModel.Tokens.Jwt;
using System.Security.Claims;
using System.Text;

public class TokenService
{
    private readonly IConfiguration _configuration;

    public TokenService(IConfiguration configuration)
    {
        _configuration = configuration;
    }

    public string GenerateToken(string userId, string username, string email, string[] roles)
    {
        var claims = new List<Claim>
        {
            new Claim(ClaimTypes.NameIdentifier, userId),
            new Claim(ClaimTypes.Name, username),
            new Claim(ClaimTypes.Email, email),
            new Claim(JwtRegisteredClaimNames.Jti, Guid.NewGuid().ToString())
        };

        // Add roles
        foreach (var role in roles)
        {
            claims.Add(new Claim(ClaimTypes.Role, role));
        }

        var key = new SymmetricSecurityKey(
            Encoding.UTF8.GetBytes(_configuration["Jwt:Key"]!));
        var creds = new SigningCredentials(key, SecurityAlgorithms.HmacSha256);

        var token = new JwtSecurityToken(
            issuer: _configuration["Jwt:Issuer"],
            audience: _configuration["Jwt:Audience"],
            claims: claims,
            expires: DateTime.UtcNow.AddMinutes(
                double.Parse(_configuration["Jwt:ExpiryMinutes"]!)),
            signingCredentials: creds
        );

        return new JwtSecurityTokenHandler().WriteToken(token);
    }
}
```

#### Client: Sending Authentication Token

```csharp
using Grpc.Core;
using Grpc.Net.Client;

class Program
{
    static async Task Main(string[] args)
    {
        // Your JWT token (from login)
        var token = "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...";

        using var channel = GrpcChannel.ForAddress("https://localhost:5001");
        var client = new ProductService.ProductServiceClient(channel);

        // Create metadata with authorization header
        var headers = new Metadata
        {
            { "Authorization", $"Bearer {token}" }
        };

        try
        {
            // Call with authentication
            var response = await client.GetProductAsync(
                new ProductRequest { Id = 1 },
                headers: headers
            );

            Console.WriteLine($"Product: {response.Name}");
        }
        catch (RpcException ex) when (ex.StatusCode == StatusCode.Unauthenticated)
        {
            Console.WriteLine("Authentication failed - invalid or expired token");
        }
        catch (RpcException ex) when (ex.StatusCode == StatusCode.PermissionDenied)
        {
            Console.WriteLine("Authorization failed - insufficient permissions");
        }
    }
}
```

#### Client: Automatic Token Injection with CallCredentials

```csharp
using Grpc.Core;
using Grpc.Net.Client;

var token = GetJwtToken(); // Your token retrieval logic

// Create credentials that automatically add the token
var credentials = CallCredentials.FromInterceptor((context, metadata) =>
{
    if (!string.IsNullOrEmpty(token))
    {
        metadata.Add("Authorization", $"Bearer {token}");
    }
    return Task.CompletedTask;
});

// Configure channel with credentials
var channel = GrpcChannel.ForAddress("https://localhost:5001", new GrpcChannelOptions
{
    Credentials = ChannelCredentials.Create(
        new SslCredentials(), 
        credentials)
});

var client = new ProductService.ProductServiceClient(channel);

// All calls automatically include token
var response = await client.GetProductAsync(new ProductRequest { Id = 1 });
```

#### Client: Using gRPC Client Factory with Authentication

```csharp
// Startup configuration
builder.Services.AddGrpcClient<ProductService.ProductServiceClient>(options =>
{
    options.Address = new Uri("https://localhost:5001");
})
.AddCallCredentials((context, metadata) =>
{
    var token = context.GetHttpContext()?.Request.Headers["Authorization"].ToString();
    if (!string.IsNullOrEmpty(token))
    {
        metadata.Add("Authorization", token);
    }
    return Task.CompletedTask;
});

// Inject and use
public class ProductManager
{
    private readonly ProductService.ProductServiceClient _client;

    public ProductManager(ProductService.ProductServiceClient client)
    {
        _client = client;
    }

    public async Task<ProductResponse> GetProductAsync(int id)
    {
        // Automatically includes authentication
        return await _client.GetProductAsync(new ProductRequest { Id = id });
    }
}
```

### Handling Authentication Errors

#### Server-Side Error Handling

```csharp
[Authorize]
public class ProductService : Products.ProductsBase
{
    public override async Task<ProductResponse> GetProduct(
        ProductRequest request, 
        ServerCallContext context)
    {
        var httpContext = context.GetHttpContext();
        
        // Check authentication
        if (!httpContext.User.Identity?.IsAuthenticated ?? true)
        {
            throw new RpcException(
                new Status(StatusCode.Unauthenticated, "Authentication required"));
        }
        
        // Check authorization (role)
        if (!httpContext.User.IsInRole("User"))
        {
            throw new RpcException(
                new Status(StatusCode.PermissionDenied, "Insufficient permissions"));
        }
        
        // Check specific claim
        var userId = httpContext.User.FindFirst(ClaimTypes.NameIdentifier)?.Value;
        if (string.IsNullOrEmpty(userId))
        {
            throw new RpcException(
                new Status(StatusCode.Unauthenticated, "Invalid user token"));
        }
        
        // Implementation...
    }
}
```

#### Client-Side Error Handling

```csharp
try
{
    var response = await client.GetProductAsync(
        new ProductRequest { Id = 1 },
        headers: headers
    );
}
catch (RpcException ex) when (ex.StatusCode == StatusCode.Unauthenticated)
{
    Console.WriteLine("Authentication failed:");
    Console.WriteLine($"- Status: {ex.Status.Detail}");
    Console.WriteLine("- Token may be invalid, expired, or missing");
    Console.WriteLine("- Please log in again");
}
catch (RpcException ex) when (ex.StatusCode == StatusCode.PermissionDenied)
{
    Console.WriteLine("Authorization failed:");
    Console.WriteLine($"- Status: {ex.Status.Detail}");
    Console.WriteLine("- You don't have permission for this operation");
    Console.WriteLine("- Contact administrator for access");
}
catch (RpcException ex) when (ex.StatusCode == StatusCode.Unavailable)
{
    Console.WriteLine("Service unavailable - check network connection");
}
```

### Advanced: Certificate-Based Authentication (mTLS)

For service-to-service communication, mutual TLS (mTLS) provides strong authentication.

```csharp
// Server configuration
builder.WebHost.ConfigureKestrel(options =>
{
    options.ListenLocalhost(5001, listenOptions =>
    {
        listenOptions.UseHttps(httpsOptions =>
        {
            // Require client certificate
            httpsOptions.ClientCertificateMode = ClientCertificateMode.RequireCertificate;
            httpsOptions.ClientCertificateValidation = (cert, chain, errors) =>
            {
                // Custom validation logic
                return cert?.Thumbprint == "expected-thumbprint";
            };
        });
    });
});

// Client configuration
var handler = new HttpClientHandler();
handler.ClientCertificates.Add(GetClientCertificate());

var channel = GrpcChannel.ForAddress("https://localhost:5001", 
    new GrpcChannelOptions
    {
        HttpHandler = handler
    });
```

### Best Practices

#### 1. Always Use HTTPS in Production

```csharp
✅ Production:
https://api.example.com

❌ Development only:
http://localhost:5000
```

#### 2. Validate Tokens Properly

```csharp
✅ Good: Validate issuer, audience, lifetime, signature
options.TokenValidationParameters = new TokenValidationParameters
{
    ValidateIssuer = true,
    ValidateAudience = true,
    ValidateLifetime = true,
    ValidateIssuerSigningKey = true,
    // ...
};

❌ Bad: Skip validation
options.TokenValidationParameters = new TokenValidationParameters
{
    ValidateIssuer = false,
    ValidateAudience = false,
    // Insecure!
};
```

#### 3. Use Appropriate Token Expiration

```csharp
✅ Good: Short-lived tokens with refresh mechanism
expires: DateTime.UtcNow.AddMinutes(15)  // 15 min access token
// + refresh token (24 hours)

❌ Bad: Long-lived tokens
expires: DateTime.UtcNow.AddDays(365)  // Too long!
```

#### 4. Store Secrets Securely

```csharp
❌ Bad: Hardcoded secrets
var key = "MySecretKey123";

✅ Good: Configuration + secure storage
var key = configuration["Jwt:Key"];  // From User Secrets/Key Vault
```

#### 5. Implement Token Refresh

```csharp
// Client: Detect expiration and refresh
public async Task<ProductResponse> GetProductWithRetryAsync(int id)
{
    try
    {
        return await _client.GetProductAsync(new ProductRequest { Id = id });
    }
    catch (RpcException ex) when (ex.StatusCode == StatusCode.Unauthenticated)
    {
        // Token expired, refresh it
        await RefreshTokenAsync();
        
        // Retry with new token
        return await _client.GetProductAsync(new ProductRequest { Id = id });
    }
}
```
