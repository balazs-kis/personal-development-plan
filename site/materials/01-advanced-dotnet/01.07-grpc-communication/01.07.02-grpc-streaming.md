## Introduction

gRPC streaming is one of its most powerful features, enabling real-time, bidirectional communication between clients and servers. Unlike traditional request-response patterns, streaming allows continuous data flow, making it perfect for scenarios like live dashboards, chat applications, file uploads, real-time notifications, and IoT data ingestion. Understanding when and how to use each streaming pattern is essential for building high-performance, responsive distributed systems.

## Key Concepts Summary

### Four gRPC Communication Patterns

```
1. Unary (Request-Response)
   Client → Request → Server
   Client ← Response ← Server

2. Server Streaming
   Client → Request → Server
   Client ← Stream ← Server
   Client ← Stream ← Server
   Client ← Stream ← Server

3. Client Streaming
   Client → Stream → Server
   Client → Stream → Server
   Client → Stream → Server
   Client ← Response ← Server

4. Bidirectional Streaming
   Client ⇄ Stream ⇄ Server
   Client ⇄ Stream ⇄ Server
   Client ⇄ Stream ⇄ Server
```

### When to Use Each Pattern

| Pattern | Use Cases | Examples |
|---------|-----------|----------|
| **Unary** | Simple request-response | Get user, Create order, Update product |
| **Server Streaming** | Push data to client | Live dashboard, Stock prices, News feed, Progress updates |
| **Client Streaming** | Upload from client | File upload, Bulk data import, Metrics collection |
| **Bidirectional** | Real-time two-way communication | Chat, Live collaboration, Gaming, IoT sensors |

## Server Streaming

Server streaming allows the server to send multiple messages in response to a single client request.

### Proto Definition

```protobuf
syntax = "proto3";

service StockService {
  // Server streaming: one request, stream of responses
  rpc GetStockPrices (StockRequest) returns (stream StockPrice);
}

message StockRequest {
  string symbol = 1;
}

message StockPrice {
  string symbol = 1;
  double price = 2;
  google.protobuf.Timestamp timestamp = 3;
}
```

**Key Points:**
- `returns (stream StockPrice)` - Indicates server streaming
- Client sends one request
- Server sends multiple responses over time

### Server Implementation

```csharp
using Grpc.Core;

public class StockService : StockService.StockServiceBase
{
    private readonly ILogger<StockService> _logger;

    public StockService(ILogger<StockService> logger)
    {
        _logger = logger;
    }

    public override async Task GetStockPrices(
        StockRequest request,
        IServerStreamWriter<StockPrice> responseStream,
        ServerCallContext context)
    {
        _logger.LogInformation($"Streaming stock prices for {request.Symbol}");

        // Stream stock prices every second for 10 seconds
        for (int i = 0; i < 10; i++)
        {
            // Check if client cancelled
            if (context.CancellationToken.IsCancellationRequested)
            {
                _logger.LogInformation("Client cancelled the stream");
                break;
            }

            // Generate mock price
            var price = new StockPrice
            {
                Symbol = request.Symbol,
                Price = GetRandomPrice(),
                Timestamp = Timestamp.FromDateTime(DateTime.UtcNow)
            };

            // Write to stream
            await responseStream.WriteAsync(price);

            _logger.LogInformation($"Sent price: ${price.Price}");

            // Wait before next update
            await Task.Delay(1000, context.CancellationToken);
        }

        _logger.LogInformation("Stream completed");
    }

    private double GetRandomPrice()
    {
        return 100 + Random.Shared.NextDouble() * 50;
    }
}
```

**Key Components:**
- `IServerStreamWriter<T>` - Interface for writing to the stream
- `context.CancellationToken` - Check if client cancelled
- `responseStream.WriteAsync()` - Send each message
- Method returns when streaming is complete

### Client Implementation

```csharp
using var channel = GrpcChannel.ForAddress("https://localhost:7042");
var client = new StockService.StockServiceClient(channel);

// Create cancellation token for timeout or user cancellation
var cts = new CancellationTokenSource(TimeSpan.FromSeconds(15));

try
{
    // Start the streaming call
    var call = client.GetStockPrices(
        new StockRequest { Symbol = "AAPL" },
        cancellationToken: cts.Token);

    // Read responses as they arrive
    await foreach (var price in call.ResponseStream.ReadAllAsync())
    {
        Console.WriteLine($"{price.Symbol}: ${price.Price:F2} at {price.Timestamp}");
    }

    Console.WriteLine("Stream completed");
}
catch (RpcException ex) when (ex.StatusCode == StatusCode.Cancelled)
{
    Console.WriteLine("Stream cancelled");
}
catch (OperationCanceledException)
{
    Console.WriteLine("Operation timed out");
}
```

**Key Components:**
- `call.ResponseStream` - Access to the response stream
- `ReadAllAsync()` - Async enumerable for reading messages
- `await foreach` - Modern C# syntax for async streams
- Cancellation token for client-side timeout

### Alternative Client Pattern

```csharp
// Manual reading with MoveNext
var call = client.GetStockPrices(new StockRequest { Symbol = "AAPL" });

while (await call.ResponseStream.MoveNext(CancellationToken.None))
{
    var price = call.ResponseStream.Current;
    Console.WriteLine($"${price.Price:F2}");
}
```

## Client Streaming

Client streaming allows the client to send multiple messages to the server, which responds once.

### Proto Definition

```protobuf
service FileUploadService {
  // Client streaming: stream of requests, one response
  rpc UploadFile (stream FileChunk) returns (FileUploadResponse);
}

message FileChunk {
  string file_name = 1;
  int32 chunk_number = 2;
  bytes data = 3;
}

message FileUploadResponse {
  string file_id = 1;
  int64 total_size = 2;
  bool success = 3;
}
```

**Key Points:**
- `(stream FileChunk)` - Indicates client streaming
- Client sends multiple requests
- Server sends one response when done

### Server Implementation

```csharp
public class FileUploadService : FileUploadService.FileUploadServiceBase
{
    private readonly ILogger<FileUploadService> _logger;

    public FileUploadService(ILogger<FileUploadService> logger)
    {
        _logger = logger;
    }

    public override async Task<FileUploadResponse> UploadFile(
        IAsyncStreamReader<FileChunk> requestStream,
        ServerCallContext context)
    {
        _logger.LogInformation("Starting file upload");

        string? fileName = null;
        long totalSize = 0;
        var chunks = new List<byte[]>();

        // Read all chunks from client
        await foreach (var chunk in requestStream.ReadAllAsync())
        {
            if (fileName == null)
            {
                fileName = chunk.FileName;
                _logger.LogInformation($"Receiving file: {fileName}");
            }

            chunks.Add(chunk.Data.ToByteArray());
            totalSize += chunk.Data.Length;

            _logger.LogInformation($"Received chunk {chunk.ChunkNumber}, size: {chunk.Data.Length} bytes");
        }

        // Combine chunks and save file
        var fileData = chunks.SelectMany(x => x).ToArray();
        var fileId = Guid.NewGuid().ToString();
        
        // Save to storage (simplified)
        await File.WriteAllBytesAsync($"uploads/{fileId}", fileData);

        _logger.LogInformation($"File upload complete: {totalSize} bytes");

        // Return single response
        return new FileUploadResponse
        {
            FileId = fileId,
            TotalSize = totalSize,
            Success = true
        };
    }
}
```

**Key Components:**
- `IAsyncStreamReader<T>` - Interface for reading from the stream
- `await foreach` - Read all incoming messages
- Return single response when done

### Client Implementation

```csharp
using var channel = GrpcChannel.ForAddress("https://localhost:7042");
var client = new FileUploadService.FileUploadServiceClient(channel);

// Start the streaming call
using var call = client.UploadFile();

// Read file in chunks
var filePath = "large-file.dat";
var fileName = Path.GetFileName(filePath);
const int chunkSize = 64 * 1024; // 64 KB chunks

using var fileStream = File.OpenRead(filePath);
var buffer = new byte[chunkSize];
int chunkNumber = 0;
int bytesRead;

while ((bytesRead = await fileStream.ReadAsync(buffer)) > 0)
{
    chunkNumber++;
    
    var chunk = new FileChunk
    {
        FileName = fileName,
        ChunkNumber = chunkNumber,
        Data = ByteString.CopyFrom(buffer, 0, bytesRead)
    };

    // Send chunk to server
    await call.RequestStream.WriteAsync(chunk);
    
    Console.WriteLine($"Sent chunk {chunkNumber} ({bytesRead} bytes)");
}

// Complete the client stream
await call.RequestStream.CompleteAsync();

// Get the single response
var response = await call.ResponseAsync;

Console.WriteLine($"Upload complete!");
Console.WriteLine($"File ID: {response.FileId}");
Console.WriteLine($"Total size: {response.TotalSize} bytes");
```

**Key Components:**
- `call.RequestStream` - Stream for sending requests
- `WriteAsync()` - Send each chunk
- `CompleteAsync()` - Signal end of stream
- `call.ResponseAsync` - Get the single response

## Bidirectional Streaming

Bidirectional streaming allows both client and server to send messages independently.

### Proto Definition

```protobuf
service ChatService {
  // Bidirectional streaming
  rpc Chat (stream ChatMessage) returns (stream ChatMessage);
}

message ChatMessage {
  string user_id = 1;
  string message = 2;
  google.protobuf.Timestamp timestamp = 3;
}
```

**Key Points:**
- `(stream ChatMessage) returns (stream ChatMessage)` - Bidirectional
- Client and server both send multiple messages
- Streams are independent (don't block each other)

### Server Implementation

```csharp
public class ChatService : ChatService.ChatServiceBase
{
    private readonly ILogger<ChatService> _logger;

    public ChatService(ILogger<ChatService> logger)
    {
        _logger = logger;
    }

    public override async Task Chat(
        IAsyncStreamReader<ChatMessage> requestStream,
        IServerStreamWriter<ChatMessage> responseStream,
        ServerCallContext context)
    {
        _logger.LogInformation("Chat session started");

        try
        {
            // Read messages from client
            await foreach (var message in requestStream.ReadAllAsync())
            {
                _logger.LogInformation($"Received from {message.UserId}: {message.Message}");

                // Echo back with timestamp
                var response = new ChatMessage
                {
                    UserId = "Server",
                    Message = $"Echo: {message.Message}",
                    Timestamp = Timestamp.FromDateTime(DateTime.UtcNow)
                };

                // Send response
                await responseStream.WriteAsync(response);

                // Simulate processing
                await Task.Delay(100);

                // Send another message
                if (message.Message.Contains("?"))
                {
                    var answer = new ChatMessage
                    {
                        UserId = "Server",
                        Message = "That's a good question!",
                        Timestamp = Timestamp.FromDateTime(DateTime.UtcNow)
                    };

                    await responseStream.WriteAsync(answer);
                }
            }
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Error in chat session");
        }

        _logger.LogInformation("Chat session ended");
    }
}
```

**Key Components:**
- Both `IAsyncStreamReader<T>` and `IServerStreamWriter<T>`
- Read and write independently
- Streams don't block each other

### Client Implementation (Background Reading)

```csharp
using var channel = GrpcChannel.ForAddress("https://localhost:7042");
var client = new ChatService.ChatServiceClient(channel);

var cts = new CancellationTokenSource();

// Start the bidirectional call
using var call = client.Chat(cancellationToken: cts.Token);

// Background task to read responses
var readTask = Task.Run(async () =>
{
    try
    {
        await foreach (var response in call.ResponseStream.ReadAllAsync())
        {
            Console.WriteLine($"[{response.UserId}]: {response.Message}");
        }
    }
    catch (RpcException ex) when (ex.StatusCode == StatusCode.Cancelled)
    {
        Console.WriteLine("Call cancelled");
    }
});

// Send messages from user input
Console.WriteLine("Enter messages (type 'exit' to quit):");

while (true)
{
    var input = Console.ReadLine();
    
    if (input?.ToLower() == "exit")
        break;

    var message = new ChatMessage
    {
        UserId = "User",
        Message = input,
        Timestamp = Timestamp.FromDateTime(DateTime.UtcNow)
    };

    await call.RequestStream.WriteAsync(message);
}

// Complete the client stream
await call.RequestStream.CompleteAsync();

// Cancel reading task
cts.Cancel();

try
{
    await readTask;
}
catch (OperationCanceledException) { }

Console.WriteLine("Chat ended");
```

**Key Components:**
- Background task for reading responses
- Main thread for sending messages
- Independent read/write operations
- Proper cleanup and cancellation

### Alternative: Ping-Pong Pattern

```csharp
// Client sends, waits for response, sends again
using var call = client.Chat();

for (int i = 0; i < 5; i++)
{
    // Send message
    await call.RequestStream.WriteAsync(new ChatMessage
    {
        UserId = "User",
        Message = $"Message {i}",
        Timestamp = Timestamp.FromDateTime(DateTime.UtcNow)
    });

    // Wait for response
    if (await call.ResponseStream.MoveNext())
    {
        var response = call.ResponseStream.Current;
        Console.WriteLine($"Response: {response.Message}");
    }
}

await call.RequestStream.CompleteAsync();
```

## Advanced Streaming Patterns

### Handling Backpressure

```csharp
// Server: Slow down if client can't keep up
public override async Task GetStockPrices(
    StockRequest request,
    IServerStreamWriter<StockPrice> responseStream,
    ServerCallContext context)
{
    var queue = new Channel<StockPrice>(100); // Buffer size

    // Producer
    var producer = Task.Run(async () =>
    {
        while (!context.CancellationToken.IsCancellationRequested)
        {
            var price = GeneratePrice();
            await queue.Writer.WriteAsync(price, context.CancellationToken);
            await Task.Delay(100);
        }
        queue.Writer.Complete();
    });

    // Consumer (respects client's reading speed)
    await foreach (var price in queue.Reader.ReadAllAsync())
    {
        await responseStream.WriteAsync(price);
    }

    await producer;
}
```

### Streaming with Cancellation

```csharp
// Client: Cancel after timeout or condition
var cts = new CancellationTokenSource();

var call = client.GetStockPrices(
    new StockRequest { Symbol = "AAPL" },
    cancellationToken: cts.Token);

var priceCount = 0;
await foreach (var price in call.ResponseStream.ReadAllAsync())
{
    Console.WriteLine($"Price: ${price.Price}");
    
    priceCount++;
    
    // Cancel after 5 prices
    if (priceCount >= 5)
    {
        cts.Cancel();
        break;
    }
}
```

### Error Handling in Streams

```csharp
// Server: Handle errors gracefully
public override async Task Chat(
    IAsyncStreamReader<ChatMessage> requestStream,
    IServerStreamWriter<ChatMessage> responseStream,
    ServerCallContext context)
{
    try
    {
        await foreach (var message in requestStream.ReadAllAsync())
        {
            // Validate message
            if (string.IsNullOrEmpty(message.Message))
            {
                throw new RpcException(
                    new Status(StatusCode.InvalidArgument, "Message cannot be empty"));
            }

            // Process message
            await responseStream.WriteAsync(ProcessMessage(message));
        }
    }
    catch (RpcException)
    {
        // Re-throw gRPC exceptions
        throw;
    }
    catch (Exception ex)
    {
        _logger.LogError(ex, "Unexpected error in chat");
        throw new RpcException(
            new Status(StatusCode.Internal, "An error occurred processing the chat"));
    }
}

// Client: Handle stream errors
try
{
    await foreach (var message in call.ResponseStream.ReadAllAsync())
    {
        Console.WriteLine(message.Message);
    }
}
catch (RpcException ex)
{
    Console.WriteLine($"Stream error: {ex.Status.Detail}");
    Console.WriteLine($"Status: {ex.StatusCode}");
}
```

## Best Practices

### 1. Use Appropriate Buffer Sizes

```csharp
✅ Good: Reasonable buffer for backpressure
var channel = new Channel<Message>(capacity: 100);

❌ Bad: Unbounded buffer (memory risk)
var channel = new Channel<Message>(int.MaxValue);
```

### 2. Always Check Cancellation

```csharp
✅ Good: Respect cancellation
while (!context.CancellationToken.IsCancellationRequested)
{
    await responseStream.WriteAsync(GetNextItem());
    await Task.Delay(1000, context.CancellationToken);
}

❌ Bad: Ignore cancellation
while (true)
{
    await responseStream.WriteAsync(GetNextItem());
    await Task.Delay(1000);
}
```

### 3. Complete Client Streams

```csharp
✅ Good: Always complete
await call.RequestStream.WriteAsync(message1);
await call.RequestStream.WriteAsync(message2);
await call.RequestStream.CompleteAsync();  // Signal end

❌ Bad: Forget to complete (server waits forever)
await call.RequestStream.WriteAsync(message1);
await call.RequestStream.WriteAsync(message2);
// Oops, forgot CompleteAsync()
```

### 4. Handle Exceptions Properly

```csharp
✅ Good: Comprehensive error handling
try
{
    await foreach (var item in stream.ReadAllAsync())
    {
        ProcessItem(item);
    }
}
catch (RpcException ex) when (ex.StatusCode == StatusCode.Cancelled)
{
    // Handle cancellation
}
catch (RpcException ex)
{
    // Handle other gRPC errors
}
catch (Exception ex)
{
    // Handle unexpected errors
}
```
