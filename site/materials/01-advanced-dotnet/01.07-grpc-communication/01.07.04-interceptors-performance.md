## Introduction

gRPC interceptors are a powerful mechanism for implementing cross-cutting concerns like logging, monitoring, authentication, and validation without cluttering your business logic. Combined with performance optimizations like connection reuse, compression, and proper deadline management, interceptors enable you to build production-grade gRPC services that are both maintainable and performant. This lesson covers the complete interceptor lifecycle and performance best practices.

## Key Concepts Summary

### What are gRPC Interceptors?

Interceptors are middleware components that execute automatically for each gRPC call, allowing you to inject behavior before and after the actual RPC method execution.

```
Request Flow with Interceptors:

Client Side:
Client Code → Interceptor 1 → Interceptor 2 → Network → Server

Server Side:
Network → Interceptor 1 → Interceptor 2 → Service Method
```

**Analogy:**
```
HTTP Middleware:    Request → Middleware1 → Middleware2 → Controller
gRPC Interceptors:  Request → Interceptor1 → Interceptor2 → Service Method
```

### When to Use Interceptors

**✅ Good Use Cases:**
- **Logging**: Request/response logging, performance metrics
- **Authentication**: Add/validate authentication tokens
- **Validation**: Validate requests before reaching service
- **Error Handling**: Catch and transform exceptions
- **Monitoring**: Track timing, success rates, errors
- **Retry Logic**: Implement automatic retries (client-side)
- **Caching**: Cache responses for idempotent calls
- **Correlation IDs**: Track requests across services

**❌ Not Suitable For:**
- Business logic (belongs in service methods)
- Complex branching logic
- TCP/connection management
- Port configuration

### Interceptor Types

**Server Interceptors:**
- Execute on the server for incoming requests
- Can intercept before and after service method execution
- Used for authentication, logging, validation

**Client Interceptors:**
- Execute on the client for outgoing requests
- Can intercept before and after RPC calls
- Used for adding headers, retry logic, monitoring

## Server Interceptors

### Creating a Server Interceptor

```csharp
using Grpc.Core;
using Grpc.Core.Interceptors;

public class LoggingInterceptor : Interceptor
{
    private readonly ILogger<LoggingInterceptor> _logger;

    public LoggingInterceptor(ILogger<LoggingInterceptor> logger)
    {
        _logger = logger;
    }

    // Intercept unary calls (single request, single response)
    public override async Task<TResponse> UnaryServerHandler<TRequest, TResponse>(
        TRequest request,
        ServerCallContext context,
        UnaryServerMethod<TRequest, TResponse> continuation)
    {
        // Before the call
        var method = context.Method;
        _logger.LogInformation("Starting call: {Method}", method);
        
        var stopwatch = System.Diagnostics.Stopwatch.StartNew();

        try
        {
            // Call the actual service method
            var response = await continuation(request, context);
            
            // After successful call
            stopwatch.Stop();
            _logger.LogInformation(
                "Completed call: {Method} in {ElapsedMs}ms", 
                method, 
                stopwatch.ElapsedMilliseconds);
            
            return response;
        }
        catch (Exception ex)
        {
            // After failed call
            stopwatch.Stop();
            _logger.LogError(
                ex, 
                "Failed call: {Method} in {ElapsedMs}ms", 
                method, 
                stopwatch.ElapsedMilliseconds);
            
            throw;
        }
    }
}
```

### Registering Server Interceptors

```csharp
// Program.cs
var builder = WebApplication.CreateBuilder(args);

// Register interceptor
builder.Services.AddSingleton<LoggingInterceptor>();

// Add gRPC with interceptor
builder.Services.AddGrpc(options =>
{
    options.Interceptors.Add<LoggingInterceptor>();
});

var app = builder.Build();

app.MapGrpcService<GreeterService>();
app.Run();
```

### Practical Server Interceptors

#### 1. Exception Handling Interceptor

```csharp
public class ExceptionInterceptor : Interceptor
{
    private readonly ILogger<ExceptionInterceptor> _logger;

    public ExceptionInterceptor(ILogger<ExceptionInterceptor> logger)
    {
        _logger = logger;
    }

    public override async Task<TResponse> UnaryServerHandler<TRequest, TResponse>(
        TRequest request,
        ServerCallContext context,
        UnaryServerMethod<TRequest, TResponse> continuation)
    {
        try
        {
            return await continuation(request, context);
        }
        catch (RpcException)
        {
            // Already a gRPC exception, re-throw
            throw;
        }
        catch (ArgumentException ex)
        {
            _logger.LogWarning(ex, "Invalid argument");
            throw new RpcException(
                new Status(StatusCode.InvalidArgument, ex.Message));
        }
        catch (UnauthorizedAccessException ex)
        {
            _logger.LogWarning(ex, "Unauthorized access");
            throw new RpcException(
                new Status(StatusCode.PermissionDenied, "Access denied"));
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Unhandled exception");
            throw new RpcException(
                new Status(StatusCode.Internal, "An error occurred"));
        }
    }
}
```

#### 2. Validation Interceptor

```csharp
public class ValidationInterceptor : Interceptor
{
    public override async Task<TResponse> UnaryServerHandler<TRequest, TResponse>(
        TRequest request,
        ServerCallContext context,
        UnaryServerMethod<TRequest, TResponse> continuation)
    {
        // Validate request
        if (request is IValidatable validatable)
        {
            var errors = validatable.Validate();
            if (errors.Any())
            {
                throw new RpcException(
                    new Status(
                        StatusCode.InvalidArgument, 
                        $"Validation failed: {string.Join(", ", errors)}"));
            }
        }

        return await continuation(request, context);
    }
}

// Request interface
public interface IValidatable
{
    IEnumerable<string> Validate();
}

// Example usage
public partial class CreateProductRequest : IValidatable
{
    public IEnumerable<string> Validate()
    {
        if (string.IsNullOrWhiteSpace(Name))
            yield return "Name is required";
        
        if (Price <= 0)
            yield return "Price must be positive";
    }
}
```

#### 3. Correlation ID Interceptor

```csharp
public class CorrelationIdInterceptor : Interceptor
{
    private readonly ILogger<CorrelationIdInterceptor> _logger;

    public CorrelationIdInterceptor(ILogger<CorrelationIdInterceptor> logger)
    {
        _logger = logger;
    }

    public override async Task<TResponse> UnaryServerHandler<TRequest, TResponse>(
        TRequest request,
        ServerCallContext context,
        UnaryServerMethod<TRequest, TResponse> continuation)
    {
        // Get or create correlation ID
        var correlationId = context.RequestHeaders
            .FirstOrDefault(h => h.Key == "x-correlation-id")?.Value
            ?? Guid.NewGuid().ToString();

        // Add to response headers
        context.ResponseTrailers.Add("x-correlation-id", correlationId);

        // Add to logging scope
        using (_logger.BeginScope(new Dictionary<string, object>
        {
            ["CorrelationId"] = correlationId
        }))
        {
            _logger.LogInformation("Processing request");
            return await continuation(request, context);
        }
    }
}
```

## Client Interceptors

### Creating a Client Interceptor

```csharp
using Grpc.Core;
using Grpc.Core.Interceptors;

public class ClientLoggingInterceptor : Interceptor
{
    private readonly ILogger<ClientLoggingInterceptor> _logger;

    public ClientLoggingInterceptor(ILogger<ClientLoggingInterceptor> logger)
    {
        _logger = logger;
    }

    // Intercept async unary calls
    public override AsyncUnaryCall<TResponse> AsyncUnaryCall<TRequest, TResponse>(
        TRequest request,
        ClientInterceptorContext<TRequest, TResponse> context,
        AsyncUnaryCallContinuation<TRequest, TResponse> continuation)
    {
        _logger.LogInformation("Calling {Method}", context.Method.FullName);

        var call = continuation(request, context);

        return new AsyncUnaryCall<TResponse>(
            HandleResponse(call.ResponseAsync),
            call.ResponseHeadersAsync,
            call.GetStatus,
            call.GetTrailers,
            call.Dispose);
    }

    private async Task<TResponse> HandleResponse<TResponse>(Task<TResponse> responseTask)
    {
        try
        {
            var response = await responseTask;
            _logger.LogInformation("Call succeeded");
            return response;
        }
        catch (RpcException ex)
        {
            _logger.LogError(ex, "Call failed with status {StatusCode}", ex.StatusCode);
            throw;
        }
    }
}
```

### Using Client Interceptors

```csharp
// Create channel
var channel = GrpcChannel.ForAddress("https://localhost:5001");

// Create interceptor
var logger = loggerFactory.CreateLogger<ClientLoggingInterceptor>();
var interceptor = new ClientLoggingInterceptor(logger);

// Create client with interceptor
var callInvoker = channel.Intercept(interceptor);
var client = new Greeter.GreeterClient(callInvoker);

// All calls go through interceptor
var response = await client.SayHelloAsync(new HelloRequest { Name = "World" });
```

### Multiple Interceptors

```csharp
// Interceptors execute in order
var callInvoker = channel
    .Intercept(new AuthenticationInterceptor())
    .Intercept(new LoggingInterceptor())
    .Intercept(new RetryInterceptor());

var client = new Greeter.GreeterClient(callInvoker);
```

**Execution Order:**
```
Request:  Auth → Logging → Retry → Network
Response: Network → Retry → Logging → Auth
```

### Practical Client Interceptors

#### 1. Authentication Interceptor

```csharp
public class AuthenticationInterceptor : Interceptor
{
    private readonly ITokenProvider _tokenProvider;

    public AuthenticationInterceptor(ITokenProvider tokenProvider)
    {
        _tokenProvider = tokenProvider;
    }

    public override AsyncUnaryCall<TResponse> AsyncUnaryCall<TRequest, TResponse>(
        TRequest request,
        ClientInterceptorContext<TRequest, TResponse> context,
        AsyncUnaryCallContinuation<TRequest, TResponse> continuation)
    {
        // Add authorization header
        var token = _tokenProvider.GetToken();
        var headers = context.Options.Headers ?? new Metadata();
        headers.Add("Authorization", $"Bearer {token}");

        var options = context.Options.WithHeaders(headers);
        var newContext = new ClientInterceptorContext<TRequest, TResponse>(
            context.Method,
            context.Host,
            options);

        return continuation(request, newContext);
    }
}
```

#### 2. Retry Interceptor

```csharp
public class RetryInterceptor : Interceptor
{
    private readonly int _maxRetries = 3;
    private readonly TimeSpan _retryDelay = TimeSpan.FromSeconds(1);

    public override AsyncUnaryCall<TResponse> AsyncUnaryCall<TRequest, TResponse>(
        TRequest request,
        ClientInterceptorContext<TRequest, TResponse> context,
        AsyncUnaryCallContinuation<TRequest, TResponse> continuation)
    {
        var call = continuation(request, context);

        return new AsyncUnaryCall<TResponse>(
            RetryAsync(call.ResponseAsync, request, context, continuation),
            call.ResponseHeadersAsync,
            call.GetStatus,
            call.GetTrailers,
            call.Dispose);
    }

    private async Task<TResponse> RetryAsync<TRequest, TResponse>(
        Task<TResponse> responseTask,
        TRequest request,
        ClientInterceptorContext<TRequest, TResponse> context,
        AsyncUnaryCallContinuation<TRequest, TResponse> continuation)
    {
        for (int attempt = 0; attempt <= _maxRetries; attempt++)
        {
            try
            {
                return await responseTask;
            }
            catch (RpcException ex) when (
                ex.StatusCode == StatusCode.Unavailable && 
                attempt < _maxRetries)
            {
                Console.WriteLine($"Retry attempt {attempt + 1}");
                await Task.Delay(_retryDelay);
                
                // Create new call for retry
                var newCall = continuation(request, context);
                responseTask = newCall.ResponseAsync;
            }
        }

        // Final attempt
        return await responseTask;
    }
}
```

#### 3. Performance Monitoring Interceptor

```csharp
public class PerformanceInterceptor : Interceptor
{
    private readonly IMetricsCollector _metrics;

    public PerformanceInterceptor(IMetricsCollector metrics)
    {
        _metrics = metrics;
    }

    public override AsyncUnaryCall<TResponse> AsyncUnaryCall<TRequest, TResponse>(
        TRequest request,
        ClientInterceptorContext<TRequest, TResponse> context,
        AsyncUnaryCallContinuation<TRequest, TResponse> continuation)
    {
        var stopwatch = Stopwatch.StartNew();
        var call = continuation(request, context);

        return new AsyncUnaryCall<TResponse>(
            MeasureAsync(call.ResponseAsync, context.Method.Name, stopwatch),
            call.ResponseHeadersAsync,
            call.GetStatus,
            call.GetTrailers,
            call.Dispose);
    }

    private async Task<TResponse> MeasureAsync<TResponse>(
        Task<TResponse> responseTask,
        string methodName,
        Stopwatch stopwatch)
    {
        try
        {
            var response = await responseTask;
            stopwatch.Stop();
            _metrics.RecordSuccess(methodName, stopwatch.ElapsedMilliseconds);
            return response;
        }
        catch (RpcException ex)
        {
            stopwatch.Stop();
            _metrics.RecordFailure(methodName, ex.StatusCode, stopwatch.ElapsedMilliseconds);
            throw;
        }
    }
}
```

## Performance Optimization

### 1. Channel Reuse (CRITICAL)

**The single most important gRPC performance optimization.**

```csharp
❌ WRONG: Create new channel per call
public async Task<string> GetGreeting(string name)
{
    using var channel = GrpcChannel.ForAddress("https://localhost:5001");
    var client = new Greeter.GreeterClient(channel);
    var response = await client.SayHelloAsync(new HelloRequest { Name = name });
    return response.Message;
}
// Creates: Socket → TCP → TLS → HTTP/2 for EVERY call!
// 100x slower than reusing channel

✅ CORRECT: Reuse channel
private static readonly GrpcChannel _channel = 
    GrpcChannel.ForAddress("https://localhost:5001");

public async Task<string> GetGreeting(string name)
{
    var client = new Greeter.GreeterClient(_channel);
    var response = await client.SayHelloAsync(new HelloRequest { Name = name });
    return response.Message;
}
// Reuses connection for all calls
```

**Performance Impact:**
```
New Channel Per Call:    100-200ms per call
Reuse Channel:           1-5ms per call
Improvement:             20-100x faster!
```

### 3. Compression

Reduce bandwidth by compressing messages.

```csharp
// Server: Enable compression
builder.Services.AddGrpc(options =>
{
    options.ResponseCompressionLevel = System.IO.Compression.CompressionLevel.Optimal;
    options.ResponseCompressionAlgorithm = "gzip";
});

// Client: Request compression
var response = await client.GetLargeDataAsync(
    new DataRequest(),
    new CallOptions(
        headers: new Metadata { { "grpc-internal-encoding-request", "gzip" } }
    )
);
```

**When to Use Compression:**
```
✅ Use for: Large messages (> 1 KB), slow networks
❌ Skip for: Small messages (< 1 KB), fast networks
```

### 4. Deadlines and Cancellation

Prevent calls from running forever.

```csharp
// Set deadline (5 seconds from now)
var deadline = DateTime.UtcNow.AddSeconds(5);

try
{
    var response = await client.SlowMethodAsync(
        new Request(),
        deadline: deadline
    );
}
catch (RpcException ex) when (ex.StatusCode == StatusCode.DeadlineExceeded)
{
    Console.WriteLine("Call timed out");
}

// Use cancellation token
var cts = new CancellationTokenSource(TimeSpan.FromSeconds(5));

try
{
    var response = await client.SlowMethodAsync(
        new Request(),
        cancellationToken: cts.Token
    );
}
catch (RpcException ex) when (ex.StatusCode == StatusCode.Cancelled)
{
    Console.WriteLine("Call cancelled");
}
```

**Server: Respect Cancellation**

```csharp
public override async Task<Response> SlowMethod(
    Request request,
    ServerCallContext context)
{
    for (int i = 0; i < 10; i++)
    {
        // Check if client cancelled
        context.CancellationToken.ThrowIfCancellationRequested();
        
        await Task.Delay(1000, context.CancellationToken);
    }
    
    return new Response();
}
```

## Best Practices

### 1. Reuse Channels

```csharp
✅ Do: Single channel for all calls
❌ Don't: New channel per call
```

### 2. Use Interceptors for Cross-Cutting Concerns

```csharp
✅ Do: Logging, auth, validation in interceptors
❌ Don't: Duplicate logging in every service method
```

### 3. Set Appropriate Deadlines

```csharp
✅ Do: Set deadlines based on expected duration
❌ Don't: No deadline or unreasonably long deadline
```

### 4. Handle Cancellation

```csharp
✅ Do: Check CancellationToken in long operations
❌ Don't: Ignore cancellation and waste resources
```

### 5. Compress Large Messages

```csharp
✅ Do: Compress messages > 1 KB
❌ Don't: Compress small messages (overhead)
```

### 6. Order Interceptors Correctly

```csharp
✅ Do: Auth → Logging → Retry
❌ Don't: Random order
```
