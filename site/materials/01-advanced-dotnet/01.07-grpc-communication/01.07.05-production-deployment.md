## Introduction

Deploying gRPC services to production requires different considerations than traditional REST APIs due to HTTP/2 requirements, load balancing challenges, and the binary nature of the protocol. This lesson covers everything from proper logging and monitoring to troubleshooting production issues, ensuring your gRPC services are reliable, observable, and maintainable in production environments.

## Key Concepts Summary

### Production Deployment Considerations

gRPC differs from REST APIs in several critical ways that affect deployment:

```
REST API Deployment:
- HTTP/1.1
- Text-based (JSON)
- Works with any load balancer
- Easy to inspect traffic
- Browser-friendly

gRPC Deployment:
- HTTP/2 required
- Binary protocol (Protobuf)
- Requires HTTP/2-aware load balancing
- Needs specialized tools to inspect
- Requires gRPC-Web for browsers
```

### Infrastructure Requirements

**1. HTTP/2 Support**
- Load balancers must support HTTP/2
- Use pass-through mode, not termination
- Configure proper ALPN (Application-Layer Protocol Negotiation)

**2. TLS Configuration**
- Always use TLS in production
- Configure proper certificates
- Enable HTTP/2 over TLS (h2)
- Consider mutual TLS (mTLS) for service-to-service

**3. Load Balancing**
- Client-side load balancing preferred
- Server-side requires HTTP/2-aware LB (Envoy, Nginx, HAProxy)
- Avoid L4 load balancers (connection-level)
- Use L7 load balancers (request-level)

## Logging and Diagnostics

### Structured Logging

gRPC in .NET uses `ILogger` for structured logging.

```csharp
public class ProductService : Products.ProductsBase
{
    private readonly ILogger<ProductService> _logger;

    public ProductService(ILogger<ProductService> logger)
    {
        _logger = logger;
    }

    public override async Task<ProductResponse> GetProduct(
        ProductRequest request,
        ServerCallContext context)
    {
        // Log with structured data
        _logger.LogInformation(
            "Getting product {ProductId} for user {UserId}",
            request.Id,
            context.GetHttpContext().User.Identity?.Name);

        try
        {
            var product = await GetProductFromDatabase(request.Id);
            
            _logger.LogDebug(
                "Product retrieved: {ProductName}, Price: {Price}",
                product.Name,
                product.Price);

            return MapToResponse(product);
        }
        catch (ProductNotFoundException ex)
        {
            _logger.LogWarning(
                ex,
                "Product {ProductId} not found",
                request.Id);
            
            throw new RpcException(
                new Status(StatusCode.NotFound, "Product not found"));
        }
        catch (Exception ex)
        {
            _logger.LogError(
                ex,
                "Error retrieving product {ProductId}",
                request.Id);
            
            throw new RpcException(
                new Status(StatusCode.Internal, "An error occurred"));
        }
    }
}
```

### Correlation IDs

Track requests across services:

```csharp
public class CorrelationMiddleware
{
    private readonly RequestDelegate _next;

    public CorrelationMiddleware(RequestDelegate next)
    {
        _next = next;
    }

    public async Task InvokeAsync(HttpContext context)
    {
        // Get or create correlation ID
        var correlationId = context.Request.Headers["x-correlation-id"].FirstOrDefault()
            ?? Guid.NewGuid().ToString();

        // Add to response headers
        context.Response.Headers["x-correlation-id"] = correlationId;

        // Add to logging scope
        using (context.RequestServices
            .GetRequiredService<ILogger<CorrelationMiddleware>>()
            .BeginScope(new Dictionary<string, object>
            {
                ["CorrelationId"] = correlationId
            }))
        {
            await _next(context);
        }
    }
}

// Register middleware
app.UseMiddleware<CorrelationMiddleware>();
```

### Custom Metrics

```csharp
using System.Diagnostics.Tracing;

[EventSource(Name = "GrpcService-Metrics")]
public sealed class GrpcMetrics : EventSource
{
    public static readonly GrpcMetrics Instance = new();

    private readonly EventCounter _requestCounter;
    private readonly EventCounter _errorCounter;
    private readonly EventCounter _durationCounter;

    private GrpcMetrics()
    {
        _requestCounter = new EventCounter("requests", this);
        _errorCounter = new EventCounter("errors", this);
        _durationCounter = new EventCounter("duration-ms", this);
    }

    public void RecordRequest()
    {
        _requestCounter.WriteMetric(1);
    }

    public void RecordError()
    {
        _errorCounter.WriteMetric(1);
    }

    public void RecordDuration(long milliseconds)
    {
        _durationCounter.WriteMetric(milliseconds);
    }
}

// Usage in service
public override async Task<ProductResponse> GetProduct(
    ProductRequest request,
    ServerCallContext context)
{
    GrpcMetrics.Instance.RecordRequest();
    
    var stopwatch = Stopwatch.StartNew();
    
    try
    {
        var response = await GetProductInternal(request);
        stopwatch.Stop();
        GrpcMetrics.Instance.RecordDuration(stopwatch.ElapsedMilliseconds);
        return response;
    }
    catch
    {
        GrpcMetrics.Instance.RecordError();
        throw;
    }
}
```

## Error Handling

### Status Codes

Use appropriate gRPC status codes for different error scenarios:

```csharp
public override async Task<ProductResponse> GetProduct(
    ProductRequest request,
    ServerCallContext context)
{
    // Validation errors
    if (request.Id <= 0)
    {
        throw new RpcException(
            new Status(StatusCode.InvalidArgument, "Product ID must be positive"));
    }

    // Not found
    var product = await _repository.GetByIdAsync(request.Id);
    if (product == null)
    {
        throw new RpcException(
            new Status(StatusCode.NotFound, $"Product {request.Id} not found"));
    }

    // Authorization errors
    if (!await _authService.CanAccessProduct(context.GetHttpContext().User, product))
    {
        throw new RpcException(
            new Status(StatusCode.PermissionDenied, "Access denied"));
    }

    // Business logic errors
    if (!product.IsAvailable)
    {
        throw new RpcException(
            new Status(StatusCode.FailedPrecondition, "Product is not available"));
    }

    // Temporary errors
    try
    {
        return MapToResponse(product);
    }
    catch (DatabaseException)
    {
        throw new RpcException(
            new Status(StatusCode.Unavailable, "Service temporarily unavailable"));
    }
}
```

**Common Status Codes:**

| Code | When to Use | Example |
|------|-------------|---------|
| `OK` | Success | Request completed successfully |
| `Cancelled` | Client cancelled | User clicked cancel |
| `InvalidArgument` | Invalid input | Missing required field, negative ID |
| `NotFound` | Resource not found | Product ID doesn't exist |
| `PermissionDenied` | No access | User doesn't have role |
| `Unauthenticated` | Not authenticated | Invalid/missing token |
| `FailedPrecondition` | State violation | Account not activated |
| `Unavailable` | Temporary failure | Database down, retry possible |
| `Internal` | Server error | Unexpected exception |
| `DeadlineExceeded` | Timeout | Request took too long |

### Rich Error Details

```csharp
public override async Task<ProductResponse> CreateProduct(

    if (errors.Any())
    {
        var status = new Google.Rpc.Status

            Details =

                    FieldViolations =

                        errors.Select(e => new BadRequest.Types.FieldViolation
                        {
                            Field = e.Field,
                            Description = e.Message
                        })
                    }
                })
            }
        };

        throw status.ToRpcException();
    }

    // ... create product
}
```

### Global Error Handling

```csharp
public class GlobalExceptionInterceptor : Interceptor
{
    private readonly ILogger<GlobalExceptionInterceptor> _logger;

    public GlobalExceptionInterceptor(ILogger<GlobalExceptionInterceptor> logger)
    {
        _logger = logger;
    }

    public override async Task<TResponse> UnaryServerHandler<TRequest, TResponse>(
        TRequest request,
        ServerCallContext context,
        UnaryServerMethod<TRequest, TResponse> continuation)
    {
        try
        {
            return await continuation(request, context);
        }
        catch (RpcException)
        {
            // Already gRPC exception, re-throw
            throw;
        }
        catch (ArgumentException ex)
        {
            _logger.LogWarning(ex, "Invalid argument");
            throw new RpcException(new Status(StatusCode.InvalidArgument, ex.Message));
        }
        catch (UnauthorizedAccessException ex)
        {
            _logger.LogWarning(ex, "Unauthorized");
            throw new RpcException(new Status(StatusCode.PermissionDenied, "Access denied"));
        }
        catch (TimeoutException ex)
        {
            _logger.LogWarning(ex, "Timeout");
            throw new RpcException(new Status(StatusCode.DeadlineExceeded, "Request timeout"));
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Unhandled exception");
            throw new RpcException(new Status(StatusCode.Internal, "An error occurred"));
        }
    }
}
```

### Custom Health Check

```csharp
using Microsoft.Extensions.Diagnostics.HealthChecks;

public class DatabaseHealthCheck : IHealthCheck
{
    private readonly IDbConnection _connection;

    public DatabaseHealthCheck(IDbConnection connection)
    {
        _connection = connection;
    }

    public async Task<HealthCheckResult> CheckHealthAsync(
        HealthCheckContext context,
        CancellationToken cancellationToken = default)
    {
        try
        {
            await _connection.OpenAsync(cancellationToken);
            await _connection.CloseAsync();
            
            return HealthCheckResult.Healthy("Database is healthy");
        }
        catch (Exception ex)
        {
            return HealthCheckResult.Unhealthy(
                "Database is unhealthy",
                ex);
        }
    }
}

// Register
builder.Services.AddHealthChecks()
    .AddCheck<DatabaseHealthCheck>("database");
```

### Client Health Check

```csharp
using Grpc.Health.V1;
using Grpc.Net.Client;

var channel = GrpcChannel.ForAddress("https://localhost:5001");
var healthClient = new Health.HealthClient(channel);

var response = await healthClient.CheckAsync(new HealthCheckRequest
{
    Service = "" // Empty for overall health
});

if (response.Status == HealthCheckResponse.Types.ServingStatus.Serving)
{
    Console.WriteLine("Service is healthy");
}
else
{
    Console.WriteLine($"Service is unhealthy: {response.Status}");
}
```

```csharp
// Program.cs
builder.WebHost.ConfigureKestrel(options =>
{
    // HTTP/2 endpoint with TLS
    options.ListenAnyIP(5001, listenOptions =>
    {
        listenOptions.Protocols = HttpProtocols.Http2;
```

## Troubleshooting Common Issues

### Issue 1: HTTP/2 Not Working

**Symptoms:**
- Connection refused
- Protocol errors

**Solutions:**
```csharp
// Ensure HTTP/2 is enabled
builder.WebHost.ConfigureKestrel(options =>
{
    options.ListenAnyIP(5001, listenOptions =>
    {
        listenOptions.Protocols = HttpProtocols.Http2; // Critical!
        listenOptions.UseHttps();
    });
});

// Client must also support HTTP/2
var handler = new SocketsHttpHandler
{
    EnableMultipleHttp2Connections = true
};
```

### Issue 2: DEADLINE_EXCEEDED Errors

**Symptoms:**
- Calls timing out
- Inconsistent failures

**Solutions:**
```csharp
// Server: Optimize slow operations
public override async Task<Response> SlowMethod(
    Request request,
    ServerCallContext context)
{
    // Add caching
    var cached = await _cache.GetAsync(request.Id);
    if (cached != null) return cached;
    
    // Add timeout protection
    using var cts = CancellationTokenSource.CreateLinkedTokenSource(
        context.CancellationToken);
    cts.CancelAfter(TimeSpan.FromSeconds(10));
    
    return await ProcessAsync(request, cts.Token);
}

// Client: Set appropriate deadline
var response = await client.SlowMethodAsync(
    new Request(),
    deadline: DateTime.UtcNow.AddSeconds(30));
```

### Issue 3: Load Balancer Issues

**Symptoms:**
- Uneven load distribution
- Connection resets

**Solutions:**
```
Option 1: Client-side load balancing
- Use dns:/// resolver
- Round-robin across endpoints

Option 2: L7 load balancer (Envoy/Nginx)
- Configure HTTP/2 support
- Use least-connections algorithm

Option 3: Service mesh (Istio/Linkerd)
- Automatic load balancing
- Built-in retries and circuit breaking
```

### Issue 4: TLS/Certificate Errors

**Symptoms:**
- SSL handshake failures
- Certificate validation errors

**Solutions:**
```csharp
// Development: Bypass certificate validation (INSECURE!)
var handler = new HttpClientHandler
{
    ServerCertificateCustomValidationCallback = 
        HttpClientHandler.DangerousAcceptAnyServerCertificateValidator
};

var channel = GrpcChannel.ForAddress("https://localhost:5001",
    new GrpcChannelOptions { HttpHandler = handler });

// Production: Use valid certificates
// - Let's Encrypt for public services
// - Internal CA for private services
// - Azure Key Vault for certificate management
```

## Versioning Strategies

### Proto File Versioning

```protobuf
// v1/products.proto
syntax = "proto3";
package products.v1;

service ProductService {
  rpc GetProduct (GetProductRequest) returns (ProductResponse);

  rpc GetProduct (GetProductRequest) returns (ProductResponse);
```

```csharp
✅ Use appropriate status codes
❌ Return generic "Internal" for everything
```

### 5. Implement Health Checks

```csharp
✅ Check: Database, cache, dependencies
❌ Only check: Service is running
```

```csharp
✅ Set realistic deadlines based on SLAs
```
