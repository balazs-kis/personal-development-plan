## Introduction

gRPC (gRPC Remote Procedure Call) is a modern, high-performance framework for building distributed systems. Developed by Google, it uses Protocol Buffers for efficient binary serialization and HTTP/2 for transport. gRPC enables contract-first development where you define your API in `.proto` files, making it ideal for microservices, real-time communication, and polyglot environments where multiple languages need to communicate efficiently.

## Key Concepts Summary

### What is gRPC?

gRPC is a modern Remote Procedure Call (RPC) framework:

```
Traditional REST API:
Client → HTTP/1.1 JSON → Server
       ← HTTP/1.1 JSON ← 

gRPC:
Client → HTTP/2 Binary Protobuf → Server
       ← HTTP/2 Binary Protobuf ←
```

**Key Characteristics:**
- **High Performance** - Binary protocol, HTTP/2 multiplexing
- **Contract-First** - Define API in `.proto` files
- **Strongly Typed** - Generated code for type safety
- **Multi-Language** - Works across different programming languages
- **Streaming Support** - Built-in streaming capabilities

### gRPC vs. REST

| Feature | REST | gRPC |
|---------|------|------|
| **Protocol** | HTTP/1.1 | HTTP/2 |
| **Payload** | JSON (text) | Protobuf (binary) |
| **Performance** | Slower | ~7-10x faster |
| **Streaming** | Limited (SSE, WebSockets) | Native support |
| **Browser Support** | Universal | Limited (requires gRPC-Web) |
| **API Contract** | Optional (OpenAPI) | Required (.proto) |
| **Code Generation** | Optional | Built-in |
| **Human Readable** | Yes (JSON) | No (binary) |

**When to Use gRPC:**
```
✅ Use gRPC when:
   - Microservice communication (service-to-service)
   - Performance is critical
   - Real-time bidirectional streaming needed
   - Polyglot environments (multiple languages)
   - Strong contracts required
   - Internal APIs

❌ Stick with REST when:
   - Browser clients without gRPC-Web
   - Public APIs for third parties
   - Human-readable payloads needed
   - Simple CRUD operations
   - Team unfamiliar with gRPC
```

### Protocol Buffers (Protobuf)

Protocol Buffers is a language-neutral serialization format:

**Benefits:**
1. **Compact** - 3-10x smaller than JSON
2. **Fast** - 20-100x faster serialization/deserialization
3. **Type Safe** - Strongly typed with schema validation
4. **Versioned** - Forward and backward compatibility
5. **Multi-Language** - Code generation for many languages

**Comparison:**

```json
// JSON - 82 bytes
{
  "id": 1,
  "name": "John Doe",
  "email": "john@example.com",
  "age": 30
}

// Protobuf - ~25 bytes (binary)
// Same data, much smaller!
```

### Proto3 Syntax Basics

#### File Structure

```protobuf
// greeter.proto
syntax = "proto3";

option csharp_namespace = "GrpcGreeter";

package greet;

// Service definition
service Greeter {
  rpc SayHello (HelloRequest) returns (HelloReply);
}

// Message definitions
message HelloRequest {
  string name = 1;
}

message HelloReply {
  string message = 1;
}
```

**Key Components:**
- `syntax = "proto3"` - Specifies proto3 (required first line)
- `option csharp_namespace` - Sets .NET namespace
- `package` - Logical grouping (prevents name conflicts)
- `service` - Defines RPC service
- `message` - Defines data structures
- Field numbers (1, 2, 3) - Unique identifiers for serialization

#### Scalar Types

```protobuf
message Person {
  int32 id = 1;              // → int in C#
  int64 user_id = 2;         // → long
  uint32 age = 3;            // → uint
  bool is_active = 4;        // → bool
  string name = 5;           // → string
  bytes data = 6;            // → ByteString
  float rating = 7;          // → float
  double price = 8;          // → double
}
```

#### Collections

```protobuf
message TodoList {
  repeated string items = 1;           // → List<string>
  map<string, int32> priorities = 2;   // → Dictionary<string, int>
}
```

#### Enums

```protobuf
enum Status {
  STATUS_UNKNOWN = 0;  // First value must be 0
  STATUS_ACTIVE = 1;
  STATUS_INACTIVE = 2;
  STATUS_DELETED = 3;
}

message User {
  string name = 1;
  Status status = 2;
}
```

#### Nested Messages

```protobuf
message Company {
  string name = 1;
  
  message Address {
    string street = 1;
    string city = 2;
    string country = 3;
  }
  
  Address headquarters = 2;
}
```

#### Timestamps and Well-Known Types

```protobuf
import "google/protobuf/timestamp.proto";
import "google/protobuf/empty.proto";

message Event {
  string name = 1;
  google.protobuf.Timestamp created_at = 2;
}

service EventService {
  rpc DeleteEvent (google.protobuf.Empty) returns (google.protobuf.Empty);
}
```

### Creating a gRPC Service in ASP.NET Core

#### 1. Create the Project

```bash
# Using .NET CLI
dotnet new grpc -n GrpcService
cd GrpcService
```

**Project Structure:**
```
GrpcService/
├── Protos/
│   └── greet.proto
├── Services/
│   └── GreeterService.cs
├── Program.cs
└── GrpcService.csproj
```

#### 2. Define the Proto File

```protobuf
// Protos/products.proto
syntax = "proto3";

option csharp_namespace = "GrpcService";

service ProductService {
  rpc GetProduct (ProductRequest) returns (ProductResponse);
  rpc GetAllProducts (EmptyRequest) returns (ProductListResponse);
  rpc CreateProduct (CreateProductRequest) returns (ProductResponse);
}

message EmptyRequest {}

message ProductRequest {
  int32 id = 1;
}

message CreateProductRequest {
  string name = 1;
  string description = 2;
  double price = 3;
}

message ProductResponse {
  int32 id = 1;
  string name = 2;
  string description = 3;
  double price = 4;
}

message ProductListResponse {
  repeated ProductResponse products = 1;
}
```

#### 3. Configure in .csproj

```xml
<ItemGroup>
  <Protobuf Include="Protos\products.proto" GrpcServices="Server" />
</ItemGroup>
```

**GrpcServices Options:**
- `Server` - Generate server code
- `Client` - Generate client code
- `Both` - Generate both (for same project)

#### 4. Implement the Service

```csharp
using Grpc.Core;
using GrpcService;

public class ProductService : ProductService.ProductServiceBase
{
    private readonly ILogger<ProductService> _logger;
    private static readonly List<Product> _products = new();

    public ProductService(ILogger<ProductService> logger)
    {
        _logger = logger;
    }

    public override Task<ProductResponse> GetProduct(
        ProductRequest request, 
        ServerCallContext context)
    {
        var product = _products.FirstOrDefault(p => p.Id == request.Id);
        
        if (product == null)
        {
            throw new RpcException(
                new Status(StatusCode.NotFound, $"Product {request.Id} not found"));
        }

        return Task.FromResult(new ProductResponse
        {
            Id = product.Id,
            Name = product.Name,
            Description = product.Description,
            Price = product.Price
        });
    }

    public override Task<ProductListResponse> GetAllProducts(
        EmptyRequest request, 
        ServerCallContext context)
    {
        var response = new ProductListResponse();
        response.Products.AddRange(_products.Select(p => new ProductResponse
        {
            Id = p.Id,
            Name = p.Name,
            Description = p.Description,
            Price = p.Price
        }));

        return Task.FromResult(response);
    }

    public override Task<ProductResponse> CreateProduct(
        CreateProductRequest request, 
        ServerCallContext context)
    {
        var product = new Product
        {
            Id = _products.Count + 1,
            Name = request.Name,
            Description = request.Description,
            Price = request.Price
        };

        _products.Add(product);

        return Task.FromResult(new ProductResponse
        {
            Id = product.Id,
            Name = product.Name,
            Description = product.Description,
            Price = product.Price
        });
    }
}

// Domain model
public class Product
{
    public int Id { get; set; }
    public string Name { get; set; } = string.Empty;
    public string Description { get; set; } = string.Empty;
    public double Price { get; set; }
}
```

#### 5. Register the Service

```csharp
// Program.cs
var builder = WebApplication.CreateBuilder(args);

// Add gRPC services
builder.Services.AddGrpc();

var app = builder.Build();

// Map gRPC service
app.MapGrpcService<ProductService>();

app.MapGet("/", () => "Communication with gRPC endpoints must be made through a gRPC client.");

app.Run();
```

### Creating a gRPC Client

#### 1. Add Required Packages

```bash
dotnet add package Grpc.Net.Client
dotnet add package Google.Protobuf
dotnet add package Grpc.Tools
```

#### 2. Reference the Proto File

```xml
<ItemGroup>
  <Protobuf Include="Protos\products.proto" GrpcServices="Client" />
</ItemGroup>
```

#### 3. Create the Client

```csharp
using Grpc.Net.Client;
using GrpcService;

class Program
{
    static async Task Main(string[] args)
    {
        // Create channel
        using var channel = GrpcChannel.ForAddress("https://localhost:7042");
        
        // Create client
        var client = new ProductService.ProductServiceClient(channel);

        // Call GetAllProducts
        var allProducts = await client.GetAllProductsAsync(new EmptyRequest());
        
        Console.WriteLine("All Products:");
        foreach (var product in allProducts.Products)
        {
            Console.WriteLine($"- {product.Name}: ${product.Price}");
        }

        // Call CreateProduct
        var createRequest = new CreateProductRequest
        {
            Name = "New Product",
            Description = "A great product",
            Price = 29.99
        };
        
        var newProduct = await client.CreateProductAsync(createRequest);
        Console.WriteLine($"Created: {newProduct.Name} with ID {newProduct.Id}");

        // Call GetProduct
        var getRequest = new ProductRequest { Id = newProduct.Id };
        var product = await client.GetProductAsync(getRequest);
        Console.WriteLine($"Retrieved: {product.Name}");
    }
}
```

### Error Handling in gRPC

```csharp
// Server: Throw RpcException
public override Task<ProductResponse> GetProduct(
    ProductRequest request, 
    ServerCallContext context)
{
    if (request.Id <= 0)
    {
        throw new RpcException(
            new Status(StatusCode.InvalidArgument, "ID must be positive"));
    }
    
    // ... rest of implementation
}

// Client: Catch RpcException
try
{
    var response = await client.GetProductAsync(new ProductRequest { Id = -1 });
}
catch (RpcException ex)
{
    Console.WriteLine($"Error: {ex.Status.Detail}");
    Console.WriteLine($"Status Code: {ex.StatusCode}");
}
```

**Common Status Codes:**
- `OK` - Success
- `Cancelled` - Operation cancelled
- `NotFound` - Resource not found
- `InvalidArgument` - Invalid parameters
- `Unauthenticated` - Missing/invalid authentication
- `PermissionDenied` - No permission
- `Unavailable` - Service unavailable
- `Internal` - Internal server error

### Channel Management and Performance

#### Reuse Channels

```csharp
❌ Don't: Create new channel per call
for (int i = 0; i < 100; i++)
{
    using var channel = GrpcChannel.ForAddress("https://localhost:7042");
    var client = new ProductService.ProductServiceClient(channel);
    await client.GetProductAsync(new ProductRequest { Id = i });
}

✅ Do: Reuse channel
using var channel = GrpcChannel.ForAddress("https://localhost:7042");
var client = new ProductService.ProductServiceClient(channel);

for (int i = 0; i < 100; i++)
{
    await client.GetProductAsync(new ProductRequest { Id = i });
}
```

#### Use gRPC Client Factory

```csharp
// Startup configuration
builder.Services.AddGrpcClient<ProductService.ProductServiceClient>(options =>
{
    options.Address = new Uri("https://localhost:7042");
});

// Inject and use
public class ProductManager
{
    private readonly ProductService.ProductServiceClient _client;

    public ProductManager(ProductService.ProductServiceClient client)
    {
        _client = client;
    }

    public async Task<ProductResponse> GetProductAsync(int id)
    {
        return await _client.GetProductAsync(new ProductRequest { Id = id });
    }
}
```

### Metadata (Headers)

```csharp
// Server: Read metadata
public override Task<ProductResponse> GetProduct(
    ProductRequest request, 
    ServerCallContext context)
{
    var metadata = context.RequestHeaders;
    var apiKey = metadata.GetValue("api-key");
    
    if (string.IsNullOrEmpty(apiKey))
    {
        throw new RpcException(new Status(StatusCode.Unauthenticated, "API key required"));
    }
    
    // ... implementation
}

// Client: Send metadata
var headers = new Metadata
{
    { "api-key", "my-secret-key" },
    { "user-id", "123" }
};

var response = await client.GetProductAsync(
    new ProductRequest { Id = 1 }, 
    headers: headers);
```

### Deadlines and Timeouts

```csharp
// Client: Set deadline
var deadline = DateTime.UtcNow.AddSeconds(5);

try
{
    var response = await client.GetProductAsync(
        new ProductRequest { Id = 1 },
        deadline: deadline);
}
catch (RpcException ex) when (ex.StatusCode == StatusCode.DeadlineExceeded)
{
    Console.WriteLine("Request timed out");
}

// Server: Check if deadline exceeded
public override async Task<ProductResponse> GetProduct(
    ProductRequest request, 
    ServerCallContext context)
{
    // Long operation
    await Task.Delay(10000, context.CancellationToken);
    
    // This will throw if deadline exceeded or client cancelled
}
```
