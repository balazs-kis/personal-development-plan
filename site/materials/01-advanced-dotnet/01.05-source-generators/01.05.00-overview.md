# Chapter 1.5: Source Generators and Metaprogramming

## Overview
Harness the power of the compiler to generate code at build time. Source generators allow you to inspect user code and produce additional C# files, enabling scenarios that previously required reflection or IL weaving. This chapter covers everything from fundamentals to production deployment, including real-world patterns from Microsoft's own generators.

## Key Concepts
- **Compile-Time Generation:** replacing runtime reflection with build-time logic for better performance and AOT compatibility.
- **Incremental Generators:** optimizing build performance through intelligent caching.
- **Roslyn API:** working with syntax trees and semantic models to analyze code.
- **Diagnostics:** emitting helpful warnings and errors to guide developers.
- **Production Patterns:** learning from System.Text.Json, RegexGenerator, and LoggerMessage.
