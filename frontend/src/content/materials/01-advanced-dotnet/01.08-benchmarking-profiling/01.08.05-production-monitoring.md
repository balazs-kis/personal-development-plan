## Introduction

Production monitoring is fundamentally different from development profiling. In production, you need continuous observability, distributed tracing across services, alerting on anomalies, and minimal performance overhead. Application Performance Monitoring (APM) tools like Application Insights and OpenTelemetry provide the infrastructure for understanding how your application behaves under real-world conditions, enabling proactive issue detection and rapid troubleshooting.

## Key Concepts Summary

### Application Performance Monitoring (APM)

APM provides continuous monitoring and analysis of production applications:

```
Traditional Debugging:
- Local profiling
- Isolated testing
- Synthetic scenarios
- Limited scope

Production APM:
- Real user data
- Distributed systems
- Actual load patterns
- Complete picture
```

**Key APM Capabilities:**
1. **Request tracking** - Response times, throughput, failures
2. **Dependency monitoring** - Database, HTTP, external services
3. **Exception tracking** - Errors, stack traces, context
4. **Custom metrics** - Business KPIs, performance counters
5. **Distributed tracing** - Request flow across microservices
6. **Availability monitoring** - Uptime, health checks
7. **User analytics** - Sessions, page views, user flows

## Application Insights Setup

### Installation

```bash
# Install NuGet package
dotnet add package Microsoft.ApplicationInsights.AspNetCore

# Or for OpenTelemetry (recommended)
dotnet add package Azure.Monitor.OpenTelemetry.AspNetCore
```

### Basic Configuration

```csharp
// Program.cs - Traditional Application Insights
using Microsoft.ApplicationInsights.Extensibility;

var builder = WebApplication.CreateBuilder(args);

// Add Application Insights
builder.Services.AddApplicationInsightsTelemetry(options =>
{
    options.ConnectionString = builder.Configuration["ApplicationInsights:ConnectionString"];
    options.EnableAdaptiveSampling = true;
    options.EnableQuickPulseMetricStream = true; // Live Metrics
});

var app = builder.Build();

app.MapGet("/", () => "Hello World!");
app.Run();
```

### OpenTelemetry Configuration (Recommended)

```csharp
// Program.cs - OpenTelemetry with Application Insights
using Azure.Monitor.OpenTelemetry.AspNetCore;

var builder = WebApplication.CreateBuilder(args);

// Add OpenTelemetry with Application Insights
builder.Services.AddOpenTelemetry()
    .UseAzureMonitor(options =>
    {
        options.ConnectionString = builder.Configuration["ApplicationInsights:ConnectionString"];
    });

var app = builder.Build();

app.MapGet("/", () => "Hello World!");
app.Run();
```

### Configuration File

```json
// appsettings.json
{
  "ApplicationInsights": {
    "ConnectionString": "InstrumentationKey=xxx;IngestionEndpoint=https://..."
  },
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft.AspNetCore": "Warning"
    },
    "ApplicationInsights": {
      "LogLevel": {
        "Default": "Information"
      }
    }
  }
}
```

**Important:** Never commit connection strings to source control. Use:
- Azure Key Vault for production
- User Secrets for development
- Environment variables for containers

## Custom Telemetry

### Tracking Custom Events

```csharp
using Microsoft.ApplicationInsights;
using Microsoft.ApplicationInsights.DataContracts;

public class OrderService
{
    private readonly TelemetryClient _telemetry;

    public OrderService(TelemetryClient telemetry)
    {
        _telemetry = telemetry;
    }

    public async Task<Order> CreateOrderAsync(OrderRequest request)
    {
        // Track custom event
        _telemetry.TrackEvent("OrderCreated", 
            new Dictionary<string, string>
            {
                { "OrderId", order.Id.ToString() },
                { "CustomerId", request.CustomerId.ToString() },
                { "TotalAmount", order.Total.ToString("C") }
            },
            new Dictionary<string, double>
            {
                { "ItemCount", order.Items.Count },
                { "OrderValue", (double)order.Total }
            });

        return order;
    }
}
```

### Tracking Custom Metrics

```csharp
public class InventoryService
{
    private readonly TelemetryClient _telemetry;

    public InventoryService(TelemetryClient telemetry)
    {
        _telemetry = telemetry;
    }

    public void UpdateStock(int productId, int quantity)
    {
        // Track metric
        _telemetry.TrackMetric("StockLevel", quantity, 
            new Dictionary<string, string>
            {
                { "ProductId", productId.ToString() }
            });

        // Track metric with statistics
        _telemetry.GetMetric("InventoryValue")
            .TrackValue(quantity * GetProductPrice(productId));
    }
}
```

### Tracking Dependencies

```csharp
public class ExternalApiService
{
    private readonly TelemetryClient _telemetry;
    private readonly HttpClient _httpClient;

    public ExternalApiService(TelemetryClient telemetry, HttpClient httpClient)
    {
        _telemetry = telemetry;
        _httpClient = httpClient;
    }

    public async Task<string> CallExternalApiAsync()
    {
        var stopwatch = Stopwatch.StartNew();
        bool success = false;
        string resultCode = null;

        try
        {
            var response = await _httpClient.GetAsync("https://api.example.com/data");
            resultCode = ((int)response.StatusCode).ToString();
            success = response.IsSuccessStatusCode;
            return await response.Content.ReadAsStringAsync();
        }
        catch (Exception ex)
        {
            resultCode = "Exception";
            _telemetry.TrackException(ex);
            throw;
        }
        finally
        {
            stopwatch.Stop();
            
            // Manually track dependency
            _telemetry.TrackDependency(
                "HTTP",
                "api.example.com",
                "/data",
                "https://api.example.com/data",
                DateTimeOffset.UtcNow.Subtract(stopwatch.Elapsed),
                stopwatch.Elapsed,
                resultCode,
                success);
        }
    }
}
```

### Adding Custom Properties Globally

```csharp
// Telemetry initializer
using Microsoft.ApplicationInsights.Channel;
using Microsoft.ApplicationInsights.Extensibility;

public class CustomTelemetryInitializer : ITelemetryInitializer
{
    public void Initialize(ITelemetry telemetry)
    {
        // Add custom properties to all telemetry
        telemetry.Context.GlobalProperties["Environment"] = 
            Environment.GetEnvironmentVariable("ASPNETCORE_ENVIRONMENT");
        
        telemetry.Context.GlobalProperties["Region"] = "EastUS";
        telemetry.Context.GlobalProperties["Version"] = "1.2.3";
        
        // Add cloud role name for microservices
        telemetry.Context.Cloud.RoleName = "ProductService";
    }
}

// Register initializer
builder.Services.AddSingleton<ITelemetryInitializer, CustomTelemetryInitializer>();
```

## Distributed Tracing

Track requests across microservices:

### Service 1: API Gateway

```csharp
public class ApiGatewayController : ControllerBase
{
    private readonly HttpClient _httpClient;
    private readonly TelemetryClient _telemetry;

    [HttpGet("orders/{id}")]
    public async Task<IActionResult> GetOrder(int id)
    {
        // This request automatically gets a correlation ID
        
        // Call downstream service
        var order = await _httpClient.GetFromJsonAsync<Order>(
            $"http://order-service/api/orders/{id}");

        // Correlation ID automatically propagated
        
        return Ok(order);
    }
}
```

### Service 2: Order Service

```csharp
public class OrderController : ControllerBase
{
    private readonly IOrderRepository _repository;
    private readonly HttpClient _httpClient;

    [HttpGet("{id}")]
    public async Task<IActionResult> GetOrder(int id)
    {
        // Correlation ID automatically received
        
        var order = await _repository.GetByIdAsync(id);
        
        // Call another service
        var inventory = await _httpClient.GetFromJsonAsync<Inventory>(
            $"http://inventory-service/api/inventory/{order.ProductId}");

        // All tracked as single distributed transaction
        
        return Ok(order);
    }
}
```

## Querying Telemetry with KQL

Use Kusto Query Language (KQL) to analyze telemetry:

### Request Performance

```kql
// Average request duration by operation
requests
| where timestamp > ago(1h)
| summarize 
    RequestCount = count(),
    AvgDuration = avg(duration),
    P95Duration = percentile(duration, 95),
    P99Duration = percentile(duration, 99)
    by operation_Name
| order by AvgDuration desc
```

### Failed Requests

```kql
// Failed requests in last 24 hours
requests
| where timestamp > ago(24h)
| where success == false
| project 
    timestamp,
    name,
    resultCode,
    duration,
    url,
    customDimensions
| order by timestamp desc
```

### Exception Analysis

```kql
// Most common exceptions
exceptions
| where timestamp > ago(7d)
| summarize 
    ExceptionCount = count(),
    AffectedUsers = dcount(user_Id)
    by type, outerMessage
| order by ExceptionCount desc
| take 10
```

### Dependency Performance

```kql
// Slow database queries
dependencies
| where timestamp > ago(1h)
| where type == "SQL"
| where duration > 1000 // > 1 second
| project 
    timestamp,
    name,
    duration,
    success,
    data
| order by duration desc
```

### Custom Metrics

```kql
// Track business metrics
customMetrics
| where timestamp > ago(1d)
| where name == "OrderValue"
| summarize 
    TotalRevenue = sum(value),
    OrderCount = count(),
    AvgOrderValue = avg(value)
    by bin(timestamp, 1h)
| render timechart
```

## Alerts and Monitoring

### Creating Alerts

```kql
// Alert when response time exceeds threshold
requests
| where timestamp > ago(5m)
| summarize AvgDuration = avg(duration) by bin(timestamp, 1m)
| where AvgDuration > 1000 // Alert if > 1 second
```

**Alert Configuration:**
- **Metric:** Request duration
- **Condition:** Average > 1000ms
- **Evaluation:** Every 1 minute
- **Action:** Send email, webhook, SMS

### Health Checks

```csharp
// Implement health checks
```

### Availability Tests

Configure availability tests in Application Insights:
- **URL ping tests** - Check endpoint availability
- **Multi-step web tests** - Complex user flows
- **Custom availability tests** - TrackAvailability API

```csharp
public class CustomAvailabilityTest
{
    private readonly TelemetryClient _telemetry;

    public async Task RunAvailabilityTest()
    {
        var stopwatch = Stopwatch.StartNew();
        bool success = false;
        string message = null;

        try
        {
            // Perform test
            var response = await _httpClient.GetAsync("https://myapp.com/health");
            success = response.IsSuccessStatusCode;
            message = success ? "Available" : $"Failed: {response.StatusCode}";
        }
        catch (Exception ex)
        {
            message = ex.Message;
        }
        finally
        {
            stopwatch.Stop();

            _telemetry.TrackAvailability(
                "MyApp Health Check",
                DateTimeOffset.UtcNow,
                stopwatch.Elapsed,
                "EastUS",
                success,
                message);
        }
    }
}
```

## Sampling and Cost Optimization

### Adaptive Sampling

```csharp
builder.Services.AddApplicationInsightsTelemetry(options =>
{
    // Adaptive sampling (default)
    options.EnableAdaptiveSampling = true;
    
    // Target 5 requests per second
    options.AdaptiveSamplingTargetTelemetryItemsPerSecond = 5;
});
```

**How Sampling Works:**
- Keeps important events (errors, exceptions)
- Samples successful requests
- Maintains statistical accuracy
- Reduces costs

### Fixed-Rate Sampling

```csharp
builder.Services.Configure<TelemetryConfiguration>(config =>
{
    var builder = config.DefaultTelemetrySink.TelemetryProcessorChainBuilder;
    
    // Sample 25% of telemetry
    builder.UseSampling(25);
    
    builder.Build();
});
```

### Filtering Telemetry

```csharp
public class FilterHealthCheckTelemetry : ITelemetryProcessor
{
    private readonly ITelemetryProcessor _next;

    public FilterHealthCheckTelemetry(ITelemetryProcessor next)
    {
        _next = next;
    }

    public void Process(ITelemetry item)
    {
        // Filter out health check requests
        if (item is RequestTelemetry request && 
            request.Url.AbsolutePath.Contains("/health"))
        {
            return; // Don't send to Application Insights
        }

        _next.Process(item);
    }
}

// Register processor
builder.Services.AddApplicationInsightsTelemetryProcessor<FilterHealthCheckTelemetry>();
```
