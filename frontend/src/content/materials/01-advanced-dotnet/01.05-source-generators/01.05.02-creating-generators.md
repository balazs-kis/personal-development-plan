# Lesson 2: Creating Your First Generator

## Learning Objectives

By the end of this lesson, you will be able to:
- Set up a source generator project in Visual Studio or Rider
- Create a basic incremental source generator
- Use syntax providers to filter and transform code
- Generate C# code based on attributes or code patterns
- Debug and test source generators
- Package and distribute generators as NuGet packages
- Apply best practices for generator performance

## Key Concepts Summary

### Project Setup

#### 1. Create the Generator Project

```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFramework>netstandard2.0</TargetFramework>
    <LangVersion>latest</LangVersion>
    <EnforceExtendedAnalyzerRules>true</EnforceExtendedAnalyzerRules>
    <IsRoslynComponent>true</IsRoslynComponent>
  </PropertyGroup>

  <ItemGroup>
    <!-- Roslyn APIs -->
    <PackageReference Include="Microsoft.CodeAnalysis.CSharp" Version="4.3.0" PrivateAssets="all" />
    <PackageReference Include="Microsoft.CodeAnalysis.Analyzers" Version="3.3.3" PrivateAssets="all" />
  </ItemGroup>
</Project>
```

**Important:**
- Target `netstandard2.0` (required for generator compatibility)
- Set `PrivateAssets="all"` on Roslyn packages
- Use `EnforceExtendedAnalyzerRules` for better diagnostics

#### 2. Reference the Generator

```xml
<!-- In the consuming project -->
<ItemGroup>
  <ProjectReference Include="..\MyGenerator\MyGenerator.csproj"
                    OutputItemType="Analyzer"
                    ReferenceOutputAssembly="false" />
</ItemGroup>
```

**Key Properties:**
- `OutputItemType="Analyzer"` - Treats it as a generator
- `ReferenceOutputAssembly="false"` - Don't reference the DLL

### Building an Incremental Generator

#### Step 1: Create the Generator Class

```csharp
using Microsoft.CodeAnalysis;

[Generator]
public class AutoNotifyGenerator : IIncrementalGenerator
{
    public void Initialize(IncrementalGeneratorInitializationContext context)
    {
        // Build the pipeline here
    }
}
```

**Key Points:**
- Apply `[Generator]` attribute
- Implement `IIncrementalGenerator` (not `ISourceGenerator`)
- All logic goes in `Initialize`

#### Step 2: Create a Syntax Provider

```csharp
public void Initialize(IncrementalGeneratorInitializationContext context)
{
    // Filter: Find classes with the AutoNotify attribute
    var classDeclarations = context.SyntaxProvider
        .CreateSyntaxProvider(
            predicate: static (node, _) => IsSyntaxTargetForGeneration(node),
            transform: static (ctx, _) => GetSemanticTargetForGeneration(ctx)
        )
        .Where(static m => m is not null);

    // Register the output
    context.RegisterSourceOutput(classDeclarations, 
        static (spc, source) => Execute(source, spc));
}

static bool IsSyntaxTargetForGeneration(SyntaxNode node)
{
    // Quick syntactic filter (no semantic info)
    return node is ClassDeclarationSyntax classDecl
        && classDecl.AttributeLists.Count > 0;
}

static ClassDeclarationSyntax? GetSemanticTargetForGeneration(
    GeneratorSyntaxContext context)
{
    // Detailed semantic check
    var classDecl = (ClassDeclarationSyntax)context.Node;
    
    foreach (var attributeList in classDecl.AttributeLists)
    {
        foreach (var attribute in attributeList.Attributes)
        {
            var symbol = context.SemanticModel.GetSymbolInfo(attribute).Symbol;
            if (symbol?.ContainingType.Name == "AutoNotifyAttribute")
            {
                return classDecl;
            }
        }
    }
    
    return null;
}
```

**Pipeline Stages:**

```
Input: All Syntax Nodes
    ↓ (predicate - fast filter)
Filtered: Only interesting nodes
    ↓ (transform - semantic analysis)
Enriched: Semantic information attached
    ↓ (Where - final filter)
Ready: Nodes ready for generation
    ↓ (RegisterSourceOutput)
Output: Generated code
```

#### Step 3: Use ForAttributeWithMetadataName (.NET 7+)

**Optimized approach for attribute-based generators:**

```csharp
public void Initialize(IncrementalGeneratorInitializationContext context)
{
    // More efficient than CreateSyntaxProvider for attributes
    var classDeclarations = context.SyntaxProvider
        .ForAttributeWithMetadataName(
            "MyNamespace.AutoNotifyAttribute",
            predicate: static (node, _) => node is ClassDeclarationSyntax,
            transform: static (ctx, _) => GetClassInfo(ctx)
        );

    context.RegisterSourceOutput(classDeclarations, 
        static (spc, source) => Execute(source, spc));
}
```

**Benefits:**
- Faster than manual attribute checking
- Built-in caching optimizations
- **Recommended for .NET 7+**

#### Step 4: Generate Code

```csharp
static void Execute(ClassDeclarationSyntax classDecl, SourceProductionContext context)
{
    // Extract information
    string className = classDecl.Identifier.Text;
    string namespaceName = GetNamespace(classDecl);
    
    // Build the generated code
    var source = $$"""
        namespace {{namespaceName}}
        {
            partial class {{className}}
            {
                // Generated implementation
                public event PropertyChangedEventHandler? PropertyChanged;
                
                protected void OnPropertyChanged(string propertyName)
                {
                    PropertyChanged?.Invoke(this, new PropertyChangedEventArgs(propertyName));
                }
            }
        }
        """;
    
    // Add to compilation
    context.AddSource($"{className}.g.cs", source);
}
```

**Best Practices for Code Generation:**

**1. Use Raw String Literals (C# 11)**
```csharp
var source = $$"""
    // Multi-line code generation
    // {{interpolated}} values
    """;
```

**2. Use String Builder for Complex Generation**
```csharp
var sb = new StringBuilder();
sb.AppendLine($"namespace {namespaceName}");
sb.AppendLine("{");
// ... build code
sb.AppendLine("}");
return sb.ToString();
```

**3. Consistent Formatting**
```csharp
// Add #nullable disable if needed
var source = """
    #nullable disable
    // Generated code
    #nullable restore
    """;
```

### Handling Partial Classes

Source generators work best with partial classes:

```csharp
// User writes:
[AutoNotify]
public partial class Person
{
    private string _name;
}

// Generator adds:
public partial class Person
{
    public string Name
    {
        get => _name;
        set
        {
            _name = value;
            OnPropertyChanged(nameof(Name));
        }
    }
}
```

**Why Partial:**
- Generator can't modify existing code
- Partial classes allow adding members
- Both parts compile together seamlessly

### Incremental Generator Pipeline Patterns

#### Pattern 1: Simple Attribute-Based

```csharp
var pipeline = context.SyntaxProvider
    .ForAttributeWithMetadataName("MyAttribute")
    .Select((ctx, _) => ExtractInfo(ctx));

context.RegisterSourceOutput(pipeline, Generate);
```

#### Pattern 2: Combine Multiple Sources

```csharp
var classes = context.SyntaxProvider
    .ForAttributeWithMetadataName("MyAttribute")
    .Select((ctx, _) => ExtractInfo(ctx));

var assemblyName = context.CompilationProvider
    .Select((c, _) => c.AssemblyName);

// Combine them
var combined = classes.Combine(assemblyName);

context.RegisterSourceOutput(combined, 
    (ctx, data) => Generate(data.Left, data.Right, ctx));
```

#### Pattern 3: Collect Multiple Items

```csharp
var classes = context.SyntaxProvider
    .ForAttributeWithMetadataName("MyAttribute")
    .Select((ctx, _) => ExtractInfo(ctx));

// Collect all items into a single generation
var collected = classes.Collect();

context.RegisterSourceOutput(collected,
    (ctx, items) => GenerateFromAll(items, ctx));
```

### Testing Source Generators

#### Unit Test Setup

```csharp
using Microsoft.CodeAnalysis;
using Microsoft.CodeAnalysis.CSharp;
using Xunit;

public class GeneratorTests
{
    [Fact]
    public void Generator_CreatesExpectedOutput()
    {
        // Arrange: Input code
        var source = """
            [AutoNotify]
            public partial class Person
            {
                private string _name;
            }
            """;

        // Act: Run generator
        var (diagnostics, output) = GetGeneratedOutput(source);

        // Assert: Check output
        Assert.Empty(diagnostics);
        Assert.Contains("public string Name", output);
        Assert.Contains("OnPropertyChanged", output);
    }

    static (ImmutableArray<Diagnostic>, string) GetGeneratedOutput(string source)
    {
        // Create compilation
        var syntaxTree = CSharpSyntaxTree.ParseText(source);
        var references = AppDomain.CurrentDomain.GetAssemblies()
            .Where(a => !a.IsDynamic && !string.IsNullOrEmpty(a.Location))
            .Select(a => MetadataReference.CreateFromFile(a.Location))
            .ToArray();

        var compilation = CSharpCompilation.Create("TestAssembly",
            new[] { syntaxTree },
            references,
            new CSharpCompilationOptions(OutputKind.DynamicallyLinkedLibrary));

        // Run generator
        var generator = new AutoNotifyGenerator();
        var driver = CSharpGeneratorDriver.Create(generator);
        driver = driver.RunGeneratorsAndUpdateCompilation(compilation, 
            out var outputCompilation, out var diagnostics);

        // Get generated code
        var output = driver.GetRunResult().GeneratedTrees
            .FirstOrDefault()?.GetText().ToString() ?? string.Empty;

        return (diagnostics, output);
    }
}
```

#### Testing Incremental Caching

```csharp
public void Initialize(IncrementalGeneratorInitializationContext context)
{
    var pipeline = context.SyntaxProvider
        .ForAttributeWithMetadataName("MyAttribute")
        .Select((ctx, _) => ExtractInfo(ctx))
        .WithTrackingName("ExtractInfo");  // Track this step!

    context.RegisterSourceOutput(pipeline, Generate);
}
```

**Verify Caching:**
```csharp
var driver = CSharpGeneratorDriver.Create(generator)
    .WithUpdatedAnalyzerConfigOptions(/* ... */);

// Run twice
var run1 = driver.RunGenerators(compilation);
var run2 = driver.RunGenerators(compilation);

// Check tracking
var tracking = run2.Results[0].TrackedSteps["ExtractInfo"];
// Verify steps were cached, not rerun
```

### Performance Best Practices

#### 1. Use Efficient Filtering

```csharp
❌ Slow - processes everything:
var nodes = context.SyntaxProvider.CreateSyntaxProvider(
    predicate: (node, _) => true,  // Don't do this!
    transform: (ctx, _) => ExpensiveCheck(ctx)
);

✅ Fast - filters early:
var nodes = context.SyntaxProvider.CreateSyntaxProvider(
    predicate: (node, _) => node is ClassDeclarationSyntax { AttributeLists.Count: > 0 },
    transform: (ctx, _) => CheckAttribute(ctx)  // Only runs on filtered nodes
);
```

#### 2. Avoid *Syntax APIs in Hot Paths

```csharp
❌ Slow:
context.SyntaxProvider
    .CreateSyntaxProvider(
        predicate: (node, _) => node is ClassDeclarationSyntax cls && HasAttribute(cls),
        transform: (ctx, _) => ctx.Node as ClassDeclarationSyntax  // Loses type info!
    );

✅ Fast:
context.SyntaxProvider
    .ForAttributeWithMetadataName(  // Much faster!
        "MyAttribute",
        predicate: (node, _) => node is ClassDeclarationSyntax,
        transform: GetClassInfo
    );
```

#### 3. Cache Semantic Information

```csharp
✅ Good:
static ClassInfo GetClassInfo(GeneratorAttributeSyntaxContext context)
{
    var symbol = (INamedTypeSymbol)context.TargetSymbol;
    
    // Extract all needed info here (cached)
    return new ClassInfo(
        Name: symbol.Name,
        Namespace: symbol.ContainingNamespace.ToDisplayString(),
        Properties: symbol.GetMembers().OfType<IPropertySymbol>().ToArray()
    );
}
```

#### 4. Use Value Types for Models

```csharp
// Struct = less GC pressure
readonly record struct PropertyInfo(
    string Name,
    string Type,
    bool IsReadOnly
);
```

### Packaging as NuGet

```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFramework>netstandard2.0</TargetFramework>
    
    <!-- NuGet Package Info -->
    <PackageId>MyGenerator</PackageId>
    <Version>1.0.0</Version>
    <Authors>Your Name</Authors>
    <Description>Source generator for...</Description>
    
    <!-- Important for generators -->
    <IncludeBuildOutput>false</IncludeBuildOutput>
    <GeneratePackageOnBuild>true</GeneratePackageOnBuild>
  </PropertyGroup>

  <ItemGroup>
    <PackageReference Include="Microsoft.CodeAnalysis.CSharp" Version="4.3.0" PrivateAssets="all" />
    
    <!-- Include as analyzer -->
    <None Include="$(OutputPath)\$(AssemblyName).dll" Pack="true" 
          PackagePath="analyzers/dotnet/cs" Visible="false" />
  </ItemGroup>
</Project>
```

**Install in Consumer:**
```bash
dotnet add package MyGenerator
```
