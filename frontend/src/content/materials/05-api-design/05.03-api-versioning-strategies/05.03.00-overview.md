# Chapter 5.3: API Versioning Strategies

## Overview
This chapter explores the critical topic of API versioning—how to evolve your APIs over time while maintaining backward compatibility and not breaking existing clients. You'll learn different versioning approaches, when to use each, how to manage deprecation, and how to implement versioning in ASP.NET Core.

## Key Concepts
- **URL Path Versioning:** version as part of the URL path (e.g., `/api/v1/products`).
- **Header-Based Versioning:** version specified in custom or standard headers.
- **Query Parameter Versioning:** version as a query string parameter.
- **Semantic Versioning for APIs:** applying SemVer principles to API contracts.
- **Deprecation and Sunset Policies:** managing the lifecycle of old API versions.
