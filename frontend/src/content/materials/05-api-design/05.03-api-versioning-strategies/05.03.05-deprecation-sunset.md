# Lesson 5: Deprecation and Sunset Policies

## Learning Objectives

By the end of this lesson, you will be able to:
- Plan and communicate API deprecation
- Implement sunset policies
- Support multiple API versions simultaneously
- Migrate clients to new versions
- Gracefully retire old API versions

---

## Introduction

APIs must evolve, but removing old versions can break existing clients. A well-planned deprecation and sunset policy communicates changes early, provides migration time, and ensures a smooth transition. This lesson covers how to deprecate features, communicate timelines, support parallel versions, and finally retire old APIs responsibly.

## Key Concepts Summary

### Deprecation Timeline

```
Deprecation Lifecycle:

Phase 1: ACTIVE (Recommended)
├─ Fully supported
├─ Bug fixes and features
└─ Actively maintained

Phase 2: DEPRECATED (Not Recommended)
├─ Still functional
├─ Bug fixes only (security critical)
├─ No new features
├─ Deprecation warnings
├─ Migration guide available
└─ Sunset date announced (typically 6-12 months)

Phase 3: SUNSET (Removed)
├─ API no longer available
├─ Returns 410 Gone or redirect
└─ Clients must upgrade

Typical timeline:
Day 0: Announce deprecation
Day 0-30: Grace period (can be short for internal APIs)
Day 30-180: Migration period (6 months typical for public APIs)
Day 180+: Sunset (remove old version)
```

### Deprecation Headers

```csharp
// Middleware to add deprecation headers
public class DeprecationHeaderMiddleware
{
    private readonly RequestDelegate _next;
    
    public DeprecationHeaderMiddleware(RequestDelegate next)
    {
        _next = next;
    }
    
    public async Task InvokeAsync(HttpContext context)
    {
        var endpoint = context.GetEndpoint();
        var apiVersion = endpoint?.Metadata.GetMetadata<ApiVersionMetadata>();
        
        if (apiVersion != null)
        {
            var version = apiVersion.ApiVersions.FirstOrDefault();
            
            // Check if version is deprecated
            if (IsDeprecated(version))
            {
                // RFC 8594: Sunset header
                context.Response.Headers.Add("Sunset", 
                    GetSunsetDate(version).ToString("R")); // RFC 1123 format
                
                // Deprecation header (draft RFC)
                context.Response.Headers.Add("Deprecation", "true");
                
                // Link to migration guide
                context.Response.Headers.Add("Link", 
                    "</docs/migration/v1-to-v2>; rel=\"deprecation\"; type=\"text/html\"");
                
                // Custom warning header
                context.Response.Headers.Add("X-API-Warn", 
                    $"API version {version} is deprecated. Please migrate to v2 by 2024-12-31.");
            }
        }
        
        await _next(context);
    }
    
    private bool IsDeprecated(ApiVersion? version)
    {
        // Check against deprecation list
        var deprecatedVersions = new[] { "1.0", "1.1" };
        return deprecatedVersions.Contains(version?.ToString());
    }
    
    private DateTime GetSunsetDate(ApiVersion? version)
    {
        // Return sunset date for version
        return version?.ToString() switch
        {
            "1.0" => new DateTime(2024, 12, 31),
            "1.1" => new DateTime(2025, 06, 30),
            _ => DateTime.MaxValue
        };
    }
}

// Register middleware
app.UseMiddleware<DeprecationHeaderMiddleware>();

// Example response:
HTTP/1.1 200 OK
Sunset: Fri, 31 Dec 2024 23:59:59 GMT
Deprecation: true
Link: </docs/migration/v1-to-v2>; rel="deprecation"
X-API-Warn: API version 1.0 is deprecated. Please migrate to v2 by 2024-12-31.
```

### Deprecation Annotation

```csharp
// Mark deprecated endpoints
[ApiController]
[Route("api/v{version:apiVersion}/products")]
[ApiVersion("1.0", Deprecated = true)]  // Mark as deprecated
[ApiVersion("2.0")]  // Current version
public class ProductsController : ControllerBase
{
    // Deprecated endpoint
    [MapToApiVersion("1.0")]
    [HttpGet]
    [Obsolete("This endpoint is deprecated. Use v2 instead. Will be removed after 2024-12-31.")]
    public ActionResult<IEnumerable<ProductV1Dto>> GetProductsV1()
    {
        // Log usage of deprecated endpoint
        _logger.LogWarning("Deprecated API v1.0 used: GET /products");
        
        // Still functional but deprecated
        var products = _productService.GetAllProducts();
        return Ok(products.Select(MapToV1Dto));
    }
    
    // Current endpoint
    [MapToApiVersion("2.0")]
    [HttpGet]
    public ActionResult<ProductsV2Response> GetProductsV2(
        [FromQuery] string? category = null,
        [FromQuery] int page = 1,
        [FromQuery] int pageSize = 20)
    {
        var products = _productService.GetProducts(category, page, pageSize);
        return Ok(new ProductsV2Response
        {
            Data = products.Select(MapToV2Dto).ToList(),
            Pagination = new { page, pageSize, total = _productService.GetCount() }
        });
    }
}
```

### Monitoring Deprecated API Usage

```csharp
// Track which clients are still using deprecated versions
public class DeprecatedApiUsageMiddleware
{
    private readonly RequestDelegate _next;
    private readonly ILogger<DeprecatedApiUsageMiddleware> _logger;
    private readonly IDeprecationTracker _tracker;
    
    public DeprecatedApiUsageMiddleware(
        RequestDelegate next,
        ILogger<DeprecatedApiUsageMiddleware> logger,
        IDeprecationTracker tracker)
    {
        _next = next;
        _logger = logger;
        _tracker = tracker;
    }
    
    public async Task InvokeAsync(HttpContext context)
    {
        var endpoint = context.GetEndpoint();
        var apiVersion = endpoint?.Metadata.GetMetadata<ApiVersionMetadata>();
        
        if (apiVersion != null && IsDeprecated(apiVersion))
        {
            var usage = new DeprecatedApiUsage
            {
                Version = apiVersion.ApiVersions.FirstOrDefault()?.ToString(),
                Endpoint = $"{context.Request.Method} {context.Request.Path}",
                ClientId = GetClientIdentifier(context),
                UserAgent = context.Request.Headers["User-Agent"].ToString(),
                Timestamp = DateTime.UtcNow,
                IpAddress = context.Connection.RemoteIpAddress?.ToString()
            };
            
            // Track usage
            await _tracker.TrackAsync(usage);
            
            // Log warning
            _logger.LogWarning(
                "Deprecated API v{Version} used by client {ClientId} at {Endpoint}",
                usage.Version,
                usage.ClientId,
                usage.Endpoint);
        }
        
        await _next(context);
    }
    
    private string GetClientIdentifier(HttpContext context)
    {
        // Try to identify client (API key, OAuth client ID, etc.)
        if (context.Request.Headers.TryGetValue("X-API-Key", out var apiKey))
            return $"ApiKey:{apiKey}";
        
        if (context.User.Identity?.IsAuthenticated == true)
            return $"User:{context.User.Identity.Name}";
        
        return "Anonymous";
    }
}

// Generate reports of deprecated API usage
public class DeprecationReportService
{
    public async Task<DeprecationReport> GenerateReportAsync(string version)
    {
        var usages = await _tracker.GetUsagesAsync(version, DateTime.UtcNow.AddDays(-30));
        
        return new DeprecationReport
        {
            Version = version,
            TotalCalls = usages.Count(),
            UniqueClients = usages.Select(u => u.ClientId).Distinct().Count(),
            MostActiveClients = usages
                .GroupBy(u => u.ClientId)
                .OrderByDescending(g => g.Count())
                .Take(10)
                .Select(g => new { ClientId = g.Key, CallCount = g.Count() })
                .ToList(),
            EndpointsUsed = usages
                .GroupBy(u => u.Endpoint)
                .Select(g => new { Endpoint = g.Key, CallCount = g.Count() })
                .OrderByDescending(x => x.CallCount)
                .ToList()
        };
    }
}
```

### Communication Strategy

```csharp
// Email notification service for deprecation
public class DeprecationNotificationService
{
    private readonly IEmailService _emailService;
    private readonly IDeprecationTracker _tracker;
    
    public async Task NotifyClientsAsync(string deprecatedVersion, DateTime sunsetDate)
    {
        // Get all clients using deprecated version
        var usages = await _tracker.GetUsagesAsync(deprecatedVersion, DateTime.UtcNow.AddDays(-90));
        var clients = usages.Select(u => u.ClientId).Distinct();
        
        foreach (var clientId in clients)
        {
            var clientInfo = await _clientService.GetClientInfo(clientId);
            
            if (clientInfo?.Email != null)
            {
                await _emailService.SendAsync(new Email
                {
                    To = clientInfo.Email,
                    Subject = $"Action Required: API v{deprecatedVersion} Deprecation Notice",
                    Body = GenerateDeprecationEmail(deprecatedVersion, sunsetDate, clientInfo)
                });
            }
        }
    }
    
    private string GenerateDeprecationEmail(string version, DateTime sunsetDate, ClientInfo client)
    {
        return $@"
Dear {client.Name},

This is an important notice about our API.

API Version {version} has been deprecated and will be sunset on {sunsetDate:yyyy-MM-dd}.

What this means:
- The API version you're currently using will stop working after the sunset date

- No new features will be added to v{version}
```

### Migration Guide

````markdown
# Migration Guide: API v1.0 to v2.0

## Overview

API v1.0 will be sunset on December 31, 2024. This guide helps you migrate to v2.0.

## Timeline

- **September 1, 2024**: v1.0 deprecated, v2.0 generally available
- **December 31, 2024**: v1.0 sunset (removed)

## Breaking Changes

### 1. Pagination Required

**v1.0:**
```http
GET /api/v1/products
```

**v2.0:**
```http
GET /api/v2/products?page=1&pageSize=20
```

### 2. Product ID Changed from int to GUID

**v1.0:**
```json
{
  "id": 123,
  "name": "Product"
}
```

**v2.0:**
```json
{
  "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "name": "Product"
}
```

### 3. Category Required

**v1.0 (optional):**
```json
{
  "name": "Product",
  "price": 29.99
}
```

**v2.0 (required):**
```json
{
  "name": "Product",
  "price": 29.99,
  "category": "Electronics"
}
```

### Step 1: Update Base URL
Change from `https://api.example.com/v1` to `https://api.example.com/v2`

var productId = 123;
````

### Graceful Shutdown

```csharp
// After sunset date, return 410 Gone
public class SunsetEnforcementMiddleware
{
    private readonly RequestDelegate _next;
    
    public async Task InvokeAsync(HttpContext context)
    {
        var endpoint = context.GetEndpoint();
        var apiVersion = endpoint?.Metadata.GetMetadata<ApiVersionMetadata>();
        
        if (apiVersion != null)
        {
            var version = apiVersion.ApiVersions.FirstOrDefault();
            
            if (IsSunset(version))
            {
                context.Response.StatusCode = 410; // Gone
                context.Response.ContentType = "application/json";
                
                await context.Response.WriteAsJsonAsync(new
                {
                    error = "ApiVersionSunset",
                    message = $"API version {version} has been sunset as of {GetSunsetDate(version):yyyy-MM-dd}.",
                    sunsetDate = GetSunsetDate(version),
                    documentation = "https://api.example.com/docs/migration",
                    supportedVersions = new[] { "2.0", "2.1" }
                });
                
                return; // Don't call next middleware
            }
        }
        
        await _next(context);
    }
    
    private bool IsSunset(ApiVersion? version)
    {
        var sunsetDate = GetSunsetDate(version);
        return DateTime.UtcNow > sunsetDate;
    }
    
    private DateTime GetSunsetDate(ApiVersion? version)
    {
        return version?.ToString() switch
        {
            "1.0" => new DateTime(2024, 12, 31),
            "1.1" => new DateTime(2025, 06, 30),
            _ => DateTime.MaxValue
        };
    }
}

// Example response after sunset:
// HTTP 410 Gone
{
  "error": "ApiVersionSunset",
  "message": "API version 1.0 has been sunset as of 2024-12-31.",
  "sunsetDate": "2024-12-31T00:00:00Z",
  "documentation": "https://api.example.com/docs/migration",
  "supportedVersions": ["2.0", "2.1"]
}
```

### Best Practices Checklist

```

📋 Planning Phase
[ ] Identify breaking changes
[ ] Set sunset timeline (6-12 months for public APIs)
[ ] Create migration guide
[ ] Update documentation
[ ] Plan communication strategy
[ ] Identify affected clients
[ ] Prepare support resources

📋 Announcement Phase
[ ] Add deprecation headers to responses

[ ] Send email to API consumers

[ ] Update status page
[ ] Add warning to developer portal
[ ] Update SDKs with deprecation warnings

📋 Monitoring Phase
[ ] Track deprecated API usage
[ ] Identify clients still using old version
[ ] Send reminders (90 days, 30 days, 7 days before sunset)
[ ] Reach out to heavy users personally
[ ] Monitor support tickets
[ ] Generate weekly usage reports

📋 Migration Phase
[ ] Provide sandbox for testing
[ ] Offer migration support
[ ] Share code examples
[ ] Host migration webinar/Q&A
[ ] Update SDKs and client libraries
[ ] Monitor error rates
[ ] Provide migration tools/scripts

📋 Sunset Phase
[ ] Final reminder 7 days before
[ ] Disable old version

[ ] Redirect to migration guide
[ ] Monitor support tickets
[ ] Document lessons learned

📋 Post-Sunset
[ ] Remove deprecated code
[ ] Archive documentation
[ ] Update developer portal
[ ] Send "thank you for migrating" email
[ ] Analyze migration success
[ ] Update internal processes
```

### Client SDK Deprecation Warnings

```csharp
// SDK with built-in deprecation warnings

public class ProductsApiClient
{
    private readonly HttpClient _client;
    private readonly string _version;
    private static bool _deprecationWarningShown = false;
    
    public ProductsApiClient(HttpClient client, string version = "2.0")
    {
        _client = client;
        _version = version;
        
        // Warn about deprecated versions (once per app lifetime)
        if (version == "1.0" && !_deprecationWarningShown)
        {
            Console.ForegroundColor = ConsoleColor.Yellow;
            Console.WriteLine("⚠️ WARNING: API v1.0 is deprecated and will be sunset on 2024-12-31.");
            Console.WriteLine("   Please upgrade to v2.0: https://docs.example.com/migration");
            Console.ResetColor();
            _deprecationWarningShown = true;
        }
    }
    
    public async Task<List<Product>> GetProducts()
    {
        var request = new HttpRequestMessage(HttpMethod.Get, "/api/products");
        request.Headers.Add("X-API-Version", _version);
        
        var response = await _client.SendAsync(request);
        
        // Check for deprecation headers
        if (response.Headers.TryGetValues("Deprecation", out var deprecation) && 
            deprecation.Contains("true"))
        {
            if (response.Headers.TryGetValues("X-API-Warn", out var warnings))
            {
                Console.WriteLine($"⚠️ {warnings.First()}");
            }
            
            if (response.Headers.TryGetValues("Sunset", out var sunset))
            {
                Console.WriteLine($"🌅 API sunset date: {sunset.First()}");
            }
        }
        
        return await response.Content.ReadFromJsonAsync<List<Product>>();
    }
}

// Usage in client application:
var client = new ProductsApiClient(httpClient, version: "1.0");
// Output:
```

### Gradual Rollout of New Versions

```csharp
// Feature flags for gradual version rollout

public class ApiVersionFeatureFlags
{
    private readonly IFeatureFlagService _flags;
    
    public async Task<bool> IsVersionEnabledForClient(string version, string clientId)
    {
        // Gradually enable v3.0 for clients
        if (version == "3.0")
        {
            // Check feature flag
            return await _flags.IsEnabledAsync($"api_version_3_rollout", new
            {
                clientId = clientId
            });
        }
        
        return true;  // Other versions always enabled
    }
}

// Middleware to enforce gradual rollout
public class ApiVersionRolloutMiddleware
{
    private readonly RequestDelegate _next;
    private readonly ApiVersionFeatureFlags _flags;
    
    public async Task InvokeAsync(HttpContext context)
    {
        var endpoint = context.GetEndpoint();
        var apiVersion = endpoint?.Metadata.GetMetadata<ApiVersionMetadata>();
        
        if (apiVersion != null)
        {
            var version = apiVersion.ApiVersions.FirstOrDefault()?.ToString();
            var clientId = GetClientId(context);
            
            if (!await _flags.IsVersionEnabledForClient(version, clientId))
            {
                context.Response.StatusCode = 403;
                await context.Response.WriteAsJsonAsync(new
                {
                    error = "VersionNotAvailable",
                    message = $"API version {version} is not yet available for your account",
                    currentVersion = "2.0",
                    betaProgram = "https://api.example.com/beta"
                });
                
                return;
            }
        }
        
        await _next(context);
    }
}

// Rollout phases:
// Phase 1: Internal teams only (0-10%)
// Phase 2: Beta participants (10-25%)
// Phase 3: Gradual rollout (25-50-75-100%)
// Phase 4: Generally available
```


4. **Implement deprecation**
   ```csharp
   // Add middleware for deprecation headers
   app.UseMiddleware<DeprecationHeaderMiddleware>();
   
   // Mark controller as deprecated
   [ApiVersion("1.0", Deprecated = true)]
   [ApiController]
   [Route("api/v{version:apiVersion}/products")]
   public class ProductsV1Controller : ControllerBase
   {
       [HttpGet]
       public ActionResult GetProducts()
       {
           // Log usage for tracking
           _logger.LogWarning("Deprecated API v1.0 called by client {ClientId}", 
               GetClientId());
           
           // Return data with deprecation headers
           return Ok(_service.GetProducts());
       }
   }
   
   // Track usage in Application Insights or similar
   _telemetry.TrackEvent("DeprecatedApiUsage", new Dictionary<string, string>
   {
       ["Version"] = "1.0",
       ["Endpoint"] = "/api/v1/products",
       ["ClientId"] = clientId,
       ["UserAgent"] = userAgent
   });
   ```

## Self-Check Questions

1. **What's the difference between deprecation and sunset?**
   - Deprecation: API version marked as not recommended, but still functional
   - Sunset: API version completely disabled, returns 410 Gone
   - Deprecation is the warning period, sunset is the end

2. **How long should the deprecation period last?**
   - Public APIs: 6-12 months (industry standard)
   - Internal APIs: 1-3 months (shorter, known clients)
   - Enterprise APIs: 12-24 months (long migration cycles)
   - Consider: client diversity, migration complexity, business impact

3. **What headers should you use for deprecation?**
   - `Sunset`: RFC 8594, date when API will be removed
   - `Deprecation`: Indicates API is deprecated (draft RFC)
   - `Link`: Link to deprecation policy/migration guide
   - `X-API-Warn`: Custom warning message
   - `api-deprecated-versions`: Which versions are deprecated

4. **How do you track usage of deprecated APIs?**
   - Middleware logs every request to deprecated version
   - Track: ClientId, endpoint, timestamp, user agent
   - Generate reports: usage over time, clients still using old version
   - Application Insights, CloudWatch, or custom telemetry
   - Create dashboards for stakeholders

5. **What should happen when a sunset API is called?**
   - Return 410 Gone (permanent removal)
   - Include error message with sunset date
   - Provide migration guide link
   - List currently supported versions
   - Offer support contact
   - DO NOT return 404 (implies might come back)

6. **How should you communicate deprecation to API consumers?**
   - Email notifications (multiple reminders)
   - Blog posts and developer newsletters
   - Response headers on every request
   - Developer portal banners
   - SDK warnings
   - Documentation updates
   - Support articles/FAQs
   - Personal outreach to high-volume users
