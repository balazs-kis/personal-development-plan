# Chapter 5.6: GraphQL in .NET

## Overview
This chapter teaches you how to build GraphQL APIs in .NET using Hot Chocolate, the leading GraphQL server for .NET. You'll learn to define schemas using annotations or code-first approaches, implement resolvers for queries and mutations, add filtering and sorting capabilities, implement efficient cursor-based pagination, and build real-time features with subscriptions.

## Key Concepts
- **Hot Chocolate Schema Definition:** creating GraphQL schemas in .NET using annotations and code-first approach.
- **Query and Mutation Resolvers:** implementing data fetching and modification logic.
- **Filtering and Sorting:** built-in projections for flexible data querying.
- **Cursor-Based Pagination:** implementing Relay-style pagination for efficient data loading.
- **Subscriptions:** real-time updates using WebSockets and GraphQL subscriptions.
