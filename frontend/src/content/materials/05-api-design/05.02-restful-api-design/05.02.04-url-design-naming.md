# Lesson 4: URL Design and Naming Conventions

## Learning Objectives

By the end of this lesson, you will be able to:
- Design clean, intuitive URL structures
- Apply consistent naming conventions
- Handle special cases (filtering, searching, pagination)
- Avoid common URL design anti-patterns
- Create URL hierarchies that reflect domain relationships

---

## Introduction

URLs are the interface to your API's resources. Well-designed URLs are intuitive, consistent, and self-documenting. They should clearly communicate what resource is being accessed and follow predictable patterns. Poor URL design makes APIs difficult to use and maintain.

## Key Concepts Summary

### URL Structure Fundamentals

```
https://api.example.com/v1/customers/123/orders/456

Protocol: https://
Host: api.example.com
Version: /v1
Resource path: /customers/123/orders/456
    Collection: customers
    ID: 123
    Nested collection: orders
    Nested ID: 456

Good URL patterns:
✅ /api/users
✅ /api/users/123
✅ /api/users/123/orders
✅ /api/orders/456
✅ /api/products?category=electronics&sort=price

Bad URL patterns:
❌ /api/getUsers
❌ /api/user/123
❌ /api/users_orders/123
❌ /api/Products
❌ /api/user-management-service
```

### Naming Conventions

```csharp
[ApiController]
[Route("api/[controller]")]
public class CustomersController : ControllerBase
{
    // ✅ Good: lowercase, plural nouns
    // GET /api/customers
    
    // ❌ Bad examples to avoid:
    // GET /api/Customers           (uppercase)
    // GET /api/customer            (singular)
    // GET /api/getCustomers        (verb in URL)
    // GET /api/customer-list       (non-standard plural)
}

// Naming rules:
// 1. Use lowercase (or kebab-case for multi-word)
// 2. Use plural nouns for collections
// 3. Use concrete names, not abstract
// 4. Use nouns, not verbs
// 5. Be consistent

// Collection naming examples:
[Route("api/products")]          // ✅ Simple plural
[Route("api/order-items")]       // ✅ Kebab-case for compound words
[Route("api/categories")]        // ✅ Irregular plural
[Route("api/people")]            // ✅ Correct irregular plural (not "persons")

// Bad examples:
[Route("api/product")]           // ❌ Singular
[Route("api/Product")]           // ❌ Capitalized
[Route("api/order_items")]       // ❌ Snake_case (not RESTful convention)
[Route("api/getProducts")]       // ❌ Verb in URL
```

### Resource Hierarchy

```csharp
[ApiController]
[Route("api")]
public class ResourceHierarchyController : ControllerBase
{
    // One-to-many: users have orders
    [HttpGet("users/{userId}/orders")]
    public ActionResult<List<OrderDto>> GetUserOrders(int userId)
    {
        // GET /api/users/123/orders
        var orders = _orderService.GetByUserId(userId);
        return Ok(orders);
    }
    
    [HttpGet("users/{userId}/orders/{orderId}")]
    public ActionResult<OrderDto> GetUserOrder(int userId, int orderId)
    {
        // GET /api/users/123/orders/456
        var order = _orderService.GetById(orderId);
        
        // Verify order belongs to user
        if (order?.UserId != userId)
            return NotFound();
        
        return Ok(order);
    }
    
    // Alternative: flat access when resource can be independently identified
    [HttpGet("orders/{orderId}")]
    public ActionResult<OrderDto> GetOrder(int orderId)
    {
        // GET /api/orders/456
        // Use when order ID uniquely identifies the order
        var order = _orderService.GetById(orderId);
        return order == null ? NotFound() : Ok(order);
    }
    
    // Nested resources: order line items
    [HttpGet("orders/{orderId}/items")]
    public ActionResult<List<OrderItemDto>> GetOrderItems(int orderId)
    {
        // GET /api/orders/456/items
        // Items are part of the order, can't exist independently
        if (!_orderService.Exists(orderId))
            return NotFound();
        
        var items = _orderService.GetItems(orderId);
        return Ok(items);
    }
    
    [HttpPost("orders/{orderId}/items")]
    public ActionResult<OrderItemDto> AddOrderItem(
        int orderId,
        [FromBody] AddOrderItemRequest request)
    {
        // POST /api/orders/456/items
        if (!_orderService.Exists(orderId))
            return NotFound();
        
        var item = _orderService.AddItem(orderId, request);
        return CreatedAtAction(nameof(GetOrderItem), 
            new { orderId, itemId = item.Id }, item);
    }
    
    [HttpGet("orders/{orderId}/items/{itemId}")]
    public ActionResult<OrderItemDto> GetOrderItem(int orderId, int itemId)
    {
        // GET /api/orders/456/items/789
        var item = _orderService.GetItem(orderId, itemId);
        return item == null ? NotFound() : Ok(item);
    }
}

// When to nest:
// ✅ Child can't exist without parent (order-items)
// ✅ Child is always accessed through parent
// ✅ Nesting adds clarity to relationship

// When NOT to nest:
// ❌ Nesting is too deep (more than 2-3 levels)
// ❌ Child can exist independently
// ❌ Multiple paths to same resource create confusion
```

### Query Parameters

```csharp
[ApiController]
[Route("api/products")]
public class ProductsController : ControllerBase
{
    // Filtering
    [HttpGet]
    public ActionResult<List<ProductDto>> GetProducts(
        [FromQuery] string? category = null,
        [FromQuery] decimal? minPrice = null,
        [FromQuery] decimal? maxPrice = null,
        [FromQuery] bool? inStock = null)
    {
        // GET /api/products?category=electronics&minPrice=100&maxPrice=500&inStock=true
        
        var query = _repository.GetAll();
        
        if (category != null)
            query = query.Where(p => p.Category == category);
        
        if (minPrice.HasValue)
            query = query.Where(p => p.Price >= minPrice.Value);
        
        if (maxPrice.HasValue)
            query = query.Where(p => p.Price <= maxPrice.Value);
        
        if (inStock.HasValue)
            query = query.Where(p => p.InStock == inStock.Value);
        
        return Ok(query.ToList());
    }
    
    // Sorting
    [HttpGet]
    public ActionResult<List<ProductDto>> GetProductsSorted(
        [FromQuery] string? sortBy = "name",
        [FromQuery] string? order = "asc")
    {
        // GET /api/products?sortBy=price&order=desc
        
        var query = _repository.GetAll();
        
        query = sortBy?.ToLower() switch
        {
            "price" => order == "desc" 
                ? query.OrderByDescending(p => p.Price) 
                : query.OrderBy(p => p.Price),
            "name" => order == "desc" 
                ? query.OrderByDescending(p => p.Name) 
                : query.OrderBy(p => p.Name),
            _ => query.OrderBy(p => p.Name)
        };
        
        return Ok(query.ToList());
    }
    
    // Pagination
    [HttpGet]
    public ActionResult<ProductListResponse> GetProductsPaged(
        [FromQuery] int page = 1,
        [FromQuery] int pageSize = 20)
    {
        // GET /api/products?page=2&pageSize=50
        
        if (page < 1) page = 1;
        if (pageSize < 1 || pageSize > 100) pageSize = 20;
        
        var total = _repository.Count();
        var products = _repository
            .GetAll()
            .Skip((page - 1) * pageSize)
            .Take(pageSize)
            .ToList();
        
        var response = new ProductListResponse
        {
            Items = products,
            Page = page,
            PageSize = pageSize,
            TotalCount = total,
            TotalPages = (int)Math.Ceiling(total / (double)pageSize)
        };
        
        return Ok(response);
    }
    
    // Field selection (sparse fieldsets)
    [HttpGet("{id}")]
    public ActionResult GetProduct(
        int id,
        [FromQuery] string? fields = null)
    {
        // GET /api/products/123?fields=id,name,price
        
        var product = _repository.GetById(id);
        
        if (product == null)
            return NotFound();
        
        if (string.IsNullOrEmpty(fields))
            return Ok(product);
        
        // Return only requested fields
        var fieldList = fields.Split(',').Select(f => f.Trim()).ToList();
        var result = new Dictionary<string, object>();
        
        foreach (var field in fieldList)
        {
            var prop = product.GetType().GetProperty(field,
                BindingFlags.IgnoreCase | BindingFlags.Public | BindingFlags.Instance);
            
            if (prop != null)
                result[field] = prop.GetValue(product);
        }
        
        return Ok(result);
    }
    
    // Search
    [HttpGet("search")]
    public ActionResult<List<ProductDto>> SearchProducts(
        [FromQuery] string q)
    {
        // GET /api/products/search?q=laptop
        
        if (string.IsNullOrWhiteSpace(q))
            return BadRequest("Search query is required");
        
        var results = _repository.Search(q);
        return Ok(results);
    }
}

// Query parameter conventions:
// ?category=value          Filtering
// ?sortBy=field&order=asc  Sorting
// ?page=1&pageSize=20      Pagination
// ?fields=id,name          Field selection
// ?q=searchterm            Search
// ?filter=complex          Complex filters (OData style)
```

### Actions and Non-Resource Operations

```csharp
[ApiController]
[Route("api")]
public class ActionsController : ControllerBase
{
    // Controller actions (non-CRUD operations)
    // Use verbs in URL for actions
    
    [HttpPost("orders/{id}/cancel")]
    public ActionResult CancelOrder(int id)
    {
        // POST /api/orders/123/cancel
        var result = _orderService.Cancel(id);
        return result.Success ? NoContent() : BadRequest(result.Error);
    }
    
    [HttpPost("orders/{id}/ship")]
    public ActionResult ShipOrder(int id, [FromBody] ShippingDetails details)
    {
        // POST /api/orders/123/ship
        var result = _orderService.Ship(id, details);
        return result.Success ? Ok(result.Data) : BadRequest(result.Error);
    }
    
    [HttpPost("users/{id}/activate")]
    public ActionResult ActivateUser(int id)
    {
        // POST /api/users/123/activate
        _userService.Activate(id);
        return NoContent();
    }
    
    [HttpPost("users/{id}/reset-password")]
    public ActionResult ResetPassword(int id)
    {
        // POST /api/users/123/reset-password
        _userService.ResetPassword(id);
        return NoContent();
    }
    
    // Batch operations
    [HttpPost("products/bulk")]
    public ActionResult<BulkOperationResult> BulkCreateProducts(
        [FromBody] List<CreateProductRequest> products)
    {
        // POST /api/products/bulk
        var result = _productService.BulkCreate(products);
        return Ok(result);
    }
    
    [HttpDelete("products/bulk")]
    public ActionResult BulkDeleteProducts([FromBody] List<int> ids)
    {
        // DELETE /api/products/bulk
        // Body: [1, 2, 3, 4, 5]
        _productService.BulkDelete(ids);
        return NoContent();
    }
    
    // Search as action (alternative to query params)
    [HttpPost("products/search")]
    public ActionResult<List<ProductDto>> SearchProducts(
        [FromBody] ProductSearchCriteria criteria)
    {
        // POST /api/products/search
        // Use POST when search criteria is complex
        var results = _productService.Search(criteria);
        return Ok(results);
    }
}

// Action URL patterns:
// POST /resources/{id}/action      State transition
// POST /resources/bulk             Batch operation
// POST /resources/search           Complex search
// POST /resources/{id}/send        Trigger action

// When to use actions:
// ✅ State transitions (activate, deactivate, approve)
// ✅ Operations that don't fit CRUD (send, calculate, process)
// ✅ Batch operations
// ❌ Don't overuse; prefer standard HTTP methods when possible
```

### Anti-Patterns to Avoid

```csharp
// ❌ Bad: Verbs in URLs
[Route("api/getProducts")]
[Route("api/createOrder")]
[Route("api/deleteUser")]
// ✅ Good: Use HTTP methods
[HttpGet("api/products")]
[HttpPost("api/orders")]
[HttpDelete("api/users/{id}")]

// ❌ Bad: Inconsistent casing
[Route("api/Products")]
[Route("api/orderItems")]
[Route("api/User-Profile")]
// ✅ Good: Consistent lowercase/kebab-case
[Route("api/products")]
[Route("api/order-items")]
[Route("api/user-profiles")]

// ❌ Bad: File extensions
[Route("api/products.json")]
[Route("api/products.xml")]
// ✅ Good: Use Accept header
[HttpGet("api/products")]
// Accept: application/json

// ❌ Bad: CRUD operations in URL
[Route("api/products/create")]
[Route("api/products/update")]
[Route("api/products/delete")]
// ✅ Good: Use HTTP methods
[HttpPost("api/products")]
[HttpPut("api/products/{id}")]
[HttpDelete("api/products/{id}")]

// ❌ Bad: Too deep nesting
[Route("api/companies/{companyId}/departments/{deptId}/teams/{teamId}/members/{memberId}/tasks/{taskId}")]
// ✅ Good: Flatten
[Route("api/tasks/{taskId}")]
[Route("api/members/{memberId}/tasks")]

// ❌ Bad: Exposing implementation
[Route("api/tbl_products")]
[Route("api/product_dto")]
[Route("api/db/products")]
// ✅ Good: Hide implementation
[Route("api/products")]

// ❌ Bad: Non-standard plural forms
[Route("api/peoples")]
[Route("api/childs")]
// ✅ Good: Correct plural
[Route("api/people")]
[Route("api/children")]
```

### Advanced Query Patterns

```csharp
[ApiController]
[Route("api/products")]
public class AdvancedQueryController : ControllerBase
{
    // Complex filtering with operators
    [HttpGet]
    public ActionResult<List<ProductDto>> GetProducts(
        [FromQuery] string? name = null,           // Exact match
        [FromQuery] string? nameContains = null,   // Partial match
        [FromQuery] decimal? priceGt = null,       // Greater than
        [FromQuery] decimal? priceLt = null,       // Less than
        [FromQuery] decimal? priceGte = null,      // Greater than or equal
        [FromQuery] decimal? priceLte = null,      // Less than or equal
        [FromQuery] string? category = null,
        [FromQuery] string[]? tags = null,         // Array of tags
        [FromQuery] DateTime? createdAfter = null,
        [FromQuery] DateTime? createdBefore = null)
    {
        // GET /api/products?priceGt=10&priceLt=100&category=electronics&tags=sale&tags=featured
        
        var query = _repository.GetAll();
        
        if (name != null)
            query = query.Where(p => p.Name == name);
        
        if (nameContains != null)
            query = query.Where(p => p.Name.Contains(nameContains));
        
        if (priceGt.HasValue)
            query = query.Where(p => p.Price > priceGt.Value);
        
        if (priceLt.HasValue)
            query = query.Where(p => p.Price < priceLt.Value);
        
        if (priceGte.HasValue)
            query = query.Where(p => p.Price >= priceGte.Value);
        
        if (priceLte.HasValue)
            query = query.Where(p => p.Price <= priceLte.Value);
        
        if (category != null)
            query = query.Where(p => p.Category == category);
        
        if (tags != null && tags.Length > 0)
            query = query.Where(p => tags.All(tag => p.Tags.Contains(tag)));
        
        if (createdAfter.HasValue)
            query = query.Where(p => p.CreatedAt > createdAfter.Value);
        
        if (createdBefore.HasValue)
            query = query.Where(p => p.CreatedAt < createdBefore.Value);
        
        return Ok(query.ToList());
    }
    
    // OData-style filtering (alternative)
    [HttpGet("odata")]
    public ActionResult<List<ProductDto>> GetProductsOData([FromQuery] string? filter = null)
    {
        // GET /api/products/odata?filter=price gt 10 and price lt 100 and category eq 'electronics'
        
        var query = _repository.GetAll();
        
        if (!string.IsNullOrEmpty(filter))
        {
            query = _odataParser.ApplyFilter(query, filter);
        }
        
        return Ok(query.ToList());
    }
    
    // Range queries
    [HttpGet("range")]
    public ActionResult<List<ProductDto>> GetProductRange(
        [FromQuery] string? priceRange = null,  // Format: "10-100"
        [FromQuery] string? dateRange = null)   // Format: "2024-01-01,2024-12-31"
    {
        // GET /api/products/range?priceRange=10-100&dateRange=2024-01-01,2024-12-31
        
        var query = _repository.GetAll();
        
        if (priceRange != null)
        {
            var parts = priceRange.Split('-');
            if (parts.Length == 2 &&
                decimal.TryParse(parts[0], out var min) &&
                decimal.TryParse(parts[1], out var max))
            {
                query = query.Where(p => p.Price >= min && p.Price <= max);
            }
        }
        
        if (dateRange != null)
        {
            var parts = dateRange.Split(',');
            if (parts.Length == 2 &&
                DateTime.TryParse(parts[0], out var start) &&
                DateTime.TryParse(parts[1], out var end))
            {
                query = query.Where(p => p.CreatedAt >= start && p.CreatedAt <= end);
            }
        }
        
        return Ok(query.ToList());
    }
    
    // Include/Expand related resources
    [HttpGet("{id}")]
    public ActionResult<ProductDto> GetProduct(
        int id,
        [FromQuery] string? include = null)
    {
        // GET /api/products/123?include=reviews,manufacturer,categories
        
        var product = _productService.GetById(id);
        
        if (product == null)
            return NotFound();
        
        if (!string.IsNullOrEmpty(include))
        {
            var includes = include.Split(',').Select(i => i.Trim()).ToList();
            
            foreach (var inc in includes)
            {
                switch (inc.ToLower())
                {
                    case "reviews":
                        product.Reviews = _reviewService.GetByProductId(id);
                        break;
                    case "manufacturer":
                        product.Manufacturer = _manufacturerService.GetById(product.ManufacturerId);
                        break;
                    case "categories":
                        product.Categories = _categoryService.GetByProductId(id);
                        break;
                }
            }
        }
        
        return Ok(product);
    }
}
```

### URL Encoding and Special Characters

```csharp
// Handling special characters in URLs

[ApiController]
[Route("api")]
public class EncodingController : ControllerBase
{
    // Spaces and special chars in query params
    [HttpGet("search")]
    public ActionResult Search([FromQuery] string q)
    {
        // Client sends: GET /api/search?q=hello%20world
        // Received as: q = "hello world"
        
        var results = _searchService.Search(q);
        return Ok(results);
    }
    
    // Special chars in path segments
    [HttpGet("articles/{slug}")]
    public ActionResult GetArticle(string slug)
    {
        // Client sends: GET /api/articles/hello-world-2024
        // URL-safe slug with hyphens
        
        var article = _articleService.GetBySlug(slug);
        return article == null ? NotFound() : Ok(article);
    }
    
    // Reserved characters need encoding
    [HttpGet("tags/{tag}")]
    public ActionResult GetByTag(string tag)
    {
        // For tag "C#": GET /api/tags/C%23
        // For tag "R&D": GET /api/tags/R%26D
        // For tag "foo/bar": GET /api/tags/foo%2Fbar
        
        var items = _itemService.GetByTag(tag);
        return Ok(items);
    }
    
    // Matrix parameters (alternative to query params)
    [HttpGet("products/{filters}")]
    public ActionResult GetProductsByMatrix(string filters)
    {
        // GET /api/products/;category=electronics;price=10-100;color=red
        // Less common, but valid URL pattern
        
        var filterDict = ParseMatrixParams(filters);
        var products = _productService.GetByFilters(filterDict);
        return Ok(products);
    }
    
    private Dictionary<string, string> ParseMatrixParams(string matrixString)
    {
        return matrixString
            .Split(';', StringSplitOptions.RemoveEmptyEntries)
            .Select(s => s.Split('='))
            .Where(parts => parts.Length == 2)
            .ToDictionary(parts => parts[0], parts => parts[1]);
    }
}

// Common URL encoding:
// Space: %20 or +
// #: %23
// &: %26
// =: %3D
// /: %2F
// ?: %3F
// %: %25
```

### Pagination Patterns

```csharp
[ApiController]
[Route("api/items")]
public class PaginationController : ControllerBase
{
    // Offset-based pagination
    [HttpGet]
    public ActionResult<PagedResponse<ItemDto>> GetItems(
        [FromQuery] int page = 1,
        [FromQuery] int pageSize = 20)
    {
        // GET /api/items?page=2&pageSize=50
        
        if (page < 1) page = 1;
        if (pageSize < 1 || pageSize > 100) pageSize = 20;
        
        var items = _repository
            .GetAll()
            .Skip((page - 1) * pageSize)
            .Take(pageSize)
            .ToList();
        
        var total = _repository.Count();
        
        var response = new PagedResponse<ItemDto>
        {
            Data = items,
            Page = page,
            PageSize = pageSize,
            TotalCount = total,
            TotalPages = (int)Math.Ceiling(total / (double)pageSize),
            HasNextPage = page * pageSize < total,
            HasPreviousPage = page > 1
        };
        
        // Add Link headers
        AddPaginationLinks(response, "/api/items");
        
        return Ok(response);
    }
    
    // Cursor-based pagination (for frequently changing data)
    [HttpGet("cursor")]
    public ActionResult<CursorPagedResponse<ItemDto>> GetItemsCursor(
        [FromQuery] string? cursor = null,
        [FromQuery] int limit = 20)
    {
        // GET /api/items/cursor?cursor=eyJpZCI6MTIzfQ==&limit=20
        
        var (items, nextCursor) = _repository.GetPageByCursor(cursor, limit);
        
        var response = new CursorPagedResponse<ItemDto>
        {
            Data = items,
            NextCursor = nextCursor,
            HasMore = nextCursor != null
        };
        
        return Ok(response);
    }
    
    private void AddPaginationLinks(PagedResponse<ItemDto> response, string baseUrl)
    {
        Response.Headers.Add("X-Total-Count", response.TotalCount.ToString());
        
        var links = new List<string>();
        
        // First page
        links.Add($"<{baseUrl}?page=1&pageSize={response.PageSize}>; rel=\"first\"");
        
        // Previous page
        if (response.HasPreviousPage)
        {
            links.Add($"<{baseUrl}?page={response.Page - 1}&pageSize={response.PageSize}>; rel=\"prev\"");
        }
        
        // Next page
        if (response.HasNextPage)
        {
            links.Add($"<{baseUrl}?page={response.Page + 1}&pageSize={response.PageSize}>; rel=\"next\"");
        }
        
        // Last page
        links.Add($"<{baseUrl}?page={response.TotalPages}&pageSize={response.PageSize}>; rel=\"last\"");
        
        Response.Headers.Add("Link", string.Join(", ", links));
    }
}
```

## Practice Exercise

Design URLs for a blog API:

1. **List all posts**
   ```
   GET /api/posts?page=1&pageSize=20
   ```

2. **Get a specific post**
   ```
   GET /api/posts/{id}
   GET /api/posts/{slug}  (alternative with slug)
   ```

3. **Get comments for a post**
   ```
   GET /api/posts/{postId}/comments
   GET /api/posts/{postId}/comments?page=1&pageSize=50
   ```

4. **Create a comment on a post**
   ```
   POST /api/posts/{postId}/comments
   Body: { "content": "Great post!", "authorId": 123 }
   ```

5. **Get a specific comment**
   ```
   GET /api/comments/{id}  (flat access)
   GET /api/posts/{postId}/comments/{commentId}  (nested access)
   ```

6. **Get posts by author**
   ```
   GET /api/posts?authorId={authorId}
   GET /api/authors/{authorId}/posts  (alternative nested)
   ```

7. **Search posts**
   ```
   GET /api/posts/search?q=keyword
   GET /api/posts?q=keyword  (alternative)
   GET /api/search?type=posts&q=keyword  (global search)
   ```

8. **Publish a draft post (state transition)**
   ```
   POST /api/posts/{id}/publish
   ```

9. **Like a post (action)**
   ```
   POST /api/posts/{id}/likes
   DELETE /api/posts/{id}/likes  (unlike)
   GET /api/posts/{id}/likes  (get likes count/list)
   ```

## Self-Check Questions

1. **Should collection names be singular or plural?**
   - Always plural for collections: `/api/products`, `/api/users`
   - Singular only for singleton resources: `/api/users/123/profile`

2. **When should you nest resources vs keep them flat?**
   - Nest when: Child can't exist without parent, always accessed through parent
   - Flatten when: Resource can exist independently, nesting exceeds 2-3 levels
   - Consider offering both: `/api/posts/{postId}/comments/{id}` AND `/api/comments/{id}`

3. **How do you handle multi-word resource names?**
   - Use kebab-case: `/api/order-items`, `/api/user-profiles`
   - Be consistent throughout the API
   - Avoid: camelCase, snake_case, PascalCase in URLs

4. **Where do filtering parameters go?**
   - Query string: `/api/products?category=electronics&minPrice=100`
   - Not in path: ❌ `/api/products/electronics/minprice/100`
   - Use clear, descriptive parameter names

5. **When is it acceptable to use verbs in URLs?**
   - For controller actions/operations that don't fit CRUD
   - State transitions: `/api/orders/123/cancel`, `/api/posts/456/publish`
   - Operations: `/api/reports/generate`, `/api/cache/clear`
   - Always use POST for these actions

6. **What's wrong with `/api/getUser/123`?**
   - ❌ "get" is redundant (HTTP GET already indicates retrieval)
   - ❌ Mixes verb with noun
   - ❌ Singular "User" instead of plural
   - ✅ Should be: `GET /api/users/123`

7. **How do you handle resource versioning?**
   - URL versioning: `/api/v1/products`, `/api/v2/products`
   - Header versioning: `Accept: application/vnd.api.v2+json`
   - Query parameter: `/api/products?version=2` (less common)
