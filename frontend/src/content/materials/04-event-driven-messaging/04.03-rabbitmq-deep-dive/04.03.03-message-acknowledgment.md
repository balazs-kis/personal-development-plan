# Lesson 3: Message Acknowledgment Modes

## Learning Objectives

By the end of this lesson, you will be able to:
- Understand manual vs automatic acknowledgments
- Implement reliable message processing with acknowledgments
- Handle failures with negative acknowledgments
- Design idempotent consumers for at-least-once delivery

---

## Introduction

Message acknowledgments are RabbitMQ's mechanism for ensuring reliable delivery. Without proper acknowledgments, messages can be lost during processing failures. Understanding acknowledgment modes and implementing them correctly is essential for building robust messaging systems.

## Key Concepts Summary

### Auto-Ack vs Manual Ack

**Auto-Acknowledge (Unreliable):**
```csharp
// Message acknowledged immediately on delivery
var consumer = new EventingBasicConsumer(channel);
consumer.Received += (model, ea) =>
{
    // If this crashes, message is LOST
    ProcessMessage(ea.Body);
};

channel.BasicConsume(
    queue: "orders",
    autoAck: true,      // Dangerous!
    consumer: consumer
);
```

**Manual Acknowledge (Reliable):**
```csharp
// Consumer controls when message is acknowledged
var consumer = new EventingBasicConsumer(channel);
consumer.Received += (model, ea) =>
{
    try
    {
        ProcessMessage(ea.Body);
        
        // Success - acknowledge
        channel.BasicAck(ea.DeliveryTag, multiple: false);
    }
    catch (Exception ex)
    {
        // Failure - negative acknowledge
        channel.BasicNack(ea.DeliveryTag, multiple: false, requeue: true);
    }
};

channel.BasicConsume("orders", autoAck: false, consumer: consumer);
```

### Acknowledgment Types

**1. Basic Ack (Success):**
```csharp
// Single message
channel.BasicAck(deliveryTag, multiple: false);

// Multiple messages up to delivery tag
channel.BasicAck(deliveryTag, multiple: true);
```

**2. Basic Nack (Failure):**
```csharp
// Reject and requeue
channel.BasicNack(deliveryTag, multiple: false, requeue: true);

// Reject and discard (or send to DLX)
channel.BasicNack(deliveryTag, multiple: false, requeue: false);
```

**3. Basic Reject (Single Message):**
```csharp
// Simpler rejection for single message
channel.BasicReject(deliveryTag, requeue: false);
```

### Reliable Processing Pattern

```csharp
public class ReliableConsumer
{
    private readonly IModel _channel;
    private readonly ILogger _logger;
    
    public void StartConsuming()
    {
        // Set prefetch to control unacked messages
        _channel.BasicQos(0, 10, false);
        
        var consumer = new EventingBasicConsumer(_channel);
        consumer.Received += async (model, ea) =>
        {
            try
            {
                var message = Encoding.UTF8.GetBytes(ea.Body.ToArray());
                
                // Process message
                await ProcessOrderAsync(message);
                
                // Success - ack
                _channel.BasicAck(ea.DeliveryTag, false);
            }
            catch (TransientException ex)
            {
                // Transient error - requeue for retry
                _logger.LogWarning(ex, "Transient error, requeuing");
                _channel.BasicNack(ea.DeliveryTag, false, requeue: true);
            }
            catch (PermanentException ex)
            {
                // Permanent error - don't requeue
                _logger.LogError(ex, "Permanent error, sending to DLX");
                _channel.BasicNack(ea.DeliveryTag, false, requeue: false);
            }
        };
        
        _channel.BasicConsume("orders", false, consumer);
    }
}
```

### Idempotent Processing

```csharp
public class IdempotentConsumer
{
    private readonly HashSet<string> _processedIds = new();
    
    public async Task HandleMessageAsync(BasicDeliverEventArgs ea)
    {
        var messageId = ea.BasicProperties.MessageId;
        
        // Check if already processed
        if (_processedIds.Contains(messageId))
        {
            // Already processed - just ack
            _channel.BasicAck(ea.DeliveryTag, false);
            return;
        }
        
        try
        {
            // Process message
            await ProcessAsync(ea.Body);
            
            // Mark as processed
            _processedIds.Add(messageId);
            
            // Acknowledge
            _channel.BasicAck(ea.DeliveryTag, false);
        }
        catch
        {
            // On failure, don't add to processed set
            _channel.BasicNack(ea.DeliveryTag, false, requeue: true);
        }
    }
}
```

**Database-Backed Idempotency:**

```csharp
public class DatabaseIdempotentConsumer
{
    private readonly IDbConnection _db;
    
    public async Task HandleMessageAsync(BasicDeliverEventArgs ea)
    {
        var messageId = ea.BasicProperties.MessageId;
        
        using var transaction = _db.BeginTransaction();
        
        try
        {
            // Check if already processed
            var exists = await _db.QuerySingleAsync<bool>(
                "SELECT EXISTS(SELECT 1 FROM ProcessedMessages WHERE MessageId = @Id)",
                new { Id = messageId });
            
            if (exists)
            {
                _channel.BasicAck(ea.DeliveryTag, false);
                return;
            }
            
            // Process message
            await ProcessOrderAsync(ea.Body);
            
            // Record as processed (atomic with business logic)
            await _db.ExecuteAsync(
                "INSERT INTO ProcessedMessages (MessageId, ProcessedAt) VALUES (@Id, @At)",
                new { Id = messageId, At = DateTime.UtcNow });
            
            transaction.Commit();
            
            // Acknowledge after commit
            _channel.BasicAck(ea.DeliveryTag, false);
        }
        catch
        {
            transaction.Rollback();
            _channel.BasicNack(ea.DeliveryTag, false, requeue: true);
        }
    }
}
```

### Prefetch and Flow Control

**Understanding Prefetch:**

```csharp
public class PrefetchExamples
{
    public void ConfigurePrefetch()
    {
        // Prefetch = 1: Consumer gets one message at a time
        // Good for: Slow processing, ensuring fair distribution
        _channel.BasicQos(prefetchSize: 0, prefetchCount: 1, global: false);
        
        // Prefetch = 10: Consumer gets up to 10 unacked messages
        // Good for: Fast processing, reducing network round trips
        _channel.BasicQos(0, 10, false);
        
        // Prefetch = 100: Higher throughput but less fair distribution
        _channel.BasicQos(0, 100, false);
        
        // Global prefetch: Applies to entire channel
        _channel.BasicQos(0, 50, global: true);
    }
    
    public void DemonstrateFlowControl()
    {
        // With prefetch=1
        // Consumer 1: Process msg 1 (slow) - 10 seconds
        // Consumer 2: Gets msg 2, processes quickly - 1 second
        // Consumer 2: Gets msg 3, processes quickly - 1 second
        // Result: Fast consumer processes more messages (fair)
        
        // Without prefetch limit (auto-ack)
        // All messages distributed evenly upfront
        // Consumer 1: Gets 50% but processes slowly
        // Consumer 2: Gets 50% but finishes quickly, then idle
        // Result: Unfair distribution, poor throughput
    }
}
```

**Optimal Prefetch Settings:**

```csharp
public class OptimalPrefetch
{
    public ushort CalculateOptimalPrefetch(
        int avgProcessingTimeMs,
        int networkLatencyMs,
        int consumerCount)
    {
        // Formula: prefetch = (latency / processing_time) + buffer
        var roundTrips = networkLatencyMs / avgProcessingTimeMs;
        var buffer = 2; // Extra messages to prevent idle time
        var prefetch = Math.Max(1, roundTrips + buffer);
        
        return (ushort)Math.Min(prefetch, 100); // Cap at 100
        
        // Examples:
        // Fast processing (10ms), low latency (5ms): prefetch = 1-2
        // Slow processing (1000ms), high latency (50ms): prefetch = 1
        // Medium processing (100ms), medium latency (20ms): prefetch = 2-4
    }
}
```

### Advanced Acknowledgment Patterns

**Batch Acknowledgment:**

```csharp
public class BatchAcknowledgment
{
    private readonly List<ulong> _pendingAcks = new();
    private readonly object _lock = new();
    
    public async Task HandleMessageAsync(BasicDeliverEventArgs ea)
    {
        try
        {
            await ProcessAsync(ea.Body);
            
            lock (_lock)
            {
                _pendingAcks.Add(ea.DeliveryTag);
                
                // Acknowledge every 10 messages
                if (_pendingAcks.Count >= 10)
                {
                    var maxTag = _pendingAcks.Max();
                    _channel.BasicAck(maxTag, multiple: true);
                    _pendingAcks.Clear();
                }
            }
        }
        catch
        {
            // Individual nack
            _channel.BasicNack(ea.DeliveryTag, false, requeue: true);
        }
    }
    
    public void Flush()
    {
        lock (_lock)
        {
            if (_pendingAcks.Any())
            {
                var maxTag = _pendingAcks.Max();
                _channel.BasicAck(maxTag, multiple: true);
                _pendingAcks.Clear();
            }
        }
    }
}
```

**Timeout-Based Acknowledgment:**

```csharp
public class TimeoutAcknowledgment
{
    public async Task HandleMessageWithTimeoutAsync(BasicDeliverEventArgs ea)
    {
        using var cts = new CancellationTokenSource(TimeSpan.FromSeconds(30));
        
        try
        {
            await ProcessAsync(ea.Body, cts.Token);
            _channel.BasicAck(ea.DeliveryTag, false);
        }
        catch (OperationCanceledException)
        {
            // Processing timeout - nack and requeue
            _logger.LogWarning("Processing timeout, requeuing");
            _channel.BasicNack(ea.DeliveryTag, false, requeue: true);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Processing error");
            _channel.BasicNack(ea.DeliveryTag, false, requeue: true);
        }
    }
}
```

### Consumer Reliability Patterns

**Graceful Shutdown:**

```csharp
public class GracefulConsumer : IDisposable
{
    private readonly CancellationTokenSource _cts = new();
    private string _consumerTag;
    
    public void Start()
    {
        var consumer = new EventingBasicConsumer(_channel);
        
        consumer.Received += async (model, ea) =>
        {
            if (_cts.Token.IsCancellationRequested)
            {
                // Shutting down - requeue message
                _channel.BasicNack(ea.DeliveryTag, false, requeue: true);
                return;
            }
            
            try
            {
                await ProcessAsync(ea.Body, _cts.Token);
                _channel.BasicAck(ea.DeliveryTag, false);
            }
            catch
            {
                _channel.BasicNack(ea.DeliveryTag, false, requeue: true);
            }
        };
        
        _consumerTag = _channel.BasicConsume("orders", false, consumer);
    }
    
    public void Dispose()
    {
        // Signal shutdown
        _cts.Cancel();
        
        // Wait for in-flight messages (with timeout)
        Thread.Sleep(5000);
        
        // Cancel consumer
        _channel.BasicCancel(_consumerTag);
        
        _channel?.Dispose();
        _connection?.Dispose();
    }
}
```

**Circuit Breaker Pattern:**

```csharp
public class CircuitBreakerConsumer
{
    private int _consecutiveFailures = 0;
    private DateTime _circuitOpenedAt = DateTime.MinValue;
    private readonly int _failureThreshold = 5;
    private readonly TimeSpan _circuitOpenDuration = TimeSpan.FromMinutes(1);
    
    public async Task HandleMessageAsync(BasicDeliverEventArgs ea)
    {
        // Check if circuit is open
        if (_circuitOpenedAt != DateTime.MinValue)
        {
            if (DateTime.UtcNow - _circuitOpenedAt < _circuitOpenDuration)
            {
                // Circuit open - reject immediately
                _logger.LogWarning("Circuit breaker open, rejecting message");
                _channel.BasicNack(ea.DeliveryTag, false, requeue: true);
                return;
            }
            else
            {
                // Try to close circuit
                _circuitOpenedAt = DateTime.MinValue;
                _consecutiveFailures = 0;
            }
        }
        
        try
        {
            await ProcessAsync(ea.Body);
            _channel.BasicAck(ea.DeliveryTag, false);
            
            // Success - reset failure count
            _consecutiveFailures = 0;
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Processing failed");
            _consecutiveFailures++;
            
            // Open circuit if threshold exceeded
            if (_consecutiveFailures >= _failureThreshold)
            {
                _logger.LogError("Circuit breaker opened");
                _circuitOpenedAt = DateTime.UtcNow;
            }
            
            _channel.BasicNack(ea.DeliveryTag, false, requeue: true);
        }
    }
}
```

### Monitoring and Observability

**Message Processing Metrics:**

```csharp
public class ObservableConsumer
{
    private readonly IMetrics _metrics;
    
    public async Task HandleMessageAsync(BasicDeliverEventArgs ea)
    {
        var sw = Stopwatch.StartNew();
        
        try
        {
            await ProcessAsync(ea.Body);
            
            // Record success
            _metrics.IncrementCounter("messages_processed_total");
            _metrics.RecordHistogram("message_processing_duration_ms", sw.ElapsedMilliseconds);
            
            _channel.BasicAck(ea.DeliveryTag, false);
        }
        catch (Exception ex)
        {
            // Record failure
            _metrics.IncrementCounter("messages_failed_total");
            _metrics.RecordHistogram("message_processing_duration_ms", sw.ElapsedMilliseconds);
            
            _logger.LogError(ex, "Message processing failed");
            _channel.BasicNack(ea.DeliveryTag, false, requeue: true);
        }
        finally
        {
            sw.Stop();
        }
    }
}
```

**Tracking Unacknowledged Messages:**

```csharp
public class UnackedMessageTracker
{
    private readonly ConcurrentDictionary<ulong, MessageTrackingInfo> _unacked = new();
    
    public void OnMessageReceived(BasicDeliverEventArgs ea)
    {
        _unacked.TryAdd(ea.DeliveryTag, new MessageTrackingInfo
        {
            ReceivedAt = DateTime.UtcNow,
            MessageId = ea.BasicProperties.MessageId,
            RoutingKey = ea.RoutingKey
        });
        
        // Alert if too many unacked messages
        if (_unacked.Count > 100)
        {
            _logger.LogWarning($"High unacked message count: {_unacked.Count}");
        }
    }
    
    public void OnMessageAcked(ulong deliveryTag)
    {
        _unacked.TryRemove(deliveryTag, out _);
    }
    
    public void CheckStaleMessages()
    {
        var threshold = TimeSpan.FromMinutes(5);
        var stale = _unacked.Where(kvp => 
            DateTime.UtcNow - kvp.Value.ReceivedAt > threshold);
        
        foreach (var msg in stale)
        {
            _logger.LogWarning($"Stale unacked message: {msg.Value.MessageId}");
        }
    }
}

public class MessageTrackingInfo
{
    public DateTime ReceivedAt { get; set; }
    public string MessageId { get; set; }
    public string RoutingKey { get; set; }
}
```

### Common Acknowledgment Pitfalls

**1. Acknowledging Too Early:**
```csharp
// WRONG: Ack before processing
_channel.BasicAck(ea.DeliveryTag, false);
await ProcessAsync(ea.Body); // If this fails, message is lost

// CORRECT: Ack after processing
await ProcessAsync(ea.Body);
_channel.BasicAck(ea.DeliveryTag, false);
```

**2. Not Handling Exceptions:**
```csharp
// WRONG: Exception leaves message unacked forever
consumer.Received += async (model, ea) =>
{
    await ProcessAsync(ea.Body); // May throw
    _channel.BasicAck(ea.DeliveryTag, false); // Never reached
};

// CORRECT: Always handle exceptions
consumer.Received += async (model, ea) =>
{
    try
    {
        await ProcessAsync(ea.Body);
        _channel.BasicAck(ea.DeliveryTag, false);
    }
    catch
    {
        _channel.BasicNack(ea.DeliveryTag, false, requeue: true);
    }
};
```

**3. Using Wrong Channel:**
```csharp
// WRONG: Acking on different channel
var receiveChannel = connection.CreateModel();
var ackChannel = connection.CreateModel();
ackChannel.BasicAck(deliveryTag, false); // Error!

// CORRECT: Use same channel
receiveChannel.BasicAck(deliveryTag, false);
```

## Self-Check Questions

1. What's the difference between auto-ack and manual ack?
2. When should you use `requeue: true` vs `requeue: false`?
3. How does prefetch affect consumer fairness?
4. What happens if you ack a message after the channel is closed?
5. Why is idempotency important with at-least-once delivery?
6. What's the risk of batch acknowledgments?

**Answers:**
1. Auto-ack acknowledges on delivery; manual ack lets consumer control when to acknowledge
2. `requeue: true` for transient failures (retry); `requeue: false` for permanent failures (DLX)
3. Lower prefetch = better fairness; higher prefetch = better throughput but less fair
4. The ack is lost; message will be redelivered on reconnection
5. Messages can be delivered multiple times, so processing must be idempotent
6. If consumer crashes, all pending acks are lost and messages redelivered

## Key Takeaways

- **Manual ack** required for reliability (auto-ack = no guarantees)
- **Auto-ack** acknowledges immediately on delivery (before processing)
- **Nack with requeue** for retriable failures (transient errors)
- **Nack without requeue** sends to dead letter exchange (permanent errors)
- **Idempotency** essential for at-least-once delivery semantics
- **Prefetch** controls flow control and consumer fairness
- **Always handle exceptions** to prevent unacked messages
- **Monitor unacked messages** to detect processing issues
- **Graceful shutdown** prevents message loss during deployment
