## Introduction

Dead Letter Exchanges (DLX) are RabbitMQ's mechanism for handling messages that can't be processed successfully. They enable sophisticated error handling patterns including retries, exponential backoff, and poison message handling. Understanding DLX is essential for building resilient messaging systems.

## Key Concepts Summary

### When Messages are Dead-Lettered

1. **Consumer rejects** (basic.reject or basic.nack with requeue=false)
2. **Message TTL expires**
3. **Queue length limit exceeded**
4. **Message is expired**

### Basic DLX Setup

```csharp
public class DeadLetterExchangeSetup
{
    public void ConfigureDLX()
    {
        using var channel = _connection.CreateModel();
        
        // Declare dead letter exchange
        channel.ExchangeDeclare("dlx", ExchangeType.Direct, durable: true);
        
        // Declare dead letter queue
        channel.QueueDeclare("failed_messages", durable: true);
        channel.QueueBind("failed_messages", "dlx", "");
        
        // Declare main queue with DLX
        var args = new Dictionary<string, object>
        {
            { "x-dead-letter-exchange", "dlx" }
        };
        
        channel.QueueDeclare(
            queue: "orders",
            durable: true,
            exclusive: false,
            autoDelete: false,
            arguments: args
        );
    }
}
```

### Consumer with Retry Logic

```csharp
public class RetryConsumer
{
    public void StartConsuming()
    {
        var consumer = new EventingBasicConsumer(_channel);
        
        consumer.Received += async (model, ea) =>
        {
            var retryCount = GetRetryCount(ea.BasicProperties);
            
            try
            {
                await ProcessMessageAsync(ea.Body);
                _channel.BasicAck(ea.DeliveryTag, false);
            }
            catch (Exception ex)
            {
                if (retryCount < 3)
                {
                    // Retry - send to DLX which routes to retry queue
                    _logger.LogWarning($"Retry {retryCount + 1}/3");
                    
                    // Increment retry count in headers
                    var props = _channel.CreateBasicProperties();
                    props.Headers = ea.BasicProperties.Headers ?? new Dictionary<string, object>();
                    props.Headers["x-retry-count"] = retryCount + 1;
                    
                    // Reject - goes to DLX
                    _channel.BasicNack(ea.DeliveryTag, false, requeue: false);
                }
                else
                {
                    // Max retries exceeded - send to dead letter
                    _logger.LogError("Max retries exceeded, dead lettering");
                    _channel.BasicNack(ea.DeliveryTag, false, requeue: false);
                }
            }
        };
        
        _channel.BasicConsume("orders", autoAck: false, consumer: consumer);
    }
    
    private int GetRetryCount(IBasicProperties props)
    {
        if (props?.Headers != null && 
            props.Headers.TryGetValue("x-retry-count", out var count))
        {
            return Convert.ToInt32(count);
        }
        return 0;
    }
}
```

### Poison Message Handling

```csharp
public class PoisonMessageHandler
{
    public async Task ProcessDeadLetterQueueAsync()
    {
        // Monitor dead letter queue
        var result = _channel.BasicGet("failed_messages", autoAck: false);
        
        if (result != null)
        {
            var message = Encoding.UTF8.GetString(result.Body.ToArray());
            
            // Log for investigation
            _logger.LogError($"Poison message: {message}");
            
            // Store in database for analysis
            await _poisonMessageRepository.SaveAsync(new PoisonMessage
            {
                Body = message,
                Headers = result.BasicProperties.Headers,
                FailureTime = DateTime.UtcNow,
                OriginalQueue = "orders"
            });
            
            // Alert operations team
            await _alertingService.SendAlertAsync("Poison message detected");
            
            // Acknowledge to remove from DLQ
            _channel.BasicAck(result.DeliveryTag, false);
        }
    }
}
```

```csharp
public class PoisonMessageDetector
{
    public void SetupAutomaticDetection()
    {
        // Quorum queues support automatic poison message handling
        var args = new Dictionary<string, object>
        {
            { "x-queue-type", "quorum" },
            { "x-delivery-limit", 3 },  // Auto-DLX after 3 redeliveries
            { "x-dead-letter-exchange", "poison_messages" }
        };
        
        _channel.QueueDeclare("orders", durable: true, arguments: args);
        
        // Setup poison message exchange and queue
        _channel.ExchangeDeclare("poison_messages", ExchangeType.Fanout, durable: true);
        _channel.QueueDeclare("poison_messages_queue", durable: true);
        _channel.QueueBind("poison_messages_queue", "poison_messages", "");
    }
    
    public async Task MonitorPoisonMessages()
    {
        var consumer = new EventingBasicConsumer(_channel);
        
        consumer.Received += async (model, ea) =>
        {
            var messageBody = Encoding.UTF8.GetString(ea.Body.ToArray());
            var deliveryCount = GetDeliveryCount(ea.BasicProperties);
            
            _logger.LogError(
                $"Poison message detected after {deliveryCount} attempts: {messageBody}");
            
            // Store for manual investigation
            await _poisonMessageRepo.SaveAsync(new PoisonMessage
            {
                MessageId = ea.BasicProperties.MessageId,
                Body = messageBody,
                Headers = ea.BasicProperties.Headers,
                DeliveryCount = deliveryCount,
                DetectedAt = DateTime.UtcNow,
                OriginalRoutingKey = ea.RoutingKey,
                FailureReason = GetFailureReason(ea.BasicProperties)
            });
            
            // Alert team
            await _slackClient.PostMessageAsync(
                $"⚠️ Poison message detected in {ea.RoutingKey}. " +
                $"Message ID: {ea.BasicProperties.MessageId}");
            
            _channel.BasicAck(ea.DeliveryTag, false);
        };
        
        _channel.BasicConsume("poison_messages_queue", false, consumer);
    }
    
    private int GetDeliveryCount(IBasicProperties props)
    {
        if (props.Headers != null && 
            props.Headers.TryGetValue("x-delivery-count", out var count))
        {
            return Convert.ToInt32(count);
        }
        return 0;
    }
    
    private string GetFailureReason(IBasicProperties props)
    {
        if (props.Headers != null && 
            props.Headers.TryGetValue("x-first-death-reason", out var reason))
        {
            return reason.ToString();
        }
        return "unknown";
    }
}
```

### Advanced DLX Patterns

**Pattern 1: Delayed Retry with Increasing Backoff**

```csharp
public class ExponentialBackoffPattern
{
    public void Setup()
    {
        // Main queue
        var mainArgs = new Dictionary<string, object>
        {
            { "x-dead-letter-exchange", "retry_exchange" }
        };
        _channel.QueueDeclare("orders", durable: true, arguments: mainArgs);
        
        // Retry exchange
        _channel.ExchangeDeclare("retry_exchange", ExchangeType.Headers, durable: true);
        
        // Retry queues with increasing TTL
        SetupRetryQueue("orders.retry.1", 5000, "retry_exchange", "orders");    // 5s
        SetupRetryQueue("orders.retry.2", 15000, "retry_exchange", "orders");   // 15s
        SetupRetryQueue("orders.retry.3", 45000, "retry_exchange", "orders");   // 45s
        SetupRetryQueue("orders.retry.4", 135000, "retry_exchange", "orders");  // 2m 15s
        
        // Final DLX for max retries
        _channel.ExchangeDeclare("dlx", ExchangeType.Fanout, durable: true);
        SetupRetryQueue("orders.retry.5", 0, "dlx", "");  // No more retries
        
        // Bind retry queues based on retry count header
        for (int i = 1; i <= 5; i++)
        {
            var binding = new Dictionary<string, object>
            {
                { "x-match", "all" },
                { "retry-count", i }
            };
            _channel.QueueBind($"orders.retry.{i}", "retry_exchange", "", binding);
        }
    }
    
    private void SetupRetryQueue(
        string queueName, 
        int ttlMs, 
        string dlx, 
        string dlRoutingKey)
    {
        var args = new Dictionary<string, object>
        {
            { "x-dead-letter-exchange", dlx }
        };
        
        if (!string.IsNullOrEmpty(dlRoutingKey))
        {
            args["x-dead-letter-routing-key"] = dlRoutingKey;
        }
        
        if (ttlMs > 0)
        {
            args["x-message-ttl"] = ttlMs;
        }
        
        _channel.QueueDeclare(queueName, durable: true, arguments: args);
    }
    
    public void PublishWithRetryTracking(string message)
    {
        var props = _channel.CreateBasicProperties();
        props.Persistent = true;
        props.Headers = new Dictionary<string, object>
        {
            { "retry-count", 0 }
        };
        
        var body = Encoding.UTF8.GetBytes(message);
        _channel.BasicPublish("", "orders", props, body);
    }
}
```

**Pattern 2: Per-Message TTL with DLX**

```csharp
public class PerMessageTTL
{
    public void SetupDelayedProcessing()
    {
        // Delay queue (parking lot)
        var delayArgs = new Dictionary<string, object>
        {
            { "x-dead-letter-exchange", "" },
            { "x-dead-letter-routing-key", "orders" }
        };
        _channel.QueueDeclare("orders.delay", durable: true, arguments: delayArgs);
        
        // Main processing queue
        _channel.QueueDeclare("orders", durable: true);
    }
    
    public void PublishWithDelay(Order order, TimeSpan delay)
    {
        var props = _channel.CreateBasicProperties();
        props.Persistent = true;
        props.Expiration = ((int)delay.TotalMilliseconds).ToString();
        
        var body = Encoding.UTF8.GetBytes(JsonSerializer.Serialize(order));
        
        // Send to delay queue
        _channel.BasicPublish("", "orders.delay", props, body);
        
        // After TTL expires, message goes to "orders" queue via DLX
    }
    
    public void ScheduleOrder(Order order, DateTime scheduledFor)
    {
        var delay = scheduledFor - DateTime.UtcNow;
        if (delay > TimeSpan.Zero)
        {
            PublishWithDelay(order, delay);
        }
        else
        {
            // Process immediately
            var body = Encoding.UTF8.GetBytes(JsonSerializer.Serialize(order));
            _channel.BasicPublish("", "orders", null, body);
        }
    }
}
```

**Pattern 3: Priority Dead Letter Routing**

```csharp
public class PriorityDLX
{
    public void Setup()
    {
        // Main queue with DLX
        var mainArgs = new Dictionary<string, object>
        {
            { "x-dead-letter-exchange", "failure_router" }
        };
        _channel.QueueDeclare("orders", durable: true, arguments: mainArgs);
        
        // Failure router (topic exchange)
        _channel.ExchangeDeclare("failure_router", ExchangeType.Topic, durable: true);
        
        // Different failure handlers
        _channel.QueueDeclare("failures.transient", durable: true);
        _channel.QueueDeclare("failures.validation", durable: true);
        _channel.QueueDeclare("failures.timeout", durable: true);
        _channel.QueueDeclare("failures.unknown", durable: true);
        
        // Bind based on failure type
        _channel.QueueBind("failures.transient", "failure_router", "failure.transient");
        _channel.QueueBind("failures.validation", "failure_router", "failure.validation");
        _channel.QueueBind("failures.timeout", "failure_router", "failure.timeout");
        _channel.QueueBind("failures.unknown", "failure_router", "#");
    }
    
    public async Task HandleMessage(BasicDeliverEventArgs ea)
    {
        try
        {
            await ProcessAsync(ea.Body);
            _channel.BasicAck(ea.DeliveryTag, false);
        }
        catch (Exception ex)
        {
            // Classify failure and set routing key for DLX
            var failureType = ClassifyException(ex);
            
            // Add failure metadata to headers
            var props = _channel.CreateBasicProperties();
            props.Headers = new Dictionary<string, object>
            {
                { "x-failure-type", failureType },
                { "x-failure-message", ex.Message },
                { "x-failure-timestamp", DateTime.UtcNow.ToString("o") }
            };
            
            // Copy message to new one with updated properties
            _channel.BasicPublish("", $"failure.{failureType}", props, ea.Body);
            
            // Ack original message
            _channel.BasicAck(ea.DeliveryTag, false);
        }
    }
    
    private string ClassifyException(Exception ex)
    {
        return ex switch
        {
            HttpRequestException => "transient",
            ValidationException => "validation",
            TimeoutException => "timeout",
            _ => "unknown"
        };
    }
}
```

### DLX Metadata and Headers

**Understanding DLX Headers:**

```csharp
public class DLXHeaderAnalysis
{
    public void AnalyzeDLXHeaders(BasicDeliverEventArgs ea)
    {
        if (ea.BasicProperties.Headers == null)
            return;
        
        // Original exchange
        if (ea.BasicProperties.Headers.TryGetValue("x-first-death-exchange", out var exchange))
        {
            _logger.LogInformation($"Original exchange: {exchange}");
        }
        
        // Original queue
        if (ea.BasicProperties.Headers.TryGetValue("x-first-death-queue", out var queue))
        {
            _logger.LogInformation($"Original queue: {queue}");
        }
        
        // Reason for dead lettering
        if (ea.BasicProperties.Headers.TryGetValue("x-first-death-reason", out var reason))
        {
            _logger.LogInformation($"Death reason: {reason}");
            // Possible values: rejected, expired, maxlen
        }
        
        // Death count (for multiple DLX hops)
        if (ea.BasicProperties.Headers.TryGetValue("x-death", out var deaths))
        {
            var deathList = deaths as List<object>;
            _logger.LogInformation($"Death count: {deathList?.Count ?? 0}");
        }
        
        // Time of death
        if (ea.BasicProperties.Headers.TryGetValue("x-first-death-time", out var time))
        {
            var timestamp = Convert.ToInt64(time);
            var dateTime = DateTimeOffset.FromUnixTimeSeconds(timestamp);
            _logger.LogInformation($"Death time: {dateTime}");
        }
    }
}
```

**2. Implement DLQ Replay:**

```csharp
public class DLQReplay
{
    public async Task ReplayMessages(string dlqName, string targetQueue, int batchSize)
    {
        var replayed = 0;
        
        while (replayed < batchSize)
        {
            var result = _channel.BasicGet(dlqName, false);
            if (result == null)
                break;
            
            // Remove DLX headers before replaying
            var props = _channel.CreateBasicProperties();
            CopyPropertiesExceptDLXHeaders(result.BasicProperties, props);
            
            // Publish to target queue
            _channel.BasicPublish("", targetQueue, props, result.Body);
            
            // Ack from DLQ
            _channel.BasicAck(result.DeliveryTag, false);
            
            replayed++;
        }
        
        _logger.LogInformation($"Replayed {replayed} messages from DLQ");
    }
    
    private void CopyPropertiesExceptDLXHeaders(
        IBasicProperties source, 
        IBasicProperties target)
    {
        target.ContentType = source.ContentType;
        target.MessageId = source.MessageId;
        target.Timestamp = source.Timestamp;
        
        if (source.Headers != null)
        {
            target.Headers = source.Headers
                .Where(h => !h.Key.StartsWith("x-death") && 
                           !h.Key.StartsWith("x-first-death"))
                .ToDictionary(h => h.Key, h => h.Value);
        }
    }
}
```

**Answers:**

3. `x-first-death-*` = first time dead-lettered; `x-death` = array of all death events (multi-hop)
4. Quorum queues support `x-delivery-limit` for automatic poison message detection
5. After fixing the issue causing failures, or for manual reprocessing of valid messages

## Key Takeaways

- **DLX** handles messages that can't be processed (reject, expire, overflow)
- **TTL + DLX** enables delayed retry patterns (parking lot pattern)
- **Multiple retry queues** for exponential backoff (increasing delays)
- **Poison message handling** prevents queue blockage (auto-DLX after N retries)
- **Monitor DLQ depth** essential for operational visibility (alert on growth)
- **DLX headers** provide failure context (`x-death`, `x-first-death-*`)
- **Replay capability** needed for fixing and reprocessing (remove DLX headers)
- **Different DLQs** for different failure types (classification pattern)
