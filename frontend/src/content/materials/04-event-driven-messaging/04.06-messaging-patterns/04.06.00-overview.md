# Chapter 4.6: Messaging Patterns

## Overview
This chapter explores essential messaging patterns that form the building blocks of event-driven systems. You'll learn publish-subscribe for broadcasting events, competing consumers for load balancing, message filtering and routing for selective delivery, request-reply for synchronous-style communication over asynchronous channels, and the transactional outbox pattern for reliable messaging with database transactions.

## Key Concepts
- **Publish-Subscribe Pattern:** broadcasting events to multiple independent subscribers.
- **Competing Consumers:** multiple consumers processing messages from the same queue for load distribution.
- **Message Filtering and Routing:** delivering messages to specific consumers based on content or metadata.
- **Request-Reply Pattern:** implementing synchronous-style request/response over asynchronous messaging.
- **Transactional Outbox Pattern:** ensuring atomicity between database changes and message publishing.
