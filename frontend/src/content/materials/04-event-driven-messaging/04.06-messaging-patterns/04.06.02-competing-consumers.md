## Introduction

The **Competing Consumers pattern** (also called Competing Workers or Load Balancer pattern) enables horizontal scalability by distributing work across multiple consumer instances. Unlike pub/sub where each subscriber gets a copy of every message, competing consumers share the workload—each message is processed by exactly one consumer from the group.

This pattern is essential for handling high message throughput,achieving fault tolerance, and enabling elastic scaling. When one consumer can't keep up with the message rate, you simply add more consumers to share the load.

## Key Concepts Summary

### What are Competing Consumers?

**Definition:** Multiple consumer instances process messages from a shared queue/topic, with each message delivered to only one consumer.

```
Queue/Topic → [Message 1] → Consumer A (✓ processes)
           → [Message 2] → Consumer B (✓ processes)
           → [Message 3] → Consumer C (✓ processes)
           → [Message 4] → Consumer A (✓ processes)
```

**Key characteristics:**
- **One message, one consumer:** Each message processed exactly once
- **Load distribution:** Work automatically distributed across available consumers
- **Horizontal scalability:** Add consumers to increase throughput
- **Fault tolerance:** If one consumer fails, others continue processing

### Competing Consumers vs Pub/Sub

| Aspect | Competing Consumers | Pub/Sub |
|--------|-------------------|---------|
| Message recipients | One consumer from group | All subscribers |
| Use case | Task distribution | Event broadcasting |
| Scalability approach | Add consumers | Add subscriber services |
| Message processing | Divided workload | Duplicate processing |
| Example | Process orders | Notify services of order |

### Competing Consumers in RabbitMQ

RabbitMQ implements competing consumers using **multiple consumers on the same queue**:

```csharp
// Producer: Sends tasks to queue
public class OrderProcessor
{
    private readonly IModel _channel;
    
    public OrderProcessor(IConnection connection)
    {
        _channel = connection.CreateModel();
        
        // Declare work queue
        _channel.QueueDeclare(
            queue: "order-processing",
            durable: true,
            exclusive: false,
            autoDelete: false
        );
    }
    
    public void SubmitOrder(Order order)
    {
        var message = JsonSerializer.Serialize(order);
        var body = Encoding.UTF8.GetBytes(message);
        
        var properties = _channel.CreateBasicProperties();
        properties.Persistent = true;  // Survive broker restarts
        
        _channel.BasicPublish(
            exchange: "",
            routingKey: "order-processing",
            basicProperties: properties,
            body: body
        );
        
        Console.WriteLine($"Submitted order {order.Id} for processing");
    }
}

// Consumer Worker (run multiple instances)
public class OrderWorker
{
    private readonly IModel _channel;
    private readonly int _workerId;
    
    public OrderWorker(IConnection connection, int workerId)
    {
        _channel = connection.CreateModel();
        _workerId = workerId;
        
        _channel.QueueDeclare(
            queue: "order-processing",
            durable: true,
            exclusive: false,
            autoDelete: false
        );
        
        // Fair dispatch: don't give more work until current work is done
        _channel.BasicQos(
            prefetchSize: 0,
            prefetchCount: 1,  // Process one message at a time
            global: false
        );
    }
    
    public void Start()
    {
        var consumer = new EventingBasicConsumer(_channel);
        
        consumer.Received += (model, ea) =>
        {
            var body = ea.Body.ToArray();
            var message = Encoding.UTF8.GetString(body);
            var order = JsonSerializer.Deserialize<Order>(message);
            
            Console.WriteLine($"[Worker {_workerId}] Processing order {order.Id}");
            
            try
            {
                // Simulate processing time
                ProcessOrder(order);
                
                // Acknowledge after successful processing
                _channel.BasicAck(ea.DeliveryTag, false);
                Console.WriteLine($"[Worker {_workerId}] Completed order {order.Id}");
            }
            catch (Exception ex)
            {
                Console.WriteLine($"[Worker {_workerId}] Failed to process order {order.Id}: {ex.Message}");
                
                // Negative acknowledgment - requeue for another worker
                _channel.BasicNack(ea.DeliveryTag, false, requeue: true);
            }
        };
        
        _channel.BasicConsume(
            queue: "order-processing",
            autoAck: false,  // Manual ack for reliability
            consumer: consumer
        );
        
        Console.WriteLine($"[Worker {_workerId}] Started, waiting for messages...");
    }
    
    private void ProcessOrder(Order order)
    {
        // Simulate work
        Thread.Sleep(TimeSpan.FromSeconds(2));
        // Actual order processing logic here
    }
}

// Running multiple workers
class Program
{
    static void Main()
    {
        var factory = new ConnectionFactory { HostName = "localhost" };
        using var connection = factory.CreateConnection();
        
        // Start 3 competing consumers
        for (int i = 1; i <= 3; i++)
        {
            var worker = new OrderWorker(connection, i);
            Task.Run(() => worker.Start());
        }
        
        Console.WriteLine("Press Enter to exit");
        Console.ReadLine();
    }
}
```

**Key points:**
- `BasicQos(prefetchCount: 1)` ensures fair distribution (round-robin)
- Manual acknowledgment ensures at-least-once processing
- Workers can run on different machines/containers
- Add/remove workers dynamically without configuration changes

### Competing Consumers in Kafka

Kafka implements competing consumers using **consumer groups with partition assignment**:

```csharp
// Producer: Sends messages to topic
public class OrderProducer
{
    private readonly IProducer<string, Order> _producer;
    
    public OrderProducer(string bootstrapServers)
    {
        var config = new ProducerConfig
        {
            BootstrapServers = bootstrapServers
        };
        
        _producer = new ProducerBuilder<string, Order>(config)
            .SetValueSerializer(new JsonSerializer<Order>())
            .Build();
    }
    
    public async Task SubmitOrder(Order order)
    {
        await _producer.ProduceAsync("order-processing", new Message<string, Order>
        {
            Key = order.CustomerId,  // Partition by customer for ordering
            Value = order
        });
        
        Console.WriteLine($"Submitted order {order.Id} for processing");
    }
}

// Consumer Worker (run multiple instances with same GroupId)
public class OrderWorker
{
    private readonly IConsumer<string, Order> _consumer;
    private readonly int _workerId;
    
    public OrderWorker(string bootstrapServers, int workerId)
    {
        _workerId = workerId;
        
        var config = new ConsumerConfig
        {
            BootstrapServers = bootstrapServers,
            GroupId = "order-workers",  // Same group = competing consumers
            AutoOffsetReset = AutoOffsetReset.Earliest,
            EnableAutoCommit = false
        };
        
        _consumer = new ConsumerBuilder<string, Order>(config)
            .SetValueDeserializer(new JsonDeserializer<Order>())
            .Build();
        
        _consumer.Subscribe("order-processing");
    }
    
    public void Start(CancellationToken cancellationToken)
    {
        Console.WriteLine($"[Worker {_workerId}] Started, waiting for messages...");
        
        while (!cancellationToken.IsCancellationRequested)
        {
            try
            {
                var result = _consumer.Consume(cancellationToken);
                var order = result.Message.Value;
                
                Console.WriteLine(
                    $"[Worker {_workerId}] Processing order {order.Id} from partition {result.Partition}"
                );
                
                ProcessOrder(order);
                
                _consumer.Commit(result);
                Console.WriteLine($"[Worker {_workerId}] Completed order {order.Id}");
            }
            catch (ConsumeException ex)
            {
                Console.WriteLine($"[Worker {_workerId}] Consume error: {ex.Error.Reason}");
            }
            catch (Exception ex)
            {
                Console.WriteLine($"[Worker {_workerId}] Processing error: {ex.Message}");
                // Don't commit - message will be reprocessed after rebalance
            }
        }
    }
    
    private void ProcessOrder(Order order)
    {
        // Simulate work
        Thread.Sleep(TimeSpan.FromSeconds(2));
        // Actual processing logic
    }
}

// Running multiple workers
class Program
{
    static async Task Main()
    {
        var cts = new CancellationTokenSource();
        var tasks = new List<Task>();
        
        // Start 3 competing consumers (same consumer group)
        for (int i = 1; i <= 3; i++)
        {
            var worker = new OrderWorker("localhost:9092", i);
            tasks.Add(Task.Run(() => worker.Start(cts.Token)));
        }
        
        Console.WriteLine("Press Enter to stop workers");
        Console.ReadLine();
        
        cts.Cancel();
        await Task.WhenAll(tasks);
    }
}
```

**Important:** Kafka partitions limit parallelism:
- Topic with 6 partitions + 3 consumers = each consumer handles 2 partitions
- Topic with 6 partitions + 6 consumers = each consumer handles 1 partition  
- Topic with 6 partitions + 10 consumers = 4 consumers are idle (no partitions)

### Load Distribution Strategies

**Round-Robin (RabbitMQ default with QoS):**
```
Message 1 → Worker A
Message 2 → Worker B
Message 3 → Worker C
Message 4 → Worker A
...
```

**Partition-Based (Kafka):**
```
Partition 0 → Worker A
Partition 1 → Worker B
Partition 2 → Worker C
Partition 3 → Worker A
...
```

**Fair Dispatch (RabbitMQ with `prefetchCount: 1`):**
```
Fast Worker: Gets more messages (finishes quickly, acks, gets next)
Slow Worker: Gets fewer messages (takes longer, less throughput)
```

### Handling Consumer Failures

**Scenario: Consumer crashes while processing**

RabbitMQ:
```csharp
// Message not acknowledged → automatically redelivered to another consumer
consumer.Received += (model, ea) =>
{
    try
    {
        ProcessMessage(ea.Body);
        _channel.BasicAck(ea.DeliveryTag, false);  // Success
    }
    catch
    {
        // No ack sent → RabbitMQ redelivers to another consumer
    }
};
```

Kafka:
```csharp
// Offset not committed → message reprocessed after rebalance
while (true)
{
    var result = _consumer.Consume();
    try
    {
        ProcessMessage(result.Message.Value);
        _consumer.Commit(result);  // Success
    }
    catch
    {
        // No commit → after rebalance, another consumer gets this partition
    }
}
```

### Scaling Considerations

**When to add consumers:**
- Message backlog growing faster than processing rate
- Consumer lag increasing beyond acceptable thresholds
- Processing time per message high (CPU/IO bound)
- Need better fault tolerance and availability
- Peak traffic periods require elastic capacity

**Monitoring metrics:**

```csharp
// RabbitMQ: Check queue depth and consumer count
public class RabbitMQMonitoring
{
    private readonly IModel _channel;
    
    public QueueMetrics GetQueueMetrics(string queueName)
    {
        var queueInfo = _channel.QueueDeclarePassive(queueName);
        
        return new QueueMetrics
        {
            MessageCount = queueInfo.MessageCount,
            ConsumerCount = queueInfo.ConsumerCount,
            MessagesPerConsumer = queueInfo.ConsumerCount > 0 
                ? (double)queueInfo.MessageCount / queueInfo.ConsumerCount 
                : queueInfo.MessageCount
        };
    }
    
    public void LogMetrics(string queueName)
    {
        var metrics = GetQueueMetrics(queueName);
        Console.WriteLine($"Queue: {queueName}");
        Console.WriteLine($"  Messages: {metrics.MessageCount}");
        Console.WriteLine($"  Consumers: {metrics.ConsumerCount}");
        Console.WriteLine($"  Msgs/Consumer: {metrics.MessagesPerConsumer:F2}");
        
        if (metrics.MessagesPerConsumer > 100)
        {
            Console.WriteLine("  ⚠️ WARNING: Consider scaling up consumers");
        }
    }
}

// Kafka: Check consumer lag and partition assignment
public class KafkaMonitoring
{
    public ConsumerLagMetrics GetConsumerLag(IConsumer<string, Order> consumer)
    {
        var assignment = consumer.Assignment;
        var totalLag = 0L;
        var lagDetails = new List<PartitionLag>();
        
        foreach (var partition in assignment)
        {
            var watermark = consumer.GetWatermarkOffsets(partition);
            var position = consumer.Position(partition);
            var lag = watermark.High.Value - position.Value;
            
            totalLag += lag;
            lagDetails.Add(new PartitionLag
            {
                Partition = partition.Partition.Value,
                CurrentOffset = position.Value,
                HighWaterMark = watermark.High.Value,
                Lag = lag
            });
        }
        
        return new ConsumerLagMetrics
        {
            TotalLag = totalLag,
            PartitionCount = assignment.Count,
            AverageLagPerPartition = assignment.Count > 0 ? totalLag / assignment.Count : 0,
            PartitionDetails = lagDetails
        };
    }
    
    public void LogLagMetrics(ConsumerLagMetrics metrics)
    {
        Console.WriteLine($"Total Lag: {metrics.TotalLag} messages");
        Console.WriteLine($"Partitions: {metrics.PartitionCount}");
        Console.WriteLine($"Avg Lag/Partition: {metrics.AverageLagPerPartition}");
        
        foreach (var detail in metrics.PartitionDetails)
        {
            Console.WriteLine($"  Partition {detail.Partition}: Lag={detail.Lag}");
        }
        
        if (metrics.TotalLag > 10000)
        {
            Console.WriteLine("  ⚠️ WARNING: High consumer lag detected");
        }
    }
}
```

**Auto-scaling trigger example:**

```csharp
public class ConsumerAutoScaler
{
    private readonly IConsumerScaleService _scaleService;
    private readonly int _minConsumers = 2;
    private readonly int _maxConsumers = 10;
    private readonly int _lagThreshold = 10000;
    private readonly int _scaleUpThreshold = 1000;
    
    public async Task MonitorAndScale(string groupId, CancellationToken ct)
    {
        while (!ct.IsCancellationRequested)
        {
            var lag = await GetConsumerGroupLag(groupId);
            var currentCount = await _scaleService.GetConsumerCount(groupId);
            
            if (lag > _lagThreshold && currentCount < _maxConsumers)
            {
                // Scale up: add more consumer instances
                var newCount = Math.Min(currentCount + 2, _maxConsumers);
                await _scaleService.ScaleConsumers(groupId, newCount);
                
                Console.WriteLine($"⬆️ Scaled up to {newCount} consumers (lag: {lag})");
            }
            else if (lag < _scaleUpThreshold && currentCount > _minConsumers)
            {
                // Scale down: remove consumer instances
                var newCount = Math.Max(currentCount - 1, _minConsumers);
                await _scaleService.ScaleConsumers(groupId, newCount);
                
                Console.WriteLine($"⬇️ Scaled down to {newCount} consumers (lag: {lag})");
            }
            
            await Task.Delay(TimeSpan.FromSeconds(30), ct);
        }
    }
}
```

### Consumer Group Rebalancing (Kafka)

Understanding rebalancing is crucial for Kafka competing consumers:

```csharp
public class RebalanceAwareConsumer
{
    private readonly IConsumer<string, Order> _consumer;
    private readonly Dictionary<TopicPartition, long> _partitionOffsets = new();
    
    public RebalanceAwareConsumer(string bootstrapServers, int workerId)
    {
        var config = new ConsumerConfig
        {
            BootstrapServers = bootstrapServers,
            GroupId = "order-workers",
            EnableAutoCommit = false,
            SessionTimeoutMs = 10000,  // Rebalance if no heartbeat for 10s
            MaxPollIntervalMs = 300000  // 5 minutes max between polls
        };
        
        _consumer = new ConsumerBuilder<string, Order>(config)
            .SetPartitionsAssignedHandler((c, partitions) =>
            {
                Console.WriteLine($"[Worker {workerId}] Partitions assigned:");
                foreach (var partition in partitions)
                {
                    Console.WriteLine($"  - Partition {partition.Partition}");
                }
            })
            .SetPartitionsRevokedHandler((c, partitions) =>
            {
                Console.WriteLine($"[Worker {workerId}] Partitions revoked:");
                foreach (var partition in partitions)
                {
                    Console.WriteLine($"  - Partition {partition.Partition}");
                }
                
                // Commit offsets before rebalance
                c.Commit();
            })
            .SetPartitionsLostHandler((c, partitions) =>
            {
                Console.WriteLine($"[Worker {workerId}] Partitions lost (no commit):");
                foreach (var partition in partitions)
                {
                    Console.WriteLine($"  - Partition {partition.Partition}");
                }
            })
            .Build();
        
        _consumer.Subscribe("order-processing");
    }
}
```

**Rebalancing triggers:**
- New consumer joins group
- Consumer leaves group (graceful shutdown)
- Consumer fails (heartbeat timeout)
- Partition count changes
- Group coordinator fails

**Minimizing rebalancing impact:**

```csharp
public class GracefulConsumer
{
    private readonly IConsumer<string, Order> _consumer;
    private CancellationTokenSource _processingCts;
    
    public async Task Start(CancellationToken stoppingToken)
    {
        try
        {
            while (!stoppingToken.IsCancellationRequested)
            {
                // Create cancellable token for message processing
                _processingCts = CancellationTokenSource.CreateLinkedTokenSource(stoppingToken);
                
                var result = _consumer.Consume(TimeSpan.FromSeconds(1));
                
                if (result != null)
                {
                    await ProcessMessage(result, _processingCts.Token);
                    _consumer.Commit(result);
                }
            }
        }
        finally
        {
            // Graceful shutdown
            _processingCts?.Cancel();
            _consumer.Close();  // Triggers rebalance
        }
    }
    
    private async Task ProcessMessage(ConsumeResult<string, Order> result, CancellationToken ct)
    {
        // Check for cancellation frequently during long processing
        if (ct.IsCancellationRequested)
            return;
            
        // Process in chunks if operation is long
        await ProcessStep1(result.Message.Value, ct);
        
        if (ct.IsCancellationRequested)
            return;
            
        await ProcessStep2(result.Message.Value, ct);
    }
}
```

### Performance Optimization

**Batch processing for higher throughput:**

```csharp
// Kafka batch consumption
public class BatchConsumer
{
    private readonly IConsumer<string, Order> _consumer;
    private const int BatchSize = 100;
    
    public void Start(CancellationToken ct)
    {
        var batch = new List<ConsumeResult<string, Order>>();
        
        while (!ct.IsCancellationRequested)
        {
            var result = _consumer.Consume(TimeSpan.FromMilliseconds(100));
            
            if (result != null)
            {
                batch.Add(result);
            }
            
            // Process when batch is full or timeout
            if (batch.Count >= BatchSize || (batch.Count > 0 && result == null))
            {
                ProcessBatch(batch);
                
                // Commit last offset in batch
                _consumer.Commit(batch.Last());
                
                batch.Clear();
            }
        }
    }
    
    private void ProcessBatch(List<ConsumeResult<string, Order>> batch)
    {
        Console.WriteLine($"Processing batch of {batch.Count} orders");
        
        // Bulk database operations
        var orders = batch.Select(r => r.Message.Value).ToList();
        _orderRepository.BulkInsert(orders);
    }
}

// RabbitMQ batch acknowledgment
public class BatchAckConsumer
{
    private readonly IModel _channel;
    private int _unackedCount = 0;
    private const int AckBatchSize = 50;
    
    public void Start()
    {
        var consumer = new EventingBasicConsumer(_channel);
        
        consumer.Received += (model, ea) =>
        {
            ProcessOrder(ea.Body);
            
            _unackedCount++;
            
            // Batch acknowledgment
            if (_unackedCount >= AckBatchSize)
            {
                _channel.BasicAck(ea.DeliveryTag, multiple: true);  // Ack all up to this tag
                _unackedCount = 0;
            }
        };
        
        _channel.BasicConsume("order-processing", false, consumer);
    }
}
```

### Testing Competing Consumers

```csharp
public class CompetingConsumerTests
{
    [Fact]
    public async Task Messages_Are_Distributed_Across_Consumers()
    {
        // Arrange
        var messageCount = 100;
        var consumerCount = 3;
        var receivedCounts = new ConcurrentDictionary<int, int>();
        
        // Act: Start multiple consumers
        var tasks = Enumerable.Range(0, consumerCount)
            .Select(i => StartConsumer(i, receivedCounts))
            .ToList();
        
        // Publish messages
        await PublishMessages(messageCount);
        
        // Wait for processing
        await Task.Delay(TimeSpan.FromSeconds(5));
        
        // Assert: Messages distributed across consumers
        Assert.Equal(consumerCount, receivedCounts.Count);
        Assert.Equal(messageCount, receivedCounts.Values.Sum());
        
        // Check reasonable distribution (not all to one consumer)
        var maxReceived = receivedCounts.Values.Max();
        var minReceived = receivedCounts.Values.Min();
        Assert.True(maxReceived - minReceived < messageCount * 0.3);
    }
    
    [Fact]
    public async Task Failed_Consumer_Messages_Redelivered()
    {
        // Arrange: Start consumer that will crash
        var consumer1 = StartFailingConsumer();
        await PublishMessage("test-order");
        
        await Task.Delay(1000);
        consumer1.Dispose();  // Simulate crash
        
        // Act: Start new consumer
        var processedMessages = new List<string>();
        var consumer2 = StartConsumer(processedMessages);
        
        await Task.Delay(2000);
        
        // Assert: Message redelivered to new consumer
        Assert.Contains("test-order", processedMessages);
    }
}
```
