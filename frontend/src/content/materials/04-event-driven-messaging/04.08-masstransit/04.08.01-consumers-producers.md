## Introduction

**MassTransit** is a free, open-source distributed application framework for .NET that simplifies building message-based applications. It provides a consistent API across different message transports (RabbitMQ, Azure Service Bus, Amazon SQS, Kafka) and handles the complex plumbing of message routing, serialization, error handling, and retry logic.

Understanding how to produce and consume messages with MassTransit is fundamental to building event-driven systems in .NET.

### Installation and Setup

```bash
# Install MassTransit with RabbitMQ transport
dotnet add package MassTransit
dotnet add package MassTransit.RabbitMQ
```

```csharp
// Program.cs - .NET 6+
using MassTransit;

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddMassTransit(x =>
{
    // Add consumers
    x.AddConsumer<OrderSubmittedConsumer>();
    
    // Configure RabbitMQ
    x.UsingRabbitMq((context, cfg) =>
    {
        cfg.Host("localhost", "/", h =>
        {
            h.Username("guest");
            h.Password("guest");
        });
        
        // Configure endpoints
        cfg.ConfigureEndpoints(context);
    });
});

var app = builder.Build();
```

### Creating Consumers

```csharp
public class OrderSubmittedConsumer : IConsumer<OrderSubmitted>
{
    private readonly ILogger<OrderSubmittedConsumer> _logger;
    private readonly IOrderRepository _repository;
    
    public OrderSubmittedConsumer(
        ILogger<OrderSubmittedConsumer> logger,
        IOrderRepository repository)
    {
        _logger = logger;
        _repository = repository;
    }
    
    public async Task Consume(ConsumeContext<OrderSubmitted> context)
    {
        var message = context.Message;
        
        _logger.LogInformation(
            "Processing order {OrderId} for customer {CustomerId}",
            message.OrderId,
            message.CustomerId);
        
        // Business logic
        await _repository.SaveOrderAsync(new Order
        {
            Id = message.OrderId,
            CustomerId = message.CustomerId,
            TotalAmount = message.TotalAmount,
            Status = OrderStatus.Submitted,
            SubmittedAt = message.SubmittedAt
        });
        
        _logger.LogInformation("Order {OrderId} saved successfully", message.OrderId);
    }
}
```

### Publishing Events

```csharp
public class OrderService
{
    private readonly IPublishEndpoint _publishEndpoint;
    private readonly ILogger<OrderService> _logger;
    
    public OrderService(IPublishEndpoint publishEndpoint, ILogger<OrderService> logger)
    {
        _publishEndpoint = publishEndpoint;
        _logger = logger;
    }
    
    public async Task SubmitOrderAsync(SubmitOrder command)
    {
        // Validate and process order
        var orderId = Guid.NewGuid();
        
        // Publish event (fanout to all interested consumers)
        await _publishEndpoint.Publish<OrderSubmitted>(new
        {
            OrderId = orderId,
            CustomerId = command.CustomerId,
            TotalAmount = command.TotalAmount,
            SubmittedAt = DateTime.UtcNow
        });
        
        _logger.LogInformation("Published OrderSubmitted event for order {OrderId}", orderId);
    }
}
```

### Sending Commands

```csharp
// Commands are sent to a specific endpoint
public class OrderController : ControllerBase
{
    private readonly ISendEndpointProvider _sendEndpointProvider;
    
    public OrderController(ISendEndpointProvider sendEndpointProvider)
    {
        _sendEndpointProvider = sendEndpointProvider;
    }
    
    [HttpPost("orders")]
    public async Task<IActionResult> SubmitOrder([FromBody] SubmitOrderDto dto)
    {
        // Get specific endpoint
        var endpoint = await _sendEndpointProvider.GetSendEndpoint(
            new Uri("queue:submit-order"));
        
        // Send command to specific queue
        await endpoint.Send<SubmitOrder>(new
        {
            OrderId = Guid.NewGuid(),
            CustomerId = dto.CustomerId,
            Items = dto.Items,
            TotalAmount = dto.TotalAmount
        });
        
        return Accepted();
    }
}
```

### Request/Response Pattern

```csharp
// Request message
public record GetOrderStatus
{
    public Guid OrderId { get; init; }
}

// Response message
public record OrderStatus
{
    public Guid OrderId { get; init; }
    public string Status { get; init; }
    public decimal TotalAmount { get; init; }
}

// Consumer that responds
public class GetOrderStatusConsumer : IConsumer<GetOrderStatus>
{
    private readonly IOrderRepository _repository;
    
    public GetOrderStatusConsumer(IOrderRepository repository)
    {
        _repository = repository;
    }
    
    public async Task Consume(ConsumeContext<GetOrderStatus> context)
    {
        var order = await _repository.GetOrderAsync(context.Message.OrderId);
        
        // Respond to the request
        await context.RespondAsync<OrderStatus>(new
        {
            OrderId = order.Id,
            Status = order.Status.ToString(),
            TotalAmount = order.TotalAmount
        });
    }
}

// Client making request
public class OrderQueryService
{
    private readonly IRequestClient<GetOrderStatus> _client;
    
    public OrderQueryService(IRequestClient<GetOrderStatus> client)
    {
        _client = client;
    }
    
    public async Task<OrderStatus> GetOrderStatusAsync(Guid orderId)
    {
        var response = await _client.GetResponse<OrderStatus>(new
        {
            OrderId = orderId
        });
        
        return response.Message;
    }
}

// Registration
builder.Services.AddMassTransit(x =>
{
    x.AddConsumer<GetOrderStatusConsumer>();
    
    // Register request client
    x.AddRequestClient<GetOrderStatus>();
    
    x.UsingRabbitMq((context, cfg) =>
    {
        cfg.ConfigureEndpoints(context);
    });
});
```

### Message Headers and Context

```csharp
public class OrderSubmittedConsumer : IConsumer<OrderSubmitted>
{
    public async Task Consume(ConsumeContext<OrderSubmitted> context)
    {
        // Access message
        var message = context.Message;
        
        // Access headers
        var messageId = context.MessageId;
        var conversationId = context.ConversationId;
```

### Consumer Configuration

```csharp
builder.Services.AddMassTransit(x =>
{
    // Add multiple consumers
    x.AddConsumer<OrderSubmittedConsumer>();
    x.AddConsumer<OrderValidatedConsumer>();
    x.AddConsumer<PaymentProcessedConsumer>();
    
    // Configure specific consumer
    x.AddConsumer<OrderSubmittedConsumer>(cfg =>
    {
        cfg.UseConcurrentMessageLimit(10);
        cfg.UseMessageRetry(r => r.Interval(3, TimeSpan.FromSeconds(5)));
    });
    
    // Scan assembly for consumers
    x.AddConsumers(typeof(Program).Assembly);
    
    x.UsingRabbitMq((context, cfg) =>
    {
        cfg.Host("localhost");
        
        // Configure specific endpoint
        cfg.ReceiveEndpoint("order-queue", e =>
        {
            e.PrefetchCount = 16;
            e.ConfigureConsumer<OrderSubmittedConsumer>(context);
        });
        
        // Auto-configure all other endpoints
        cfg.ConfigureEndpoints(context);
    });
});
```

### Polymorphic Consumers

```csharp
// Base interface
public interface IOrderEvent
{
    Guid OrderId { get; }
    DateTime Timestamp { get; }
}

// Specific events
public record OrderPlaced : IOrderEvent
{
    public Guid OrderId { get; init; }
    public DateTime Timestamp { get; init; }
    public string CustomerId { get; init; }
}

public record OrderShipped : IOrderEvent
{
    public Guid OrderId { get; init; }
    public DateTime Timestamp { get; init; }
    public string TrackingNumber { get; init; }
}

// Consumer handles all IOrderEvent types
public class OrderEventLogger : IConsumer<IOrderEvent>
{
    private readonly ILogger<OrderEventLogger> _logger;
    
    public async Task Consume(ConsumeContext<IOrderEvent> context)
    {
        _logger.LogInformation(
            "Order event: {EventType} for Order {OrderId}",
            context.Message.GetType().Name,
            context.Message.OrderId);
        
        // Type-specific handling
        switch (context.Message)
        {
            case OrderPlaced placed:
                _logger.LogInformation("Placed by customer {CustomerId}", placed.CustomerId);
                break;
            case OrderShipped shipped:
                _logger.LogInformation("Tracking: {Tracking}", shipped.TrackingNumber);
                break;
        }
        
        await Task.CompletedTask;
    }
}
```

### Batch Consumers

```csharp
// Consume messages in batches
public class OrderBatchConsumer : IConsumer<Batch<OrderSubmitted>>
{
    private readonly IOrderRepository _repository;
    
    public async Task Consume(ConsumeContext<Batch<OrderSubmitted>> context)
    {
        // Process entire batch at once
        var orders = context.Message.Select(m => new Order
        {
            OrderId = m.Message.OrderId,
            CustomerId = m.Message.CustomerId,
            TotalAmount = m.Message.TotalAmount
        }).ToList();
        
        await _repository.SaveBatchAsync(orders);
        
        _logger.LogInformation("Processed batch of {Count} orders", orders.Count);
    }
}

// Configure batch consumption
builder.Services.AddMassTransit(x =>
{
    x.AddConsumer<OrderBatchConsumer>(cfg =>
    {
        cfg.Options<BatchOptions>(o =>
        {
            o.MessageLimit = 100;
            o.TimeLimit = TimeSpan.FromSeconds(5);
            o.ConcurrencyLimit = 10;
        });
    });
    
    x.UsingRabbitMq((context, cfg) =>
    {
        cfg.Host("localhost");

});
```

### Consume Observers

```csharp
// Monitor consumer activity
public class ConsumeObserver : IConsumeObserver
{
    private readonly ILogger<ConsumeObserver> _logger;
    
    public async Task PreConsume<T>(ConsumeContext<T> context) where T : class
    {
        _logger.LogInformation("Pre-consuming {MessageType}", typeof(T).Name);
        await Task.CompletedTask;
    }
    
    public async Task PostConsume<T>(ConsumeContext<T> context) where T : class
    {
        _logger.LogInformation("Post-consuming {MessageType}", typeof(T).Name);
        await Task.CompletedTask;
    }
    
    public async Task ConsumeFault<T>(ConsumeContext<T> context, Exception exception) where T : class
    {
        _logger.LogError(exception, "Consume fault for {MessageType}", typeof(T).Name);
        await Task.CompletedTask;
    }
}

// Register observer
builder.Services.AddMassTransit(x =>
{
    x.AddConsumer<OrderSubmittedConsumer>();
    
    x.UsingRabbitMq((context, cfg) =>
    {
        cfg.ConnectConsumeObserver(new ConsumeObserver(
            context.GetRequiredService<ILogger<ConsumeObserver>>()));
        
        cfg.Host("localhost");
        cfg.ConfigureEndpoints(context);
    });
});
```

## Self-Check Questions

1. What's the difference between `Publish` and `Send` in MassTransit?
   - **Answer:** `Publish` sends messages to all subscribed consumers (fanout), while `Send` delivers to a specific queue/endpoint (point-to-point). Use `Publish` for events, `Send` for commands.

2. How does MassTransit determine the queue name for a consumer?
   - **Answer:** By default, MassTransit uses the message type name. For `IConsumer<OrderSubmitted>`, the queue is named after the message type. You can override with explicit endpoint configuration.

3. What information is available in `ConsumeContext`?
   - **Answer:** Message payload, MessageId, CorrelationId, ConversationId, headers, sent/receive timestamps, retry count, and methods to publish/send follow-up messages.

4. How do you implement request/response with MassTransit?
   - **Answer:** Use `IRequestClient<TRequest>` to send requests and await responses. Consumer uses `context.RespondAsync<TResponse>()` to reply. MassTransit handles correlation automatically.

5. What are message contracts and why use records?
   - **Answer:** Message contracts define message structure. Records provide immutability, value equality, and concise syntax—ideal for messages that should never change after creation.

6. How does dependency injection work in MassTransit consumers?
   - **Answer:** Consumers are resolved from DI container for each message. Constructor dependencies are injected. Scoped services get fresh instances per message, singletons are shared.

7. Can multiple consumers handle the same message type?
   - **Answer:** Yes. Each consumer gets its own queue. When you publish an event, all registered consumers receive a copy in their respective queues.

8. How do you handle messages in batches?
   - **Answer:** Implement `IConsumer<Batch<TMessage>>` and configure `BatchOptions` with `MessageLimit` and `TimeLimit`. MassTransit accumulates messages and delivers them as a batch.

## Key Takeaways

- **MassTransit abstracts** message transport, providing a consistent API across RabbitMQ, Azure Service Bus, Amazon SQS, and Kafka
- **Consumers** implement `IConsumer<TMessage>` and are automatically registered with the DI container
- **Message contracts** should be immutable records with clear naming conventions (commands imperative, events past tense)
- **Publish vs Send**: Use `Publish` for events (multiple handlers), `Send` for commands (single handler)
- **Request/Response** pattern is supported through `IRequestClient<TRequest>` and `context.RespondAsync<TResponse>()`
- **ConsumeContext** provides rich metadata and methods for publishing follow-up messages with automatic correlation
- **Multiple consumers** can handle the same message type, each receiving their own copy
- **Dependency injection** works seamlessly—consumers resolve scoped dependencies per message
- **Configuration is flexible**: per-consumer settings, batch processing, scheduling, and priority queues
