## Introduction

**At-least-once delivery** is the most widely used delivery guarantee in production systems. It ensures that no message is ever lost—every message will be delivered at least one time, but possibly more. The system will retry failed deliveries until successful, which may result in duplicate processing.

This guarantee provides strong reliability without the complexity of exactly-once semantics. The trade-off is that consumers must be designed to handle duplicate messages gracefully, making idempotence a critical design consideration.

## Key Concepts Summary

### What is At-Least-Once Delivery?

**Definition:** A message will be delivered **one or more times**—it will never be lost, but may be duplicated.

```
Producer → Message → [Network/Broker/Consumer] → Either:
                                                    - Delivered once ✓
                                                    - Delivered multiple times ✓✓✓
                                                    - NEVER lost
```

**Characteristics:**
- Messages are acknowledged only after successful processing
- Failed deliveries are retried automatically
- Most common default in production systems
- Requires idempotent consumers to handle duplicates
- Balance between reliability and complexity

### Why Duplicates Occur

Duplicates happen when acknowledgments are lost or delayed:

**Scenario 1: Network failure after processing**
```
1. Consumer receives message A
2. Consumer processes message A successfully
3. Consumer sends acknowledgment
4. Network fails → acknowledgment lost
5. Broker assumes failure, redelivers message A
6. Consumer processes message A again (duplicate!)
```

**Scenario 2: Producer retry**
```
1. Producer sends message B
2. Broker receives and stores message B
3. Broker's acknowledgment is delayed/lost
4. Producer timeout triggers retry
5. Producer sends message B again
6. Broker stores duplicate of message B
```

**Scenario 3: Consumer crashes**
```
1. Consumer receives message C
2. Consumer starts processing
3. Consumer crashes before acknowledging
4. Broker redelivers to another consumer (duplicate processing)
```

### At-Least-Once in Kafka

**Producer Configuration:**

```csharp
var config = new ProducerConfig
{
    BootstrapServers = "localhost:9092",
    Acks = Acks.All,                // Wait for all in-sync replicas
    EnableIdempotence = false,      // Not using exactly-once yet
    Retries = int.MaxValue,         // Retry indefinitely
    MaxInFlight = 5,                // Allow batching
    RequestTimeoutMs = 30000,       // 30 second timeout
    RetryBackoffMs = 100            // Wait 100ms between retries
};

using var producer = new ProducerBuilder<string, Order>(config).Build();

try
{
    var deliveryResult = await producer.ProduceAsync("orders", new Message<string, Order>
    {
        Key = order.OrderId,
        Value = order
    });
    
    logger.LogInformation(
        "Order {OrderId} delivered to partition {Partition} at offset {Offset}",
        order.OrderId,
        deliveryResult.Partition,
        deliveryResult.Offset
    );
}
catch (ProduceException<string, Order> ex)
{
    // After all retries exhausted
    logger.LogError(ex, "Failed to deliver order {OrderId}", order.OrderId);
    throw;
}
```

**Consumer Configuration:**

```csharp
var config = new ConsumerConfig
{
    GroupId = "order-processor",
    BootstrapServers = "localhost:9092",
    EnableAutoCommit = false,        // Manual commit for control
    AutoOffsetReset = AutoOffsetReset.Earliest,
    EnableAutoOffsetStore = false    // Manual offset management
};

using var consumer = new ConsumerBuilder<string, Order>(config).Build();
consumer.Subscribe("orders");

while (true)
{
    try
    {
        var consumeResult = consumer.Consume(cancellationToken);
        
        // Process the message
        await ProcessOrder(consumeResult.Message.Value);
        
        // Acknowledge AFTER successful processing
        consumer.Commit(consumeResult);
        
        logger.LogInformation(
            "Processed and committed order at offset {Offset}",
            consumeResult.Offset
        );
    }
    catch (ConsumeException ex)
    {
        logger.LogError(ex, "Error consuming message");
        // Don't commit - message will be redelivered
    }
    catch (Exception ex)
    {
        logger.LogError(ex, "Error processing message");
        // Don't commit - message will be redelivered
        // This means the message will be processed again (at-least-once)
    }
}
```

**Key points:**
- `Acks.All` ensures message is replicated before acknowledgment
- Retries ensure transient failures don't lose messages
- Manual offset commit ensures acknowledgment only after processing
- Processing failures result in redelivery (potential duplicates)

### At-Least-Once in RabbitMQ

**Producer with Publisher Confirms:**

```csharp
var factory = new ConnectionFactory { HostName = "localhost" };
using var connection = factory.CreateConnection();
using var channel = connection.CreateModel();

// Enable publisher confirms
channel.ConfirmSelect();

// Declare durable queue
channel.QueueDeclare(
    queue: "orders",
    durable: true,           // Queue survives broker restart
    exclusive: false,
    autoDelete: false,
    arguments: null
);

var properties = channel.CreateBasicProperties();
properties.Persistent = true;    // Message survives broker restart

var body = Encoding.UTF8.GetBytes(JsonSerializer.Serialize(order));

try
{
    channel.BasicPublish(
        exchange: "",
        routingKey: "orders",
        basicProperties: properties,
        body: body
    );
    
    // Wait for confirmation (synchronous)
    channel.WaitForConfirmsOrDie(TimeSpan.FromSeconds(5));
    
    logger.LogInformation("Order {OrderId} confirmed by broker", order.OrderId);
}
catch (Exception ex)
{
    logger.LogError(ex, "Failed to publish order {OrderId}", order.OrderId);

    throw;
```

**Consumer with Manual Acknowledgment:**

```csharp
var factory = new ConnectionFactory { HostName = "localhost" };
using var connection = factory.CreateConnection();
using var channel = connection.CreateModel();

channel.QueueDeclare(
    queue: "orders",
    durable: true,
    exclusive: false,
    autoDelete: false,
    arguments: null
);

// Set prefetch to control how many unacknowledged messages
channel.BasicQos(prefetchSize: 0, prefetchCount: 10, global: false);

var consumer = new EventingBasicConsumer(channel);

consumer.Received += async (model, ea) =>
{
    var body = ea.Body.ToArray();
    var message = Encoding.UTF8.GetString(body);
    
    try
    {
        var order = JsonSerializer.Deserialize<Order>(message);
        await ProcessOrder(order);
        
        // Acknowledge AFTER successful processing
        channel.BasicAck(
            deliveryTag: ea.DeliveryTag,
            multiple: false  // Ack only this message
        );
        
        logger.LogInformation("Processed and acknowledged order {OrderId}", order.OrderId);
    }
    catch (Exception ex)
    {
        logger.LogError(ex, "Failed to process order");
        
        // Negative acknowledgment - requeue for retry
        channel.BasicNack(
            deliveryTag: ea.DeliveryTag,
            multiple: false,
            requeue: true    // Return to queue for redelivery
        );
    }
};

// autoAck: false = manual acknowledgment
channel.BasicConsume(
    queue: "orders",
    autoAck: false,      // Manual ack for at-least-once
    consumer: consumer
);
```

**Key points:**
- `ConfirmSelect()` enables publisher confirms
- `Persistent = true` ensures message durability
- `BasicAck` only after successful processing
- `BasicNack` with `requeue = true` for retry

### Handling Retries and Backoff

**Exponential backoff for producer retries:**

```csharp
public class ResilientProducer<TKey, TValue>
{
    private readonly IProducer<TKey, TValue> _producer;
    private readonly ILogger _logger;
    
    public async Task<DeliveryResult<TKey, TValue>> ProduceWithRetry(
        string topic,
        Message<TKey, TValue> message,
        int maxRetries = 5)
    {
        int attempt = 0;
        TimeSpan delay = TimeSpan.FromMilliseconds(100);
        
        while (true)
        {
            try
            {
                return await _producer.ProduceAsync(topic, message);
            }
            catch (ProduceException<TKey, TValue> ex) when (IsTransient(ex))
            {
                attempt++;
                
                if (attempt >= maxRetries)
                {
                    _logger.LogError(
                        "Failed to produce message after {Attempts} attempts",
                        attempt
                    );
                    throw;
                }
                
                _logger.LogWarning(
                    "Produce attempt {Attempt} failed, retrying in {Delay}ms",
                    attempt,
                    delay.TotalMilliseconds
                );
                
                await Task.Delay(delay);
                delay = TimeSpan.FromMilliseconds(delay.TotalMilliseconds * 2); // Exponential backoff
            }
        }
    }
    
    private bool IsTransient(ProduceException<TKey, TValue> ex)
    {
        // Determine if error is transient (network, timeout) vs permanent (auth, serialization)
        return ex.Error.Code == ErrorCode.NetworkException ||
               ex.Error.Code == ErrorCode.RequestTimedOut ||
               ex.Error.Code == ErrorCode.NotEnoughReplicas;
    }
}
```

**Consumer retry with dead-letter queue:**

```csharp
public class ResilientConsumer
{
    private const int MaxRetries = 3;
    private readonly ILogger _logger;
    
    public async Task ProcessWithRetry(ConsumeResult<string, Order> result, IConsumer<string, Order> consumer)
    {
        int retryCount = GetRetryCount(result);
        
        try
        {
            await ProcessOrder(result.Message.Value);
            consumer.Commit(result);  // Success - commit
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Processing failed, retry {Retry}/{Max}", retryCount, MaxRetries);
            
            if (retryCount >= MaxRetries)
            {
                // Max retries reached - send to dead-letter queue
                await SendToDeadLetterQueue(result.Message);
                consumer.Commit(result);  // Commit to prevent infinite loop
            }
            else
            {
                // Don't commit - will be redelivered
                // Optionally: delay before reprocessing
                await Task.Delay(TimeSpan.FromSeconds(Math.Pow(2, retryCount)));
            }
        }
    }
    
    private int GetRetryCount(ConsumeResult<string, Order> result)
    {
        // Track retries using message headers (if supported)
        if (result.Message.Headers.TryGetLastBytes("retry-count", out var bytes))
        {
            return BitConverter.ToInt32(bytes);
        }
        return 0;
    }
}
```

### Duplicate Detection Strategies

**1. In-Memory Deduplication Cache:**

```csharp
public class DeduplicatingConsumer
{
    private readonly IMemoryCache _processedIds;
    private readonly TimeSpan _cacheExpiration = TimeSpan.FromHours(1);
    
    public async Task<bool> ProcessIfNotDuplicate(Order order)
    {
        var cacheKey = $"order:{order.OrderId}";
        
        // Check if already processed
        if (_processedIds.TryGetValue(cacheKey, out _))
        {
            _logger.LogInformation("Duplicate order {OrderId} detected, skipping", order.OrderId);
            _metrics.IncrementCounter("orders.duplicates");
            return false;  // Duplicate
        }
        
        // Process order
        await ProcessOrder(order);
        
        // Mark as processed
        _processedIds.Set(cacheKey, true, _cacheExpiration);
        
        return true;  // Processed
    }
}
```

**2. Database-Backed Deduplication:**

```csharp
public class PersistentDeduplicatingConsumer
{
    private readonly IDbConnection _db;
    
    public async Task<bool> ProcessWithDedupe(Order order)
    {
        using var transaction = await _db.BeginTransactionAsync();
        
        try
        {
            // Check if already processed (atomic)
            var exists = await _db.QuerySingleAsync<bool>(
                "SELECT EXISTS(SELECT 1 FROM ProcessedOrders WHERE OrderId = @Id)",
                new { Id = order.OrderId });
            
            if (exists)
            {
                _logger.LogInformation("Duplicate order {OrderId}", order.OrderId);
                return false;
            }
            
            // Process order
            await ProcessOrder(order);
            
            // Mark as processed (atomic with processing)
            await _db.ExecuteAsync(
                "INSERT INTO ProcessedOrders (OrderId, ProcessedAt) VALUES (@Id, @At)",
                new { Id = order.OrderId, At = DateTime.UtcNow });
            
            await transaction.CommitAsync();
            return true;
        }
        catch
        {
            await transaction.RollbackAsync();
            throw;
        }
    }
}
```

**3. Bloom Filter for Space Efficiency:**

```csharp
public class BloomFilterDeduplicator
{
    private readonly BloomFilter<string> _bloomFilter;
    private readonly HashSet<string> _recentIds;  // Exact check for recent messages
    
    public BloomFilterDeduplicator(int expectedItems = 1_000_000)
    {
        _bloomFilter = new BloomFilter<string>(expectedItems, 0.01);  // 1% false positive
        _recentIds = new HashSet<string>();
    }
    
    public bool IsProbablyDuplicate(string orderId)
    {
        // Fast bloom filter check
        if (!_bloomFilter.Contains(orderId))
        {
            // Definitely not seen before
            _bloomFilter.Add(orderId);
            _recentIds.Add(orderId);
            return false;
        }
        
        // Might be duplicate - check exact set
        if (_recentIds.Contains(orderId))
        {
            return true;  // Confirmed duplicate
        }
        
        // Bloom filter false positive
        _recentIds.Add(orderId);
        return false;
    }
}
```

### Error Classification and Handling

**Transient vs Permanent Errors:**

```csharp
public class ErrorClassifier
{
    public async Task<bool> ProcessWithClassification(Order order, IConsumer<string, Order> consumer, ConsumeResult<string, Order> result)
    {
        try
        {
            await ProcessOrder(order);
            consumer.Commit(result);
            return true;
        }
        catch (Exception ex)
        {
            var errorType = ClassifyError(ex);
            
            switch (errorType)
            {
                case ErrorType.Transient:
                    // Retry - don't commit
                    _logger.LogWarning(ex, "Transient error, will retry");
                    await Task.Delay(TimeSpan.FromSeconds(5));
                    return false;
                    
                case ErrorType.Retriable:
                    // Retriable with backoff
                    _logger.LogWarning(ex, "Retriable error, backing off");
                    var retryCount = GetRetryCount(result);
                    if (retryCount < 3)
                    {
                        await Task.Delay(TimeSpan.FromSeconds(Math.Pow(2, retryCount)));
                        return false;
                    }
                    // Max retries - fall through to DLQ
                    goto case ErrorType.Permanent;
                    
                case ErrorType.Permanent:
                    // Send to DLQ and commit
                    _logger.LogError(ex, "Permanent error, sending to DLQ");
                    await SendToDeadLetterQueue(order, ex);
                    consumer.Commit(result);
                    return true;
                    
                default:
                    throw new ArgumentException($"Unknown error type: {errorType}");
            }
        }
    }
    
    private ErrorType ClassifyError(Exception ex)
    {
        return ex switch
        {
            HttpRequestException => ErrorType.Transient,
            TimeoutException => ErrorType.Transient,
            SqlException sqlEx when sqlEx.Number == 1205 => ErrorType.Retriable,  // Deadlock
            SqlException sqlEx when sqlEx.Number == -2 => ErrorType.Transient,    // Timeout
            JsonException => ErrorType.Permanent,  // Bad data
            ArgumentException => ErrorType.Permanent,
            _ => ErrorType.Retriable
        };
    }
}

public enum ErrorType
{
    Transient,   // Network, temporary unavailability
    Retriable,   // Deadlocks, rate limits
    Permanent    // Bad data, logic errors
}
```

### Advanced Producer Patterns

**Circuit Breaker Pattern:**

```csharp
public class CircuitBreakerProducer
{
    private int _consecutiveFailures;
    private DateTime _circuitOpenedAt = DateTime.MinValue;
    private readonly int _failureThreshold = 5;
    private readonly TimeSpan _circuitOpenDuration = TimeSpan.FromMinutes(1);
    
    public async Task<bool> ProduceWithCircuitBreaker(string topic, Message<string, Order> message)
    {
        // Check circuit state
        if (_circuitOpenedAt != DateTime.MinValue)
        {
            if (DateTime.UtcNow - _circuitOpenedAt < _circuitOpenDuration)
            {
                _logger.LogWarning("Circuit breaker open, rejecting message");
                return false;
            }
            
            // Try to close circuit
            _circuitOpenedAt = DateTime.MinValue;
            _consecutiveFailures = 0;
        }
        
        try
        {
            await _producer.ProduceAsync(topic, message);
            _consecutiveFailures = 0;  // Reset on success
            return true;
        }
        catch (Exception ex)
        {
            _consecutiveFailures++;
            
            if (_consecutiveFailures >= _failureThreshold)
            {
                _logger.LogError("Circuit breaker opened after {Count} failures", _consecutiveFailures);
                _circuitOpenedAt = DateTime.UtcNow;
            }
            
            throw;
        }
    }
}
```

### Performance Optimization

**Batch Processing:**

```csharp
public class BatchProcessor
{
    private readonly List<ConsumeResult<string, Order>> _batch = new();
    private const int BatchSize = 100;
    
    public async Task ProcessInBatches(IConsumer<string, Order> consumer)
    {
        while (true)
        {
            var result = consumer.Consume(TimeSpan.FromMilliseconds(100));
            
            if (result != null)
            {
                _batch.Add(result);
            }
            
            // Process when batch full or timeout
            if (_batch.Count >= BatchSize || (result == null && _batch.Any()))
            {
                await ProcessBatch(_batch);
                
                // Commit batch
                var lastOffset = _batch.Last();
                consumer.Commit(lastOffset);
                
                _batch.Clear();
            }
        }
    }
    
    private async Task ProcessBatch(List<ConsumeResult<string, Order>> batch)
    {
        var orders = batch.Select(r => r.Message.Value).ToList();
        
        // Bulk insert to database
        await _repository.BulkInsertOrdersAsync(orders);
        
        _logger.LogInformation("Processed batch of {Count} orders", batch.Count);
    }
}
```
