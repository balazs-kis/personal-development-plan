---

## Introduction

**Idempotence** is a mathematical property where applying an operation multiple times has the same effect as applying it once: `f(f(x)) = f(x)`. In distributed messaging, idempotent consumers can process the same message multiple times without unintended side effects.

Since at-least-once delivery (the most common guarantee) can produce duplicates, and exactly-once semantics have performance costs, idempotent consumers are the practical solution for reliable message processing. This lesson explores patterns and techniques for building idempotent consumers in .NET.

## Key Concepts Summary

### What is Idempotence?

**Definition:** An operation is idempotent if performing it multiple times has the same effect as performing it once.

**Examples:**

```csharp
// IDEMPOTENT: Setting a value
user.Status = "Active";          // Can execute 100 times, result is the same

// IDEMPOTENT: HTTP PUT
PUT /users/123 { "name": "John" }  // Replace resource completely

// IDEMPOTENT: Absolute update
UPDATE users SET status = 'Active' WHERE id = 123;

// NON-IDEMPOTENT: Incrementing a value
user.Points += 10;               // Execute 3 times → +30 points ✗

// NON-IDEMPOTENT: HTTP POST
POST /orders { "item": "Widget" }  // Creates new order each time

// NON-IDEMPOTENT: Relative update
UPDATE users SET points = points + 10 WHERE id = 123;
```

### Why Idempotence Matters in Messaging

With at-least-once delivery, duplicates are inevitable:

```
Scenario: Processing payment message

Non-idempotent consumer:
Message 1 (original): Charge $100 → Success
Message 1 (duplicate): Charge $100 → Customer charged $200! ✗

Idempotent consumer:
Message 1 (original): Charge $100 (ID: pay-123) → Success
Message 1 (duplicate): Charge $100 (ID: pay-123) → Detected duplicate, skip ✓
```

### Pattern 1: Natural Idempotence

Some operations are naturally idempotent without additional code:

```csharp
// Example 1: Setting status (absolute update)
public class UserStatusConsumer
{
    private readonly DbContext _db;
    
    public async Task Handle(UserStatusChangedEvent evt)
    {
        var user = await _db.Users.FindAsync(evt.UserId);
        
        // Naturally idempotent - setting to same value multiple times is safe
        user.Status = evt.NewStatus;
        user.UpdatedAt = evt.Timestamp;
        
        await _db.SaveChangesAsync();
    }
}

// Example 2: Upsert operations
public class ProductCatalogConsumer
{
    private readonly DbContext _db;
    
    public async Task Handle(ProductUpdatedEvent evt)
    {
        // Naturally idempotent - inserts or updates to same state
        var product = await _db.Products.FindAsync(evt.ProductId)
                      ?? new Product { Id = evt.ProductId };
        
        product.Name = evt.Name;
        product.Price = evt.Price;
        product.UpdatedAt = evt.Timestamp;
        
        if (_db.Entry(product).State == EntityState.Detached)
            _db.Products.Add(product);
        
        await _db.SaveChangesAsync();
    }
}

// Example 3: Delete operations
public class UserDeleteConsumer
{
    private readonly DbContext _db;
    
    public async Task Handle(UserDeletedEvent evt)
    {
        var user = await _db.Users.FindAsync(evt.UserId);
        
        // Naturally idempotent - deleting already-deleted entity is safe
        if (user != null)
        {
            _db.Users.Remove(user);
            await _db.SaveChangesAsync();
        }
    }
}
```

**When to use:**
- Operations that set absolute values (not relative)
- HTTP PUT-style updates
- Delete operations
- Upsert patterns

### Pattern 2: Message Deduplication

Track processed messages to detect duplicates:

```csharp
public class ProcessedMessage
{
    public string MessageId { get; set; }
    public string ConsumerGroup { get; set; }
    public DateTime ProcessedAt { get; set; }
    public long KafkaOffset { get; set; }
}

public class OrderConsumer
{
    private readonly DbContext _db;
    
    public async Task Handle(ConsumeResult<string, Order> result)
    {
        var messageId = result.Message.Headers
            .First(h => h.Key == "message-id")
            .GetValueBytes();
        
        var messageIdString = Encoding.UTF8.GetString(messageId);
        
        // Check if already processed
        var existing = await _db.ProcessedMessages
            .AnyAsync(m => m.MessageId == messageIdString);
        
        if (existing)
        {
            // Duplicate detected - skip processing
            _logger.LogInformation("Duplicate message {MessageId} detected, skipping", messageIdString);
            return;
        }
        
        using var transaction = await _db.Database.BeginTransactionAsync();
        
        try
        {
            // Process the order
            await ProcessOrder(result.Message.Value);
            
            // Record that we processed this message
            _db.ProcessedMessages.Add(new ProcessedMessage
            {
                MessageId = messageIdString,
                ConsumerGroup = "order-processor",
                ProcessedAt = DateTime.UtcNow,
                KafkaOffset = result.Offset.Value
            });
            
            await _db.SaveChangesAsync();
            await transaction.CommitAsync();
        }
        catch
        {
            await transaction.RollbackAsync();
            throw;
        }
    }
}
```

**Considerations:**
- **Storage:** Processed message table grows over time (implement cleanup/TTL)
- **Performance:** Extra database lookup per message
- **Distributed systems:** Must be checked before any side effects

**Optimization: In-memory cache + database**

```csharp
public class CachedDeduplicationService
{
    private readonly IMemoryCache _cache;
    private readonly DbContext _db;
    
    public async Task<bool> IsProcessed(string messageId)
    {
        // Check cache first (fast path)
        if (_cache.TryGetValue(messageId, out _))
            return true;
        
        // Check database (slow path)
        var exists = await _db.ProcessedMessages
            .AnyAsync(m => m.MessageId == messageId);
        
        if (exists)
        {
            // Cache hit to speed up future checks
            _cache.Set(messageId, true, TimeSpan.FromHours(1));
        }
        
        return exists;
    }
    
    public async Task MarkProcessed(string messageId)
    {
        _db.ProcessedMessages.Add(new ProcessedMessage
        {
            MessageId = messageId,
            ProcessedAt = DateTime.UtcNow
        });
        
        await _db.SaveChangesAsync();
        
        // Cache for fast future lookups
        _cache.Set(messageId, true, TimeSpan.FromHours(1));
    }
}
```

### Pattern 3: Idempotency Keys

Use business-level keys for deduplication:

```csharp
public class PaymentConsumer
{
    private readonly DbContext _db;
    private readonly IPaymentGateway _paymentGateway;
    
    public async Task Handle(ProcessPaymentCommand cmd)
    {
        // Use business key: orderId + attempt number
        var idempotencyKey = $"{cmd.OrderId}-{cmd.AttemptNumber}";
        
        // Check if payment already processed for this key
        var existingPayment = await _db.Payments
            .FirstOrDefaultAsync(p => p.IdempotencyKey == idempotencyKey);
        
        if (existingPayment != null)
        {
            _logger.LogInformation(
                "Payment for order {OrderId} with key {Key} already processed",
                cmd.OrderId,
                idempotencyKey
            );
            return;
        }
        
        using var transaction = await _db.Database.BeginTransactionAsync();
        
        try
        {
            // Process payment with external gateway
            var paymentResult = await _paymentGateway.ChargeAsync(
                cmd.CustomerId,
                cmd.Amount,
                idempotencyKey  // Gateway uses this for its own deduplication
            );
            
            // Record payment with idempotency key
            _db.Payments.Add(new Payment
            {
                Id = Guid.NewGuid(),
                OrderId = cmd.OrderId,
                IdempotencyKey = idempotencyKey,
                Amount = cmd.Amount,
                GatewayTransactionId = paymentResult.TransactionId,
                ProcessedAt = DateTime.UtcNow
            });
            
            await _db.SaveChangesAsync();
            await transaction.CommitAsync();
        }
        catch
        {
            await transaction.RollbackAsync();
            throw;
        }
    }
}
```

**Advantages:**
- Business-meaningful deduplication
- Works across consumer restarts/rebalances
- Can be used by external APIs (e.g., Stripe's idempotency keys)

### Pattern 4: Version Numbers / Timestamps

Use version numbers or timestamps to detect stale messages:

```csharp
public class InventoryConsumer
{
    private readonly DbContext _db;
    
    public async Task Handle(InventoryUpdatedEvent evt)
    {
        var product = await _db.Products.FindAsync(evt.ProductId);
        
        if (product == null)
        {
            // New product
            _db.Products.Add(new Product
            {
                Id = evt.ProductId,
                StockLevel = evt.StockLevel,
                Version = evt.Version
            });
        }
        else
        {
            // Check version to detect out-of-order or duplicate messages
            if (evt.Version <= product.Version)
            {
                _logger.LogInformation(
                    "Stale or duplicate inventory update for product {ProductId}: " +
                    "event version {EventVersion} <= current version {CurrentVersion}",
                    evt.ProductId,
                    evt.Version,
                    product.Version
                );
                return;  // Skip stale/duplicate
            }
            
            // Apply update
            product.StockLevel = evt.StockLevel;
            product.Version = evt.Version;
        }
        
        await _db.SaveChangesAsync();
    }
}
```

**Use cases:**
- Event sourcing
- Optimistic concurrency control
- Detecting out-of-order messages

### Pattern 5: Deterministic Side Effects

Make side effects themselves idempotent:

```csharp
public class EmailNotificationConsumer
{
    private readonly IEmailService _emailService;
    private readonly DbContext _db;
    
    public async Task Handle(OrderConfirmationEvent evt)
    {
        // Check if email already sent
        var notification = await _db.SentNotifications
            .FirstOrDefaultAsync(n => 
                n.OrderId == evt.OrderId && 
                n.Type == "OrderConfirmation"
            );
        
        if (notification != null)
        {
            _logger.LogInformation(
                "Order confirmation email for {OrderId} already sent at {SentAt}",
                evt.OrderId,
                notification.SentAt
            );
            return;
        }
        
        // Send email
        await _emailService.SendOrderConfirmationAsync(
            evt.CustomerEmail,
            evt.OrderId,
            evt.OrderDetails
        );
        
        // Record that we sent it
        _db.SentNotifications.Add(new SentNotification
        {
            OrderId = evt.OrderId,
            Type = "OrderConfirmation",
            RecipientEmail = evt.CustomerEmail,
            SentAt = DateTime.UtcNow
        });
        
        await _db.SaveChangesAsync();
    }
}
```

### Choosing an Idempotency Strategy

| Strategy | Complexity | Performance | Use When |
|----------|------------|-------------|----------|
| Natural Idempotence | Low | High | Operations are naturally idempotent |
| Message Deduplication | Medium | Medium | Need universal deduplication |
| Idempotency Keys | Medium | High | Business-level deduplication needed |
| Version Numbers | Low | High | Events have natural ordering |
| Deterministic Side Effects | High | Medium | External APIs, non-reversible actions |

### Advanced Idempotency Patterns

**Pattern 6: Composite Idempotency Keys:**

```csharp
public class ShippingConsumer
{
    public async Task Handle(ShipOrderCommand cmd)
    {
        // Composite key: orderId + shippingProvider + attemptDate
        var idempotencyKey = $"{cmd.OrderId}:{cmd.ShippingProvider}:{cmd.AttemptDate:yyyy-MM-dd}";
        
        var existingShipment = await _db.Shipments
            .FirstOrDefaultAsync(s => s.IdempotencyKey == idempotencyKey);
        
        if (existingShipment != null)
        {
            _logger.LogInformation("Shipment already created: {Key}", idempotencyKey);
            return;
        }
        
        // Create shipment
        var shipment = await _shippingProvider.CreateShipmentAsync(cmd);
        
        // Store with idempotency key
        _db.Shipments.Add(new Shipment
        {
            Id = shipment.ShipmentId,
            OrderId = cmd.OrderId,
            IdempotencyKey = idempotencyKey,
            TrackingNumber = shipment.TrackingNumber,
            CreatedAt = DateTime.UtcNow
        });
        
        await _db.SaveChangesAsync();
    }
}
```

**Pattern 7: Time-Window Deduplication:**

```csharp
public class TimeWindowDeduplicator
{
    private readonly IDistributedCache _cache;
    
    public async Task<bool> IsWithinWindow(string messageId, TimeSpan window)
    {
        var cacheKey = $"processed:{messageId}";
        
        // Check cache
        var exists = await _cache.GetStringAsync(cacheKey);
        
        if (exists != null)
        {
            return true;  // Duplicate within window
        }
        
        // Mark as processed for the window duration
        await _cache.SetStringAsync(
            cacheKey,
            DateTime.UtcNow.ToString("o"),
            new DistributedCacheEntryOptions
            {
                AbsoluteExpirationRelativeToNow = window
            });
        
        return false;
    }
}

// Usage
public async Task ProcessMessage(Order order, string messageId)
{
    // Check if processed within last hour
    if (await _deduplicator.IsWithinWindow(messageId, TimeSpan.FromHours(1)))
    {
        _logger.LogInformation("Duplicate detected within 1-hour window");
        return;
    }
    
    await ProcessOrder(order);
}
```

**Pattern 8: Saga Idempotency:**

```csharp
public class SagaIdempotentHandler
{
    public async Task HandleSagaStep(SagaStepCommand cmd)
    {
        // Use sagaId + stepName as idempotency key
        var key = $"{cmd.SagaId}:{cmd.StepName}";
        
        var stepExecution = await _db.SagaExecutions
            .FirstOrDefaultAsync(e => e.IdempotencyKey == key);
        
        if (stepExecution != null)
        {
            // Step already executed
            if (stepExecution.Status == ExecutionStatus.Completed)
            {
                _logger.LogInformation("Saga step already completed: {Key}", key);
                return;
            }
            
            if (stepExecution.Status == ExecutionStatus.Failed)
            {
                // Previous execution failed - allow retry with same key
                _logger.LogInformation("Retrying failed saga step: {Key}", key);
            }
        }
        else
        {
            // First execution
            stepExecution = new SagaExecution
            {
                Id = Guid.NewGuid(),
                SagaId = cmd.SagaId,
                StepName = cmd.StepName,
                IdempotencyKey = key,
                Status = ExecutionStatus.InProgress,
                StartedAt = DateTime.UtcNow
            };
            _db.SagaExecutions.Add(stepExecution);
            await _db.SaveChangesAsync();
        }
        
        try
        {
            // Execute step
            await ExecuteSagaStep(cmd);
            
            // Mark completed
            stepExecution.Status = ExecutionStatus.Completed;
            stepExecution.CompletedAt = DateTime.UtcNow;
            await _db.SaveChangesAsync();
        }
        catch
        {
            stepExecution.Status = ExecutionStatus.Failed;
            stepExecution.FailedAt = DateTime.UtcNow;
            await _db.SaveChangesAsync();
            throw;
        }
    }
}
```

### Testing Idempotency

```csharp
public class IdempotencyTests
{
    [Fact]
    public async Task ProcessMessage_Twice_ShouldBeIdempotent()
    {
        // Arrange
        var order = new Order { Id = "order-123", CustomerId = "user-1", Amount = 100 };
        var messageId = Guid.NewGuid().ToString();
        
        // Act: Process same message twice
        await _consumer.HandleAsync(order, messageId);
        await _consumer.HandleAsync(order, messageId);  // Duplicate
        
        // Assert: Order processed only once
        var orders = await _db.Orders.Where(o => o.Id == "order-123").ToListAsync();
        Assert.Single(orders);
        
        var payments = await _db.Payments.Where(p => p.OrderId == "order-123").ToListAsync();
        Assert.Single(payments);
        
        // Verify idempotency record
        var processed = await _db.ProcessedMessages.CountAsync(m => m.MessageId == messageId);
        Assert.Equal(1, processed);
    }
    
    [Fact]
    public async Task IncrementOperation_Twice_ShouldApplyOnce()
    {
        // Arrange
        var userId = "user-123";
        var user = new User { Id = userId, Points = 100 };
        _db.Users.Add(user);
        await _db.SaveChangesAsync();
        
        var messageId = Guid.NewGuid().ToString();
        var evt = new PointsAwardedEvent { UserId = userId, Points = 50 };
        
        // Act: Process same increment twice
        await _loyaltyConsumer.HandleAsync(evt, messageId);
        await _loyaltyConsumer.HandleAsync(evt, messageId);  // Duplicate
        
        // Assert: Points incremented only once
        var updatedUser = await _db.Users.FindAsync(userId);
        Assert.Equal(150, updatedUser.Points);  // Not 200
    }
}
```

### Idempotency in Distributed Systems

**Handling race conditions:**

```csharp
public class DistributedIdempotentConsumer
{
    private readonly IDistributedLock _lockProvider;
    private readonly DbContext _db;
    
    public async Task HandleWithLock(Order order, string messageId)
    {
        // Acquire distributed lock for this message
        await using var @lock = await _lockProvider.AcquireLockAsync(
            $"message:{messageId}",
            TimeSpan.FromSeconds(30));
        
        if (@lock == null)
        {
            // Another instance is processing this message
            _logger.LogInformation("Message {MessageId} already being processed", messageId);
            return;
        }
        
        // Check if already processed (with lock held)
        var exists = await _db.ProcessedMessages
            .AnyAsync(m => m.MessageId == messageId);
        
        if (exists)
        {
            return;
        }
        
        // Process message
        await ProcessOrder(order);
        
        // Mark as processed
        _db.ProcessedMessages.Add(new ProcessedMessage
        {
            MessageId = messageId,
            ProcessedAt = DateTime.UtcNow
        });
        
        await _db.SaveChangesAsync();
    }
}
```

### Performance Optimization for Idempotency

**Bloom Filters for Fast Negative Checks:**

```csharp
public class OptimizedDeduplication
{
    private readonly BloomFilter<string> _bloomFilter;
    private readonly IMemoryCache _recentCache;
    private readonly DbContext _db;
    
    public async Task<bool> IsDuplicate(string messageId)
    {
        // 1. Bloom filter (fastest, probabilistic)
        if (!_bloomFilter.Contains(messageId))
        {
            // Definitely not seen before
            return false;
        }
        
        // 2. Memory cache (fast, exact)
        if (_recentCache.TryGetValue(messageId, out _))
        {
            return true;
        }
        
        // 3. Database (slow, authoritative)
        var exists = await _db.ProcessedMessages
            .AnyAsync(m => m.MessageId == messageId);
        
        if (exists)
        {
            // Cache for future fast lookups
            _recentCache.Set(messageId, true, TimeSpan.FromMinutes(10));
        }
        
        return exists;
    }
    
    public async Task MarkProcessed(string messageId)
    {
        // Add to all layers
        _bloomFilter.Add(messageId);
        _recentCache.Set(messageId, true, TimeSpan.FromMinutes(10));
        
        _db.ProcessedMessages.Add(new ProcessedMessage
        {
            MessageId = messageId,
            ProcessedAt = DateTime.UtcNow
        });
        
        await _db.SaveChangesAsync();
    }
}
```
