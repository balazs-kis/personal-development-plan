# Chapter 4.7: Event Sourcing in Practice

## Overview
This chapter explores event sourcing—a powerful pattern for building systems where state is derived from a sequence of events rather than storing current state directly. You'll learn to design event stores, reconstruct aggregates from events, handle event versioning as your system evolves, optimize performance with snapshots, and build read models through projections for efficient querying.

## Key Concepts
- **Event Store Design:** structuring storage for append-only event streams with optimized retrieval.
- **Aggregate Reconstruction:** rebuilding current state by replaying events from the event store.
- **Event Versioning and Upcasting:** managing schema evolution as events change over time.
- **Snapshots for Performance:** caching aggregate state to avoid replaying all events.
- **Projections and Read Models:** building queryable views from event streams for CQRS.
