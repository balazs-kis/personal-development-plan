# Chapter 9.3: Indexing Strategies

## Overview

This chapter covers PostgreSQL indexing in depth—from understanding how B-tree indexes work to selecting the right index type for your use case. Proper indexing is often the single most impactful performance optimization you can make, but it requires understanding trade-offs between read performance, write overhead, and storage.

## Key Concepts
- **B-tree Indexes:** understanding the default index type and when to use it.
- **Composite Indexes:** multi-column indexes and the importance of column order.
- **Specialized Index Types:** GIN, GiST, BRIN, and Hash indexes for specific data types.
- **Partial and Covering Indexes:** optimizing indexes for specific queries and workloads.
- **Index Maintenance:** managing bloat, monitoring performance, and when to rebuild.
