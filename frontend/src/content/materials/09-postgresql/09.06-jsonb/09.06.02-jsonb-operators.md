# Lesson 2: JSONB Operators and Querying

## Learning Objectives

By the end of this lesson, you will be able to:
- Use JSONB extraction operators (`->`, `->>`) to access data
- Filter data using containment operators (`@>`, `<@`)
- Check for key existence with `?`, `?&`, and `?|` operators
- Modify JSONB data using concatenation and deletion operators
- Build and aggregate JSONB data using functions

---

## Introduction

PostgreSQL provides a rich set of operators and functions specifically designed for working with JSONB data. These operators enable you to query, filter, and manipulate JSON documents directly in SQL without needing to parse them in application code.

Mastering these operators is essential for writing efficient JSONB queries. The right operator can make the difference between a fast, indexed query and a slow sequential scan.

## Key Concepts Summary

### Extraction Operators

**`->` Operator: Extract as JSONB**

Returns the value as JSONB type (can be chained for nested access):

```sql
-- Extract top-level field
SELECT profile->'city' FROM users;
-- Result: "New York" (JSONB)

-- Extract nested field
SELECT profile->'address'->'city' FROM users;

-- Extract array element by index
SELECT tags->0 FROM articles;  -- First element

-- Chain multiple extractions
SELECT 
    data->'user'->'profile'->'settings'->'theme' AS theme
FROM config;
```

**`->>` Operator: Extract as Text**

Returns the value as text (cannot be chained):

```sql
-- Extract as text
SELECT profile->>'city' FROM users;
-- Result: New York (TEXT)

-- Use in WHERE clause
SELECT * FROM users WHERE profile->>'age' = '30';

-- Nested extraction (must use -> for intermediate steps)
SELECT profile->'address'->>'city' FROM users;
```

**Key difference:**
- `->` returns JSONB (can chain, can use with other JSONB operators)
- `->>` returns TEXT (final extraction, use in WHERE/ORDER BY)

### Containment Operators

**`@>` Operator: Contains**

Check if left JSONB contains right JSONB:

```sql
-- Check if JSON contains specific key-value pair
SELECT * FROM products 
WHERE attributes @> '{"brand": "Apple"}';

-- Check for multiple conditions
SELECT * FROM products 
WHERE attributes @> '{"brand": "Apple", "color": "silver"}';

-- Check for nested structure
SELECT * FROM users 
WHERE profile @> '{"address": {"country": "USA"}}';

-- Check if array contains value
SELECT * FROM articles 
WHERE tags @> '["postgresql"]';  -- Array must contain "postgresql"
```

**`<@` Operator: Contained In**

Check if left JSONB is contained in right JSONB (reverse of @>):

```sql
-- Check if JSON is subset of another
SELECT '{"a": 1}'::JSONB <@ '{"a": 1, "b": 2}'::JSONB;
-- Result: true

-- Practical use: check if document matches template
SELECT * FROM events 
WHERE '{"type": "purchase"}'::JSONB <@ payload;
```

### Key Existence Operators

**`?` Operator: Key Exists**

Check if top-level key exists:

```sql
-- Check if key exists
SELECT * FROM users WHERE profile ? 'age';

-- Check for nested key (doesn't work - only top-level)
SELECT * FROM users WHERE profile->'address' ? 'city';  -- Correct

-- Common pattern: ensure required field exists
SELECT * FROM products 
WHERE attributes ? 'price';
```

**`?&` Operator: All Keys Exist**

Check if all specified keys exist:

```sql
-- Ensure multiple required fields exist
SELECT * FROM users 
WHERE profile ?& ARRAY['first_name', 'last_name', 'email'];

-- Validation query
SELECT 
    id,
    profile ?& ARRAY['first_name', 'last_name'] AS has_complete_name
FROM users;
```

**`?|` Operator: Any Key Exists**

Check if any of the specified keys exist:

```sql
-- Find users with any social media profile
SELECT * FROM users 
WHERE profile ?| ARRAY['twitter', 'linkedin', 'facebook'];

-- Find products with any discount indicator
SELECT * FROM products 
WHERE attributes ?| ARRAY['sale_price', 'discount', 'promo_code'];
```

### Modification Operators

**`||` Operator: Concatenate/Merge**

Merge two JSONB objects:

```sql
-- Add new fields
UPDATE users 
SET profile = profile || '{"last_login": "2024-01-15"}'::JSONB
WHERE id = 1;

-- Merge multiple fields
UPDATE products 
SET attributes = attributes || jsonb_build_object(
    'updated_at', NOW(),
    'version', 2
)
WHERE id = 100;

-- Overwrite existing fields
UPDATE users 
SET profile = profile || '{"city": "San Francisco"}'::JSONB
WHERE id = 1;
-- New city value replaces old one
```

**`-` Operator: Delete Key**

Remove a key from JSONB object:

```sql
-- Remove single key
UPDATE users 
SET profile = profile - 'temp_field'
WHERE id = 1;

-- Remove multiple keys
UPDATE products 
SET attributes = attributes - ARRAY['deprecated_field', 'old_price']
WHERE category = 'electronics';

-- Remove array element by index
UPDATE articles 
SET tags = tags - 0  -- Remove first element
WHERE id = 1;
```

**`#-` Operator: Delete at Path**

Remove nested key using path:

```sql
-- Remove nested key
UPDATE users 
SET profile = profile #- '{address,apartment}'
WHERE id = 1;
-- Removes profile.address.apartment

-- Remove array element from nested structure
UPDATE products 
SET attributes = attributes #- '{specs,colors,0}'
WHERE id = 100;
-- Removes first color from specs.colors array
```

### Array Operators

**`jsonb_array_elements()` Function**

Expand JSONB array to rows:

```sql
-- Expand array elements
SELECT 
    id,
    jsonb_array_elements(tags) AS tag
FROM articles;

-- Expand and extract text
SELECT 
    id,
    jsonb_array_elements_text(tags) AS tag
FROM articles;

-- Common pattern: find records with specific array element
SELECT DISTINCT article_id 
FROM articles,
     jsonb_array_elements_text(tags) AS tag
WHERE tag = 'postgresql';
```

**`jsonb_array_length()` Function**

Get array length:

```sql
-- Count array elements
SELECT 
    id,
    name,
    jsonb_array_length(tags) AS tag_count
FROM articles;

-- Filter by array length
SELECT * FROM articles 
WHERE jsonb_array_length(tags) > 3;
```

### Building JSONB

**`jsonb_build_object()` Function**

Create JSONB object from key-value pairs:

```sql
-- Build simple object
SELECT jsonb_build_object('name', 'Alice', 'age', 30);
-- Result: {"age": 30, "name": "Alice"}

-- Build from table columns
SELECT jsonb_build_object(
    'id', id,
    'username', username,
    'email', email
) AS user_json
FROM users;

-- Nested objects
SELECT jsonb_build_object(
    'user', jsonb_build_object(
        'id', user_id,
        'name', username
    ),
    'created', created_at
) FROM orders;
```

**`jsonb_build_array()` Function**

Create JSONB array:

```sql
-- Build array
SELECT jsonb_build_array(1, 2, 3, 'text');
-- Result: [1, 2, 3, "text"]

-- Build from query results
SELECT jsonb_build_array(
    (SELECT name FROM products WHERE id = 1),
    (SELECT name FROM products WHERE id = 2)
);
```

**`jsonb_agg()` Aggregate Function**

Aggregate rows into JSONB array:

```sql
-- Aggregate all rows into array
SELECT jsonb_agg(name) AS product_names
FROM products;

-- Aggregate objects
SELECT jsonb_agg(
    jsonb_build_object(
        'id', id,
        'name', name,
        'price', price
    )
) AS products
FROM products
WHERE category = 'electronics';

-- Group by and aggregate
SELECT 
    category,
    jsonb_agg(name) AS products
FROM products
GROUP BY category;
```

**`jsonb_object_agg()` Aggregate Function**

Aggregate rows into JSONB object:

```sql
-- Create object from key-value pairs
SELECT jsonb_object_agg(username, email)
FROM users;
-- Result: {"alice": "alice@example.com", "bob": "bob@example.com"}

-- Group settings by user
SELECT 
    user_id,
    jsonb_object_agg(setting_key, setting_value) AS settings
FROM user_settings
GROUP BY user_id;
```

### Update Functions

**`jsonb_set()` Function**

Set value at specific path:

```sql
-- Set top-level field
UPDATE users 
SET profile = jsonb_set(profile, '{city}', '"Boston"')
WHERE id = 1;

-- Set nested field
UPDATE users 
SET profile = jsonb_set(
    profile, 
    '{address,city}', 
    '"San Francisco"'
)
WHERE id = 1;

-- Set with create_missing = true (default is true)
UPDATE users 
SET profile = jsonb_set(
    profile, 
    '{new_field}', 
    '"value"',
    true  -- Create path if doesn't exist
)
WHERE id = 1;

-- Update multiple fields (chain jsonb_set calls)
UPDATE users 
SET profile = jsonb_set(
    jsonb_set(profile, '{city}', '"Boston"'),
    '{updated_at}', 
    to_jsonb(NOW())
)
WHERE id = 1;
```

**`jsonb_insert()` Function**

Insert value at specific position:

```sql
-- Insert into array
UPDATE articles 
SET tags = jsonb_insert(
    tags, 
    '{0}',  -- Path: insert at beginning
    '"featured"',
    true  -- insert_after = true means insert after position
)
WHERE id = 1;
```

### Comparison Operators

```sql
-- Equality
SELECT * FROM products 
WHERE attributes = '{"brand": "Apple"}'::JSONB;

-- Inequality
SELECT * FROM products 
WHERE attributes != '{"brand": "Apple"}'::JSONB;

-- Less than, greater than (compares keys alphabetically, then values)
SELECT '{"a": 1}'::JSONB < '{"b": 2}'::JSONB;
-- Result: true
```

## Practice Exercise

After completing the materials, try this exercise (do not spend more than 25 minutes):

1. Create sample data:

```sql
CREATE TABLE products (
    id SERIAL PRIMARY KEY,
    name TEXT NOT NULL,
    attributes JSONB DEFAULT '{}'
);

INSERT INTO products (name, attributes) VALUES
    ('Laptop Pro', '{
        "brand": "TechCorp",
        "price": 1299,
        "specs": {"cpu": "Intel i7", "ram": "16GB"},
        "tags": ["business", "premium"],
        "in_stock": true
    }'),
    ('Laptop Air', '{
        "brand": "TechCorp",
        "price": 999,
        "specs": {"cpu": "Intel i5", "ram": "8GB"},
        "tags": ["portable", "lightweight"],
        "in_stock": true
    }'),
    ('Desktop Pro', '{
        "brand": "PowerCo",
        "price": 1599,
        "specs": {"cpu": "AMD Ryzen", "ram": "32GB"},
        "tags": ["workstation", "premium"],
        "in_stock": false
    }');
```

2. Practice extraction operators:

```sql
-- Extract brand as JSONB
SELECT name, attributes->'brand' AS brand FROM products;

-- Extract brand as text
SELECT name, attributes->>'brand' AS brand FROM products;

-- Extract nested spec
SELECT 
    name,
    attributes->'specs'->>'cpu' AS cpu,
    attributes->'specs'->>'ram' AS ram
FROM products;

-- Extract array element
SELECT 
    name,
    attributes->'tags'->0 AS first_tag
FROM products;
```

3. Practice containment and existence:

```sql
-- Find TechCorp products
SELECT name FROM products 
WHERE attributes @> '{"brand": "TechCorp"}';

-- Find products with i7 CPU
SELECT name FROM products 
WHERE attributes @> '{"specs": {"cpu": "Intel i7"}}';

-- Find products with tags
SELECT name FROM products 
WHERE attributes ? 'tags';

-- Find products with ALL required fields
SELECT name FROM products 
WHERE attributes ?& ARRAY['brand', 'price', 'in_stock'];

-- Find products with ANY premium indicator
SELECT name FROM products 
WHERE attributes->'tags' @> '["premium"]';
```

4. Practice modifications:

```sql
-- Add discount field
UPDATE products 
SET attributes = attributes || '{"discount": 10}'
WHERE attributes->>'brand' = 'TechCorp';

-- Remove a tag (rebuild array without it)
UPDATE products 
SET attributes = jsonb_set(
    attributes,
    '{tags}',
    (SELECT jsonb_agg(tag) 
     FROM jsonb_array_elements(attributes->'tags') tag
     WHERE tag != '"lightweight"')
)
WHERE name = 'Laptop Air';

-- Update nested value
UPDATE products 
SET attributes = jsonb_set(
    attributes,
    '{specs,ram}',
    '"64GB"'
)
WHERE name = 'Desktop Pro';
```

5. Practice aggregation:

```sql
-- Get all brands as array
SELECT jsonb_agg(DISTINCT attributes->>'brand') AS brands
FROM products;

-- Aggregate products by brand
SELECT 
    attributes->>'brand' AS brand,
    jsonb_agg(jsonb_build_object(
        'name', name,
        'price', attributes->'price'
    )) AS products
FROM products
GROUP BY attributes->>'brand';

-- Count products by tag
SELECT 
    tag,
    COUNT(*) AS product_count
FROM products,
     jsonb_array_elements_text(attributes->'tags') AS tag
GROUP BY tag
ORDER BY product_count DESC;
```
