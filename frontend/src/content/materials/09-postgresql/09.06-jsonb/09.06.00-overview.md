# Chapter 9.6: PostgreSQL JSONB

## Overview
This chapter explores PostgreSQL's JSONB type for storing and querying semi-structured data. You'll learn when to use JSONB vs normalized tables, how to query JSON data efficiently, create appropriate indexes, and combine relational and document-style data models effectively.

## Key Concepts
- **JSON vs JSONB:** Understanding the differences in storage, performance, and use cases.
- **JSONB operators and functions:** Querying, extracting, and manipulating JSON data.
- **JSONB path queries:** Using JSONPath expressions for complex queries.
- **GIN indexes for JSONB:** Optimizing JSONB queries with appropriate indexing strategies.
- **When to use JSONB vs normalized tables:** Design patterns and trade-offs.
