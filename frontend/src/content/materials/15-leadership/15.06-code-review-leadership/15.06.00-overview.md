# Chapter 15.6: Code Review as Leadership

## Overview
Use code review as a leadership tool: providing constructive feedback, mentoring through review, maintaining standards, and scaling review across teams. Code review is one of the most effective ways to share knowledge and maintain quality. Effective reviewers elevate the entire team's code.

## Key Concepts
- **Constructive Feedback Techniques:** empathetic communication, structured comments, and actionable suggestions.
- **Balancing Thoroughness and Velocity:** maintaining code quality while keeping team velocity high.
- **Mentoring Through Review:** using code review as a teaching tool for junior developers.
- **Code Review Standards and Guidelines:** establishing team checklists and shared expectations.
- **Automated Checks to Reduce Review Burden:** leveraging linters, CI/CD, and static analysis tools.
