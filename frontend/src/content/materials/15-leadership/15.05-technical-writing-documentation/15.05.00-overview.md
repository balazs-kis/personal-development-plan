# Chapter 15.5: Technical Writing and Documentation

## Overview
Communicate technical concepts effectively: design documents, technical specifications, RFCs, and documentation that actually gets read. Technical leaders must communicate complex ideas clearly. Good documentation reduces misunderstanding and enables asynchronous collaboration.

## Key Concepts
- **Design Document Structure:** organizing technical proposals for clarity and decision-making.
- **Writing for Different Audiences:** tailoring content for engineers, stakeholders, and mixed audiences.
- **Diagrams and Visual Communication:** using C4 model, PlantUML, and Mermaid for architecture visualization.
- **RFC Processes:** structuring requests for comments to drive consensus and alignment.
- **Documentation Maintenance:** keeping documentation up-to-date and relevant over time.
