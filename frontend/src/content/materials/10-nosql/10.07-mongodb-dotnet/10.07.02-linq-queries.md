---

## Introduction

The MongoDB .NET driver includes a LINQ provider that translates LINQ queries into MongoDB aggregation pipelines. This allows you to use familiar C# query syntax while leveraging MongoDB's powerful query capabilities. The LINQ3 provider (introduced in driver v2.14) offers improved translation and supports more LINQ operations.

## Key Concepts Summary

### Enabling LINQ Queries

```csharp
using MongoDB.Driver;
using MongoDB.Driver.Linq;

var client = new MongoClient("mongodb://localhost:27017");
var database = client.GetDatabase("shop");
var collection = database.GetCollection<Product>("products");

// Enable LINQ with AsQueryable()
var queryable = collection.AsQueryable();
```

### Configuring LINQ3 Provider

```csharp
// Set LINQ3 provider explicitly (recommended)
var clientSettings = MongoClientSettings.FromConnectionString(connectionString);
clientSettings.LinqProvider = LinqProvider.V3;
var client = new MongoClient(clientSettings);
```

### Query Syntax vs Method Syntax

```csharp
// Query syntax
var query1 = from p in collection.AsQueryable()
             where p.Category == "Electronics"
             where p.Price > 100
             orderby p.Price descending
             select p;

var results1 = await query1.ToListAsync();

// Method syntax (equivalent)
var query2 = collection.AsQueryable()
    .Where(p => p.Category == "Electronics")
    .Where(p => p.Price > 100)
    .OrderByDescending(p => p.Price);

var results2 = await query2.ToListAsync();
```

### Common LINQ Operations

```csharp
// Filtering
var electronics = collection.AsQueryable()
    .Where(p => p.Category == "Electronics");

// Multiple conditions
var available = collection.AsQueryable()
    .Where(p => p.Category == "Electronics" && p.InStock && p.Price < 1000);

// Projection (Select)
var productNames = await collection.AsQueryable()
    .Where(p => p.Category == "Electronics")
    .Select(p => new { p.Name, p.Price })
    .ToListAsync();

// Sorting
var sorted = collection.AsQueryable()
    .OrderBy(p => p.Category)
    .ThenByDescending(p => p.Price);

// Pagination
var page = await collection.AsQueryable()
    .OrderBy(p => p.Name)
    .Skip(20)
    .Take(10)
    .ToListAsync();

// Aggregation
var totalValue = await collection.AsQueryable()
    .Where(p => p.InStock)
    .SumAsync(p => p.Price);

var avgPrice = await collection.AsQueryable()
    .Where(p => p.Category == "Electronics")
    .AverageAsync(p => p.Price);

var count = await collection.AsQueryable()
    .Where(p => p.InStock)
    .CountAsync();
```

### Grouping

```csharp
// Group by category
var byCategory = await collection.AsQueryable()
    .GroupBy(p => p.Category)
    .Select(g => new
    {
        Category = g.Key,
        Count = g.Count(),
        TotalValue = g.Sum(p => p.Price),
        AvgPrice = g.Average(p => p.Price)
    })
    .ToListAsync();

// Complex grouping
var categoryStats = await collection.AsQueryable()
    .Where(p => p.InStock)
    .GroupBy(p => p.Category)
    .Select(g => new
    {
        Category = g.Key,
        ProductCount = g.Count(),
        MinPrice = g.Min(p => p.Price),
        MaxPrice = g.Max(p => p.Price),
        AvgPrice = g.Average(p => p.Price)
    })
    .OrderByDescending(x => x.ProductCount)
    .ToListAsync();
```

### String Operations

```csharp
// String contains (case-sensitive)
var laptops = collection.AsQueryable()
    .Where(p => p.Name.Contains("Laptop"));

// Case-insensitive search (LINQ3)
var search = collection.AsQueryable()
    .Where(p => p.Name.ToLower().Contains("laptop"));

// Starts with
var startsWithM = collection.AsQueryable()
    .Where(p => p.Name.StartsWith("M"));

// String length
var shortNames = collection.AsQueryable()
    .Where(p => p.Name.Length < 10);
```

### Working with Arrays

```csharp
public class Product
{
    [BsonId]
    [BsonRepresentation(BsonType.ObjectId)]
    public string? Id { get; set; }
    
    public string Name { get; set; } = string.Empty;
    public decimal Price { get; set; }
    public List<string> Tags { get; set; } = new();
}

// Any element matches
var hasElectronicsTag = collection.AsQueryable()
    .Where(p => p.Tags.Contains("electronics"));

// Array length
var multipleTags = collection.AsQueryable()
    .Where(p => p.Tags.Count > 2);

// All elements match condition
var allTagsShort = collection.AsQueryable()
    .Where(p => p.Tags.All(t => t.Length < 10));

// Any element matches condition
var anyLongTag = collection.AsQueryable()
    .Where(p => p.Tags.Any(t => t.Length > 10));
```

### Joins (using SelectMany)

```csharp
public class Category
{
    [BsonId]
    [BsonRepresentation(BsonType.ObjectId)]
    public string? Id { get; set; }
    
    public string Name { get; set; } = string.Empty;
    public string Description { get; set; } = string.Empty;
}

// Manual join using LINQ
var categoriesCollection = database.GetCollection<Category>("categories");

var productsWithCategory = await collection.AsQueryable()
    .Join(
        categoriesCollection.AsQueryable(),
        product => product.Category,
        category => category.Name,
        (product, category) => new
        {
            ProductName = product.Name,
            ProductPrice = product.Price,
            CategoryDescription = category.Description
        }
    )
    .ToListAsync();
```

### Dates and Times

```csharp
public class Order
{
    [BsonId]
    [BsonRepresentation(BsonType.ObjectId)]
    public string? Id { get; set; }
    
    public string ProductId { get; set; } = string.Empty;
    public DateTime OrderDate { get; set; }
    public decimal Total { get; set; }
}

var ordersCollection = database.GetCollection<Order>("orders");

// Date comparisons
var recentOrders = ordersCollection.AsQueryable()
    .Where(o => o.OrderDate > DateTime.Now.AddDays(-30));

// Extract date parts
var ordersThisYear = ordersCollection.AsQueryable()
    .Where(o => o.OrderDate.Year == DateTime.Now.Year);

var januaryOrders = ordersCollection.AsQueryable()
    .Where(o => o.OrderDate.Month == 1);
```

### First, Single, and Element Access

```csharp
// First or default
var firstElectronic = await collection.AsQueryable()
    .Where(p => p.Category == "Electronics")
    .OrderBy(p => p.Price)
    .FirstOrDefaultAsync();

// Single (throws if more than one)
var uniqueProduct = await collection.AsQueryable()
    .Where(p => p.Name == "Unique Item")
    .SingleOrDefaultAsync();

// Any (exists check)
var hasElectronics = await collection.AsQueryable()
    .AnyAsync(p => p.Category == "Electronics");

// All
var allInStock = await collection.AsQueryable()
    .AllAsync(p => p.InStock);
```

### Query Execution and Translation

```csharp
// Deferred execution - query is built but not executed
var query = collection.AsQueryable()
    .Where(p => p.Category == "Electronics")
    .OrderBy(p => p.Price);

// Execution happens here
var results = await query.ToListAsync();

// View generated MongoDB query (for debugging)
var mongoQuery = query.ToString();
Console.WriteLine(mongoQuery);
```

## LINQ3 Improvements

1. **Better Translation:** More LINQ operations are supported and translated correctly.
2. **Aggregation Pipeline:** Generates more efficient aggregation pipelines.
3. **Bug Fixes:** Resolves issues from LINQ2 provider.
4. **New Features:** Support for newer C# language features.
5. **Performance:** Improved query generation and execution.

## Limitations and Considerations

### Unsupported Operations

```csharp
// ❌ This will throw at runtime - cannot be translated
var query = collection.AsQueryable()
    .Where(p => CustomMethod(p.Name)); // Custom methods not supported

// ✅ Use supported operations
var query = collection.AsQueryable()
    .Where(p => p.Name.StartsWith("A"));
```

### Client-Side Evaluation

```csharp
// Some operations force client-side evaluation (downloads all data)
var query = collection.AsQueryable()
    .ToList() // Executes query, gets all data
    .Where(p => ComplexClientLogic(p)); // Runs in memory

// Better approach: filter in database first
var query = collection.AsQueryable()
    .Where(p => p.Category == "Electronics") // Executed in DB
    .ToList()
    .Where(p => ComplexClientLogic(p)); // Minimal data processed in memory
```

---

## Best Practices

1. **Use LINQ3:** Configure the LINQ3 provider for best results.
2. **Filter Early:** Apply filters before projections to reduce data transfer.
3. **Test Translation:** Use `ToString()` to verify the generated MongoDB query.
4. **Avoid Client Evaluation:** Be aware of operations that force client-side processing.
5. **Pagination:** Always use `Skip()` and `Take()` for large result sets.
6. **Indexes:** Ensure appropriate indexes exist for filtered and sorted fields.
