## Introduction

Proper connection management is crucial for application performance and reliability. The MongoDB .NET driver manages connection pooling automatically, but understanding how to configure it correctly can significantly improve your application's behavior under load, reduce latency, and prevent connection exhaustion.

## Key Concepts Summary

### MongoClient Lifecycle

```csharp
using MongoDB.Driver;

// ✅ CORRECT: Create once, reuse throughout application lifetime
public class DatabaseService
{
    private static readonly MongoClient _client = new MongoClient(
        "mongodb://localhost:27017"
    );
    
    public IMongoDatabase GetDatabase(string databaseName)
    {
        return _client.GetDatabase(databaseName);
    }
}

// ❌ WRONG: Creating new client for each operation
public async Task<List<Product>> GetProducts()
{
    var client = new MongoClient("mongodb://localhost:27017"); // Don't do this!
    var database = client.GetDatabase("shop");
    var collection = database.GetCollection<Product>("products");
    return await collection.Find(_ => true).ToListAsync();
}
```

### Connection String Configuration

```csharp
// Basic connection string
const string connectionString = "mongodb://localhost:27017";

// With authentication
const string connectionString = 
    "mongodb://username:password@localhost:27017/admin";

// MongoDB Atlas
const string connectionString = 
    "mongodb+srv://username:password@cluster0.mongodb.net/myDatabase?retryWrites=true&w=majority";

// Multiple hosts (replica set)
const string connectionString = 
    "mongodb://host1:27017,host2:27017,host3:27017/?replicaSet=myReplicaSet";

// With connection pool settings
const string connectionString = 
    "mongodb://localhost:27017/?minPoolSize=10&maxPoolSize=50&maxIdleTimeMS=300000";

var client = new MongoClient(connectionString);
```

### MongoClientSettings Configuration

```csharp
using MongoDB.Driver;
using MongoDB.Driver.Core.Configuration;

var settings = new MongoClientSettings
{
    // Server configuration
    Server = new MongoServerAddress("localhost", 27017),
    
    // Or multiple servers for replica set
    Servers = new[]
    {
        new MongoServerAddress("host1", 27017),
        new MongoServerAddress("host2", 27017),
        new MongoServerAddress("host3", 27017)
    },
    
    // Replica set name
    ReplicaSetName = "myReplicaSet",
    
    // Connection pool settings
    MaxConnectionPoolSize = 100,
    MinConnectionPoolSize = 10,
    MaxConnecting = 2,
    
    // Timeout settings
    ConnectTimeout = TimeSpan.FromSeconds(30),
    SocketTimeout = TimeSpan.FromMinutes(2),
    ServerSelectionTimeout = TimeSpan.FromSeconds(30),
    
    // Connection lifetime
    MaxConnectionIdleTime = TimeSpan.FromMinutes(10),
    MaxConnectionLifeTime = TimeSpan.FromMinutes(30),
    
    // Wait queue
    WaitQueueTimeout = TimeSpan.FromMinutes(2),
    
    // Credentials
    Credential = MongoCredential.CreateCredential(
        databaseName: "admin",
        username: "myUser",
        password: "myPassword"
    ),
    
    // SSL/TLS
    UseTls = true,
    
    // Application name (appears in MongoDB logs)
    ApplicationName = "MyApp",
    
    // Direct connection
    DirectConnection = false,
    
    // Retry writes
    RetryWrites = true,
    RetryReads = true,
    
    // Read/Write concerns
    ReadConcern = ReadConcern.Majority,
    WriteConcern = WriteConcern.WMajority,
    
    // LINQ provider
    LinqProvider = LinqProvider.V3
};

var client = new MongoClient(settings);
```

### Connection Pool Settings

```csharp
var settings = MongoClientSettings.FromConnectionString(connectionString);

// Maximum number of connections
// Default: 100
// Increase if database load is low, decrease if CPU usage is high
settings.MaxConnectionPoolSize = 200;

// Minimum number of connections maintained in pool
// Default: 0
// Set to number of connections needed at startup
settings.MinConnectionPoolSize = 25;

// Maximum number of connections being established concurrently
// Default: 2
// Increase if you see connection storms
settings.MaxConnecting = 5;

// Close idle connections after this time
// Default: 10 minutes
settings.MaxConnectionIdleTime = TimeSpan.FromMinutes(5);

// Close all connections after this time (rolling reconnect)
// Default: 30 minutes
settings.MaxConnectionLifeTime = TimeSpan.FromMinutes(15);

// How long threads wait for available connection
// Default: 2 minutes
settings.WaitQueueTimeout = TimeSpan.FromMinutes(1);

var client = new MongoClient(settings);
```

### Timeout Configuration

```csharp
var settings = MongoClientSettings.FromConnectionString(connectionString);

// Connection establishment timeout
// Default: 30 seconds
// Set higher than longest network latency
settings.ConnectTimeout = TimeSpan.FromSeconds(45);

// Socket read/write timeout
// Default: OS default (infinite)
// Set to 2-3x slowest operation duration
settings.SocketTimeout = TimeSpan.FromMinutes(3);

// Server selection timeout
// Default: 30 seconds
// How long to wait for suitable server
settings.ServerSelectionTimeout = TimeSpan.FromSeconds(45);

var client = new MongoClient(settings);
```

### Authentication Strategies

```csharp
// SCRAM-SHA-256 (default for MongoDB 4.0+)
var credential = MongoCredential.CreateCredential(
    databaseName: "admin",
    username: "myUser",
    password: "myPassword"
);

// SCRAM-SHA-1 (legacy)
var credential = MongoCredential.CreateScramSha1Credential(
    databaseName: "admin",
    username: "myUser",
    password: "myPassword"
);

// X.509 Certificate
var credential = MongoCredential.CreateMongoX509Credential("CN=myClient");

// AWS IAM (for AWS DocumentDB or Atlas)
var credential = MongoCredential.CreateAwsCredential(
    username: "accessKeyId",
    password: "secretAccessKey"
);

// Kerberos (GSSAPI)
var credential = MongoCredential.CreateGssapiCredential(
    username: "user@REALM"
);

var settings = new MongoClientSettings
{
    Server = new MongoServerAddress("localhost", 27017),
    Credential = credential
};

var client = new MongoClient(settings);
```

### SSL/TLS Configuration

```csharp
using System.Security.Cryptography.X509Certificates;

var settings = MongoClientSettings.FromConnectionString(connectionString);

// Enable SSL/TLS
settings.UseTls = true;

// Allow invalid certificates (development only!)
settings.AllowInsecureTls = true;

// Client certificate
var certificate = new X509Certificate2("client.pfx", "password");
settings.SslSettings = new SslSettings
{
    ClientCertificates = new[] { certificate },
    CheckCertificateRevocation = true
};

var client = new MongoClient(settings);
```

### Read and Write Concerns

```csharp
var settings = MongoClientSettings.FromConnectionString(connectionString);

// Read Concern
settings.ReadConcern = ReadConcern.Majority; // Wait for majority acknowledgment
// Other options: Local, Linearizable, Snapshot, Available

// Write Concern
settings.WriteConcern = new WriteConcern(
    w: "majority",              // Wait for majority
    wTimeout: TimeSpan.FromSeconds(5), // Timeout
    journal: true               // Wait for journal
);
// Other w options: 1 (primary only), 0 (unacknowledged), "majority", number

// Read Preference
settings.ReadPreference = ReadPreference.SecondaryPreferred;
// Options: Primary, PrimaryPreferred, Secondary, SecondaryPreferred, Nearest

var client = new MongoClient(settings);
```

### Configuration from appsettings.json (ASP.NET Core)

```json
{
  "MongoDB": {
    "ConnectionString": "mongodb://localhost:27017",
    "DatabaseName": "shop",
    "MaxConnectionPoolSize": 100,
    "MinConnectionPoolSize": 10,
    "ConnectTimeoutSeconds": 30,
    "ApplicationName": "MyShopApi"
  }
}
```

```csharp
// Configuration class
public class MongoDbSettings
{
    public string ConnectionString { get; set; } = string.Empty;
    public string DatabaseName { get; set; } = string.Empty;
    public int MaxConnectionPoolSize { get; set; } = 100;
    public int MinConnectionPoolSize { get; set; } = 10;
    public int ConnectTimeoutSeconds { get; set; } = 30;
    public string ApplicationName { get; set; } = string.Empty;
}

// Startup/Program.cs
var mongoSettings = builder.Configuration
    .GetSection("MongoDB")
    .Get<MongoDbSettings>()!;

var clientSettings = MongoClientSettings.FromConnectionString(
    mongoSettings.ConnectionString
);
clientSettings.MaxConnectionPoolSize = mongoSettings.MaxConnectionPoolSize;
clientSettings.MinConnectionPoolSize = mongoSettings.MinConnectionPoolSize;
clientSettings.ConnectTimeout = TimeSpan.FromSeconds(mongoSettings.ConnectTimeoutSeconds);
clientSettings.ApplicationName = mongoSettings.ApplicationName;

builder.Services.AddSingleton<IMongoClient>(new MongoClient(clientSettings));

builder.Services.AddScoped(sp =>
{
    var client = sp.GetRequiredService<IMongoClient>();
    return client.GetDatabase(mongoSettings.DatabaseName);
});
```

### Monitoring and Health Checks

```csharp
using MongoDB.Driver;

public class MongoHealthCheck
{
    private readonly IMongoClient _client;
    
    public MongoHealthCheck(IMongoClient client)
    {
        _client = client;
    }
    
    public async Task<bool> CheckHealthAsync(CancellationToken cancellationToken)
    {
        try
        {
            // Ping the database
            var database = _client.GetDatabase("admin");
            var command = new BsonDocument { { "ping", 1 } };
            await database.RunCommandAsync<BsonDocument>(
                command,
                cancellationToken: cancellationToken
            );
            return true;
        }
        catch
        {
            return false;
        }
    }
}
```

### Connection Events (Monitoring)

```csharp
using MongoDB.Driver.Core.Events;

var settings = MongoClientSettings.FromConnectionString(connectionString);

// Subscribe to connection pool events
settings.ClusterConfigurator = cb =>
{
    cb.Subscribe<ConnectionPoolOpenedEvent>(e =>
    {
        Console.WriteLine($"Pool opened. ServerId: {e.ServerId}");
    });
    
    cb.Subscribe<ConnectionPoolClosedEvent>(e =>
    {
        Console.WriteLine($"Pool closed. ServerId: {e.ServerId}");
    });
    
    cb.Subscribe<ConnectionCreatedEvent>(e =>
    {
        Console.WriteLine($"Connection created. ConnectionId: {e.ConnectionId}");
    });
    
    cb.Subscribe<ConnectionPoolCheckedOutConnectionEvent>(e =>
    {
        Console.WriteLine($"Connection checked out. ConnectionId: {e.ConnectionId}");
    });
    
    cb.Subscribe<ConnectionPoolCheckedInConnectionEvent>(e =>
    {
        Console.WriteLine($"Connection checked in. ConnectionId: {e.ConnectionId}");
    });
    
    cb.Subscribe<CommandStartedEvent>(e =>
    {
        Console.WriteLine($"Command started: {e.CommandName}");
    });
};

var client = new MongoClient(settings);
```

## Performance Tuning Guidelines

### Optimal Pool Size

| Scenario | MinPoolSize | MaxPoolSize | MaxConnecting |
|----------|-------------|-------------|---------------|
| Low-traffic app | 0 | 50 | 2 |
| Medium-traffic app | 10 | 100 | 2 |
| High-traffic app | 25 | 200 | 5 |
| Microservice | 5 | 50 | 2 |

### Timeout Recommendations

| Setting | Conservative | Aggressive | Use Case |
|---------|-------------|------------|----------|
| ConnectTimeout | 30s | 10s | Time to establish connection |
| SocketTimeout | 120s | 30s | Time for operation to complete |
| ServerSelectionTimeout | 30s | 10s | Time to find suitable server |

## Troubleshooting Common Issues

### Connection Timeout

```csharp
// Problem: ConnectTimeout too low
// Solution: Increase timeout or check network
settings.ConnectTimeout = TimeSpan.FromSeconds(60);
```

### Pool Exhaustion

```csharp
// Problem: All connections in use, WaitQueueTimeout exceeded
// Solution: Increase MaxPoolSize or optimize query performance
settings.MaxConnectionPoolSize = 200;
```

### Slow Startup

```csharp
// Problem: Creating connections at startup is slow
// Solution: Increase MinPoolSize to pre-create connections
settings.MinConnectionPoolSize = 10;
```

## Best Practices

1. **Singleton Client:** Create `MongoClient` once and reuse it.
2. **Connection String Security:** Store connection strings securely (Azure Key Vault, environment variables).
3. **Application Name:** Set application name for easier monitoring.
4. **Appropriate Pool Size:** Start conservative, tune based on metrics.
5. **Timeout Configuration:** Set timeouts appropriate for your network and operations.
6. **SSL in Production:** Always use SSL/TLS for production.
7. **Monitor Connection Pool:** Subscribe to events in development to understand behavior.
8. **Retry Configuration:** Enable retry writes and reads for resilience.
