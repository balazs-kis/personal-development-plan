## Introduction

StackExchange.Redis is the primary .NET client library for Redis, providing high-performance, thread-safe access to Redis from C# applications. It supports all Redis features including data structures, pub/sub, transactions, and Lua scripting. Understanding how to use this library effectively is essential for building scalable .NET applications with Redis.

### ConnectionMultiplexer

The central object that manages the connection to Redis. It should be created once and reused.

```csharp
using StackExchange.Redis;

// Basic connection
var redis = ConnectionMultiplexer.Connect("localhost:6379");

// Connection string with options
var redis = ConnectionMultiplexer.Connect("localhost:6379,password=secret,ssl=true");

// Using ConfigurationOptions
var options = ConfigurationOptions.Parse("localhost:6379");
options.Password = "secret";
options.Ssl = true;
options.AbortOnConnectFail = false;
options.ConnectTimeout = 5000;
options.SyncTimeout = 5000;

var redis = await ConnectionMultiplexer.ConnectAsync(options);
```

#### Connection String Options

```csharp
var connectionString = "localhost:6379," +
    "password=secret," +
    "ssl=true," +
    "abortConnect=false," +    // Don't fail on initial connect
    "connectTimeout=5000," +   // 5 seconds to connect
    "syncTimeout=5000," +      // 5 seconds for sync operations
    "connectRetry=3," +        // Retry 3 times
    "keepAlive=60," +          // Send keepalive every 60 seconds
    "allowAdmin=false";        // Disable admin commands

var redis = ConnectionMultiplexer.Connect(connectionString);
```

#### Best Practices

```csharp
// ✅ CORRECT: Singleton instance
public class RedisService
{
    private static readonly Lazy<ConnectionMultiplexer> _lazyConnection = 
        new(() => ConnectionMultiplexer.Connect("localhost:6379"));
    
    public static ConnectionMultiplexer Connection => _lazyConnection.Value;
}

// ❌ WRONG: Creating new connection every time
public string GetValue(string key)
{
    var redis = ConnectionMultiplexer.Connect("localhost:6379"); // Don't do this!
    var db = redis.GetDatabase();
    return db.StringGet(key);
}
```

### ASP.NET Core Integration with IDistributedCache

#### Configuration (Program.cs)

```csharp
using Microsoft.Extensions.Caching.Distributed;

var builder = WebApplication.CreateBuilder(args);

// Add Redis distributed cache
builder.Services.AddStackExchangeRedisCache(options =>
{
    options.Configuration = builder.Configuration.GetConnectionString("Redis");
    options.InstanceName = "MyApp:";  // Prefix for all keys
});

// Alternative: More configuration options
builder.Services.AddStackExchangeRedisCache(options =>
{
    options.ConfigurationOptions = new ConfigurationOptions
    {
        EndPoints = { "localhost:6379" },
        Password = "secret",
        Ssl = true,
        AbortOnConnectFail = false,
        ConnectTimeout = 5000
    };
    options.InstanceName = "MyApp:";
});

var app = builder.Build();
```

#### Using IDistributedCache

```csharp
using Microsoft.Extensions.Caching.Distributed;
using System.Text.Json;

public class ProductService
{
    private readonly IDistributedCache _cache;
    private readonly ApplicationDbContext _database;
    
    public ProductService(IDistributedCache cache, ApplicationDbContext database)
    {
        _cache = cache;
        _database = database;
    }
    
    public async Task<Product?> GetProductAsync(int id)
    {
        var cacheKey = $"product:{id}";
        
        // Try to get from cache
        var cachedBytes = await _cache.GetAsync(cacheKey);
        if (cachedBytes != null)
        {
            return JsonSerializer.Deserialize<Product>(cachedBytes);
        }
        
        // Load from database
        var product = await _database.Products.FindAsync(id);
        if (product == null)
            return null;
        
        // Cache with 5-minute expiration
        var serialized = JsonSerializer.SerializeToUtf8Bytes(product);
        await _cache.SetAsync(cacheKey, serialized, new DistributedCacheEntryOptions
        {
            AbsoluteExpirationRelativeToNow = TimeSpan.FromMinutes(5)
        });
        
        return product;
    }
    
    // Helper method for cleaner code
    public async Task<T?> GetOrSetAsync<T>(
        string key,
        Func<Task<T>> factory,
        TimeSpan? expiration = null)
    {
        // Try cache
        var cachedBytes = await _cache.GetAsync(key);
        if (cachedBytes != null)
        {
            return JsonSerializer.Deserialize<T>(cachedBytes);
        }
        
        // Execute factory
        var value = await factory();
        if (value == null)
            return default;
        
        // Cache result
        var serialized = JsonSerializer.SerializeToUtf8Bytes(value);
        await _cache.SetAsync(key, serialized, new DistributedCacheEntryOptions
        {
            AbsoluteExpirationRelativeToNow = expiration ?? TimeSpan.FromMinutes(5)
        });
        
        return value;
    }
}

// Usage
public async Task<Product?> GetProductAsync(int id)
{
    return await _cache.GetOrSetAsync(
        $"product:{id}",
        async () => await _database.Products.FindAsync(id),
        TimeSpan.FromMinutes(10)
    );
}
```

### Output Caching with Redis (.NET 7+)

```csharp
// Program.cs
builder.Services.AddOutputCache(options =>
{
    options.AddBasePolicy(builder => builder.Expire(TimeSpan.FromMinutes(5)));
});

// Use Redis for output cache (requires Redis module)
builder.Services.AddStackExchangeRedisOutputCache(options =>
{
    options.Configuration = builder.Configuration.GetConnectionString("Redis");
    options.InstanceName = "OutputCache:";
});

var app = builder.Build();

app.UseOutputCache();

// Controller/Endpoint
[ApiController]
[Route("api/[controller]")]
public class ProductsController : ControllerBase
{
    [HttpGet]
    [OutputCache(Duration = 300)] // Cache for 5 minutes
    public async Task<IActionResult> GetAll()
    {
        var products = await _database.Products.ToListAsync();
        return Ok(products);
    }
    
    [HttpGet("{id}")]
    [OutputCache(Duration = 300, VaryByRouteValueNames = new[] { "id" })]
    public async Task<IActionResult> GetById(int id)
    {
        var product = await _database.Products.FindAsync(id);
        return product == null ? NotFound() : Ok(product);
    }
}
```

### Batching and Transactions

```csharp
// Batching (fire and forget)
var db = redis.GetDatabase();
var batch = db.CreateBatch();

var task1 = batch.StringSetAsync("key1", "value1");
var task2 = batch.StringSetAsync("key2", "value2");
var task3 = batch.StringSetAsync("key3", "value3");

batch.Execute();

await Task.WhenAll(task1, task2, task3);

// Transactions (atomic)
var tran = db.CreateTransaction();

tran.AddCondition(Condition.KeyNotExists("lock:resource"));

var setTask = tran.StringSetAsync("lock:resource", "locked", TimeSpan.FromSeconds(30));
var incrTask = tran.StringIncrementAsync("counter");

if (await tran.ExecuteAsync())
{
    Console.WriteLine("Transaction succeeded");
}
else
{
    Console.WriteLine("Transaction failed (condition not met)");
}
```

### Lua Scripts

```csharp
// Rate limiter using Lua script
const string rateLimitScript = @"
    local key = KEYS[1]
    local limit = tonumber(ARGV[1])
    local window = tonumber(ARGV[2])
    
    local current = redis.call('INCR', key)
    if current == 1 then
        redis.call('EXPIRE', key, window)
    end
    
    if current > limit then
        return 0
    else
        return 1
    end
";

public async Task<bool> IsRateLimitedAsync(string userId, int limit, int windowSeconds)
{
    var db = redis.GetDatabase();
    var key = $"rate:{userId}";
    
    var result = await db.ScriptEvaluateAsync(
        rateLimitScript,
        new RedisKey[] { key },
        new RedisValue[] { limit, windowSeconds }
    );
    
    return (int)result == 0; // 0 = rate limited, 1 = allowed
}
```

### Error Handling and Resilience

```csharp
public class ResilientCacheService
{
    private readonly IDatabase _db;
    private readonly ILogger<ResilientCacheService> _logger;
    
    public async Task<T?> GetAsync<T>(string key)
    {
        try
        {
            var value = await _db.StringGetAsync(key);
            if (value.IsNullOrEmpty)
                return default;
            
            return JsonSerializer.Deserialize<T>(value!);
        }
        catch (RedisConnectionException ex)
        {
            _logger.LogError(ex, "Redis connection failed for key {Key}", key);
            return default; // Fallback to null
        }
        catch (RedisTimeoutException ex)
        {
            _logger.LogError(ex, "Redis timeout for key {Key}", key);
            return default;
        }
    }
    
    public async Task SetAsync<T>(string key, T value, TimeSpan? expiry = null)
    {
        try
        {
            var serialized = JsonSerializer.Serialize(value);
            await _db.StringSetAsync(key, serialized, expiry);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Failed to cache key {Key}", key);
            // Don't throw - cache failure shouldn't break the application
        }
    }
}
```

### Configuration Best Practices

```csharp
var options = ConfigurationOptions.Parse(connectionString);

// Connection
options.AbortOnConnectFail = false;      // Keep trying to connect
options.ConnectTimeout = 5000;           // 5 seconds to establish connection
options.SyncTimeout = 5000;              // 5 seconds for sync operations
options.AsyncTimeout = 5000;             // 5 seconds for async operations
options.ConnectRetry = 3;                // Retry 3 times

// Keep-alive
options.KeepAlive = 60;                  // Send keepalive every 60 seconds

// Security
options.Password = "secret";
options.Ssl = true;
options.AllowAdmin = false;              // Disable dangerous commands

// Resilience
options.ReconnectRetryPolicy = new ExponentialRetry(5000);

var redis = await ConnectionMultiplexer.ConnectAsync(options);
```

## Production Considerations

1. **Connection Management:**
   - Use singleton ConnectionMultiplexer
   - Configure appropriate timeouts
   - Enable connection keep-alive

2. **Error Handling:**
   - Wrap Redis calls in try-catch
   - Don't let cache failures break functionality
   - Log errors for monitoring

3. **Performance:**
   - Use batching for multiple operations
   - Use async methods
   - Consider pipeline operations

4. **Monitoring:**
   - Subscribe to connection events
   - Track cache hit rates
   - Monitor Redis memory usage

5. **Security:**
   - Use SSL/TLS in production
   - Implement authentication
   - Disable admin commands

## Best Practices

1. **Singleton Connection:** Create ConnectionMultiplexer once
2. **Use IDistributedCache:** For standard caching scenarios
3. **Handle Failures Gracefully:** Cache should enhance, not break
4. **Set Appropriate Timeouts:** Balance responsiveness and reliability
5. **Monitor Performance:** Track cache operations
6. **Use Strong Types:** Leverage C# type system for safety
7. **Test Failover:** Ensure application works without Redis
