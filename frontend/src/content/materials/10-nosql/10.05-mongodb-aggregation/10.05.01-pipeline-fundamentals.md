## Introduction

The MongoDB aggregation framework is a powerful data processing pipeline that allows you to perform complex transformations, analytics, and computations directly in the database. Unlike simple find queries that return documents as-is, aggregation pipelines can filter, reshape, group, and calculate data in sophisticated ways. Understanding the pipeline concept—where data flows through sequential stages, each transforming the output of the previous stage—is fundamental to mastering MongoDB data analysis.

## Key Concepts Summary

### What is an Aggregation Pipeline?

An aggregation pipeline is a framework for data processing where documents pass through multiple **stages**, each performing a specific operation:

```javascript
db.collection.aggregate([
  { <stage1> },
  { <stage2> },
  { <stage3> }
])
```

**Key characteristics:**
- Documents flow sequentially through stages
- Each stage transforms the input and passes output to the next stage
- Similar to Unix pipes: `stage1 | stage2 | stage3`
- Stages can filter, transform, group, sort, or reshape data

### Aggregation vs. Find Queries

**Find Query (Simple):**
```javascript
// Returns matching documents as-is
db.orders.find({ status: "completed" })
```

**Aggregation Pipeline (Powerful):**
```javascript
// Calculates total sales by product category
db.orders.aggregate([
  { $match: { status: "completed" } },
  { $unwind: "$items" },
  { $group: {
      _id: "$items.category",
      totalSales: { $sum: { $multiply: ["$items.price", "$items.quantity"] } },
      orderCount: { $sum: 1 }
    }
  },
  { $sort: { totalSales: -1 } }
])
```

**When to use aggregation:**
- Computing calculations (sums, averages, counts)
- Grouping data by fields
- Transforming document structure
- Joining data from multiple collections
- Complex filtering with multiple conditions
- Reshaping arrays and nested documents

### Basic Pipeline Example

**Scenario:** Analyze movie ratings from a movies collection.

```javascript
// Sample document
{
  _id: 1,
  title: "The Matrix",
  year: 1999,
  genres: ["Action", "Sci-Fi"],
  rating: 8.7,
  votes: 1500000
}

// Pipeline: Find top-rated Sci-Fi movies from 2000s
db.movies.aggregate([
  // Stage 1: Filter to 2000s movies
  {
    $match: {
      year: { $gte: 2000, $lte: 2009 },
      genres: "Sci-Fi"
    }
  },
  
  // Stage 2: Only keep fields we need
  {
    $project: {
      title: 1,
      year: 1,
      rating: 1
    }
  },
  
  // Stage 3: Sort by rating descending
  {
    $sort: { rating: -1 }
  },
  
  // Stage 4: Get top 10
  {
    $limit: 10
  }
])
```

**Output:**
```javascript
[
  { _id: 5, title: "Inception", year: 2010, rating: 8.8 },
  { _id: 8, title: "District 9", year: 2009, rating: 7.9 },
  // ... 8 more movies
]
```

### Common Aggregation Stages

| Stage | Purpose | Example |
|-------|---------|---------|
| `$match` | Filter documents | `{ $match: { status: "active" } }` |
| `$project` | Select/reshape fields | `{ $project: { name: 1, total: "$amount" } }` |
| `$group` | Group and calculate | `{ $group: { _id: "$category", count: { $sum: 1 } } }` |
| `$sort` | Sort results | `{ $sort: { createdAt: -1 } }` |
| `$limit` | Limit number of docs | `{ $limit: 100 }` |
| `$skip` | Skip documents | `{ $skip: 20 }` |
| `$lookup` | Join collections | `{ $lookup: { from: "users", ... } }` |
| `$unwind` | Deconstruct arrays | `{ $unwind: "$items" }` |

### Pipeline Data Flow

Understanding how documents transform through stages:

```javascript
// Initial documents
[
  { name: "Alice", age: 30, city: "NYC" },
  { name: "Bob", age: 25, city: "LA" },
  { name: "Charlie", age: 30, city: "NYC" }
]

// After $match: { age: 30 }
[
  { name: "Alice", age: 30, city: "NYC" },
  { name: "Charlie", age: 30, city: "NYC" }
]

// After $group: { _id: "$city", count: { $sum: 1 } }
[
  { _id: "NYC", count: 2 }
]
```

Each stage receives documents from the previous stage and outputs transformed documents to the next stage.

## Practice Exercise

After completing the materials, try this exercise (do not spend more than 15 minutes):

Given a `sales` collection with documents like:
```javascript
{
  _id: 1,
  product: "Laptop",
  category: "Electronics",
  price: 1200,
  quantity: 2,
  date: ISODate("2026-01-15")
}
```

Write aggregation pipelines to:

1. **Find total sales (price × quantity) for all orders**
   - Hint: Use `$group` with `$sum` and `$multiply`

2. **Get sales by category, sorted by total descending**
   - Hint: Group by category, calculate total, then sort

3. **Find the average order value (price × quantity per order)**
   - Hint: Use `$avg` accumulator

4. **Count how many products were sold in January 2026**
   - Hint: `$match` for date range, then `$group` with `$sum`
