# Chapter 10.3: MongoDB Fundamentals

## Overview
This chapter teaches MongoDB basics: CRUD operations, query operators, projections, and the MongoDB shell. You'll learn to interact with MongoDB through practical examples and understand the query language that makes MongoDB powerful.

## Key Concepts
- **CRUD Operations:** creating, reading, updating, and deleting documents.
- **Query Operators:** filtering and matching documents with operators.
- **Projections:** selecting specific fields from query results.
- **Sort, Skip, Limit:** controlling result sets and pagination.
- **MongoDB Tools:** using mongosh shell and Compass GUI.
