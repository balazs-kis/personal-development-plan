## Introduction

The Authorization Code Flow with PKCE (Proof Key for Code Exchange) is the modern standard for OAuth 2.0 authentication. Originally designed to secure public clients like mobile apps and SPAs, PKCE is now recommended for *all* OAuth 2.0 clients, including confidential clients with backend servers.

PKCE solves a critical security problem: what happens if an attacker intercepts the authorization code? Without PKCE, they could exchange it for an access token. PKCE makes this attack impossible.

## Key Concepts Summary

### The Problem PKCE Solves

**Without PKCE:**
```
1. Malicious app intercepts authorization code from URL
2. Malicious app exchanges code for access token
3. Malicious app gains access to user's resources
```

**With PKCE:**
```
1. Malicious app intercepts authorization code
2. Malicious app tries to exchange code
3. Authorization server rejects: code verifier doesn't match
4. Attack prevented ✓
```

### How PKCE Works

PKCE adds two parameters to the OAuth 2.0 flow:
1. **Code Verifier:** A cryptographically random string (43-128 characters)
2. **Code Challenge:** SHA256 hash of the code verifier, base64-url encoded

```
┌─────────────────────────────────────────────────────────────┐
│ Step 1: Generate Code Verifier and Challenge               │
└─────────────────────────────────────────────────────────────┘

Code Verifier (random):
  "dBjftJeZ4CVP-mB92K27uhbUJU1p1r_wW1gFWFOEjXk"

Code Challenge (SHA256 hash, base64url encoded):
  "E9Melhoa2OwvFrEMTJguCHaoeK1t8URWbuGJSstw-cM"
```

### Complete PKCE Flow

```
┌──────────┐                                  ┌─────────────────┐
│  Client  │                                  │ Authorization   │
│          │                                  │ Server          │
└────┬─────┘                                  └────────┬────────┘
     │                                                  │
     │ 1. Generate Code Verifier                       │
     │    code_verifier = random(43-128 chars)         │
     │                                                  │
     │ 2. Create Code Challenge                        │
     │    code_challenge = SHA256(code_verifier)       │
     │                                                  │
     │ 3. Authorization Request                        │
     ├─────────────────────────────────────────────────>│
     │    + code_challenge                             │
     │    + code_challenge_method=S256                 │
     │                                                  │
     │                                4. User Authorizes│
     │                                                  │
     │ 5. Authorization Code                           │
     │<─────────────────────────────────────────────────┤
     │                                                  │
     │ 6. Token Request                                │
     ├─────────────────────────────────────────────────>│
     │    + authorization_code                         │
     │    + code_verifier                              │
     │                                                  │
     │                     7. Verify:                  │
     │                     SHA256(code_verifier) ==    │
     │                     code_challenge?             │
     │                                                  │
     │ 8. Access Token                                 │
     │<─────────────────────────────────────────────────┤
     │    (only if verification passes)                │
     │                                                  │
```

## Implementation Examples

### Step 1: Generate Code Verifier

```csharp
// C# implementation
using System.Security.Cryptography;
using System.Text;

public static string GenerateCodeVerifier()
{
    // Generate 32 random bytes
    var bytes = new byte[32];
    RandomNumberGenerator.Fill(bytes);
    
    // Base64-url encode (43 characters)
    return Base64UrlEncode(bytes);
}

private static string Base64UrlEncode(byte[] input)
{
    return Convert.ToBase64String(input)
        .TrimEnd('=')
        .Replace('+', '-')
        .Replace('/', '_');
}
```

### Step 2: Create Code Challenge

```csharp
public static string GenerateCodeChallenge(string codeVerifier)
{
    // SHA256 hash
    using var sha256 = SHA256.Create();
    var hash = sha256.ComputeHash(Encoding.UTF8.GetBytes(codeVerifier));
    
    // Base64-url encode
    return Base64UrlEncode(hash);
}
```

### Step 3: Build Authorization URL

```csharp
public static string BuildAuthorizationUrl(
    string authorizationEndpoint,
    string clientId,
    string redirectUri,
    string codeChallenge,
    string state)
{
    var queryParams = new Dictionary<string, string>
    {
        ["response_type"] = "code",
        ["client_id"] = clientId,
        ["redirect_uri"] = redirectUri,
        ["scope"] = "openid profile email",
        ["state"] = state,
        ["code_challenge"] = codeChallenge,
        ["code_challenge_method"] = "S256"
    };
    
    var query = string.Join("&", 
        queryParams.Select(kvp => $"{kvp.Key}={Uri.EscapeDataString(kvp.Value)}"));
    
    return $"{authorizationEndpoint}?{query}";
}
```

### Step 4: Exchange Code for Token

```csharp
public static async Task<TokenResponse> ExchangeCodeForToken(
    string tokenEndpoint,
    string clientId,
    string code,
    string codeVerifier,
    string redirectUri)
{
    using var httpClient = new HttpClient();
    
    var requestBody = new Dictionary<string, string>
    {
        ["grant_type"] = "authorization_code",
        ["code"] = code,
        ["client_id"] = clientId,
        ["redirect_uri"] = redirectUri,
        ["code_verifier"] = codeVerifier  // ← PKCE magic happens here
    };
    
    var response = await httpClient.PostAsync(
        tokenEndpoint,
        new FormUrlEncodedContent(requestBody));
    
    response.EnsureSuccessStatusCode();
    
    return await response.Content.ReadFromJsonAsync<TokenResponse>();
}
```

## JavaScript/TypeScript Example

```typescript
// Generate code verifier
function generateCodeVerifier(): string {
    const array = new Uint8Array(32);
    crypto.getRandomValues(array);
    return base64UrlEncode(array);
}

// Generate code challenge
async function generateCodeChallenge(verifier: string): Promise<string> {
    const encoder = new TextEncoder();
    const data = encoder.encode(verifier);
    const hash = await crypto.subtle.digest('SHA-256', data);
    return base64UrlEncode(new Uint8Array(hash));
}

function base64UrlEncode(array: Uint8Array): string {
    return btoa(String.fromCharCode(...array))
        .replace(/\+/g, '-')
        .replace(/\//g, '_')
        .replace(/=+$/, '');
}

// Complete flow
async function initiateOAuthFlow() {
    // Generate and store verifier
    const codeVerifier = generateCodeVerifier();
    sessionStorage.setItem('code_verifier', codeVerifier);
    
    // Generate challenge
    const codeChallenge = await generateCodeChallenge(codeVerifier);
    
    // Build authorization URL
    const params = new URLSearchParams({
        response_type: 'code',
        client_id: 'your-client-id',
        redirect_uri: 'https://your-app.com/callback',
        scope: 'openid profile email',
        state: generateRandomState(),
        code_challenge: codeChallenge,
        code_challenge_method: 'S256'
    });
    
    // Redirect to authorization server
    window.location.href = `https://auth.example.com/authorize?${params}`;
}

// After redirect back
async function handleCallback(code: string) {
    const codeVerifier = sessionStorage.getItem('code_verifier');
    
    const response = await fetch('https://auth.example.com/token', {
        method: 'POST',
        headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
        body: new URLSearchParams({
            grant_type: 'authorization_code',
            code: code,
            client_id: 'your-client-id',
            redirect_uri: 'https://your-app.com/callback',
            code_verifier: codeVerifier!
        })
    });
    
    const tokens = await response.json();
    // Store tokens securely
}
```

## Security Considerations

### Why PKCE for All Clients?

**Original thinking:** PKCE only for public clients (SPAs, mobile apps)

**Current best practice (RFC 9700, 2025):** PKCE for *all* clients, including confidential clients

**Reasons:**
1. **Defense in depth:** Adds security even if client secret is compromised
2. **Prevents authorization code injection attacks**
3. **No downside:** Minimal overhead, significant security benefit
4. **Future-proof:** Aligns with latest security standards

### Code Verifier Requirements

```
Length: 43-128 characters
Characters: A-Z, a-z, 0-9, -, ., _, ~
Entropy: High (cryptographically random)

✅ GOOD: "dBjftJeZ4CVP-mB92K27uhbUJU1p1r_wW1gFWFOEjXk"
❌ BAD:  "password123"  (predictable)
❌ BAD:  "abc"  (too short)
```

### Code Challenge Methods

```
S256 (SHA256): ✅ RECOMMENDED
  - More secure
  - Supported by all modern servers

plain: ⚠️ FALLBACK ONLY
  - code_challenge = code_verifier (no hashing)
  - Only use if S256 not supported
  - Still better than no PKCE
```

## Common Pitfalls

### ❌ Storing code verifier insecurely
```javascript
// BAD: localStorage is vulnerable to XSS
localStorage.setItem('code_verifier', verifier);

// BETTER: sessionStorage (cleared on tab close)
sessionStorage.setItem('code_verifier', verifier);

// BEST: In-memory (for SPAs)
let codeVerifier = generateCodeVerifier();
```

### ❌ Reusing code verifiers
```csharp
// BAD: Reusing the same verifier
static string codeVerifier = GenerateCodeVerifier();

// GOOD: Generate fresh verifier for each flow
string codeVerifier = GenerateCodeVerifier();
```

### ❌ Using weak random number generators
```javascript
// BAD: Not cryptographically secure
Math.random().toString(36)

// GOOD: Cryptographically secure
crypto.getRandomValues(new Uint8Array(32))
```

## ASP.NET Core Integration

```csharp
// Startup.cs / Program.cs
services.AddAuthentication(options =>
{
    options.DefaultScheme = CookieAuthenticationDefaults.AuthenticationScheme;
    options.DefaultChallengeScheme = OpenIdConnectDefaults.AuthenticationScheme;
})
.AddCookie()
.AddOpenIdConnect(options =>
{
    options.Authority = "https://auth.example.com";
    options.ClientId = "your-client-id";
    options.ClientSecret = "your-client-secret";  // For confidential clients
    options.ResponseType = "code";  // Authorization Code Flow
    
    // PKCE is enabled by default in ASP.NET Core 3.0+
    // But you can explicitly enable it:
    options.UsePkce = true;
    
    options.Scope.Add("openid");
    options.Scope.Add("profile");
    options.Scope.Add("email");
    
    options.SaveTokens = true;
});
```
