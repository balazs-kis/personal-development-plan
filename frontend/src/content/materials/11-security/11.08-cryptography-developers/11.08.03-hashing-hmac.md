## Introduction

Cryptographic hash functions are one-way mathematical operations that produce a fixed-size output (digest) from arbitrary input data. Unlike encryption, hashing cannot be reversed—you can't get the original data back from a hash. Hashes are used for integrity verification, digital signatures, and password storage (with proper techniques). This lesson covers hashing for integrity and authentication, not password storage.

**Key principle:** Hash functions are for integrity verification and identification, not for confidentiality. Use appropriate hash algorithms (SHA-256+) and HMAC when authentication is needed.

## Key Concepts Summary

### What is a Cryptographic Hash?

A hash function takes input data of any size and produces a fixed-size output (digest):

```
"Hello" → SHA256 → 185f8db32271fe25f561a6fc938b2e264306ec304eda518007d1764826381969
"Hello!" → SHA256 → 334d016f755cd6dc58c53a86e183882f8ec14f52fb05345887c8a5edd42c87b7

Key properties:
- Deterministic: Same input always produces same output
- One-way: Cannot reverse hash to get original data
- Avalanche effect: Small input change drastically changes output
- Collision resistant: Nearly impossible to find two inputs with same hash
- Fixed size: Always same length regardless of input size
```

### Computing SHA-256 Hashes

```csharp
using System.Security.Cryptography;
using System.Text;

public class HashingService
{
    // Simple hash computation
    public static string ComputeSHA256Hash(string input)
    {
        byte[] bytes = Encoding.UTF8.GetBytes(input);
        byte[] hash = SHA256.HashData(bytes);
        
        // Convert to hexadecimal string
        return Convert.ToHexString(hash).ToLower();
    }
    
    // Alternative: Using StringBuilder for hex conversion
    public static string ComputeSHA256HashAlt(string input)
    {
        byte[] bytes = Encoding.UTF8.GetBytes(input);
        byte[] hash = SHA256.HashData(bytes);
        
        var builder = new StringBuilder();
        foreach (byte b in hash)
        {
            builder.Append(b.ToString("x2"));
        }
        return builder.ToString();
    }
}

// Usage
string data = "Sensitive document content";
string hash = HashingService.ComputeSHA256Hash(data);
Console.WriteLine($"SHA-256: {hash}");
// Output: 64 characters (256 bits / 4 bits per hex digit = 64)
```

### Hashing Files for Integrity

```csharp
public static string ComputeFileHash(string filePath)
{
    using var stream = File.OpenRead(filePath);
    byte[] hash = SHA256.HashData(stream);
    return Convert.ToHexString(hash).ToLower();
}

// Verify file integrity
public static bool VerifyFileIntegrity(string filePath, string expectedHash)
{
    string actualHash = ComputeFileHash(filePath);
    
    // Use constant-time comparison to prevent timing attacks
    return CryptographicOperations.FixedTimeEquals(
        Convert.FromHexString(expectedHash),
        Convert.FromHexString(actualHash)
    );
}

// Usage
string filePath = "important-document.pdf";
string originalHash = ComputeFileHash(filePath);
Console.WriteLine($"Original hash: {originalHash}");

// Later, verify the file hasn't been tampered with
bool isValid = VerifyFileIntegrity(filePath, originalHash);
Console.WriteLine($"File integrity: {(isValid ? "Valid" : "Compromised")}");
```

### HMAC (Hash-based Message Authentication Code)

HMAC adds a secret key to hashing, proving both integrity and authenticity:

```csharp
public class HmacService
{
    // Generate HMAC-SHA256
    public static byte[] ComputeHMAC(byte[] data, byte[] key)
    {
        using var hmac = new HMACSHA256(key);
        return hmac.ComputeHash(data);
    }
    
    // Verify HMAC
    public static bool VerifyHMAC(byte[] data, byte[] key, byte[] expectedHmac)
    {
        byte[] actualHmac = ComputeHMAC(data, key);
        
        // Use constant-time comparison
        return CryptographicOperations.FixedTimeEquals(actualHmac, expectedHmac);
    }
}

// Usage
string message = "Transfer $1000 to account 12345";
byte[] key = RandomNumberGenerator.GetBytes(32); // 256-bit key

byte[] messageBytes = Encoding.UTF8.GetBytes(message);
byte[] hmac = HmacService.ComputeHMAC(messageBytes, key);

Console.WriteLine($"Message: {message}");
Console.WriteLine($"HMAC: {Convert.ToHexString(hmac)}");

// Verify the message hasn't been tampered with
bool isValid = HmacService.VerifyHMAC(messageBytes, key, hmac);
Console.WriteLine($"Valid: {isValid}");
```

### API Authentication with HMAC

```csharp
public class ApiAuthenticationService
{
    private readonly byte[] _apiSecret;
    
    public ApiAuthenticationService(string apiSecret)
    {
        _apiSecret = Encoding.UTF8.GetBytes(apiSecret);
    }
    
    // Create signature for API request
    public string CreateSignature(HttpRequestMessage request)
    {
        // Build string to sign: METHOD + URI + TIMESTAMP + BODY
        var timestamp = DateTimeOffset.UtcNow.ToUnixTimeSeconds().ToString();
        var method = request.Method.ToString();
        var uri = request.RequestUri?.AbsolutePath ?? "";
        var body = request.Content?.ReadAsStringAsync().Result ?? "";
        
        var stringToSign = $"{method}\n{uri}\n{timestamp}\n{body}";
        var dataToSign = Encoding.UTF8.GetBytes(stringToSign);
        
        // Compute HMAC
        using var hmac = new HMACSHA256(_apiSecret);
        byte[] signatureBytes = hmac.ComputeHash(dataToSign);
        
        return Convert.ToBase64String(signatureBytes);
    }
    
    // Verify incoming request signature
    public bool VerifySignature(string receivedSignature, HttpRequestMessage request)
    {
        string computedSignature = CreateSignature(request);
        
        byte[] receivedBytes = Convert.FromBase64String(receivedSignature);
        byte[] computedBytes = Convert.FromBase64String(computedSignature);
        
        return CryptographicOperations.FixedTimeEquals(receivedBytes, computedBytes);
    }
}

// Usage in API
public class SecureApiClient
{
    private readonly ApiAuthenticationService _auth;
    private readonly HttpClient _client;
    
    public async Task<string> MakeAuthenticatedRequest(string endpoint, object payload)
    {
        var request = new HttpRequestMessage(HttpMethod.Post, endpoint);
        request.Content = JsonContent.Create(payload);
        
        // Add HMAC signature to header
        string signature = _auth.CreateSignature(request);
        request.Headers.Add("X-API-Signature", signature);
        request.Headers.Add("X-API-Timestamp", DateTimeOffset.UtcNow.ToUnixTimeSeconds().ToString());
        
        var response = await _client.SendAsync(request);
        return await response.Content.ReadAsStringAsync();
    }
}
```

### Hashing vs Password Hashing

```csharp
// ❌ WRONG: Do NOT use SHA-256 for passwords!
public static string HashPassword_INSECURE(string password)
{
    // This is FAST, which is BAD for passwords
    // Vulnerable to brute force and rainbow table attacks
    return HashingService.ComputeSHA256Hash(password);
}

// ✅ CORRECT: Use password-specific algorithms with salt and iterations
public static string HashPassword_SECURE(string password)
{
    // Use Rfc2898DeriveBytes (PBKDF2), Argon2, Scrypt, or BCrypt
    byte[] salt = RandomNumberGenerator.GetBytes(16);
    
    using var pbkdf2 = new Rfc2898DeriveBytes(
        password,
        salt,
        iterations: 100000,
        HashAlgorithmName.SHA256
    );
    
    byte[] hash = pbkdf2.GetBytes(32);
    
    // Store both salt and hash
    byte[] hashBytes = new byte[48]; // 16 salt + 32 hash
    Array.Copy(salt, 0, hashBytes, 0, 16);
    Array.Copy(hash, 0, hashBytes, 16, 32);
    
    return Convert.ToBase64String(hashBytes);
}

// Key differences:
// - SHA-256: Fast hashing for data integrity
// - PBKDF2/Argon2: Slow hashing for password storage
```

### Content-Addressed Storage

```csharp
public class ContentAddressableStorage
{
    private readonly string _storageRoot;
    
    public ContentAddressableStorage(string storageRoot)
    {
        _storageRoot = storageRoot;
    }
    
    // Store content using its hash as the filename
    public string Store(byte[] content)
    {
        string hash = Convert.ToHexString(SHA256.HashData(content)).ToLower();
        
        // Use hash as filename (content-addressed)
        string directory = Path.Combine(_storageRoot, hash.Substring(0, 2));
        string filePath = Path.Combine(directory, hash);
        
        Directory.CreateDirectory(directory);
        
        if (!File.Exists(filePath))
        {
            File.WriteAllBytes(filePath, content);
        }
        
        return hash;
    }
    
    // Retrieve content by hash
    public byte[] Retrieve(string hash)
    {
        string directory = Path.Combine(_storageRoot, hash.Substring(0, 2));
        string filePath = Path.Combine(directory, hash);
        
        if (!File.Exists(filePath))
        {
            throw new FileNotFoundException($"Content with hash {hash} not found");
        }
        
        byte[] content = File.ReadAllBytes(filePath);
        
        // Verify integrity
        string actualHash = Convert.ToHexString(SHA256.HashData(content)).ToLower();
        if (actualHash != hash)
        {
            throw new InvalidOperationException("Content integrity check failed!");
        }
        
        return content;
    }
}

// Usage (similar to Git's object storage)
var storage = new ContentAddressableStorage("./storage");

byte[] data = Encoding.UTF8.GetBytes("Important document");
string hash = storage.Store(data);
Console.WriteLine($"Stored with hash: {hash}");

byte[] retrieved = storage.Retrieve(hash);
Console.WriteLine($"Retrieved: {Encoding.UTF8.GetString(retrieved)}");
```

### Merkle Trees (Hash Trees)

```csharp
public class MerkleTree
{
    // Build a Merkle tree for a list of data blocks
    public static string BuildMerkleRoot(List<string> dataBlocks)
    {
        if (dataBlocks.Count == 0)
            throw new ArgumentException("Must have at least one block");
        
        // Hash all data blocks
        var hashes = dataBlocks
            .Select(data => Convert.ToHexString(
                SHA256.HashData(Encoding.UTF8.GetBytes(data))).ToLower())
            .ToList();
        
        // Build tree bottom-up
        while (hashes.Count > 1)
        {
            var nextLevel = new List<string>();
            
            for (int i = 0; i < hashes.Count; i += 2)
            {
                if (i + 1 < hashes.Count)
                {
                    // Combine two hashes
                    string combined = hashes[i] + hashes[i + 1];
                    string parentHash = Convert.ToHexString(
                        SHA256.HashData(Encoding.UTF8.GetBytes(combined))).ToLower();
                    nextLevel.Add(parentHash);
                }
                else
                {
                    // Odd number of nodes, promote single node
                    nextLevel.Add(hashes[i]);
                }
            }
            
            hashes = nextLevel;
        }
        
        return hashes[0]; // Root hash
    }
}

// Usage (used in blockchain, git, etc.)
var blocks = new List<string>
{
    "Transaction 1: Alice pays Bob $100",
    "Transaction 2: Bob pays Charlie $50",
    "Transaction 3: Charlie pays Dave $25",
    "Transaction 4: Dave pays Alice $10"
};

string merkleRoot = MerkleTree.BuildMerkleRoot(blocks);
Console.WriteLine($"Merkle Root: {merkleRoot}");

// Changing any transaction changes the root
blocks[0] = "Transaction 1: Alice pays Bob $1000"; // Tampered!
string newRoot = MerkleTree.BuildMerkleRoot(blocks);
Console.WriteLine($"New Root: {newRoot}");
Console.WriteLine($"Tampered: {merkleRoot != newRoot}");
```

### Best Practices

```csharp
// ✅ DO: Use SHA-256 or stronger for new applications
byte[] hash = SHA256.HashData(data);

// ✅ DO: Use HMAC when you need authentication
byte[] hmac = new HMACSHA256(key).ComputeHash(data);

// ✅ DO: Use constant-time comparison for verification
bool isValid = CryptographicOperations.FixedTimeEquals(expected, actual);

// ✅ DO: Hash files in chunks for memory efficiency
using var stream = File.OpenRead(path);
byte[] hash = SHA256.HashData(stream);

// ❌ DON'T: Use MD5 or SHA-1 for security purposes
// byte[] hash = MD5.HashData(data); // INSECURE!

// ❌ DON'T: Use simple hashing for passwords
// Use PBKDF2, Argon2, Scrypt, or BCrypt instead

// ❌ DON'T: Use simple string comparison for hashes
// if (hash1 == hash2) // Vulnerable to timing attacks!

// ✅ DO: Specify encoding explicitly
byte[] data = Encoding.UTF8.GetBytes(text); // Consistent
```
