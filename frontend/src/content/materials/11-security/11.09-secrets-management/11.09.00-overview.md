# Chapter 11.9: Secrets Management

## Overview
This chapter covers the critical practice of managing secrets securely throughout the software development lifecycle. We'll explore why secrets don't belong in source control, how to use environment variables and configuration providers, and how to leverage dedicated secret stores like Azure Key Vault and HashiCorp Vault. You'll learn about secret rotation strategies and how to manage secrets in containerized environments like Kubernetes.

## Key Concepts
- **Secrets in Version Control:** Understanding the risks and why secrets must never be committed to Git.
- **Environment Variables:** Using environment-based configuration as an improvement over hardcoded secrets.
- **Azure Key Vault:** Leveraging cloud-native secret storage with managed identities for .NET applications.
- **External Secret Stores:** Integrating with HashiCorp Vault and other enterprise secret management solutions.
- **Secret Rotation:** Implementing automated rotation strategies and managing secrets in Kubernetes.
