## Introduction

Claims-based authorization is more flexible than simple role-based authorization. A claim is a name-value pair that represents what a subject is, not what they can do. Claims can represent any attribute: age, department, clearance level, or even arbitrary metadata. This flexibility makes claims ideal for complex authorization scenarios.

**Key principle:** Claims represent identity attributes. Authorization policies interpret these attributes to make access decisions.

## Key Concepts Summary

### What is a Claim?

A **claim** is a name-value pair issued by a trusted authority that represents an attribute of the subject.

```csharp
public class Claim
{
    public string Type { get; set; }    // "email", "department", "clearance"
    public string Value { get; set; }   // "user@example.com", "Engineering", "Secret"
    public string Issuer { get; set; }  // Who issued this claim
}
```

**Examples:**
```csharp
new Claim("email", "alice@example.com")
new Claim("department", "Engineering")
new Claim("clearance_level", "Secret")
new Claim("employee_type", "FullTime")
new Claim("age", "25")
new Claim("country", "US")
```

### Claims vs Roles

```
┌─────────────────────────────────────────────────────┐
│ ROLES                                               │
├─────────────────────────────────────────────────────┤
│ • Fixed categories (Admin, Editor, Viewer)          │
│ • Binary: You have it or you don't                 │
│ • Simple but inflexible                             │
│ • Example: User is "Editor"                         │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ CLAIMS                                              │
├─────────────────────────────────────────────────────┤
│ • Flexible attributes (department, clearance, etc)  │
│ • Can have values: "Engineering", "Level 3"         │
│ • Multiple claims per user                          │
│ • Example: department="Engineering", level="Senior" │
└─────────────────────────────────────────────────────┘
```

**Note:** In ASP.NET Core, roles are actually implemented as claims with type `ClaimTypes.Role`.

## Claims in ASP.NET Core

### ClaimsPrincipal

The authenticated user is represented as a `ClaimsPrincipal` containing claims.

```csharp
// In a controller or middleware
var user = HttpContext.User;  // ClaimsPrincipal

// Access claims
var userId = user.FindFirst(ClaimTypes.NameIdentifier)?.Value;
var email = user.FindFirst(ClaimTypes.Email)?.Value;
var department = user.FindFirst("department")?.Value;

// Check if claim exists
bool hasEmailClaim = user.HasClaim(c => c.Type == ClaimTypes.Email);

// Get all claims
var allClaims = user.Claims.ToList();
```

### Adding Claims During Authentication

```csharp
// JWT token creation
public string CreateToken(User user)
{
    var claims = new[]
    {
        new Claim(ClaimTypes.NameIdentifier, user.Id),
        new Claim(ClaimTypes.Name, user.Name),
        new Claim(ClaimTypes.Email, user.Email),
        new Claim("department", user.Department),
        new Claim("employee_type", user.EmployeeType),
        new Claim("clearance_level", user.ClearanceLevel.ToString())
    };
    
    var key = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(_secret));
    var credentials = new SigningCredentials(key, SecurityAlgorithms.HmacSha256);
    
    var token = new JwtSecurityToken(
        issuer: _issuer,
        audience: _audience,
        claims: claims,
        expires: DateTime.UtcNow.AddHours(1),
        signingCredentials: credentials
    );
    
    return new JwtSecurityTokenHandler().WriteToken(token);
}

// Cookie authentication
public async Task SignInUser(User user)
{
    var claims = new List<Claim>
    {
        new Claim(ClaimTypes.NameIdentifier, user.Id),
        new Claim(ClaimTypes.Name, user.Name),
        new Claim(ClaimTypes.Email, user.Email),
        new Claim("department", user.Department),
        new Claim("clearance_level", user.ClearanceLevel.ToString())
    };
    
    var claimsIdentity = new ClaimsIdentity(claims, 
        CookieAuthenticationDefaults.AuthenticationScheme);
    
    var claimsPrincipal = new ClaimsPrincipal(claimsIdentity);
    
    await HttpContext.SignInAsync(
        CookieAuthenticationDefaults.AuthenticationScheme,
        claimsPrincipal);
}
```

## Claims-Based Authorization

### Simple Claim Checks

```csharp
// Startup / Program.cs
services.AddAuthorization(options =>
{
    // Require a specific claim to exist
    options.AddPolicy("RequireEmail", policy =>
        policy.RequireClaim(ClaimTypes.Email));
    
    // Require claim with specific value
    options.AddPolicy("RequireEngineeringDepartment", policy =>
        policy.RequireClaim("department", "Engineering"));
    
    // Require claim with one of multiple values
    options.AddPolicy("RequireHighClearance", policy =>
        policy.RequireClaim("clearance_level", "Secret", "TopSecret"));
});

// Controller
[Authorize(Policy = "RequireEngineeringDepartment")]
public class EngineeringController : Controller
{
    [HttpGet]
    public IActionResult Dashboard()
    {
        // Only users with department="Engineering" can access
        return View();
    }
}
```

### Claim Value Checks

```csharp
services.AddAuthorization(options =>
{
    // Custom logic for claim values
    options.AddPolicy("RequireAdult", policy =>
        policy.RequireAssertion(context =>
        {
            var ageClaim = context.User.FindFirst("age");
            if (ageClaim == null)
                return false;
            
            return int.TryParse(ageClaim.Value, out int age) && age >= 18;
        }));
    
    // Require multiple claims
    options.AddPolicy("RequireFullTimeEngineer", policy =>
        policy.RequireClaim("department", "Engineering")
              .RequireClaim("employee_type", "FullTime"));
});
```

## Advanced Claims Authorization

### Custom Claim Requirements

```csharp
// Define custom requirement
public class MinimumClearanceLevelRequirement : IAuthorizationRequirement
{
    public int MinimumLevel { get; }
    
    public MinimumClearanceLevelRequirement(int minimumLevel)
    {
        MinimumLevel = minimumLevel;
    }
}

// Implement handler
public class MinimumClearanceLevelHandler : 
    AuthorizationHandler<MinimumClearanceLevelRequirement>
{
    protected override Task HandleRequirementAsync(
        AuthorizationHandlerContext context,
        MinimumClearanceLevelRequirement requirement)
    {
        var clearanceClaim = context.User.FindFirst("clearance_level");
        
        if (clearanceClaim == null)
        {
            return Task.CompletedTask;  // Requirement not met
        }
        
        if (int.TryParse(clearanceClaim.Value, out int userLevel))
        {
            if (userLevel >= requirement.MinimumLevel)
            {
                context.Succeed(requirement);
            }
        }
        
        return Task.CompletedTask;
    }
}

// Register
services.AddSingleton<IAuthorizationHandler, MinimumClearanceLevelHandler>();

services.AddAuthorization(options =>
{
    options.AddPolicy("Level3Clearance", policy =>
        policy.Requirements.Add(new MinimumClearanceLevelRequirement(3)));
});

// Use in controller
[Authorize(Policy = "Level3Clearance")]
[HttpGet("classified")]
public IActionResult ClassifiedData()
{
    return Ok("Top secret data");
}
```

### Combining Multiple Claims

```csharp
public class DepartmentAndLevelRequirement : IAuthorizationRequirement
{
    public string Department { get; }
    public int MinimumLevel { get; }
    
    public DepartmentAndLevelRequirement(string department, int minimumLevel)
    {
        Department = department;
        MinimumLevel = minimumLevel;
    }
}

public class DepartmentAndLevelHandler : 
    AuthorizationHandler<DepartmentAndLevelRequirement>
{
    protected override Task HandleRequirementAsync(
        AuthorizationHandlerContext context,
        DepartmentAndLevelRequirement requirement)
    {
        var deptClaim = context.User.FindFirst("department");
        var levelClaim = context.User.FindFirst("level");
        
        if (deptClaim?.Value == requirement.Department &&
            int.TryParse(levelClaim?.Value, out int level) &&
            level >= requirement.MinimumLevel)
        {
            context.Succeed(requirement);
        }
        
        return Task.CompletedTask;
    }
}

// Usage
services.AddAuthorization(options =>
{
    options.AddPolicy("SeniorEngineer", policy =>
        policy.Requirements.Add(
            new DepartmentAndLevelRequirement("Engineering", 3)));
});
```

## Claims Transformation

### Adding Claims After Authentication

```csharp
// Claims transformer
public class CustomClaimsTransformer : IClaimsTransformation
{
    private readonly IUserService _userService;
    
    public CustomClaimsTransformer(IUserService userService)
    {
        _userService = userService;
    }
    
    public async Task<ClaimsPrincipal> TransformAsync(ClaimsPrincipal principal)
    {
        // Clone the principal
        var clone = principal.Clone();
        var identity = (ClaimsIdentity)clone.Identity;
        
        // Get user ID from existing claims
        var userId = principal.FindFirst(ClaimTypes.NameIdentifier)?.Value;
        
        if (userId != null)
        {
            // Fetch additional user data
            var user = await _userService.GetUserById(userId);
            
            // Add additional claims
            if (user != null)
            {
                identity.AddClaim(new Claim("department", user.Department));
                identity.AddClaim(new Claim("level", user.Level.ToString()));
                identity.AddClaim(new Claim("manager_id", user.ManagerId ?? ""));
            }
        }
        
        return clone;
    }
}

// Register
services.AddScoped<IClaimsTransformation, CustomClaimsTransformer>();
```

## Imperative Claims Checks

### Manual Authorization in Code

```csharp
[ApiController]
[Route("api/[controller]")]
public class DataController : ControllerBase
{
    [HttpGet("sensitive")]
    [Authorize]
    public IActionResult GetSensitiveData()
    {
        // Manual claim check
        var department = User.FindFirst("department")?.Value;
        
        if (department != "Security")
        {
            return Forbid();
        }
        
        // Additional logic
        var clearance = User.FindFirst("clearance_level")?.Value;
        
        if (!int.TryParse(clearance, out int level) || level < 3)
        {
            return Forbid();
        }
        
        // Authorization passed
        return Ok(GetSensitiveInformation());
    }
}
```

### Using IAuthorizationService

```csharp
public class DocumentController : ControllerBase
{
    private readonly IAuthorizationService _authorizationService;
    
    public DocumentController(IAuthorizationService authorizationService)
    {
        _authorizationService = authorizationService;
    }
    
    [HttpGet("{id}")]
    public async Task<IActionResult> GetDocument(int id)
    {
        var document = await _documentRepo.GetById(id);
        
        // Check policy imperatively
        var authResult = await _authorizationService.AuthorizeAsync(
            User, document, "Level3Clearance");
        
        if (!authResult.Succeeded)
        {
            return Forbid();
        }
        
        return Ok(document);
    }
}
```

## Claims Best Practices

### 1. Don't Store Sensitive Data in Claims

```csharp
// ❌ BAD: Sensitive data in claims
new Claim("ssn", "123-45-6789")
new Claim("credit_card", "4111-1111-1111-1111")
new Claim("password_hash", "...")

// ✅ GOOD: Non-sensitive identity attributes
new Claim("user_id", "12345")
new Claim("department", "Engineering")
new Claim("clearance_level", "3")
```

**Reason:** Claims are often stored in JWTs or cookies, which can be decoded by anyone.

### 2. Use Standard Claim Types When Possible

```csharp
// ✅ GOOD: Standard claim types
new Claim(ClaimTypes.NameIdentifier, userId)
new Claim(ClaimTypes.Name, userName)
new Claim(ClaimTypes.Email, email)
new Claim(ClaimTypes.Role, "Admin")

// ⚠️ OK but less standard
new Claim("department", "Engineering")
new Claim("custom_attribute", "value")
```

### 3. Keep Claims Small

```csharp
// ❌ BAD: Large claim values
new Claim("user_data", JsonSerializer.Serialize(largeUserObject))

// ✅ GOOD: Minimal necessary claims
new Claim("user_id", "12345")
// Fetch additional data from database when needed
```

### 4. Validate Claim Values

```csharp
public class SafeClaimHandler : AuthorizationHandler<CustomRequirement>
{
    protected override Task HandleRequirementAsync(
        AuthorizationHandlerContext context,
        CustomRequirement requirement)
    {
        var claim = context.User.FindFirst("custom_claim");
        
        // ✅ GOOD: Validate before using
        if (claim == null || string.IsNullOrWhiteSpace(claim.Value))
        {
            return Task.CompletedTask;
        }
        
        // Sanitize and validate
        if (!IsValidClaimValue(claim.Value))
        {
            return Task.CompletedTask;
        }
        
        // Use claim value safely
        context.Succeed(requirement);
        return Task.CompletedTask;
    }
    
    private bool IsValidClaimValue(string value)
    {
        // Validation logic
        return !string.IsNullOrEmpty(value) && value.Length <= 100;
    }
}
```

## Real-World Example

### Multi-Tenant SaaS Application

```csharp
// Claims for multi-tenant app
public string CreateToken(User user)
{
    var claims = new[]
    {
        // Identity claims
        new Claim(ClaimTypes.NameIdentifier, user.Id),
        new Claim(ClaimTypes.Email, user.Email),
        
        // Tenant claims
        new Claim("tenant_id", user.TenantId),
        new Claim("tenant_role", user.TenantRole),  // "owner", "admin", "member"
        
        // Feature flags
        new Claim("features", string.Join(",", user.EnabledFeatures)),
        
        // Subscription tier
        new Claim("subscription_tier", user.Tenant.SubscriptionTier)
    };
    
    return CreateJwt(claims);
}

// Authorization policies
services.AddAuthorization(options =>
{
    // Tenant owner only
    options.AddPolicy("TenantOwner", policy =>
        policy.RequireClaim("tenant_role", "owner"));
    
    // Admin or owner
    options.AddPolicy("TenantAdmin", policy =>
        policy.RequireClaim("tenant_role", "owner", "admin"));
    
    // Premium tier only
    options.AddPolicy("PremiumFeature", policy =>
        policy.RequireClaim("subscription_tier", "premium", "enterprise"));
    
    // Feature flag check
    options.AddPolicy("AdvancedAnalytics", policy =>
        policy.RequireAssertion(context =>
        {
            var featuresClaim = context.User.FindFirst("features");
            return featuresClaim?.Value.Contains("advanced_analytics") == true;
        }));
});

// Usage
[Authorize(Policy = "TenantAdmin")]
[HttpPost("invite")]
public IActionResult InviteUser([FromBody] InviteRequest request)
{
    var tenantId = User.FindFirst("tenant_id")?.Value;
    // Only admins and owners can invite users
    return Ok();
}

[Authorize(Policy = "PremiumFeature")]
[HttpGet("advanced-reports")]
public IActionResult GetAdvancedReports()
{
    // Only premium and enterprise tiers can access
    return Ok();
}
```

## Testing Claims Authorization

```csharp
[Fact]
public async Task UserWithEngineeringClaim_CanAccessEngineeringDashboard()
{
    // Arrange
    var claims = new[]
    {
        new Claim(ClaimTypes.NameIdentifier, "user1"),
        new Claim("department", "Engineering")
    };
    var identity = new ClaimsIdentity(claims, "Test");
    var principal = new ClaimsPrincipal(identity);
    
    _controller.ControllerContext = new ControllerContext
    {
        HttpContext = new DefaultHttpContext { User = principal }
    };
    
    // Act
    var result = await _controller.EngineeringDashboard();
    
    // Assert
    Assert.IsType<OkResult>(result);
}

[Fact]
public async Task UserWithoutEngineeringClaim_CannotAccessEngineeringDashboard()
{
    // Arrange
    var claims = new[]
    {
        new Claim(ClaimTypes.NameIdentifier, "user1"),
        new Claim("department", "Marketing")  // Wrong department
    };
    var identity = new ClaimsIdentity(claims, "Test");
    var principal = new ClaimsPrincipal(identity);
    
    _controller.ControllerContext = new ControllerContext
    {
        HttpContext = new DefaultHttpContext { User = principal }
    };
    
    // Act & Assert
    await Assert.ThrowsAsync<UnauthorizedAccessException>(
        () => _controller.EngineeringDashboard());
}
```
