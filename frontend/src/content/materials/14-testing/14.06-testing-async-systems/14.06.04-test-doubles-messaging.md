# Lesson 4: Test Doubles for Messaging Systems

## Learning Objectives

By the end of this lesson, you will be able to:
- Use in-memory message brokers for testing
- Create test doubles for message publishing
- Mock external messaging dependencies
- Choose between in-memory brokers and mocks
- Test message handling without external dependencies

---

## Introduction

Testing message-driven systems doesn't require running real message brokers. Test doubles—including in-memory brokers, mocks, and fakes—enable fast, isolated tests while maintaining confidence in message handling logic.

## Key Concepts Summary

### Test Double Types

```
Test Doubles for Messaging:

Dummy
├── Minimal implementation
├── Does nothing
└── Satisfies interface

Stub
├── Returns hardcoded responses
├── No verification
└── Simple behavior

Fake
├── Working implementation
├── In-memory broker
└── Real logic, fake infrastructure

Mock
├── Records interactions
├── Verifies calls
└── Behavior verification

Spy
├── Wraps real object
├── Records calls
└── Partial mocking
```

### In-Memory Message Bus

```csharp
public interface IMessageBus
{
    Task PublishAsync<T>(T message, CancellationToken cancellationToken = default)
        where T : class;
    
    void Subscribe<T>(Func<T, Task> handler) where T : class;
}

public class InMemoryMessageBus : IMessageBus
{
    private readonly Dictionary<Type, List<Delegate>> _handlers = new();
    private readonly object _lock = new();

    public void Subscribe<T>(Func<T, Task> handler) where T : class
    {
        lock (_lock)
        {
            var messageType = typeof(T);
            if (!_handlers.ContainsKey(messageType))
            {
                _handlers[messageType] = new List<Delegate>();
            }
            _handlers[messageType].Add(handler);
        }
    }

    public async Task PublishAsync<T>(
        T message, 
        CancellationToken cancellationToken = default) 
        where T : class
    {
        List<Delegate> handlers;
        lock (_lock)
        {
            var messageType = typeof(T);
            if (!_handlers.ContainsKey(messageType))
            {
                return;
            }
            handlers = _handlers[messageType].ToList();
        }

        foreach (var handler in handlers)
        {
            var typedHandler = (Func<T, Task>)handler;
            await typedHandler(message);
        }
    }
}
```

### Using In-Memory Message Bus

### Spy Pattern for Message Bus

```csharp
public class SpyMessageBus : IMessageBus
{
    private readonly IMessageBus _inner;
    private readonly List<object> _publishedMessages = new();

    public SpyMessageBus(IMessageBus inner)
    {
        _inner = inner;
    }

    public IReadOnlyList<object> PublishedMessages => _publishedMessages.AsReadOnly();

    public async Task PublishAsync<T>(
        T message, 
        CancellationToken cancellationToken = default) 
        where T : class
    {
        _publishedMessages.Add(message);
        await _inner.PublishAsync(message, cancellationToken);
    }

    public void Subscribe<T>(Func<T, Task> handler) where T : class
    {
        _inner.Subscribe(handler);
    }

    public List<T> GetPublishedMessages<T>() where T : class
    {
        return _publishedMessages.OfType<T>().ToList();
    }

    public void Clear()
    {
        _publishedMessages.Clear();
    }
}

// Usage
[Fact]
public async Task CreateOrder_PublishesCorrectMessage()
{
    var innerBus = new InMemoryMessageBus();
    var spyBus = new SpyMessageBus(innerBus);
    var service = new OrderService(spyBus);

    await service.CreateOrderAsync(new CreateOrderCommand
    {
        CustomerId = Guid.NewGuid(),
        Items = new[] { "Item1" }
    });

    var messages = spyBus.GetPublishedMessages<OrderCreatedMessage>();
    Assert.Single(messages);
    Assert.NotEqual(Guid.Empty, messages[0].OrderId);
}
```

### Fake Message Queue

```csharp
public interface IMessageQueue<T>
{
    Task EnqueueAsync(T message);
    Task<T> DequeueAsync(CancellationToken cancellationToken = default);
    int Count { get; }
}

public class InMemoryMessageQueue<T> : IMessageQueue<T>
{
    private readonly Channel<T> _channel;
    private readonly ChannelReader<T> _reader;
    private readonly ChannelWriter<T> _writer;

    public InMemoryMessageQueue(int capacity = 1000)
    {
        _channel = Channel.CreateBounded<T>(new BoundedChannelOptions(capacity)
        {
            FullMode = BoundedChannelFullMode.Wait
        });
        _reader = _channel.Reader;
        _writer = _channel.Writer;
    }

    public int Count => _reader.Count;

    public async Task EnqueueAsync(T message)
    {
        await _writer.WriteAsync(message);
    }

    public async Task<T> DequeueAsync(CancellationToken cancellationToken = default)
    {
        return await _reader.ReadAsync(cancellationToken);
    }
}

// Usage
[Fact]
public async Task EnqueueMessage_DequeuesInOrder()
{
    var queue = new InMemoryMessageQueue<OrderMessage>();

    var message1 = new OrderMessage { OrderId = Guid.NewGuid() };
    var message2 = new OrderMessage { OrderId = Guid.NewGuid() };

    await queue.EnqueueAsync(message1);
    await queue.EnqueueAsync(message2);

    var dequeued1 = await queue.DequeueAsync();
    var dequeued2 = await queue.DequeueAsync();

    Assert.Equal(message1.OrderId, dequeued1.OrderId);
    Assert.Equal(message2.OrderId, dequeued2.OrderId);
}
```

### Fake Message Broker with Topics

```csharp
public class FakeMessageBroker
{
    private readonly Dictionary<string, List<Func<object, Task>>> _topicSubscribers = new();
    private readonly List<(string Topic, object Message)> _publishedMessages = new();

    public IReadOnlyList<(string Topic, object Message)> PublishedMessages 
        => _publishedMessages.AsReadOnly();

    public void Subscribe<T>(string topic, Func<T, Task> handler)
    {
        if (!_topicSubscribers.ContainsKey(topic))
        {
            _topicSubscribers[topic] = new List<Func<object, Task>>();
        }

        _topicSubscribers[topic].Add(async msg => await handler((T)msg));
    }

    public async Task PublishAsync<T>(string topic, T message)
    {
        _publishedMessages.Add((topic, message));

        if (_topicSubscribers.ContainsKey(topic))
        {
            foreach (var handler in _topicSubscribers[topic])
            {
                await handler(message);
            }
        }
    }

    public List<T> GetPublishedMessages<T>(string topic)
    {
        return _publishedMessages
            .Where(m => m.Topic == topic && m.Message is T)
            .Select(m => (T)m.Message)
            .ToList();
    }

    public void Clear()
    {
        _publishedMessages.Clear();
    }
}

// Usage
[Fact]
public async Task PublishToTopic_ReceivesOnSubscriber()
{
    var broker = new FakeMessageBroker();
    var receivedMessages = new List<OrderCreatedMessage>();

    broker.Subscribe<OrderCreatedMessage>("orders.created", async msg =>
    {
        receivedMessages.Add(msg);
        await Task.CompletedTask;
    });

    await broker.PublishAsync("orders.created", new OrderCreatedMessage
    {
        OrderId = Guid.NewGuid()
    });

    await Task.Delay(50); // Wait for async handling

    Assert.Single(receivedMessages);
    var published = broker.GetPublishedMessages<OrderCreatedMessage>("orders.created");
    Assert.Single(published);
}
```

### Configurable Fake Broker

```csharp
public class ConfigurableFakeBroker
{
    private readonly FakeMessageBroker _broker = new();
    
    public TimeSpan? MessageDelay { get; set; }
    public bool SimulateFailures { get; set; }
    public double FailureRate { get; set; } = 0.1;

    public void Subscribe<T>(string topic, Func<T, Task> handler)
    {
        _broker.Subscribe<T>(topic, async message =>
        {
            if (SimulateFailures && Random.Shared.NextDouble() < FailureRate)
            {
                throw new Exception("Simulated broker failure");
            }

            if (MessageDelay.HasValue)
            {
                await Task.Delay(MessageDelay.Value);
            }

            await handler(message);
        });
    }

    public async Task PublishAsync<T>(string topic, T message)
    {
        if (SimulateFailures && Random.Shared.NextDouble() < FailureRate)
        {
            throw new Exception("Simulated broker failure");
        }

        if (MessageDelay.HasValue)
        {
            await Task.Delay(MessageDelay.Value);
        }

        await _broker.PublishAsync(topic, message);
    }

    public List<T> GetPublishedMessages<T>(string topic) 
        => _broker.GetPublishedMessages<T>(topic);
}

// Usage
[Fact]
public async Task PublishWithDelay_HandlesSlowBroker()
{
    var broker = new ConfigurableFakeBroker
    {
        MessageDelay = TimeSpan.FromMilliseconds(100)
    };

    var receivedMessages = new List<OrderCreatedMessage>();
    broker.Subscribe<OrderCreatedMessage>("orders.created", async msg =>
    {
        receivedMessages.Add(msg);
        await Task.CompletedTask;
    });

    var stopwatch = Stopwatch.StartNew();
    await broker.PublishAsync("orders.created", new OrderCreatedMessage
    {
        OrderId = Guid.NewGuid()
    });

    await Task.Delay(200); // Wait for delayed handling
    stopwatch.Stop();

    Assert.Single(receivedMessages);
    Assert.True(stopwatch.ElapsedMilliseconds >= 100);
}
```

### Testing with WebApplicationFactory

```csharp
public class OrderApiTests : IClassFixture<WebApplicationFactory<Program>>
{
    private readonly WebApplicationFactory<Program> _factory;
    private readonly FakeMessageBroker _fakeBroker;

    public OrderApiTests(WebApplicationFactory<Program> factory)
    {
        _fakeBroker = new FakeMessageBroker();

        _factory = factory.WithWebHostBuilder(builder =>
        {
            builder.ConfigureServices(services =>
            {
                // Replace real message broker with fake
                var descriptor = services.SingleOrDefault(
                    d => d.ServiceType == typeof(IMessageBroker));
                if (descriptor != null)
                {
                    services.Remove(descriptor);
                }

                services.AddSingleton<IMessageBroker>(_fakeBroker);
            });
        });
    }

    [Fact]
    public async Task CreateOrder_PublishesMessage()
    {
        var client = _factory.CreateClient();

        var response = await client.PostAsJsonAsync("/api/orders", new
        {
            customerId = Guid.NewGuid(),
            items = new[] { "Item1" }
        });

        response.EnsureSuccessStatusCode();

        var messages = _fakeBroker
            .GetPublishedMessages<OrderCreatedMessage>("orders.created");
        
        Assert.Single(messages);
    }
}
```

### Capturing Message Arguments

```csharp
public class CapturingMessagePublisher : IMessagePublisher
{
    private readonly List<(Type MessageType, object Message)> _published = new();

    public IReadOnlyList<(Type MessageType, object Message)> Published 
        => _published.AsReadOnly();

    public Task PublishAsync<T>(
        T message, 
        CancellationToken cancellationToken = default)
    {
        _published.Add((typeof(T), message));
        return Task.CompletedTask;
    }

    public List<T> GetPublishedMessages<T>()
    {
        return _published
            .Where(p => p.Message is T)
            .Select(p => (T)p.Message)
            .ToList();
    }
}

public async Task CreateOrders_PublishesMultipleMessages()
{

    var service = new OrderService(publisher);

    await service.CreateOrderAsync(new CreateOrderCommand { /* ... */ });

    var messages = publisher.GetPublishedMessages<OrderCreatedMessage>();
    Assert.Equal(2, messages.Count);
}
```

### Best Practices

**1. Choose the Right Test Double:**
```csharp
// ✓ Unit test - Mock
var mock = new Mock<IMessagePublisher>();
mock.Verify(x => x.PublishAsync(...));

// ✓ Integration test - Fake
var fake = new InMemoryMessageBus();

// ✓ Component test - In-memory with real logic
var broker = new FakeMessageBroker();
```

**2. Keep Fakes Simple:**
```csharp
// ✓ Good - Simple, focused fake
public class InMemoryMessageBus : IMessageBus
{
    // Essential functionality only
}

// ✗ Bad - Complex fake replicating real broker
public class InMemoryRabbitMQ : IMessageBroker
{
    // Exchanges, bindings, dead letters, etc.
}
```

**3. Isolate Test State:**
```csharp
// ✓ Good - Fresh instance per test
[Fact]
public async Task Test1()
{
    var broker = new InMemoryMessageBus();
}

[Fact]
public async Task Test2()
{
    var broker = new InMemoryMessageBus();
}

// ✗ Bad - Shared state
private static readonly InMemoryMessageBus _broker = new();
```

**4. Verify Behavior, Not Implementation:**
```csharp
// ✓ Good - Verify message was published
var messages = broker.GetPublishedMessages<OrderCreatedMessage>();
Assert.Single(messages);

// ✗ Bad - Verify internal method calls
mock.Verify(x => x.InternalSerialize(...));
```

**5. Use Real Objects When Possible:**
```csharp
// ✓ Good - Test real object
var service = new OrderService(fakeBroker, realRepository);

// ✗ Bad - Mock everything
var service = new OrderService(mockBroker.Object, mockRepository.Object);
```
