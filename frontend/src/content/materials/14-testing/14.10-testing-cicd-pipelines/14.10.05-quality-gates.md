---

## Introduction

Quality gates are automated checkpoints that prevent bad code from reaching production. They enforce standards, catch regressions, and provide confidence that deployments will succeed. This lesson teaches you how to implement quality gates that protect production without slowing down development.

**Key principle:** Quality gates should be fast, objective, and automated. Manual gates create bottlenecks; slow gates train developers to bypass them.

## Key Concepts Summary

### What Are Quality Gates?

```
Definition:
Quality gates are automated checkpoints in your CI/CD pipeline that 
enforce quality standards before allowing code to proceed to the next stage.

Types of Gates:

1. BUILD GATES (CI)
   ✓ All tests pass
   ✓ Code coverage > threshold
   ✓ No high-severity security vulnerabilities
   ✓ Code quality metrics acceptable
   ✓ No compilation warnings

2. DEPLOYMENT GATES (CD)
   ✓ All pre-deployment tests pass
   ✓ No active incidents in monitoring
   ✓ Health checks pass
   ✓ Load metrics within acceptable range
   ✓ Manual approval obtained

3. MERGE GATES (PR)
   ✓ All CI checks pass
   ✓ Code review approved
   ✓ No merge conflicts
   ✓ Branch protection rules satisfied
```

### Build Quality Gates

```yaml
# GitHub Actions: Enforce quality gates
name: CI with Quality Gates

on:
  pull_request:
    branches: [main]
  push:
    branches: [main]

jobs:
  quality-gates:
    runs-on: ubuntu-latest
    
    steps:
      - uses: actions/checkout@v4
      
      - name: Setup .NET
        uses: actions/setup-dotnet@v4
        with:
          dotnet-version: '8.0.x'
      
      # Gate 1: Build must succeed
      - name: Gate 1 - Build
        run: |
          echo "::group::Quality Gate 1: Build"
          dotnet build --configuration Release
          if [ $? -ne 0 ]; then
            echo "::error::Build failed - quality gate not passed"
            exit 1
          fi
          echo "✅ Build succeeded"
          echo "::endgroup::"
      
      # Gate 2: All tests must pass
      - name: Gate 2 - Tests
        run: |
          echo "::group::Quality Gate 2: Tests"
          dotnet test \
            --no-build \
            --configuration Release \
            --logger "trx" \
            --results-directory TestResults
          
          if [ $? -ne 0 ]; then
            echo "::error::Tests failed - quality gate not passed"
            exit 1
          fi
          echo "✅ All tests passed"
          echo "::endgroup::"
      
      # Gate 3: Code coverage threshold
      - name: Gate 3 - Code Coverage
        run: |
          echo "::group::Quality Gate 3: Code Coverage"
          dotnet test \
            --no-build \
            --configuration Release \
            /p:CollectCoverage=true \
            /p:Threshold=80 \
            /p:ThresholdType=line \
            /p:ThresholdStat=total
          
          if [ $? -ne 0 ]; then
            echo "::error::Code coverage below 80% - quality gate not passed"
            exit 1
          fi
          echo "✅ Code coverage ≥ 80%"
          echo "::endgroup::"
      
      # Gate 4: No compiler warnings
      - name: Gate 4 - Warnings
        run: |
          echo "::group::Quality Gate 4: Warnings"
          dotnet build \
            --no-restore \
            --configuration Release \
            /warnaserror > build.log 2>&1
          
          if [ $? -ne 0 ]; then
            echo "::error::Build has warnings - quality gate not passed"
            cat build.log
            exit 1
          fi
          echo "✅ No warnings"
          echo "::endgroup::"
      
      # Gate 5: Security scan
      - name: Gate 5 - Security Scan
        run: |
          echo "::group::Quality Gate 5: Security"
          dotnet list package --vulnerable --include-transitive
          
          if [ $? -ne 0 ]; then
            echo "::error::Vulnerable packages detected - quality gate not passed"
            exit 1
          fi
          echo "✅ No vulnerable packages"
          echo "::endgroup::"
      
      - name: All Quality Gates Passed
        run: |
          echo "::notice::🎉 All quality gates passed! Ready for deployment."
```

### Deployment Gates in Azure DevOps

```yaml
# azure-pipelines-release.yml
trigger: none  # Manual or CD trigger

stages:
  - stage: Deploy_Dev
    jobs:
      - deployment: DeployDev
        environment: 'Development'
        strategy:
          runOnce:
            deploy:
              steps:
                - script: echo "Deploying to Dev"
  
  - stage: Deploy_Staging
    dependsOn: Deploy_Dev
    jobs:
      - deployment: DeployStaging
        environment: 'Staging'
        
        # Pre-deployment gates
        preDeploymentGates:
          gates:
            # Gate 1: Ensure no active incidents
            - task: InvokeRESTAPI@1
              inputs:
                connectionType: 'connectedServiceName'
                serviceConnection: 'monitoring-api'
                method: 'GET'
                urlSuffix: '/api/incidents/active'
                successCriteria: 'eq(root.count, 0)'
              displayName: 'Check Active Incidents'
            
            # Gate 2: Validate monitoring health
            - task: QueryAzureMonitor@1
              inputs:
                azureSubscription: 'production-sub'
                resourceGroupName: 'app-rg'
                resourceType: 'Microsoft.Web/sites'
                resourceName: 'my-app'
                metricName: 'Http5xx'
                timeRange: 'PT5M'  # Last 5 minutes
                aggregation: 'Average'
                successCriteria: 'lt(root.value, 5)'  # Less than 5 errors
              displayName: 'Check Error Rate'
          
          timeout: 360  # 6 hours max gate duration
          samplingInterval: 300  # Check every 5 minutes
          minSuccessDuration: 0  # Must pass immediately
        
        strategy:
          runOnce:
            deploy:
              steps:
                - script: echo "Deploying to Staging"
        
        # Post-deployment gates
        postDeploymentGates:
          gates:
            # Gate 1: Health check
            - task: InvokeRESTAPI@1
              inputs:
                connectionType: 'connectedServiceName'
                serviceConnection: 'app-api'
                method: 'GET'
                urlSuffix: '/health'
                successCriteria: 'eq(root.status, "healthy")'
              displayName: 'Health Check'
            
            # Gate 2: Smoke tests
            - task: DotNetCoreCLI@2
              inputs:
                command: 'test'
                projects: '**/*SmokeTests.csproj'
                arguments: '--filter Category=Smoke'
              displayName: 'Run Smoke Tests'
          
          timeout: 60  # 1 hour
          samplingInterval: 60  # Check every minute
          minSuccessDuration: 300  # Must pass for 5 minutes straight
```

### GitHub Actions: Deployment Gates

```yaml
# .github/workflows/deploy.yml
name: Deploy to Production

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    environment:
      name: production
      url: https://app.example.com
    
    steps:
      - uses: actions/checkout@v4
      
      # Pre-deployment gates
      - name: Gate 1 - Check for Active Incidents
        run: |
          echo "Checking for active incidents..."
          INCIDENTS=$(curl -s https://api.monitoring.com/incidents/active | jq '.count')
          
          if [ "$INCIDENTS" -gt 0 ]; then
            echo "::error::Found $INCIDENTS active incidents - blocking deployment"
            exit 1
          fi
          
          echo "✅ No active incidents"
      
      - name: Gate 2 - Validate Monitoring Health
        run: |
          echo "Checking monitoring system health..."
          HEALTH=$(curl -s https://api.monitoring.com/health | jq -r '.status')
          
          if [ "$HEALTH" != "healthy" ]; then
            echo "::error::Monitoring system unhealthy - blocking deployment"
            exit 1
          fi
          
          echo "✅ Monitoring healthy"
      
      - name: Gate 3 - Check Error Rates
        run: |
          echo "Checking recent error rates..."
          ERRORS=$(curl -s https://api.monitoring.com/metrics/errors?duration=5m | jq '.value')
          
          if [ "$ERRORS" -gt 10 ]; then
            echo "::error::Error rate too high ($ERRORS errors in last 5min)"
            exit 1
          fi
          
          echo "✅ Error rate acceptable ($ERRORS errors)"
      
      # Deploy
      - name: Deploy to Production
        run: |
          echo "Deploying application..."
          # Your deployment steps here
      
      # Post-deployment gates
      - name: Wait for Deployment
        run: sleep 30
      
      - name: Post-Deploy Gate 1 - Health Check
        run: |
          echo "Running health check..."
          for i in {1..10}; do
            HEALTH=$(curl -s https://app.example.com/health | jq -r '.status')
            
            if [ "$HEALTH" = "healthy" ]; then
              echo "✅ Application healthy"
              exit 0
            fi
            
            echo "Attempt $i: Application not healthy yet, retrying..."
            sleep 10
          done
          
          echo "::error::Application failed health checks"
          exit 1
      
      - name: Post-Deploy Gate 2 - Smoke Tests
        run: |
          echo "Running smoke tests..."
          dotnet test SmokeTests/ --filter "Category=Smoke"
      
      - name: Post-Deploy Gate 3 - Monitor for 5 Minutes
        run: |
          echo "Monitoring for anomalies..."
          START=$(date +%s)
          
          while [ $(($(date +%s) - START)) -lt 300 ]; do
            ERRORS=$(curl -s https://api.monitoring.com/metrics/errors?duration=1m | jq '.value')
            
            if [ "$ERRORS" -gt 5 ]; then
              echo "::error::High error rate detected after deployment"
              # Trigger rollback
              exit 1
            fi
            
            sleep 30
          done
          
          echo "✅ No anomalies detected in 5-minute observation period"
```

### SonarQube Quality Gate

```yaml
# GitHub Actions: SonarQube quality gate
name: CI with SonarQube

on: [push, pull_request]

jobs:
  sonarqube:
    runs-on: ubuntu-latest
    
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0  # Shallow clones should be disabled for better analysis
      
      - name: Setup .NET
        uses: actions/setup-dotnet@v4
        with:
          dotnet-version: '8.0.x'
      
      - name: Install SonarScanner
        run: dotnet tool install --global dotnet-sonarscanner
      
      - name: Begin SonarScanner
        env:
          SONAR_TOKEN: ${{ secrets.SONAR_TOKEN }}
        run: |
          dotnet sonarscanner begin \
            /k:"my-project" \
            /d:sonar.host.url="https://sonarqube.example.com" \
            /d:sonar.token="$SONAR_TOKEN" \
            /d:sonar.cs.opencover.reportsPaths="**/coverage.opencover.xml"
      
      - name: Build and Test
        run: |
          dotnet build
          dotnet test /p:CollectCoverage=true /p:CoverletOutputFormat=opencover
      
      - name: End SonarScanner
        env:
          SONAR_TOKEN: ${{ secrets.SONAR_TOKEN }}
        run: dotnet sonarscanner end /d:sonar.token="$SONAR_TOKEN"
      
      - name: Check Quality Gate
        run: |
          # Wait for analysis to complete
          sleep 30
          
          # Check quality gate status
          STATUS=$(curl -s -u "${{ secrets.SONAR_TOKEN }}:" \
            "https://sonarqube.example.com/api/qualitygates/project_status?projectKey=my-project" \
            | jq -r '.projectStatus.status')
          
          if [ "$STATUS" != "OK" ]; then
            echo "::error::SonarQube quality gate failed: $STATUS"
            exit 1
          fi
          
          echo "✅ SonarQube quality gate passed"
```

### Code Coverage Gates

```xml
<!-- Directory.Build.props - Project-wide coverage enforcement -->
<Project>
  <PropertyGroup>
    <!-- Fail build if coverage is below threshold -->
    <CoverletOutputFormat>cobertura</CoverletOutputFormat>
    
    <!-- Overall threshold: 80% -->
    <Threshold>80</Threshold>
    
    <!-- Apply to both line and branch coverage -->
    <ThresholdType>line,branch</ThresholdType>
    
    <!-- Measure total across all assemblies -->
    <ThresholdStat>total</ThresholdStat>
    
    <!-- Exclude certain files from coverage -->
    <ExcludeByFile>
      **/Migrations/**/*.cs,
      **/Program.cs,
      **/Startup.cs
    </ExcludeByFile>
    
    <!-- Exclude auto-generated code -->
    <ExcludeByAttribute>
      GeneratedCode,
      CompilerGenerated
    </ExcludeByAttribute>
  </PropertyGroup>
</Project>
```

            /p:ThresholdStat=total
      
      - name: Check Per-File Coverage
        run: |
          # Install ReportGenerator
          dotnet tool install -g dotnet-reportgenerator-globaltool
          
          # Generate coverage report
          reportgenerator \
            -reports:TestResults/**/coverage.cobertura.xml \
            -targetdir:CoverageReport \
            -reporttypes:JsonSummary
          
          # Check critical files have high coverage
          CUSTOMER_SERVICE_COVERAGE=$(jq -r \
            '.coverage.assemblies[] | select(.name == "CustomerService") | .classCoverage' \
            CoverageReport/Summary.json)
          
          if (( $(echo "$CUSTOMER_SERVICE_COVERAGE < 90" | bc -l) )); then
            echo "::error::CustomerService coverage is $CUSTOMER_SERVICE_COVERAGE%, requires 90%"
            exit 1
          fi
          
          echo "✅ All critical files meet coverage requirements"

### Dynamic Quality Gates

```csharp
// Adjust quality gates based on context
public class DynamicQualityGates
{
    public static QualityGateConfig GetGatesForBranch(string branch)
    {
        return branch switch
        {
            "main" => new QualityGateConfig
            {
                RequiredCoverage = 80,
                AllowedWarnings = 0,
                RequireCodeReview = true,
                RequireSecurityScan = true,
                RequirePerformanceTest = true
            },
            
            var s when s.StartsWith("release/") => new QualityGateConfig
            {
                RequiredCoverage = 85,
                AllowedWarnings = 0,
                RequireCodeReview = true,
                RequireSecurityScan = true,
                RequirePerformanceTest = true
            },
            
            var s when s.StartsWith("feature/") => new QualityGateConfig
            {
                RequiredCoverage = 70,
                AllowedWarnings = 5,
                RequireCodeReview = true,
                RequireSecurityScan = false,
                RequirePerformanceTest = false
            },
            
            _ => new QualityGateConfig
            {
                RequiredCoverage = 60,
                AllowedWarnings = 10,
                RequireCodeReview = false,
                RequireSecurityScan = false,
                RequirePerformanceTest = false
            }
        };
    }
}

public class QualityGateConfig
{
    public int RequiredCoverage { get; set; }
    public int AllowedWarnings { get; set; }
    public bool RequireCodeReview { get; set; }
    public bool RequireSecurityScan { get; set; }
    public bool RequirePerformanceTest { get; set; }
}
```

```yaml
# GitHub Actions: Dynamic gates based on branch
name: CI with Dynamic Gates

on: [push, pull_request]

jobs:
  determine-gates:
    runs-on: ubuntu-latest
    outputs:
      coverage-threshold: ${{ steps.gates.outputs.coverage }}
      require-review: ${{ steps.gates.outputs.review }}
    
    steps:
      - name: Determine Quality Gates
        id: gates
        run: |
          BRANCH="${{ github.ref_name }}"
          
          if [[ "$BRANCH" == "main" ]]; then
            echo "coverage=80" >> $GITHUB_OUTPUT
            echo "review=true" >> $GITHUB_OUTPUT
          elif [[ "$BRANCH" == release/* ]]; then
            echo "coverage=85" >> $GITHUB_OUTPUT
            echo "review=true" >> $GITHUB_OUTPUT
          elif [[ "$BRANCH" == feature/* ]]; then
            echo "coverage=70" >> $GITHUB_OUTPUT
            echo "review=true" >> $GITHUB_OUTPUT
          else
            echo "coverage=60" >> $GITHUB_OUTPUT
            echo "review=false" >> $GITHUB_OUTPUT
          fi
  
  test:
    needs: determine-gates
    runs-on: ubuntu-latest
    
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-dotnet@v4
        with:
          dotnet-version: '8.0.x'
      
      - name: Test with Dynamic Coverage Gate
        run: |
          dotnet test \
            /p:CollectCoverage=true \
            /p:Threshold=${{ needs.determine-gates.outputs.coverage-threshold }} \
            /p:ThresholdType=line
```

### Bypass Mechanisms (Emergency Only)

```yaml
# GitHub Actions: Emergency bypass with explicit approval
name: Deploy with Emergency Bypass

on:
  workflow_dispatch:
    inputs:
      bypass-gates:
        description: 'Bypass quality gates (emergency only)'
        required: true
        type: boolean
        default: false
      bypass-reason:
        description: 'Reason for bypass (required if bypassing)'
        required: false
        type: string

jobs:
  deploy:
    runs-on: ubuntu-latest
    
    steps:
      - name: Validate Bypass
        if: ${{ inputs.bypass-gates == true }}
        run: |
          if [ -z "${{ inputs.bypass-reason }}" ]; then
            echo "::error::Bypass reason is required"
            exit 1
          fi
          
          echo "::warning::⚠️  QUALITY GATES BYPASSED"
          echo "::warning::Reason: ${{ inputs.bypass-reason }}"
          echo "::warning::Bypassed by: ${{ github.actor }}"
          
          # Log to audit system
          curl -X POST https://api.audit.com/events \
            -d "{\"type\":\"gate_bypass\",\"reason\":\"${{ inputs.bypass-reason }}\",\"user\":\"${{ github.actor }}\"}"
      
      - name: Run Quality Gates
        if: ${{ inputs.bypass-gates == false }}
        run: |
          # Normal quality gate checks
          dotnet test /p:Threshold=80
      
      - name: Deploy
        run: |
          echo "Deploying..."
```
