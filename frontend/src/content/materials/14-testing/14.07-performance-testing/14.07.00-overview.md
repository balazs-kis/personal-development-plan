# Chapter 14.7: Performance Testing

## Overview
Conduct performance testing: test types, tool selection (k6, NBomber), test design, baseline establishment, and performance regression testing.

## Key Concepts
- **Performance Test Types:** load, stress, spike, and soak testing.
- **k6:** JavaScript-based load testing tool.
- **NBomber:** .NET-native performance testing framework.
- **Test Scenario Design:** creating realistic load patterns.
- **Baseline and Thresholds:** establishing performance expectations and detecting regressions.
