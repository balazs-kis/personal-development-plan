## Introduction

NBomber is a modern, .NET-native load testing framework that allows you to write performance tests in C# or F#. Unlike JavaScript-based tools, NBomber lets you leverage the full .NET ecosystem, type safety, and familiar tooling. It's protocol-agnostic, meaning you can test HTTP, WebSockets, gRPC, databases, message brokers, or any custom protocol.

### Installation and Setup

**Create a new console application:**
```bash
dotnet new console -n MyLoadTest -lang "C#"
cd MyLoadTest
```

**Add NBomber package:**
```bash
dotnet add package NBomber
dotnet add package NBomber.Http  # For HTTP testing
```

**Project structure:**
```
MyLoadTest/
├── MyLoadTest.csproj
├── Program.cs
└── Scenarios/
    └── UserScenarios.cs
```

### Basic Test Structure

#### Hello World Example

```csharp
using NBomber.CSharp;
using NBomber.Http.CSharp;

var httpClient = new HttpClient();

var scenario = Scenario.Create("hello_world_scenario", async context =>
{
    var response = await httpClient.GetAsync("https://nbomber.com");
    
    return response.IsSuccessStatusCode
        ? Response.Ok()
        : Response.Fail();
})
.WithoutWarmUp()
.WithLoadSimulations(
    Simulation.Inject(
        rate: 10,
        interval: TimeSpan.FromSeconds(1),
        during: TimeSpan.FromSeconds(30)
    )
);

NBomberRunner
    .RegisterScenarios(scenario)
    .Run();
```

**Run the test:**
```bash
dotnet run -c Release
```

> **Important:** Always run performance tests in Release mode for accurate results!

### Load Simulation Models

NBomber supports two fundamental load models:

#### Open Model (Rate-Based)
**Use for:** HTTP APIs, web services, systems where requests arrive independently

- **Inject:** Constant arrival rate
- **RampingInject:** Gradually increasing/decreasing rate
- **InjectRandom:** Random arrival rate

```csharp
// Inject: 10 requests per second for 30 seconds
Simulation.Inject(
    rate: 10,
    interval: TimeSpan.FromSeconds(1),
    during: TimeSpan.FromSeconds(30)
)

// RampingInject: Gradually increase from 10 to 50 RPS
Simulation.RampingInject(
    rate: 10,
    interval: TimeSpan.FromSeconds(1),
    during: TimeSpan.FromSeconds(30)
)
```

#### Closed Model (VU-Based)
**Use for:** Databases, message brokers, systems with persistent connections

- **KeepConstant:** Constant number of concurrent users
- **RampingConstant:** Gradually changing number of users

```csharp
// KeepConstant: 50 concurrent users for 5 minutes
Simulation.KeepConstant(
    copies: 50,
    during: TimeSpan.FromMinutes(5)
)

// RampingConstant: Ramp from 10 to 100 users
Simulation.RampingConstant(
    copies: 10,
    during: TimeSpan.FromMinutes(1)
),
Simulation.RampingConstant(
    copies: 100,
    during: TimeSpan.FromMinutes(2)
)
```

### HTTP Testing with NBomber.Http

#### Simple GET Request

```csharp
using NBomber.CSharp;
using NBomber.Http.CSharp;

var httpClient = new HttpClient();

var scenario = Scenario.Create("get_users", async context =>
{
    var request = Http.CreateRequest("GET", "https://api.example.com/users")
        .WithHeader("Accept", "application/json");
    
    var response = await Http.Send(httpClient, request);
    
    return response.IsSuccessStatusCode
        ? Response.Ok(statusCode: (int)response.StatusCode)
        : Response.Fail(statusCode: (int)response.StatusCode);
})
.WithLoadSimulations(
    Simulation.Inject(
        rate: 50,
        interval: TimeSpan.FromSeconds(1),
        during: TimeSpan.FromMinutes(2)
    )
);
```

#### POST Request with JSON

```csharp
using NBomber.CSharp;
using NBomber.Http.CSharp;
using System.Text.Json;

var httpClient = new HttpClient();

var scenario = Scenario.Create("create_user", async context =>
{
    var user = new
    {
        Name = $"User_{context.InvocationNumber}",
        Email = $"user{context.InvocationNumber}@example.com"
    };
    
    var json = JsonSerializer.Serialize(user);
    
    var request = Http.CreateRequest("POST", "https://api.example.com/users")
        .WithHeader("Content-Type", "application/json")
        .WithBody(new StringContent(json));
    
    var response = await Http.Send(httpClient, request);
    
    return response.IsSuccessStatusCode
        ? Response.Ok(payload: await response.Content.ReadAsStringAsync())
        : Response.Fail();
})
.WithLoadSimulations(
    Simulation.Inject(rate: 10, interval: TimeSpan.FromSeconds(1), during: TimeSpan.FromMinutes(1))
);
```

### Multi-Step User Journey

```csharp
using NBomber.CSharp;
using NBomber.Http.CSharp;

var httpClient = new HttpClient();

var scenario = Scenario.Create("user_journey", async context =>
{
    // Step 1: Browse products
    var productsRequest = Http.CreateRequest("GET", "https://api.example.com/api/products");
    var productsResponse = await Http.Send(httpClient, productsRequest);
    
    if (!productsResponse.IsSuccessStatusCode)
        return Response.Fail("Failed to load products");
    
    await Task.Delay(TimeSpan.FromSeconds(2)); // Think time
    
    // Step 2: Get product details
    var productId = 123; // In real test, parse from products response
    var detailRequest = Http.CreateRequest("GET", $"https://api.example.com/api/products/{productId}");
    var detailResponse = await Http.Send(httpClient, detailRequest);
    
    if (!detailResponse.IsSuccessStatusCode)
        return Response.Fail("Failed to load product details");
    
    await Task.Delay(TimeSpan.FromSeconds(1)); // Think time
    
    // Step 3: Add to cart
    var cartPayload = JsonSerializer.Serialize(new { productId, quantity = 1 });
    var cartRequest = Http.CreateRequest("POST", "https://api.example.com/api/cart")
        .WithHeader("Content-Type", "application/json")
        .WithHeader("Authorization", "Bearer fake-token")
        .WithBody(new StringContent(cartPayload));
    
    var cartResponse = await Http.Send(httpClient, cartRequest);
    
    return cartResponse.IsSuccessStatusCode
        ? Response.Ok()
        : Response.Fail("Failed to add to cart");
})
.WithLoadSimulations(
    Simulation.RampingInject(
        rate: 10,
        interval: TimeSpan.FromSeconds(1),
        during: TimeSpan.FromMinutes(5)
    )
);

NBomberRunner
    .RegisterScenarios(scenario)
    .Run();
```

### Advanced Configuration

#### Test Settings

```csharp
var scenario = Scenario.Create("advanced_test", async context =>
{
    // Scenario logic
    return Response.Ok();
})
.WithWarmUpDuration(TimeSpan.FromSeconds(10))  // Warm up period
.WithLoadSimulations(
    Simulation.RampingInject(rate: 10, interval: TimeSpan.FromSeconds(1), during: TimeSpan.FromMinutes(1)),
    Simulation.Inject(rate: 50, interval: TimeSpan.FromSeconds(1), during: TimeSpan.FromMinutes(3)),
    Simulation.RampingInject(rate: 10, interval: TimeSpan.FromSeconds(1), during: TimeSpan.FromMinutes(1))
);

NBomberRunner
    .RegisterScenarios(scenario)
    .WithReportFileName("my_load_test")
    .WithReportFolder("./reports")
    .WithReportFormats(ReportFormat.Html, ReportFormat.Md)
    .Run();
```

### Understanding NBomber Context

The `context` parameter provides useful information during test execution:

```csharp
var scenario = Scenario.Create("context_example", async context =>
{
    // Unique test run ID
    var testRunId = context.TestInfo.TestSuite;
    
    // Current scenario name
    var scenarioName = context.ScenarioInfo.ScenarioName;
    
    // Current iteration number (0-based)
    var iteration = context.InvocationNumber;
    
    // Get custom feed data
    var userData = context.FeedItem;
    
    // Log custom data
    context.Logger.Information($"Iteration {iteration} started");
    
    // Your test logic
    return Response.Ok();
})
.WithLoadSimulations(Simulation.KeepConstant(10, TimeSpan.FromMinutes(1)));
```

### Data Feeds

Use data feeds to parameterize tests:

```csharp
// Create a data feed
var userFeed = Feed.CreateCircular(
    name: "userFeed",
    provider: new[]
    {
        new { UserId = 1, Email = "user1@example.com" },
        new { UserId = 2, Email = "user2@example.com" },
        new { UserId = 3, Email = "user3@example.com" },
    }
);

var scenario = Scenario.Create("data_feed_example", async context =>
{
    var user = context.FeedItem;
    
    var request = Http.CreateRequest("GET", $"https://api.example.com/users/{user.UserId}")
        .WithHeader("User-Email", user.Email);
    
    var response = await Http.Send(httpClient, request);
    
    return response.IsSuccessStatusCode
        ? Response.Ok()
        : Response.Fail();
})
.WithFeed(userFeed)
.WithLoadSimulations(Simulation.Inject(rate: 10, interval: TimeSpan.FromSeconds(1), during: TimeSpan.FromMinutes(1)));
```

### Testing Non-HTTP Protocols

#### gRPC Testing Example

```csharp
using Grpc.Net.Client;
using NBomber.CSharp;

var channel = GrpcChannel.ForAddress("https://localhost:5001");
var client = new UserService.UserServiceClient(channel);

var scenario = Scenario.Create("grpc_test", async context =>
{
    try
    {
        var request = new GetUserRequest { Id = context.InvocationNumber % 100 };
        var response = await client.GetUserAsync(request);
        
        return Response.Ok(sizeBytes: response.CalculateSize());
    }
    catch (Exception ex)
    {
        return Response.Fail(error: ex.Message);
    }
})
.WithLoadSimulations(
    Simulation.KeepConstant(copies: 50, during: TimeSpan.FromMinutes(2))
);
```

#### Database Testing Example

```csharp
using Npgsql;
using NBomber.CSharp;

var connectionString = "Host=localhost;Database=testdb;Username=user;Password=pass";

var scenario = Scenario.Create("database_test", async context =>
{
    await using var connection = new NpgsqlConnection(connectionString);
    await connection.OpenAsync();
    
    await using var cmd = new NpgsqlCommand("SELECT * FROM users WHERE id = @id", connection);
    cmd.Parameters.AddWithValue("id", context.InvocationNumber % 1000);
    
    await using var reader = await cmd.ExecuteReaderAsync();
    var hasData = await reader.ReadAsync();
    
    return hasData
        ? Response.Ok()
        : Response.Fail("User not found");
})
.WithLoadSimulations(
    Simulation.KeepConstant(copies: 20, during: TimeSpan.FromMinutes(1))
);
```

### Understanding NBomber Reports

After running a test, NBomber generates an HTML report with:

#### Key Metrics
- **Request Count:** Total requests executed
- **OK/Failed:** Success and failure counts
- **RPS (Requests Per Second):** Throughput
- **Latency Percentiles:** p50, p75, p95, p99, StdDev, Min, Max
- **Data Transfer:** KB sent and received

#### Statistics Sections
1. **Scenario Stats:** Overall scenario performance
2. **Step Stats:** Performance of individual steps
3. **Status Codes:** Distribution of HTTP status codes
4. **Timeline:** Request rate over time
5. **Load Simulations:** Virtual users over time

#### Reading the Report

## NBomber vs. k6

| Feature | NBomber | k6 |
|---------|---------|-----|
| **Language** | C#/F# | JavaScript |
| **Type Safety** | Strong typing | Dynamic typing |
| **Protocols** | Any (HTTP, gRPC, DB, custom) | Primarily HTTP |
| **Ecosystem** | Full .NET ecosystem | Node.js packages (limited) |
| **CI/CD** | Easy with .NET projects | Requires separate k6 installation |
| **Learning Curve** | Familiar for .NET devs | Familiar for JS devs |
| **Performance** | High (compiled) | High (Go runtime) |
| **Reporting** | HTML reports | Console + external tools |

**When to use NBomber:**
- You're a .NET developer
- Testing .NET applications
- Need to test non-HTTP protocols
- Want type safety and IDE support
- Testing databases or message brokers

**When to use k6:**
- You prefer JavaScript
- Testing HTTP/REST APIs
- Need cloud execution (k6 Cloud)
- Want extensive community resources
- Integrating with Grafana ecosystem
