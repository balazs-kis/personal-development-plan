# Chapter 7.1: Linux Fundamentals Review

## Overview
This chapter solidifies your understanding of the Linux filesystem hierarchy, file permissions, users and groups, and the Unix philosophy. These fundamentals underpin everything else in Linux—gaps here cause confusion when dealing with permissions issues, finding files, or understanding system structure.

## Key Concepts
- **Filesystem Hierarchy Standard (FHS):** understanding the standard Linux directory structure.
- **File Permissions:** mastering rwx notation and numeric (octal) permissions.
- **Users and Groups:** managing ownership, users, and group access.
- **Symbolic vs Hard Links:** understanding different types of file links.
- **Unix Philosophy:** leveraging pipes and composable tools.
