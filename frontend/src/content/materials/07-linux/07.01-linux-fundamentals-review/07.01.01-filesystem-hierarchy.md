## Introduction

The Filesystem Hierarchy Standard (FHS) defines the directory structure and directory contents in Unix and Linux distributions. Understanding FHS is fundamental to working effectively with Linux—knowing where files live helps you configure systems, troubleshoot issues, and write scripts that work across distributions.

Unlike Windows with its drive letters (C:, D:), Linux uses a single-rooted tree structure where everything starts at `/` (root) and branches out from there.

## Key Concepts Summary

### The Root Directory (/)
Everything in Linux starts at `/`. All files and directories exist under this single root, regardless of physical devices or partitions.

### Essential Directories

#### System Binaries
- **/bin** - Essential user command binaries (ls, cp, cat, bash)
- **/sbin** - System binaries for administration (fsck, reboot, shutdown)
- **/usr/bin** - Non-essential user programs
- **/usr/sbin** - Non-essential system administration programs

#### Configuration and Data
- **/etc** - Host-specific system configuration files
- **/home** - User home directories (e.g., /home/alice)
- **/root** - Root user's home directory
- **/var** - Variable data (logs, cache, temporary files)
  - **/var/log** - System and application logs
  - **/var/cache** - Application cache
  - **/var/tmp** - Temporary files preserved between reboots

#### Libraries and Kernel
- **/lib** - Essential shared libraries and kernel modules
- **/usr/lib** - Libraries for /usr/bin and /usr/sbin programs

#### Boot and Device
- **/boot** - Static files for the boot loader (kernel, initrd)
- **/dev** - Device files (hard drives, terminals, printers)

#### Mount Points
- **/mnt** - Temporary mount points for filesystems
- **/media** - Mount points for removable media (USB drives, CDs)

#### Optional and System Info
- **/opt** - Optional/add-on software packages
- **/proc** - Virtual filesystem providing process and kernel information
- **/sys** - Virtual filesystem exposing kernel objects
- **/tmp** - Temporary files (often cleared on reboot)

### Why This Matters

Knowing where to look saves time:
- **Debugging an app?** Check `/var/log`
- **Need to modify a service?** Check `/etc`
- **Installing third-party software?** Use `/opt`
- **Writing a script?** Use standard paths so it works everywhere

## Practice Exercise

After completing the materials, try this exercise (spend 5-10 minutes):

Open a terminal and explore the filesystem:

```bash
# List root directories
ls -l /

# Find where bash is located
which bash

# View system logs directory
ls -l /var/log

# Check your home directory location
echo $HOME

# View device files
ls -l /dev | head -20
```

Can you identify:
1. Which directory contains your user files?
2. Where would you find network configuration files?
3. Where does the system store temporary files?
