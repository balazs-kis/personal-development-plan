# Lesson 3: Find and Xargs for File Operations

## Learning Objectives

By the end of this lesson, you will be able to:
- Use find to locate files based on various criteria
- Execute commands on found files with find's -exec option
- Combine find with xargs for batch processing
- Understand when to use xargs vs find -exec
- Apply find and xargs for system administration tasks

---

## Introduction

The `find` command is essential for locating files and directories based on criteria like name, size, modification time, and permissions. Combined with `xargs`, you can perform batch operations on files efficiently. These tools are crucial for system maintenance, cleanup tasks, and file management at scale.

Whether you're searching for large files, finding recently modified configurations, or batch processing files, find and xargs are indispensable tools.

## Key Concepts Summary

### Find Command Basics

**Basic find syntax:**
```bash
find [path] [options] [expression]
```

**Find by name:**
```bash
find . -name "file.txt"              # Exact name
find . -name "*.log"                 # Pattern matching
find . -iname "*.LOG"                # Case-insensitive
find /var -name "error*"             # Start with "error"
```

**Find by type:**
```bash
find . -type f                       # Regular files
find . -type d                       # Directories
find . -type l                       # Symbolic links
find /tmp -type f -name "*.tmp"      # Combine criteria
```

### Find by Size

**Size criteria:**
```bash
find . -size +100M                   # Larger than 100MB
find . -size -1k                     # Smaller than 1KB
find . -size 50M                     # Exactly 50MB
find /var/log -size +1G              # Logs larger than 1GB
```

**Size units:**
- `c` - bytes
- `k` - kilobytes
- `M` - megabytes
- `G` - gigabytes

### Find by Time

**Modification time:**
```bash
find . -mtime 0                      # Modified in last 24 hours
find . -mtime -7                     # Modified in last 7 days
find . -mtime +30                    # Modified more than 30 days ago
find . -mmin -60                     # Modified in last 60 minutes
```

**Access time:**
```bash
find . -atime -7                     # Accessed in last 7 days
find . -amin -30                     # Accessed in last 30 minutes
```

**Change time (metadata):**
```bash
find . -ctime -1                     # Changed in last day
find . -cmin -10                     # Changed in last 10 minutes
```

**Newer than a file:**
```bash
find . -newer reference.txt          # Modified after reference.txt
```

### Find by Permissions

**Permission criteria:**
```bash
find . -perm 644                     # Exactly 644
find . -perm -644                    # At least 644
find . -perm /644                    # Any of these permissions
find . -perm -u+x                    # User executable
```

**Security auditing:**
```bash
find / -type f -perm 777             # World-writable files (security risk)
find ~ -type f -perm -o+w            # Files writable by others
find /etc -type f ! -perm 644        # Config files with unusual permissions
```

### Find by Ownership

```bash
find . -user alice                   # Owned by alice
find . -group developers             # Owned by developers group
find / -nouser                       # Files with no owner (orphaned)
find / -nogroup                      # Files with no group
```

### Combining Criteria

**AND conditions (default):**
```bash
find . -name "*.log" -size +10M      # .log files larger than 10MB
find . -type f -mtime -7 -user bob   # Bob's files modified in last 7 days
```

**OR conditions:**
```bash
find . -name "*.log" -o -name "*.txt"           # .log OR .txt files
find . \( -name "*.log" -o -name "*.txt" \) -size +1M   # (log OR txt) AND large
```

**NOT conditions:**
```bash
find . -name "*.txt" ! -name "test*"            # .txt but not starting with test
find . -type f ! -name "*.log"                  # Files but not .log files
```

### Find with Actions

**Print results:**
```bash
find . -name "*.txt" -print          # Default: print paths
find . -name "*.txt" -ls             # Detailed listing
find . -name "*.txt" -printf "%f\n"  # Just filename
```

**Execute commands (-exec):**
```bash
# Delete files
find . -name "*.tmp" -exec rm {} \;

# Copy files
find . -name "*.conf" -exec cp {} /backup/ \;

# Change permissions
find . -type f -exec chmod 644 {} \;
find . -type d -exec chmod 755 {} \;

# Show file details
find . -name "*.log" -exec ls -lh {} \;

# Multiple commands
find . -name "*.txt" -exec echo "Processing: {}" \; -exec cat {} \;
```

**Understanding -exec:**
- `{}` is replaced with the found file path
- `\;` ends the command (one execution per file)
- `+` at end runs command once with all files as arguments (more efficient)

```bash
# One rm per file (slower)
find . -name "*.tmp" -exec rm {} \;

# One rm with all files (faster)
find . -name "*.tmp" -exec rm {} +
```

**Confirm before action (-ok):**
```bash
find . -name "*.tmp" -ok rm {} \;    # Prompt before each delete
```

**Delete with -delete:**
```bash
find . -name "*.tmp" -delete         # Safer than rm
find . -type f -empty -delete        # Delete empty files
```

### Practical Find Examples

**System cleanup:**
```bash
# Find and remove old log files
find /var/log -name "*.log" -mtime +30 -delete

# Find and remove empty directories
find . -type d -empty -delete

# Find large files consuming disk space
find / -type f -size +1G -exec ls -lh {} \; 2>/dev/null

# Find temporary files older than 7 days
find /tmp -type f -mtime +7 -user $(whoami) -delete
```

**Code management:**
```bash
# Find all JavaScript files
find ./src -name "*.js" -type f

# Find files modified today
find . -name "*.py" -mtime 0

# Find large node_modules directories
find . -name "node_modules" -type d -exec du -sh {} \;

# Count lines of code
find ./src -name "*.js" -exec wc -l {} + | tail -1
```

**Security auditing:**
```bash
# Find SUID files
find / -perm -4000 -type f 2>/dev/null

# Find world-writable files
find / -type f -perm -o+w 2>/dev/null

# Find files modified in last hour (potential intrusion)
find /etc /bin /sbin -mmin -60 -type f
```

## Xargs Command

**What is xargs?**
Xargs converts stdin into command arguments. It's useful because many commands don't accept piped input.

**Basic xargs syntax:**
```bash
command1 | xargs command2
```

### Why Use Xargs?

**Problem: Some commands don't accept stdin:**
```bash
find . -name "*.txt" | rm              # ❌ Doesn't work
```

**Solution: Use xargs:**
```bash
find . -name "*.txt" | xargs rm        # ✅ Works
```

### Basic Xargs Usage

**Simple examples:**
```bash
# Remove files from list
echo "file1.txt file2.txt file3.txt" | xargs rm

# Create directories
echo "dir1 dir2 dir3" | xargs mkdir

# Show file details
find . -name "*.conf" | xargs ls -l

# Search in multiple files
find . -name "*.js" | xargs grep "function"
```

### Xargs Options

**Limit arguments per command (-n):**
```bash
echo "1 2 3 4 5" | xargs -n 2 echo     # Run echo twice: "1 2" and "3 4" and "5"
find . -name "*.log" | xargs -n 10 rm  # Delete 10 files at a time
```

**Use specific argument placement (-I):**
```bash
# {} is replaced with input
find . -name "*.txt" | xargs -I {} cp {} /backup/

# Multiple uses of placeholder
cat files.txt | xargs -I {} sh -c 'echo Processing {}; cat {}'
```

**Handle spaces in filenames (-0 and -print0):**
```bash
# Problem: filenames with spaces break
find . -name "*.txt" | xargs rm        # ❌ Breaks on "my file.txt"

# Solution: use null-terminated strings
find . -name "*.txt" -print0 | xargs -0 rm     # ✅ Works with spaces
```

**Parallel execution (-P):**
```bash
# Run up to 4 processes in parallel
find . -name "*.jpg" | xargs -P 4 -I {} convert {} {}.optimized

# Use all CPU cores
cat urls.txt | xargs -P $(nproc) -I {} curl -O {}
```

**Verbose output (-t):**
```bash
find . -name "*.log" | xargs -t rm     # Shows command being executed
```

**Prompt before execution (-p):**
```bash
find . -name "*.tmp" | xargs -p rm     # Ask confirmation for each command
```

### Find vs Xargs vs Find -exec

**Comparison:**

```bash
# Method 1: find -exec (one process per file - slow)
find . -name "*.txt" -exec rm {} \;

# Method 2: find -exec with + (one process for all files - fast)
find . -name "*.txt" -exec rm {} +

# Method 3: find with xargs (one process for batches - fast)
find . -name "*.txt" | xargs rm

# Method 4: find with xargs and null delimiter (handles spaces - fast)
find . -name "*.txt" -print0 | xargs -0 rm
```

**When to use what:**
- Use `find -exec {} \;` when you need to run complex commands per file
- Use `find -exec {} +` when the command accepts multiple arguments
- Use `xargs` when you need parallel processing or better control
- Always use `-print0` with `xargs -0` if filenames might have spaces

### Practical Xargs Examples

**Batch processing:**
```bash
# Convert images in parallel
find . -name "*.png" -print0 | xargs -0 -P 4 -I {} convert {} -resize 50% {}

# Download multiple URLs
cat urls.txt | xargs -P 5 -n 1 curl -O

# Compress log files
find /var/log -name "*.log" -mtime +7 | xargs gzip

# Search pattern in multiple files
find . -name "*.js" | xargs grep -l "TODO"
```

**System administration:**
```bash
# Set ownership on found files
find /var/www -type f | xargs chown www-data:www-data

# Change permissions
find . -type f -name "*.sh" | xargs chmod +x

# Copy files preserving structure
find ./src -name "*.ts" -print0 | xargs -0 -I {} cp --parents {} ./backup/
```

**Chaining operations:**
```bash
# Find, sort by size, and delete largest files
find . -type f -name "*.log" -print0 | xargs -0 ls -lS | head -10

# Find and archive
find . -mtime +30 -name "*.pdf" | xargs tar -czf archive.tar.gz

# Find and count lines
find ./src -name "*.py" | xargs wc -l | sort -n
```

**Real-world scenarios:**
```bash
# Find old logs and compress
find /var/log -name "*.log" -mtime +7 -print0 | xargs -0 gzip

# Find large files in home directory
find ~ -type f -size +100M -exec ls -lh {} \; | sort -k5 -hr

find /etc -name "*.conf" -mtime -7 | xargs -I {} cp {} /backup/

find ./src -name "*.js" | xargs grep -c "TODO" | awk -F: '{sum+=$2} END {print sum}'
```
