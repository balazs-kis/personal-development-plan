- Troubleshoot common network interface issues

## Introduction

Network interfaces are the connection points between your Linux system and networks. Understanding how to configure and manage these interfaces is fundamental to Linux system administration. Modern Linux systems use consistent device naming and offer multiple configuration methods, from command-line tools to automated network managers.

Whether you're setting up a server, troubleshooting connectivity issues, or configuring virtual machines, mastering network interface management is essential.

## Key Concepts Summary

### What is a Network Interface?

**Definition:**
- Connection point between computer and network
- Links software networking to hardware
- Has unique identifier (interface name)
- Can be physical or virtual

**Types of interfaces:**
```
Physical interfaces:
- Ethernet cards (enp3s0, eth0)
- Wireless adapters (wlp2s0, wlan0)
- Hardware NICs

Virtual interfaces:
- Loopback (lo)
- Virtual bridges (br0)
- VLANs (eth0.10)
- Tunnels (tun0, tap0)
```

### Interface Naming Conventions

**Traditional naming (deprecated):**
```
eth0    - First Ethernet interface
eth1    - Second Ethernet interface
wlan0   - First wireless interface
```

**Modern predictable naming:**
```
en      - Ethernet
wl      - Wireless LAN
ww      - Wireless WAN

Naming scheme:
enp3s0  - Ethernet, PCI bus 3, slot 0
wlp2s0  - Wireless, PCI bus 2, slot 0
eno1    - Ethernet, onboard device 1
```

**Special interfaces:**
```
lo      - Loopback (127.0.0.1)
virbr0  - Virtual bridge (KVM/libvirt)
docker0 - Docker bridge
```

### Viewing Network Interfaces

**List all interfaces:**
```bash
# Modern command (ip)
ip link show
ip link

# Alternative
ip addr show
ip a

# Legacy command (deprecated)
ifconfig
ifconfig -a
```

**Example output:**
```bash
$ ip link show
1: lo: <LOOPBACK,UP,LOWER_UP> mtu 65536 qdisc noqueue state UNKNOWN
    link/loopback 00:00:00:00:00:00 brd 00:00:00:00:00:00
2: enp3s0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc fq_codel state UP
    link/ether 52:54:00:12:34:56 brd ff:ff:ff:ff:ff:ff
```

**View IP addresses:**
```bash
ip addr show enp3s0
ip addr show

# Short form
ip a s enp3s0
```

**Example output:**
```bash
2: enp3s0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500
    inet 192.168.1.100/24 brd 192.168.1.255 scope global enp3s0
    inet6 fe80::5054:ff:fe12:3456/64 scope link
```

### Interface States

**Common states:**
```
UP          - Interface is enabled
DOWN        - Interface is disabled
LOWER_UP    - Physical link is up (cable connected)
UNKNOWN     - State cannot be determined
DORMANT     - Interface waiting for external event
```

**Check interface state:**
```bash
ip link show enp3s0 | grep state
cat /sys/class/net/enp3s0/operstate
```

### Basic Interface Operations

**Bring interface up:**
```bash
sudo ip link set enp3s0 up
```

**Bring interface down:**
```bash
sudo ip link set enp3s0 down
```

**Set MTU:**
```bash
sudo ip link set enp3s0 mtu 9000
```

**View interface statistics:**
```bash
ip -s link show enp3s0
ip -s -s link show enp3s0  # More detailed
```

### IP Address Configuration

**Add IP address (temporary):**
```bash
sudo ip addr add 192.168.1.100/24 dev enp3s0
```

**Remove IP address:**
```bash
sudo ip addr del 192.168.1.100/24 dev enp3s0
```

**Flush all addresses:**
```bash
sudo ip addr flush dev enp3s0
```

**Add secondary IP:**
```bash
sudo ip addr add 192.168.1.101/24 dev enp3s0
```

### DHCP Configuration

**Manual DHCP request:**
```bash
sudo dhclient enp3s0
sudo dhclient -v enp3s0  # Verbose

# Release DHCP lease
sudo dhclient -r enp3s0
```

**Check DHCP lease:**
```bash
cat /var/lib/dhcp/dhclient.leases
cat /var/lib/dhclient/dhclient.leases
```

### Static IP Configuration

**Temporary (until reboot):**
```bash
sudo ip addr add 192.168.1.100/24 dev enp3s0
sudo ip route add default via 192.168.1.1
```

**Permanent configuration depends on your system:**

**Ubuntu/Debian with netplan:**
```yaml
# /etc/netplan/01-netcfg.yaml
network:
  version: 2
  renderer: networkd
  ethernets:
    enp3s0:
      addresses:
        - 192.168.1.100/24
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses: [8.8.8.8, 1.1.1.1]
```

Apply configuration:
```bash
sudo netplan apply
```

**Red Hat/CentOS/Rocky (NetworkManager):**
```bash
sudo nmcli con mod enp3s0 ipv4.addresses 192.168.1.100/24
sudo nmcli con mod enp3s0 ipv4.gateway 192.168.1.1
sudo nmcli con mod enp3s0 ipv4.dns "8.8.8.8 1.1.1.1"
sudo nmcli con mod enp3s0 ipv4.method manual
sudo nmcli con up enp3s0
```

**Debian (legacy /etc/network/interfaces):**
```bash
# /etc/network/interfaces
auto enp3s0
iface enp3s0 inet static
    address 192.168.1.100
    netmask 255.255.255.0
    gateway 192.168.1.1
    dns-nameservers 8.8.8.8 1.1.1.1
```

Restart networking:
```bash
sudo systemctl restart networking
```

### NetworkManager (nmcli)

**List connections:**
```bash
nmcli connection show
nmcli con show
```

**Show connection details:**
```bash
nmcli connection show enp3s0
```

**List devices:**
```bash
nmcli device status
nmcli dev status
```

**Create new connection:**
```bash
sudo nmcli con add type ethernet con-name my-connection ifname enp3s0
```

**Modify connection:**
```bash
# Set static IP
sudo nmcli con mod my-connection ipv4.addresses 192.168.1.100/24
sudo nmcli con mod my-connection ipv4.gateway 192.168.1.1
sudo nmcli con mod my-connection ipv4.dns "8.8.8.8,1.1.1.1"
sudo nmcli con mod my-connection ipv4.method manual

# Set DHCP
sudo nmcli con mod my-connection ipv4.method auto
```

**Activate connection:**
```bash
sudo nmcli con up my-connection
```

**Delete connection:**
```bash
sudo nmcli con delete my-connection
```

### Routing

**View routing table:**
```bash
ip route show
ip route
ip r

# Alternative
route -n
netstat -rn
```

**Example output:**
```bash
default via 192.168.1.1 dev enp3s0 proto dhcp metric 100
192.168.1.0/24 dev enp3s0 proto kernel scope link src 192.168.1.100
```

**Add default gateway:**
```bash
sudo ip route add default via 192.168.1.1
```

**Add specific route:**
```bash
sudo ip route add 10.0.0.0/8 via 192.168.1.254
```

**Delete route:**
```bash
sudo ip route del default via 192.168.1.1
sudo ip route del 10.0.0.0/8
```

### DNS Configuration

**Check current DNS:**
```bash
cat /etc/resolv.conf
```

**systemd-resolved (modern systems):**
```bash
# View DNS configuration
resolvectl status
systemd-resolve --status

# Set DNS for interface
sudo resolvectl dns enp3s0 8.8.8.8 1.1.1.1
```

**Manual DNS configuration:**
```bash
# Edit /etc/resolv.conf
nameserver 8.8.8.8
nameserver 1.1.1.1
search example.com
```

### Troubleshooting

**Check connectivity:**
```bash
# Test network connectivity
ping -c 4 8.8.8.8
ping -c 4 google.com

# Check interface is up
ip link show enp3s0
```

**Check IP assignment:**
```bash
ip addr show enp3s0
```

**Check routing:**
```bash
ip route show
```

**Check DNS:**
```bash
cat /etc/resolv.conf
nslookup google.com
dig google.com
```

**View kernel messages:**
```bash
dmesg | grep -i eth
dmesg | grep -i network
```

**Check interface errors:**
```bash
ip -s link show enp3s0
ethtool -S enp3s0
```

**Restart networking:**
```bash
# NetworkManager
sudo systemctl restart NetworkManager

# systemd-networkd
sudo systemctl restart systemd-networkd

# netplan
sudo netplan apply
```

### Common Scenarios

**Scenario 1: Configure static IP**
```bash
# Using nmcli
sudo nmcli con mod enp3s0 ipv4.addresses 192.168.1.100/24
sudo nmcli con mod enp3s0 ipv4.gateway 192.168.1.1
sudo nmcli con mod enp3s0 ipv4.dns "8.8.8.8"
sudo nmcli con mod enp3s0 ipv4.method manual
sudo nmcli con up enp3s0

# Verify
ip addr show enp3s0
ip route show
```

**Scenario 2: Switch to DHCP**
```bash
sudo nmcli con mod enp3s0 ipv4.method auto
sudo nmcli con up enp3s0

# Or using dhclient
sudo dhclient enp3s0
```

**Scenario 3: Add second IP**
```bash
sudo ip addr add 192.168.1.101/24 dev enp3s0
ip addr show enp3s0
```

**Scenario 4: Temporarily change IP**
```bash
# Take interface down
sudo ip link set enp3s0 down

# Change IP
sudo ip addr flush dev enp3s0
sudo ip addr add 192.168.1.200/24 dev enp3s0

# Bring interface up
sudo ip link set enp3s0 up
sudo ip route add default via 192.168.1.1
```
