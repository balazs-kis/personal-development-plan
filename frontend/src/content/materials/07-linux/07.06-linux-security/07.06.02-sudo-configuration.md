## Introduction

Sudo (superuser do) allows authorized users to execute commands with elevated privileges without sharing the root password. Proper sudo configuration is critical for security: it enables controlled administrative access, provides an audit trail, and implements the principle of least privilege.

This lesson teaches you to configure sudo safely and effectively for production systems.

## Key Concepts Summary

### What is Sudo?

**Purpose:**
- Execute commands with elevated privileges
- Controlled administrative access
- Alternative to root login
- Audit trail of privileged actions

**How it works:**
```
1. User runs: sudo command
2. Sudo checks /etc/sudoers for authorization
3. Prompts for user's password (not root)
4. Executes command as root (or specified user)
5. Logs action to /var/log/auth.log
```

**Benefits:**
- No need to share root password
- Per-user access control
- Temporary privilege elevation
- Complete audit logging
- Configurable timeout
- Granular permissions

### Basic Sudo Usage

**Run command as root:**
```bash
sudo command
sudo apt update
sudo systemctl restart nginx
```

**Run as different user:**
```bash
sudo -u username command
sudo -u postgres psql
```

**Interactive shell:**
```bash
sudo -i           # Root shell (login)
sudo -s           # Root shell (non-login)
sudo su -         # Switch to root
```

**Environment variables:**
```bash
# Preserve environment
sudo -E command

# Set specific variable
sudo VAR=value command
```

**List sudo privileges:**
```bash
sudo -l
sudo -l -U username  # For specific user
```

### Sudoers File

**Location:**
```
/etc/sudoers           # Main configuration
/etc/sudoers.d/*       # Additional configuration files
```

**NEVER edit directly:**
```bash
# WRONG - can break sudo
sudo nano /etc/sudoers

# RIGHT - validates syntax
sudo visudo
```

**Edit additional files:**
```bash
sudo visudo -f /etc/sudoers.d/custom
```

**Basic syntax:**
```
user  hosts=(runas) commands
```

**Examples:**
```
# Full root access
alice ALL=(ALL:ALL) ALL

# Specific command
bob ALL=(ALL) /usr/bin/systemctl restart nginx

# No password required
charlie ALL=(ALL) NOPASSWD: /usr/bin/systemctl status nginx
```

### Sudoers File Syntax

**User specification format:**
```
User_List Host_List = (Runas_List) Command_List
```

**User_List:**
```
alice                    # Single user
alice, bob               # Multiple users
%developers              # Group (prefix with %)
#1000                    # UID
%#1000                   # GID
```

**Host_List:**
```
ALL                      # Any host
hostname                 # Specific hostname
192.168.1.0/24          # IP range
```

**Runas_List:**
```
(ALL)                    # Any user
(ALL:ALL)               # Any user and group
(root)                   # Run as root
(postgres)               # Run as postgres user
(root:admin)            # Run as root, group admin
```

**Command_List:**
```
ALL                                    # Any command
/usr/bin/systemctl restart nginx       # Specific command
/usr/bin/systemctl                     # Command with any args
/usr/bin/apt update, /usr/bin/apt upgrade  # Multiple commands
```

### Common Sudo Configurations

**Full administrative access:**
```bash
# User gets full sudo
alice ALL=(ALL:ALL) ALL

# Group gets full sudo
%sudo ALL=(ALL:ALL) ALL
%wheel ALL=(ALL:ALL) ALL  # Red Hat/CentOS
```

**Specific commands:**
```bash
# Restart web server
alice ALL=(ALL) /bin/systemctl restart nginx.service

# Multiple related commands
bob ALL=(ALL) /bin/systemctl start nginx, \
              /bin/systemctl stop nginx, \
              /bin/systemctl restart nginx, \
              /bin/systemctl status nginx
```

**No password required:**
```bash
# Passwordless sudo for specific command
alice ALL=(ALL) NOPASSWD: /bin/systemctl status nginx

# Passwordless sudo for all commands (not recommended)
alice ALL=(ALL) NOPASSWD: ALL
```

**Run as specific user:**
```bash
# Run commands as postgres
alice ALL=(postgres) /usr/bin/psql

# Run as any user except root
bob ALL=(ALL,!root) ALL
```

**Command with arguments:**
```bash
# Exact command with specific args
alice ALL=(ALL) /usr/bin/systemctl restart nginx.service

# Command with any args
bob ALL=(ALL) /usr/bin/systemctl

# Command with wildcards (dangerous!)
charlie ALL=(ALL) /usr/bin/systemctl * nginx
```

### Sudo Aliases

**User aliases:**
```bash
# Define alias
User_Alias ADMINS = alice, bob, charlie
User_Alias DEVS = dave, eve

# Use alias
ADMINS ALL=(ALL:ALL) ALL
```

**Host aliases:**
```bash
Host_Alias WEBSERVERS = web1, web2, web3
Host_Alias DBSERVERS = db1, db2

alice WEBSERVERS=(ALL) /bin/systemctl restart nginx
```

**Command aliases:**
```bash
Cmnd_Alias SERVICES = /bin/systemctl restart nginx, \
                      /bin/systemctl restart postgresql, \
                      /bin/systemctl restart redis

alice ALL=(ALL) SERVICES
```

**Runas aliases:**
```bash
Runas_Alias APPS = postgres, redis, nginx

alice ALL=(APPS) ALL
```

**Complete example:**
```bash
# Aliases
User_Alias WEBADMINS = alice, bob
Host_Alias WEBSERVERS = web1, web2, web3
Cmnd_Alias WEBSERVICES = /bin/systemctl restart nginx, \
                         /bin/systemctl reload nginx, \
                         /bin/systemctl status nginx

# Rule
WEBADMINS WEBSERVERS=(ALL) WEBSERVICES
```

### Sudo Defaults

**Timeout settings:**
```bash
# Password timeout (default 15 minutes)
Defaults timestamp_timeout=5        # 5 minutes
Defaults timestamp_timeout=0        # Always prompt
Defaults timestamp_timeout=-1       # Never timeout (password once)
```

**Environment:**
```bash
# Preserve specific variables
Defaults env_keep += "SSH_AUTH_SOCK"
Defaults env_keep += "EDITOR"

# Reset environment (default)
Defaults env_reset

# Allow specific environment variables
Defaults env_keep = "COLORS DISPLAY HOSTNAME"
```

**Security options:**
```bash
# Require tty (prevent some attacks)
Defaults requiretty

# Use root path
Defaults secure_path="/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin"

# Log input/output
Defaults log_input
Defaults log_output
```

**Per-user defaults:**
```bash
# Alice has longer timeout
Defaults:alice timestamp_timeout=30

# Bob never needs password
Defaults:bob !authenticate
```

### Sudo Logging

**Auth log location:**
```bash
# Ubuntu/Debian
/var/log/auth.log

# Red Hat/CentOS
/var/log/secure

# View sudo logs
sudo grep sudo /var/log/auth.log
sudo journalctl -u sudo
```

**Example log entries:**
```
Jan 26 10:00:00 server sudo: alice : TTY=pts/0 ; PWD=/home/alice ; USER=root ; COMMAND=/usr/bin/apt update
Jan 26 10:01:00 server sudo: alice : TTY=pts/0 ; PWD=/home/alice ; USER=root ; COMMAND=/bin/systemctl restart nginx
```

**Enhanced logging:**
```bash
# Log I/O
Defaults log_input, log_output
Defaults iolog_dir=/var/log/sudo-io
```

**View sudo history:**
```bash
# All sudo commands
sudo grep sudo /var/log/auth.log

# Specific user
sudo grep "sudo.*alice" /var/log/auth.log

# Failed sudo attempts
sudo grep "sudo.*COMMAND=.*authentication failure" /var/log/auth.log
```

### Security Best Practices

**1. Always use visudo:**
```bash
sudo visudo              # Edit main file
sudo visudo -c           # Check syntax
sudo visudo -f /etc/sudoers.d/custom  # Edit drop-in
```

**2. Minimize ALL usage:**
```bash
# BAD - too permissive
alice ALL=(ALL) ALL

# GOOD - specific commands
alice ALL=(ALL) /bin/systemctl restart nginx, \
                /bin/systemctl reload nginx
```

**3. Avoid NOPASSWD when possible:**
```bash
# Only use for automation
ansible ALL=(ALL) NOPASSWD: ALL

# Better: specific commands
jenkins ALL=(ALL) NOPASSWD: /usr/bin/docker
```

**4. Be careful with wildcards:**
```bash
# DANGEROUS - can be abused
alice ALL=(ALL) /bin/*

# BETTER - specific paths
alice ALL=(ALL) /bin/systemctl
```

**5. Use sudoers.d directory:**
```bash
# Create separate files for different roles
/etc/sudoers.d/webadmins
/etc/sudoers.d/dbadmins
/etc/sudoers.d/developers
```

**6. Regular audits:**
```bash
# Review sudoers configuration
sudo visudo -c

# Check who has sudo
getent group sudo

# Review sudo logs
sudo grep sudo /var/log/auth.log | tail -50
```

### Troubleshooting

**User not in sudoers:**
```bash
# Error: user is not in the sudoers file

# Solution: Add to sudo group
sudo usermod -aG sudo username

# Or add to sudoers
echo "username ALL=(ALL) ALL" | sudo tee /etc/sudoers.d/username
```

**Syntax errors:**
```bash
# Always use visudo - it validates
sudo visudo

# Check syntax
sudo visudo -c
```

**Password not accepted:**
```bash
# Verify user password
sudo passwd username

# Check if NOPASSWD is set
sudo -l
```

**Command not allowed:**
```bash
# Check permissions
sudo -l

# View full sudo config
sudo cat /etc/sudoers
sudo cat /etc/sudoers.d/*
```

### Practical Examples

**Web server administrators:**
```bash
# /etc/sudoers.d/webadmins
User_Alias WEBADMINS = alice, bob
Cmnd_Alias WEBSERVICES = /bin/systemctl restart nginx, \
                         /bin/systemctl reload nginx, \
                         /bin/systemctl start nginx, \
                         /bin/systemctl stop nginx

WEBADMINS ALL=(ALL) WEBSERVICES
```

**Database administrators:**
```bash
# /etc/sudoers.d/dbadmins
User_Alias DBADMINS = charlie, dave
Cmnd_Alias DBSERVICES = /bin/systemctl * postgresql, \
                        /usr/bin/pg_*

DBADMINS ALL=(postgres) DBSERVICES
```

**Developers (limited sudo):**
```bash
# /etc/sudoers.d/developers
%developers ALL=(ALL) /bin/systemctl status *, \
                      /bin/journalctl -u *, \
                      /usr/bin/tail /var/log/*
```

**Automation user:**
```bash
# /etc/sudoers.d/ansible
ansible ALL=(ALL) NOPASSWD: ALL
Defaults:ansible !requiretty
```
