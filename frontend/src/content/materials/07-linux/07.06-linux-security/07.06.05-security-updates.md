## Learning Objectives

By the end of this lesson, you will be able to:
- Understand the importance of security updates
- Configure automatic security updates on Linux
- Use unattended-upgrades on Ubuntu/Debian
- Manage updates on Red Hat/CentOS systems
- Configure update notifications and logging
- Balance security and stability in patch management
- Implement a patch management strategy

---

## Introduction

Keeping Linux systems updated with security patches is critical for protecting against vulnerabilities. Unpatched systems are easy targets for attackers exploiting known vulnerabilities. This lesson covers automated patch management to ensure systems stay secure without requiring constant manual intervention.

## Key Concepts Summary

### Why Security Updates Matter

**Risks of unpatched systems:**
```
Known vulnerabilities - Attackers exploit public CVEs
Remote code execution - Gain system access
Privilege escalation  - Obtain root access
Data breaches         - Steal sensitive information
Ransomware           - Encrypt and hold data hostage
Compliance failures  - Violate regulatory requirements
```

**Benefits of patching:**
- Fixes known vulnerabilities
- Closes security holes
- Prevents exploitation
- Maintains compliance
- Improves stability
- Adds security features

**Patch management challenges:**
```
Manual updates:
- Time-consuming
- Easy to forget
- Inconsistent
- Doesn't scale

Automatic updates:
- Consistent
- Timely
- Scales well
- May break applications
- Requires testing strategy
```

### Update Types

**Security updates:**
```
Priority: Critical
Risk: Low
Frequency: As released
Auto-install: Recommended
```

**Bug fixes:**
```
Priority: Medium
Risk: Low-Medium
Frequency: Regular
Auto-install: Optional
```

**Feature updates:**
```
Priority: Low
Risk: Medium-High
Frequency: Version releases
Auto-install: Not recommended
```

**Kernel updates:**
```
Priority: High (security)
Risk: Medium (requires reboot)
Frequency: Regular
Auto-install: With caution
Requires: Reboot
```

### Ubuntu/Debian: unattended-upgrades

**What is unattended-upgrades?**
- Automatic security update tool
- Debian and Ubuntu standard
- Configurable update sources
- Email notifications
- Automatic reboot options
- Minimal maintenance

**Installation:**
```bash
# Install package
sudo apt update
sudo apt install unattended-upgrades

# Enable with wizard
sudo dpkg-reconfigure --priority=low unattended-upgrades

# Or install with apt-config-auto-update
sudo apt install apt-config-auto-update
```

**Check if enabled:**
```bash
# Check service status
systemctl status apt-daily-upgrade.timer
systemctl status apt-daily.timer

# Check configuration
cat /etc/apt/apt.conf.d/20auto-upgrades
```

### Configuration Files

**Main configuration files:**
```
/etc/apt/apt.conf.d/20auto-upgrades    - Enable/disable
/etc/apt/apt.conf.d/50unattended-upgrades - Detailed config
/etc/apt/apt.conf.d/10periodic          - Update frequency
```

**Enable automatic updates:**
```bash
# /etc/apt/apt.conf.d/20auto-upgrades
APT::Periodic::Update-Package-Lists "1";
APT::Periodic::Unattended-Upgrade "1";
```

**Extended configuration:**
```bash
# /etc/apt/apt.conf.d/20auto-upgrades
APT::Periodic::Update-Package-Lists "1";           # Daily
APT::Periodic::Download-Upgradeable-Packages "1"; # Daily
APT::Periodic::Unattended-Upgrade "1";            # Daily
APT::Periodic::AutocleanInterval "7";             # Weekly
APT::Periodic::Verbose "2";                        # Verbose output
```

### Detailed Configuration

**Edit main config:**
```bash
sudo nano /etc/apt/apt.conf.d/50unattended-upgrades
```

**Update sources (what to update):**
```
Unattended-Upgrade::Allowed-Origins {
    "${distro_id}:${distro_codename}-security";
    "${distro_id}:${distro_codename}-updates";
    // "${distro_id}:${distro_codename}-proposed";
    // "${distro_id}:${distro_codename}-backports";
};
```

**Security updates only:**
```
Unattended-Upgrade::Allowed-Origins {
    "${distro_id}:${distro_codename}-security";
};
```

**Blacklist packages (never auto-update):**
```
Unattended-Upgrade::Package-Blacklist {
    "nginx";
    "postgresql*";
    "mysql*";
};
```

**Auto-reboot configuration:**
```
// Automatically reboot if needed
Unattended-Upgrade::Automatic-Reboot "true";

// Reboot time (2 AM)
Unattended-Upgrade::Automatic-Reboot-Time "02:00";

// Reboot only if no users logged in
Unattended-Upgrade::Automatic-Reboot-WithUsers "false";
```

**Email notifications:**
```
// Email address for notifications
Unattended-Upgrade::Mail "admin@example.com";

// When to email
// "always", "only-on-error", "on-change"
Unattended-Upgrade::MailReport "on-change";
```

**Logging:**
```
// Log to syslog
Unattended-Upgrade::SyslogEnable "true";
Unattended-Upgrade::SyslogFacility "daemon";

// Detailed logging
Unattended-Upgrade::Verbose "true";
```

**Advanced options:**
```
// Remove unused dependencies
Unattended-Upgrade::Remove-Unused-Dependencies "true";

// Remove unused kernel packages
Unattended-Upgrade::Remove-Unused-Kernel-Packages "true";

// Minimum free space required (MB)
Unattended-Upgrade::MinimalSteps "true";

// Split upgrade into minimal steps
Unattended-Upgrade::InstallOnShutdown "false";
```

### Testing and Debugging

**Dry run (test without installing):**
```bash
sudo unattended-upgrade --dry-run --debug
```

**Manual run:**
```bash
sudo unattended-upgrade --debug
```

**View logs:**
```bash
# Main log
sudo cat /var/log/unattended-upgrades/unattended-upgrades.log

# Detailed log
sudo cat /var/log/unattended-upgrades/unattended-upgrades-dpkg.log

sudo tail -f /var/log/unattended-upgrades/unattended-upgrades.log
```

**Check last run:**
```bash
ls -la /var/log/unattended-upgrades/
stat /var/log/unattended-upgrades/unattended-upgrades.log
```

**View apt history:**
```bash
cat /var/log/apt/history.log
cat /var/log/apt/term.log
```

### Red Hat/CentOS: yum-cron/dnf-automatic

**Installation:**
```bash
# Red Hat 7/CentOS 7
sudo yum install yum-cron

# Red Hat 8+/CentOS 8+/Rocky/Alma
sudo dnf install dnf-automatic
```

**Enable service:**
```bash
# yum-cron
sudo systemctl enable --now yum-cron

# dnf-automatic
sudo systemctl enable --now dnf-automatic.timer
```

**Configuration:**
```bash
# yum-cron
sudo nano /etc/yum/yum-cron.conf

# dnf-automatic
sudo nano /etc/dnf/automatic.conf
```

**yum-cron configuration:**
```ini
[commands]
# What to do: apply, download-only, check-only
update_cmd = security
download_updates = yes
apply_updates = yes

[emitters]
emit_via = stdio,email

[email]
email_from = root@localhost
email_to = admin@example.com
email_host = localhost
```

**dnf-automatic configuration:**
```ini
[commands]
# What to update
upgrade_type = security

# Apply updates
apply_updates = yes

# Download only
download_updates = yes

[emitters]
emit_via = stdio email

[email]
email_from = root@localhost
email_to = admin@example.com
email_host = localhost
```

**Check status:**
```bash
# yum-cron
sudo systemctl status yum-cron

# dnf-automatic
sudo systemctl status dnf-automatic.timer
systemctl list-timers dnf-automatic.*
```

### Manual Update Commands

**Ubuntu/Debian:**
```bash
# Update package list
sudo apt update

# Show available updates
apt list --upgradable

# Install security updates only
sudo unattended-upgrade

# Install all updates
sudo apt upgrade

# Full upgrade (may remove packages)
sudo apt full-upgrade

# Auto-remove unused packages
sudo apt autoremove
```

**Red Hat/CentOS:**
```bash
# Check for updates
sudo yum check-update    # Red Hat 7
sudo dnf check-update    # Red Hat 8+

# Security updates only
sudo yum update --security
sudo dnf upgrade --security

# All updates
sudo yum update
sudo dnf upgrade

# Auto-remove unused packages
sudo dnf autoremove
```

### Monitoring Updates

**Check pending updates:**
```bash
# Ubuntu/Debian
apt list --upgradable

# Red Hat/CentOS 7
yum list updates

# Red Hat/CentOS 8+
dnf list updates
dnf list --security
```

**View update history:**
```bash
# Ubuntu/Debian
cat /var/log/apt/history.log | grep "End-Date" | tail -10

# Red Hat/CentOS
sudo yum history
sudo dnf history
```

**Check last update time:**
```bash
# Ubuntu/Debian
stat /var/lib/apt/periodic/update-success-stamp

# Red Hat/CentOS
stat /var/cache/yum/*
stat /var/cache/dnf/*
```

### Reboot Management

**Check if reboot required:**
```bash
# Ubuntu/Debian
if [ -f /var/run/reboot-required ]; then
    echo "Reboot required"
    cat /var/run/reboot-required.pkgs
fi

# Red Hat/CentOS
sudo needs-restarting -r
```

**Schedule reboot:**
```bash
# Reboot at specific time
sudo shutdown -r 02:00

# Reboot in 10 minutes
sudo shutdown -r +10

# Cancel scheduled reboot
sudo shutdown -c
```

**Automatic reboot with unattended-upgrades:**
```
Unattended-Upgrade::Automatic-Reboot "true";
Unattended-Upgrade::Automatic-Reboot-Time "02:00";
```

### Patch Management Strategy

**Production environments:**
```
1. Test environment
   - Auto-update enabled
   - Test for issues

2. Staging environment
   - Apply tested updates
   - Validate functionality

3. Production environment
   - Apply validated updates
   - Maintenance window
   - Rollback plan ready
```

**Development/Testing:**
```
- Auto-update all packages
- Stay current with latest
- Test application compatibility
```

**Critical servers:**
```
- Security updates only
- Manual approval
- Maintenance windows
- Change control process
```

**Web/Application servers:**
```
- Auto security updates
- Manual feature updates
- Rolling updates
- Load balancer health checks
```

### Best Practices

**Configuration:**
- Enable automatic security updates
- Configure email notifications
- Blacklist critical packages
- Set appropriate reboot policy
- Configure logging
- Test before production

**Monitoring:**
- Check logs regularly
- Monitor update success
- Track reboot requirements
- Review update history
- Alert on failures

**Maintenance:**
- Regular security audits
- Test update process
- Maintain rollback procedures
- Document exceptions
- Review blacklist periodically

**Compliance:**
- Document patch policies
- Track patch status
- Audit update history
- Maintain evidence
- Regular reporting
