## Introduction

Context transforms logs from isolated events into a coherent story. Adding correlation IDs, user IDs, and other contextual information enables you to track requests across services, find all logs related to a specific user or transaction, and understand the complete picture of what happened. This lesson teaches you to enrich logs with the context needed for effective debugging.

## Key Concepts Summary

### What is Context?

**Definition:**
```
Additional information about the environment
Where, when, who, and why of log events
Enables filtering and correlation
Provides debugging insights
```

**Types of context:**
```
Temporal:    When did it happen?
Identity:    Who was involved?
Location:    Where in the system?
Correlation: How do events relate?
Business:    What business context?
```

### Correlation IDs

**Purpose:**
```
Track requests across services
Link logs from same transaction
Enable end-to-end tracing
Troubleshoot distributed systems
```

**Implementation:**
```csharp
public class CorrelationIdMiddleware
{
    private readonly RequestDelegate _next;
    private const string CorrelationIdHeader = "X-Correlation-ID";

    public async Task InvokeAsync(HttpContext context, ILogger<CorrelationIdMiddleware> logger)
    {
        // Extract or generate correlation ID
        var correlationId = context.Request.Headers[CorrelationIdHeader].FirstOrDefault()
            ?? Guid.NewGuid().ToString();
        
        // Add to response
        context.Response.Headers.Add(CorrelationIdHeader, correlationId);
        
        // Add to logs via LogContext
        using (LogContext.PushProperty("CorrelationId", correlationId))
        {
            logger.LogInformation("Request started: {Method} {Path}", 
                context.Request.Method, 
                context.Request.Path);
            
            await _next(context);
            
            logger.LogInformation("Request completed: {StatusCode}", 
                context.Response.StatusCode);
        }
    }
}

// Register
app.UseMiddleware<CorrelationIdMiddleware>();
```

**Result:**
```json
{
  "Timestamp": "2026-01-27T10:00:00Z",
  "Level": "Information",
  "Message": "Request started: GET /api/users",
  "CorrelationId": "abc-123-def",
  "Method": "GET",
  "Path": "/api/users"
}
```

### LogContext

**Push properties:**
```csharp
using Serilog.Context;

// Single property
using (LogContext.PushProperty("UserId", userId))
{
    _logger.LogInformation("Processing request");
    // Includes UserId automatically
    
    await ProcessAsync();
    // All logs in this scope include UserId
}
// UserId removed from context
```

**Multiple properties:**
```csharp
using (LogContext.PushProperty("OrderId", orderId))
using (LogContext.PushProperty("UserId", userId))
using (LogContext.PushProperty("SessionId", sessionId))
{
    _logger.LogInformation("Order processing started");
    // All three properties included
    
    await ValidateOrderAsync();
    await ChargePaymentAsync();
    await ShipOrderAsync();
    // Every log in this scope includes all three properties
}
```

**Destructuring objects:**
```csharp
var requestContext = new
{
    UserId = userId,
    SessionId = sessionId,
    IpAddress = ipAddress,
    UserAgent = userAgent
};

using (LogContext.PushProperty("RequestContext", requestContext, destructureObjects: true))
{
    // All logs include full RequestContext object
    _logger.LogInformation("Request received");
}
```

### User Context

**Add user information:**
```csharp
public class UserContextMiddleware
{
    public async Task InvokeAsync(HttpContext context)
    {
        if (context.User.Identity?.IsAuthenticated == true)
        {
            var userId = context.User.FindFirst(ClaimTypes.NameIdentifier)?.Value;
            var userName = context.User.FindFirst(ClaimTypes.Name)?.Value;
            var roles = context.User.FindAll(ClaimTypes.Role)
                .Select(c => c.Value)
                .ToArray();
            
            using (LogContext.PushProperty("UserId", userId))
            using (LogContext.PushProperty("UserName", userName))
            using (LogContext.PushProperty("UserRoles", roles))
            {
                await _next(context);
            }
        }
        else
        {
            await _next(context);
        }
    }
}
```

### Trace Context Integration

**Add OpenTelemetry trace context:**
```csharp
using System.Diagnostics;

public class TraceContextEnricher : ILogEventEnricher
{
    public void Enrich(LogEvent logEvent, ILogEventPropertyFactory propertyFactory)
    {
        var activity = Activity.Current;
        if (activity != null)
        {
            logEvent.AddPropertyIfAbsent(
                propertyFactory.CreateProperty("TraceId", activity.TraceId.ToString()));
            logEvent.AddPropertyIfAbsent(
                propertyFactory.CreateProperty("SpanId", activity.SpanId.ToString()));
            logEvent.AddPropertyIfAbsent(
                propertyFactory.CreateProperty("ParentId", activity.ParentId));
        }
    }
}

// Register
.Enrich.With<TraceContextEnricher>()
```

**Result:**
```json
{
  "Timestamp": "2026-01-27T10:00:00Z",
  "Message": "Processing payment",
  "TraceId": "abc123def456",
  "SpanId": "xyz789",
  "ParentId": "parent-123",
  "UserId": "user-456"
}
```

### Environment Context

**Add environment information:**
```csharp
.Enrich.WithMachineName()       // Server name
.Enrich.WithEnvironmentName()   // Development/Staging/Production
.Enrich.WithThreadId()          // Thread ID
.Enrich.WithProcessId()         // Process ID
```

**Custom environment enricher:**
```csharp
public class ApplicationEnricher : ILogEventEnricher
{
    private readonly string _applicationName;
    private readonly string _version;
    private readonly string _environment;

    public ApplicationEnricher(IConfiguration configuration)
    {
        _applicationName = configuration["ApplicationName"] ?? "MyApp";
        _version = Assembly.GetExecutingAssembly()
            .GetCustomAttribute<AssemblyInformationalVersionAttribute>()?
            .InformationalVersion ?? "unknown";
        _environment = Environment.GetEnvironmentVariable("ASPNETCORE_ENVIRONMENT") 
            ?? "Production";
    }

    public void Enrich(LogEvent logEvent, ILogEventPropertyFactory propertyFactory)
    {
        logEvent.AddOrUpdateProperty(
            propertyFactory.CreateProperty("Application", _applicationName));
        logEvent.AddOrUpdateProperty(
            propertyFactory.CreateProperty("Version", _version));
        logEvent.AddOrUpdateProperty(
            propertyFactory.CreateProperty("Environment", _environment));
    }
}
```

### Practical Example

**Complete context setup:**
```csharp
// Middleware registration order matters!
app.UseMiddleware<CorrelationIdMiddleware>();  // First
app.UseAuthentication();
app.UseMiddleware<UserContextMiddleware>();    // After auth
app.UseSerilogRequestLogging();                // Log requests

// Example controller with context
[ApiController]
[Route("api/orders")]
public class OrdersController : ControllerBase
{
    [HttpPost]
    public async Task<IActionResult> CreateOrder([FromBody] CreateOrderRequest request)
    {
        // Context already includes:
        // - CorrelationId (from middleware)
        // - UserId, UserName (from middleware)
        // - TraceId, SpanId (from enricher)
        // - Machine, Environment (from enrichers)
        
        // Add operation-specific context
        using (LogContext.PushProperty("OrderId", request.OrderId))
        using (LogContext.PushProperty("OrderType", request.Type))
        {
            _logger.LogInformation(
                "Creating order: {@OrderRequest}",
                request);
            
            try
            {
                var order = await _orderService.CreateAsync(request);
                
                _logger.LogInformation(
                    "Order created: Total {Total}",
                    order.Total);
                
                return Ok(order);
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Order creation failed");
                return StatusCode(500);
            }
        }
    }
}
```

### Querying with Context

**Find all logs for user:**
```sql
WHERE UserId = "user-456"
ORDER BY Timestamp DESC
```

**Find all logs for correlation ID:**
```sql
WHERE CorrelationId = "abc-123-def"
ORDER BY Timestamp ASC
```

**Find errors by trace:**
```sql
WHERE TraceId = "trace-789"
AND Level = "Error"
```

**Business analytics:**
```sql
SELECT OrderType, COUNT(*), AVG(Total)
FROM logs
WHERE Message LIKE "%Order created%"
GROUP BY OrderType
```

### Best Practices

**Do add:**
```
✓ Correlation/Request IDs
✓ User IDs (if authenticated)
✓ Session IDs
✓ Trace and Span IDs
✓ Application name and version
✓ Environment name
✓ Relevant business identifiers
```

**Don't add:**
```
✗ Passwords or secrets
✗ PII without masking
✗ Credit card numbers
✗ Authentication tokens
✗ Too much data (performance)
```

**Masking sensitive data:**
```csharp
public static class SensitiveDataMasker
{
    public static string MaskEmail(string email)
    {
        if (string.IsNullOrEmpty(email)) return email;
        
        var parts = email.Split('@');
        if (parts.Length != 2) return email;
        
        var local = parts[0];
        var masked = local.Length > 2
            ? $"{local[0]}***{local[^1]}"
            : "***";
        
        return $"{masked}@{parts[1]}";
    }
    
    public static string MaskCardNumber(string cardNumber)
    {
        if (string.IsNullOrEmpty(cardNumber)) return cardNumber;
        return $"****-****-****-{cardNumber[^4..]}";
    }
}

// Usage
_logger.LogInformation(
    "Payment processed for {MaskedEmail}",
    SensitiveDataMasker.MaskEmail(email));
```
