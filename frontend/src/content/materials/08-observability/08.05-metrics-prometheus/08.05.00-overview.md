# Chapter 8.5: Metrics Collection with Prometheus

## Overview
This chapter explores Prometheus, the leading open-source metrics system and de facto standard for cloud-native monitoring. You'll learn about its architecture, the four metric types (counters, gauges, histograms, and summaries), PromQL query language, recording and alerting rules, and service discovery mechanisms—everything you need to implement effective metrics collection in production environments.

## Key Concepts
- **Prometheus Architecture:** understanding the components that make up the Prometheus monitoring system.
- **Metric Types:** mastering counters, gauges, histograms, and summaries for different use cases.
- **PromQL:** learning the powerful query language for aggregating and analyzing metrics.
- **Recording Rules and Alerts:** creating rules for precomputed queries and alerting conditions.
- **Service Discovery:** automatically discovering monitoring targets in dynamic environments.
