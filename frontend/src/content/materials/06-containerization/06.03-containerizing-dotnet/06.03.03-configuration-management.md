By the end of this lesson, you will be able to:

## Introduction

Configuration management in containers requires a different approach than traditional deployments. You need to externalize configuration, handle secrets securely, and support multiple environments. This lesson covers .NET-specific configuration patterns optimized for containerized environments.

## Key Concepts Summary

### ASP.NET Core Configuration Hierarchy

ASP.NET Core loads configuration in this order (later sources override earlier):

```
1. appsettings.json
2. appsettings.{Environment}.json
3. User Secrets (Development only)
4. Environment Variables
5. Command-line arguments
```

**In containers, you typically use:**
- `appsettings.json` → Default values
- Environment variables → Runtime configuration
- Docker secrets/volumes → Sensitive data

### appsettings.json Configuration

**appsettings.json** (baked into image):
```json
{
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft.AspNetCore": "Warning"
    }
  },
  "AllowedHosts": "*",
  "ConnectionStrings": {
    "DefaultConnection": "Server=localhost;Database=MyDb;",
    "Redis": "localhost:6379"
  },
  "AppSettings": {
    "MaxItemsPerPage": 50,
    "CacheExpirationMinutes": 30
  }
}
```

**appsettings.Production.json** (also baked in):
```json
{
  "Logging": {
    "LogLevel": {
      "Default": "Warning",
      "Microsoft.AspNetCore": "Error"
    }
  },
  "AppSettings": {
    "MaxItemsPerPage": 100
  }
}
```

### Environment Variables Override

Environment variables override JSON configuration:

**Hierarchical configuration:**
```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=localhost;Database=MyDb;"
  }
}
```

**Override with environment variable:**
```bash
# Use double underscore (__) for hierarchy
ConnectionStrings__DefaultConnection="Server=proddb;Database=MyDb;User=sa;Password=secret"
```

**In Docker:**
```dockerfile
ENV ConnectionStrings__DefaultConnection="Server=db;Database=MyDb;User=sa;Password=secret"
```

Or with docker run:
```bash
docker run -e "ConnectionStrings__DefaultConnection=Server=db;..." myapp
```

### Docker Compose Configuration

**docker-compose.yml:**
```yaml
version: '3.8'

services:
  api:
    image: myapi:latest
    environment:
      # Override appsettings values
      - ASPNETCORE_ENVIRONMENT=Production
      - ConnectionStrings__DefaultConnection=Server=db;Database=MyDb;User Id=sa;Password=${DB_PASSWORD}
      - ConnectionStrings__Redis=redis:6379
      - AppSettings__MaxItemsPerPage=200
      - Logging__LogLevel__Default=Information
    env_file:
      - .env
    depends_on:
      - db
      - redis

  db:
    image: mcr.microsoft.com/mssql/server:2022-latest
    environment:
      - ACCEPT_EULA=Y
      - SA_PASSWORD=${DB_PASSWORD}
    
  redis:
    image: redis:7-alpine
```

**.env file:**
```env
DB_PASSWORD=YourStrong!Password123
JWT_SECRET=your-super-secret-jwt-key
API_KEY=your-api-key
```

### Environment-Specific Configuration

**Program.cs:**
```csharp
var builder = WebApplication.CreateBuilder(args);

// Configuration is automatically loaded:
// 1. appsettings.json
// 2. appsettings.{Environment}.json
// 3. Environment variables
// 4. Command-line args

var app = builder.Build();
```

**Access configuration:**
```csharp
// In controllers/services
public class MyService
{
    private readonly IConfiguration _configuration;
    
    public MyService(IConfiguration configuration)
    {
        _configuration = configuration;
    }
    
    public void DoSomething()
    {
        var connectionString = _configuration.GetConnectionString("DefaultConnection");
        var maxItems = _configuration.GetValue<int>("AppSettings:MaxItemsPerPage");
        var apiKey = _configuration["ApiSettings:ApiKey"];
    }
}
```

**Using Options Pattern (recommended):**
```csharp
// appsettings.json
{
  "AppSettings": {
    "MaxItemsPerPage": 50,
    "CacheExpirationMinutes": 30,
    "EnableFeatureX": true
  }
}

// AppSettings.cs
public class AppSettings
{
    public int MaxItemsPerPage { get; set; }
    public int CacheExpirationMinutes { get; set; }
    public bool EnableFeatureX { get; set; }
}

// Program.cs
builder.Services.Configure<AppSettings>(
    builder.Configuration.GetSection("AppSettings"));

// Usage in controller
public class MyController : ControllerBase
{
    private readonly AppSettings _settings;
    
    public MyController(IOptions<AppSettings> settings)
    {
        _settings = settings.Value;
    }
    
    [HttpGet]
    public IActionResult Get()
    {
        var maxItems = _settings.MaxItemsPerPage;
        // ...
    }
}
```

### Handling Secrets in Containers

**❌ DON'T hardcode secrets:**
```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=prod;User=sa;Password=P@ssw0rd123"
  }
}
```

**✅ DO use environment variables:**
```bash
docker run \
  -e "ConnectionStrings__DefaultConnection=Server=db;User=sa;Password=$DB_PASS" \
  myapi
```

**✅ DO use Docker secrets (Swarm):**
```yaml
version: '3.8'

services:
  api:
    image: myapi:latest
    secrets:
      - db_password
      - jwt_secret
    environment:
      - ConnectionStrings__DefaultConnection=Server=db;Database=MyDb;User Id=sa;Password_File=/run/secrets/db_password

secrets:
  db_password:
    external: true
  jwt_secret:
    external: true
```

**✅ DO use Azure Key Vault:**
```csharp
// Program.cs
builder.Configuration.AddAzureKeyVault(
    new Uri($"https://{keyVaultName}.vault.azure.net/"),
    new DefaultAzureCredential());
```

### Mount Configuration Files

**Mount appsettings as volume:**
```bash
docker run \
  -v $(pwd)/appsettings.Production.json:/app/appsettings.Production.json:ro \
  myapi
```

**Docker Compose:**
```yaml
version: '3.8'

services:
  api:
    image: myapi:latest
    volumes:
      - ./config/appsettings.Production.json:/app/appsettings.Production.json:ro
    environment:
      - ASPNETCORE_ENVIRONMENT=Production
```

**Benefits:**
- Update configuration without rebuilding image
- Different configs for different environments
- Centralized configuration management

### Connection Strings for Containers

**Database connection string:**
```bash
# Use service name as hostname in Docker Compose
"Server=sqlserver;Database=MyDb;User Id=sa;Password=YourPassword;TrustServerCertificate=True"
```

**Redis connection:**
```bash
"redis:6379"
```

**Example in docker-compose.yml:**
```yaml
services:
  api:
    environment:
      - ConnectionStrings__DefaultConnection=Server=sqlserver;Database=MyDb;User Id=sa;Password=${DB_PASSWORD};TrustServerCertificate=True
      - ConnectionStrings__Redis=redis:6379
    depends_on:
      - sqlserver
      - redis

  sqlserver:
    image: mcr.microsoft.com/mssql/server:2022-latest
    environment:
      - ACCEPT_EULA=Y
      - SA_PASSWORD=${DB_PASSWORD}

  redis:
    image: redis:7-alpine
```

### ASPNETCORE_ENVIRONMENT

Set the environment:

**Dockerfile:**
```dockerfile
ENV ASPNETCORE_ENVIRONMENT=Production
```

**docker run:**
```bash
docker run -e ASPNETCORE_ENVIRONMENT=Production myapi
```

**docker-compose.yml:**
```yaml
services:
  api:
    environment:
      - ASPNETCORE_ENVIRONMENT=Production
```

**Effects:**
- Loads `appsettings.Production.json`
- Disables Developer Exception Page
- Enables response caching
- Uses production logging levels

### Complete Configuration Example

**appsettings.json:**
```json
{
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft.AspNetCore": "Warning"
    }
  },
  "AllowedHosts": "*",
  "ConnectionStrings": {
    "DefaultConnection": "Server=localhost;Database=MyDb;Integrated Security=true",
    "Redis": "localhost:6379"
  },
  "JwtSettings": {
    "SecretKey": "development-secret-key",
    "Issuer": "MyApp",
    "Audience": "MyApp",
    "ExpirationMinutes": 60
  },
  "ExternalApis": {
    "WeatherApi": {
      "BaseUrl": "https://api.weather.com",
      "ApiKey": "dev-api-key"
    }
  },
  "FeatureFlags": {
    "EnableNewFeature": false,
    "EnableCaching": true
  }
}
```

**appsettings.Production.json:**
```json
{
  "Logging": {
    "LogLevel": {
      "Default": "Warning",
      "Microsoft.AspNetCore": "Error"
    }
  },
  "FeatureFlags": {
    "EnableNewFeature": true,
    "EnableCaching": true
  }
}
```

**docker-compose.yml:**
```yaml
version: '3.8'

services:
  api:
    build: .
    ports:
      - "8080:8080"
    environment:
      - ASPNETCORE_ENVIRONMENT=Production
      - ASPNETCORE_URLS=http://+:8080
      
      # Connection strings
      - ConnectionStrings__DefaultConnection=Server=sqlserver;Database=MyDb;User Id=sa;Password=${DB_PASSWORD};TrustServerCertificate=True
      - ConnectionStrings__Redis=redis:6379
      
      # JWT settings
      - JwtSettings__SecretKey=${JWT_SECRET}
      - JwtSettings__ExpirationMinutes=120
      
      # External API
      - ExternalApis__WeatherApi__ApiKey=${WEATHER_API_KEY}
      
      # Feature flags
      - FeatureFlags__EnableNewFeature=true
    
    env_file:
      - .env
    
    depends_on:
      - sqlserver
      - redis
    
    networks:
      - app-network

  sqlserver:
    image: mcr.microsoft.com/mssql/server:2022-latest
    environment:
      - ACCEPT_EULA=Y
      - SA_PASSWORD=${DB_PASSWORD}
    volumes:
      - sqlserver-data:/var/opt/mssql
    networks:
      - app-network

  redis:
    image: redis:7-alpine
    volumes:
      - redis-data:/data
    networks:
      - app-network

volumes:
  sqlserver-data:
  redis-data:

networks:
  app-network:
```

**.env:**
```env
DB_PASSWORD=YourStrong!Password123
JWT_SECRET=your-super-secret-jwt-key-min-32-characters
WEATHER_API_KEY=your-weather-api-key
```

### Using Azure Key Vault

**Install package:**
```bash
dotnet add package Azure.Extensions.AspNetCore.Configuration.Secrets
dotnet add package Azure.Identity
```

**Program.cs:**
```csharp
var builder = WebApplication.CreateBuilder(args);

// Add Azure Key Vault
if (builder.Environment.IsProduction())
{
    var keyVaultEndpoint = builder.Configuration["KeyVaultEndpoint"];
    if (!string.IsNullOrEmpty(keyVaultEndpoint))
    {
        builder.Configuration.AddAzureKeyVault(
            new Uri(keyVaultEndpoint),
            new DefaultAzureCredential());
    }
}

var app = builder.Build();
```

**docker-compose.yml:**
```yaml
services:
  api:
    environment:
      - KeyVaultEndpoint=https://myvault.vault.azure.net/
      - AZURE_CLIENT_ID=${AZURE_CLIENT_ID}
      - AZURE_CLIENT_SECRET=${AZURE_CLIENT_SECRET}
      - AZURE_TENANT_ID=${AZURE_TENANT_ID}
```

### Configuration Validation

**Validate configuration on startup:**
```csharp
// AppSettings.cs
public class AppSettings
{
    [Required]
    [Range(1, 1000)]
    public int MaxItemsPerPage { get; set; }
    
    [Required]
    [Range(1, 1440)]
    public int CacheExpirationMinutes { get; set; }
}

// Program.cs
builder.Services.AddOptions<AppSettings>()
    .Bind(builder.Configuration.GetSection("AppSettings"))
    .ValidateDataAnnotations()
    .ValidateOnStart();
```

### Best Practices

**1. Never hardcode secrets:**
```csharp
// ❌ Bad
var apiKey = "hardcoded-api-key";

// ✅ Good
var apiKey = _configuration["ExternalApis:ApiKey"];
```

**2. Use Options Pattern:**
```csharp
// ✅ Good
builder.Services.Configure<DatabaseSettings>(
    builder.Configuration.GetSection("Database"));
```

**3. Validate configuration:**
```csharp
builder.Services.AddOptions<AppSettings>()
    .ValidateDataAnnotations()
    .ValidateOnStart();
```

**4. Use separate files for secrets:**
```yaml
# docker-compose.yml
env_file:
  - .env
  - .env.secrets  # Not in version control
```

**5. Read-only volume mounts:**
```yaml
volumes:
  - ./appsettings.Production.json:/app/appsettings.Production.json:ro
```

**6. Log configuration sources (not values!):**
```csharp
var logger = app.Services.GetRequiredService<ILogger<Program>>();
logger.LogInformation("Configuration loaded from: {Sources}", 
    string.Join(", ", builder.Configuration.Sources.Select(s => s.GetType().Name)));
```
