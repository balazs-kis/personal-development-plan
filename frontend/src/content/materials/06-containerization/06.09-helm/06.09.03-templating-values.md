# Lesson 3: Templating and Values

## Learning Objectives

By the end of this lesson, you will be able to:
- Use Go templating syntax in Helm charts
- Access and manipulate values in templates
- Use built-in objects (Release, Chart, Values)
- Implement flow control (if/else, range, with)
- Create and use named templates
- Apply template functions and pipelines

---

## Introduction

Helm templates use the Go template language to generate Kubernetes manifests dynamically. Templates access configuration values and use functions, pipelines, and flow control to create flexible, reusable charts. Understanding templating is essential for building powerful Helm charts that work across different environments.

## Key Concepts Summary

### Built-in Objects

**Release object:**
```yaml
# Release information
{{ .Release.Name }}       # Release name (e.g., "my-app")
{{ .Release.Namespace }}  # Namespace
{{ .Release.IsUpgrade }}  # true if upgrade
{{ .Release.IsInstall }}  # true if install
{{ .Release.Revision }}   # Revision number
{{ .Release.Service }}    # "Helm"
```

**Chart object:**
```yaml
# Chart metadata from Chart.yaml
{{ .Chart.Name }}         # Chart name
{{ .Chart.Version }}      # Chart version
{{ .Chart.AppVersion }}   # App version
{{ .Chart.Description }}  # Description
```

**Values object:**
```yaml
# From values.yaml or --set
{{ .Values.replicaCount }}
{{ .Values.image.repository }}
{{ .Values.service.type }}
```

**Files object:**
```yaml
# Access files in chart
{{ .Files.Get "config.ini" }}
{{ .Files.Glob "*.yaml" }}
```

**Capabilities object:**
```yaml
# Cluster information
{{ .Capabilities.KubeVersion }}
{{ .Capabilities.APIVersions }}
```

### Basic Template Syntax

**Variables:**
```yaml
# Simple substitution
name: {{ .Release.Name }}

# With default
tag: {{ .Values.image.tag | default .Chart.AppVersion }}

# Concatenation
name: {{ .Release.Name }}-{{ .Chart.Name }}
```

**Example deployment:**
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: {{ .Release.Name }}-{{ .Chart.Name }}
  namespace: {{ .Release.Namespace }}
  labels:
    app: {{ .Chart.Name }}
    version: {{ .Chart.AppVersion }}
spec:
  replicas: {{ .Values.replicaCount }}
  selector:
    matchLabels:
      app: {{ .Chart.Name }}
  template:
    metadata:
      labels:
        app: {{ .Chart.Name }}
    spec:
      containers:
      - name: {{ .Chart.Name }}
        image: "{{ .Values.image.repository }}:{{ .Values.image.tag }}"
        ports:
        - containerPort: {{ .Values.service.port }}
```

### Flow Control

**If/Else:**
```yaml
apiVersion: v1
kind: Service
metadata:
  name: {{ .Release.Name }}
spec:
  type: {{ .Values.service.type }}
  ports:
  - port: {{ .Values.service.port }}
  {{- if eq .Values.service.type "NodePort" }}
    nodePort: {{ .Values.service.nodePort }}
  {{- end }}
```

**If with else:**
```yaml
apiVersion: apps/v1
kind: Deployment
spec:
  replicas: {{ if .Values.production }}5{{ else }}1{{ end }}
```

**Checking for values:**
```yaml
{{- if .Values.ingress.enabled }}
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: {{ .Release.Name }}
spec:
  # ... ingress spec
{{- end }}
```

### Range (Loops)

**Loop over list:**
```yaml
# values.yaml
environments:
  - dev
  - staging
  - prod

# template
{{- range .Values.environments }}
- {{ . }}
{{- end }}

# Output:
# - dev
# - staging
# - prod
```

**Loop over map:**
```yaml
# values.yaml
labels:
  app: myapp
  tier: frontend
  env: production

# template
metadata:
  labels:
{{- range $key, $value := .Values.labels }}
    {{ $key }}: {{ $value }}
{{- end }}

# Output:
# labels:
#   app: myapp
#   tier: frontend
#   env: production
```

**Loop with index:**
```yaml
{{- range $index, $env := .Values.environments }}
{{ $index }}: {{ $env }}
{{- end }}
```

### With Scope

**Change scope:**
```yaml
# values.yaml
image:
  repository: nginx
  tag: alpine
  pullPolicy: IfNotPresent

# template (without with)
image: {{ .Values.image.repository }}:{{ .Values.image.tag }}
imagePullPolicy: {{ .Values.image.pullPolicy }}

# template (with with)
{{- with .Values.image }}
image: {{ .repository }}:{{ .tag }}
imagePullPolicy: {{ .pullPolicy }}
{{- end }}
```

**With and else:**
```yaml
{{- with .Values.nodeSelector }}
nodeSelector:
  {{- toYaml . | nindent 2 }}
{{- else }}
# No node selector specified
{{- end }}
```

### Variables

**Define variables:**
```yaml
{{- $relname := .Release.Name -}}
{{- $chartname := .Chart.Name -}}

name: {{ $relname }}-{{ $chartname }}
```

**Variables in range:**
```yaml
{{- range $key, $val := .Values.env }}
- name: {{ $key }}
  value: {{ $val | quote }}
{{- end }}
```

### Template Functions

**String functions:**
```yaml
# quote
env: {{ .Values.env | quote }}              # "production"

# upper/lower
name: {{ .Values.name | upper }}            # MYAPP
name: {{ .Values.name | lower }}            # myapp

# trimSuffix/trimPrefix
name: {{ .Values.name | trimSuffix "-app" }}

# trunc
name: {{ .Values.name | trunc 63 }}         # Max 63 chars

# replace
name: {{ .Values.name | replace "_" "-" }}
```

**Default values:**
```yaml
# Use default if not set
tag: {{ .Values.image.tag | default "latest" }}

# Multiple defaults
tag: {{ .Values.image.tag | default .Chart.AppVersion | default "latest" }}
```

**Type conversion:**
```yaml
# toString
port: {{ .Values.port | toString }}

# toJson
config: {{ .Values.config | toJson }}

# toYaml (most common)
resources:
  {{- toYaml .Values.resources | nindent 2 }}
```

**Logic functions:**
```yaml
# and
{{- if and .Values.enabled .Values.production }}
replicas: 5
{{- end }}

# or
{{- if or .Values.dev .Values.staging }}
replicas: 1
{{- end }}

# not
{{- if not .Values.disabled }}
enabled: true
{{- end }}

# eq (equal)
{{- if eq .Values.env "production" }}
```

### Whitespace Control

**Problem without control:**
```yaml
# Template
{{- if .Values.enabled }}
enabled: true
{{- end }}

# Bad output (extra blank line)

enabled: true

```

**Solution:**
```yaml
# Use {{- and -}}
{{- if .Values.enabled }}
enabled: true
{{- end }}

# {{- removes whitespace before
# -}} removes whitespace after
```

**Common pattern:**
```yaml
{{- if .Values.ingress.enabled -}}
apiVersion: networking.k8s.io/v1
kind: Ingress
{{- end }}
```

### Indentation (nindent)

**toYaml with proper indentation:**
```yaml
# values.yaml
resources:
  limits:
    cpu: 100m
    memory: 128Mi
  requests:
    cpu: 50m
    memory: 64Mi

# template
spec:
  containers:
  - name: app
    resources:
      {{- toYaml .Values.resources | nindent 6 }}

# Output:
spec:
  containers:
  - name: app
    resources:
      limits:
        cpu: 100m
        memory: 128Mi
      requests:
        cpu: 50m
        memory: 64Mi
```

### Named Templates

**Define in _helpers.tpl:**
```yaml
{{/*
Create chart name and version as used by the chart label.
*/}}
{{- define "mychart.chart" -}}
{{- printf "%s-%s" .Chart.Name .Chart.Version | replace "+" "_" | trunc 63 | trimSuffix "-" }}
{{- end }}

{{/*
Common labels
*/}}
{{- define "mychart.labels" -}}
helm.sh/chart: {{ include "mychart.chart" . }}
app.kubernetes.io/name: {{ include "mychart.name" . }}
app.kubernetes.io/instance: {{ .Release.Name }}
{{- if .Chart.AppVersion }}
app.kubernetes.io/version: {{ .Chart.AppVersion | quote }}
{{- end }}
app.kubernetes.io/managed-by: {{ .Release.Service }}
{{- end }}
```

**Use with include:**
```yaml
metadata:
  name: {{ include "mychart.fullname" . }}
  labels:
    {{- include "mychart.labels" . | nindent 4 }}
```

**Template vs include:**
```yaml
# template: Can't pipe output
{{ template "mychart.labels" . }}

# include: Can pipe to functions
{{ include "mychart.labels" . | nindent 4 }}
```

### Complete Example

**values.yaml:**
```yaml
replicaCount: 2

image:
  repository: nginx
  tag: "1.25-alpine"
  pullPolicy: IfNotPresent

service:
  type: ClusterIP
  port: 80

ingress:
  enabled: true
  className: nginx
  hosts:
    - host: app.example.com
      paths:
        - path: /
          pathType: Prefix

resources:
  limits:
    cpu: 200m
    memory: 256Mi
  requests:
    cpu: 100m
    memory: 128Mi

env:
  - name: ENVIRONMENT
    value: production
  - name: LOG_LEVEL
    value: info
```

**deployment.yaml:**
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: {{ include "mychart.fullname" . }}
  labels:
    {{- include "mychart.labels" . | nindent 4 }}
spec:
  replicas: {{ .Values.replicaCount }}
  selector:
    matchLabels:
      {{- include "mychart.selectorLabels" . | nindent 6 }}
  template:
    metadata:
      labels:
        {{- include "mychart.selectorLabels" . | nindent 8 }}
    spec:
      containers:
      - name: {{ .Chart.Name }}
        image: "{{ .Values.image.repository }}:{{ .Values.image.tag | default .Chart.AppVersion }}"
        imagePullPolicy: {{ .Values.image.pullPolicy }}
        ports:
        - name: http
          containerPort: 80
          protocol: TCP
        env:
        {{- range .Values.env }}
        - name: {{ .name }}
          value: {{ .value | quote }}
        {{- end }}
        resources:
          {{- toYaml .Values.resources | nindent 10 }}
```

**ingress.yaml:**
```yaml
{{- if .Values.ingress.enabled -}}
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: {{ include "mychart.fullname" . }}
  labels:
    {{- include "mychart.labels" . | nindent 4 }}
spec:
  {{- if .Values.ingress.className }}
  ingressClassName: {{ .Values.ingress.className }}
  {{- end }}
  rules:
  {{- range .Values.ingress.hosts }}
  - host: {{ .host | quote }}
    http:
      paths:
      {{- range .paths }}
      - path: {{ .path }}
        pathType: {{ .pathType }}
        backend:
          service:
            name: {{ include "mychart.fullname" $ }}
            port:
              number: {{ $.Values.service.port }}
      {{- end }}
  {{- end }}
{{- end }}
```

### Best Practices

**1. Quote strings:**
```yaml
# Good
env: {{ .Values.env | quote }}

# Risky (YAML type coercion)
env: {{ .Values.env }}
```

**2. Use default values:**
```yaml
tag: {{ .Values.image.tag | default .Chart.AppVersion }}
```

**3. Use toYaml for complex structures:**
```yaml
resources:
  {{- toYaml .Values.resources | nindent 2 }}
```

**4. Control whitespace:**
```yaml
{{- if .Values.enabled -}}
# content
{{- end }}
```

**5. Use named templates:**
```yaml
# Define once in _helpers.tpl
# Reuse everywhere
{{- include "mychart.labels" . | nindent 4 }}
```

### Advanced Template Functions

**String manipulation:**
```yaml
# repeat
separator: {{ "-" | repeat 20 }}  # --------------------

# trim/trimAll
name: {{ .Values.name | trim }}
name: {{ .Values.name | trimAll "-" }}

# nospace
name: {{ .Values.firstName }}{{ .Values.lastName | nospace }}

# randAlpha/randAlphaNum
password: {{ randAlphaNum 16 }}  # Generate random password

# sha256sum
checksum: {{ .Values.config | toJson | sha256sum }}
```

**List/Array functions:**
```yaml
# first/last
{{- $first := .Values.items | first }}
{{- $last := .Values.items | last }}

# append/prepend
{{- $list := list "a" "b" }}
{{- $list = append $list "c" }}  # [a, b, c]

# has
{{- if has "production" .Values.environments }}
Production environment enabled
{{- end }}

# uniq
{{- $unique := list "a" "b" "a" "c" | uniq }}  # [a, b, c]

# compact (remove empty values)
{{- $clean := list "a" "" "b" nil "c" | compact }}  # [a, b, c]
```

**Dictionary/Map functions:**
```yaml
# dict (create dictionary)
{{- $myDict := dict "key1" "value1" "key2" "value2" }}

# get/set
{{- $value := get $myDict "key1" }}
{{- $_ := set $myDict "key3" "value3" }}

# hasKey
{{- if hasKey $myDict "key1" }}
Key exists
{{- end }}

# keys/values
{{- range keys $myDict | sortAlpha }}
{{ . }}
{{- end }}

# merge
{{- $merged := merge $dict1 $dict2 }}
```

**Date functions:**
```yaml
# now
timestamp: {{ now | date "2006-01-02T15:04:05Z07:00" }}

# date formats
date: {{ now | date "2006-01-02" }}          # 2026-01-26
datetime: {{ now | date "2006-01-02 15:04" }} # 2026-01-26 10:30

# dateModify
future: {{ now | dateModify "24h" | date "2006-01-02" }}  # Tomorrow
```

**Encoding functions:**
```yaml
# b64enc/b64dec
encoded: {{ "hello" | b64enc }}    # aGVsbG8=
decoded: {{ "aGVsbG8=" | b64dec }} # hello

# toJson/fromJson
config: {{ .Values.config | toJson }}

# toYaml/fromYaml
config: |
  {{- .Values.config | toYaml | nindent 2 }}

# toToml
config: {{ .Values.config | toToml }}
```

**Type checking:**
```yaml
# kindIs
{{- if kindIs "string" .Values.port }}
Port is a string
{{- else if kindIs "int" .Values.port }}
Port is an integer
{{- end }}

# kindOf
type: {{ kindOf .Values.port }}  # "string" or "int" or "map", etc.

# typeIs
{{- if typeIs "int" .Values.port }}
Port is int
{{- end }}
```

**Cryptographic functions:**
```yaml
# sha256sum
hash: {{ "password" | sha256sum }}

# htpasswd (generate htpasswd entry)
auth: {{ htpasswd "username" "password" }}
```

**Flow control functions:**
```yaml
# coalesce (first non-empty value)
value: {{ coalesce .Values.override .Values.default "fallback" }}

# ternary (if-then-else as function)
replicas: {{ ternary 5 1 (eq .Values.env "production") }}
# If production: 5, else: 1

# fail
{{- if not .Values.required }}
  {{- fail "required value is missing!" }}
{{- end }}
```

### Complex Template Patterns

**Multi-container pod:**
```yaml
apiVersion: v1
kind: Pod
metadata:
  name: {{ include "mychart.fullname" . }}
spec:
  containers:
  - name: {{ .Chart.Name }}
    image: "{{ .Values.image.repository }}:{{ .Values.image.tag }}"
    env:
    {{- range $key, $value := .Values.env }}
    - name: {{ $key }}
      value: {{ $value | quote }}
    {{- end }}
  
  {{- if .Values.sidecar.enabled }}
  - name: {{ .Values.sidecar.name }}
    image: "{{ .Values.sidecar.image }}"
  {{- end }}
```

**Dynamic environment variables:**
```yaml
# values.yaml
env:
  APP_ENV: production
  LOG_LEVEL: info

# template
spec:
  containers:
  - name: app
    env:
    {{- range $key, $value := .Values.env }}
    - name: {{ $key }}
      value: {{ $value | quote }}
    {{- end }}
```

**Conditional service ports:**
```yaml
# values.yaml
service:
  ports:
    - name: http
      port: 80
      enabled: true
    - name: https
      port: 443
      enabled: false

# template
spec:
  ports:
  {{- range .Values.service.ports }}
  {{- if .enabled }}
  - name: {{ .name }}
    port: {{ .port }}
  {{- end }}
  {{- end }}
```

**ConfigMap from files pattern:**
```yaml
# templates/configmap.yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: {{ include "mychart.fullname" . }}-config
data:
  {{- range $path, $content := .Files.Glob "config/*.conf" }}
  {{ base $path }}: |
    {{- $.Files.Get $path | nindent 4 }}
  {{- end }}
```

### Template Debugging

**Debug helpers:**
```yaml
# _helpers.tpl
{{/*
Debug template
*/}}
{{- define "mychart.debug" -}}
{{- . | toYaml | printf "\nDEBUG:\n%s\n" }}
{{- end }}
```

**Fail fast on errors:**
```yaml
{{- if not .Values.required }}

{{- end }}
```

## Practice Exercise

After completing the materials (20 minutes max):

1. **Create chart:**
```bash
helm create myapp
cd myapp
```

2. **Add custom values:**
```yaml
# values.yaml
environment: production

database:
  host: postgres.default
  port: 5432
  name: myapp

features:
  caching: true
  logging: true
  metrics: false
```

3. **Create ConfigMap template:**
```yaml
# templates/configmap.yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: {{ include "myapp.fullname" . }}
data:
  environment: {{ .Values.environment | quote }}
  database-host: {{ .Values.database.host | quote }}
  database-port: {{ .Values.database.port | toString | quote }}
  {{- range $key, $value := .Values.features }}
  feature-{{ $key }}: {{ $value | toString | quote }}
  {{- end }}
```

4. **Test template:**
```bash
cd ..
helm template myapp/
```
