# Chapter 6.5: Kubernetes Architecture

## Overview
This chapter provides a deep dive into Kubernetes architecture, explaining how the control plane and worker nodes work together to orchestrate containerized applications. You'll learn about each component's role, how they communicate, and how Kubernetes maintains your desired cluster state through continuous reconciliation.

## Key Concepts
- **Control Plane Components:** API server, etcd, scheduler, controller manager, and their responsibilities.
- **Node Components:** Kubelet and kube-proxy managing container operations and networking.
- **Declarative vs Imperative Management:** different approaches to managing cluster resources.
- **The Reconciliation Loop:** how Kubernetes continuously ensures desired state matches actual state.
- **Kubernetes API and Resources:** understanding the API object model and resource types.
