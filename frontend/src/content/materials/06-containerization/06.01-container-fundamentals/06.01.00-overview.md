# Chapter 6.1: Container Fundamentals

## Overview
This chapter introduces containerization technology from the ground up. You'll learn what containers are, how they differ from virtual machines, and understand the core concepts that make containers the standard deployment unit for modern applications.

## Key Concepts
- **Containers vs Virtual Machines:** understanding the architectural differences and trade-offs.
- **Container Images and Layers:** how container images are structured and stored.
- **Container Registries:** centralized repositories for storing and distributing container images.
- **Container Runtimes:** the software that executes containers (containerd, Docker, CRI-O).
- **OCI Specifications:** industry standards that ensure container portability.
