## Introduction

Secrets are Kubernetes objects for storing sensitive information like passwords, OAuth tokens, SSH keys, and TLS certificates. While similar to ConfigMaps in usage, Secrets are designed for confidential data with additional security features like base64 encoding, encryption at rest, and access controls. Proper Secrets management is critical for application security.

## Key Concepts Summary

### What are Secrets?

```
ConfigMap vs Secret:
ConfigMap: Non-sensitive config
  - App settings
  - URLs
  - Feature flags

Secret: Sensitive data
  - Passwords
  - API keys
  - Certificates
  - Tokens
```

**Security features:**
- Base64 encoded (not encrypted by default!)
- Can enable encryption at rest
- RBAC access control
- Audit logging
- Mounted as tmpfs (RAM, not disk)

### Secret Types

**Opaque (default):**
```yaml
apiVersion: v1
kind: Secret
metadata:
  name: db-credentials
type: Opaque
data:
  username: YWRtaW4=      # base64("admin")
  password: cGFzc3dvcmQ=  # base64("password")
```

**kubernetes.io/dockerconfigjson:**
```yaml
apiVersion: v1
kind: Secret
metadata:
  name: docker-registry-secret
type: kubernetes.io/dockerconfigjson
data:
  .dockerconfigjson: <base64-encoded-docker-config>
```

**kubernetes.io/tls:**
```yaml
apiVersion: v1
kind: Secret
metadata:
  name: tls-secret
type: kubernetes.io/tls
data:
  tls.crt: <base64-encoded-cert>
  tls.key: <base64-encoded-key>
```

**kubernetes.io/basic-auth:**
```yaml
apiVersion: v1
kind: Secret
metadata:
  name: basic-auth
type: kubernetes.io/basic-auth
stringData:
  username: admin
  password: t0p-Secret123
```

**kubernetes.io/ssh-auth:**
```yaml
apiVersion: v1
kind: Secret
metadata:
  name: ssh-key
type: kubernetes.io/ssh-auth
data:
  ssh-privatekey: <base64-encoded-private-key>
```

### Creating Secrets

**From literal values:**
```bash
kubectl create secret generic db-secret \
  --from-literal=username=admin \
  --from-literal=password='MyP@ssw0rd!'
```

**From files:**
```bash
# Database credentials
echo -n 'admin' > username.txt
echo -n 'MyP@ssw0rd!' > password.txt

kubectl create secret generic db-secret \
  --from-file=username=username.txt \
  --from-file=password=password.txt

# Clean up files
rm username.txt password.txt
```

**From Docker config:**
```bash
kubectl create secret docker-registry docker-secret \
  --docker-server=docker.io \
  --docker-username=myuser \
  --docker-password=mypassword \
  --docker-email=me@example.com
```

**From TLS cert:**
```bash
kubectl create secret tls tls-secret \
  --cert=path/to/tls.crt \
  --key=path/to/tls.key
```

**From YAML (with stringData):**
```yaml
apiVersion: v1
kind: Secret
metadata:
  name: db-secret
type: Opaque
stringData:  # No base64 encoding needed!
  username: admin
  password: MyP@ssw0rd!
  connection-string: postgresql://admin:MyP@ssw0rd!@db:5432/myapp
```

**From YAML (with data):**
```yaml
apiVersion: v1
kind: Secret
metadata:
  name: db-secret
type: Opaque
data:
  username: YWRtaW4=                      # base64("admin")
  password: TXlQQHNzdzByZCE=              # base64("MyP@ssw0rd!")
```

**Encode/decode base64:**
```bash
# Encode
echo -n 'MyP@ssw0rd!' | base64
# TXlQQHNzdzByZCE=

# Decode
echo 'TXlQQHNzdzByZCE=' | base64 -d
# MyP@ssw0rd!
```

### Consuming as Environment Variables

**Single key:**
```yaml
apiVersion: v1
kind: Pod
metadata:
  name: app
spec:
  containers:
  - name: app
    image: myapp:latest
    env:
    - name: DB_USERNAME
      valueFrom:
        secretKeyRef:
          name: db-secret
          key: username
    - name: DB_PASSWORD
      valueFrom:
        secretKeyRef:
          name: db-secret
          key: password
```

**All keys:**
```yaml
apiVersion: v1
kind: Pod
metadata:
  name: app
spec:
  containers:
  - name: app
    image: myapp:latest
    envFrom:
    - secretRef:
        name: db-secret
```

**⚠️ Warning:** Environment variables can be exposed via:
- Pod describe/logs
- Container processes
- Application crashes/dumps

### Consuming as Volume Mounts (More Secure)

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: app
spec:
  containers:
  - name: app
    image: myapp:latest
    volumeMounts:
    - name: secret-volume
      mountPath: /etc/secrets
      readOnly: true
  volumes:
  - name: secret-volume
    secret:
      secretName: db-secret
      defaultMode: 0400  # Read-only
```

**Result:**
```bash
# Inside container
ls -la /etc/secrets/
# -r-------- 1 root root  5 Jan 26 09:00 username
# -r-------- 1 root root 11 Jan 26 09:00 password

cat /etc/secrets/username  # admin
cat /etc/secrets/password  # MyP@ssw0rd!
```

**Mount specific keys:**
```yaml
volumes:
- name: secret-volume
  secret:
    secretName: db-secret
    items:
    - key: username
      path: db-user
      mode: 0400
    - key: password
      path: db-pass
      mode: 0400
```

### Docker Registry Secrets

**Create:**
```bash
kubectl create secret docker-registry regcred \
  --docker-server=gcr.io \
  --docker-username=_json_key \
  --docker-password="$(cat key.json)" \
  --docker-email=me@example.com
```

**Use in pod:**
```yaml
apiVersion: v1
kind: Pod
metadata:
  name: private-app
spec:
  imagePullSecrets:
  - name: regcred
  containers:
  - name: app
    image: gcr.io/my-project/private-image:latest
```

### TLS Secrets for Ingress

**Create TLS secret:**
```bash
kubectl create secret tls tls-secret \
  --cert=tls.crt \
  --key=tls.key
```

**Use in Ingress:**
```yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: app-ingress
spec:
  tls:
  - hosts:
    - app.example.com
    secretName: tls-secret
  rules:
  - host: app.example.com
    http:
      paths:
      - path: /
        pathType: Prefix
        backend:
          service:
            name: app
            port:
              number: 80
```

### Encryption at Rest

**⚠️ By default, Secrets are stored unencrypted in etcd!**

**Enable encryption:**

1. Create encryption config:
```yaml
# encryption-config.yaml
apiVersion: apiserver.config.k8s.io/v1
kind: EncryptionConfiguration
resources:
- resources:
  - secrets
  providers:
  - aescbc:
      keys:
      - name: key1
        secret: <32-byte-base64-encoded-key>
  - identity: {}  # Fallback to unencrypted
```

2. Generate encryption key:
```bash
head -c 32 /dev/urandom | base64
```

3. Configure API server:
```bash
kube-apiserver \
  --encryption-provider-config=/etc/kubernetes/encryption-config.yaml \
  ...
```

4. Encrypt existing secrets:
```bash
kubectl get secrets --all-namespaces -o json | \
  kubectl replace -f -
```

### RBAC for Secrets

**Principle of least privilege:**
```yaml
apiVersion: rbac.authorization.k8s.io/v1
kind: Role
metadata:
  name: secret-reader
  namespace: production
rules:
- apiGroups: [""]
  resources: ["secrets"]
  resourceNames: ["db-secret"]  # Specific secret only
  verbs: ["get"]  # get only, not list/watch

---
apiVersion: rbac.authorization.k8s.io/v1
kind: RoleBinding
metadata:
  name: read-secrets
  namespace: production
subjects:
- kind: ServiceAccount
  name: app-sa
roleRef:
  kind: Role
  name: secret-reader
  apiGroup: rbac.authorization.k8s.io
```

### Immutable Secrets

```yaml
apiVersion: v1
kind: Secret
metadata:
  name: db-secret
type: Opaque
data:
  password: TXlQQHNzdzByZCE=
immutable: true
```

**Benefits:**
- Prevents accidental changes
- Improves performance (no watches)
- Forces explicit rotation

### Complete Deployment Example

```yaml
# secrets.yaml
apiVersion: v1
kind: Secret
metadata:
  name: db-credentials
type: Opaque
stringData:
  username: postgres
  password: MySecureP@ssw0rd
  database: myapp

---
apiVersion: v1
kind: Secret
metadata:
  name: api-keys
type: Opaque
stringData:
  stripe-key: sk_test_abc123
  sendgrid-key: SG.xyz789

---
# deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: api
spec:
  replicas: 3
  selector:
    matchLabels:
      app: api
  template:
    metadata:
      labels:
        app: api
    spec:
      containers:
      - name: api
        image: myapi:latest
        env:
        # Database credentials
        - name: DB_HOST
          value: postgres-service
        - name: DB_USER
          valueFrom:
            secretKeyRef:
              name: db-credentials
              key: username
        - name: DB_PASSWORD
          valueFrom:
            secretKeyRef:
              name: db-credentials
              key: password
        - name: DB_NAME
          valueFrom:
            secretKeyRef:
              name: db-credentials
              key: database
        # API keys from volume
        volumeMounts:
        - name: api-keys
          mountPath: /etc/api-keys
          readOnly: true
      volumes:
      - name: api-keys
        secret:
          secretName: api-keys
          defaultMode: 0400
```

### External Secrets Operator

**For production, use external secret managers:**

**Install External Secrets Operator:**
```bash
helm repo add external-secrets https://charts.external-secrets.io
helm install external-secrets \
  external-secrets/external-secrets \
  -n external-secrets-system \
  --create-namespace
```

**AWS Secrets Manager:**
```yaml
apiVersion: external-secrets.io/v1beta1
kind: SecretStore
metadata:
  name: aws-secrets-manager
spec:
  provider:
    aws:
      service: SecretsManager
      region: us-west-2
      auth:
        secretRef:
          accessKeyIDSecretRef:
            name: aws-credentials
            key: access-key-id
          secretAccessKeySecretRef:
            name: aws-credentials
            key: secret-access-key

---
apiVersion: external-secrets.io/v1beta1
kind: ExternalSecret
metadata:
  name: db-credentials
spec:
  refreshInterval: 1h
  secretStoreRef:
    name: aws-secrets-manager
    kind: SecretStore
  target:
    name: db-secret
    creationPolicy: Owner
  data:
  - secretKey: password
    remoteRef:
      key: prod/db/password
  - secretKey: username
    remoteRef:
      key: prod/db/username
```

**Azure Key Vault:**
```yaml
apiVersion: external-secrets.io/v1beta1
kind: SecretStore
metadata:
  name: azure-key-vault
spec:
  provider:
    azurekv:
      tenantId: "your-tenant-id"
      vaultUrl: "https://your-vault.vault.azure.net"
      authSecretRef:
        clientId:
          name: azure-credentials
          key: client-id
        clientSecret:
          name: azure-credentials
          key: client-secret

---
apiVersion: external-secrets.io/v1beta1
kind: ExternalSecret
metadata:
  name: api-keys
spec:
  refreshInterval: 5m
  secretStoreRef:
    name: azure-key-vault
  target:
    name: api-secret
  data:
  - secretKey: apiKey
    remoteRef:
      key: api-key
```

**HashiCorp Vault:**
```yaml
apiVersion: external-secrets.io/v1beta1
kind: SecretStore
metadata:
  name: vault-backend
spec:
  provider:
    vault:
      server: "https://vault.example.com"
      path: "secret"
      version: "v2"
      auth:
        kubernetes:
          mountPath: "kubernetes"
          role: "my-app"
          serviceAccountRef:
            name: vault-sa

---
apiVersion: external-secrets.io/v1beta1
kind: ExternalSecret
metadata:
  name: vault-secret
spec:
  refreshInterval: 15m
  secretStoreRef:
    name: vault-backend
  target:
    name: app-secret
  data:
  - secretKey: dbPassword
    remoteRef:
      key: database/prod
      property: password
```

### Secret Rotation

**Manual rotation:**
```bash
kubectl create secret generic db-secret-v2 \
  --from-literal=password=NewPassword123

kubectl patch deployment api \
  -p '{"spec":{"template":{"spec":{"containers":[{"name":"api","env":[{"name":"DB_PASSWORD","valueFrom":{"secretKeyRef":{"name":"db-secret-v2","key":"password"}}}]}]}}}}'
```

**Automated with External Secrets:**
```yaml
spec:
  refreshInterval: 1h  # Fetch new version hourly
```

### Secret Validation

**Password strength validation:**
```python
def validate_secret(secret):
    password = base64.b64decode(secret.data['password'])
    if len(password) < 12:
        return False, "Password too short"
    return True, "Valid"
```

### Sealed Secrets (GitOps)

**Install Sealed Secrets:**
```bash
kubectl apply -f https://github.com/bitnami-labs/sealed-secrets/releases/download/v0.24.0/controller.yaml
brew install kubeseal
```

**Create sealed secret:**
```bash
# Create regular secret
kubectl create secret generic db-secret \
  --from-literal=password=MyPassword \
  --dry-run=client -o yaml > secret.yaml

# Seal it
kubeseal -f secret.yaml -w sealed-secret.yaml

# Safe to commit
git add sealed-secret.yaml
```

**Deploy:**
```bash
kubectl apply -f sealed-secret.yaml
# Controller decrypts and creates Secret
```

### Best Practices

**1. Never commit secrets to Git:**
```bash
# .gitignore
secrets.yaml
*.key
*.crt
*-secret.yaml
```

**2. Use RBAC restrictively:**
```yaml
rules:
- apiGroups: [""]
  resources: ["secrets"]
  resourceNames: ["specific-secret"]  # Not wildcard
  verbs: ["get"]  # Not list/watch
```

**3. Enable encryption at rest:**
```yaml
providers:
- aescbc:
    keys:
    - name: key1
      secret: <32-byte-base64-key>
```

**4. Use volume mounts over env vars:**
```yaml
volumeMounts:
- name: secrets
  mountPath: /etc/secrets
  readOnly: true
```

**5. Rotate secrets regularly:**
```bash
# Automated rotation schedule
refreshInterval: 24h
```

**6. Use external secret managers:**
- AWS Secrets Manager
- Azure Key Vault
- HashiCorp Vault
- Google Secret Manager

**7. Audit secret access:**
```bash
# Enable audit logging
--audit-policy-file=/etc/kubernetes/audit-policy.yaml
```

**8. Use namespaces for isolation:**
```bash
kubectl create secret ... -n production
kubectl create secret ... -n development
```

**9. Implement least privilege:**
```yaml
# Service account with minimal permissions
serviceAccountName: app-sa
```

**10. Monitor secret changes:**
```bash
kubectl get events --field-selector involvedObject.kind=Secret
```

**11. Use immutable secrets:**
```yaml
immutable: true  # For production
```

**12. Validate secret format:**
```yaml
# Ensure base64 encoding
data:
  password: <valid-base64>
```

### Troubleshooting

**Secret not found:**
```bash
kubectl get secrets
kubectl describe secret db-secret
```

**Base64 encoding issues:**
```bash
# Must use -n to avoid newline
echo -n 'password' | base64
```

**Permission denied:**
```bash
# Check RBAC
kubectl auth can-i get secrets
kubectl describe rolebinding
```

**Pod can't access secret:**
```bash
# Check namespace
kubectl get secret db-secret -n <namespace>

# Check serviceAccount permissions
kubectl describe serviceaccount <sa-name>
```
