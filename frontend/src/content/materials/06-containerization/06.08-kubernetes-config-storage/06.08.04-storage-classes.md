# Lesson 4: StorageClasses and Dynamic Provisioning

## Learning Objectives

By the end of this lesson, you will be able to:
- Understand StorageClasses and dynamic provisioning
- Create and configure StorageClasses
- Use different provisioners (AWS EBS, Azure Disk, GCE PD, NFS)
- Configure volume binding modes and reclaim policies
- Set default StorageClasses

---

## Introduction

StorageClasses enable dynamic volume provisioning, eliminating the need for administrators to manually create PersistentVolumes. When a user creates a PVC requesting a StorageClass, Kubernetes automatically provisions the underlying storage from the cloud provider or storage system. This makes storage management scalable and self-service.

## Key Concepts Summary

### Static vs Dynamic Provisioning

**Static (manual):**
```
1. Admin creates PV manually
2. User creates PVC
3. PVC binds to existing PV
❌ Manual work for each volume
```

**Dynamic (automatic):**
```
1. Admin creates StorageClass once
2. User creates PVC with storageClassName
3. Kubernetes creates PV automatically
✅ Self-service, scalable
```

### StorageClass Structure

```yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: fast-ssd
provisioner: kubernetes.io/aws-ebs  # Volume plugin
parameters:                          # Provisioner-specific
  type: gp3
  iopsPerGB: "10"
  encrypted: "true"
reclaimPolicy: Delete               # Delete or Retain
allowVolumeExpansion: true          # Enable resizing
volumeBindingMode: WaitForFirstConsumer  # When to bind
mountOptions:                       # Mount options
  - debug
```

### Common Provisioners

**AWS EBS:**
```yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: aws-ebs-gp3
provisioner: kubernetes.io/aws-ebs
parameters:
  type: gp3              # gp2, gp3, io1, io2, st1, sc1
  iopsPerGB: "10"
  fsType: ext4
  encrypted: "true"
allowVolumeExpansion: true
reclaimPolicy: Delete
```

**Azure Disk:**
```yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: azure-disk-premium
provisioner: kubernetes.io/azure-disk
parameters:
  storageaccounttype: Premium_LRS  # Standard_LRS, Premium_LRS
  kind: Managed                    # Managed or Shared
allowVolumeExpansion: true
reclaimPolicy: Delete
```

**GCE Persistent Disk:**
```yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: gce-pd-ssd
provisioner: kubernetes.io/gce-pd
parameters:
  type: pd-ssd          # pd-standard or pd-ssd
  replication-type: regional-pd  # For HA
allowVolumeExpansion: true
reclaimPolicy: Delete
```

**NFS (using nfs-subdir-external-provisioner):**
```yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: nfs-client
provisioner: cluster.local/nfs-subdir-external-provisioner
parameters:
  archiveOnDelete: "false"
reclaimPolicy: Delete
allowVolumeExpansion: true
```

**Local Storage:**
```yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: local-storage
provisioner: kubernetes.io/no-provisioner
volumeBindingMode: WaitForFirstConsumer
```

### Volume Binding Mode

**Immediate (default):**
```yaml
volumeBindingMode: Immediate
```
- PV created immediately when PVC is created
- May cause pod scheduling issues if PV is in wrong zone

**WaitForFirstConsumer:**
```yaml
volumeBindingMode: WaitForFirstConsumer
```
- PV created when pod using PVC is scheduled
- Ensures PV is in correct zone/node
- **Recommended for topology-aware provisioning**

**Example:**
```yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: aws-ebs-delayed
provisioner: kubernetes.io/aws-ebs
parameters:
  type: gp3
volumeBindingMode: WaitForFirstConsumer  # Wait for pod
allowVolumeExpansion: true
```

### Using StorageClass

**Create PVC with storageClassName:**
```yaml
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: my-pvc
spec:
  accessModes:
  - ReadWriteOnce
  storageClassName: fast-ssd  # Reference StorageClass
  resources:
    requests:
      storage: 10Gi
```

**Result:**
```bash
kubectl apply -f pvc.yaml

# PV automatically created!
kubectl get pv
# NAME                  CAPACITY   STORAGECLASS
# pvc-abc123-def456     10Gi       fast-ssd

kubectl get pvc
# NAME     STATUS   VOLUME                CAPACITY   STORAGECLASS
# my-pvc   Bound    pvc-abc123-def456     10Gi       fast-ssd
```

### Default StorageClass

**Mark as default:**
```yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: standard
  annotations:
    storageclass.kubernetes.io/is-default-class: "true"
provisioner: kubernetes.io/aws-ebs
parameters:
  type: gp3
```

**PVC without storageClassName uses default:**
```yaml
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: my-pvc
spec:
  accessModes:
  - ReadWriteOnce
  resources:
    requests:
      storage: 10Gi
  # storageClassName not specified → uses default
```

**Check default:**
```bash
kubectl get storageclass
# NAME                 PROVISIONER             RECLAIMPOLICY   
# standard (default)   kubernetes.io/aws-ebs   Delete
# fast-ssd             kubernetes.io/aws-ebs   Delete
```

### Multiple StorageClasses

**Create tiers:**
```yaml
# Standard (default, cheap)
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: standard
  annotations:
    storageclass.kubernetes.io/is-default-class: "true"
provisioner: kubernetes.io/aws-ebs
parameters:
  type: gp3
reclaimPolicy: Delete

---
# Fast SSD (expensive)
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: fast
provisioner: kubernetes.io/aws-ebs
parameters:
  type: io2
  iopsPerGB: "100"
reclaimPolicy: Delete
allowVolumeExpansion: true

---
# Retain (production data)
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: retain
provisioner: kubernetes.io/aws-ebs
parameters:
  type: gp3
reclaimPolicy: Retain  # Don't delete on PVC deletion
allowVolumeExpansion: true
```

**Use different tiers:**
```yaml
# Development
spec:
  storageClassName: standard
  resources:
    requests:
      storage: 10Gi

# Production database
spec:
  storageClassName: fast
  resources:
    requests:
      storage: 100Gi

# Critical data
spec:
  storageClassName: retain
  resources:
    requests:
      storage: 500Gi
```

### Volume Expansion

**Enable in StorageClass:**
```yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: expandable
provisioner: kubernetes.io/aws-ebs
parameters:
  type: gp3
allowVolumeExpansion: true  # Enable expansion
```

**Expand PVC:**
```yaml
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: my-pvc
spec:
  accessModes:
  - ReadWriteOnce
  storageClassName: expandable
  resources:
    requests:
      storage: 20Gi  # Increased from 10Gi
```

**Apply:**
```bash
kubectl apply -f pvc.yaml

# Check status
kubectl get pvc my-pvc
# May show FileSystemResizePending

# Restart pod to complete
kubectl rollout restart deployment myapp
```

### Complete Application Example

```yaml
# storage-classes.yaml
apiVersion: storage.k8s.io/v1

  name: postgres-pvc

  accessModes:
  - ReadWriteOnce
  storageClassName: fast
  resources:
    requests:
      storage: 50Gi

apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: postgres
spec:
  serviceName: postgres
  replicas: 1
  selector:
    matchLabels:
      app: postgres
  template:
    metadata:
      labels:
        app: postgres
    spec:
      containers:
      - name: postgres
        image: postgres:15-alpine
        ports:
        - containerPort: 5432
        env:
        - name: POSTGRES_PASSWORD
          valueFrom:
            secretKeyRef:
              name: postgres-secret

          value: /var/lib/postgresql/data/pgdata
        volumeMounts:
        - name: data
          mountPath: /var/lib/postgresql/data

  - metadata:
      name: data

      - ReadWriteOnce

      resources:
```

### Volume Topology

**Topology-aware provisioning:**
```yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: topology-aware
provisioner: ebs.csi.aws.com
volumeBindingMode: WaitForFirstConsumer
allowedTopologies:
- matchLabelExpressions:
  - key: topology.kubernetes.io/zone
    values:
    - us-west-2a
    - us-west-2b
```

**Benefits:**
- Ensures volume in same zone as pod
- Avoids cross-zone data transfer costs
- Better performance

### Storage Capacity Tracking

**Enable capacity tracking:**
```yaml
apiVersion: storage.k8s.io/v1
kind: CSIDriver
metadata:
  name: ebs.csi.aws.com
spec:
  storageCapacity: true
```

**CSIStorageCapacity objects:**
```bash
kubectl get csistoragecapacities
```

**Benefits:**
- Scheduler aware of available storage
- Better pod placement decisions
- Prevents binding failures

### Volume Snapshots with StorageClass

**Snapshot class:**
```yaml
apiVersion: snapshot.storage.k8s.io/v1
kind: VolumeSnapshotClass
metadata:
  name: csi-snapclass
driver: ebs.csi.aws.com
deletionPolicy: Delete
parameters:
  tagSpecification_1: "Name=snapshot,Environment=production"
```

**Create snapshot:**
```yaml
apiVersion: snapshot.storage.k8s.io/v1
kind: VolumeSnapshot
metadata:
  name: db-snapshot
spec:
  volumeSnapshotClassName: csi-snapclass
  source:
    persistentVolumeClaimName: db-pvc
```

**Restore from snapshot:**
```yaml
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: db-restored
spec:
  dataSource:
    name: db-snapshot
    kind: VolumeSnapshot
    apiGroup: snapshot.storage.k8s.io
  accessModes:
  - ReadWriteOnce
  storageClassName: fast
  resources:
    requests:
      storage: 50Gi
```

### Best Practices

**1. Use CSI drivers (modern):**
```yaml
# New
provisioner: ebs.csi.aws.com

# Old (deprecated)
provisioner: kubernetes.io/aws-ebs
```

**2. Use WaitForFirstConsumer:**
```yaml
volumeBindingMode: WaitForFirstConsumer
```

**3. Enable volume expansion:**
```yaml
allowVolumeExpansion: true
```

**4. Set appropriate reclaim policy:**
```yaml
# Production
reclaimPolicy: Retain

# Dev/Test
reclaimPolicy: Delete
```

**5. Create multiple tiers:**
```yaml
- standard (default, cheap)
- fast (SSD, expensive)
- retain (critical data)
```

**6. Use meaningful names:**
```yaml
metadata:
  name: aws-gp3-fast  # Good
  # Not: sc1
```

**7. Add labels and annotations:**
```yaml
metadata:
  labels:
    tier: standard
    provider: aws
  annotations:
    description: "Fast SSD storage for databases"
    cost-center: "platform"
```

**8. Document parameters:**
```yaml
metadata:
  annotations:
    parameters: "type=gp3, iops=3000, encrypted=true"
    use-case: "Production databases requiring high IOPS"
```

**9. Set resource quotas:**
```yaml
# Prevent unlimited storage consumption
spec:
  hard:
    requests.storage: "1Ti"
```

**10. Monitor costs:**
```bash
# Tag resources for cost tracking
parameters:
  tagSpecification_1: "Environment=production"
  tagSpecification_2: "Team=platform"
```
