# Chapter 2.3: Clean Architecture

## Overview
Understand the principles of Clean Architecture (also known as Onion Architecture or Hexagonal Architecture), focusing on dependency rules, layer separation, and keeping business logic independent of frameworks. Learn how to create systems where the core business logic is testable and independent of external concerns.

## Key Concepts
- **Dependency Rule:** dependencies point inward toward business logic.
- **Layers:** understanding Entities, Use Cases, Interface Adapters, and Frameworks.
- **Ports and Adapters:** implementing the hexagonal architecture pattern.
- **Framework Independence:** keeping business logic free from framework coupling.
- **Testability:** achieving high testability through architectural design.
