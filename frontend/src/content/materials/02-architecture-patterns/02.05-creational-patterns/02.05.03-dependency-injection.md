# Lesson 3: Dependency Injection as a Pattern

## Learning Objectives
- Understand DI as a creational pattern
- Configure service lifetimes properly
- Avoid DI anti-patterns
- Use Options pattern for configuration

## Introduction

Dependency Injection is a creational pattern where objects receive their dependencies from external sources rather than creating them internally. In .NET, DI is a first-class citizen and the primary way to manage object creation and lifecycle.

## Key Concepts Summary

### The Dependency Injection Pattern

**Problem: Tight Coupling**
```csharp
// BAD - Tightly coupled to concrete implementation
public class OrderService
{
    private readonly EmailSender _emailSender;
    private readonly SqlServerRepository _repository;
    
    public OrderService()
    {
        _emailSender = new EmailSender();  // Hard dependency
        _repository = new SqlServerRepository();  // Hard dependency
    }
    
    // Hard to test, hard to change implementations
}
```

**Solution: Dependency Injection**
```csharp
// GOOD - Dependencies injected through constructor
public class OrderService
{
    private readonly IEmailSender _emailSender;
    private readonly IOrderRepository _repository;
    
    public OrderService(IEmailSender emailSender, IOrderRepository repository)
    {
        _emailSender = emailSender;
        _repository = repository;
    }
    
    // Easy to test with mocks, easy to swap implementations
}
```

### Service Lifetimes

```csharp
// Transient - New instance every time
services.AddTransient<IEmailSender, EmailSender>();
// Use for: Lightweight, stateless services
// Example: Validators, formatters, calculators

// Scoped - One instance per request/scope
services.AddScoped<IOrderService, OrderService>();
services.AddScoped<ApplicationDbContext>();
// Use for: Database contexts, request-specific data, unit of work
// Example: DbContext, request handlers, user context

// Singleton - One instance for application lifetime
services.AddSingleton<IMemoryCache, MemoryCache>();
services.AddSingleton<IConfiguration>(configuration);
// Use for: Caching, configuration, thread-safe services
// Example: Configuration, caches, metrics collectors
```

### Lifetime Pitfalls

```csharp
// DANGER: Captive Dependency
// Singleton capturing a Scoped service
public class SingletonService  // Registered as Singleton
{
    private readonly ApplicationDbContext _context;  // Scoped!
    
    // BAD - DbContext will be held for app lifetime
    public SingletonService(ApplicationDbContext context)
    {
        _context = context;  // This context instance never gets disposed!
    }
}

// Solution 1: Use IServiceScopeFactory
public class SingletonService
{
    private readonly IServiceScopeFactory _scopeFactory;
    
    public SingletonService(IServiceScopeFactory scopeFactory)
    {
        _scopeFactory = scopeFactory;
    }
    
    public async Task DoWork()
    {
        using var scope = _scopeFactory.CreateScope();
        var context = scope.ServiceProvider.GetRequiredService<ApplicationDbContext>();
        // Use context...
    }
}

// Solution 2: Change the singleton to scoped if possible
services.AddScoped<PreviouslySingletonService>();
```

### Constructor Injection (Primary Method)

```csharp
public class UserController : ControllerBase
{
    private readonly IUserService _userService;
    private readonly ILogger<UserController> _logger;
    private readonly IMapper _mapper;
```

### Options Pattern

```csharp
// appsettings.json
{
  "Email": {
    "SmtpServer": "smtp.example.com",
    "Port": 587,
    "Username": "user@example.com",
    "EnableSsl": true,
    "FromAddress": "noreply@example.com"
  }
}

// Configuration class
public class EmailSettings
{
    public const string SectionName = "Email";
    
    public string SmtpServer { get; set; }
    public int Port { get; set; }
    public string Username { get; set; }
    public string Password { get; set; }
    public bool EnableSsl { get; set; }
    public string FromAddress { get; set; }
}

// Register with validation
services.AddOptions<EmailSettings>()
    .Bind(configuration.GetSection(EmailSettings.SectionName))
    .ValidateDataAnnotations()
    .ValidateOnStart();

// Consume with IOptions<T>
public class EmailService : IEmailService
{
    private readonly EmailSettings _settings;
    private readonly ILogger<EmailService> _logger;
    
    public EmailService(
        IOptions<EmailSettings> options,
        ILogger<EmailService> logger)
    {
        _settings = options.Value;
        _logger = logger;
    }
    
    public async Task SendEmail(string to, string subject, string body)
    {
        using var client = new SmtpClient(_settings.SmtpServer, _settings.Port);
        client.EnableSsl = _settings.EnableSsl;
        client.Credentials = new NetworkCredential(_settings.Username, _settings.Password);
        
        var message = new MailMessage(_settings.FromAddress, to, subject, body);
        await client.SendMailAsync(message);
        
        _logger.LogInformation("Email sent to {To}", to);
    }
}
```

### IOptions vs IOptionsSnapshot vs IOptionsMonitor

```csharp
// IOptions<T> - Singleton, value never changes
public class Service1
{
    private readonly EmailSettings _settings;
    
    public Service1(IOptions<EmailSettings> options)
    {
        _settings = options.Value;  // Captured once
    }
}

// IOptionsSnapshot<T> - Scoped, reloaded per request
public class Service2
{
    private readonly IOptionsSnapshot<EmailSettings> _options;
    
    public Service2(IOptionsSnapshot<EmailSettings> options)
    {
        _options = options;
    }
    
    public void DoWork()
    {
        var settings = _options.Value;  // Fresh value per request
    }
}

// IOptionsMonitor<T> - Singleton, but monitors changes
public class Service3
{
    private readonly IOptionsMonitor<EmailSettings> _options;
    
    public Service3(IOptionsMonitor<EmailSettings> options)
    {
        _options = options;
        
        // React to configuration changes
        _options.OnChange(settings =>
        {
            Console.WriteLine("Configuration changed!");
        });
    }
    
    public void DoWork()
    {
        var settings = _options.CurrentValue;  // Always current
    }
}
```

### Factory Pattern with DI

```csharp
// Factory registered in DI
public interface INotificationFactory
{
    INotificationSender CreateSender(NotificationType type);
}

public class NotificationFactory : INotificationFactory
{
    private readonly IServiceProvider _serviceProvider;
    
    public NotificationFactory(IServiceProvider serviceProvider)
    {
        _serviceProvider = serviceProvider;
    }
    
    public INotificationSender CreateSender(NotificationType type)
    {
        return type switch
        {
            NotificationType.Email => _serviceProvider.GetRequiredService<EmailNotificationSender>(),
            NotificationType.Sms => _serviceProvider.GetRequiredService<SmsNotificationSender>(),
            NotificationType.Push => _serviceProvider.GetRequiredService<PushNotificationSender>(),
            _ => throw new ArgumentException($"Unknown notification type: {type}")
        };
    }
}

// Registration
services.AddTransient<EmailNotificationSender>();
services.AddTransient<SmsNotificationSender>();
services.AddTransient<PushNotificationSender>();
services.AddSingleton<INotificationFactory, NotificationFactory>();
```

### Generic Service Registration

```csharp
public interface IRepository<T> where T : class
```

### Keyed Services (.NET 8+)

```csharp
// Register services with keys
services.AddKeyedSingleton<ICache, RedisCache>("redis");
services.AddKeyedSingleton<ICache, MemoryCache>("memory");

// Inject using keys
public class CacheManager
{
    private readonly ICache _redisCache;
    private readonly ICache _memoryCache;
    
    public CacheManager(
        [FromKeyedServices("redis")] ICache redisCache,
        [FromKeyedServices("memory")] ICache memoryCache)
    {
        _redisCache = redisCache;
        _memoryCache = memoryCache;
    }
    
    public async Task<T> GetOrCreateAsync<T>(string key, Func<Task<T>> factory)
    {
        // Try memory cache first
        if (await _memoryCache.TryGetAsync<T>(key, out var value))
            return value;
        
        // Try redis
        if (await _redisCache.TryGetAsync<T>(key, out value))
        {
            await _memoryCache.SetAsync(key, value);
            return value;
        }
        
        // Create and cache
        value = await factory();
        await _memoryCache.SetAsync(key, value);
        await _redisCache.SetAsync(key, value);
        return value;
    }
}
```

### Decorator Pattern with DI

```csharp
// Base service
public interface IOrderService
{
    Task<Order> CreateOrderAsync(CreateOrderRequest request);
}

public class OrderService : IOrderService
{
    private readonly IOrderRepository _repository;
    
    public OrderService(IOrderRepository repository)
    {
        _repository = repository;
    }
    
    public async Task<Order> CreateOrderAsync(CreateOrderRequest request)
    {
        var order = new Order(request);
        await _repository.AddAsync(order);
        return order;
    }
}

// Logging decorator
public class LoggingOrderService : IOrderService
{
    private readonly IOrderService _inner;
    private readonly ILogger<LoggingOrderService> _logger;
    
    public LoggingOrderService(
        IOrderService inner,
        ILogger<LoggingOrderService> logger)
    {
        _inner = inner;
        _logger = logger;
    }
    
    public async Task<Order> CreateOrderAsync(CreateOrderRequest request)
    {
        _logger.LogInformation("Creating order for user {UserId}", request.UserId);
        var order = await _inner.CreateOrderAsync(request);
        _logger.LogInformation("Order {OrderId} created", order.Id);
        return order;
    }
}

// Caching decorator
public class CachingOrderService : IOrderService
{
    private readonly IOrderService _inner;
    private readonly IMemoryCache _cache;
    
    public CachingOrderService(IOrderService inner, IMemoryCache cache)
    {
        _inner = inner;
        _cache = cache;
    }
    
    public async Task<Order> CreateOrderAsync(CreateOrderRequest request)
    {
        var cacheKey = $"order_{request.UserId}";
        if (_cache.TryGetValue<Order>(cacheKey, out var cached))
            return cached;
        
        var order = await _inner.CreateOrderAsync(request);
        _cache.Set(cacheKey, order, TimeSpan.FromMinutes(5));
        return order;
    }
}

// Register with decorators (using Scrutor or manual)
services.AddScoped<OrderService>();
services.Decorate<IOrderService, LoggingOrderService>();
services.Decorate<IOrderService, CachingOrderService>();

// Or manual registration
services.AddScoped<IOrderService>(provider =>
{
    var repository = provider.GetRequiredService<IOrderRepository>();
    var logger = provider.GetRequiredService<ILogger<LoggingOrderService>>();
    var cache = provider.GetRequiredService<IMemoryCache>();
    
    IOrderService service = new OrderService(repository);
    service = new LoggingOrderService(service, logger);
    service = new CachingOrderService(service, cache);
    return service;
});
```

### Service Resolution

```csharp
// Resolving services manually
public class SomeService
{
    private readonly IServiceProvider _serviceProvider;
    
    public SomeService(IServiceProvider serviceProvider)
    {
        _serviceProvider = serviceProvider;
    }
    
    public void DoWork()
    {
        // Get required service (throws if not found)
        var service1 = _serviceProvider.GetRequiredService<IMyService>();
        
        // Get optional service (returns null if not found)
        var service2 = _serviceProvider.GetService<IOptionalService>();
        
        // Get multiple implementations
        var services = _serviceProvider.GetServices<INotificationSender>();
        
        // Get with key (.NET 8+)
        var keyedService = _serviceProvider.GetRequiredKeyedService<ICache>("redis");
    }
}
```

### Common DI Anti-Patterns

1. **Service Locator Anti-Pattern**
```csharp
// BAD - Using IServiceProvider everywhere
public class MyService
{
    private readonly IServiceProvider _provider;
    
    public MyService(IServiceProvider provider)
    {
        _provider = provider;
    }
    
    public void DoWork()
    {
        var service = _provider.GetRequiredService<ISomeService>();
        // Hides dependencies!
    }
}

// GOOD - Explicit dependencies
public class MyService
{
    private readonly ISomeService _someService;
    
    public MyService(ISomeService someService)
    {
        _someService = someService;
    }
}
```

2. **Over-Injection**
```csharp
// BAD - Too many dependencies
public class GodService
{
    public GodService(
        IDep1 d1, IDep2 d2, IDep3 d3, IDep4 d4,
        IDep5 d5, IDep6 d6, IDep7 d7, IDep8 d8)
    {
        // This class is doing too much!
    }
}

// GOOD - Split responsibilities
public class FocusedService
{
    public FocusedService(IDep1 d1, IDep2 d2)
    {
        // Single responsibility
    }
}
```

## Practice Exercise

Create a notification system with DI (15 min):

**Requirements:**
1. Create `INotificationSender` interface with `SendAsync(string recipient, string message)` method
2. Implement three concrete senders:
   - `EmailNotificationSender` (uses `IOptions<EmailSettings>`)
   - `SmsNotificationSender` (uses `IOptions<SmsSettings>`)
   - `PushNotificationSender`
3. Create `NotificationService` that coordinates multiple senders
4. Register services with appropriate lifetimes
5. Use Options pattern for configuration
6. Inject dependencies into a controller or API endpoint

**Solution Structure:**

```csharp
// 1. Configuration
public class EmailSettings
{
    public string SmtpServer { get; set; }
    public int Port { get; set; }
    public string FromAddress { get; set; }
}

public class SmsSettings
{
    public string ApiKey { get; set; }
    public string FromNumber { get; set; }
}

// 2. Interfaces
public interface INotificationSender
{
    Task SendAsync(string recipient, string message);
}

// 3. Implementations
public class EmailNotificationSender : INotificationSender
{
    private readonly EmailSettings _settings;
    private readonly ILogger<EmailNotificationSender> _logger;
    
    public EmailNotificationSender(
        IOptions<EmailSettings> settings,
        ILogger<EmailNotificationSender> logger)
    {
        _settings = settings.Value;
        _logger = logger;
    }
    
    public async Task SendAsync(string recipient, string message)
    {
        _logger.LogInformation("Sending email to {Recipient} via {Server}", 
            recipient, _settings.SmtpServer);
        // Email sending logic...
        await Task.CompletedTask;
    }
}

public class SmsNotificationSender : INotificationSender
{
    private readonly SmsSettings _settings;
    private readonly ILogger<SmsNotificationSender> _logger;
    
    public SmsNotificationSender(
        IOptions<SmsSettings> settings,
        ILogger<SmsNotificationSender> logger)
    {
        _settings = settings.Value;
        _logger = logger;
    }
    
    public async Task SendAsync(string recipient, string message)
    {
        _logger.LogInformation("Sending SMS to {Recipient}", recipient);
        // SMS sending logic...
        await Task.CompletedTask;
    }
}

public class PushNotificationSender : INotificationSender
{
    private readonly ILogger<PushNotificationSender> _logger;
    
    public PushNotificationSender(ILogger<PushNotificationSender> logger)
    {
        _logger = logger;
    }
    
    public async Task SendAsync(string recipient, string message)
    {
        _logger.LogInformation("Sending push notification to {Recipient}", recipient);
        // Push notification logic...
        await Task.CompletedTask;
    }
}

// 4. Coordinating service
public interface INotificationService
{
    Task SendNotificationAsync(string recipient, string message, NotificationType type);
    Task BroadcastAsync(string message);
}

public class NotificationService : INotificationService
{
    private readonly IEnumerable<INotificationSender> _senders;
    private readonly Dictionary<NotificationType, INotificationSender> _senderMap;
    
    public NotificationService(IEnumerable<INotificationSender> senders)
    {
        _senders = senders;
        _senderMap = new Dictionary<NotificationType, INotificationSender>
        {
            [NotificationType.Email] = senders.OfType<EmailNotificationSender>().First(),
            [NotificationType.Sms] = senders.OfType<SmsNotificationSender>().First(),
            [NotificationType.Push] = senders.OfType<PushNotificationSender>().First()
        };
    }
    
    public async Task SendNotificationAsync(string recipient, string message, NotificationType type)
    {
        var sender = _senderMap[type];
        await sender.SendAsync(recipient, message);
    }
    
    public async Task BroadcastAsync(string message)
    {
        var tasks = _senders.Select(sender => sender.SendAsync("all", message));
        await Task.WhenAll(tasks);
    }
}

// 5. Registration (in Program.cs or Startup.cs)
var builder = WebApplication.CreateBuilder(args);

// Configure options
builder.Services.Configure<EmailSettings>(
    builder.Configuration.GetSection("Email"));
builder.Services.Configure<SmsSettings>(
    builder.Configuration.GetSection("Sms"));

// Register senders
builder.Services.AddTransient<INotificationSender, EmailNotificationSender>();
builder.Services.AddTransient<INotificationSender, SmsNotificationSender>();
builder.Services.AddTransient<INotificationSender, PushNotificationSender>();

// Register coordinating service
builder.Services.AddScoped<INotificationService, NotificationService>();

// 6. Use in controller
[ApiController]
[Route("api/[controller]")]
public class NotificationsController : ControllerBase
{
    private readonly INotificationService _notificationService;
    
    public NotificationsController(INotificationService notificationService)
    {
        _notificationService = notificationService;
    }
    
    [HttpPost("send")]
    public async Task<IActionResult> SendNotification(
        [FromBody] NotificationRequest request)
    {
        await _notificationService.SendNotificationAsync(
            request.Recipient,
            request.Message,
            request.Type);
        
        return Ok("Notification sent");
    }
    
    [HttpPost("broadcast")]
    public async Task<IActionResult> Broadcast([FromBody] BroadcastRequest request)
    {
        await _notificationService.BroadcastAsync(request.Message);
        return Ok("Broadcast sent");
    }
}
```

## Self-Check Questions

1. **What are the three service lifetimes in .NET DI?**
   - Transient: New instance every request
   - Scoped: One instance per scope (HTTP request)
   - Singleton: One instance for app lifetime

2. **When should you use IOptions vs IOptionsSnapshot vs IOptionsMonitor?**
   - IOptions: Singleton, value never reloads
   - IOptionsSnapshot: Scoped, reloads per request
   - IOptionsMonitor: Singleton, but watches for changes

3. **What is the captive dependency problem?**
   - When a longer-lived service (Singleton) holds a shorter-lived service (Scoped/Transient)
   - Can cause memory leaks and stale data

4. **Why is constructor injection preferred over property injection?**
   - Makes dependencies explicit and required
   - Enables compile-time checking
   - Supports immutability

5. **What's wrong with injecting IServiceProvider everywhere?**
   - Service Locator anti-pattern
   - Hides dependencies
   - Makes testing harder
   - Runtime errors instead of compile-time

6. **How do you register multiple implementations of the same interface?**
   ```csharp
   services.AddTransient<INotificationSender, EmailSender>();
   services.AddTransient<INotificationSender, SmsSender>();
   
   // Inject as IEnumerable
   public MyService(IEnumerable<INotificationSender> senders) { }
   ```
