# Chapter 2.6: Structural Design Patterns

## Overview
Explore patterns that compose objects into larger structures: Adapter, Bridge, Composite, Decorator, Facade, Flyweight, and Proxy, with practical .NET examples. These patterns help organize code into composable, flexible structures, especially useful for integrating with external systems and creating layered abstractions.

## Key Concepts
- **Adapter Pattern:** integrating with incompatible interfaces.
- **Decorator Pattern:** adding cross-cutting concerns dynamically.
- **Facade Pattern:** simplifying complex subsystems.
- **Proxy Pattern:** controlling access and lazy loading.
- **Composite Pattern:** working with tree structures uniformly.
