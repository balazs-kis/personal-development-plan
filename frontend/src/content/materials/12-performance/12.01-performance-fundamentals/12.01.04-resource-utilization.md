## Introduction

Performance problems often stem from resource exhaustion: CPU saturation, memory pressure, disk I/O bottlenecks, or network constraints. Understanding how to monitor resource utilization helps you identify bottlenecks before they cause outages and optimize resource allocation for better performance and cost efficiency.

## Key Concepts Summary

### The Four Pillars of Resource Monitoring

**1. CPU Utilization**
- Percentage of CPU time spent on work vs idle
- User time (application code) vs system time (kernel operations)
- CPU throttling and saturation

**2. Memory Usage**
- Working set (RAM actively used)
- Private bytes (memory exclusive to process)
- GC heap size and collections
- Memory leaks and pressure

**3. Disk I/O**
- Read/write operations per second (IOPS)
- Throughput (MB/s)
- Latency per operation
- Queue depth

**4. Network I/O**
- Bytes sent/received
- Active connections
- Connection pool utilization
- Bandwidth saturation

## Monitoring CPU Usage

### Understanding CPU Metrics

**CPU Time vs Wall Clock Time:**
```csharp
var stopwatch = Stopwatch.StartNew();
var cpuBefore = Process.GetCurrentProcess().TotalProcessorTime;

// Do some work
await ProcessRequestAsync();

stopwatch.Stop();
var cpuAfter = Process.GetCurrentProcess().TotalProcessorTime;

var wallClockTime = stopwatch.Elapsed;
var cpuTime = cpuAfter - cpuBefore;

Console.WriteLine($"Wall clock: {wallClockTime.TotalMilliseconds}ms");
Console.WriteLine($"CPU time: {cpuTime.TotalMilliseconds}ms");

// If CPU time << wall clock time: Waiting on I/O
// If CPU time ≈ wall clock time: CPU-bound operation
```

### CPU Utilization Monitoring

```csharp
using System.Diagnostics;
using System.Diagnostics.Metrics;

public class CpuMonitor
{
    private readonly Meter _meter;
    private readonly ObservableGauge<double> _cpuUsage;
    private readonly Process _process;

    public CpuMonitor(IMeterFactory meterFactory)
    {
        _meter = meterFactory.Create("MyApp.Resources");
        _process = Process.GetCurrentProcess();
        
        _cpuUsage = _meter.CreateObservableGauge<double>(
            "process.cpu.utilization",
            () => GetCpuUsagePercentage(),
            unit: "%",
            description: "CPU utilization percentage");
    }

    private double GetCpuUsagePercentage()
    {
        var startTime = DateTime.UtcNow;
        var startCpuUsage = _process.TotalProcessorTime;
        
        Thread.Sleep(100); // Sample period
        
        var endTime = DateTime.UtcNow;
        var endCpuUsage = _process.TotalProcessorTime;
        
        var cpuUsedMs = (endCpuUsage - startCpuUsage).TotalMilliseconds;
        var totalMsPassed = (endTime - startTime).TotalMilliseconds;
        var cpuUsageTotal = cpuUsedMs / (Environment.ProcessorCount * totalMsPassed);
        
        return cpuUsageTotal * 100;
    }
}
```

### Identifying CPU Bottlenecks

**Symptoms:**
```
- High CPU utilization (>80% sustained)
- Request queuing and increased latency
- Thread pool starvation
- Application unresponsiveness
```

**Common causes in .NET:**
```csharp
// 1. Synchronous blocking on thread pool
Task.Run(() => SomeWork()).Wait();  // ❌ Blocks thread

// 2. CPU-intensive loops
for (int i = 0; i < 1_000_000; i++)
{
    // Complex computation on request thread
}

// 3. Inefficient algorithms
var results = collection
    .Where(x => x.IsValid())
    .OrderBy(x => x.Date)
    .ToList()
    .Where(x => x.Amount > 0)  // ❌ Double enumeration
    .ToList();

// 4. Excessive allocations causing GC pressure
for (int i = 0; i < 10000; i++)
{
    var temp = new byte[1024];  // ❌ Allocates on every iteration
}
```

## Monitoring Memory Usage

### Memory Metrics

```csharp
public class MemoryMonitor
{
    private readonly Meter _meter;
    private readonly ObservableGauge<long> _workingSet;
    private readonly ObservableGauge<long> _gcHeapSize;
    private readonly ObservableGauge<long> _privateBytes;
    private readonly Process _process;

    public MemoryMonitor(IMeterFactory meterFactory)
    {
        _meter = meterFactory.Create("MyApp.Resources");
        _process = Process.GetCurrentProcess();
        
        // Working Set: Total physical memory used
        _workingSet = _meter.CreateObservableGauge<long>(
            "process.memory.working_set",
            () => _process.WorkingSet64,
            unit: "bytes",
            description: "Process working set in bytes");
        
        // Private Bytes: Memory allocated exclusively to this process
        _privateBytes = _meter.CreateObservableGauge<long>(
            "process.memory.private",
            () => _process.PrivateMemorySize64,
            unit: "bytes");
        
        // GC Heap Size: Managed memory
        _gcHeapSize = _meter.CreateObservableGauge<long>(
            "dotnet.gc.heap.size",
            () => GC.GetTotalMemory(forceFullCollection: false),
            unit: "bytes");
    }
    
    public MemorySnapshot GetSnapshot()
    {
        _process.Refresh();
        
        return new MemorySnapshot
        {
            WorkingSetMB = _process.WorkingSet64 / 1024.0 / 1024.0,
            PrivateBytesMB = _process.PrivateMemorySize64 / 1024.0 / 1024.0,
            GcHeapMB = GC.GetTotalMemory(false) / 1024.0 / 1024.0,
            Gen0Collections = GC.CollectionCount(0),
            Gen1Collections = GC.CollectionCount(1),
            Gen2Collections = GC.CollectionCount(2)
        };
    }
}

public record MemorySnapshot
{
    public double WorkingSetMB { get; init; }
    public double PrivateBytesMB { get; init; }
    public double GcHeapMB { get; init; }
    public int Gen0Collections { get; init; }
    public int Gen1Collections { get; init; }
    public int Gen2Collections { get; init; }
}
```

### GC Monitoring

```csharp
public class GcMonitor
{
    private readonly Meter _meter;
    private readonly Counter<long> _gen0Collections;
    private readonly Counter<long> _gen1Collections;
    private readonly Counter<long> _gen2Collections;
    private int _lastGen0Count;
    private int _lastGen1Count;
    private int _lastGen2Count;

    public GcMonitor(IMeterFactory meterFactory)
    {
        _meter = meterFactory.Create("MyApp.GC");
        
        _gen0Collections = _meter.CreateCounter<long>(
            "dotnet.gc.collections",
            unit: "collections",
            description: "GC collections");
        
        // Register GC callbacks
        GC.RegisterForFullGCNotification(10, 10);
        Task.Run(MonitorGc);
    }

    private async Task MonitorGc()
    {
        while (true)
        {
            var currentGen0 = GC.CollectionCount(0);
            var currentGen1 = GC.CollectionCount(1);
            var currentGen2 = GC.CollectionCount(2);
            
            if (currentGen0 > _lastGen0Count)
            {
                _gen0Collections.Add(currentGen0 - _lastGen0Count,
                    new KeyValuePair<string, object?>("generation", "0"));
                _lastGen0Count = currentGen0;
            }
            
            if (currentGen1 > _lastGen1Count)
            {
                _gen1Collections.Add(currentGen1 - _lastGen1Count,
                    new KeyValuePair<string, object?>("generation", "1"));
                _lastGen1Count = currentGen1;
            }
            
            if (currentGen2 > _lastGen2Count)
            {
                _gen2Collections.Add(currentGen2 - _lastGen2Count,
                    new KeyValuePair<string, object?>("generation", "2"));
                _lastGen2Count = currentGen2;
                
                // Gen2 collections are expensive - log them
                Console.WriteLine($"Gen2 GC occurred. Heap size: {GC.GetTotalMemory(false) / 1024 / 1024}MB");
            }
            
            await Task.Delay(TimeSpan.FromSeconds(5));
        }
    }
}
```

### Detecting Memory Leaks

```csharp
public class MemoryLeakDetector
{
    private readonly List<MemorySnapshot> _snapshots = new();
    private readonly TimeSpan _samplingInterval = TimeSpan.FromMinutes(5);

    public async Task MonitorForLeaks(CancellationToken ct)
    {
        while (!ct.IsCancellationRequested)
        {
            var snapshot = GetMemorySnapshot();
            _snapshots.Add(snapshot);
            
            // Keep last 24 hours of data
            if (_snapshots.Count > 288) // 24 hours / 5 minutes
            {
                _snapshots.RemoveAt(0);
            }
            
            if (_snapshots.Count >= 12) // At least 1 hour of data
            {
                var leak = DetectLeak();
                if (leak.IsDetected)
                {
                    await AlertOnMemoryLeak(leak);
                }
            }
            
            await Task.Delay(_samplingInterval, ct);
        }
    }

    private MemoryLeakAnalysis DetectLeak()
    {
        // Check if memory is consistently growing
        var recentSnapshots = _snapshots.TakeLast(12).ToList();
        var oldSnapshots = _snapshots.Take(12).ToList();
        
        var recentAvg = recentSnapshots.Average(s => s.PrivateBytesMB);
        var oldAvg = oldSnapshots.Average(s => s.PrivateBytesMB);
        
        var growthRate = (recentAvg - oldAvg) / oldAvg;
        
        return new MemoryLeakAnalysis
        {
            IsDetected = growthRate > 0.20, // 20% growth
            GrowthRate = growthRate,
            CurrentMemoryMB = recentAvg,
            Message = $"Memory grew by {growthRate:P1} in last hour"
        };
    }
}
```

## Monitoring Disk and Network I/O

### Disk I/O Monitoring

```csharp
public class DiskIoMonitor
{
    private readonly Meter _meter;
    private readonly Counter<long> _bytesRead;
    private readonly Counter<long> _bytesWritten;
    private readonly Histogram<double> _ioLatency;

    public DiskIoMonitor(IMeterFactory meterFactory)
    {
        _meter = meterFactory.Create("MyApp.DiskIO");
        
        _bytesRead = _meter.CreateCounter<long>(
            "disk.io.bytes.read",
            unit: "bytes");
        
        _bytesWritten = _meter.CreateCounter<long>(
            "disk.io.bytes.written",
            unit: "bytes");
        
        _ioLatency = _meter.CreateHistogram<double>(
            "disk.io.latency",
            unit: "ms");
    }

    public async Task<byte[]> ReadFileWithMetrics(string path)
    {
        var stopwatch = Stopwatch.StartNew();
        
        try
        {
            var data = await File.ReadAllBytesAsync(path);
            
            stopwatch.Stop();
            _bytesRead.Add(data.Length);
            _ioLatency.Record(stopwatch.ElapsedMilliseconds,
                new KeyValuePair<string, object?>("operation", "read"));
            
            return data;
        }
        catch
        {
            stopwatch.Stop();
            _ioLatency.Record(stopwatch.ElapsedMilliseconds,
                new KeyValuePair<string, object?>("operation", "read"),
                new KeyValuePair<string, object?>("status", "error"));
            throw;
        }
    }
}
```

### Network I/O Monitoring

```csharp
public class NetworkMonitor
{
    private readonly Meter _meter;
    private readonly Counter<long> _bytesSent;
    private readonly Counter<long> _bytesReceived;
    private readonly ObservableGauge<int> _activeConnections;
    private readonly HttpClient _httpClient;

    public NetworkMonitor(IMeterFactory meterFactory, HttpClient httpClient)
    {
        _meter = meterFactory.Create("MyApp.Network");
        _httpClient = httpClient;
        
        _bytesSent = _meter.CreateCounter<long>(
            "network.io.bytes.sent",
            unit: "bytes");
        
        _bytesReceived = _meter.CreateCounter<long>(
            "network.io.bytes.received",
            unit: "bytes");
        
        _activeConnections = _meter.CreateObservableGauge<int>(
            "network.connections.active",
            () => GetActiveConnectionCount());
    }

    private int GetActiveConnectionCount()
    {
        // Get active TCP connections for this process
        var properties = IPGlobalProperties.GetIPGlobalProperties();
        var connections = properties.GetActiveTcpConnections();
        var processId = Process.GetCurrentProcess().Id;
        
        // Note: This is simplified; actual implementation would need to filter by process
        return connections.Count(c => c.State == TcpState.Established);
    }

    public async Task<HttpResponseMessage> SendRequestWithMetrics(HttpRequestMessage request)
    {
        var requestSize = request.Content?.Headers.ContentLength ?? 0;
        _bytesSent.Add(requestSize);
        
        var response = await _httpClient.SendAsync(request);
        
        var responseSize = response.Content.Headers.ContentLength ?? 0;
        _bytesReceived.Add(responseSize);
        
        return response;
    }
}
```

## Resource Utilization Alerts

### Setting Alert Thresholds

```csharp
public class ResourceAlertManager
{
    private readonly ILogger<ResourceAlertManager> _logger;
    
    private readonly Dictionary<string, ResourceThreshold> _thresholds = new()
    {
        ["cpu"] = new ResourceThreshold { Warning = 70, Critical = 90 },
        ["memory"] = new ResourceThreshold { Warning = 75, Critical = 85 },
        ["disk_io_latency"] = new ResourceThreshold { Warning = 50, Critical = 100 },
        ["active_connections"] = new ResourceThreshold { Warning = 500, Critical = 900 }
    };

    public async Task MonitorResources(CancellationToken ct)
    {
        while (!ct.IsCancellationRequested)
        {
            var cpuUsage = GetCpuUsage();
            CheckThreshold("cpu", cpuUsage);
            
            var memoryUsage = GetMemoryUsagePercentage();
            CheckThreshold("memory", memoryUsage);
            
            var diskLatency = GetAverageDiskLatency();
            CheckThreshold("disk_io_latency", diskLatency);
            
            var connections = GetActiveConnections();
            CheckThreshold("active_connections", connections);
            
            await Task.Delay(TimeSpan.FromSeconds(30), ct);
        }
    }

    private void CheckThreshold(string metric, double value)
    {
        if (!_thresholds.TryGetValue(metric, out var threshold))
            return;

        if (value >= threshold.Critical)
        {
            _logger.LogError(
                "CRITICAL: {Metric} is {Value:F1}% (threshold: {Threshold}%)",
                metric, value, threshold.Critical);
            
            // Send critical alert
            SendAlert(metric, value, AlertLevel.Critical);
        }
        else if (value >= threshold.Warning)
        {
            _logger.LogWarning(
                "WARNING: {Metric} is {Value:F1}% (threshold: {Threshold}%)",
                metric, value, threshold.Warning);
            
            // Send warning alert
            SendAlert(metric, value, AlertLevel.Warning);
        }
    }
}

public record ResourceThreshold
{
    public double Warning { get; init; }
    public double Critical { get; init; }
}
```

## Correlating Resources with Performance

### Example: CPU Saturation Impact

```csharp
public class PerformanceCorrelationAnalyzer
{
    public CorrelationReport AnalyzeCpuImpact(
        List<PerformanceDataPoint> dataPoints)
    {
        // Group by time windows
        var windows = dataPoints
            .GroupBy(p => new DateTime(p.Timestamp.Ticks / TimeSpan.TicksPerMinute * TimeSpan.TicksPerMinute))
            .Select(g => new
            {
                Time = g.Key,
                AvgCpu = g.Average(p => p.CpuUsage),
                P95Latency = GetPercentile(g.Select(p => p.Latency).ToList(), 95)
            })
            .ToList();
        
        // Find correlation
        var highCpuWindows = windows.Where(w => w.AvgCpu > 80).ToList();
        var normalCpuWindows = windows.Where(w => w.AvgCpu <= 80).ToList();
        
        var highCpuLatency = highCpuWindows.Any() 
            ? highCpuWindows.Average(w => w.P95Latency) 
            : 0;
        var normalCpuLatency = normalCpuWindows.Any() 
            ? normalCpuWindows.Average(w => w.P95Latency) 
            : 0;
        
        return new CorrelationReport
        {
            HighResourceLatency = highCpuLatency,
            NormalResourceLatency = normalCpuLatency,
            ImpactPercentage = ((highCpuLatency - normalCpuLatency) / normalCpuLatency) * 100,
            Conclusion = highCpuLatency > normalCpuLatency * 1.5
                ? "High CPU usage significantly impacts latency"
                : "CPU usage has minimal latency impact"
        };
    }
}
```

## Best Practices

### 1. Monitor the Right Metrics

```
✅ Monitor:
- CPU usage (process and system)
- Memory working set and GC heap
- GC collection frequency (especially Gen2)
- Active connections
- Request queue length
- Disk I/O latency

❌ Don't obsess over:
- Momentary spikes (unless persistent)
- Metrics that don't correlate with user experience
- Too many fine-grained metrics (alert fatigue)
```

### 2. Set Realistic Thresholds

```csharp
// Bad: Too aggressive
const int CpuWarningThreshold = 30;  // Will alert constantly

// Good: Based on capacity planning
const int CpuWarningThreshold = 70;  // Warning: approaching limits
const int CpuCriticalThreshold = 90; // Critical: immediate action needed
```

### 3. Track Trends, Not Just Point-in-Time

```csharp
// Track over time
public class TrendAnalyzer
{
    public bool IsMemoryLeaking(List<MemorySnapshot> snapshots)
    {
        // Need consistent growth trend, not single spike
        var hourlyAverages = snapshots
            .GroupBy(s => s.Timestamp.Hour)
            .Select(g => g.Average(s => s.WorkingSetMB))
            .ToList();
        
        // Check if memory is growing over time
        return IsConsistentlyIncreasing(hourlyAverages);
    }
}
```

### 4. Correlate with Application Metrics

```
Resource metrics + application metrics = insights

High CPU + Low throughput = Inefficient code
High memory + Frequent GC = Memory leak or pressure
High disk I/O + High latency = Disk bottleneck
```

## Summary

Resource monitoring provides visibility into how your application uses system resources. Monitor CPU, memory, disk, and network utilization to identify bottlenecks and capacity limits. Use .NET diagnostic tools (dotnet-counters, dotnet-trace, dotnet-dump) for deep investigation. Set alerts based on realistic thresholds and track trends over time, not just point-in-time values. Correlate resource metrics with application performance to understand cause and effect.
