## Introduction

Once service discovery tells you *which* instances are available, load balancing determines *which one* to call. The algorithm you choose—round-robin, least connections, random, weighted, or something more sophisticated—has significant impact on performance, resource utilization, and user experience.

Poor load balancing can leave some instances idle while others are overwhelmed. Good load balancing distributes requests evenly, accounts for instance capacity differences, and adapts to changing conditions. The right strategy depends on your workload: stateless APIs behave differently from stateful websocket connections, and CPU-intensive tasks need different treatment than I/O-bound operations.

## Key Concepts Summary

### Common Load Balancing Algorithms

#### 1. **Round-Robin**
Distributes requests sequentially across all instances.

```
Request 1 → Instance 1
Request 2 → Instance 2
Request 3 → Instance 3
Request 4 → Instance 1  (wraps around)
Request 5 → Instance 2
```

```csharp
public class RoundRobinLoadBalancer : ILoadBalancer
{
    private int _currentIndex = 0;
    private readonly object _lock = new object();
    
    public ServiceInstance Choose(List<ServiceInstance> instances)
    {
        if (!instances.Any())
            throw new NoInstancesAvailableException();
        
        lock (_lock)
        {
            var instance = instances[_currentIndex % instances.Count];
            _currentIndex++;
            return instance;
        }
    }
}
```

**Pros:**
- ✅ Simple, predictable
- ✅ Even distribution (if all instances are equal)
- ✅ No state needed between requests

**Cons:**
- ❌ Doesn't account for instance capacity differences
- ❌ Doesn't consider current load
- ❌ Can overload slow instances

**Best for:** Stateless APIs with uniform instance capacity

---

#### 2. **Weighted Round-Robin**
Like round-robin, but some instances receive more traffic based on weights.

```
Instance 1 (weight: 3) → Gets 3 requests
Instance 2 (weight: 1) → Gets 1 request
Instance 3 (weight: 2) → Gets 2 requests
```

```csharp
public class WeightedRoundRobinLoadBalancer : ILoadBalancer
{
    public ServiceInstance Choose(List<ServiceInstance> instances)
    {
        var weightedList = new List<ServiceInstance>();
        
        foreach (var instance in instances)
        {
            int weight = instance.Metadata.GetValueOrDefault("weight", 1);
            for (int i = 0; i < weight; i++)
            {
                weightedList.Add(instance);
            }
        }
        
        var index = Interlocked.Increment(ref _currentIndex) % weightedList.Count;
        return weightedList[index];
    }
}
```

**Best for:** Instances with different capacities (larger machines get more weight)

---

#### 3. **Least Connections**
Routes to the instance with fewest active connections.

```
Instance 1: 5 active connections
Instance 2: 3 active connections  ← Choose this
Instance 3: 7 active connections
```

```csharp
public class LeastConnectionsLoadBalancer : ILoadBalancer
{
    private readonly ConcurrentDictionary<string, int> _activeConnections = new();
    
    public ServiceInstance Choose(List<ServiceInstance> instances)
    {
        return instances.OrderBy(i => _activeConnections.GetOrAdd(i.Id, 0)).First();
    }
    
    public void TrackConnection(string instanceId, bool isActive)
    {
        if (isActive)
            _activeConnections.AddOrUpdate(instanceId, 1, (_, count) => count + 1);
        else
            _activeConnections.AddOrUpdate(instanceId, 0, (_, count) => Math.Max(0, count - 1));
    }
}
```

**Pros:**
- ✅ Accounts for connection duration differences
- ✅ Prevents overloading slow-responding instances
- ✅ Works well with long-lived connections

**Cons:**
- ❌ Requires tracking connection state
- ❌ More complex than round-robin
- ❌ May not reflect actual load (short vs long requests)

**Best for:** Long-lived connections (WebSockets, gRPC streams, database connections)

---

#### 4. **Random**
Chooses a random instance for each request.

```csharp
public class RandomLoadBalancer : ILoadBalancer
{
    private readonly Random _random = new Random();
    
    public ServiceInstance Choose(List<ServiceInstance> instances)
    {
        return instances[_random.Next(instances.Count)];
    }
}
```

**Pros:**
- ✅ Very simple
- ✅ No state needed
- ✅ Eventually distributes evenly (law of large numbers)

**Cons:**
- ❌ Can be uneven in short term
- ❌ No optimization

**Best for:** Stateless, homogeneous instances where simplicity matters

---

#### 5. **IP Hash / Session Affinity**
Routes based on client IP or session ID to ensure same client always hits same instance.

```csharp
public class IpHashLoadBalancer : ILoadBalancer
{
    public ServiceInstance Choose(List<ServiceInstance> instances, string clientIp)
    {
        var hash = clientIp.GetHashCode();
        var index = Math.Abs(hash % instances.Count);
        return instances[index];
    }
}
```

**Pros:**
- ✅ Session stickiness without session storage
- ✅ Cache locality (same instance has warmed cache for same clients)

**Cons:**
- ❌ Uneven distribution if client IPs not diverse
- ❌ Loses stickiness when instances scale up/down
- ❌ Not ideal for stateless applications

**Best for:** Stateful applications, WebSocket connections, cached data scenarios

#### 6. **Least Response Time**
Routes to instance with fastest recent response times.

```csharp
public class LeastResponseTimeLoadBalancer : ILoadBalancer
{
    private readonly ConcurrentDictionary<string, List<long>> _responseTimes = new();
    
    public ServiceInstance Choose(List<ServiceInstance> instances)
    {
        return instances.OrderBy(i => GetAverageResponseTime(i.Id)).First();
    }
    
    public void RecordResponseTime(string instanceId, long milliseconds)
    {
        var times = _responseTimes.GetOrAdd(instanceId, _ => new List<long>());
        
        lock (times)
        {
            times.Add(milliseconds);
            if (times.Count > 100) // Keep last 100 measurements
                times.RemoveAt(0);
        }
    }
    
    private double GetAverageResponseTime(string instanceId)
    {
        if (!_responseTimes.TryGetValue(instanceId, out var times) || !times.Any())
            return 0;
        
        lock (times)
        {
            return times.Average();
        }
    }
}
```

**Best for:** When instances have variable performance characteristics

#### 7. **Power of Two Choices (P2C)**
Randomly picks two instances and chooses the one with fewer connections.

```csharp
public class PowerOfTwoChoicesLoadBalancer : ILoadBalancer
{
    private readonly Random _random = new Random();
    private readonly ConcurrentDictionary<string, int> _activeConnections = new();
    
    public ServiceInstance Choose(List<ServiceInstance> instances)
    {
        if (instances.Count == 1)
            return instances[0];
        
        // Pick two random instances
        var first = instances[_random.Next(instances.Count)];
        var second = instances[_random.Next(instances.Count)];
        
        // Choose the one with fewer connections
        var firstConnections = _activeConnections.GetOrAdd(first.Id, 0);
        var secondConnections = _activeConnections.GetOrAdd(second.Id, 0);
        
        return firstConnections <= secondConnections ? first : second;
    }
}
```

**Pros:**
- ✅ Better than random, simpler than least connections
- ✅ No global coordination needed
- ✅ Proven to work well in practice

**Best for:** High-scale distributed systems (used by Google, AWS)

## Advanced Considerations

### Consistent Hashing
Minimizes remapping when instances are added/removed.

```csharp
public class ConsistentHashLoadBalancer : ILoadBalancer
{
    private readonly SortedDictionary<int, ServiceInstance> _ring = new();
    private const int VirtualNodes = 150;
    
    public void AddInstance(ServiceInstance instance)
    {
        for (int i = 0; i < VirtualNodes; i++)
        {
            var key = $"{instance.Id}:{i}";
            var hash = key.GetHashCode();
            _ring[hash] = instance;
        }
    }
    
    public ServiceInstance Choose(string requestKey)
    {
        var hash = requestKey.GetHashCode();
        
        foreach (var kvp in _ring)
        {
            if (kvp.Key >= hash)
                return kvp.Value;
        }
        
        return _ring.Values.First(); // Wrap around
    }
}
```

**Best for:** Caching scenarios, minimizing cache invalidation

### Health-Aware Load Balancing

```csharp
public class HealthAwareLoadBalancer : ILoadBalancer
{
    private readonly ILoadBalancer _baseLoadBalancer;
    private readonly IHealthChecker _healthChecker;
    
    public ServiceInstance Choose(List<ServiceInstance> instances)
    {
        // Filter to only healthy instances
        var healthyInstances = instances
            .Where(i => _healthChecker.IsHealthy(i.Id))
            .ToList();
        
        if (!healthyInstances.Any())
        {
            // Fallback: try any instance (maybe they'll recover)
            return _baseLoadBalancer.Choose(instances);
        }
        
        return _baseLoadBalancer.Choose(healthyInstances);
    }
}
```

## Decision Matrix

| Workload Type | Recommended Algorithm | Why |
|--------------|----------------------|-----|
| Stateless REST API | Round-Robin or Random | Simple, even distribution |
| Long-lived connections | Least Connections | Accounts for connection duration |
| Variable instance capacity | Weighted Round-Robin | Larger instances get more load |
| Stateful/session-based | IP Hash or Sticky Sessions | Same client → same instance |
| Caching scenario | Consistent Hashing | Minimizes cache misses |
| High-scale distributed | Power of Two Choices | Good balance of simplicity and effectiveness |
| Performance-sensitive | Least Response Time | Routes to fastest instances |

## Advanced Load Balancing Implementations

### Weighted Response Time Load Balancer

```csharp
public class WeightedResponseTimeLoadBalancer : ILoadBalancer
{
    private readonly ConcurrentDictionary<string, Queue<long>> _responseTimes = new();
    private const int SampleSize = 100;
    
    public ServiceInstance Choose(List<ServiceInstance> instances)
    {
        if (instances.Count == 1)
            return instances[0];
        
        // Calculate weights based on inverse of response times
        var weights = instances.Select(i => new
        {
            Instance = i,
            Weight = CalculateWeight(i.Id)
        }).ToList();
        
        var totalWeight = weights.Sum(w => w.Weight);
        var random = Random.Shared.NextDouble() * totalWeight;
        
        double cumulative = 0;
        foreach (var item in weights)
        {
            cumulative += item.Weight;
            if (random < cumulative)
                return item.Instance;
        }
        
        return instances.Last();
    }
    
    private double CalculateWeight(string instanceId)
    {
        if (!_responseTimes.TryGetValue(instanceId, out var times) || !times.Any())
            return 1.0;  // Default weight
        
        var avgResponseTime = times.Average();
        
        // Inverse weight: faster instances get higher weight
        return avgResponseTime > 0 ? 1000.0 / avgResponseTime : 1.0;
    }
    
    public void RecordResponseTime(string instanceId, long milliseconds)
    {
        var times = _responseTimes.GetOrAdd(instanceId, _ => new Queue<long>());
        
        lock (times)
        {
            times.Enqueue(milliseconds);
            
            while (times.Count > SampleSize)
                times.Dequeue();
        }
    }
}
```

### Zone-Aware Load Balancer

```csharp
public class ZoneAwareLoadBalancer : ILoadBalancer
{
    private readonly string _currentZone;
    private readonly ILoadBalancer _localBalancer;
    private readonly ILoadBalancer _crossZoneBalancer;
    private readonly double _crossZoneThreshold = 0.2;  // 20% threshold
    
    public ServiceInstance Choose(List<ServiceInstance> instances)
    {
        // Separate instances by zone
        var localInstances = instances.Where(i => i.Zone == _currentZone).ToList();
        var remoteInstances = instances.Where(i => i.Zone != _currentZone).ToList();
        
        // Prefer local zone if enough healthy instances
        if (localInstances.Count >= instances.Count * (1 - _crossZoneThreshold))
        {
            return _localBalancer.Choose(localInstances);
        }
        
        // Use cross-zone if local zone has too few instances
        _logger.LogWarning(
            "Local zone has only {LocalCount}/{TotalCount} instances, using cross-zone routing",
            localInstances.Count,
            instances.Count);
        
        return _crossZoneBalancer.Choose(instances);
    }
}
```

### Adaptive Load Balancer with Health Scores

```csharp
public class HealthScoreLoadBalancer : ILoadBalancer
{
    private readonly ConcurrentDictionary<string, HealthScore> _healthScores = new();
    
    public ServiceInstance Choose(List<ServiceInstance> instances)
    {
        var scored = instances.Select(i => new
        {
            Instance = i,
            Score = GetHealthScore(i.Id)
        }).OrderByDescending(x => x.Score).ToList();
        
        // Weighted random selection favoring healthier instances
        var totalScore = scored.Sum(s => s.Score);
        var random = Random.Shared.NextDouble() * totalScore;
        
        double cumulative = 0;
        foreach (var item in scored)
        {
            cumulative += item.Score;
            if (random < cumulative)
                return item.Instance;
        }
        
        return scored.First().Instance;
    }
    
    private double GetHealthScore(string instanceId)
    {
        if (!_healthScores.TryGetValue(instanceId, out var score))
            return 100.0;  // Default score
        
        return score.CurrentScore;
    }
    
    public void RecordSuccess(string instanceId)
    {
        var score = _healthScores.GetOrAdd(instanceId, _ => new HealthScore());
        score.RecordSuccess();
    }
    
    public void RecordFailure(string instanceId)
    {
        var score = _healthScores.GetOrAdd(instanceId, _ => new HealthScore());
        score.RecordFailure();
    }
}

public class HealthScore
{
    private double _currentScore = 100.0;
    private readonly object _lock = new object();
    
    public double CurrentScore
    {
        get { lock (_lock) return _currentScore; }
    }
    
    public void RecordSuccess()
    {
        lock (_lock)
        {
            _currentScore = Math.Min(100.0, _currentScore + 1.0);
        }
    }
    
    public void RecordFailure()
    {
        lock (_lock)
        {
            _currentScore = Math.Max(0.0, _currentScore - 10.0);
        }
    }
}
```

## Production Load Balancing Patterns

### Load Balancer with Circuit Breaker Integration

```csharp
public class CircuitBreakerAwareLoadBalancer : ILoadBalancer
{
    private readonly ILoadBalancer _baseBalancer;
    private readonly Dictionary<string, ICircuitBreaker> _circuitBreakers = new();
    
    public async Task<HttpResponseMessage> ExecuteAsync(
        List<ServiceInstance> instances,
        Func<ServiceInstance, Task<HttpResponseMessage>> operation)
    {
        // Filter out instances with open circuit breakers
        var availableInstances = instances
            .Where(i => GetCircuitBreaker(i.Id).State != CircuitState.Open)
            .ToList();
        
        if (!availableInstances.Any())
        {
            throw new NoHealthyInstancesException(
                "All instances have open circuit breakers");
        }
        
        var instance = _baseBalancer.Choose(availableInstances);
        var breaker = GetCircuitBreaker(instance.Id);
        
        try
        {
            return await breaker.ExecuteAsync(() => operation(instance));
        }
        catch (Exception)
        {
            // Circuit breaker will handle the failure
            throw;
        }
    }
    
    private ICircuitBreaker GetCircuitBreaker(string instanceId)
    {
        return _circuitBreakers.GetOrAdd(instanceId, 
            id => new CircuitBreaker(failureThreshold: 5, timeout: TimeSpan.FromSeconds(30)));
    }
}
```

### Session Affinity with Fallback

```csharp
public class StickySessionLoadBalancer : ILoadBalancer
{
    private readonly ILoadBalancer _fallbackBalancer;
    private readonly ConcurrentDictionary<string, string> _sessionMappings = new();
    private readonly IHealthChecker _healthChecker;
    
    public ServiceInstance Choose(List<ServiceInstance> instances, string sessionId = null)
    {
        if (string.IsNullOrEmpty(sessionId))
        {
            // No session - use fallback balancer
            return _fallbackBalancer.Choose(instances);
        }
        
        // Check if we have a mapping for this session
        if (_sessionMappings.TryGetValue(sessionId, out var instanceId))
        {
            var mappedInstance = instances.FirstOrDefault(i => i.Id == instanceId);
            
            // Use mapped instance if it's still healthy
            if (mappedInstance != null && _healthChecker.IsHealthy(mappedInstance.Id))
            {
                return mappedInstance;
            }
            
            // Mapped instance is gone or unhealthy, remove mapping
            _sessionMappings.TryRemove(sessionId, out _);
        }
        
        // Create new mapping
        var newInstance = _fallbackBalancer.Choose(instances);
        _sessionMappings.TryAdd(sessionId, newInstance.Id);
        
        return newInstance;
    }
    
    public void ClearSession(string sessionId)
    {
        _sessionMappings.TryRemove(sessionId, out _);
    }
}
```

### Metrics Collection

```csharp
public class ObservableLoadBalancer : ILoadBalancer
{
    private readonly ILoadBalancer _inner;
    private readonly Counter<long> _selectionCounter;
    private readonly Histogram<double> _selectionLatency;
    private readonly Gauge<int> _availableInstances;
    
    public ObservableLoadBalancer(ILoadBalancer inner, IMeterFactory meterFactory)
    {
        _inner = inner;
        var meter = meterFactory.Create("LoadBalancer");
        
        _selectionCounter = meter.CreateCounter<long>(
            "lb.selections",
            description: "Number of instance selections");
        
        _selectionLatency = meter.CreateHistogram<double>(
            "lb.selection_latency_ms",
            unit: "ms",
            description: "Instance selection latency");
        
        _availableInstances = meter.CreateGauge<int>(
            "lb.available_instances",
            description: "Number of available instances");
    }
    
    public ServiceInstance Choose(List<ServiceInstance> instances)
    {
        _availableInstances.Record(instances.Count);
        
        var sw = Stopwatch.StartNew();
        var selected = _inner.Choose(instances);
        sw.Stop();
        
        _selectionCounter.Add(1,
            new KeyValuePair<string, object>("instance", selected.Id),
            new KeyValuePair<string, object>("algorithm", _inner.GetType().Name));
        
        _selectionLatency.Record(sw.Elapsed.TotalMilliseconds);
        
        return selected;
    }
}
```

### Load Distribution Analysis

```csharp
public class LoadBalancerAnalyzer
{
    private readonly ConcurrentDictionary<string, long> _requestCounts = new();
    
    public void RecordRequest(string instanceId)
    {
        _requestCounts.AddOrUpdate(instanceId, 1, (_, count) => count + 1);
    }
    
    public LoadDistributionReport GenerateReport()
    {
        var total = _requestCounts.Values.Sum();
        var instances = _requestCounts.Select(kvp => new InstanceLoad
        {
            InstanceId = kvp.Key,
            RequestCount = kvp.Value,
            Percentage = (double)kvp.Value / total * 100
        }).OrderByDescending(i => i.RequestCount).ToList();
        
        return new LoadDistributionReport
        {
            TotalRequests = total,
            InstanceCount = instances.Count,
            Instances = instances,
            StandardDeviation = CalculateStandardDeviation(instances),
            IsBalanced = CalculateStandardDeviation(instances) < 10.0  // <10% deviation
        };
    }
    
    private double CalculateStandardDeviation(List<InstanceLoad> instances)
    {
        var mean = instances.Average(i => i.Percentage);
        var variance = instances.Average(i => Math.Pow(i.Percentage - mean, 2));
        return Math.Sqrt(variance);
    }
}
```

        for (int i = 0; i < 400; i++)
        {
            var selected = balancer.Choose(instances);
            selections[selected.Id] = selections.GetValueOrDefault(selected.Id) + 1;
        }
        
        // Assert - instance 1 should get ~75%, instance 2 should get ~25%
        Assert.InRange(selections["1"], 280, 320);  // ~300 (75%)
        Assert.InRange(selections["2"], 80, 120);   // ~100 (25%)
    }
}
