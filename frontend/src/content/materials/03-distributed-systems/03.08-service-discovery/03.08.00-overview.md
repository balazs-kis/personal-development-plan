# Chapter 3.8: Service Discovery and Load Balancing

## Overview
This chapter explores how services locate and communicate with each other in dynamic, containerized environments. You'll learn how service discovery eliminates hardcoded endpoints, how load balancing distributes traffic across instances, and how health checking ensures requests only reach healthy services. These are foundational skills for operating microservices in production, where service locations constantly change due to auto-scaling, deployments, and failures.

## Key Concepts
- **Service Discovery:** how services find each other without hardcoded addresses.
- **Client-Side vs Server-Side Discovery:** trade-offs between discovery patterns.
- **DNS-Based Discovery:** using DNS as a simple service discovery mechanism.
- **Health Checking:** ensuring traffic routes only to healthy instances.
- **Load Balancing Strategies:** algorithms for distributing load effectively.
- **Service Mesh:** Istio and Linkerd concepts for advanced service networking.
