# Lesson 4: Fallback Strategies and Graceful Degradation

## Learning Objectives

By the end of this lesson, you will be able to:
- Implement fallback strategies when primary operations fail
- Design systems that degrade gracefully under failure
- Choose appropriate fallback mechanisms for different scenarios
- Balance between availability and consistency during failures

---

## Introduction

Circuit breakers and retries tell you *when* an operation has failed. **Fallback strategies** tell you *what to do about it*. Rather than showing users an error page, gracefully degraded systems provide reduced functionality—cached data, default values, or simplified alternatives.

Think of fallback strategies like a backup power generator: when the main power fails, the backup kicks in. You might not have full functionality, but critical systems keep running. The goal is to maintain the best possible user experience even when dependencies fail.

## Key Concepts Summary

### Types of Fallback Strategies

#### 1. **Cached Response**

Return stale but valid data from cache:

```csharp
public async Task<WeatherForecast> GetWeatherAsync(string city)
{
    try
    {
        // Try primary service
        var forecast = await weatherApiClient.GetAsync(city);
        
        // Update cache on success
        await cache.SetAsync($"weather:{city}", forecast, TimeSpan.FromMinutes(15));
        
        return forecast;
    }
    catch (Exception)
    {
        // Fall back to cached data
        var cachedForecast = await cache.GetAsync<WeatherForecast>($"weather:{city}");
        
        if (cachedForecast != null)
        {
            cachedForecast.IsFromCache = true; // Let user know data may be stale
            return cachedForecast;
        }
        
        throw; // No fallback available
    }
}
```

**When to use:**
- Data doesn't change frequently
- Stale data is better than no data
- Examples: weather, news feeds, product catalogs

#### 2. **Default Value**

Return a sensible default when unable to retrieve data:

```csharp
public async Task<UserPreferences> GetUserPreferencesAsync(string userId)
{
    try
    {
        return await preferencesService.GetAsync(userId);
    }
    catch (Exception)
    {
        // Fall back to system defaults
        return new UserPreferences
        {
            Theme = "light",
            Language = "en-US",
            NotificationsEnabled = true,
            ItemsPerPage = 20
        };
    }
}
```

**When to use:**
- System can function with default settings
- Missing data is non-critical
- Examples: user preferences, feature flags, configuration

#### 3. **Alternative Service**

Call a backup service or alternative implementation:

```csharp
public async Task<GeoLocation> GetLocationAsync(string address)
{
    try
    {
        // Primary geocoding service (Google Maps)
        return await googleMapsClient.GeocodeAsync(address);
    }
    catch (Exception)
    {
        try
        {
            // Fallback to alternative service (OpenStreetMap)
            return await openStreetMapClient.GeocodeAsync(address);
        }
        catch (Exception)
        {
            // Final fallback: approximate location from IP
            return await ipGeolocationClient.GetLocationFromIpAsync();
        }
    }
}
```

**When to use:**
- Multiple providers exist for the same functionality
- Cost vs. reliability trade-offs (expensive primary, cheaper fallback)
- Examples: payment processors, geocoding, email delivery

#### 4. **Simplified Response**

Return a reduced-fidelity version:

```csharp
public async Task<ProductDetails> GetProductAsync(string productId)
{
    try
    {
        // Full details including reviews, recommendations, inventory across stores
        return await productService.GetFullDetailsAsync(productId);
    }
    catch (Exception)
    {
        // Fallback: basic product info from cache (no reviews, no recommendations)
        var basicInfo = await cache.GetAsync<BasicProduct>($"product:{productId}");
        
        return new ProductDetails
        {
            Id = basicInfo.Id,
            Name = basicInfo.Name,
            Price = basicInfo.Price,
            InStock = true, // Assume in stock when we can't check
            Reviews = new List<Review>(), // Empty reviews
            Recommendations = new List<Product>() // No recommendations
        };
    }
}
```

**When to use:**
- Some features depend on external services
- Core functionality can work without enrichments
- Examples: product pages without reviews, profiles without activity history

#### 5. **Queued for Later**

Accept the request but process it asynchronously:

```csharp
public async Task<OrderResult> PlaceOrderAsync(Order order)
{
    try
    {
        // Try immediate processing
        var result = await paymentProcessor.ProcessAsync(order.Payment);
        var shipment = await shippingService.CreateShipmentAsync(order);
        
        return new OrderResult
        {
            OrderId = order.Id,
            Status = "Confirmed",
            EstimatedDelivery = shipment.EstimatedDelivery
        };
    }
    catch (Exception)
    {
        // Fallback: queue for background processing
        await orderQueue.EnqueueAsync(order);
        
        return new OrderResult
        {
            OrderId = order.Id,
            Status = "Pending", // Will be processed when services recover
            EstimatedDelivery = null, // Unknown until processed
            Message = "Your order is queued and will be processed shortly"
        };
    }
}
```

**When to use:**
- Operation doesn't need to complete immediately
- Eventually consistent is acceptable
- Examples: order processing, report generation, batch updates

#### 6. **Fail Silent (Observe Only)**

For non-critical operations, fail silently and log:

```csharp
public async Task<PageView> TrackPageViewAsync(PageView pageView)
{
    try
    {
        await analyticsService.TrackAsync(pageView);
    }
    catch (Exception ex)
    {
        // Don't fail the user request for analytics
        logger.LogWarning(ex, "Failed to track page view for {Page}", pageView.Page);
    }
    
    // Return the page regardless of analytics success
    return pageView;
}
```

**When to use:**
- Operation is non-critical (analytics, logging, recommendations)
- User experience shouldn't depend on success
- Examples: analytics, A/B tests, recommendations

## Graceful Degradation Strategy

### Priority Levels

Define which features are critical vs. optional:

| Priority | Features | Fallback Strategy |
|----------|----------|------------------|
| P0 (Critical) | Login, checkout, core functionality | Cache, alternative service, queue |
| P1 (Important) | Search, recommendations | Simplified results, cached data |
| P2 (Nice to have) | Reviews, social features | Empty/default values, fail silent |
| P3 (Optional) | Analytics, personalization | Fail silent, log only |

### Feature Toggle Approach

```csharp
public class FeatureDegradationService
{
    private readonly IFeatureFlagService _featureFlags;
    
    public async Task<ProductPage> GetProductPageAsync(string productId)
    {
        var page = new ProductPage
        {
            BasicInfo = await GetBasicInfoAsync(productId) // Always required
        };
        
        // Gracefully add features based on availability
        if (await _featureFlags.IsEnabledAsync("reviews"))
        {
            try
            {
                page.Reviews = await reviewService.GetReviewsAsync(productId);
            }
            catch
            {
                page.Reviews = new List<Review>(); // Degrade gracefully
            }
        }
        
        if (await _featureFlags.IsEnabledAsync("recommendations"))
        {
            try
            {
                page.Recommendations = await recommendationService.GetAsync(productId);
            }
            catch
            {
                page.Recommendations = new List<Product>(); // Degrade gracefully
            }
        }
        
        if (await _featureFlags.IsEnabledAsync("inventory"))
        {
            try
            {
                page.Inventory = await inventoryService.CheckAsync(productId);
            }
            catch
            {
                page.Inventory = new Inventory { InStock = true, Quantity = null };
            }
        }
        
        return page;
    }
}
```

## Advanced Fallback Patterns

### Multi-Tier Fallback Chain

```csharp
public class MultiTierFallbackService
{
    public async Task<WeatherData> GetWeatherAsync(string city)
    {
        // Tier 1: Primary service
        try
        {
            return await _primaryWeatherService.GetAsync(city);
        }
        catch (Exception ex)
        {
            _logger.LogWarning(ex, "Primary weather service failed");
        }
        
        // Tier 2: Secondary service
        try
        {
            return await _secondaryWeatherService.GetAsync(city);
        }
        catch (Exception ex)
        {
            _logger.LogWarning(ex, "Secondary weather service failed");
        }
        
        // Tier 3: Cached data
        var cached = await _cache.GetAsync<WeatherData>($"weather:{city}");
        if (cached != null)
        {
            cached.IsStale = true;
            cached.Source = "cache";
            return cached;
        }
        
        // Tier 4: Default/estimated data
        return EstimateWeather(city);
    }
    
    private WeatherData EstimateWeather(string city)
    {
        // Historical average for this date
        var avgTemp = GetHistoricalAverage(city, DateTime.UtcNow);
        
        return new WeatherData
        {
            City = city,
            Temperature = avgTemp,
            Description = "Estimated from historical data",
            IsEstimated = true,
            Source = "historical_average"
        };
    }
}
```

### Graceful Feature Degradation

```csharp
public class ProductService
{
    private readonly IFeatureAvailability _features;
    
    public async Task<ProductDetails> GetProductAsync(int productId)
    {
        var product = await _db.Products.FindAsync(productId);
        if (product == null) return null;
        
        var details = new ProductDetails
        {
            Id = product.Id,
            Name = product.Name,
            Price = product.Price,
            Description = product.Description
        };
        
        // Enhanced features - degrade gracefully if unavailable
        await AddReviews(details);
        await AddInventory(details);
        await AddRecommendations(details);
        await AddPersonalization(details);
        
        return details;
    }
    
    private async Task AddReviews(ProductDetails details)
    {
        if (!await _features.IsAvailableAsync("reviews"))
        {
            details.Reviews = new List<Review>();
            details.AvailableFeatures.Remove("reviews");
            return;
        }
        
        try
        {
            details.Reviews = await _reviewService.GetReviewsAsync(details.Id);
        }
        catch (Exception ex)
        {
            _logger.LogWarning(ex, "Failed to load reviews for product {ProductId}", details.Id);
            details.Reviews = new List<Review>();
            details.AvailableFeatures.Remove("reviews");
        }
    }
    
    private async Task AddInventory(ProductDetails details)
    {
        if (!await _features.IsAvailableAsync("real_time_inventory"))
        {
            // Fall back to approximate inventory
            details.InStock = true;
            details.InventoryNote = "Stock information approximate";
            return;
        }
        
        try
        {
            var inventory = await _inventoryService.GetAsync(details.Id);
            details.InStock = inventory.Quantity > 0;
            details.StockQuantity = inventory.Quantity;
        }
        catch (Exception ex)
        {
            _logger.LogWarning(ex, "Failed to load inventory for product {ProductId}", details.Id);
            details.InStock = true;  // Assume in stock
            details.InventoryNote = "Real-time stock unavailable";
        }
    }
}
```

## Advanced Caching Strategies

### Refresh-Ahead Cache

Proactively refresh cache before expiration:

```csharp
public class RefreshAheadCache<T>
{
    private readonly IDistributedCache _cache;
    private readonly TimeSpan _ttl;
    private readonly TimeSpan _refreshThreshold;
    private readonly ConcurrentDictionary<string, SemaphoreSlim> _refreshLocks = new();
    
    public RefreshAheadCache(IDistributedCache cache, TimeSpan ttl, double refreshThresholdPercent = 0.8)
    {
        _cache = cache;
        _ttl = ttl;
        _refreshThreshold = TimeSpan.FromMilliseconds(ttl.TotalMilliseconds * refreshThresholdPercent);
    }
    
    public async Task<T> GetOrFetchAsync(string key, Func<Task<T>> fetchFunc)
    {
        var cacheEntry = await _cache.GetStringAsync(key);
        
        if (cacheEntry != null)
        {
            var entry = JsonSerializer.Deserialize<CacheEntry<T>>(cacheEntry);
            
            // Check if we should refresh proactively
            var age = DateTime.UtcNow - entry.CachedAt;
            if (age > _refreshThreshold)
            {
                _ = Task.Run(async () => await RefreshAsync(key, fetchFunc));
            }
            
            return entry.Value;
        }
        
        // Cache miss - fetch and store
        return await RefreshAsync(key, fetchFunc);
    }
    
    private async Task<T> RefreshAsync(string key, Func<Task<T>> fetchFunc)
    {
        var lockObj = _refreshLocks.GetOrAdd(key, _ => new SemaphoreSlim(1));
        
        // Prevent multiple simultaneous refreshes
        await lockObj.WaitAsync();
        try
        {
            var value = await fetchFunc();
            
            var entry = new CacheEntry<T>
            {
                Value = value,
                CachedAt = DateTime.UtcNow
            };
            
            await _cache.SetStringAsync(
                key,
                JsonSerializer.Serialize(entry),
                new DistributedCacheEntryOptions
                {
                    AbsoluteExpirationRelativeToNow = _ttl
                });
            
            return value;
        }
        finally
        {
            lockObj.Release();
        }
    }
    
    private class CacheEntry<TValue>
    {
        public TValue Value { get; set; }
        public DateTime CachedAt { get; set; }
    }
}
```

### Stale-While-Revalidate

Serve stale data while fetching fresh data in background:

```csharp
public class StaleWhileRevalidateCache<T>
{
    public async Task<T> GetAsync(string key, Func<Task<T>> fetchFunc)
    {
        var cached = await _cache.GetAsync<CachedValue<T>>(key);
        
        if (cached != null)
        {
            // Serve stale data immediately
            if (cached.IsStale)
            {
                // Trigger refresh in background
                _ = Task.Run(async () =>
                {
                    try
                    {
                        var fresh = await fetchFunc();
                        await _cache.SetAsync(key, new CachedValue<T>
                        {
                            Value = fresh,
                            CachedAt = DateTime.UtcNow,
                            ExpiresAt = DateTime.UtcNow.AddMinutes(5)
                        });
                    }
                    catch (Exception ex)
                    {
                        _logger.LogWarning(ex, "Background refresh failed for {Key}", key);
                    }
                });
            }
            
            return cached.Value;
        }
        
        // No cache - fetch synchronously
        var value = await fetchFunc();
        await _cache.SetAsync(key, new CachedValue<T>
        {
            Value = value,
            CachedAt = DateTime.UtcNow,
            ExpiresAt = DateTime.UtcNow.AddMinutes(5)
        });
        
        return value;
    }
}

public class CachedValue<T>
{
    public T Value { get; set; }
    public DateTime CachedAt { get; set; }
    public DateTime ExpiresAt { get; set; }
    public bool IsStale => DateTime.UtcNow > ExpiresAt;
}
```

## Dynamic Fallback Selection

### Health-Based Fallback

Choose fallback based on service health:

```csharp
public class HealthAwareFallbackService
{
    private readonly IHealthCheckService _healthCheck;
    
    public async Task<Data> GetDataAsync(string key)
    {
        var health = await _healthCheck.CheckHealthAsync();
        
        // Choose strategy based on system health
        if (health.Status == HealthStatus.Healthy)
        {
            // Normal operation
            return await FetchFromPrimaryAsync(key);
        }
        else if (health.Status == HealthStatus.Degraded)
        {
            // Degraded - try primary but fallback quickly
            try
            {
                using var cts = new CancellationTokenSource(TimeSpan.FromSeconds(2));
                return await FetchFromPrimaryAsync(key).WaitAsync(cts.Token);
            }
            catch
            {
                return await FetchFromCacheAsync(key);
            }
        }
        else
        {
            // Unhealthy - skip primary entirely
            return await FetchFromCacheAsync(key);
        }
    }
}
```

### Load-Based Fallback

```csharp
public class LoadAwareFallbackService
{
    public async Task<Result> ProcessAsync(Request request)
    {
        var currentLoad = await GetCurrentLoadAsync();
        
        if (currentLoad < 0.7)  // Less than 70% capacity
        {
            // Full processing
            return await ProcessFullAsync(request);
        }
        else if (currentLoad < 0.9)  // 70-90% capacity
        {
            // Reduced quality processing
            return await ProcessReducedQualityAsync(request);
        }
        else  // Over 90% capacity
        {
            // Minimal processing or cached response
            return await ProcessMinimalAsync(request);
        }
    }
    
    private async Task<double> GetCurrentLoadAsync()
    {
        var cpuUsage = GetCpuUsage();
        var memoryUsage = GetMemoryUsage();
        var queueDepth = GetQueueDepth();
        
        return Math.Max(cpuUsage, Math.Max(memoryUsage, queueDepth / 1000.0));
    }
}
```

## Compensating Transactions

When fallback involves undoing operations:

```csharp
public class OrderCompensationService
{
    public async Task<OrderResult> PlaceOrderAsync(Order order)
    {
        var compensations = new Stack<Func<Task>>();
        
        try
        {
            // Step 1: Reserve inventory
            await _inventoryService.ReserveAsync(order.Items);
            compensations.Push(async () => 
                await _inventoryService.ReleaseAsync(order.Items));
            
            // Step 2: Process payment
            var paymentResult = await _paymentService.ChargeAsync(order.Payment);
            compensations.Push(async () => 
                await _paymentService.RefundAsync(paymentResult.TransactionId));
            
            // Step 3: Create shipment
            var shipment = await _shippingService.CreateShipmentAsync(order);
            compensations.Push(async () => 
                await _shippingService.CancelShipmentAsync(shipment.Id));
            
            // Success - commit
            return new OrderResult { OrderId = order.Id, Status = "Confirmed" };
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Order failed, executing compensations");
            
            // Rollback in reverse order
            while (compensations.Count > 0)
            {
                try
                {
                    var compensation = compensations.Pop();
                    await compensation();
                }
                catch (Exception compensationEx)
                {
                    _logger.LogError(compensationEx, "Compensation failed");
                    // Continue with remaining compensations
                }
            }
            
            throw new OrderFailedException("Order failed and was rolled back", ex);
        }
    }
}
```
