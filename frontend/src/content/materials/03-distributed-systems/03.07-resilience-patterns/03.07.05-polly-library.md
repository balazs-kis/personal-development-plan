## Introduction

**Polly** is the de facto standard resilience library for .NET. Rather than implementing circuit breakers, retries, and timeouts from scratch, Polly provides battle-tested, production-ready implementations. It's maintained by the .NET Foundation and used by thousands of companies, including Stack Overflow, Jet.com, and many Microsoft teams.

Polly makes resilience patterns as simple as defining a policy and wrapping your operations with it. It supports all the patterns we've learned: circuit breakers, retries, timeouts, bulkheads, fallbacks, and more—plus the ability to combine them into sophisticated resilience strategies.

### Basic Policies

#### 1. **Retry Policy**

```csharp
using Polly;
using Polly.Retry;

// Simple retry
var retryPolicy = Policy
    .Handle<HttpRequestException>()
    .RetryAsync(3);

// Retry with exponential backoff
var retryPolicy = Policy
    .Handle<HttpRequestException>()
    .Or<TimeoutException>()
    .WaitAndRetryAsync(
        retryCount: 3,
        sleepDurationProvider: retryAttempt => 
            TimeSpan.FromSeconds(Math.Pow(2, retryAttempt)),
        onRetry: (exception, timespan, retryCount, context) =>
        {
            Console.WriteLine($"Retry {retryCount} after {timespan.TotalSeconds}s due to: {exception.Message}");
        }
    );

// Usage
var result = await retryPolicy.ExecuteAsync(async () =>
{
    return await httpClient.GetStringAsync("https://api.example.com/data");
});
```

#### 2. **Circuit Breaker Policy**

```csharp
// Break circuit after 5 failures, stay open for 30 seconds
var circuitBreakerPolicy = Policy
    .Handle<HttpRequestException>()
    .CircuitBreakerAsync(
        exceptionsAllowedBeforeBreaking: 5,
        durationOfBreak: TimeSpan.FromSeconds(30),
        onBreak: (exception, duration) =>
        {
            Console.WriteLine($"Circuit broken for {duration.TotalSeconds}s due to: {exception.Message}");
        },
        onReset: () =>
        {
            Console.WriteLine("Circuit reset - service recovered");
        },
        onHalfOpen: () =>
        {
            Console.WriteLine("Circuit half-open - testing service");
        }
    );

// Advanced: Circuit breaker with percentage threshold
var advancedCircuitBreaker = Policy
    .Handle<HttpRequestException>()
    .AdvancedCircuitBreakerAsync(
        failureThreshold: 0.5,           // Break if 50% of requests fail
        samplingDuration: TimeSpan.FromSeconds(10),  // Within 10 second window
        minimumThroughput: 8,            // Need at least 8 requests
        durationOfBreak: TimeSpan.FromSeconds(30)
    );
```

#### 3. **Timeout Policy**

```csharp
// Timeout after 30 seconds
var timeoutPolicy = Policy
    .TimeoutAsync(
        timeout: TimeSpan.FromSeconds(30),
        onTimeoutAsync: async (context, timespan, task) =>
        {
            Console.WriteLine($"Operation timed out after {timespan.TotalSeconds}s");
            await Task.CompletedTask;
        }
    );

// Optimistic timeout (allows cancellation)
var optimisticTimeout = Policy
    .TimeoutAsync(
        TimeSpan.FromSeconds(30),
        TimeoutStrategy.Optimistic
    );

// Pessimistic timeout (forceful)
var pessimisticTimeout = Policy
    .TimeoutAsync(
        TimeSpan.FromSeconds(30),
        TimeoutStrategy.Pessimistic
    );
```

#### 4. **Bulkhead Policy**

```csharp
// Allow max 10 parallel executions, queue up to 5 more
var bulkheadPolicy = Policy
    .BulkheadAsync(
        maxParallelization: 10,
        maxQueuingActions: 5,
        onBulkheadRejectedAsync: async context =>
        {
            Console.WriteLine("Bulkhead rejected - too many concurrent operations");
            await Task.CompletedTask;
        }
    );

// Usage
try
{
    await bulkheadPolicy.ExecuteAsync(async () =>
    {
        await ExpensiveOperationAsync();
    });
}
catch (BulkheadRejectedException)
{
    // Handle rejection - maybe return cached data or queue for later
}
```

#### 5. **Fallback Policy**

```csharp
// Return fallback value on failure
var fallbackPolicy = Policy<string>
    .Handle<HttpRequestException>()
    .Or<BrokenCircuitException>()
    .FallbackAsync(
        fallbackValue: "{\"status\":\"unavailable\"}",
        onFallbackAsync: async (result, context) =>
        {
            Console.WriteLine($"Fallback triggered. Exception: {result.Exception?.Message}");
            await Task.CompletedTask;
        }
    );

// Execute fallback action
var fallbackActionPolicy = Policy
    .Handle<Exception>()
    .FallbackAsync(
        fallbackAction: async (cancellationToken) =>
        {
            // Call alternative service or return cached data
            return await GetFromCacheAsync();
        },
        onFallbackAsync: async (exception) =>
        {
            await LogFallbackAsync(exception);
        }
    );
```

## Policy Wrap: Combining Policies

Combine multiple policies into a single strategy:

```csharp
// Innermost to outermost: Retry → Circuit Breaker → Timeout → Fallback
var retryPolicy = Policy
    .Handle<HttpRequestException>()
    .WaitAndRetryAsync(3, retryAttempt => TimeSpan.FromSeconds(Math.Pow(2, retryAttempt)));

var circuitBreakerPolicy = Policy
    .Handle<HttpRequestException>()
    .CircuitBreakerAsync(5, TimeSpan.FromSeconds(30));

var timeoutPolicy = Policy
    .TimeoutAsync(TimeSpan.FromSeconds(10));

var fallbackPolicy = Policy<string>
    .Handle<Exception>()
    .FallbackAsync("{\"error\":\"Service unavailable\"}");

// Combine policies (order matters!)
var policyWrap = Policy.WrapAsync(
    fallbackPolicy,        // Outermost
    timeoutPolicy,
    circuitBreakerPolicy,
    retryPolicy           // Innermost
);

// Execute with all policies
var result = await policyWrap.ExecuteAsync(async () =>
{
    return await httpClient.GetStringAsync("https://api.example.com/data");
});
```

**Execution flow:**
1. **Fallback** catches all failures and provides fallback value
2. **Timeout** enforces time limit on entire operation
3. **Circuit Breaker** prevents calls if service is down
4. **Retry** retries transient failures with backoff

## Integration with HttpClient

### Using IHttpClientFactory (Recommended)

```csharp
// Program.cs / Startup.cs
services.AddHttpClient("resilientApi", client =>
{
    client.BaseAddress = new Uri("https://api.example.com");
    client.Timeout = TimeSpan.FromSeconds(60);
})
.AddTransientHttpErrorPolicy(policyBuilder =>
    policyBuilder.WaitAndRetryAsync(3, retryAttempt => 
        TimeSpan.FromSeconds(Math.Pow(2, retryAttempt))
    ))
.AddTransientHttpErrorPolicy(policyBuilder =>
    policyBuilder.CircuitBreakerAsync(
        handledEventsAllowedBeforeBreaking: 5,
        durationOfBreak: TimeSpan.FromSeconds(30)
    ))
.AddPolicyHandler(Policy.TimeoutAsync<HttpResponseMessage>(TimeSpan.FromSeconds(10)));

// Usage in service
public class ApiService
{
    private readonly HttpClient _httpClient;
    
    public ApiService(IHttpClientFactory httpClientFactory)
    {
        _httpClient = httpClientFactory.CreateClient("resilientApi");
    }
    
    public async Task<string> GetDataAsync()
    {
        var response = await _httpClient.GetAsync("/data");
        response.EnsureSuccessStatusCode();
        return await response.Content.ReadAsStringAsync();
    }
}
```

### Advanced Configuration

```csharp
services.AddHttpClient<IOrderService, OrderService>()
    .AddPolicyHandler((services, request) =>
    {
        // Different policies based on request type
        return request.Method == HttpMethod.Get
            ? GetRetryPolicy()      // GET: Retry aggressively
            : GetNoRetryPolicy();   // POST/PUT: Don't retry (not idempotent)
    })
    .AddPolicyHandler(GetCircuitBreakerPolicy())
    .AddPolicyHandler(GetTimeoutPolicy());

static IAsyncPolicy<HttpResponseMessage> GetRetryPolicy()
{
    return HttpPolicyExtensions
        .HandleTransientHttpError()
        .Or<TimeoutRejectedException>()
        .WaitAndRetryAsync(
            retryCount: 3,
            sleepDurationProvider: retryAttempt => 
                TimeSpan.FromSeconds(Math.Pow(2, retryAttempt)) + 
                TimeSpan.FromMilliseconds(new Random().Next(0, 1000)) // Jitter
        );
}

static IAsyncPolicy<HttpResponseMessage> GetCircuitBreakerPolicy()
{
    return HttpPolicyExtensions
        .HandleTransientHttpError()
        .AdvancedCircuitBreakerAsync(
            failureThreshold: 0.25,    // 25% failure rate
            samplingDuration: TimeSpan.FromSeconds(60),
            minimumThroughput: 7,
            durationOfBreak: TimeSpan.FromSeconds(30)
        );
}

static IAsyncPolicy<HttpResponseMessage> GetTimeoutPolicy()
{
    return Policy.TimeoutAsync<HttpResponseMessage>(TimeSpan.FromSeconds(10));
}
```

```csharp
[Fact]
public async Task Should_Retry_On_TransientFailure()
{
    // Arrange
    int attempts = 0;
    var policy = Policy
        .Handle<HttpRequestException>()
        .RetryAsync(3);
    
    // Act
    await Assert.ThrowsAsync<HttpRequestException>(async () =>
    {
        await policy.ExecuteAsync(() =>
        {
            attempts++;
            throw new HttpRequestException("Transient error");
        });
    });
    
    // Assert
    Assert.Equal(4, attempts); // Initial + 3 retries
}

public async Task Should_OpenCircuit_After_FailureThreshold()
{
    // Arrange
    var policy = Policy
        .Handle<Exception>()
        .CircuitBreakerAsync(2, TimeSpan.FromMinutes(1));
    
    // Act - cause 2 failures to open circuit
    await Assert.ThrowsAsync<Exception>(() => policy.ExecuteAsync(() => throw new Exception()));
    await Assert.ThrowsAsync<Exception>(() => policy.ExecuteAsync(() => throw new Exception()));
```

## Advanced Polly Patterns

### Context-Based Policies

Pass context through policy execution:

```csharp
public class OrderService
{
    private readonly IAsyncPolicy<HttpResponseMessage> _policy;
    
    public async Task<Order> GetOrderAsync(int orderId, string userId)
    {
        var context = new Context
        {
            ["orderId"] = orderId.ToString(),
            ["userId"] = userId,
            ["correlationId"] = Guid.NewGuid().ToString(),
            ["timestamp"] = DateTime.UtcNow.ToString("O")
        };
        
        var response = await _policy.ExecuteAsync(
            (ctx, ct) => _httpClient.GetAsync($"/api/orders/{orderId}", ct),
            context,
            CancellationToken.None
        );
        
        return await response.Content.ReadFromJsonAsync<Order>();
    }
}

// Policy with context logging
var policy = Policy
    .HandleResult<HttpResponseMessage>(r => !r.IsSuccessStatusCode)
    .WaitAndRetryAsync(
        retryCount: 3,
        sleepDurationProvider: (attempt, context) =>
        {
            var orderId = context.GetValueOrDefault("orderId");
            _logger.LogWarning("Retrying order {OrderId}, attempt {Attempt}", orderId, attempt);
            return TimeSpan.FromSeconds(Math.Pow(2, attempt));
        },
        onRetry: (outcome, timespan, attempt, context) =>
        {
            _logger.LogWarning(
                "Retry {Attempt} for order {OrderId} after {Delay}ms. Correlation: {CorrelationId}",
                attempt,
                context.GetValueOrDefault("orderId"),
                timespan.TotalMilliseconds,
                context.GetValueOrDefault("correlationId"));
        }
    );
```

### Result-Based Policies

Handle specific response values, not just exceptions:

```csharp
// Handle both exceptions and unsuccessful responses
var policy = Policy
    .HandleResult<ApiResponse>(r => !r.Success || r.StatusCode >= 500)
    .Or<HttpRequestException>()
    .Or<TimeoutException>()
    .WaitAndRetryAsync(
        retryCount: 3,
        sleepDurationProvider: attempt => TimeSpan.FromSeconds(Math.Pow(2, attempt)),
        onRetry: (outcome, timespan, attempt, context) =>
        {
            if (outcome.Exception != null)
            {
                _logger.LogWarning(outcome.Exception, 
                    "Retry {Attempt} due to exception", attempt);
            }
            else
            {
                _logger.LogWarning(
                    "Retry {Attempt} due to status {StatusCode}", 
                    attempt, outcome.Result.StatusCode);
            }
        }
    );

// Usage
var response = await policy.ExecuteAsync(async () =>
{
    var httpResponse = await _httpClient.GetAsync(url);
    var apiResponse = await httpResponse.Content.ReadFromJsonAsync<ApiResponse>();
    return apiResponse;
});
```

### Rate Limiting with Polly

```csharp
public class RateLimitPolicy
{
    private readonly AsyncRateLimitPolicy<HttpResponseMessage> _rateLimitPolicy;
    
    public RateLimitPolicy()
    {
        // Allow 100 executions per 1 second
        _rateLimitPolicy = Policy.RateLimitAsync<HttpResponseMessage>(
            numberOfExecutions: 100,
            perTimeSpan: TimeSpan.FromSeconds(1),
            maxBurst: 10  // Allow bursts up to 110
        );
    }
    
    public async Task<HttpResponseMessage> ExecuteAsync(Func<Task<HttpResponseMessage>> operation)
    {
        try
        {
            return await _rateLimitPolicy.ExecuteAsync(operation);
        }
        catch (RateLimitRejectedException ex)
        {
            _logger.LogWarning("Rate limit exceeded: {Message}", ex.Message);
            
            // Return 429 Too Many Requests
            return new HttpResponseMessage(HttpStatusCode.TooManyRequests)
            {
                Content = new StringContent("Rate limit exceeded. Retry after 1 second.")
            };
        }
    }
}
```

## Polly Registry for Centralized Policies

### Creating a Policy Registry

```csharp
public static class PolicyRegistry
{
    public static IPolicyRegistry<string> Create(IServiceProvider services)
    {
        var logger = services.GetRequiredService<ILogger<Program>>();
        var metrics = services.GetRequiredService<IMetrics>();
        
        var registry = new PolicyRegistry
        {
            // Retry policies
            ["standard-retry"] = CreateStandardRetryPolicy(logger),
            ["aggressive-retry"] = CreateAggressiveRetryPolicy(logger),
            ["no-retry"] = Policy.NoOpAsync<HttpResponseMessage>(),
            
            // Circuit breakers
            ["standard-breaker"] = CreateStandardCircuitBreaker(logger, metrics),
            ["critical-breaker"] = CreateCriticalCircuitBreaker(logger, metrics),
            
            // Timeouts
            ["short-timeout"] = Policy.TimeoutAsync<HttpResponseMessage>(TimeSpan.FromSeconds(5)),
            ["standard-timeout"] = Policy.TimeoutAsync<HttpResponseMessage>(TimeSpan.FromSeconds(30)),
            ["long-timeout"] = Policy.TimeoutAsync<HttpResponseMessage>(TimeSpan.FromSeconds(60)),
            
            // Bulkheads
            ["high-priority-bulkhead"] = Policy.BulkheadAsync<HttpResponseMessage>(20, 10),
            ["normal-bulkhead"] = Policy.BulkheadAsync<HttpResponseMessage>(10, 5),
            
            // Composite policies
            ["payment-policy"] = CreatePaymentPolicy(logger, metrics),
            ["search-policy"] = CreateSearchPolicy(logger, metrics),
            ["analytics-policy"] = CreateAnalyticsPolicy(logger)
        };
        
        return registry;
    }
    
    private static IAsyncPolicy<HttpResponseMessage> CreateStandardRetryPolicy(ILogger logger)
    {
        return HttpPolicyExtensions
            .HandleTransientHttpError()
            .Or<TimeoutRejectedException>()
            .WaitAndRetryAsync(
                retryCount: 3,
                sleepDurationProvider: attempt => 
                    TimeSpan.FromSeconds(Math.Pow(2, attempt)) + 
                    TimeSpan.FromMilliseconds(Random.Shared.Next(0, 1000)),
                onRetry: (outcome, timespan, attempt, context) =>
                {
                    logger.LogWarning(
                        outcome.Exception,
                        "Retry {Attempt} after {Delay}ms",
                        attempt,
                        timespan.TotalMilliseconds);
                }
            );
    }
    
    private static IAsyncPolicy<HttpResponseMessage> CreatePaymentPolicy(
        ILogger logger, 
        IMetrics metrics)
    {
        var retry = HttpPolicyExtensions
            .HandleTransientHttpError()
            .WaitAndRetryAsync(5, attempt => TimeSpan.FromSeconds(Math.Pow(2, attempt)));
        
        var breaker = HttpPolicyExtensions
            .HandleTransientHttpError()
            .AdvancedCircuitBreakerAsync(
                failureThreshold: 0.25,
                samplingDuration: TimeSpan.FromSeconds(60),
                minimumThroughput: 7,
                durationOfBreak: TimeSpan.FromSeconds(30),
                onBreak: (outcome, duration) =>
                {
                    logger.LogError("Payment circuit breaker opened for {Duration}s", duration.TotalSeconds);
                    metrics.IncrementCounter("circuit_breaker.payment.opened");
                });
        
        var timeout = Policy.TimeoutAsync<HttpResponseMessage>(TimeSpan.FromSeconds(30));
        
        return Policy.WrapAsync(timeout, breaker, retry);
    }
}

// Registration
services.AddSingleton(PolicyRegistry.Create);

// Usage
public class PaymentService
{
    private readonly IHttpClientFactory _clientFactory;
    private readonly IReadOnlyPolicyRegistry<string> _policyRegistry;
    
    public PaymentService(
        IHttpClientFactory clientFactory,
        IReadOnlyPolicyRegistry<string> policyRegistry)
    {
        _clientFactory = clientFactory;
        _policyRegistry = policyRegistry;
    }
    
    public async Task<PaymentResult> ProcessPaymentAsync(Payment payment)
    {
        var client = _clientFactory.CreateClient("payment");
        var policy = _policyRegistry.Get<IAsyncPolicy<HttpResponseMessage>>("payment-policy");
        
        var response = await policy.ExecuteAsync(() =>
            client.PostAsJsonAsync("/api/payments", payment));
        
        return await response.Content.ReadFromJsonAsync<PaymentResult>();
    }
}
```

## Dynamic Policy Selection

### Policy per HTTP Method

```csharp
services.AddHttpClient("dynamic-api")
    .AddPolicyHandler((services, request) =>
    {
        var registry = services.GetRequiredService<IReadOnlyPolicyRegistry<string>>();
        
        return request.Method switch
        {
            HttpMethod m when m == HttpMethod.Get => 
                registry.Get<IAsyncPolicy<HttpResponseMessage>>("aggressive-retry"),
            
            HttpMethod m when m == HttpMethod.Post => 
                registry.Get<IAsyncPolicy<HttpResponseMessage>>("no-retry"),
            
            HttpMethod m when m == HttpMethod.Put => 
                registry.Get<IAsyncPolicy<HttpResponseMessage>>("standard-retry"),
            
            _ => registry.Get<IAsyncPolicy<HttpResponseMessage>>("standard-retry")
        };
    });
```

### Policy per Endpoint

```csharp
services.AddHttpClient("api")
    .AddPolicyHandler((services, request) =>
    {
        var registry = services.GetRequiredService<IReadOnlyPolicyRegistry<string>>();
        
        if (request.RequestUri.PathAndQuery.Contains("/payments"))
        {
            return registry.Get<IAsyncPolicy<HttpResponseMessage>>("payment-policy");
        }
        else if (request.RequestUri.PathAndQuery.Contains("/search"))
        {
            return registry.Get<IAsyncPolicy<HttpResponseMessage>>("search-policy");
        }
        else if (request.RequestUri.PathAndQuery.Contains("/analytics"))
        {
            return registry.Get<IAsyncPolicy<HttpResponseMessage>>("analytics-policy");
        }
        
        return registry.Get<IAsyncPolicy<HttpResponseMessage>>("standard-retry");
    });
```

## Monitoring Polly Policies

### Custom Logging

```csharp
public static class PolicyBuilderExtensions
{
    public static PolicyBuilder<TResult> WithLogging<TResult>(
        this PolicyBuilder<TResult> builder,
        ILogger logger,
        string policyName)
    {
        return builder
            .OnRetry((outcome, timespan, retryCount, context) =>
            {
                logger.LogWarning(
                    outcome.Exception,
                    "[{Policy}] Retry {RetryCount} after {Delay}ms",
                    policyName,
                    retryCount,
                    timespan.TotalMilliseconds);
            })
            .OnBreak((outcome, duration, context) =>
            {
                logger.LogError(
                    outcome.Exception,
                    "[{Policy}] Circuit breaker opened for {Duration}s",
                    policyName,
                    duration.TotalSeconds);
            })
            .OnReset(context =>
            {
                logger.LogInformation("[{Policy}] Circuit breaker reset", policyName);
            });
    }
}
```

### Metrics Collection

```csharp
public class PolicyMetrics
{
    private readonly Counter<long> _policyExecutions;
    private readonly Histogram<double> _policyDuration;
    
    public PolicyMetrics(IMeterFactory meterFactory)
    {
        var meter = meterFactory.Create("Polly");
        
        _policyExecutions = meter.CreateCounter<long>(
            "policy.executions",
            description: "Number of policy executions by outcome");
        
        _policyDuration = meter.CreateHistogram<double>(
            "policy.duration_ms",
            unit: "ms",
            description: "Duration of policy executions");
    }
    
    public void RecordExecution(string policyName, string outcome, TimeSpan duration)
    {
        _policyExecutions.Add(1,
            new KeyValuePair<string, object>("policy", policyName),
            new KeyValuePair<string, object>("outcome", outcome));
        
        _policyDuration.Record(duration.TotalMilliseconds,
            new KeyValuePair<string, object>("policy", policyName));
    }
}
```
