# Lesson 3: Timeouts and Bulkhead Pattern

## Learning Objectives

By the end of this lesson, you will be able to:
- Configure appropriate timeouts for different operation types
- Understand how timeouts prevent resource exhaustion
- Implement the bulkhead pattern to isolate failures
- Prevent one failing dependency from taking down your entire system

---

## Introduction

**Timeouts** are your first line of defense against slow or unresponsive services. Without timeouts, a single slow dependency can exhaust your thread pool, memory, and connection limits—bringing down your entire application. A well-configured timeout ensures you fail fast rather than waiting indefinitely.

The **Bulkhead Pattern** takes its name from ship compartments: if one compartment floods, watertight bulkheads prevent the entire ship from sinking. Similarly, bulkheads in software isolate resources (threads, connections, memory) so that if one dependency fails, it doesn't exhaust resources needed by other parts of your system.

These two patterns work together: timeouts prevent individual operations from hanging forever, while bulkheads prevent resource exhaustion even when many operations time out simultaneously.

## Key Concepts Summary

### Timeout Strategies

**Connection Timeout:**
- How long to wait for a connection to establish
- Typical values: 1-5 seconds
- Should be much shorter than request timeout

**Request Timeout:**
- Total time allowed for an operation to complete
- Must account for retries and processing time
- Should be based on SLA requirements

**Example Configuration:**
```csharp
var httpClient = new HttpClient
{
    Timeout = TimeSpan.FromSeconds(30) // Total request timeout
};

var socketHandler = new SocketsHttpHandler
{
    ConnectTimeout = TimeSpan.FromSeconds(5), // Connection timeout
    PooledConnectionLifetime = TimeSpan.FromMinutes(2)
};
```

### Timeout Guidelines by Operation Type

| Operation Type | Typical Timeout | Rationale |
|---------------|----------------|-----------|
| Database Query (simple) | 5-10 seconds | Should be fast; longer indicates problem |
| Database Query (complex) | 30-60 seconds | Reports and analytics may take longer |
| HTTP API Call (internal) | 5-15 seconds | Internal services should be responsive |
| HTTP API Call (external) | 30-60 seconds | Less control over external services |
| Message Queue Publish | 1-5 seconds | Should be fast; queues buffer |
| File Upload | 60-300 seconds | Large files need time |

### Cascading Timeouts

Each layer should have progressively shorter timeouts:

```
User Request (60s timeout)
    → API Gateway (50s timeout)
        → Service A (40s timeout)
            → Service B (30s timeout)
                → Database (20s timeout)
```

If the database times out at 20s, Service B has 10s to handle it and return. This prevents timeouts from piling up and exceeding the user's original timeout.

## Bulkhead Pattern

### Resource Isolation

**Without Bulkhead:**
```csharp
// All operations share the same thread pool
// If one service is slow, it can exhaust all threads
await SlowServiceA(); // Takes 100 threads
await SlowServiceB(); // No threads left!
await CriticalServiceC(); // Blocked!
```

**With Bulkhead:**
```csharp
// Each service gets its own resource pool
var serviceALimiter = new SemaphoreSlim(10); // Max 10 concurrent calls
var serviceBLimiter = new SemaphoreSlim(10); // Max 10 concurrent calls
var serviceCLimiter = new SemaphoreSlim(20); // Critical service gets more

await serviceALimiter.WaitAsync();
try
{
    await SlowServiceA(); // Limited to 10 concurrent calls
}
finally
{
    serviceALimiter.Release();
}
```

### Implementation Patterns

**Thread Pool Bulkhead:**
```csharp
public class ThreadPoolBulkhead
{
    private readonly SemaphoreSlim _semaphore;
    private readonly int _maxParallelization;
    
    public ThreadPoolBulkhead(int maxParallelization)
    {
        _maxParallelization = maxParallelization;
        _semaphore = new SemaphoreSlim(maxParallelization, maxParallelization);
    }
    
    public async Task<T> ExecuteAsync<T>(Func<Task<T>> operation, TimeSpan timeout)
    {
        // Wait to enter bulkhead (with timeout)
        bool entered = await _semaphore.WaitAsync(timeout);
        
        if (!entered)
        {
            throw new BulkheadRejectedException(
                $"Bulkhead is full. Max {_maxParallelization} concurrent operations.");
        }
        
        try
        {
            // Execute with timeout
            using var cts = new CancellationTokenSource(timeout);
            return await operation().WaitAsync(cts.Token);
        }
        finally
        {
            _semaphore.Release();
        }
    }
}

// Usage
var paymentBulkhead = new ThreadPoolBulkhead(maxParallelization: 20);

try
{
    var result = await paymentBulkhead.ExecuteAsync(
        operation: () => paymentService.ProcessPayment(order),
        timeout: TimeSpan.FromSeconds(30)
    );
}
catch (BulkheadRejectedException)
{
    // Too many concurrent payment operations
    // Return 503 Service Unavailable or queue for later
}
catch (OperationCanceledException)
{
    // Operation timed out
}
```

**Connection Pool Bulkhead:**
```csharp
// Database connection pools are a form of bulkhead
var connectionString = "Server=myserver;Database=mydb;Max Pool Size=50;";

// HTTP client connection pools
var socketsHandler = new SocketsHttpHandler
{
    MaxConnectionsPerServer = 10 // Limits connections to each service
};
```

### Bulkhead Sizing

**Factors to Consider:**
- Available resources (CPU, memory, connections)
- Dependency SLAs and typical response times
- Expected concurrent load
- Criticality of each dependency

**Example Calculation:**
- Total thread pool: 200 threads
- Service A (non-critical, slow): 20 threads (10%)
- Service B (non-critical): 30 threads (15%)
- Service C (critical): 50 threads (25%)
- Reserve: 100 threads (50%) for other operations

### Benefits of Bulkheads

✅ **Failure Isolation:** A slow database doesn't prevent API calls from working

✅ **Resource Protection:** Each dependency gets guaranteed resources

✅ **Predictable Degradation:** System degrades gracefully under load

✅ **Priority Control:** Critical services get more resources

## Timeout + Bulkhead Combined

```csharp
public class ResilientHttpClient
{
    private readonly HttpClient _httpClient;
    private readonly ThreadPoolBulkhead _bulkhead;
    
    public ResilientHttpClient(int maxConcurrent, TimeSpan timeout)
    {
        _httpClient = new HttpClient { Timeout = timeout };
        _bulkhead = new ThreadPoolBulkhead(maxConcurrent);
    }
    
    public async Task<HttpResponseMessage> GetAsync(string url)
    {
        return await _bulkhead.ExecuteAsync(
            operation: async () =>
            {
                using var cts = new CancellationTokenSource(_httpClient.Timeout);
                return await _httpClient.GetAsync(url, cts.Token);
            },
            timeout: _httpClient.Timeout
        );
    }
}

// Configure different bulkheads for different services
var internalApiClient = new ResilientHttpClient(
    maxConcurrent: 50,
    timeout: TimeSpan.FromSeconds(10)
);

var externalApiClient = new ResilientHttpClient(
    maxConcurrent: 10,
    timeout: TimeSpan.FromSeconds(30)
);
```

## Advanced Timeout Patterns

### Adaptive Timeouts

Adjust timeouts based on observed latency:

```csharp
public class AdaptiveTimeoutPolicy
{
    private readonly Queue<double> _recentLatencies = new Queue<double>();
    private const int WindowSize = 100;
    private readonly TimeSpan _minimumTimeout;
    private readonly TimeSpan _maximumTimeout;
    
    public AdaptiveTimeoutPolicy(TimeSpan minTimeout, TimeSpan maxTimeout)
    {
        _minimumTimeout = minTimeout;
        _maximumTimeout = maxTimeout;
    }
    
    public TimeSpan CalculateTimeout()
    {
        if (_recentLatencies.Count < 10)
            return _minimumTimeout;  // Not enough data
        
        // P95 + 50% buffer
        var p95 = CalculatePercentile(0.95);
        var adaptive = TimeSpan.FromMilliseconds(p95 * 1.5);
        
        // Clamp to min/max
        if (adaptive < _minimumTimeout) return _minimumTimeout;
        if (adaptive > _maximumTimeout) return _maximumTimeout;
        
        return adaptive;
    }
    
    public void RecordLatency(TimeSpan latency)
    {
        _recentLatencies.Enqueue(latency.TotalMilliseconds);
        
        if (_recentLatencies.Count > WindowSize)
            _recentLatencies.Dequeue();
    }
    
    private double CalculatePercentile(double percentile)
    {
        var sorted = _recentLatencies.OrderBy(x => x).ToArray();
        var index = (int)(percentile * sorted.Length);
        return sorted[Math.Min(index, sorted.Length - 1)];
    }
}

// Usage
public class ResilientApiClient
{
    private readonly AdaptiveTimeoutPolicy _timeoutPolicy;
    
    public async Task<T> GetAsync<T>(string url)
    {
        var timeout = _timeoutPolicy.CalculateTimeout();
        var sw = Stopwatch.StartNew();
        
        using var cts = new CancellationTokenSource(timeout);
        
        try
        {
            var result = await _httpClient.GetAsync(url, cts.Token);
            _timeoutPolicy.RecordLatency(sw.Elapsed);
            return await result.Content.ReadFromJsonAsync<T>();
        }
        catch (OperationCanceledException) when (cts.IsCancellationRequested)
        {
            throw new TimeoutException($"Request timed out after {timeout.TotalSeconds}s");
        }
    }
}
```

### Deadline Propagation

Pass deadlines through service call chains:

```csharp
public class DeadlineContext
{
    public DateTime Deadline { get; set; }
    
    public TimeSpan RemainingTime => Deadline - DateTime.UtcNow;
    
    public bool IsExpired => DateTime.UtcNow >= Deadline;
    
    public static DeadlineContext Create(TimeSpan timeout)
    {
        return new DeadlineContext 
        { 
            Deadline = DateTime.UtcNow + timeout 
        };
    }
}

// Service A
public async Task<Result> ProcessRequestAsync(Request request, DeadlineContext deadline)
{
    if (deadline.IsExpired)
        throw new DeadlineExceededException();
    
    // Reserve 10% of time for this service
    var localTimeout = TimeSpan.FromMilliseconds(deadline.RemainingTime.TotalMilliseconds * 0.1);
    
    using var cts = new CancellationTokenSource(localTimeout);
    var result = await DoWorkAsync(request, cts.Token);
    
    // Pass deadline to downstream service
    return await _serviceBClient.CallAsync(result, deadline);
}

// Service B
public async Task<Result> CallAsync(Data data, DeadlineContext deadline)
{
    if (deadline.IsExpired)
        throw new DeadlineExceededException();
    
    // Reserve remaining time
    using var cts = new CancellationTokenSource(deadline.RemainingTime);
    
    return await ProcessAsync(data, cts.Token);
}
```

## Advanced Bulkhead Patterns

### Priority-Based Bulkhead

Different priority levels get different resource allocations:

```csharp
public class PriorityBulkhead
{
    private readonly SemaphoreSlim _highPriority;
    private readonly SemaphoreSlim _normalPriority;
    private readonly SemaphoreSlim _lowPriority;
    
    public PriorityBulkhead(int highSlots, int normalSlots, int lowSlots)
    {
        _highPriority = new SemaphoreSlim(highSlots);
        _normalPriority = new SemaphoreSlim(normalSlots);
        _lowPriority = new SemaphoreSlim(lowSlots);
    }
    
    public async Task<T> ExecuteAsync<T>(
        Func<Task<T>> operation, 
        Priority priority,
        TimeSpan timeout)
    {
        var semaphore = priority switch
        {
            Priority.High => _highPriority,
            Priority.Normal => _normalPriority,
            Priority.Low => _lowPriority,
            _ => _normalPriority
        };
        
        bool entered = await semaphore.WaitAsync(timeout);
        
        if (!entered)
        {
            throw new BulkheadRejectedException(
                $"Bulkhead full for {priority} priority requests");
        }
        
        try
        {
            return await operation();
        }
        finally
        {
            semaphore.Release();
        }
    }
}

// Usage
var bulkhead = new PriorityBulkhead(
    highSlots: 20,    // Premium customers
    normalSlots: 50,  // Regular customers
    lowSlots: 10      // Background jobs
);

var result = await bulkhead.ExecuteAsync(
    operation: () => _service.ProcessAsync(request),
    priority: request.IsPremiumCustomer ? Priority.High : Priority.Normal,
    timeout: TimeSpan.FromSeconds(5)
);
```

### Adaptive Bulkhead

Adjust bulkhead size based on system load:

```csharp
public class AdaptiveBulkhead
{
    private SemaphoreSlim _semaphore;
    private int _currentCapacity;
    private readonly int _minCapacity;
    private readonly int _maxCapacity;
    private readonly object _lock = new object();
    
    public AdaptiveBulkhead(int minCapacity, int maxCapacity)
    {
        _minCapacity = minCapacity;
        _maxCapacity = maxCapacity;
        _currentCapacity = minCapacity;
        _semaphore = new SemaphoreSlim(_currentCapacity);
        
        // Adjust capacity every minute
        _ = Task.Run(async () =>
        {
            while (true)
            {
                await Task.Delay(TimeSpan.FromMinutes(1));
                AdjustCapacity();
            }
        });
    }
    
    private void AdjustCapacity()
    {
        var cpuUsage = GetCpuUsage();
        var memoryUsage = GetMemoryUsage();
        
        int newCapacity;
        
        if (cpuUsage > 80 || memoryUsage > 80)
        {
            // System under load - reduce capacity
            newCapacity = Math.Max(_currentCapacity - 5, _minCapacity);
        }
        else if (cpuUsage < 50 && memoryUsage < 50)
        {
            // System idle - increase capacity
            newCapacity = Math.Min(_currentCapacity + 5, _maxCapacity);
        }
        else
        {
            return;  // No change
        }
        
        lock (_lock)
        {
            if (newCapacity != _currentCapacity)
            {
                _logger.LogInformation(
                    "Adjusting bulkhead capacity from {Old} to {New}", 
                    _currentCapacity, newCapacity);
                
                _currentCapacity = newCapacity;
                _semaphore = new SemaphoreSlim(newCapacity);
            }
        }
    }
}
```

### Circuit Breaker + Bulkhead Integration

```csharp
public class ResilientExecutor
{
    private readonly CircuitBreaker _circuitBreaker;
    private readonly SemaphoreSlim _bulkhead;
    private readonly TimeSpan _timeout;
    
    public ResilientExecutor(
        CircuitBreaker circuitBreaker,
        int maxConcurrency,
        TimeSpan timeout)
    {
        _circuitBreaker = circuitBreaker;
        _bulkhead = new SemaphoreSlim(maxConcurrency);
        _timeout = timeout;
    }
    
    public async Task<T> ExecuteAsync<T>(Func<Task<T>> operation)
    {
        // 1. Check circuit breaker first (fail fast if open)
        if (_circuitBreaker.State == CircuitState.Open)
        {
            throw new CircuitBreakerOpenException();
        }
        
        // 2. Enter bulkhead (resource isolation)
        bool entered = await _bulkhead.WaitAsync(TimeSpan.FromSeconds(5));
        if (!entered)
        {
            _circuitBreaker.RecordFailure();  // Bulkhead full counts as failure
            throw new BulkheadRejectedException();
        }
        
        try
        {
            // 3. Execute with timeout
            using var cts = new CancellationTokenSource(_timeout);
            
            var result = await _circuitBreaker.ExecuteAsync(async () =>
            {
                return await operation().WaitAsync(cts.Token);
            });
            
            return result;
        }
        catch (OperationCanceledException) when (cts.IsCancellationRequested)
        {
            _circuitBreaker.RecordFailure();
            throw new TimeoutException($"Operation timed out after {_timeout.TotalSeconds}s");
        }
        finally
        {
            _bulkhead.Release();
        }
    }
}
```

```csharp
            npgsqlOptions.CommandTimeout(30);

// Monitor pool exhaustion
public class ConnectionPoolMonitor : BackgroundService
{
    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            var stats = GetPoolStatistics();
            
            if (stats.AvailableConnections < stats.MinPoolSize * 0.2)
            {
                _logger.LogWarning(
                    "Connection pool nearly exhausted: {Available}/{Total}",
                    stats.AvailableConnections,
                    stats.TotalConnections);
            }
            
            _metrics.RecordGauge("db.pool.available", stats.AvailableConnections);
            _metrics.RecordGauge("db.pool.total", stats.TotalConnections);
            
            await Task.Delay(TimeSpan.FromSeconds(10), stoppingToken);
        }
    }
}
```

```csharp
public class TimeoutMetrics
```

### Bulkhead Health Check

```csharp
public class BulkheadHealthCheck : IHealthCheck
{
    private readonly Dictionary<string, SemaphoreSlim> _bulkheads;
    
    public Task<HealthCheckResult> CheckHealthAsync(
        HealthCheckContext context,
        CancellationToken cancellationToken = default)
    {
        var unhealthy = new List<string>();
        
        foreach (var (name, semaphore) in _bulkheads)
        {
            var utilization = (double)semaphore.CurrentCount / _capacity[name];
            
            if (utilization < 0.1)  // Less than 10% available
            {
                unhealthy.Add($"{name}: {utilization:P0} available");
            }
        }
        
        if (unhealthy.Any())
        {
            return Task.FromResult(HealthCheckResult.Degraded(
                $"Bulkheads nearly full: {string.Join(", ", unhealthy)}"));
        }
        
        return Task.FromResult(HealthCheckResult.Healthy());
    }
}
```

## Testing Timeouts and Bulkheads

### Timeout Testing

```csharp
[Fact]
public async Task Operation_TimesOut_AfterConfiguredDuration()
{
    // Arrange
    var timeout = TimeSpan.FromSeconds(2);
    var slowOperation = async () =>
    {
        await Task.Delay(TimeSpan.FromSeconds(10));
        return "result";
    };
    
    // Act & Assert
    var sw = Stopwatch.StartNew();
    await Assert.ThrowsAsync<TimeoutException>(async () =>
    {
        using var cts = new CancellationTokenSource(timeout);
        await slowOperation().WaitAsync(cts.Token);
    });
    
    sw.Stop();
    Assert.True(sw.Elapsed < TimeSpan.FromSeconds(3), "Should timeout quickly");
}
```

### Bulkhead Testing

```csharp
[Fact]
public async Task Bulkhead_RejectsRequests_WhenFull()
{
    // Arrange
    var bulkhead = new ThreadPoolBulkhead(maxParallelization: 2);
    var longRunningTask = () => Task.Delay(TimeSpan.FromSeconds(30));
    
    // Act - fill bulkhead
    var task1 = bulkhead.ExecuteAsync(longRunningTask, TimeSpan.FromMinutes(1));
    var task2 = bulkhead.ExecuteAsync(longRunningTask, TimeSpan.FromMinutes(1));
    
    await Task.Delay(100);  // Ensure tasks are running
    
    // Assert - 3rd task should be rejected
    await Assert.ThrowsAsync<BulkheadRejectedException>(async () =>
    {
        await bulkhead.ExecuteAsync(longRunningTask, TimeSpan.FromSeconds(1));
    });
}
```
